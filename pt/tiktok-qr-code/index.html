Qual link do TikTok usar

O TikTok oferece três tipos de URL, e impressos eles se comportam de forma diferente.

Tipo de linkParece comA leitura abreSobrevive se o vídeo for apagado?
Perfiltiktok.com/@yourhandleseu perfil, botão de seguir no toposim
Vídeo únicotiktok.com/@yourhandle/video/7312…esse vídeo, em reproduçãonão
Hashtagtiktok.com/tag/yourcampaigntodos os vídeos da tagsim, mas mostra publicações de outras pessoas

Para cartão de visita, vitrine ou encarte na embalagem, use o link do perfil. Ele continua valendo conforme você publica, e o botão de seguir fica a um toque da página de destino.

Use um link de vídeo quando o código tiver uma única missão: um cartaz de lançamento, ou um adesivo no produto apontando para o anúncio. O link fixa um ID de vídeo. Apague o vídeo e o código morre.

Links de hashtag funcionam, mas mostram as publicações de todo mundo naquela tag, não só as suas. Bom para uma página de campanha, ruim para um cartão de visita.

A passagem para o app é um aviso, não uma garantia. Alguns celulares mostram um banner em tela cheia "Abrir no TikTok?", outros uma barra fina no topo, e alguns abrem o site móvel sem aviso nenhum. A maioria das pessoas toca, mas algumas não — conte com uma parte das leituras caindo na versão web.

Duas consequências para planejar. Escanear não é seguir: a pessoa ainda precisa tocar em Seguir depois de chegar, então o código leva até a porta, não através dela. E a versão web móvel carrega mais devagar que o app, o que pesa se o código estiver numa embalagem onde a atenção já é escassa.

Uma conta privada mostra a quem escaneia a versão básica do perfil e um botão de solicitação. Nenhum QR code contorna esse ajuste.

O QR code do próprio TikTok, e quando usá-lo

O app já traz um: abra seu perfil, toque no ícone de compartilhar, escolha código QR. É grátis e funciona — dentro do TikTok.

O problema é quem consegue ler. Esse código foi feito para o leitor do TikTok. Escaneie com a câmera de um iPhone ou a câmera padrão do Android e muitas vezes não acontece nada, ou pedem para instalar o TikTok antes. Numa tela de celular, com o app já aberto, tudo bem. Num adesivo impresso, numa vitrine ou num cardápio, quem escaneia é um estranho com a câmera padrão.

O código que você cria aqui é um QR padrão. Qualquer câmera lê, e o link dentro se comporta como uma URL digitada. É toda a diferença, e o motivo de valer a pena gerar um código impresso separado do que fica no app.

Um ponto de atenção: seu nome de usuário faz parte da URL. Renomeie a conta e os dois códigos quebram. Gere um novo depois da troca e substitua tudo que já foi impresso.

Preserve a zona de silêncio. A margem branca ao redor do padrão é o que permite às câmeras encontrar o código, e cortá-la para caber no design é o motivo mais comum de um código impresso falhar.

Teste a prova com um celular antes da tiragem. Um código que funciona na tela pode falhar numa garrafa curva ou num rótulo brilhante, e você só descobre quando as caixas chegam.

Bom saber

Link do perfil ou um vídeo específico?

Link do perfil para seguidores em geral. Um link de vídeo reproduz um vídeo — útil para campanhas, encartes de embalagem e pôsteres de lançamento.

How do I copy my TikTok link?

Open the profile or video, tap Share, then Copy link. On desktop, copy the URL from the address bar. Both give the same permanent address.

Ele abre no app do TikTok?

Na maioria dos celulares, sim — tocar no link escaneado oferece o app, se instalado; caso contrário, abre no navegador.

Posso adicionar meu logo ou as cores da minha marca?

Sim — envie seu logo e defina as cores da sua marca. Mantenha o contraste alto para escanear sob qualquer luz.

Expira se eu mudar meu nome de usuário?

O código codifica a URL exata, então se seu @ mudar, crie um código novo. O código em si nunca expira.
