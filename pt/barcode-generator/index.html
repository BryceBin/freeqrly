Bom saber

Qual formato de código de barras devo usar?

Code 128 para uso geral — aceita qualquer texto. EAN-13 para produtos de varejo vendidos internacionalmente, UPC-A para varejo nos EUA, Code 39 quando o scanner é antigo ou o código precisa ser legível por humanos, ITF-14 para caixas de transporte.

Preciso de um dígito verificador?

Não — para EAN-13, UPC-A e ITF-14, digite um dígito a menos e o dígito verificador é calculado para você. Code 128 e Code 39 não precisam de nenhum.

PNG ou SVG para impressão?

SVG para embalagens e impressão profissional — escala infinitamente sem borrar. PNG para impressão de escritório e apps que não aceitam SVG.

É mesmo grátis? Tem marca d'água?

Grátis, sem marca d'água, sem cadastro. O código de barras é desenhado no seu navegador — nada é enviado.
