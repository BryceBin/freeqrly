Onde hospedar seu PDF

Um QR code contém um link, não um arquivo. O código que você imprime aponta para onde seu PDF já está, então a primeira decisão é onde hospedá-lo. Três opções cobrem quase todos os casos.

Onde ele ficaComo o link aparecePlano gratuitoQuebra se você...
Google Drivedrive.google.com/file/d/…/view15 GBmover o arquivo, apagá-lo ou mudar quem pode vê-lo
Dropboxdropbox.com/s/…/menu.pdf2 GBapagar ou renomear o arquivo
Seu próprio siteyoursite.com/menu.pdfdepende da hospedagemremover o arquivo

Seja qual for a opção, defina o compartilhamento como "qualquer pessoa com o link". Um PDF compartilhado com pessoas específicas pede login a cada leitura, e a maioria não vai fazer isso.

Por que um link do Drive às vezes mostra um aviso

Duas coisas confundem as pessoas, e nenhuma tem a ver com o código.

A primeira é o tamanho do arquivo. O Google verifica downloads do Drive em busca de vírus e pula essa verificação acima de 100 MB. Em vez do download, você vê uma página dizendo que o Google não conseguiu verificar o arquivo, com um botão para continuar mesmo assim. O PDF abre, mas numa mesa de restaurante parece suspeito. Mantenha cardápios e folhetos abaixo de 100 MB e o aviso nunca aparece.

A segunda é a permissão. Se o arquivo ainda estiver privado, quem escaneia cai numa página de login do Google. Abra as configurações de compartilhamento e mude para "qualquer pessoa com o link pode ver".

Se nenhuma das duas soluções for viável — um portfólio de 300 MB, ou um cliente que insiste numa pasta privada —, hospede o PDF no seu próprio domínio. Você controla as permissões, e não há página intermediária.

Qual tamanho imprimir

Um código que funciona no seu monitor pode falhar numa parede. A regra prática: o código impresso deve medir cerca de um décimo da distância de leitura esperada. A 3 metros, imprima um código de 30 cm.

Onde ele ficaDistância habitual de leituraMenor tamanho que funcionaTamanho confortável
Display de balcão, cartão de mesa30 cm3 cm4–5 cm
Cartaz A4 na vitrine1–2 m10 cm15 cm
Placa de porta, painel de feira3 m30 cm40 cm
Embalagem do produto15–25 cm2 cm3 cm

Deixe margem. A borda branca ao redor do padrão — a zona de silêncio — é parte do que permite aos leitores encontrar o código. Cortá-la para ganhar espaço é o motivo mais comum de um código impresso parar de funcionar.

Quando você atualiza o PDF

O código aponta para um link. Poder trocar o PDF sem reimprimir depende inteiramente de o link continuar igual.

Se você substituir o arquivo no mesmo lugar, o link sobrevive. No Drive, abra o arquivo existente e envie uma nova versão em vez de criar outro; no Dropbox, sobrescreva o arquivo no mesmo caminho. A URL não muda, então todos os códigos impressos continuam funcionando.

Se você enviar um arquivo novo, ganha um link novo. O código antigo agora abre um arquivo apagado ou um 404. Vai precisar reimprimir — algo bom de saber antes de encomendar 500 cartões de mesa.

Mais um caso: se o PDF estiver no seu domínio e o nome do arquivo não mudar, trocar o arquivo por trás é invisível para quem escaneia. É a configuração mais tolerante, e a que escolheríamos para qualquer tiragem grande.

Teste antes de imprimir

Escaneie o código na tela com dois celulares diferentes — um iPhone e um Android — antes de mandar para a gráfica. Tela e papel falham de formas diferentes: reflexo, tinta que espalha e zona de silêncio cortada só aparecem na versão impressa.

Depois escaneie a prova na distância prevista. Se levar mais de um segundo para reconhecer, o código está pequeno demais para aquele lugar, não mal feito.

Bom saber

Posso enviar um PDF direto aqui?

O FreeQrly não hospeda arquivos — seu PDF fica no Drive, Dropbox ou no seu site, e o QR code apenas abre o link. Isso também significa que você pode trocar o arquivo depois sem reimprimir, desde que o link continue o mesmo.

Does the scanner download the PDF or preview it?

It depends on the file and the phone. iOS and Android both preview most PDFs in the browser before saving; a large file may download instead. Keep the PDF under a few megabytes if you want it to open quickly at the table.

E se o PDF for grande?

O tamanho não importa para o código — ele só codifica o link. Mantenha o próprio PDF em um tamanho razoável para abrir rápido nos celulares.
