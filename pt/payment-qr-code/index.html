Quais serviços de pagamento funcionam?

Qualquer serviço que forneça um link de pagamento: PayPal.me, Venmo, Cash App, Stripe Payment Links e a maioria das páginas de checkout. O QR code apenas abre seu link.

É seguro imprimir um link de pagamento?

O código só abre seu link de pagamento público — o mesmo link que você enviaria em uma mensagem. Nunca codifique dados privados da conta; use o link oficial de compartilhamento do serviço.

Posso pré-definir o valor?

Sim, se seu link de pagamento permitir (o PayPal.me deixa adicionar um valor). O código abre o que o link contiver.

Ele expira?

Não. Códigos estáticos nunca expiram e não precisam de conta.
