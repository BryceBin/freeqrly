Bom saber

Um QR code grátis expira?

Nunca. O destino vai codificado no padrão, então funciona enquanto o destino existir. Códigos dinâmicos pagos passam pelos servidores do fornecedor e podem morrer se você parar de pagar — mais um motivo para preferir o estático.

Minha senha do WiFi está segura aqui?

Em um código estático, sim. Sua senha nunca sai do seu navegador — nada é enviado a lugar algum. Precavido? Carregue a página, desconecte-se e digite.

Estático ou dinâmico?

Se o destino não vai mudar, use estático: WiFi, cartões, links fixos. Os dinâmicos (links editáveis e estatísticas) servem para campanhas — estão no nosso roteiro.

Posso usar comercialmente?

Claro. Tudo que você criar aqui é seu — embalagens, cardápios, cartões, sem atribuição.

O FreeQrly é realmente grátis?

Sim — tudo nesta página é grátis, sem marca d'água. Os estáticos não precisam de conta. Não vendemos assinaturas; isto é uma ferramenta, não um funil.

Preciso de uma conta?

Para os estáticos, não. Não há nada para cadastrar — abra a página e crie seu código. Os dinâmicos pedem uma conta grátis, para editar depois de imprimir.

Posso colocar meu logo no código?

Sim — envie um logo quadrado e o colocamos no centro, aumentando automaticamente a correção de erros para continuar escaneável. Para impressão, use Q ou H.
