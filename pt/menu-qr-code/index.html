Cardápio em PDF ou página web — qual é melhor?

Uma página web carrega mais rápido e é mais fácil de editar; um PDF preserva seu layout exato. Ambos funcionam — escolha o que você já tem.

Posso atualizar o cardápio sem reimprimir?

Sim, se você substituir o arquivo no mesmo link. Os convidados que escanearem o mesmo código veem o novo cardápio.

Os clientes precisam de um app?

Não. A câmera de qualquer celular abre o cardápio direto pelo scan.

Qual tamanho para displays de mesa?

Pelo menos 3 x 3 cm para os convidados escanearem das mesas. Maior é mais seguro em salões pouco iluminados.
