Ofertas de Black Friday, a um escaneamento de distância.

Um cliente de Black Friday não vai digitar um código promocional, uma URL longa, nem criar uma conta no caixa. Ele vai escanear um código — ou passar direto pela oferta. Um QR code transforma cada superfície dentro e ao redor da sua loja numa porta de entrada para a promoção — cartaz de vitrine, etiqueta de prateleira, panfleto, recibo, postagem, e-mail. O cliente aponta o celular e o desconto abre. A decisão mais importante é tomada antes de imprimir qualquer coisa: estático ou dinâmico? Um código estático é o certo para um cupom fixo. Um código dinâmico é o certo para tudo que pode mudar — a página da promoção, a oferta por hora, o item que esgota antes do meio-dia. Acertando essa escolha em cada lugar, o resto do fim de semana fica fácil.

Códigos estáticos vs. dinâmicos para uma promoção curta

Um código estático tem o destino — um link, um código de cupom, um texto — gravado no próprio padrão. Ele nunca pode mudar, não precisa de conta nem de servidor: o FreeQrly o gera inteiramente no seu navegador, sem nada enviado e sem rastreamento. Um código dinâmico guarda um link curto de redirecionamento. O padrão impresso fica o mesmo, mas você pode mudar para onde ele aponta e ver quantas vezes foi escaneado. Códigos dinâmicos exigem login gratuito para serem criados.

Para uma promoção de três dias, essa diferença é toda a estratégia — a maioria das lojas precisa dos dois, decididos por lugar, não por campanha.

A regra de ouro: se a oferta está impressa como texto no mesmo cartaz ("20% de desconto, código BF20"), o código pode ser estático — o texto do cupom nunca muda. Se o escaneamento abre uma página cujo conteúdo, preço ou estoque pode mudar durante o fim de semana, faça dinâmico. Um código dinâmico custa um login gratuito e um minuto de configuração; uma reimpressão custa uma tiragem de cartazes, uma escada e a manhã de sexta-feira.

A jornada do cliente: ver, escanear, resgatar e usar

Um QR code de Black Friday falha em exatamente quatro lugares, um em cada passo da jornada. Projete pensando no passo em que os clientes desistem de fato.

Figura 1: do cartaz à compra. Quatro passos com setas — ver o código, escaneá-lo, resgatar o cupom, usá-lo (na loja, no caixa, ou online, no checkout). Nota abaixo: "Cada passo deve levar segundos. Se um passo exige digitar, fazer login ou baixar um aplicativo, os clientes desistem."

  • Veja o código. É preciso reparar nele antes de poder escaneá-lo. Coloque-o na altura dos olhos, deixe uma margem de respiro e acrescente uma frase curta dizendo o que o escaneamento dá: "Escaneie e ganhe 20% de desconto" é melhor que "Escaneie-me", porque responde à única pergunta de quem passa — o que eu ganho com isso?
  • Escaneie. Tem que funcionar só com a câmera do celular, sem aplicativo — como todo código que o FreeQrly faz. Teste no iPhone e no Android antes de imprimir, na luz real e na distância real.
  • Resgate o cupom. A página que o escaneamento abre deve mostrar o desconto e as condições na primeira tela — porcentagem, valor mínimo, validade — sem nada para digitar e sem cadastro. Cada campo a mais custa resgates.
  • Use o cupom. Na loja, o cliente mostra o celular no caixa. On-line, o desconto já deve estar aplicado no checkout, ou o cupom deve ser copiado com um toque. Se o resgate exige que a equipe consulte alguma coisa, ou que o cliente lembre uma sequência de caracteres, a jornada quebra no último passo.

Dicas de impressão e posicionamento

  • O tamanho segue a distância. Regra aproximada: o código deve ter cerca de um décimo da largura da distância de onde será escaneado. Uma etiqueta de prateleira escaneada a 30 cm de distância pode ter 3 cm de largura; um cartaz de vitrine escaneado da calçada precisa de pelo menos 10 cm (4 pol.). Na dúvida, imprima maior.
  • O contraste não é opcional. Código escuro sobre fundo claro, sempre. Um código preto num cartaz preto, um código dourado sobre amarelo ou um código sobre uma foto cheia de detalhes não escaneia com confiança na luz da loja. Se o cartaz for escuro, coloque o código sobre um quadrado branco.
  • Deixe uma zona de silêncio. Mantenha uma margem livre ao redor do código pelo menos tão larga quanto um dos quadradinhos dele — sem texto, sem logos, sem borda encostando nele.
  • Use correção de erros alta para tudo que é manuseado ou fica ao ar livre. Ajuste a correção de erros para Alto ou Máximo em recibos, panfletos e embalagens que serão dobrados, molhados de chuva ou arranhados. Uma correção de erros maior permite que o código sobreviva a danos; o custo é um padrão um pouco mais denso.
  • Coloque seu logo no centro, com cuidado. Mantenha-o pequeno — menos de cerca de um quinto da largura do código — e use correção de erros alta para que o código continue legível.
  • Imprima um, escaneie e só então imprima o resto. Imprima uma cópia de cada arte, escaneie-a no lugar real, da distância real, na luz real, e só então imprima a leva.
  • Escreva a oferta em palavras ao lado do código. "Escaneie e ganhe 20% de desconto só hoje" diz ao cliente por que vale a pena. Um código sozinho é decoração — e se um celular não conseguir escaneá-lo, o cliente ainda consegue ler a oferta.

Resgate e fraude: cupons de uso único vs. cupons ilimitados

  • Cupons ilimitados são o padrão para uma oferta-relâmpago de Black Friday: um código, qualquer um pode usar, sem controle de quem resgatou. Simples, rápido num caixa cheio, e ideal quando o desconto é modesto e o objetivo é movimento na loja. O risco é exatamente o que parece — o código se espalha. Para uma oferta de 10–20% para a loja toda, isso geralmente é aceitável; o compartilhamento é o marketing.
  • Cupons de uso único fazem sentido quando o desconto é grande — um item de alto valor, uma porcentagem alta, um brinde. O uso único precisa de um sistema por trás do código: um código único por cliente, uma lista que o caixa possa conferir, um jeito de marcá-lo como usado. Um único código estático não faz isso — todo mundo que escaneia o mesmo cartaz recebe o mesmo código. Se precisar de uso único, gere códigos únicos por cliente (o modo em Lote faz até 50 de cada vez) e valide-os no caixa ou no checkout.
  • Um meio-termo prático. A maioria dos pequenos varejistas se dá bem com códigos ilimitados mais três controles baratos: uma validade clara ("só na sexta-feira"), um valor mínimo de compra e um limite por compra ("um desconto por compra"). Imprima-os no cartaz, mostre-os na landing page e aplique-os no caixa — sem precisar de nenhum sistema extra.
  • Orientar a equipe vale mais que software. Diga à equipe do caixa, por escrito, o que cada código faz, quais são as condições e o que fazer quando um cliente mostra um print da tela do celular de outra pessoa. Uma orientação de cinco minutos na manhã de sexta-feira evita mais fraudes — e mais discussões — do que qualquer sistema de validação.
  • Depois da promoção, deixe a validade bem visível. Se um cupom tem validade, respeite-a e diga isso no cartaz. Nada destrói a confiança mais rápido do que um código que funcionou na sexta-feira e falha em silêncio no sábado.

Quando a oferta muda no meio da promoção

  1. Redirecione, não reimprima. Esse é todo o motivo de usar códigos dinâmicos para páginas de ofertas e ofertas-relâmpago. Edite o destino no seu painel; o código impresso continua funcionando. Uma reimpressão leva horas que você não tem numa sexta-feira.
  2. Decida com antecedência para onde aponta um código esgotado. O padrão deve ser a página principal da promoção ou o item equivalente mais próximo — nunca uma página fora do ar, e nunca uma página ainda anunciando o item esgotado pelo preço antigo. Escreva o plano B na sua lista de códigos durante a semana de planejamento.
  3. Mude o destino e, se der, o texto do cartaz. Se o cartaz diz "50% de desconto em fones de ouvido" e os fones acabaram, um adesivinho "esgotado — veja as ofertas de hoje" sobre o título é honesto e leva um minuto. O redirecionamento do código faz o resto.
  4. Deixe uma só pessoa responsável pelas mudanças. Edições no meio da promoção feitas por três pessoas geram três destinos diferentes. Uma pessoa cuida do painel no fim de semana; todo o resto passa os pedidos por ela. Registre cada mudança numa linha só — horário, código, destino antigo e novo.

Bom saber

Estático ou dinâmico — o que uma promoção de Black Friday precisa?

Os dois, para funções diferentes. Estático para o próprio código do cupom: ele carrega o código como texto e nunca expira. Dinâmico para tudo que muda — a página da promoção, as ofertas por hora, o estoque que esgota. Códigos dinâmicos são grátis com cadastro, e o plano gratuito inclui 20 deles.

Posso mudar para onde um código já impresso aponta?

Sim — é isso que dinâmico significa aqui. Edite o destino no seu painel quando quiser; o código impresso nunca muda. Códigos estáticos não podem ser alterados depois de imprimir, e é por isso que só servem para cupons fixos.

O que acontece com meus códigos depois da liquidação?

Nada expira. Redirecione os códigos dinâmicos para a sua próxima campanha e guarde os cartazes para o ano que vem — os mesmos códigos, novas ofertas. Códigos estáticos continuam funcionando enquanto a página ou o cupom por trás deles seguir válido.

Qual deve ser o tamanho do código num cartaz de vitrine?

Grande o bastante para escanear através do vidro, da calçada — 10 cm ou mais. A regra é mais ou menos um décimo da distância de escaneamento, então teste da calçada, não de dentro da loja.

Consigo fazer um código diferente para cada produto em oferta?

Sim — use o modo em Lote no gerador: um link por linha, ou envie um arquivo CSV/XLSX, até 50 códigos por lote, baixados num ZIP de PNGs. O lote é só para códigos estáticos, então use-o para páginas fixas por produto e cupons.

Os clientes precisam de aplicativo para escanear o código?

Não. Todo código abre com a câmera embutida do celular. Se um código parece exigir um aplicativo, ele foi feito errado — faça um escaneamento de teste com a câmera comum antes de imprimir.

Como evito que um cupom seja compartilhado por todas as redes sociais?

Não dá para impedir que um cupom estático seja printado. Se o desconto é grande, use códigos de uso único validados no caixa em vez de um código compartilhado. Para a maioria das ofertas da loja inteira, uma data de validade, um valor mínimo e um limite de um por transação bastam — e o compartilhamento traz clientes para você.
