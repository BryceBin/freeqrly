Bom saber

Este scanner é privado?

Sim. A imagem é decodificada por JavaScript rodando no seu dispositivo. Nada é enviado a nenhum servidor — carregue a página, fique offline, e o envio de imagens continua funcionando.

Por que meu QR code não escaneia?

Geralmente é pequeno demais, com baixo contraste, danificado ou fotografado em ângulo acentuado. Segure firme, preencha o quadro com o código e use boa luz. A lista completa está em por que meu QR code não escaneia.

Preciso instalar alguma coisa?

Não — qualquer navegador moderno de celular ou desktop funciona. O modo câmera pede permissão de câmera uma vez; o modo de envio funciona em todo lugar, mesmo offline.

Posso criar meus próprios QR codes também?

Claro — essa é a atração principal. Gere um QR code grátis com seu logo, em 13 tipos de código QR, incluindo o modo lote, direto no seu navegador.
