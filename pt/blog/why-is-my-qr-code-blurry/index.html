Por que meu QR code está embaçado?

Um QR code embaçado quase sempre é um problema de resolução: poucos pixels esticados em espaço demais. A correção é exportar maior — ou em SVG.

October 17, 2026 · 4 min de leitura

Um QR code parece nítido na tela e vira uma mancha no papel. A causa quase sempre é a mesma: a imagem não tinha pixels suficientes para o tamanho em que foi impressa. Um QR code é uma grade de quadradinhos — quando não há pixels suficientes, as bordas borram, os celulares não encontram a grade e os scans falham.

As 5 causas mais comuns

  1. Exportação em baixa resolução. Um PNG de 512 px parece bom com 2 cm de largura. Ampliado para um pôster de 20 cm, cada módulo vira uma mancha. Quanto maior a impressão, mais pixels você precisa.
  2. Compressão JPEG. O JPEG borra bordas nítidas — exatamente do que um QR code é feito. Um código salvo como JPEG de baixa qualidade pode falhar até em tamanhos pequenos. Só PNG ou SVG.
  3. Distorção. Arrastar um canto da imagem distorce a grade: quadrados viram retângulos e os leitores desistem. Sempre redimensione proporcionalmente.
  4. Impressão ruim. Impressoras de baixo DPI, vazamento de tinta em papel áspero ou absorvente e reflexo de papel brilhante suavizam as bordas. Papel fosco e impressora a laser ganham de jato de tinta em guardanapo.
  5. Cópia da cópia. Tirar print de um código numa mensagem e depois print desse print perde resolução a cada vez. Sempre volte à exportação original.

Como corrigir

  • Exporte maior. PNG em 1024 px para cartões e flyers, 2048 px para pôsteres. Regra prática: o tamanho da impressão em cm, vezes ~100, é a quantidade de pixels que você quer.
  • Use SVG para impressão. SVG é vetor — escalável infinitamente sem nenhum borrão. Use sempre que a gráfica ou o designer aceitar.
  • Mantenha as proporções. Segure Shift (ou o ícone de cadeado) ao redimensionar para os quadrados continuarem quadrados.
  • Teste no tamanho final. Imprima uma cópia no tamanho real, afaste-se até a distância real de leitura e escaneie com seu celular. Se ler de primeira, o lote está seguro.

Ainda não escaneia depois de uma reimpressão nítida? O problema é outro — tamanho, contraste ou dano. O guia completo de solução de problemas cobre esses casos. Para a regra de tamanho vs. distância, veja o guia de tamanho de impressão.

Por que meu QR code parece embaçado, mas ainda escaneia?

Celulares são tolerantes — a correção de erros recupera uma quantidade surpreendente de borrão. Mas um código que escaneia no seu escritório claro pode falhar com pouca luz ou à distância do braço. Nítido é seguro; quase-escaneando, não.

De qual resolução preciso para um pôster?

PNG de 2048 px no mínimo, ou SVG. Um pôster visto a 2 metros precisa de muito mais pixels que um cartão de visita visto a 30 cm — veja o guia de tamanho de impressão para a regra da distância.

PNG ou SVG para impressão?

SVG sempre que a gráfica ou o designer aceitar — ele escala infinitamente sem nenhum borrão. PNG em 1024–2048 px é a alternativa para impressão de escritório e apps que não aceitam SVG.

Dá para corrigir um código impresso embaçado sem reimprimir?

Não. O borrão está gravado na imagem impressa. Reimprima a partir de uma exportação em maior resolução (ou SVG). Editar um código dinâmico não ajuda — o padrão no papel é o que é.
