Edite um QR code depois de imprimir

Os folhetos já saíram — e o link está errado. Com um código dinâmico, isso é uma correção de dois minutos, não uma reimpressão.

October 16, 2026 · 4 min de leitura

Os folhetos já saíram — e o link está errado. Ou o cardápio mudou. Ou a página da campanha não estava final quando o pôster foi para impressão. Com um código estático, isso é uma reimpressão. Com um código dinâmico, é uma correção de dois minutos.

O truque: o padrão de um código dinâmico nunca muda. Ele aponta para um link curto no servidor do FreeQrly, e você controla para onde esse link manda as pessoas. Edite o destino e cada cópia impressa — já nas paredes, folhetos, embalagens — passa a servir o conteúdo novo na hora. Sem reimpressão, sem adesivos sobre o código antigo.

  1. Entre. Abra a página de login e entre na conta que é dona do código.
  2. Abra o Painel. Vá para seu Painel. Todo código dinâmico da sua conta está lá como um cartão, com sua miniatura do QR e a contagem de scans.
  3. Abra Editar. No cartão do código, clique em Editar. Você verá o mesmo gerador que usou para criá-lo — tipo, conteúdo, estilo, tudo.
  4. Mude o que precisar. Destino, conteúdo, até o tipo: um código de Site pode virar um código de WiFi. Cores, logo, moldura — tudo editável também.
  5. Salvar. Clique em Salvar alterações. Pronto. O código impresso agora serve o conteúdo novo. Teste com a câmera do seu celular para confirmar.

O que você pode mudar — e o que não pode

  • Destino e conteúdo: o link, o texto, a senha do WiFi — qualquer coisa que o código carregue.
  • Tipo: mude um código de um tipo de conteúdo para outro. O padrão não se importa; ele só guarda o link curto.
  • Estilo: cores, pontos, logo, moldura. A miniatura do Painel atualiza para combinar.
  • O que você não pode mudar: o padrão impresso em si — mas você nunca precisa, já que o padrão só guarda o link curto. E você não pode transferir um código para outra conta.

Duas coisas que valem saber

Edições são instantâneas e silenciosas. Não há etapa de "republicar" nem atraso — o próximo scan já recebe o novo destino. Se o destino antigo era uma página que você tirou do ar, corrija o código primeiro e depois tire a página do ar.

Excluir é permanente. Exclua um código e suas cópias impressas param de funcionar — não há desfazer. Exclua só quando o código estiver realmente aposentado; a vaga libera para um código novo. Preciso reimprimir um QR code depois de editá-lo?

Não. O padrão impresso guarda um link curto; editar muda para onde esse link aponta. Cada cópia impressa serve o conteúdo novo imediatamente.

Posso mudar um QR code dinâmico para outro tipo?

Sim. No Painel, abra Editar e escolha um novo tipo — um código de Site pode virar um código de WiFi, por exemplo. O padrão impresso continua válido.

Editar um QR code zera as estatísticas de escaneamento?

Não. As estatísticas continuam acumulando no mesmo código. Excluir um código remove ele e suas estatísticas permanentemente.

E se eu excluir um QR code dinâmico por engano?

Não há desfazer — as cópias impressas param de funcionar e a vaga libera. Exclua só códigos realmente aposentados.
