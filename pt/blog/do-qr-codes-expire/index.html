QR codes expiram?

Resposta curta: não — pelo menos, não o tipo que você cria aqui. A resposta longa vale a pena conhecer antes de imprimir mil deles.

October 13, 2026 · 4 min de leitura

Você já viu os avisos: "QR codes grátis expiram!" Geralmente bem ao lado de uma página de preços. Então vamos resolver isso com clareza: um QR code estático não pode expirar. Não há relógio dentro daqueles quadradinhos. Um código estático é apenas seu link, desenhado como um padrão. Enquanto o link funcionar, o código funciona — imprima hoje, escaneie daqui a dez anos.

Então por que as pessoas dizem que QR codes expiram?

Três coisas diferentes se misturam:

  • Códigos dinâmicos morrem quando você para de pagar. Muitos geradores "grátis" na verdade criam códigos dinâmicos: em vez do seu link, o padrão guarda uma URL curta no servidor deles, que redireciona para o seu link. Pare de pagar e eles desligam o redirecionamento. Seu código não expirou — ele foi feito de refém.
  • Links apodrecem; códigos, não. Se a página por trás do código for excluída, o scan não leva a lugar algum. É o destino morrendo, não o código. Um QR code apontando para um link morto é um código perfeitamente saudável sem nada a dizer.
  • Contas de teste são desativadas. Alguns serviços vinculam seus códigos a uma conta e depois empurram você para uma assinatura. O código não expirou — a conta, sim.

Estático vs. dinâmico, em um parágrafo

Um código estático codifica o destino diretamente: WIFI:T:WPA;S:MyCafe;P:secret;; ou https://your-site.com/menu. Nada para manter, nada para cobrar. Um código dinâmico codifica um redirecionamento no servidor de alguém, o que permite ao dono mudar o destino depois e contar scans. Útil para campanhas de marketing — e uma assinatura para sempre.

Regra geral: se o destino nunca vai mudar — seu WiFi, seu cartão de visita, seu cardápio de restaurante — o estático não é a opção barata. É a opção certa.

O que realmente dá errado com códigos impressos

Como expiração não existe, aqui está o que realmente observar:

  • Impressão pequena demais. Como regra geral, mantenha códigos com pelo menos 2 × 2 cm e uma margem de silêncio. Códigos minúsculos em cartões de visita são uma falha comum de scan.
  • Baixo contraste. Tinta escura sobre fundo claro. Aquele código de casamento champanhe sobre creme é lindo e ilegível.
  • Danos. Códigos externos desbotam e riscam. Maior correção de erros (nosso padrão é M, e aumentamos automaticamente quando você adiciona um logo) permite que um código sobreviva a até 30% de danos no nível Alto definido na ISO/IEC 18004.
  • Mudanças de link. Mudando de site? O código antigo ainda aponta para a URL antiga. Mantenha uma lista de onde cada código vive.

QR codes grátis expiram?

Não. Um QR code estático grátis dura tanto quanto o link para o qual aponta. Códigos que "expiram" são códigos dinâmicos vinculados a uma assinatura paga — o fornecedor os desliga quando você para de pagar.

Um QR code pode parar de funcionar?

Sim, mas não por expiração. As causas usuais: a página de destino foi excluída, o código foi impresso pequeno demais ou com baixo contraste, ou foi danificado fisicamente.

Quanto tempo duram os QR codes estáticos?

Indefinidamente. O padrão codifica seus dados diretamente sem nenhum servidor envolvido, então não há nada para manter ou renovar.
