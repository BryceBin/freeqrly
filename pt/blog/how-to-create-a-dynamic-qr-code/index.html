Como criar um QR code dinâmico

Um QR code dinâmico permite mudar o destino depois de imprimir — e ver quantas pessoas escanearam. Veja como fazer um, de graça, em cerca de um minuto.

October 16, 2026 · 4 min de leitura

Códigos estáticos são ótimos — até o destino mudar. O folheto já foi impresso, o cardápio mudou, a URL da campanha não estava final. Um QR code dinâmico resolve isso: o padrão impresso continua o mesmo, mas você pode mudar para onde ele aponta, quando quiser, no seu Painel. Você também recebe contagens de scans, para saber se alguém está realmente escaneando.

No FreeQrly, códigos dinâmicos são grátis. Entre (e-mail, Google ou GitHub) e você recebe 8. Sem teste, sem cartão, sem joguinhos de expiração. Veja o processo inteiro.

  1. Entre — grátis. Abra a página de login e crie uma conta com e-mail + senha, Google ou GitHub. Códigos estáticos nunca precisam disso; os dinâmicos, sim, porque o código precisa pertencer a alguém.
  2. Mude para Dinâmico. No estúdio, vire a chave de Estático para Dinâmico. Todo o resto — tipos, estilo, download — funciona exatamente igual.
  3. Escolha um tipo e preencha. Site, WiFi, contato, evento — todos os 12 tipos de conteúdo funcionam como códigos dinâmicos. (O lote continua estático: um código dinâmico por geração.)
  4. Estilize se quiser. Pontos, cores, logo, moldura — a prévia atualiza ao vivo. O estilo é salvo com o código, então o Painel e o download combinam.
  5. Gerar. Clique em Gerar. Você recebe um link curto como freeqrly.com/q/XXXXXXX — é isso que o padrão do QR codifica. Imprima, envie, cole na parede.
  6. Gerencie depois. Seus códigos vivem no Painel: edite, confira as estatísticas ou exclua um para liberar uma vaga.

O que o QR code realmente contém

Um código dinâmico não guarda seu link diretamente. Ele guarda um link curto do FreeQrly, e nosso servidor redireciona quem escaneia para o seu destino. Esse é o mecanismo que torna a edição e a contagem possíveis — e é por isso que códigos dinâmicos precisam de conta e os estáticos não. Se um serviço disser que seus códigos "grátis" precisam de conta, esse é o mecanismo em ação; a diferença aqui é que a conta é grátis e os códigos não morrem.

Os limites, às claras

  • 8 códigos, grátis. Essa é a cota grátis. Exclua um código e a vaga libera.
  • Um de cada vez. Códigos dinâmicos são gerados um por um; a geração em lote continua estática.
  • Editar muda o destino, não o padrão. O código impresso continua funcionando a cada edição — que é todo o objetivo.
