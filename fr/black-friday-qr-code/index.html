Les offres Black Friday, à un scan.

Un acheteur du Black Friday ne tapera pas un code promo, une longue URL, ni ne créera un compte à la caisse. Il scannera un code — ou passera devant l'offre sans s'arrêter. Un QR code transforme chaque surface de votre boutique, dedans comme dehors, en porte d'entrée vers les soldes : affiche de vitrine, étiquette de rayon, flyer, reçu, publication sur les réseaux, e-mail. L'acheteur pointe son téléphone et la réduction s'ouvre. La décision la plus importante se prend avant même d'imprimer : statique ou dynamique ? Un code statique convient pour un coupon fixe. Un code dynamique convient pour tout ce qui peut changer : la page des soldes, la promotion horaire, l'article en rupture de stock à midi. Faites le bon choix pour chaque emplacement et le reste du week-end se déroule tout seul.

Codes statiques ou dynamiques pour une courte promotion

Un code statique porte sa destination — un lien, un code promo, un bout de texte — directement dans son motif. Il ne peut jamais changer, ne demande ni compte ni serveur : FreeQrly le génère entièrement dans votre navigateur, sans rien téléverser ni suivre. Un code dynamique, lui, contient un court lien de redirection. Le motif imprimé reste le même, mais vous pouvez changer sa destination et voir combien de fois il a été scanné. Les codes dynamiques nécessitent une connexion gratuite pour être créés.

Pour des soldes de trois jours, cette différence, c'est toute la stratégie : la plupart des boutiques ont besoin des deux, en décidant emplacement par emplacement, et non campagne par campagne.

La règle d'or : si l'offre est imprimée en toutes lettres sur la même affiche (« 20 % de réduction, code BF20 »), le code peut être statique — le texte du coupon ne change jamais. Si le scan ouvre une page web dont le contenu, le prix ou le stock peut changer pendant le week-end, faites-le dynamique. Un code dynamique coûte une connexion gratuite et une minute de configuration ; une réimpression coûte un tirage d'affiches, une échelle et le vendredi matin.

Le parcours client : le voir, le scanner, récupérer le coupon, l'utiliser

Un QR code du Black Friday échoue à exactement quatre endroits, un par étape du parcours. Concevez pour l'étape où les acheteurs décrochent vraiment.

Figure 1 : de l'affiche à l'achat. Quatre étapes avec des flèches : voir le code, le scanner, récupérer le coupon, l'utiliser (en magasin à la caisse, ou en ligne au paiement). Note en dessous : « Chaque étape doit prendre quelques secondes. Si une étape demande de taper quelque chose, de se connecter ou de télécharger une application, les acheteurs décrochent. »

  • Voir le code. Il faut d'abord remarquer le code pour pouvoir le scanner. Placez-le à hauteur des yeux, laissez une marge de silence autour, et ajoutez une courte phrase qui dit ce que le scan donne : « Scannez pour 20 % de réduction » vaut mieux que « Scannez-moi », parce que cela répond à la seule question du passant : qu'est-ce que j'y gagne ?
  • Scanner. Cela doit fonctionner avec l'appareil photo du téléphone seul, sans application — c'est vrai de tous les codes que FreeQrly crée. Testez sur iPhone et Android avant d'imprimer, dans la vraie lumière, à la vraie distance.
  • Récupérer le coupon. La page ouverte par le scan doit montrer la réduction et ses conditions dès le premier écran — pourcentage, montant minimum, date d'expiration — sans rien à taper et sans inscription. Chaque champ supplémentaire fait perdre des utilisations.
  • Utiliser. En magasin, le client montre son téléphone à la caisse. En ligne, la réduction doit déjà être appliquée au paiement, ou le coupon doit se copier en un seul geste. Si l'utilisation demande au personnel de chercher quelque chose, ou au client de retenir une suite de caractères, le parcours casse à la dernière étape.

Conseils d'impression et de placement

  • La taille suit la distance. Règle approximative : le code doit faire environ un dixième de la distance à laquelle il sera scanné. Une étiquette de rayon scannée à 30 cm peut faire 3 cm de large ; une affiche de vitrine scannée depuis le trottoir doit faire au moins 10 cm (4 pouces). Dans le doute, imprimez plus grand.
  • Le contraste n'est pas optionnel. Code sombre sur fond clair, toujours. Un code noir sur une affiche noire, un code doré sur du jaune, ou un code sur une photo chargée ne se scannera pas fiablement sous l'éclairage d'une boutique. Si l'affiche est sombre, placez le code sur un carré blanc.
  • Laissez une zone de silence. Gardez une marge vide autour du code, au moins aussi large qu'un de ses petits carrés — pas de texte, pas de logo, pas de bordure qui le touche.
  • Utilisez une correction d'erreur élevée pour tout ce qui est manipulé ou en extérieur. Réglez la correction d'erreur sur Élevé ou Max pour les reçus, les flyers et les emballages qui seront pliés, mouillés ou éraflés. Une correction d'erreur plus élevée permet au code de survivre aux dégâts ; en contrepartie, le motif est légèrement plus dense.
  • Ajoutez votre logo au centre, avec précaution. Gardez-le petit — moins d'environ un cinquième de la largeur du code — et utilisez une correction d'erreur élevée pour que le code reste lisible.
  • Imprimez-en un, scannez-le, puis imprimez le reste. Imprimez un exemplaire de chaque visuel, scannez-le sur place, à la vraie distance, dans la vraie lumière, et seulement ensuite lancez le tirage.
  • Écrivez l'offre en toutes lettres à côté du code. « Scannez pour 20 % de réduction, aujourd'hui seulement » dit à l'acheteur pourquoi cela vaut le coup. Un code seul n'est que de la décoration — et si un téléphone ne peut pas le scanner, l'acheteur peut toujours lire l'offre.

Utilisation et fraude : coupons à usage unique ou illimités

  • Les coupons illimités sont le choix par défaut pour une promotion éclair du Black Friday : un seul code, utilisable par tout le monde, sans suivi de qui l'a utilisé. Simple, rapide à une caisse bondée, et parfait quand la réduction est modeste et que l'objectif est de faire venir du monde. Le risque est exactement ce qu'il semble : le code circule. Pour une offre de 10–20 % sur tout le magasin, c'est généralement acceptable ; le partage, c'est la publicité.
  • Les coupons à usage unique ont du sens quand la réduction est importante — un article de valeur, un gros pourcentage, un cadeau offert. L'usage unique demande un système derrière le code : un code unique par client, une liste que la caisse peut vérifier, un moyen de le marquer comme utilisé. Un seul code statique ne peut pas faire cela : tous ceux qui scannent la même affiche obtiennent le même code. Si vous avez besoin de codes à usage unique, générez des codes uniques par client (le mode Série peut en faire jusqu'à 50 à la fois) et validez-les à la caisse ou au paiement.
  • Un juste milieu pratique. La plupart des petits commerçants s'en sortent très bien avec des codes illimités et trois contrôles peu coûteux : une expiration claire (« vendredi seulement »), un montant minimum et une limite par transaction (« une réduction par transaction »). Imprimez-les sur l'affiche, affichez-les sur la page d'arrivée, appliquez-les à la caisse — aucun système supplémentaire n'est nécessaire.
  • Le briefing du personnel compte plus que le logiciel. Dites par écrit au personnel de caisse ce que fait chaque code, ses conditions, et quoi faire quand un client montre une capture d'écran du téléphone de quelqu'un d'autre. Un briefing de cinq minutes le vendredi matin évite plus de fraudes — et plus de disputes — que n'importe quel système de validation.
  • Après les soldes, faites expirer les coupons de façon visible. Si un coupon a une date d'expiration, respectez-la et indiquez-la sur l'affiche. Rien n'abîme la confiance plus vite qu'un code qui fonctionnait le vendredi et échoue silencieusement le samedi.

Quand l’offre change en cours de soldes

  1. Réorientez, ne réimprimez pas. C'est toute la raison d'utiliser des codes dynamiques pour les pages de soldes et les promotions éclair. Modifiez la destination depuis votre tableau de bord ; le code imprimé continue de fonctionner. Une réimpression prend des heures que vous n'avez pas un vendredi.
  2. Décidez à l'avance vers quoi pointe un code en rupture de stock. Par défaut, ce devrait être la page principale des soldes ou l'article équivalent le plus proche — jamais une page morte, et jamais une page qui annonce encore l'article épuisé à l'ancien prix. Notez la solution de repli dans votre liste de codes pendant la semaine de préparation.
  3. Changez la destination, puis le texte de l'affiche si vous le pouvez. Si l'affiche dit « 50 % de réduction sur les casques » et que les casques sont partis, un petit autocollant « épuisé — voir les offres du jour » sur le titre est honnête et prend une minute. La réorientation du code fait le reste.
  4. Confiez les changements à une seule personne. Des modifications faites en pleine vente par trois personnes donnent trois destinations différentes. Une seule personne gère le tableau de bord pendant le week-end ; les autres lui transmettent leurs demandes. Notez chaque changement en une ligne : heure, code, ancienne et nouvelle destination.

Bon à savoir

Statique ou dynamique — de quoi une vente du Black Friday a-t-elle besoin ?

Les deux, pour des travaux différents. Statique pour le code coupon lui-même : il porte le code en texte et n’expire jamais. Dynamique pour tout ce qui change — la page des soldes, les promotions horaires, le stock qui s’épuise. Les codes dynamiques sont gratuits avec une inscription, et l’offre gratuite en inclut 20.

Puis-je changer la destination d'un code déjà imprimé ?

Oui — c’est ce que dynamique signifie ici. Modifiez la destination depuis votre tableau de bord à tout moment ; le code imprimé ne change jamais. Les codes statiques ne peuvent pas être modifiés après impression, c’est pourquoi ils ne conviennent qu’aux coupons fixes.

Que deviennent mes codes après les soldes ?

Rien n’expire. Réorientez les codes dynamiques vers votre prochaine campagne, et gardez les affiches pour l’année prochaine — mêmes codes, nouvelles offres. Les codes statiques continuent de fonctionner tant que la page ou le coupon derrière eux reste valide.

Quelle taille pour le code d'une affiche de vitrine ?

Assez grand pour être scanné à travers la vitre depuis le trottoir — 10 cm (4 pouces) ou plus. La règle est environ un dixième de la distance de scan, alors testez depuis le trottoir, pas de l’intérieur de la boutique.

Puis-je créer un code différent pour chaque produit en solde ?

Oui — utilisez le mode Série dans le générateur : un lien par ligne, ou téléversez un fichier CSV/XLSX, jusqu’à 50 codes par lot, téléchargés en ZIP de PNG. Le mode Série est réservé aux codes statiques, alors utilisez-le pour les pages fixes par produit et les coupons.

Les clients ont-ils besoin d’une application pour scanner le code ?

Non. Chaque code s’ouvre avec l’appareil photo intégré du téléphone. Si un code semble exiger une application, il a été mal créé — testez le scan avec un appareil photo ordinaire avant d’imprimer.

Comment empêcher qu’un coupon soit partagé partout sur les réseaux sociaux ?

Vous ne pouvez pas empêcher qu’un coupon statique soit pris en capture d’écran. Si la réduction est importante, utilisez des codes à usage unique validés à la caisse au lieu d’un seul code partagé. Pour la plupart des offres générales en magasin, une date d’expiration, une dépense minimale et une limite d’un par transaction suffisent — et le partage vous amène des clients.
