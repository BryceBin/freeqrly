Bon à savoir

Lien du profil ou vidéo précise ?

Le lien du profil pour les abonnements en général. Un lien vidéo lance une seule vidéo — pratique pour les campagnes, les encarts d'emballage et les affiches de lancement.

Est-ce que ça s'ouvre dans l'app TikTok ?

Sur la plupart des téléphones, oui — toucher le lien scanné propose l'app si elle est installée, sinon il s'ouvre dans le navigateur.

Puis-je ajouter mon logo ou les couleurs de ma marque ?

Oui — envoyez votre logo et choisissez vos couleurs. Gardez un contraste élevé pour qu’il se scanne dans toutes les lumières.

Est-ce que ça expire si je change mon nom d'utilisateur ?

Le code encode l'URL exacte, donc si votre identifiant change, créez un nouveau code. Le code lui-même n'expire jamais.
