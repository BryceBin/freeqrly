Si la destination ne changera jamais, utilisez un code statique gratuit : sans inscription, sans filigrane, il n'expire jamais. Si la destination peut changer en cours de saison — un événement complet, un nouveau total de dons, un menu différent — utilisez un code dynamique gratuit, que vous pouvez réorienter après impression et qui vous montre combien de fois il a été scanné. Ce que fait vraiment un QR code de Noël

Un QR code n'est ni le cadeau, ni le billet, ni le don. C'est la porte d'entrée : la personne scanne, son téléphone ouvre une page, et c'est la page qui fait le travail — elle joue une vidéo de vœux, vend une carte cadeau, recueille un don. Le code est imprimé une fois et on ne peut pas le retirer une fois imprimé ; la page derrière, elle, peut être corrigée, mise à jour ou remplacée. La décision la plus importante de ce guide est donc de savoir quel type de code vous imprimez.

Statique ou dynamique : la décision dont tout le reste dépend

Un code statique porte son contenu dans le motif lui-même. Ce que vous imprimez, c'est ce qu'il fera toujours. Un code dynamique contient une courte redirection : le motif imprimé reste le même, mais la destination est conservée par FreeQrly, donc vous pouvez changer vers où il pointe après l'impression — et voir combien de fois il a été scanné.

Comment fonctionne le parcours client

Parcours A — achat d'une carte cadeau

La figure 1 montre les cinq étapes : l'acheteur voit le code sur un présentoir de cartes cadeaux, une affiche ou un bord d'étagère → le scanne avec l'appareil photo de son téléphone, sans application → choisit un montant et un message et paie sur la page → reçoit la carte cadeau par e-mail ou en carte imprimable → le destinataire l'utilise en magasin ou en ligne.

La leçon est dans la deuxième étape : la page ouverte par le code doit être la page des cartes cadeaux, pas votre page d'accueil. Chaque étape supplémentaire fait perdre des acheteurs debout dans votre boutique, téléphone en main, prêts à acheter.

Parcours B — billet d'événement et don

La figure 2 montre les cinq étapes : l'invité voit le code sur une affiche, un panneau d'affichage d'église, un stand de marché ou une publication sur les réseaux → le scanne pour ouvrir la page de l'événement ou le formulaire de don → réserve un billet, confirme sa présence ou fait un don → reçoit un billet ou un reçu par e-mail, et une invitation est ajoutée à son calendrier → l'organisateur fait un suivi avec un remerciement, et pour les codes dynamiques, le nombre de scans montre quelles affiches ont fonctionné.

La leçon est dans la quatrième étape : un don ou une réservation qui se termine dans le silence donne l'impression que quelque chose a raté, même quand le paiement est passé. Confirmez l'action à l'écran et par e-mail. Pour les événements, le type de code Événement ajoute la date, l'heure et le lieu directement dans l'application de calendrier de l'invité en un seul scan.

Cartes cadeaux : le code de Noël à plus forte valeur

Les cartes cadeaux, c'est là qu'un QR code se transforme le plus directement en argent — et là qu'un mauvais choix coûte le plus cher.

  1. Utilisez un code dynamique sur le présentoir. Les montants des cartes cadeaux s'épuisent et les visuels changent ; un code dynamique permet de changer la destination sans réimprimer le présentoir. L'offre gratuite autorise 20 codes dynamiques, ce qui couvre un présentoir, une affiche et une publication sur les réseaux, avec de la marge ; Pro (9 $/mois ou 90 $/an) ne fait que supprimer cette limite de 20 codes. Pendant l’offre limitée en cours, les codes dynamiques gratuits sont illimités ; une fois l’offre terminée, le forfait gratuit comprendra 20 codes dynamiques.
  2. Imprimez la gamme de montants sur le présentoir, pas seulement le code. « Cartes cadeaux dès 10 $ » à côté du code fixe les attentes avant le scan. Un code seul, sans contexte, reçoit moins de scans, parce que les acheteurs ne savent pas pourquoi ils scannent.
  3. Testez tout l'achat sur un vrai téléphone. Scannez le présentoir imprimé, achetez vous-même la carte la moins chère et vérifiez l'e-mail que reçoit le destinataire. Si une étape demande un téléchargement d'application ou une connexion que l'acheteur n'a pas, corrigez la page.

Dons et collectes de fonds : la confiance est le produit

Un code de don demande à un inconnu d'envoyer de l'argent à une page qu'il n'a jamais vue. Tout dans la configuration doit dissiper les doutes :

  • Liez vers une page qui nomme la cause, l'organisation et la destination de l'argent — pas vers un simple formulaire de paiement. Elle doit ressembler à l'organisation qui l'a imprimée : même nom, même logo, même cause.
  • Utilisez un code dynamique. Les collectes de fonds évoluent tout au long de décembre : une période de dons abondés s'ouvre, un objectif est atteint, un nouveau total est publié. Un code dynamique permet à la même affiche imprimée de suivre la campagne au lieu de la figer dans sa formulation de novembre.
  • Placez le code là où les gens s'arrêtent. Un code de don sur une affiche devant laquelle on passe est à peine regardé ; le même code sur une table de collecte, un programme ou un comptoir de stand — là où les gens sont déjà arrêtés, téléphone en main — est scanné. Ajoutez une courte phrase à côté : « Scannez pour faire un don » vaut mieux qu'un code seul, parce que cela dit ce qui se passe ensuite. Et si la page de campagne affiche un total en cours ou un message de remerciement, les donateurs qui scannent deux fois voient que leur don a compté.

Cartes de vœux, étiquettes cadeaux et calendriers de l'avent

Ce sont les usages personnels, et c'est là que les codes statiques excellent : le contenu est fixe, personnel et fait pour durer.

  • Cartes de vœux vidéo. Téléversez le message quelque part avec un lien partageable — une vidéo YouTube non répertoriée fonctionne bien — créez un QR code à partir du lien et imprimez-le dans la carte. Un scan et elle se lance. Comme le code est statique, il fonctionnera encore à Noël prochain, tant que la vidéo reste en ligne.
  • Albums photo, playlists et invitations. Liez le code à un album partagé ou à la playlist de la soirée : les invités l'ouvrent en un seul geste, sans application à installer. Le type de code Événement porte le titre, l'heure et le lieu, donc un scan place la fête dans les applications de calendrier de vos invités.
  • Un code différent sur chaque étiquette cadeau. Créez-les toutes d'un coup avec le mode Série : un lien par ligne, un code par étiquette, téléchargés en ZIP. Le mode Série est réservé aux codes statiques, avec un maximum de 50 codes par lot — collez-en un par ligne, ou téléversez un fichier CSV ou XLSX.
  • Un calendrier de l'avent avec 24 cases. Imprimez un code derrière chaque case — une photo, un indice, une courte vidéo. Les vingt-quatre codes tiennent largement dans un seul lot de 50 maximum. Gardez la destination de chaque case courte et fixe : un indice qui change après l'impression, c'est une case qui déçoit un enfant.
  • Un mot de remerciement qui survit au sapin. Imprimez le code de remerciement avec les cadeaux. Un code statique continue de fonctionner tant que la page derrière reste en ligne ; un code dynamique permet de le réorienter après les fêtes — vers les soldes de janvier ou l'événement de l'année prochaine — sans réimprimer le mot.

Calendrier de préparation : quand imprimer

La figure 4 montre le calendrier en quatre étapes. L'ordre compte plus que les dates : décider, tester, imprimer, puis surveiller.

  • Début novembre — décidez des codes et des destinations. Listez chaque endroit où un code apparaîtra et ce que chacun doit ouvrir, et décidez statique ou dynamique pour chacun en utilisant le tableau 2. C'est le moment le moins coûteux pour changer d'avis.
  • Mi-novembre — épreuves et premiers contrôles de scan. Imprimez un exemplaire de chaque code à taille réelle et scannez-le avec deux téléphones différents, dans la lumière où il sera vraiment utilisé. Vérifiez la page qu'il ouvre, pas seulement qu'il se scanne.
  • Fin novembre — imprimez et placez tout. Imprimez avec un export à 1024 px ou plus pour tout ce qui est plus grand qu'une étiquette cadeau, et à 2048 px pour les affiches. Placez les codes là où les gens s'arrêtent et où la lumière est bonne — pas derrière une vitre qui reflète, et pas à hauteur de cheville.
  • Décembre — surveillez, réorientez, remerciez. Vérifiez chaque semaine le nombre de scans des codes dynamiques : une affiche sans scans est peut-être mal placée, pas impopulaire. Réorientez les codes dynamiques quand les détails changent au lieu de réimprimer.

Quand les détails changent en cours de saison

Les plans de Noël changent : un événement est déplacé, un produit est épuisé, un objectif de don est atteint, un stand de marché change d'emplacement. Que faire dépend du type de code :

  • Code dynamique : changez la destination dans votre tableau de bord FreeQrly. Le code imprimé ne change pas, et chaque affiche, carte et panneau de stand suit immédiatement.
  • Code statique, et la page derrière vous appartient : mettez la page à jour. Un code statique qui pointe vers votre page d'événement fonctionne toujours si vous modifiez la page elle-même — nouvel horaire, nouveaux détails, même code.
  • Code statique, et la page derrière ne vous appartient pas : vous ne pouvez pas le corriger. Un code statique qui pointe vers une vidéo supprimée ou une page de billetterie tierce épuisée est un code mort — c'est pourquoi tout ce qui échappe à votre contrôle devrait être dynamique.

Bon à savoir

Comment mettre une vidéo dans une carte de Noël ?

Téléversez la vidéo quelque part avec un lien partageable — une vidéo YouTube non répertoriée fonctionne bien — créez un QR code à partir du lien, et imprimez-le dans la carte. Un scan et elle joue. Utilisez un code statique : les vœux sont fixes, et il fonctionnera encore à Noël prochain tant que la vidéo reste en ligne.

Un code peut-il ajouter la fête au calendrier de mes invités ?

Oui. Le type Événement porte le titre, l’heure et le lieu ; un scan ajoute la fête à leur application de calendrier. Mettez-le sur l’invitation elle-même, pas seulement dans l’e-mail — l’invitation papier est celle que les gens gardent sur le frigo.

J’ai besoin d’un code différent sur chaque étiquette cadeau. Comment faire ?

Utilisez le mode Série dans le générateur : un lien par ligne, un code par étiquette, tous téléchargés en ZIP. Le mode Série est réservé aux codes statiques, avec un maximum de 50 codes par lot, et vous pouvez aussi téléverser un fichier CSV ou XLSX au lieu de coller des liens.

Puis-je voir combien de personnes ont scanné mon affiche de Noël ?

Oui, avec un code dynamique : les statistiques de scan apparaissent dans votre tableau de bord FreeQrly. Les codes statiques sont créés entièrement dans votre navigateur sans rien téléverser, donc il n’y a rien à compter. Si le suivi compte, donnez à chaque affiche son propre code dynamique — un code partagé ne montre que le total.
