Bon à savoir

Quelles informations entrent dans le code ?

Un contact vCard 3.0 standard : nom complet, numéro de téléphone et e-mail. Les téléphones reconnaissent le format et proposent de l’enregistrer comme nouveau contact.

Est-ce que ça marche sur iPhone et Android ?

Oui — les deux ouvrent les QR codes vCard nativement dans l’app Appareil photo et proposent de créer un contact. Pas d’app supplémentaire nécessaire.

Quelle taille pour l’imprimer sur une carte de visite ?

Au moins 2 × 2 cm (environ 0,8 po) avec une marge calme autour. Exportez à 1024 px ou plus pour que l’impression reste nette.

Mes coordonnées vont-elles un jour expirer ou changer ?

Le code est statique — il porte vos coordonnées dans le motif, donc il fonctionne indéfiniment. Si votre numéro change, générez-en simplement un nouveau.
