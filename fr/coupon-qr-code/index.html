Bon à savoir

Que voit-on au scan ?

Votre description plus le code, en texte brut — p. ex. « -20 % » sur une ligne et « Code : SAVE20 » sur la suivante. Le personnel le saisit comme d'habitude.

La remise s'applique-t-elle seule ?

Non — c'est un code statique avec le texte promo, pas un lien profond vers votre boutique. Ajoutez une URL courte vers la page d'offre pour qu'un scan fasse les deux.

Un code par coupon ou un seul pour tous ?

Un code par coupon. Chaque code est statique et gratuit : créez-en autant que de promos.

Expire-t-il ?

Le code lui-même n'expire jamais. Quand la promo se termine, cessez de l'imprimer — le code ne gère pas les dates.
