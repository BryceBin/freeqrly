QR codes, sans le navigateur.

FreeQrly parle HTTP et MCP. Générez des QR codes statiques depuis n’importe quel agent, script ou flux de travail — sans clé, sans inscription, sans expiration. Si vous pouvez faire une requête, vous pouvez faire un code.

Façons de se connecter

🧰 Serveur MCP

Ajoutez https://freeqrly.com/mcp à votre client MCP. Un outil — generate_qr — sans authentification. Fonctionne avec Claude Code, Cursor et tout ce qui parle HTTP Streamable.

🌐 API HTTP

Un endpoint GET simple qui renvoie du SVG. CORS est grand ouvert, donc navigateurs, curl et fonctions serverless peuvent tous l’appeler directement.

📜 Compétence d’agent

Un SKILL.md avec des recettes de payload vit dans le dépôt à skills/qr-generator/. Pointez votre agent dessus et il connaît la suite.

🤖 llms.txt

/llms.txt décrit tout le site pour les robots et les assistants — endpoints, formats de payload et plan des pages dans un seul fichier.

API HTTP

GET https://freeqrly.com/api/qr?data=TEXT&size=1024&margin=4&color=2F4A62&bgcolor=ffffff&ecc=M

Renvoie image/svg+xml. Seul data est requis ; tout le reste a une valeur par défaut raisonnable. Les erreurs reviennent en JSON avec un champ error.

curl "https://freeqrly.com/api/qr?data=https://example.com&size=1024" \
  -o qr.svg

# WiFi QR code for guests
curl "https://freeqrly.com/api/qr?data=WIFI:T:WPA;S:CafeNet;P:s3cret;;" \
  -o wifi.svg

Paramètres

  • data — texte à encoder (requis, max 2000 caractères). URL, chaînes WiFi, vCards, texte brut.
  • size — taille de sortie en px, 128–2048 (par défaut 1024).
  • margin — zone de silence en modules, 0–10 (par défaut 4).
  • color / bgcolor — hexadécimal à 6 chiffres, sans # (par défaut 2F4A62 / ffffff).
  • ecc — correction d’erreur L, M, Q, H (par défaut M). Utilisez Q/H pour l’impression ou les logos.

MCP

POST https://freeqrly.com/mcp

HTTP Streamable standard : initialize, puis tools/list / tools/call. L’outil generate_qr prend data, size, color, bgcolor, ecc et renvoie une URL SVG prête à télécharger.

{
  "jsonrpc": "2.0", "id": 1, "method": "tools/call",
  "params": {
    "name": "generate_qr",
    "arguments": { "data": "https://example.com", "size": 1024 }
  }
}

Recettes de payload

Website : https://example.com/menu
WiFi    : WIFI:T:WPA;S:CafeNet;P:s3cret;;
Contact : BEGIN:VCARD\nVERSION:3.0\nN:Ada Lovelace\nTEL:+15550100\nEND:VCARD
Place   : geo:37.7749,-122.4194
SMS     : sms:+15550100?body=Hello

Usage équitable

C’est gratuit, mais soyez aimable : mettez les résultats en cache au lieu de redemander le même code, et gardez le trafic automatisé raisonnable. Des limites de débit par IP s’appliquent. Les codes statiques sont déterministes — la même entrée donne toujours la même sortie, donc la mise en cache est triviale.
