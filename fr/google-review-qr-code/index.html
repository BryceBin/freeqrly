Bon à savoir

Où trouver mon lien d’avis Google ?

Dans votre fiche d’établissement Google : ouvrez votre fiche, cliquez sur Demander des avis ou Partager le formulaire d’avis, et copiez le lien court.

Les personnes qui laissent un avis doivent-elles être connectées ?

Il leur faut un compte Google pour publier, mais le scan fonctionne pour tout le monde — le code ouvre simplement votre formulaire d’avis.

Puis-je suivre combien de scans il reçoit ?

Les codes FreeQrly sont statiques et privés — aucun suivi par design. Pour les chiffres, mettez un raccourcisseur d’URL avec statistiques devant le lien.

Le code expire-t-il ?

Non. Les codes statiques n’expirent jamais et n’ont besoin d’aucun compte, donc votre carte de comptoir fonctionne pour toujours.
