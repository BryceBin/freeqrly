Partagez votre Wi-Fi avec un QR code

Vos invités demandent le mot de passe. Vous désignez le frigo. Un scan et ils sont en ligne — sans épeler, sans faute de frappe, sans déchiffrer l'étiquette de la box.

28 octobre 2026 · 4 min de lecture

Tous les hôtes connaissent le rituel : un invité arrive, demande le mot de passe Wi-Fi, et vous récitez une suite de majuscules, de chiffres et de symboles pendant qu'il se trompe deux fois. Un QR code WiFi met fin à tout ça. Vous imprimez un seul code, vous le collez là où vos invités regardent, et leur téléphone rejoint le réseau dès le scan — sans taper quoi que ce soit.

Ce que contient un QR code WiFi

Trois éléments : le nom du réseau (SSID), le mot de passe et le type de sécurité — le plus souvent WPA ou WPA2 sur une box domestique, WEP sur du matériel très ancien, ou rien du tout pour un réseau ouvert. Un téléphone qui scanne le code lit les trois d'un coup et se connecte directement, sans passer par les réglages ni taper quoi que ce soit.

Créez-en un en trois étapes

  1. Retrouvez les informations de votre réseau. Le nom et le mot de passe figurent généralement sur une étiquette collée sur la box. Si vous les avez modifiés, utilisez ceux que vous avez définis — le code doit correspondre exactement à la box, majuscules comprises.
  2. Générez le code. Dans le générateur de QR code WiFi, choisissez le type Wi-Fi, saisissez le nom du réseau, le mot de passe et le type de sécurité. Le code apparaît instantanément.
  3. Imprimez-le et placez-le là où vos invités regardent. Porte du frigo à la maison, carte sur le comptoir dans un café, livret d'accueil dans un Airbnb, bureau d'accueil dans un bureau. Au moins 2 × 2 cm à l'impression, pour que les téléphones le lisent à bout de bras.

Quels téléphones se connectent grâce à un scan ?

Les iPhone sous iOS 11 et versions ultérieures se connectent directement depuis l'app Appareil photo — visez, touchez la notification, c'est fait. La plupart des téléphones Android sous Android 10 et versions ultérieures font pareil depuis l'appareil photo ou les réglages Wi-Fi. Aucune app supplémentaire n'est nécessaire, et vos invités ne voient jamais le mot de passe lui-même.

La note de sécurité, en toute honnêteté

Un code Wi-Fi statique est pratique parce que le mot de passe vit dans le motif lui-même — ce qui veut dire aussi que quiconque photographie le code peut rejoindre votre réseau. Pour une maison, un café ou une location, c'est exactement le compromis qu'on recherche : les invités sont censés être en ligne. Deux règles suffisent à garder ça raisonnable :

  • Générez-le en privé. Un code statique est dessiné entièrement dans votre navigateur — votre mot de passe n'est jamais envoyé ni stocké nulle part. Pour encore plus de tranquillité, chargez la page, déconnectez-vous d'internet, puis tapez.
  • Si le code fuite là où il ne devrait pas, changez le mot de passe et réimprimez. Un code statique ne peut pas être modifié après impression, mais en créer un nouveau est gratuit et prend une minute.

Réseaux masqués et box capricieuses

Les réseaux masqués fonctionnent de la même façon — saisissez le nom exact du réseau et le téléphone se connecte sans jamais le voir dans une liste. Pour les box WPA3, choisissez l'option WPA2/WPA si WPA3 n'est pas proposée ; la plupart des box WPA3 acceptent les clients WPA2. Et si le téléphone d'un invité refuse de se connecter, vérifiez d'abord les majuscules du mot de passe — c'est la cause presque à chaque fois.

Bon à savoir

Mon mot de passe Wi-Fi est-il en sécurité dans un QR code ?

Pour un code statique, oui — il est dessiné entièrement dans votre navigateur et n'est jamais envoyé ni stocké. Quiconque photographie le code imprimé peut se connecter, alors traitez-le comme une clé d'invité : parfait pour les maisons, les cafés et les locations, et réimprimez-le s'il fuite.

Quels téléphones peuvent scanner un QR code WiFi ?

Les iPhone sous iOS 11+ se connectent directement depuis l'app Appareil photo ; la plupart des téléphones Android sous Android 10+ font pareil depuis l'appareil photo ou les réglages Wi-Fi. Aucune app supplémentaire nécessaire.

Ça marche avec WPA3 ou les réseaux masqués ?

Choisissez le type de sécurité qui correspond à votre box (WPA, WPA2, WEP ou ouvert). Saisissez le nom exact d'un réseau masqué et il se connecte de la même façon.

Et si je change mon mot de passe Wi-Fi plus tard ?

Un code statique ne peut pas être modifié, alors imprimez-en un nouveau — c'est gratuit et ça prend une minute. C'est aussi pourquoi le code convient le mieux aux réseaux dont le mot de passe change rarement.
