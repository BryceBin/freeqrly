Notes de terrain

Pourquoi ce truc ne se scanne-t-il pas ?

Un QR code qui ne se scanne pas n’est presque jamais un mystère. Parcourez ces sept vérifications — dans l’ordre — et vous trouverez le coupable en environ deux minutes.

14 octobre 2026 · Dernière mise à jour : 3 novembre 2026 · 15 min de lecture

Un QR code qui ne veut pas scanner n'est presque jamais un mystère. Parcourez ces vérifications — dans l'ordre — et vous trouverez le coupable en deux minutes environ. Avant de changer quoi que ce soit, divisez le problème en trois : le téléphone, le code imprimé ou affiché, et la destination. Scannez avec un deuxième téléphone. S'il lit le code, le premier téléphone, son appareil photo, ou son éclairage est le problème. Si aucun téléphone ne le lit, le code lui-même — taille, contraste, marge, dégâts, ou logo — est le problème. Si les téléphones le lisent mais que le lien ne mène nulle part, le code fait son travail et la destination est le problème. Cette division en trois épargne à la plupart des gens une réimpression inutile, parce que chaque branche a un correctif différent.

Les deux normes qui expliquent la plupart des échecs

Deux idées d'ISO/IEC 18004, la spécification de la symbologie QR code, expliquent une part surprenante des échecs de scan. La première est la zone de silence : une marge blanche d'au moins 4 modules de large de chaque côté, où un module est un petit carré de la grille. Les lecteurs utilisent cette bordure pour trouver où le symbole commence et finit, donc du texte, des graphiques, ou un rognage qui l'envahit peut rendre un code parfait invisible pour un appareil photo. La deuxième est la correction d'erreur : des données supplémentaires qui permettent à un lecteur de reconstruire les mots de code revenus faux ou illisibles, à quatre niveaux — L environ 7 %, M environ 15 %, Q environ 25 %, H environ 30 %. Ces pourcentages décrivent des mots de code, pas une surface visible : un motif de repérage déchiré peut tuer un code bien dans son niveau, tandis que des dégâts mineurs épars ailleurs peuvent survivre. Les niveaux plus élevés ne sont pas gratuits non plus : plus de données de récupération veut dire une grille plus dense, donc augmenter le niveau sur un code déjà petit peut le rendre plus difficile à lire. Augmentez-le pour une raison — un logo, une manipulation rude, un usage extérieur — puis revérifiez la taille et testez au scan.

Étape 1 : écarter le téléphone

Essuyez l'objectif. Un objectif maculé est derrière un nombre gênant de codes prétendument cassés, parce qu'un mince film de graisse adoucit toute l'image juste assez pour brouiller les bords des modules. Testez ensuite sur un deuxième téléphone : si le téléphone B le lit, le code n'a jamais été le problème. Tout le carré doit être dans le cadre, avec un peu d'air autour — un code rogné par le bord du viseur ne se lira pas. Tenez stable une fois que le code remplit environ la moitié du viseur, et passez à une meilleure lumière dans des conditions sombres. Un code qui affiche un aperçu mais ne mène nulle part quand on le touche a un problème de destination (étape 9), pas un problème de scan.

Étape 2 : taille et distance

L'échec classique est un code serré dans un coin de carte de visite à 1 cm de large. En règle générale, les codes imprimés exigent au moins 2 x 2 cm (environ 0,8 pouce), et plus grand est toujours plus sûr. Taille et distance suivent la règle empirique du 1:10 pour la distance : largeur du code d'au moins un dixième de la distance de scan — 5 cm pour une carte de table scannée depuis 50 cm, 50 cm pour une affiche scannée depuis 5 mètres. En dessous de cette règle pour sa distance, aucun nettoyage, réangle ou réexport ne le réparera de façon fiable — réimprimez plus grand, ou rapprochez le code de l'endroit où les gens se tiennent. La ventilation complète par cas d'usage est dans le guide des tailles d'impression. La densité resserre la règle : un lien court donne une grille aérée, tandis qu'un lien long, une carte de contact complète, ou un long mot de passe Wi-Fi donne une grille plus dense avec des modules plus petits, exigeant un tirage plus grand. Un code dynamique raccourcit le motif imprimé sans raccourcir la destination finale, parce qu'il encode un lien court que vous contrôlez et pouvez rediriger plus tard, avec des statistiques de scan montrant la performance.

Étape 3 : contraste

Les lecteurs de QR cherchent des modules foncés sur fond clair. Gris clair sur blanc, pastels de marque, code foncé sur foncé, ou code sur une photo chargée échoueront — surtout dans une lumière faible. Jugez-le dans la lumière où le code sera réellement scanné : si vous plissez les yeux pour distinguer les modules de l'arrière-plan, un appareil photo de téléphone peinera aussi. Le correctif est le noir sur blanc, qui marche toujours, avec la zone de silence dans la même couleur claire de fond. Les codes inversés — modules clairs sur foncé — sont un cas particulier : certains lecteurs les gèrent et beaucoup non, ne comptez donc pas sur l'inversion pour les codes publics. Si les couleurs de marque comptent, gardez-les dans le design environnant et un petit logo central, pas dans les modules, et testez d'abord la version colorée dans une lumière faible.

Étape 4 : la zone de silence

La marge blanche autour du code n'est pas de la décoration — les lecteurs en ont besoin pour trouver les bords. Gardez une bordure nette d'au moins 4 modules de large sur les quatre côtés, comme spécifié dans ISO/IEC 18004, et gardez texte, filets, bordures décoratives et images proches hors de cette zone. Cet échec est fréquent dans les mises en page travaillées, où un titre, un filet ou un bord de photo s'insinue dans la marge, et au bord d'une page, où un code trop près de la coupe perd sa marge. Vérifiez les quatre côtés : une marge généreuse sur trois côtés et nulle sur le quatrième échoue quand même. Le correctif est la mise en page, pas le réexport — donnez de l'air au code, ou placez-le sur un panneau clair uni qui garantit la marge dans une mise en page chargée.

Étape 5 : dégâts, effacement et usure

Dépliants froissés, affiches décolorées par le soleil, autocollants rayés, étiquettes tachées de pluie : la correction d'erreur peut survivre à certains dégâts, mais l'emplacement compte plus que la taille. Les dégâts aux trois grands motifs de repérage d'angle sont les plus graves, parce que sans eux le lecteur ne peut ni trouver ni orienter la grille — un motif de repérage déchiré est souvent fatal même quand le reste semble intact. Les éraflures éparses dans la zone de données sont bien plus indulgentes, parce que c'est ce que la correction d'erreur est faite pour reconstruire. L'effacement est un dégât plus lent : à mesure que les modules foncés s'éclaircissent vers l'arrière-plan, le contraste chute jusqu'à ce que le lecteur ne puisse plus séparer les modules, même si le motif est encore là. Jugez un code usé par les coins d'abord, puis le contraste, puis la surface. Le correctif pour un tirage abîmé est une réimpression ; pour un code qui vivra une vie difficile — en extérieur, sur un emballage, sur un véhicule — soyez préventif : correction d'erreur plus élevée, tirage plus grand, pelliculage ou emplacement abrité.

Étape 6 : obstruction par le logo

Un logo au centre mange dans le motif, consommant une partie du budget de correction d'erreur par construction — c'est pourquoi cela peut marcher, et pourquoi cela peut échouer. Jugez-le par la part de la grille que le logo recouvre et s'il touche un motif de repérage : un petit logo proprement centré, à l'écart des trois coins, est sûr ; un grand logo, un logo qui s'étend vers les coins, ou un logo aux détails chargés imitant les modules est risqué. En règle générale, gardez le logo sous environ 30 % de la surface du code, imprimez les codes avec logo à 3 x 3 cm ou plus, et utilisez la correction d'erreur Q ou H. Testez spécifiquement la version avec logo : un code simple qui scanne ne dit rien de son frère avec logo. Si un code avec logo échoue, réduisez d'abord le logo, puis agrandissez le tirage, puis augmentez le niveau, en testant après chaque changement. Voir comment ajouter un logo à un QR code et le générateur de code avec logo.

Étape 7 : reflets, courbure et angle

Un pelliculage brillant sous une lumière vive, un code enroulé autour d'une bouteille, ou une photo prise sous un angle prononcé déforment tous ce que l'appareil photo voit. Les reflets effacent les modules par plaques ; une courbe étire les modules de bord tout en comprimant ceux du milieu ; un angle prononcé transforme les carrés en trapèzes que le lecteur doit redresser. Inclinez lentement le tirage : si la plaque illisible bouge avec le reflet, c'est un reflet. Aplatissez la surface si vous pouvez, et photographiez bien de face. Préférez un panneau plat à une courbe serrée, le mat au brillant là où les lumières sont fortes, et un emplacement que les gens peuvent affronter de face. Un code de bouteille qui scanne quand on le tourne face à l'appareil photo est un problème de placement — déplacez-le vers l'endroit le plus plat et le plus frontal, et imprimez-le plus grand.

Étape 8 : netteté — quand le flou est le coupable

Si le code est à la bonne taille, à fort contraste, bien margé, intact et sans logo, mais hésite quand même, regardez les bords des modules : nets ou brouillés ? Les exports basse résolution, la compression JPEG, l'étirement, la mauvaise impression et les copies de copies adoucissent tous les bords, et les bords doux échouent d'abord dans une lumière faible et à distance. Le diagnostic complet est dans pourquoi votre QR code semble flou. En bref : réexportez à 1024 px pour les cartes et dépliants ou 2048 px pour les affiches, utilisez le SVG dès que l'imprimeur l'accepte, n'utilisez jamais le JPEG pour un code, gardez les proportions en redimensionnant, et testez d'abord un vrai tirage à la vraie distance. Douceur et faible contraste se cumulent, corrigez donc les deux plutôt que de chercher un seul coupable.

Étape 9 : la destination est morte

Parfois le code scanne très bien — mais le lien est cassé, la page a déménagé, le site est en panne, ou un générateur basé sur un essai a désactivé le code. C'est le piège du lien expiré : rien d'utile ne se passe après le toucher, donc cela ressemble à un échec de scan. Surveillez l'aperçu du lien : si un aperçu apparaît, le code a été décodé et la destination est le problème. Vérifiez si la page s'ouvre quand on la tape directement dans un navigateur, et si le lien a été raccourci par un service qui a depuis changé ses conditions. Les codes statiques n'expirent jamais d'eux-mêmes — la destination vit dans le motif, donc un code statique n'échoue que si la destination elle-même disparaît. Les codes dynamiques pointent vers un lien court que vous contrôlez, donc une page déplacée est réparable sans réimpression : connectez-vous, changez la destination, et le code imprimé fonctionne à nouveau, avec des statistiques de scan pour le confirmer. Cette possibilité de modification est aussi le piège à éviter quand on choisit un générateur : un code lié à un essai terminé peut cesser de fonctionner même si le motif est parfait — voir les QR codes expirent-ils ? avant un grand tirage. Pour les codes déjà imprimés : statique plus page déplacée veut dire restaurer la page ou réimprimer ; dynamique veut dire le rediriger et tester sur deux téléphones.

Scénarios : la même liste de contrôle, des coupables différents

Un dépliant qui scanne au bureau mais pas à l'événement

La lumière du bureau est indulgente ; celle de l'événement ne l'est pas. Les coupables habituels sont un contraste qui passe tout juste en lumière vive, un code légèrement trop petit pour la distance à laquelle les gens se tiennent, et le brillant sous les lumières du lieu. Corrigez dans l'ordre : testez dans la lumière du lieu, agrandissez le code, passez au mat, et revenez au noir sur blanc avant de réimprimer.

Une carte de visite qui scanne pour vous mais pas pour vos clients

Votre téléphone connaît le code ; le téléphone d'un inconnu le rencontre à froid, dans une lumière pire, sous un angle différent. Vérifiez la taille d'abord — en dessous de 2 cm en règle générale, cela échoue sur beaucoup de téléphones — puis la zone de silence, que les designs de cartes adorent encombrer, puis le papier, qui peut absorber l'encre et adoucir les bords.

Un code à l'écran — diapositives, vidéo, ou images sociales

Les codes à l'écran échouent sur la compression, la taille et le temps. Un code recompressé par une plateforme, montré petit dans un coin de diapositive, ou flashé brièvement dans une vidéo donne peu à l'appareil photo pour travailler. Gardez-le grand, à plat face à l'appareil photo, et à l'écran assez longtemps pour scanner ; pour un code dans une photo, le scan depuis une image est le repli.

Comparaison honnête : réimprimer, rediriger, ou repenser ?

Tous les échecs ne méritent pas une réimpression. Si la destination a déménagé et que le code est dynamique, rediriger bat réimprimer en coût, en gaspillage et en vitesse — le motif reste valide et le correctif prend quelques minutes. Si le code est statique et que la destination a déménagé, rediriger n'est pas une option : restaurez la destination ou réimprimez, et choisissez le dynamique la prochaine fois si la destination peut changer à nouveau. Si le motif lui-même est en cause — trop petit, faible contraste, marge encombrée, logo lourd, tirage flou — aucune redirection n'aidera, parce que le lecteur ne peut pas décoder le motif ; réimprimez avec ce paramètre changé, un paramètre à la fois, pour apprendre quel correctif a marché. Deux compromis méritent d'être dits clairement. D'abord, une correction d'erreur plus élevée n'est pas un remède universel : elle achète de la tolérance aux dégâts et aux logos, mais elle densifie la grille, donc augmenter le niveau sur un code déjà petit peut l'aggraver. Ensuite, un code coloré ou avec logo qui scanne dans votre bureau n'est pas prouvé : il ne l'est que quand il scanne du premier coup, dans la vraie lumière, à la vraie distance, sur deux téléphones différents, sur le vrai matériau.

Testez avant d'imprimer — à chaque fois

  1. Scannez sur deux téléphones — un iPhone, un Android si possible — avant d'imprimer.
  2. Testez à la vraie distance et dans la vraie lumière, sur le vrai matériau.
  3. Vérifiez l'aperçu, puis la destination : un aperçu veut dire que le code a été décodé ; une page qui s'ouvre veut dire que la destination fonctionne.
  4. Ne changez qu'une chose à la fois quand un test échoue, pour savoir quel correctif a réellement corrigé.

Si l'échec est la netteté plutôt que la taille, le contraste ou les dégâts, voir pourquoi votre QR code semble flou ; pour les tailles par cas d'usage, voir le guide des tailles d'impression ; et si le code scanne mais que la destination doit changer après impression, voir comment modifier un QR code après impression.

Bon à savoir

Pourquoi mon QR code se scanne sur un téléphone mais pas sur un autre ?

Alors le code lui-même va généralement bien — c'est l'appareil photo, l'éclairage, ou l'angle sur le téléphone qui échoue. Essuyez l'objectif, passez à une meilleure lumière, tenez le code pour qu'il remplisse environ la moitié du viseur, et réessayez.

Un QR code endommagé peut-il toujours fonctionner ?

Souvent oui, grâce à la correction d'erreur — au niveau Élevé, environ 30 % des mots de code peuvent être restaurés, comme défini dans ISO/IEC 18004. Mais les dégâts aux trois motifs de repérage d'angle ou à la zone de silence sont bien plus difficiles à récupérer, et un fort effacement tuera un code même quand sa forme semble intacte.

Mon QR code scanne mais le lien ne fonctionne pas — le code est-il cassé ?

Non, le code fait son travail. La destination est le problème : la page a déménagé, le site est en panne, ou un générateur basé sur un essai l'a désactivé. Si le code est dynamique, connectez-vous et redirigez-le ; s'il est statique, restaurez la page ou réimprimez.

Quelle taille doit faire un QR code imprimé ?

En règle générale, au moins 2 x 2 cm, et au moins un dixième de la distance de scan : 5 cm pour une carte de table scannée depuis 50 cm, 50 cm pour une affiche scannée depuis 5 mètres. Les codes plus denses contenant de longs liens ou des cartes de contact doivent être plus grands à la même distance.

Pourquoi mon code avec logo échoue-t-il alors que la version simple scanne ?

Le logo recouvre une partie de la grille et consomme du budget de correction d'erreur. Gardez le logo sous environ 30 % de la surface du code en règle générale, imprimez les codes avec logo à 3 x 3 cm ou plus, utilisez la correction d'erreur Q ou H, et testez la version avec logo elle-même — un code simple qui scanne ne prouve rien de son frère avec logo.

De combien d'espace blanc un QR code a-t-il besoin autour de lui ?

Une zone de silence d'au moins 4 modules de large sur les quatre côtés, comme spécifié dans ISO/IEC 18004. Gardez texte, filets, bordures décoratives et images proches hors de cette zone, et vérifiez les quatre côtés — une marge généreuse sur trois côtés et nulle sur le quatrième échoue quand même.

Puis-je corriger un QR code imprimé sans réimprimer ?

Seulement si le problème est la destination et que le code est dynamique : connectez-vous, changez la destination, et le motif imprimé fonctionne à nouveau. Si le motif lui-même est en cause — trop petit, faible contraste, marge encombrée, logo lourd, ou tirage flou — le correctif est une réimpression avec ce paramètre changé.
