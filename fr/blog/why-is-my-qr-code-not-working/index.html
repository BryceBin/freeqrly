Pourquoi ce truc ne se scanne-t-il pas ?

Un QR code qui ne se scanne pas n’est presque jamais un mystère. Parcourez ces sept vérifications — dans l’ordre — et vous trouverez le coupable en environ deux minutes.

14 octobre 2026 · 4 min de lecture

1. Il est trop petit

Le classique. Un code écrasé dans le coin d’une carte de visite à 1 cm de large ne se scanne pas de façon fiable. Minimum pour l’impression, en règle générale : 2x2 cm (environ 0,8 pouce), et plus grand c’est toujours plus sûr. Il y a une analyse complète dans le guide des tailles d’impression.

2. Le faible contraste l’a tué

Les lecteurs QR cherchent des modules sombres sur un fond clair. Gris clair sur blanc, pastels de marque, ou un code sur une photo chargée échoueront — surtout en faible lumière. Dans le doute : noir sur blanc fonctionne toujours.

3. Il est endommagé ou décoloré

Flyers froissés, affiches décolorées par le soleil, autocollants rayés. La correction d’erreur peut survivre à certains dégâts (c’est pourquoi ajouter un logo fonctionne), mais il y a une limite. Si un quart du code a disparu, réimprimez.

4. Pas de zone de silence

La marge blanche autour du code n’est pas de la décoration — les scanners en ont besoin pour trouver les bords. Gardez une bordure nette d’au moins 4 modules de large sur les quatre côtés, comme spécifié dans ISO/IEC 18004. Ne laissez pas le texte ou les éléments de design l’encombrer.

5. Reflet, courbe ou angle

Plastification brillante sous lumière vive, un code enroulé autour d’une bouteille, ou photographié sous un angle prononcé. Aplatissez-le, tuez le reflet, photographiez de face.

6. Le contenu est mort

Le code se scanne bien — mais le lien est cassé, la page a déménagé, ou l’essai du générateur « gratuit » a expiré et a emporté votre code avec lui. C’est le piège du lien expiré : les QR codes expirent-ils ? explique lesquels expirent et comment les éviter.

7. Votre caméra

Essuyez l’objectif. Sérieusement — un objectif maculé est derrière un nombre embarrassant de codes « cassés ». Puis testez sur un deuxième téléphone : si le téléphone B le lit, le code n’a jamais été le problème.

Testez avant d’imprimer

Scannez le code sur deux téléphones différents (un iPhone, un Android si vous pouvez) avant d’envoyer quoi que ce soit à l’impression. Trente secondes maintenant évitent une réimpression plus tard. Générez un code de test dans le générateur gratuit et essayez-le.

Sources

Bon à savoir

Pourquoi mon QR code se scanne sur un téléphone mais pas sur un autre ?

Alors le code lui-même va bien — c’est la caméra, l’éclairage ou l’angle sur le téléphone qui échoue. Essuyez l’objectif et essayez en meilleure lumière.

Un QR code endommagé peut-il toujours fonctionner ?

Souvent oui, grâce à la correction d’erreur — jusqu’à 30 % de dégâts peuvent être tolérés au réglage Élevé, comme défini dans ISO/IEC 18004. Mais de gros dégâts, la décoloration ou des motifs de repérage manquants le tueront.

Mon QR code se scanne mais le lien ne fonctionne pas — le code est-il cassé ?

Non, le code fait son travail. La destination est le problème : la page a déménagé, le site est en panne, ou un générateur basé sur l’essai l’a désactivé.
