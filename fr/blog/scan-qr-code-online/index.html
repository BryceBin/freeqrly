Scanner des QR codes en ligne, en privé

Beaucoup de scanners QR en ligne vous demandent de téléverser votre image vers leur serveur. Le nôtre, non — le code est décodé directement dans votre navigateur. Caméra ou téléversement d’image, gratuit pour toujours.

14 octobre 2026 · 4 min de lecture

Pourquoi « pas de téléversement » compte

Les QR codes contiennent souvent des choses sensibles : mots de passe WiFi, billets d’événement, cartes d’embarquement, liens privés. Téléverser cette image vers le serveur d’un inconnu — juste pour la lire — est un échange de confidentialité que la plupart des gens ne réalisent pas qu’ils font. Le scanner QR de FreeQrly décode l’image avec JavaScript sur votre appareil (la bibliothèque jsQR open-source). L’image ne quitte jamais la page.

Deux façons de scanner

Caméra : touchez « Démarrer la caméra », pointez vers le code, c’est fait. Utilise votre caméra arrière sur les téléphones. Votre navigateur demandera l’autorisation de la caméra une fois — c’est entre vous et votre navigateur ; nous ne voyons jamais le flux.

Téléversement : vous avez une capture d’écran, un flyer enregistré, ou une photo avec un code dedans ? Téléversez l’image et elle est décodée instantanément. Ça fonctionne même hors ligne — chargez la page une fois, déconnectez-vous, et le scan par téléversement fonctionne toujours.

Ce que vous récupérez

Le contenu décodé brut, plus des actions intelligentes : les liens obtiennent un bouton « Ouvrir le lien » (vérifiez d’abord l’URL — le guide de scan a une habitude de sécurité en 3 secondes), tout le reste obtient un bouton Copier.

Quand il ne peut pas lire votre code

Photos floues, petits codes, gros reflets — les suspects habituels. La liste complète des correctifs est dans pourquoi votre QR code ne se scanne pas. Et si vous avez besoin de créer votre propre QR code à la place, c’est le studio principal — aussi gratuit, aussi privé.
