Dépannage de QR code de bout en bout

Ne scanne pas, scanne parfois, ou scanne vers nulle part ? Trouvez votre échec dans le tableau, suivez son correctif, et testez à nouveau — la plupart des codes sont corrigés sans réimpression.

3 novembre 2026 · 15 min de lecture

Un QR code qui ne veut pas scanner est rarement un mystère. La plupart des échecs se résument à l'une de onze causes, et elles se divisent en trois questions : le motif est-il illisible, le téléphone peine-t-il, ou le code a-t-il bien scanné et la destination vous a-t-elle déçu ? Répondez d'abord à celles-ci, et vous ne réimprimerez pas un code sain — ni ne réparerez un motif quand le lien est mort.

Vérifiez ces trois choses d'abord

  1. Essayez un deuxième téléphone. Si un autre téléphone lit le code, le motif va bien. Passez directement aux vérifications du téléphone ci-dessous.
  2. Regardez le code, pas l'écran. Est-il petit, pâle, encombré par du texte voisin, couvert par un logo, rayé, ou effacé ? N'importe lequel de ces défauts peut rendre un motif illisible. Essayez aussi une copie fraîche du fichier d'origine : si la copie fraîche scanne, c'est l'impression d'origine qui a échoué, pas les données.
  3. Lisez ce que le scan renvoie. Si le téléphone reconnaît le code mais que la page ne charge jamais ou arrive quelque part d'inattendu, le motif a fait son travail. La destination est le problème : une page supprimée, un lien mal tapé, ou un code dynamique désactivé.

Une distinction compte tout au long : un code qui ne scanne jamais a un problème de motif ou d'appareil photo, tandis qu'un code qui scanne parfois — en pleine lumière mais pas en faible lumière, de près mais pas à bout de bras — est un code limite. Les codes limites passent à votre bureau et échouent entre les mains d'un client : traitez un code parfois comme cassé.

Le motif lui-même : six façons dont un code devient illisible

1. Trop petit pour la distance de scan

Les petits codes échouent parce que les appareils photo ne peuvent pas résoudre les modules individuels — les petits carrés — quand ils sont minuscules dans le cadre. En règle empirique, gardez les codes imprimés à au moins 2 × 2 cm, et agrandissez avec la distance : la largeur du code devrait être au moins un dixième de la distance de scan prévue. Une carte de table scannée à 50 cm nécessite un code d'environ 5 cm de large ; une affiche scannée à 5 mètres en nécessite un d'environ 50 cm de large. Les codes denses contenant de longs liens ont besoin de plus de place que les liens courts. Les tableaux complets de tailles sont dans le guide des tailles d'impression.

2. Flou ou basse résolution

Le flou veut dire trop peu de pixels étirés sur trop d'espace, donc les bords des modules se brouillent ensemble. Les coupables habituels sont une exportation basse résolution, un enregistrement JPEG qui adoucit les bords nets, une capture d'écran d'une capture d'écran, ou un fichier étiré hors de proportion de sorte que les carrés deviennent des rectangles. Corrigez-le au fichier source : réexportez en PNG haute résolution, ou en SVG, qui se met à l'échelle sans flou, en ne redimensionnant que proportionnellement. Une impression déjà floue ne peut pas être re-nettoyée — réimprimez depuis le fichier propre. Les cinq causes et leurs correctifs sont dans pourquoi votre QR code est flou.

3. Faible contraste

Les lecteurs cherchent des modules sombres sur un fond clair. Gris clair sur blanc, couleurs de marque pastel, un code sur une photographie, ou des modules sombres sur un fond sombre enlèvent tous la différence dont l'appareil photo a besoin. C'est l'échec le plus courant lié au design, et le plus évitable : noir sur blanc fonctionne toujours, et toute paire de couleurs devrait toujours se lire en noir et blanc. Méfiez-vous des codes inversés et des codes sur des images chargées, où le fond rivalise avec le motif. Si un code scanne en pleine lumière mais pas dans une pièce sombre, le contraste est le premier suspect.

4. Zone de silence encombrée ou rognée

La marge blanche autour d'un code n'est pas de la décoration. Les lecteurs l'utilisent pour trouver les bords du motif, et la norme spécifie une zone de silence d'au moins 4 modules de large — quatre des propres petits carrés du code — des quatre côtés, comme défini dans ISO/IEC 18004. Du texte ou des motifs s'entassant dans cette marge perturbent la détection, donc le téléphone ne lit jamais les données. Cet échec est facile à manquer parce que le code lui-même semble parfait. Testez-le en couvrant tout autour du code : s'il scanne proprement, restaurez la marge et gardez-la vide.

5. Un logo recouvrant trop le motif

Un logo central ne fonctionne que parce que la correction d'erreur reconstruit les données couvertes. ISO/IEC 18004 définit quatre niveaux de correction d'erreur — L, M, Q, et H — avec une récupération approximative des mots de code de 7 %, 15 %, 25 %, et 30 % respectivement. Ces pourcentages décrivent la récupération des mots de code, pas une part garantie de surface visible que vous pouvez couvrir. En règle empirique, gardez le logo petit — le guide des tailles suggère moins d'environ 30 % de la surface du code — utilisez le niveau de correction d'erreur le plus élevé, imprimez plus grand que pour un code simple, et ne couvrez jamais les trois grands carrés d'angle, dont le lecteur a besoin pour orienter le motif. Testez d'abord sur deux téléphones. Voir comment ajouter un logo à un QR code et le générateur de code avec logo.

6. Dégâts, saleté et effacement

Plis, rayures, éclaboussures, effacement, et autocollants usés entament tous le motif, et la correction d'erreur ne peut reconstruire que jusqu'à un certain point. Les dégâts aux carrés d'angle sont particulièrement fatals : sans eux, le lecteur ne peut pas localiser le code du tout. Pour les codes réels — menus, étiquettes, panneaux extérieurs — la prévention bat la réparation : pelliculez la surface, choisissez un niveau de correction d'erreur plus élevé, imprimez un exemplaire de rechange, et inspectez d'abord les copies les plus anciennes. Si le motif lui-même est usé, réimprimez depuis le fichier d'origine plutôt que de rafistoler la copie abîmée.

La destination : quand le code scanne mais que rien de bon ne se passe

Un scan qui renvoie une page d'erreur, une page manquante, ou une page de destination que vous n'attendiez pas est un scan réussi d'une destination cassée. Ouvrez le lien sur un ordinateur et lisez-le caractère par caractère : une page déplacée ou supprimée, une adresse mal tapée, un site en panne, ou un lien court dont le propriétaire a changé la destination sont les causes habituelles.

Une version structurelle décide si un correctif est même possible. Un code statique contient la destination directement dans son motif, donc il fonctionne tant que le lien fonctionne — et si le lien meurt, seule la page derrière lui peut être restaurée ou le code réimprimé. Un code dynamique contient une courte redirection à la place, donc son propriétaire peut changer la destination sans réimprimer — mais le code dépend alors de ce compte et de ce service restant actifs. Si ce compte expire ou que le service désactive la redirection, le code imprimé cesse de mener quelque part d'utile, même si le motif est impeccable. C'est le mécanisme derrière la plupart des histoires « mon code a expiré », expliqué dans les codes QR expirent-ils ?. Vérifiez d'abord si la destination peut être restaurée ou redirigée avant de réimprimer.

Le téléphone et le moment : autorisation, mise au point, lumière, et écrans

  • Autorisation d'appareil photo. Un lecteur à qui l'accès à l'appareil photo n'a jamais été accordé ne peut rien voir du tout. Autorisez l'accès à l'appareil photo, puis réessayez. Le lecteur FreeQrly décode dans votre navigateur sur votre propre appareil — voir la page du lecteur — mais le navigateur a toujours besoin de l'autorisation pour ouvrir l'appareil photo.
  • Un objectif sale. Essuyez l'objectif avec un chiffon doux. Un objectif maculé brouille exactement le fin détail dont un QR code est fait.
  • Mise au point et distance. Tenez le téléphone stable, gardez tout le code et sa zone de silence dans le cadre, et bougez lentement jusqu'à ce que la mise au point se verrouille. Très près n'est pas toujours mieux : la plupart des appareils photo ne peuvent pas faire la mise au point à quelques centimètres.
  • Lumière et reflets. Un pelliculage brillant, un écran, ou un spot peut renvoyer de la lumière dans l'appareil photo et effacer les modules. Inclinez le code ou le téléphone, sortez de la lumière directe, ou passez à un fini mat. Un reflet qui bouge quand vous inclinez est un reflet, pas un dégât.
  • Surfaces courbes ou en angle. Un code enroulé autour d'une bouteille ou photographié sous un angle prononcé est déformé, et les lecteurs ne tolèrent cela que jusqu'à un certain point. Aplatissez ce que vous pouvez et photographiez aussi frontalement que possible.
  • Un code sur l'écran du téléphone lui-même. On ne peut pas pointer l'appareil photo d'un téléphone vers son propre écran. Pour un code dans une photo, une capture d'écran, ou un message sur le même téléphone, décodez plutôt le fichier image : sur iPhone, appuyez longuement sur le code dans Photos ; sur Android, utilisez Lens dans Photos ; sur un ordinateur, téléversez-le vers un décodeur comme le lecteur FreeQrly. Le propre guide d'Apple confirme la base : sur iPhone, ouvrez l'application Appareil photo ou le lecteur de code dans le Centre de contrôle, tenez le téléphone pour que le code apparaisse dans le cadre, et touchez le lien qui apparaît. Si ce chemin ne donne rien sur un code que d'autres téléphones lisent, soupçonnez l'autorisation, la mise au point, et la lumière — pas une application de scan manquante. Par scène : impression, écran, et extérieur

Codes imprimés : prospectus, cartes, menus, emballages

Les échecs d'impression sont généralement la taille, la résolution, le contraste, ou l'usure — dans cet ordre. Testez à la taille finale, pas à l'écran : imprimez une copie, reculez à la distance de vision réelle, et scannez-la avec deux téléphones. Vérifiez la zone de silence dans la mise en page finie, pas seulement dans l'aperçu, parce que les outils de mise en page rognent les marges. Pelliculez les codes manipulés et gardez l'exportation d'origine.

Codes sur écrans : diapositives, TV, appels vidéo, sites web

Les codes d'écran échouent sur les reflets, le scintillement de rafraîchissement, et la taille relative à la distance du spectateur. Faites le code grand sur la diapositive, gardez-le à l'écran plusieurs secondes plutôt que de le faire passer en éclair, et évitez de le placer sur un fond mouvant. Pour l'affichage de téléphone à téléphone, augmentez la luminosité et inclinez loin des lumières au plafond.

Codes extérieurs : affiches, panneaux, véhicules, vitrines

Les codes extérieurs affrontent tous les échecs à la fois : distance, soleil, reflets, météo, et effacement. Agrandissez généreusement selon la règle du dixième, imprimez à fort contraste sur support mat, imperméabilisez-le, et testez à la distance et à l'angle réels des passants. Les codes de vitrine nécessitent une vérification spéciale : scannez depuis l'extérieur de la vitre, en plein jour, parce que des reflets invisibles de l'intérieur peuvent effacer le code.

Une comparaison honnête : codes gratuits, codes payants, et codes « expirés »

Un code statique de n'importe quel générateur honnête a la même propriété : la destination est intégrée au motif, donc il n'y a rien qui expire, rien à renouveler, et aucun compte qui peut expirer et emporter le code avec lui. Un code dynamique est un produit différent, et le marché honnête est celui-ci : vous gagnez la modification après impression et les statistiques de scan, et vous acceptez une dépendance à un compte et à un service. Refaire, réimprimer, ou corriger la destination ?

  • Corrigez la destination quand le code scanne mais que la page est fausse ou manquante, et que vous contrôlez la page ou la redirection. Pas de réimpression nécessaire.
  • Réimprimez depuis le fichier d'origine quand la copie fraîche scanne mais que la copie installée ne scanne pas : l'impression, la surface, ou le placement a échoué.
  • Refaites le code quand la copie fraîche échoue aussi, que les données sont fausses, ou que le design — taille, contraste, logo, marge — est en cause. Générez un code propre, testez-le sur deux téléphones, et imprimez seulement ensuite.
  • Changez de type de code pour les échecs structurels récurrents : une destination qui change appartient à un code dynamique ; une destination qui ne doit jamais dépendre d'un compte appartient à un code statique.

Si un code échoue toujours sur deux téléphones depuis une impression fraîche, grande, noir sur blanc avec une marge claire, soupçonnez les données elles-mêmes — un lien trop long, ou une adresse mal tapée. Raccourcissez le lien et régénérez.

Bon à savoir

Pourquoi mon QR code scanne-t-il sur un téléphone mais pas sur un autre ?

Alors le code et le lien vont tous les deux bien — le téléphone défaillant est le problème. Essuyez son objectif, autorisez l'accès à l'appareil photo, tenez stable avec tout le code dans le cadre, et essayez dans une meilleure lumière. S'il échoue toujours sur ce seul téléphone, utilisez le chemin de l'appareil photo intégré plutôt qu'une application de scan tierce.

Mon QR code scanne parfois mais pas toujours — est-ce correct ?

Non. Un code parfois est un code limite : il passe à votre bureau et échoue entre les mains d'un client. Traitez-le comme cassé et corrigez la cause sous-jacente — généralement la taille, le contraste, les reflets, ou une zone de silence encombrée — plutôt que d'espérer une bonne lumière.

Quelle taille doit faire un QR code imprimé ?

En règle empirique, au moins 2 x 2 cm, et au moins un dixième de la distance de scan prévue : une carte de table scannée à 50 cm nécessite un code d'environ 5 cm de large, et une affiche scannée à 5 mètres en nécessite un d'environ 50 cm de large. Les codes denses contenant de longs liens ont besoin de plus de place que les liens courts.

Quelle part d'un QR code un logo peut-il recouvrir ?

Gardez-le petit. Utilisez le niveau de correction d'erreur le plus élevé, imprimez plus grand que pour un code simple, et ne couvrez jamais les trois grands carrés d'angle, dont le lecteur a besoin pour orienter le motif. En règle empirique, le guide des tailles suggère moins d'environ 30 % de la surface du code — et testez toujours le code fini sur deux téléphones avant d'imprimer.

Mon code scanne mais la page a disparu — le code est-il cassé ?

Non. Le motif a parfaitement décodé ; la destination a échoué. Une page déplacée ou supprimée, une adresse mal tapée, ou un code dynamique dont le compte ou la redirection a été désactivé ressemblent tous à cela. Si vous contrôlez la page ou la redirection dynamique, restaurez-la ou redirigez-la — aucune réimpression n'est nécessaire. Un code statique ne peut pas être redirigé ; seule la page derrière lui peut être restaurée.

Ai-je besoin d'une application de scan pour tester mon code ?

Non. Sur iPhone, utilisez l'application Appareil photo ou le lecteur de code dans le Centre de contrôle ; sur Android, utilisez l'appareil photo intégré ou Lens. Pour un code qui est déjà sur l'écran du téléphone lui-même — dans une photo ou une capture d'écran — décodez le fichier image au lieu de pointer l'appareil photo vers son propre écran.
