Votre logo, au centre — toujours lisible

Un logo rend un code vraiment vôtre. Il recouvre aussi une partie du motif. Voici comment avoir les deux : logo parfaitement centré, code qui scanne toujours du premier coup.

28 octobre 2026 · 4 min de lecture

Un QR code simple fonctionne. Un QR code avec logo au centre fonctionne et se reconnaît — sur un emballage, sur une carte de visite, sur une affiche de l'autre côté de la pièce. Le piège est bien réel, pourtant : le logo repose sur le motif, et c'est le motif que le téléphone lit. Si l'équilibre est raté, le code cesse de scanner. S'il est juste, personne ne remarque la technique — on ne voit que votre marque.

Les trois règles

  1. PNG carré avec transparence. Un logo carré sur fond transparent s'installe le plus proprement au centre. Un logo rectangulaire ou encadré de blanc gaspille de la place et lutte contre le motif.
  2. Gardez-le sous ~30 % de la surface du code. C'est la règle empirique qu'utilise le générateur lui-même : assez petit pour que le motif restant porte encore les données, assez grand pour se lire d'un coup d'œil.
  3. Laissez la correction d'erreur faire son travail. Les QR codes sont conçus pour survivre aux dommages — jusqu'à 30 % du motif peut manquer et le code se lit encore. Quand vous ajoutez un logo, la correction d'erreur est relevée automatiquement pour que le centre recouvert ne pose pas problème.

Étape par étape

Créez d'abord le code — tous les types acceptent un logo : un lien, une vCard, un réseau Wi-Fi. Puis importez le logo à l'étape logo du studio, dimensionnez-le au centre, et téléchargez. PNG jusqu'à 2048 px pour l'impression, ou SVG si vous en avez besoin en taille infiniment adaptable. L'étape logo fonctionne avec tous les types de code, et le même logo peut s'appliquer à tout un lot.

Quatre erreurs qui cassent les scans

  • Logo trop grand. Au-delà de ~30 % de la surface, même la correction d'erreur ne peut pas reconstruire les données manquantes. Si le logo doit être grand, utilisez un lien plus court — moins de données, c'est un motif plus aéré.
  • Logo peu contrasté. Un logo pâle sur un code clair, ou un logo qui se fond dans les modules, perturbe les appareils photo. Logo foncé, fond clair, fort contraste — la même règle que pour le code lui-même.
  • Fond chargé derrière le code. Un code avec logo posé sur une photo ou un motif, c'est deux combats à la fois. Offrez au code une zone propre et claire où se poser, avec sa marge de silence dégagée.
  • Code étiré. Un redimensionnement non proportionnel déforme la grille. Agrandissez uniformément pour que les carrés restent carrés.

Le test qui le prouve

Avant d'imprimer une série, scannez le code avec deux téléphones — un iPhone, un Android — et scannez l'impression, pas seulement l'écran. Si les deux lisent du premier coup, c'est bon. Si l'un des deux hésite, réduisez le logo d'un cran ou augmentez le contraste et testez à nouveau. Trente secondes ici vous épargnent une réimpression.

Bon à savoir

Mon logo va-t-il casser le QR code ?

Non, s'il reste sous ~30 % de la surface du code. La correction d'erreur est relevée automatiquement quand un logo est ajouté, donc le centre recouvert n'empêche pas le scan.

Quel fichier de logo fonctionne le mieux ?

Un PNG carré avec transparence. Les logos rectangulaires et les logos encadrés de blanc gaspillent de la place et luttent contre le motif.

Puis-je utiliser un logo avec tous les types de QR code ?

Oui — lien, vCard, Wi-Fi et tous les autres types. Le même logo peut aussi s'appliquer à tout un lot.

PNG ou SVG pour l'impression ?

PNG jusqu'à 2048 px pour la plupart des travaux d'impression, ou SVG quand vous en avez besoin en taille infiniment adaptable, comme pour une banderole.
