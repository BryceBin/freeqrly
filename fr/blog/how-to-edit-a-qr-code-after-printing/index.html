Modifiez un QR code après impression

Les dépliants sont déjà sortis — et le lien est faux. Avec un code dynamique, c’est une correction de deux minutes, pas une réimpression.

16 octobre 2026 · 4 min de lecture

Les dépliants sont déjà sortis — et le lien est faux. Ou le menu a déménagé. Ou la page de campagne n’était pas définitive quand l’affiche est partie à l’impression. Avec un code statique, c’est une réimpression. Avec un code dynamique, c’est une correction de deux minutes.

L’astuce : le motif d’un code dynamique ne change jamais. Il pointe vers un lien court sur le serveur de FreeQrly, et vous contrôlez où ce lien envoie les gens. Modifiez la destination, et chaque exemplaire imprimé — déjà sur les murs, les dépliants, les emballages — sert le nouveau contenu instantanément. Pas de réimpression, pas d’autocollants sur l’ancien code.

  1. Connectez-vous. Ouvrez la page de connexion et connectez-vous au compte qui possède le code.
  2. Ouvrez le tableau de bord. Allez à votre tableau de bord. Chaque code dynamique de votre compte y est présenté comme une carte, avec sa miniature QR et son nombre de scans.
  3. Ouvrez Modifier. Sur la carte du code, cliquez sur Modifier. Vous verrez le même générateur que celui utilisé pour le créer — type, contenu, style, tout.
  4. Changez ce dont vous avez besoin. Destination, contenu, même le type : un code Site web peut devenir un code WiFi. Couleurs, logo, cadre — tout est modifiable aussi.
  5. Enregistrer. Cliquez sur Enregistrer les modifications. C’est fait. Le code imprimé sert maintenant le nouveau contenu. Testez-le avec l’appareil photo de votre téléphone pour être sûr.

Ce que vous pouvez changer — et ce que vous ne pouvez pas

  • Destination et contenu : le lien, le texte, le mot de passe WiFi — tout ce que le code porte.
  • Type : passez un code d’un type de contenu à un autre. Le motif s’en moque ; il ne contient que le lien court.
  • Style : couleurs, points, logo, cadre. La miniature du tableau de bord se met à jour en conséquence.
  • Ce que vous ne pouvez pas changer : le motif imprimé lui-même — mais vous n’en avez jamais besoin, puisque le motif ne contient que le lien court. Et vous ne pouvez pas transférer un code vers un autre compte.

Deux choses à savoir

Les modifications sont instantanées et silencieuses. Il n’y a ni étape de « republication » ni délai — le prochain scan obtient la nouvelle destination. Si l’ancienne destination était une page que vous avez retirée, corrigez d’abord le code, puis retirez la page.

Supprimer est définitif. Supprimez un code et ses exemplaires imprimés cessent de fonctionner — il n’y a pas d’annulation. Supprimez uniquement quand le code est vraiment retiré ; la place se libère pour un nouveau code. (Toujours pas sûr que le dynamique vous convienne ? Statique vs dynamique, expliqué honnêtement. Bon à savoir

Faut-il réimprimer un QR code après l’avoir modifié ?

Non. Le motif imprimé contient un lien court ; modifier change l’endroit vers lequel ce lien pointe. Chaque exemplaire imprimé sert le nouveau contenu immédiatement.

Puis-je changer un QR code dynamique pour un autre type ?

Oui. Dans le tableau de bord, ouvrez Modifier et choisissez un nouveau type — un code Site web peut devenir un code WiFi, par exemple. Le motif imprimé reste valide.

Modifier un QR code réinitialise-t-il ses statistiques de scans ?

Non. Les statistiques continuent de s’accumuler sur le même code. Supprimer un code le supprime avec ses statistiques, définitivement.

Et si je supprime un QR code dynamique par erreur ?

Il n’y a pas d’annulation — les exemplaires imprimés cessent de fonctionner et la place se libère. Supprimez uniquement les codes vraiment retirés.
