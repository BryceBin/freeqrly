Cartes d'avis imprimables qui tiennent dans un portefeuille

Le meilleur moment pour demander un avis est le moment où un client sourit. Ces cartes format portefeuille — huit par page A4 — vous permettent de transmettre la demande sans discours : un scan, directement vers votre page d'avis.

4 novembre 2026 · 4 min de lecture

Les avis sont gênants à demander à voix haute, c'est pourquoi la plupart des clients satisfaits n'en laissent jamais. Une petite carte résout le problème du timing : remettez-la avec le reçu, le sac ou l'au revoir, et le client décide plus tard, sur son propre téléphone, avec le lien déjà en main.

Chaque carte ci-dessous mesure 85 × 55 mm — format standard de carte de visite — et la page en dispose huit en grille, donc une feuille A4 vous donne une pile à garder près de la caisse. Pour l'utiliser : générez un QR code qui renvoie directement vers votre page d'avis, collez-le dans l'emplacement pointillé, imprimez et découpez. Si vous voulez que la demande atterrisse spécifiquement sur Google, obtenir des avis Google avec un QR code couvre la configuration du lien. Utilisez un code dynamique si votre lien d'avis peut changer — alors les cartes imprimées ne deviennent jamais obsolètes ; voir comment modifier un QR code après impression. Pour un format plus grand à carte unique, voir QR codes sur cartes de visite.

Bon à savoir

Sur quel papier dois-je imprimer les cartes d'avis ?

Le papier cartonné standard fonctionne bien — il ressemble à une vraie carte de visite et survit à une poche ou un portefeuille. Le papier d'imprimante ordinaire convient pour un lot de test, mais il se plisse vite dans la main d'un client.

Puis-je les imprimer en noir et blanc ?

Oui. Rien sur la carte ne dépend de la couleur ; un code sombre sur fond clair scanne tout aussi bien en monochrome. Gardez le code sombre sur clair dans tous les cas — ne l'inversez jamais.

Comment placer mon propre QR code dans l'emplacement pointillé ?

Générez le code, imprimez-le à 25 × 25 mm, et collez-le sur la case pointillée dans votre outil de mise en page — ou imprimez la feuille et collez une étiquette de code imprimée sur chaque emplacement. Testez le scan d'une carte finie avant de découper toute la page.

25 mm est-il assez grand pour le code ?

Oui pour une carte tenue en main et scannée à 20–30 cm — cela se situe au-dessus du plancher de 2 cm pour l'impression. Ne le réduisez pas davantage pour caser plus de texte ; un code trop petit est l'échec d'impression le plus fréquent.

Que se passe-t-il si mon lien d'avis change après avoir imprimé une pile ?

Utilisez un QR code dynamique : la destination derrière le code peut être mise à jour tandis que les cartes imprimées restent valides. Avec un code statique, un lien modifié signifie réimprimer.

Combien de cartes tiennent sur une page, et comment les découper ?

Huit cartes par page A4, en grille 2 × 4. Découpez le long des bords des cartes avec un massicot pour des bords droits ; les intervalles de la grille vous donnent un peu de tolérance de coupe.

Dois-je les plastifier ?

Seulement si elles seront mouillées ou manipulées rudement. La plastification ajoute des reflets sous les lumières vives, donc si vous plastifiez, testez le scan d'une carte plastifiée avant d'imprimer tout le tirage.
