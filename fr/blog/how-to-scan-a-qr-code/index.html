Comment scanner un QR code

Pas d’app requise. Chaque iPhone et téléphone Android moderne scanne les QR codes avec la caméra qu’il a déjà. Voici comment — plus ce qu’il faut faire quand rien ne se passe.

14 octobre 2026 · 4 min de lecture

  1. Pointez votre caméra vers le code Ouvrez l’app Appareil photo intégrée et pointez-la vers le QR code, en gardant tout le carré dans le cadre.
  2. Touchez la notification Une bannière ou un aperçu de lien apparaît — touchez-le pour ouvrir la destination.
  3. Sur iPhone, utilisez les raccourcis intégrés Scanner QR du Centre de contrôle, ou appui long sur l’icône Appareil photo. Pour un code dans une photo, appui long dessus dans Photos.
  4. Sur Android, utilisez Lens ou les Paramètres rapides Google Lens dans la caméra ou l’app Google, ou la tuile Scanner un QR code dans les Paramètres rapides. Pour une image enregistrée, Google Photos + Lens.
  5. Si rien ne se passe, réparez le code, pas le téléphone Rapprochez-vous, essuyez l’objectif, et vérifiez le code lui-même : trop petit, faible contraste, endommagé, ou imprimé sur une courbe.
  6. Vérifiez l’aperçu avant d’ouvrir Jetez un œil à l’URL avant de toucher, surtout pour les codes trouvés dans des lieux publics.

Sur iPhone

Ouvrez l’app Appareil photo et pointez-la vers le code — tenez bon une seconde. Une notification jaune apparaît ; touchez-la. C’est tout. Ça marche sur n’importe quel iPhone moderne — le guide d’Apple couvre l’app Appareil photo et le Scanner de code.

Deux raccourcis à connaître : ouvrez le Centre de contrôle et touchez l’icône du scanner QR (ajoutez-la via Réglages → Centre de contrôle si elle manque), ou appui long sur l’icône Appareil photo sur l’écran de verrouillage. Si le code est dans une photo ou une capture d’écran, ouvrez-la dans l’app Photos et appui long sur le code — iOS le détecte directement dans l’image.

Sur Android

La plupart des téléphones Android scannent aussi depuis la caméra intégrée : pointez, attendez l’invite, touchez. Sur Pixel et beaucoup d’autres, Google Lens dans la caméra ou l’app Google s’en charge. Les téléphones Samsung ont un scanner dédié dans le panneau des Paramètres rapides — balayez vers le bas et cherchez « Scanner un QR code ». Et comme sur iPhone, vous pouvez ouvrir une image enregistrée dans Google Photos et toucher le bouton Lens.

Quand rien ne se passe

Neuf fois sur dix, c’est le code, pas votre téléphone : trop petit, faible contraste, endommagé, ou imprimé sur une courbe. La liste complète est dans pourquoi votre QR code ne se scanne pas. L’objectif sale est le classique oublié — essuyez-le et réessayez.

Une habitude de sécurité en 3 secondes

Votre téléphone affiche un aperçu du lien avant de l’ouvrir. Jetez-y un œil. Si un code sur un lampadaire promet un parcmètre mais que l’URL ressemble à une suite aléatoire de caractères, ne touchez pas — les autocollants sur les vrais codes sont une arnaque connue dont la FTC a averti. Bon à savoir

Ai-je besoin d’une app pour scanner des QR codes ?

Non. Les iPhone et pratiquement tous les téléphones Android scannent les QR codes avec la caméra intégrée. Les apps de scan tierces sont inutiles et souvent pleines de publicités. Le guide d’Apple couvre l’app Appareil photo et le Scanner de code sur iPhone.

Comment scanner un QR code depuis une capture d’écran ?

Sur iPhone, ouvrez la capture d’écran dans Photos et appui long sur le code. Sur Android, ouvrez-la dans Google Photos et touchez le bouton Lens.

Pourquoi ma caméra ne scanne pas le QR code ?

En général, le code est trop petit, à faible contraste, endommagé, ou il n’y a pas de zone de silence autour. Essuyez votre objectif, rapprochez-vous, et voyez la liste complète des correctifs dans notre guide de dépannage.
