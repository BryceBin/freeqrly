Comment scanner un QR code

Pas d’app requise. Chaque iPhone et téléphone Android moderne scanne les QR codes avec la caméra qu’il a déjà. Voici comment — plus ce qu’il faut faire quand rien ne se passe.

14 octobre 2026 · Dernière mise à jour : 3 novembre 2026 · 15 min de lecture

Réponse courte : pointez l'appareil photo de votre téléphone vers le code, attendez l'aperçu, lisez-le, et touchez-le. Pas d'application à installer, pas de compte à créer, pas de photo à prendre. Chaque iPhone et téléphone Android moderne lit les QR codes avec l'appareil photo qu'il possède déjà, et tout le travail prend quelques secondes une fois qu'on connaît le rythme : cadrer tout le code, tenir stable, lire l'aperçu, toucher. Ce guide explique ce que chaque type de code fait, ce que votre téléphone demande en chemin, l'habitude de sécurité qui compte le plus, et une chaîne de pannes pour le moment où rien ne se passe.

Commencez par reconnaître ce que vous regardez. Un QR code est le motif carré avec trois grands carrés d'angle ; ces coins sont les repères du lecteur, et un motif sans eux n'est pas du tout un QR code — ce peut être un code-barres ordinaire, une marque propriétaire, ou un motif décoratif, et aucun lecteur de QR ne le lira. Un vrai QR code peut contenir plusieurs types de contenu, et savoir lequel vous avez scanné change ce à quoi vous devez vous attendre ensuite. Un lien ouvre une page, un code Wi-Fi propose un réseau, un code contact propose une personne à enregistrer, un code texte affiche des mots, un code événement propose une entrée d'agenda, et un code de paiement ou de billet ouvre une application ou un paiement. L'aperçu de votre téléphone vous dit lequel c'est avant que quoi que ce soit se passe.

Les étapes, du code à la destination

  1. Cadrez tout le code. Ouvrez l'application Appareil photo intégrée et tenez le téléphone pour que tout le carré, marge blanche autour comprise, soit dans le cadre. Pas besoin d'appuyer sur le déclencheur. Si une partie du code est coupée, reculez jusqu'à ce que les quatre coins soient visibles.
  2. Tenez stable et laissez l'appareil photo faire la mise au point. Donnez une seconde à l'appareil photo pour se stabiliser ; un téléphone en mouvement produit un motif flou.
  3. Lisez l'aperçu. Un lien, un nom de réseau, ou une action apparaît à l'écran. Lisez-le entièrement avant de toucher — le domaine, pas seulement les premiers mots. Cette étape est l'habitude de sécurité, traitée en détail ci-dessous.
  4. Touchez pour ouvrir, et répondez à la confirmation. Toucher ouvre la destination ; lisez toute confirmation de la même façon, comme un deuxième aperçu.
  5. Si rien n'apparaît, parcourez la chaîne de pannes. Ne continuez pas à pointer en espérant. Les vérifications ordonnées ci-dessous séparent un problème de téléphone d'un problème de lumière d'un problème de code en une minute environ.
  6. Si le code est déjà sur votre propre écran, lisez l'image à la place. Capturez le code, ou enregistrez l'image, et lisez-la depuis l'image (Photos sur iPhone, Google Photos avec Lens sur Android). La version complète est le guide pour scanner un QR code depuis une photo.

Avant de toucher : autorisations et confirmations

Le scan vous demande très peu, et cela fait partie de son attrait — mais les quelques choses qu'il demande méritent l'attention. Un lecteur dans le navigateur peut demander l'autorisation de l'appareil photo la première fois ; autorisez-la pendant l'utilisation de la page, et révoquez-la ensuite. Il n'a pas besoin de vos photos, contacts ou position, et toute demande de ce type est une raison de s'arrêter.

Après l'aperçu, les confirmations suivent le type de code. Un code Wi-Fi vous demande de rejoindre un réseau — vérifiez le nom par rapport au panneau avant de rejoindre, puisqu'un réseau pirate avec un nom plausible est un vrai piège, et rejoindre le mauvais réseau est pire que de ne pas rejoindre le bon. Un code contact vous demande d'enregistrer une personne, et un code d'application vous demande d'ouvrir une application — vérifiez les deux par rapport à ce que vous attendiez. Un téléchargement devrait vous faire marquer une pause : un fichier est un engagement plus lourd qu'une page. Et un formulaire de connexion atteint depuis un code public mérite un deuxième regard avant qu'un mot de passe s'en approche.

Scénarios : le même rythme, des enjeux différents

Menus, affiches et horaires sont les scans aux enjeux les plus faibles, et le rythme y est à son plus simple : cadrer, aperçu, toucher. Les échecs ici sont généralement physiques : incliner contre les reflets, se rapprocher pour la taille, ajouter de la lumière contre l'obscurité. Billets et enregistrements sont à enjeux plus élevés parce qu'ils sont sensibles au temps et souvent à usage unique. Ayez le code prêt avant d'arriver à la file, et scannez vite s'il se rafraîchit.

L'habitude de sécurité, en détail

Un QR code cache sa destination par construction. On ne peut pas lire une URL en regardant le motif, et c'est exactement pourquoi un code est un véhicule si efficace pour un lien sur lequel vous ne cliqueriez jamais si vous pouviez le voir. La défense n'est pas d'éviter les codes — c'est de lire l'aperçu, à chaque fois, et de traiter l'aperçu comme une décision, pas comme une formalité. La Federal Trade Commission américaine a mis en garde contre ce schéma dans une alerte aux consommateurs datée du 6 décembre 2023 : des escrocs recouvrent de vrais codes avec leurs propres autocollants — sur les parcmètres, par exemple — ou envoient des codes dans des messages inattendus, et un code scanné peut mener à un site contrefait qui semble réel, où tout ce qui est saisi peut être volé, ou à un logiciel malveillant. Le conseil de la FTC dans cette alerte est la même habitude que ce guide recommande : inspectez l'URL avant de l'ouvrir, cherchez les fautes d'orthographe ou une lettre échangée dans un nom familier, et ne scannez pas un code venu d'un message inattendu, surtout un message qui presse d'agir vite.

Transformez ce conseil en trois vérifications : le domaine, lettre par lettre, correspond à l'entreprise ou au panneau devant vous ; le code ne montre aucune falsification, comme un autocollant collé par-dessus un autre code ; et le contexte colle — vous attendiez ce code, à cet endroit, pour cet usage. Échouer à l'un seul de ces contrôles suffit pour s'arrêter. Un aperçu qui ne montre qu'un lien raccourci cache la destination finale tout aussi complètement que le code lui-même ; si vous ne reconnaissez pas l'expéditeur, c'est une raison de s'arrêter, pas de toucher pour découvrir.

Quand rien ne se passe : la chaîne de pannes, dans l'ordre

Parcourez cette chaîne dans l'ordre. Chaque étape prend quelques secondes, et l'ordre compte : on passe des correctifs les moins chers au test le plus concluant, pour s'arrêter dès qu'on trouve la panne au lieu de tout essayer au hasard. Les versions propres à chaque téléphone de ces étapes — les interrupteurs et raccourcis exacts sur iPhone, Pixel et Samsung — sont dans le guide de scan sur téléphone ; cette chaîne est la logique qui se trouve en dessous.

  1. Cadrage. Tout le code, marge calme comprise, est-il dans le cadre ? Reculez jusqu'à ce que les quatre coins soient visibles. Un code rogné par le bord du cadre est la cause la plus fréquente de silence.
  2. Mode. Utilisez la vue photo normale, pas le portrait ni la vidéo, ou utilisez le raccourci de lecteur dédié de votre téléphone.
  3. Réglage. Un interrupteur désactivé par une mise à jour ressemble exactement à un code cassé ; vérifiez d'abord les réglages de votre appareil photo.
  4. Mise au point et stabilité. Tenez stable et rapprochez-vous ou éloignez-vous lentement jusqu'à ce que le motif devienne net.
  5. Lumière. Ajoutez de la lumière dans une pièce sombre, supprimez les reflets dans une pièce lumineuse, et inclinez légèrement pour un code derrière une vitre.
  6. Objectif. L'objectif est-il propre ? Essuyez-le avec un chiffon doux. Un objectif maculé floute tous les codes pareillement, c'est pourquoi un objectif sale est si souvent pris pour une mauvaise impression.
  7. Intégrité du code. Les carrés d'angle sont-ils intacts, le contraste foncé-sur-clair, et le code exempt de dégâts, d'effacement, ou d'une courbure qui déforme ?
  8. Taille et distance. Le code est-il assez grand pour la distance ? Selon le guide des tailles d'impression, un code doit faire au moins un dixième de la distance de scan et au moins 2 × 2 cm à l'impression ; rapprochez-vous s'il est trop petit pour sa distance.
  9. Test du deuxième téléphone. Si un autre téléphone le lit, le problème vient de votre téléphone ; si aucun ne le lit, c'est le code.

Aller plus loin : flou, dégâts, et zone de silence

Trois pannes côté code méritent plus qu'une ligne dans une chaîne, parce que ce sont celles que les gens diagnostiquent le plus mal. Le flou d'abord. Un code peut être flou dès sa création — un export basse résolution étiré à la taille d'une affiche — ou à la capture — un téléphone en mouvement, une main tremblante, un code photographié dans une mauvaise lumière. Le flou de capture se corrige en tenant stable, en ajoutant de la lumière, et en reprenant ; le flou de création ne se corrige que par un meilleur original. Le traitement complet est dans pourquoi votre QR code est flou.

Les dégâts ensuite. Selon ISO/IEC 18004, quatre niveaux de correction d'erreur — L, M, Q, H — permettent à un lecteur de reconstruire un motif abîmé : environ 7 % des mots de code en L, 15 % en M, 25 % en Q, et 30 % en H. Un code éraflé se lit donc souvent encore, et un code avec un logo central se lit parce que la correction absorbe le milieu manquant. La limite, ce sont les carrés d'angle : abîmez-en un gravement et le lecteur ne peut plus orienter le motif du tout, si bonne que soit la correction d'erreur ailleurs. C'est pourquoi un coin déchiré échoue alors qu'un milieu éraflé réussit.

La zone de silence est la troisième, et la plus souvent sacrifiée au design. La marge blanche autour d'un code, d'au moins quatre modules de large de chaque côté selon la norme, est ce qui permet au lecteur de trouver les bords du code. Un design qui entasse le code avec du texte, des bordures ou des graphiques jusqu'à son bord n'est pas élégant ; il supprime la marge dont le lecteur a besoin pour trouver le motif. L'entassement, les couleurs pâles sur blanc, et un logo recouvrant un carré d'angle sont les choix de design qui transforment le plus souvent un code qui fonctionne en décoration ; voir pourquoi votre QR code ne scanne pas.

La comparaison honnête : scan intégré, lecteurs dans le navigateur, et applications de scan

Trois types de lecteurs se disputent le même travail, et le classement honnête est court. L'appareil photo intégré est le meilleur choix par défaut : déjà installé, déjà mis à jour avec le téléphone, et il lit les codes standards avec le même aperçu que n'importe quel autre lecteur, sans compte ni publicité entre vous et un menu. Un lecteur dans le navigateur est le meilleur repli : il n'exige aucune installation, il fonctionne sur un téléphone ou un ordinateur, et — quand il décode dans votre navigateur plutôt que de téléverser votre image — c'est l'outil qu'il faut pour un code dans une image enregistrée ou sur un écran d'ordinateur. Les applications de scan sont le choix par défaut le plus faible pour le scan de tous les jours : elles ajoutent une installation, un écran d'autorisation, et souvent des publicités ou un compte, en échange d'une capacité que votre téléphone possède déjà.

Les exceptions sont réelles mais étroites. Un téléphone assez vieux pour n'avoir aucun lecteur intégré a besoin d'une application ou d'un lecteur dans le navigateur. Une personne qui scanne des codes toute la journée pour le travail — inventaire, billets, étiquettes d'actifs — peut vouloir un historique, une lecture en masse, ou des exports, et un outil dédié peut se justifier là. Et un code dans une image enregistrée sur un téléphone dont les outils de galerie n'offrent pas de lecteur peut avoir besoin d'un décodeur dans le navigateur, ce qui est une meilleure réponse qu'une application pour un seul code. Pour tous les autres, le cas contre une application est concret : beaucoup d'applications de scan affichent des publicités, et certaines demandent des autorisations bien au-delà de l'appareil photo — contacts, position, ou un compte qui lie votre historique de scans à une identité. Un lecteur qui connaît chaque menu, billet et affiche vers lesquels vous l'avez pointé en sait beaucoup sur vos déplacements, et ce savoir est le produit vendu quand l'application elle-même ne coûte rien. L'appareil photo intégré lit le code et passe à autre chose ; il ne tient pas un journal de vos scans.

Quand le scan fonctionne mais pas la destination

Parfois tout ce qui précède se passe bien et le résultat déçoit quand même : un lien mort, une page déplacée, un formulaire qui n'existe plus, un billet déjà utilisé. Ce n'est pas un échec de scan ; c'est un échec de destination, et le correctif appartient à celui qui a émis le code. Un code statique contient sa destination directement, donc si la destination a disparu, le code n'a rien à dire. Si la destination a déménagé, seul l'émetteur peut pointer le code ailleurs — ce qui est exactement à quoi sert un code dynamique : il reste modifiable après impression, avec des statistiques de scan, sous un compte gratuit. Si c'est vous qui scannez et que le lien est mort, ne continuez pas à rescanner ; demandez un code tout neuf à l'expéditeur.

Tester vos propres codes avant que d'autres les scannent

Si vous imprimez des codes pour d'autres — un menu, une affiche, un billet, une carte de visite — testez-les comme votre public les scannera, pas comme vous les avez faits. Scannez l'épreuve imprimée, pas seulement la version écran, parce que l'impression change la taille, le contraste et la netteté. Scannez-la sur deux téléphones si possible, un iPhone et un Android, parce qu'un code qui se lit sur l'un et pas sur l'autre cache un vrai problème dans sa taille, son contraste, ou sa zone de silence. Scannez-la dans la lumière et depuis la distance où elle sera réellement utilisée. Trente secondes de test par code épargnent une réimpression, une file de clients perplexes, et une affiche qui est une décoration plutôt qu'une porte.

Bon à savoir

Ai-je besoin d’une app pour scanner des QR codes ?

Non. Les iPhones et pratiquement tous les téléphones Android scannent les QR codes avec l'appareil photo intégré. Les applications de scan tierces sont inutiles pour les codes standards, et ne sont une réponse raisonnable que pour un téléphone sans lecteur intégré ou pour un travail qui exige un historique ou une lecture en masse.

Que se passe-t-il après avoir scanné un QR code ?

Cela dépend de ce que le code contient : un lien ouvre une page web, un code Wi-Fi propose de rejoindre un réseau, un code contact propose d'enregistrer une personne, un code texte affiche des mots, et un code événement propose une entrée d'agenda. L'aperçu de votre téléphone vous dit lequel c'est avant que quoi que ce soit s'ouvre.

Comment scanner un QR code qui est sur l'écran de mon propre téléphone ?

Capturez le code ou enregistrez l'image, puis lisez-la depuis l'image : sur iPhone, ouvrez-la dans Photos et appuyez longuement sur le code ; sur Android, ouvrez-la dans Google Photos et touchez Lens. Un appareil photo ne peut pas viser son propre écran.

Pourquoi ma caméra ne scanne pas le QR code ?

Parcourez la chaîne de pannes dans l'ordre : tout le code dans le cadre, vue photo normale, scan activé, mise au point stable, bonne lumière sans reflets, objectif propre, carrés d'angle intacts et contraste, et taille adaptée à la distance. Terminez par un test sur un deuxième téléphone : si un autre téléphone le lit, le problème vient de votre téléphone ; si aucun ne le lit, c'est le code.

Quelle est la différence entre un QR code et un code-barres ?

Un QR code est le motif carré avec trois grands carrés d'angle, qui sont les repères du lecteur. Un motif sans ces carrés d'angle n'est pas un QR code, et aucun lecteur de QR ne le lira.

Mon QR code scanne, mais le lien ne fonctionne pas. Le code est-il cassé ?

Non. Le code a fait son travail ; la destination est le problème — la page a déménagé, le site est en panne, ou le formulaire n'existe plus. Contactez l'expéditeur pour un code tout neuf, ou, si c'est vous qui l'avez émis, utilisez un code dont vous contrôlez la destination ou un code dynamique qui reste modifiable.

Est-il sûr de scanner un QR code trouvé dans un lieu public ?

Lisez l'aperçu avant de toucher : le domaine devrait correspondre au panneau devant vous, le code ne devrait montrer aucune falsification comme un autocollant collé par-dessus un autre code, et vous auriez dû attendre ce code à cet endroit. Échouer à l'un seul de ces contrôles suffit pour s'arrêter.

Comment tester un QR code imprimé avant que d'autres le scannent ?

Scannez l'épreuve imprimée, pas seulement la version écran, sur deux téléphones si possible — un iPhone et un Android — dans la lumière et depuis la distance où elle sera réellement utilisée. Un code qui se lit dans toutes ces conditions a la bonne taille, le bon contraste, et la bonne zone de silence.
