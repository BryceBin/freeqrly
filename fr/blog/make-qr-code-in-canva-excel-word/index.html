QR codes dans Canva, Excel et Word

Aucune de ces apps n’a un bon générateur QR intégré. La voie rapide : générez le code dans FreeQrly, téléchargez un PNG, et déposez-le. Deux minutes, à chaque fois.

17 octobre 2026 · 4 min de lecture

Canva a une app QR enfouie dans sa place de marché. Excel n’en a pas. Word n’en a pas. Google Docs et Sheets non plus. Mais chacun d’eux permet d’insérer une image — et un QR code n’est qu’une image. Donc le processus fiable est le même partout : créez le code dans un vrai générateur, téléchargez un PNG, insérez-le.

Le processus (fonctionne dans les quatre)

  1. Créez le code. Dans le studio FreeQrly, choisissez le type (Site web pour un lien, WiFi pour un réseau, vCard pour un contact), remplissez-le, personnalisez-le si vous voulez.
  2. Téléchargez le PNG. Utilisez le téléchargement PNG à 1024 px ou plus. Le PNG garde les bords nets à l’impression et à l’écran ; le SVG est meilleur si votre app l’accepte (Word et Docs non, Canva oui).
  3. Insérez-le. Canva : Importations → Importer des fichiers. Excel : Insertion → Images. Word : Insertion → Images. Google Docs/Sheets : Insertion → Image → Importer depuis l’ordinateur.
  4. Testez-le. Pointez l’appareil photo de votre téléphone vers l’écran (ou une impression test). S’il se scanne du premier coup, c’est prêt.

Canva

L’app QR de Canva fonctionne, mais elle verrouille le style et le code vit dans Canva. Un PNG FreeQrly vous donne un contrôle total — logo, couleurs, cadre — et le même fichier fonctionne dans votre flyer, votre publication Instagram et votre export PDF. Importez une fois, réutilisez partout. Dimensionnez-le à au moins 2 × 2 cm sur le design final pour que les téléphones le lisent à bout de bras.

Excel

Excel n’a pas de fonction QR. La fonction IMAGE (Excel récent) peut afficher un QR code depuis une URL, mais elle demande que l’image soit hébergée quelque part et casse dans les anciennes versions et à l’impression. Un PNG collé est la voie fiable : il s’imprime, survit au partage de fichier, et fonctionne dans toutes les versions d’Excel. Placez-le dans un coin de cellule ou flottant sur la feuille — dans tous les cas, gardez la marge de silence autour bien dégagée.

Word

Word n’a pas d’outil QR non plus. Insertion → Images, puis réglez l’habillage du texte sur Carré ou Serré pour que le paragraphe coule autour. Pour les papiers à en-tête et les factures, épinglez le code à un endroit fixe (un en-tête, un pied de page ou une zone de texte) pour qu’il atterrisse au même endroit sur chaque page. Pour l’impression, exportez le document en PDF — le code reste net.

Google Docs et Sheets

Même schéma : Insertion → Image → Importer depuis l’ordinateur. Dans Docs, utilisez « Habillage du texte » pour que le code se place à côté du paragraphe. Dans Sheets, faites-le flotter sur une plage de cellules en coin. Un conseil en plus : Docs compresse les grandes images à l’export, alors partez d’un PNG de 1024 px et gardez le code à une taille raisonnable — un petit code sur une grande page est la raison la plus courante des échecs de scan.

Trois erreurs qui cassent les scans

  • Trop petit. Sous 2 × 2 cm à l’impression, ou sous ~150 px à l’écran, les téléphones peinent. En cas de doute, allez plus grand.
  • Faible contraste. Les couleurs fantaisie sont belles et échouent silencieusement. Code sombre sur fond clair, toujours. Voir le guide des tailles d’impression pour la règle de distance.
  • Étirement. Tirer un coin déforme la grille. Redimensionnez proportionnellement (maintenez Maj dans la plupart des apps) pour que les carrés restent carrés.

Bon à savoir

Canva a-t-il un générateur de QR code intégré ?

Canva a une app QR dans sa place de marché, mais elle verrouille le style et garde le code dans Canva. Un PNG FreeQrly vous donne un contrôle total et fonctionne partout.

Excel peut-il générer des QR codes nativement ?

Non. Excel n’a pas de fonction QR. Collez un PNG — il s’imprime, survit au partage de fichier, et fonctionne dans toutes les versions.

PNG ou SVG pour Word et Docs ?

PNG. Word et Google Docs gèrent les images PNG nativement ; le support SVG est inconstant. Exportez à 1024 px ou plus pour l’impression.

Le code restera-t-il net quand j’exporte en PDF ?

Oui, si vous partez d’un PNG de 1024 px et ne le réduisez pas minuscule. Testez le scan du PDF exporté avant de l’envoyer.
