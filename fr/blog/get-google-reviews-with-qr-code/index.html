Obtenez plus d’avis Google avec un QR code

Le meilleur moment pour demander un avis, c’est quand un client satisfait se tient devant vous. Un QR code fait de ce moment un seul scan.

19 octobre 2026 · Dernière mise à jour : 3 novembre 2026 · 15 min de lecture

Les avis Google décident qui est choisi — et les entreprises avec le plus d'avis ne les ont pas obtenus par chance. Elles ont demandé, au bon moment, sans aucune friction. Un QR code pointant droit vers votre formulaire d'avis Google transforme « laissez-nous un avis, s'il vous plaît » en un seul scan. Obtenez le lien que Google lui-même émet, transformez-le en code, mettez-le là où un client satisfait se tient déjà, et demandez une fois, simplement. Tout le reste de ce guide est du détail autour de cette séquence.

La raison pour laquelle un code fonctionne là où un e-mail de suivi souvent non, c'est le timing. Une demande qui arrive des jours plus tard rivalise avec tout le reste d'une boîte de réception. Un code sur la table, le reçu, ou la carte remise à la fin d'une visite rencontre le client pendant que l'expérience est encore fraîche. Le code ne persuade personne. Il supprime les étapes entre « j'évaluerais bien cet endroit » et le formulaire d'avis : pas de recherche du nom de l'entreprise, pas de choix de la bonne fiche parmi les sosies, pas de chasse au bouton d'avis.

Là où chaque emplacement gagne son scan

L'emplacement est tout le jeu, et les différents emplacements attrapent les clients à des moments différents. Utilisez ce tableau pour choisir les emplacements de votre entreprise plutôt que d'imprimer le même panneau partout.

Deux remarques sur ce tableau. Un code de carte de visite est facile à imprimer trop petit : un code entassé dans un coin est ignoré, tandis qu'un code de 5 cm sur un chevalet de table est scanné. Et une signature d'e-mail est le seul emplacement où le code lui-même est le mauvais outil — le lecteur est déjà sur un écran, donnez-lui donc le lien d'avis comme un texte sur lequel il peut toucher. Le lien va là où les gens lisent, le code va là où les gens se tiennent.

Étape 1 — récupérez votre lien d’avis Google

Vous avez besoin du lien direct vers votre formulaire d'avis, pas seulement de votre fiche d'entreprise. Google émet ce lien depuis votre Business Profile, et sa page d'aide actuelle donne ces étapes :

  1. Sur un ordinateur, allez sur votre Business Profile en étant connecté au compte Google qui le gère.
  2. Sélectionnez Lire les avis, puis Obtenir plus d'avis.
  3. Sélectionnez Copier pour copier le lien d'avis. Le lien ressemble à g.page/r/…/review — un lien court qui ouvre directement votre formulaire d'avis.

Deux détails comptent ici. D'abord, le même panneau contient aussi un QR code que vous pouvez enregistrer en cliquant droit dessus et en choisissant « Enregistrer l'image sous » — mais Google note que les QR codes d'avis ne peuvent être générés que sur un navigateur d'ordinateur, pas sur un appareil mobile, faites donc cette étape à un bureau. Ensuite, le code propre de Google est simple : pas de marque, pas de cadre, pas de ligne d'instruction. Pour un panneau de comptoir ou un chevalet de table, générer un code stylisé depuis le même lien — logo, cadre, et une ligne disant aux gens ce qui se passe quand ils scannent — vaut généralement la minute supplémentaire. La destination est identique dans les deux cas.

Testez le lien avant que quoi que ce soit parte à l'impression. Ouvrez-le dans une fenêtre de navigation privée et confirmez qu'il atterrit sur le formulaire d'avis de votre entreprise, pas sur une fiche générale ou une entreprise au nom similaire. Un code imprimé avec la mauvaise destination apprend aux clients que vos codes ne mènent nulle part d'utile.

Étape 2 — transformez-le en QR code

Collez le lien dans un générateur de QR code d'avis Google — cela prend quelques secondes, c'est gratuit, et un code statique n'expire jamais. Imprimez-le à une taille correcte, gardez une encre foncée sur fond clair, et laissez une marge calme nette autour du code. Le guide des tailles d'impression couvre les tailles en détail ; la version courte est qu'un code pour lequel les gens doivent se pencher pour lire est un code que les gens ne scanneront pas.

Choisissez maintenant entre statique et dynamique, parce que le choix est plus difficile à inverser une fois que des centaines de cartes sont imprimées :

  • Le statique est le défaut pour la plupart des commerces. Le lien d'avis vit dans le motif lui-même, le code n'exige pas de compte, et il continue de fonctionner tant que votre Business Profile existe. Un seul code statique, bien imprimé et bien placé, est tout ce dont la plupart des entreprises à un seul site ont besoin.
  • Le dynamique mérite sa place dans deux situations. D'abord, quand la destination peut changer : si Google change un jour votre lien d'avis, ou si vous déplacez la demande vers une autre page, un code dynamique permet de changer la destination depuis votre tableau de bord sans réimprimer. Ensuite, quand vous voulez comparer les emplacements : donnez au comptoir, au reçu et au sac de livraison chacun son propre code dynamique, et les statistiques de scan montrent quel emplacement est réellement scanné. Les codes dynamiques sont gratuits pour commencer avec une connexion, modifiables après impression, et accompagnés de statistiques de scan, avec 20 codes sur le compte gratuit et des scans illimités pendant la promotion à durée limitée. Le compromis est honnête : un code dynamique pointe vers un lien court sur un serveur, il dépend donc de la disponibilité de ce service, tandis qu'un code statique ne dépend de rien d'autre que du motif imprimé et de la destination.

Si vous gérez plusieurs lieux, ne partagez pas un seul code entre eux. Chaque lieu a son propre Business Profile et son propre lien d'avis, créez donc un code par lieu, nommez les fichiers par le nom du lieu, et vérifiez chacun avant l'impression.

Étape 3 — placez-le là où le moment se joue

Le code doit être devant un client satisfait avant qu'il parte. Parcourez votre propre parcours client et marquez chaque point où quelqu'un est heureux, sans hâte, et son téléphone en main — ce sont vos emplacements, et partout ailleurs c'est de la décoration.

Restaurants et cafés

Les chevalets de table et le reçu sont les deux emplacements qui comptent. Le chevalet de table attrape les gens en plein repas, quand ils sont détendus et que le téléphone est déjà sur la table. Le reçu les attrape à la fin, quand toute la visite est fraîche. Un code sur la porte d'entrée, en revanche, est scanné par les gens qui arrivent — le seul moment où ils n'ont encore rien à évaluer. Adaptez la formulation au moment : « Le repas vous a plu ? Un seul scan. »

Commerce de détail et salons

Le comptoir de caisse est l'endroit naturel — la satisfaction culmine à l'achat, et le client se tient déjà là avec son téléphone en main pendant que le paiement par carte passe. Mettez le code à hauteur des yeux, pas à plat sur le comptoir où les sacs le recouvrent, et pas derrière la caisse où seul le personnel peut le voir. Un petit panneau sur pied à côté du lecteur de carte bat une affiche sur le mur du fond.

Services : plombiers, tuteurs, cliniques, salons

Pour un travail effectué au domicile d'un client ou en rendez-vous, le moment de la remise est tout. Une carte remise à la fin de la visite — ou un autocollant sur la facture — rentre à la maison et reste sur le plan de travail de la cuisine comme un rappel. La demande parlée compte autant que la carte : « Si vous êtes satisfait du travail, cette carte vous mène droit à nos avis Google. » Sans cette phrase, la carte n'est qu'un bout de papier de plus.

Livraison et à emporter

Un autocollant sur le sac ou la boîte met le code devant le client au moment exact où il ouvre la nourriture. La nourriture est le rappel, et le code est déjà entre leurs mains. Gardez la formulation à une ligne : un sac de livraison a un espace limité et une courte fenêtre d'attention.

Signatures d'e-mail et messages de suivi

Pour les entreprises qui envoient déjà des e-mails aux clients — factures, confirmations de réservation, remerciements — la signature est un emplacement discret et permanent. Ajoutez le lien d'avis comme une courte ligne de texte plutôt qu'une image de code, puisque le lecteur est déjà sur un écran. Il en va de même pour un message de suivi après la visite : un court message, un lien, envoyé le jour même tant que la visite est encore fraîche.

Quoi écrire à côté

Un code nu obtient moins de scans qu'un code avec une raison. Restez court et précis :

  • « Votre visite vous a plu ? Scannez pour nous évaluer sur Google. »
  • « Le repas vous a plu ? Un seul scan pour nous évaluer. »
  • « Satisfait du travail ? Ce code vous mène à nos avis Google. »

Demander des avis Google par leur nom compte — les clients se rabattent par défaut sur la plateforme la plus facile. Une formulation qui suggère une note en étoiles (« Laissez-nous cinq étoiles ») passe de la demande à l'orientation, et la politique de Google traite l'orientation comme une violation, comme la section conformité ci-dessous l'explique.

Les règles de conformité, vérifiées par rapport aux propres pages de Google

Cette section n'énonce que les points de politique qui figurent sur les pages d'assistance officielles de Google, parce que la politique des avis est exactement le genre de sujet où les résumés de seconde main dérivent. La page contenu interdit et restreint de Google et sa page conseils pour obtenir plus d'avis s'accordent sur ce qui suit :

  • Les avis doivent refléter une expérience réelle, et être authentiques et impartiaux. C'est le fondement dont tout le reste dépend. Un avis de quelqu'un qui n'est jamais venu, ou un avis écrit sous la dictée de l'entreprise, échoue à ce test quelle que soit la façon dont il a été obtenu.
  • N'offrez jamais d'incitations pour un avis. Google n'autorise pas les commerçants à offrir un paiement, des réductions, des biens gratuits ou des services gratuits en échange de la publication d'un avis, de la révision d'un avis, ou du retrait d'un avis négatif. Les avis incités ou biaisés sont retirés de Maps. Cela couvre les cas évidents — une réduction pour un avis, un dessert gratuit pour un avis — et les moins évidents, comme une participation à un tirage au sort pour les évaluateurs ou un avantage offert pour faire retirer un avis négatif.
  • Ne découragez pas les avis négatifs, et ne demandez pas seulement aux clients que vous attendez heureux. La politique de Google classe les deux comme manipulation de notes : décourager ou interdire les avis négatifs, et solliciter sélectivement des avis positifs. La version conforme est simple et aussi meilleure commercialement : demandez à chaque client, de la même façon, au même point du parcours. Un profil d'avis construit uniquement à partir de clients heureux triés sur le volet est à la fois un risque de politique et un problème de crédibilité — les lecteurs le voient.
  • N'exigez ni ne pressez personne d'évaluer pendant qu'ils sont sur place, et ne dictez pas le contenu. La politique de Google dit que les commerçants ne devraient ni exiger ni presser les utilisateurs de laisser des notes ou d'écrire des avis pendant qu'ils sont sur place, et ne devraient pas demander qu'un contenu précis soit inclus — y compris les quotas du personnel ou les avis mentionnant un membre du personnel en particulier. La ligne pratique : un code visible plus une demande parlée et volontaire est conforme ; rester planté au-dessus d'un client jusqu'à ce qu'il publie ne l'est pas.
  • Demander elle-même est autorisé. Google autorise expressément les commerçants à solliciter ou encourager un contenu qui représente bien une expérience réelle, à condition qu'aucune incitation ne soit offerte et qu'aucune tentative ne soit faite pour influencer la note ou le contenu. Le QR code est simplement la forme à la friction la plus faible de cette demande autorisée.

Au-delà des propres règles de Google, les entreprises américaines devraient savoir que la règle sur les avis de consommateurs de la Federal Trade Commission, en vigueur depuis le 21 octobre 2024, interdit de fournir une compensation ou d'autres incitations conditionnées à un avis exprimant un sentiment particulier, et autorise des sanctions civiles pour les violations sciemment commises. Notez la différence de portée : la règle de la FTC vise les incitations liées à un sentiment, tandis que la formulation de Google interdit les incitations pour la publication d'un avis tout court.

La conformité ne consiste pas seulement à éviter le retrait. Une entreprise qui répond à ses avis en obtient davantage, parce que les évaluateurs voient qu'ils sont lus. La page de conseils de Google conseille de garder les réponses professionnelles, polies, courtes et spécifiques plutôt que d'envoyer le même remerciement à tout le monde, et de déplacer une plainte complexe vers un canal privé plutôt que de se disputer en public. Répondez aussi aux avis négatifs, calmement et sans partager les informations privées de l'évaluateur.

La comparaison honnête : ce qu'un code d'avis ne peut pas faire

Un code d'avis est un réducteur de friction, pas une machine à réputation, et il vaut la peine d'énoncer ses limites clairement avant d'imprimer une centaine de cartes :

  • Il ne peut pas créer la satisfaction. Un code devant un client mécontent produit, au mieux, rien, et au pire un avis négatif honnête. Corrigez d'abord l'expérience.
  • Il ne peut pas remplacer la demande. Le code est passif. Dans chaque emplacement ci-dessus, il fonctionne le mieux jumelé à une phrase dite au bon moment, puis au silence.
  • Il ne peut pas viser seulement les clients heureux. Tout système qui filtre — un code montré seulement après un bon résultat, une demande envoyée seulement aux clients qui ont souri — enfreint la règle de Google contre la sollicitation sélective. Demandez à tout le monde et répondez à tout.
  • Il ne peut pas corriger un lien cassé tout seul. Un code statique contient le lien avec lequel il a été imprimé. Si votre lien d'avis change, un code statique continue de pointer vers l'ancienne destination. C'est le seul cas où un code dynamique se paie tout seul : changez la destination une fois dans le tableau de bord et chaque exemplaire imprimé suit.

Quelques conseils honnêtes

  • Demandez, ne suppliez pas. Un code visible plus un « nous adorerions un avis » dit à voix haute bat cinq panneaux.
  • Commencez par un emplacement, pas cinq. Mettez le code là où votre moment le plus heureux se produit déjà et faites-le tourner quelques semaines avant de l'imprimer partout.
  • Répondez aux avis. Une entreprise qui répond aux avis en obtient davantage ; les évaluateurs voient que vous les lisez. Gardez les réponses courtes, spécifiques et humaines.
  • Suivez ce qui marche. Si vous voulez savoir quel emplacement génère des scans, utilisez un code dynamique pour un lieu et comparez.

Bon à savoir

Comment créer un QR code pour les avis Google ?

Copiez votre lien d'avis Google depuis votre Business Profile (Lire les avis, puis Obtenir plus d'avis, puis Copier), collez-le dans un générateur de QR code gratuit, et imprimez le code. Les codes statiques sont gratuits et n'expirent jamais. Notez que Google ne génère son propre QR code d'avis que sur un navigateur d'ordinateur, pas sur un appareil mobile.

Où placer mon QR code d’avis Google ?

Partout où un client satisfait se tient avant de partir : tables et reçus de restaurant, comptoirs de caisse de commerce, factures de services, ou emballages de livraison. Pour l'e-mail, utilisez le lien d'avis comme une ligne de texte cliquable dans votre signature au lieu d'une image de code, puisque le lecteur est déjà sur un écran.

Les QR codes d’avis Google expirent-ils ?

Un QR code statique n'expire jamais — il contient directement votre lien d'avis. Tant que votre Business Profile Google existe, le code continue de fonctionner. Un code dynamique continue aussi de fonctionner, tant que le service derrière son lien court reste en ligne et que vous ne supprimez pas le code.

Faut-il offrir une réduction en échange d’un avis Google ?

Non. Google interdit d'offrir un paiement, des réductions, des biens gratuits ou des services gratuits en échange de la publication, de la révision ou du retrait d'un avis, et les avis incités ou biaisés sont retirés de Maps. Aux États-Unis, la règle FTC sur les avis de consommateurs interdit aussi les incitations conditionnées à un avis exprimant un sentiment particulier. Demandez plutôt au bon moment — c'est à cela que sert le QR code.

Dois-je utiliser un code statique ou dynamique pour les avis Google ?

Statique pour la plupart des entreprises à un seul site : gratuit, pas d'inscription, n'expire jamais. Dynamique quand la destination peut changer ou quand vous voulez comparer les emplacements — donnez au comptoir, au reçu et au sac de livraison chacun son propre code dynamique et comparez leurs statistiques de scan. Les codes dynamiques sont gratuits avec une connexion, modifiables après impression, et accompagnés de statistiques de scan.

Puis-je demander à des clients un avis alors qu'ils sont encore dans ma boutique ?

Oui, avec une seule demande parlée et volontaire — mais n'exigez ni ne pressez personne d'évaluer sur place, et ne leur remettez pas de formulation à copier. La politique de Google interdit d'exiger ou de presser les utilisateurs de laisser des notes ou des avis sur place et interdit de demander un contenu précis, y compris les quotas d'avis du personnel.

Et si mon lien d'avis Google change après avoir imprimé des cartes ?

Un code statique continue de pointer vers l'ancien lien, vous devriez donc réimprimer. Un code dynamique peut être redirigé dans le tableau de bord sans réimpression : changez la destination une fois et chaque exemplaire imprimé suit. Si vous imprimez des codes statiques, notez quel lien chaque lot porte et retestez le lien après tout changement de votre Business Profile.
