QR code vs code-barres

Les codes-barres identifient les produits en caisse. Les QR codes portent des liens, menus, mots de passe WiFi, cartes de contact. Même idée, des rôles très différents.

17 octobre 2026 · 4 min de lecture

Ils se ressemblent, mais un code-barres et un QR code résolvent des problèmes différents. Un code-barres est une rangée de lignes verticales qui encode un court numéro — généralement un ID produit. Un QR code est une grille carrée qui encode du texte, des liens ou des cartes de contact entières. Si vous ne retenez qu’une phrase : les codes-barres pointent vers une entrée de base de données ; les QR codes portent le contenu lui-même.

Les différences qui comptent

Code-barres (1D)QR code (2D)
Ce qu’il contientUn court numéro (généralement 8 à 13 chiffres)Texte, URL, détails WiFi, contacts — jusqu’à ~4 000 caractères
Comment il se scanneLes scanners laser le lisent dans un sens ; il faut l’alignerN’importe quel appareil photo de téléphone, sous n’importe quel angle, en une fraction de seconde
Tolérance aux dommagesFaible — une ligne rayée peut le rendre illisibleÉlevée — la correction d’erreur récupère jusqu’à 30 % d’un code abîmé
Besoin d’une base de données ?Oui — le numéro est inutile sans la rechercheNon — le contenu vit dans le motif
Usage typiqueCaisse de magasin, inventaire, livres de bibliothèqueMenus, billets, paiements, WiFi, marketing, cartes de contact

Quand un code-barres reste le bon choix

Caisse de magasin, inventaire d’entrepôt, et tout ce qui est scanné par un scanner laser dédié à courte distance. Les codes-barres coûtent peu à imprimer, sont rapides sur matériel laser, et tout le commerce parle déjà UPC/EAN. Si votre processus est « scanner un produit, retrouver sa fiche », un code-barres est l’outil qu’il faut.

Quand un QR code gagne

Tout ce qu’une personne scanne avec un téléphone : menus, billets, liens de paiement, codes de connexion WiFi, cartes de contact, pages produit, formulaires de retour. Les QR codes contiennent bien plus, survivent aux dommages, et n’ont besoin d’aucun matériel spécial. Ils peuvent aussi porter un lien produit — un QR code sur un emballage qui ouvre le manuel, la page de garantie ou la page de réapprovisionnement fait mieux le travail d’un code-barres.

Un QR code peut-il remplacer un code-barres sur les produits ?

Pour les usages grand public, oui — et le commerce s’y dirige avec GS1 Digital Link, qui met sur l’emballage un QR code portant la même identité produit qu’un code-barres, plus un lien vers du contenu web. Pour les caisses équipées de scanners laser uniquement, les codes-barres restent pour l’instant : les scanners laser ne peuvent pas lire les codes 2D. La règle pratique : code-barres là où règnent les scanners laser, QR code partout où un téléphone est en jeu.

Bon à savoir

Un QR code peut-il contenir le même numéro qu’un code-barres ?

Oui — un QR code peut encoder le numéro de n’importe quel code-barres (UPC, EAN, Code 128) en texte brut. Mais un téléphone qui le scanne affichera le numéro, sans le rechercher, sauf si le code pointe vers une page qui fait la recherche.

Pourquoi les codes-barres existent-ils encore si les QR codes contiennent plus ?

Matériel hérité. Des millions de caisses et d’entrepôts utilisent des scanners laser qui ne lisent que les codes-barres 1D. Tant que ce matériel ne sera pas remplacé, les codes-barres restent pour la caisse — les QR codes prennent tout le reste.

Lequel est le meilleur pour une étiquette produit ?

Pour la caisse : un code-barres (ou les deux). Pour les clients : un QR code menant au manuel, à la garantie ou à la page de réapprovisionnement. Beaucoup de marques impriment maintenant les deux sur le même emballage.

Les QR codes expirent-ils alors que les codes-barres non ?

Aucun n’expire de lui-même. Un QR code statique fonctionne tant que sa destination existe — comme le numéro d’un code-barres qui reste valide. Seuls les codes dynamiques peuvent cesser de fonctionner, si le service derrière eux s’arrête.
