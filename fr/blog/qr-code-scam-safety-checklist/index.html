Repérez un faux QR code avant de le scanner

Un QR code est un lien que vous ne pouvez pas lire avec vos yeux, ce qui explique exactement pourquoi les arnaqueurs l'apprécient. Cette checklist vous offre deux pauses qui stoppent la plupart des arnaques par QR : une inspection rapide avant de scanner, et une lecture attentive de l'aperçu après le scan.

4 novembre 2026 · 14 min de lecture

Un QR code est un lien que vous ne pouvez pas lire avec vos yeux. C'est ce qui le rend pratique, et c'est aussi ce qui le rend utile aux arnaqueurs. Un code sur un horodateur, une affiche, un colis ou dans un message peut avoir l'air ordinaire tout en pointant vers une fausse page de connexion, une page de paiement que vous n'aviez jamais l'intention de visiter, ou un téléchargement que vous n'avez jamais demandé. La plupart des arnaques par QR échouent si vous ralentissez à deux moments : avant de scanner, et après que votre téléphone vous a montré la destination.

Comment fonctionne généralement une arnaque par QR code

La plupart des arnaques par QR, souvent appelées quishing — hameçonnage par QR code — suivent le même schéma. Un arnaqueur cache un lien nuisible dans un code, puis vous donne une raison de le scanner dans la précipitation. La Federal Trade Commission (FTC) a averti dans son alerte aux consommateurs de décembre 2023 que les arnaqueurs recouvrent les vrais codes des horodateurs avec leurs propres codes, et envoient des codes par SMS ou e-mail avec des histoires inventées : un colis qui n'a pas pu être livré, un problème de compte, ou une activité suspecte qui exigerait soi-disant un changement de mot de passe. Chaque histoire est conçue pour créer l'urgence, afin que vous scanniez le code et ouvriez le lien sans réfléchir.

Une fois le scan fait, le piège est généralement la page derrière le code plutôt que le code lui-même. La FTC décrit un site usurpé qui a l'air réel mais ne l'est pas : si vous vous y connectez, les arnaqueurs peuvent voler tout ce que vous saisissez, et un mauvais code peut aussi tenter d'installer un logiciel malveillant. ESET, écrivant sur le quishing, souligne un point connexe : parce que la destination est encodée dans un motif visuel plutôt qu'écrite en texte lisible, elle reste cachée jusqu'au scan, et certains filtres d'e-mail traditionnels ne peuvent pas l'inspecter comme ils inspectent un lien visible. Rien de tout cela ne signifie que les QR codes sont dangereux en eux-mêmes. Cela signifie que la vérification doit avoir lieu après le scan, dans l'aperçu que votre téléphone vous montre, avant d'aller plus loin.

Avant de scanner : l'inspection en cinq secondes

L'appareil photo de votre téléphone ne peut pas vous dire si un code imprimé a été trafiqué. Vos yeux peuvent aider. Passez en revue ces vérifications avant de pointer votre appareil photo vers quoi que ce soit.

1. Cherchez un autocollant placé sur le vrai code

Touchez et regardez les bords. Un autocollant posé sur un panneau imprimé présente souvent une bordure visible, un bord légèrement surélevé, un brillant ou une texture de papier différente, ou des coins qui se décollent. Si le code se trouve par-dessus un autre code, un logo ou un texte imprimé, considérez-le comme suspect. C'est l'astuce classique de l'horodateur décrite par la FTC : le vrai code de paiement est recouvert, et le paiement va à l'arnaqueur. Si quoi que ce soit semble superposé, ne le scannez pas. Payez plutôt via l'application officielle, l'horodateur lui-même, ou le site web du lieu que vous connaissez déjà.

2. Vérifiez une impression abîmée, incohérente ou bâclée

Comparez le code avec le reste du panneau. Un code authentique imprimé dans un panneau correspond généralement à son environnement : même qualité d'impression, même alignement, même style. Méfiez-vous si le code est flou alors que le reste du panneau est net, s'il est de travers ou d'une taille étrange pour son cadre, ou s'il ressemble à une impression domestique collée sur un affichage professionnel. Un dégât seul ne prouve pas une arnaque — une affiche usée par le temps peut simplement être vieille — mais un dégât combiné à une demande de paiement ou de connexion inattendue doit vous arrêter. Notre guide de dépannage explique comment distinguer un problème d'impression d'un problème de falsification.

3. Demandez-vous si le code a sa place ici

Un code à un endroit inattendu est un signal d'alarme à lui seul. Un code collé sur un lampadaire, un distributeur de billets ou un prospectus quelconque, sans nom d'entreprise, sans contexte et sans explication de sa destination, n'a pas gagné votre confiance. Il en va de même pour un code dans un colis inattendu ou dans un message d'un expéditeur que vous ne reconnaissez pas. Les entreprises légitimes vous disent à quoi sert le code — voir le menu, payer le stationnement, rejoindre le Wi-Fi — et où il doit vous mener. Si ni l'un ni l'autre n'est clair, laissez-le tranquille.

4. Lisez le message autour du code, pas seulement le code

L'urgence est l'outil préféré de l'arnaqueur. Méfiez-vous des messages qui exigent une action immédiate : un compte sera fermé, un colis sera retourné, ou un paiement est en retard. Méfiez-vous des menaces, des prix que vous n'avez pas gagnés, et des demandes qui ne correspondent à rien de ce que vous avez réellement commandé. Une entreprise authentique vous donnera presque toujours un autre moyen de vérifier — sa propre application, son site web officiel, ou un numéro de téléphone en qui vous avez déjà confiance — et n'insistera pas pour que le scan soit la seule option.

5. Décidez comment vous scannerez avant de scanner

Utilisez l'appareil photo intégré de votre téléphone ou un lecteur en qui vous avez confiance, et prévoyez de lire l'aperçu. Votre appareil photo intégré affiche généralement l'adresse de destination avant de l'ouvrir, ce qui est exactement la pause sur laquelle repose cette checklist. Évitez d'installer une nouvelle application de scan au moment où vous avez besoin de scanner, surtout une promue par le panneau ou le message même qui porte le code. Notre guide pour scanner un QR code détaille l'étape de l'aperçu sur les téléphones courants.

Après le scan : lisez l'aperçu avant de toucher

Scanner n'est pas l'étape dangereuse. Aller plus loin sans lire l'est. Quand votre appareil photo reconnaît un code, il affiche un aperçu — généralement l'adresse, parfois une courte description. Cet aperçu est votre fenêtre d'inspection. Utilisez-la à chaque fois.

Vérifiez l'orthographe de l'adresse, lettre par lettre

Recherchez les fautes d'orthographe, les lettres interverties et les mots supplémentaires. Le conseil central de la FTC pour un code inattendu est d'inspecter l'URL avant de l'ouvrir, et si elle ressemble à une adresse familière, de s'assurer qu'elle n'est pas usurpée. Une seule lettre intervertie, un trait d'union là où il ne devrait pas y en avoir, un mot supplémentaire comme secure ou verify, ou un nom de marque connu accolé à un domaine inconnu peuvent tous signaler un faux. Lisez le domaine — la partie de l'adresse qui identifie le site — plutôt que le nom de marque dans le titre ou le logo de la page, car les logos sont faciles à copier et les domaines plus difficiles à imiter de façon convaincante. Si vous attendiez une entreprise précise et que le domaine n'est pas celui de cette entreprise, fermez l'aperçu.

Méfiez-vous des destinations cachées

Un lien raccourci cache la vraie destination, considérez-le donc comme non prouvé. Si l'aperçu affiche un service de lien court ou une longue chaîne de caractères aléatoires au lieu d'un domaine reconnaissable, vous ne pouvez pas savoir où il mène vraiment avant de l'ouvrir — ce qui est précisément le risque. Quand la destination est cachée, choisissez la voie connue : tapez vous-même l'adresse de l'entreprise, ou ouvrez son application.

N'entrez jamais de mots de passe ni de coordonnées de paiement sur une page inattendue

C'est la règle qui stoppe net la plupart des arnaques par QR. Si vous êtes arrivé sur une page de connexion ou de paiement uniquement parce que vous avez scanné un code — surtout un code venu d'un message que vous n'attendiez pas — n'y saisissez pas votre mot de passe, votre numéro de carte, vos coordonnées bancaires ou votre code de vérification, aussi convaincante que la page paraisse. Les pages usurpées sont conçues pour ressembler trait pour trait aux vraies. Fermez plutôt la page et rendez-vous directement au service : ouvrez son application, tapez vous-même son adresse, ou appelez un numéro en qui vous avez déjà confiance. Si le message affirmait qu'il y avait un problème avec votre compte, vérifier via l'application officielle vous dira si ce problème est réel, sans remettre vos identifiants à qui que ce soit.

Méfiez-vous des astuces d'urgence sur la page elle-même

Comptes à rebours, avertissements et fenêtres surgissantes sont des tactiques de pression, pas des preuves. Une page qui dit que votre compte sera verrouillé dans quelques minutes ou que vous devez agir avant la fin d'un minuteur essaie de vous faire passer outre les vérifications ci-dessus. Fermez l'onglet. Les vrais problèmes de compte ne disparaissent pas si vous prenez cinq minutes pour les vérifier via un canal séparé.

Ne téléchargez pas de fichiers et ne rejoignez pas de réseaux depuis un code scanné sans raison

Un QR code peut pointer vers plus qu'un site web. Il peut déclencher un téléchargement, ou proposer de vous connecter à un réseau Wi-Fi. N'installez pas une application et n'acceptez pas un téléchargement simplement parce qu'un code scanné vous l'a demandé, et soyez particulièrement prudent avec les applications proposées en dehors de la boutique officielle de votre téléphone. Ne rejoignez pas un réseau Wi-Fi inconnu proposé par un code sur une affiche sans confirmer auprès du lieu que le réseau est bien le sien.

Si vous avez déjà scanné un mauvais code

Scanner un mauvais code ne signifie pas automatiquement que vous avez subi un préjudice, et même saisir des détails sur une mauvaise page est récupérable si vous agissez rapidement. Suivez ces étapes dans l'ordre, et ne laissez pas la gêne vous ralentir — les arnaqueurs comptent sur le silence des gens.

D'abord, arrêtez-vous et déconnectez-vous. Fermez l'onglet ou l'application, ne saisissez rien de plus, et ne suivez aucune autre instruction de la page, comme appeler un numéro qu'elle affiche ou installer quoi que ce soit qu'elle propose. Si un téléchargement a commencé, ne l'ouvrez pas.

Ensuite, changez tout mot de passe saisi, depuis un appareil et une voie en qui vous avez confiance. Ouvrez l'application du vrai service ou tapez vous-même son adresse, changez-y le mot de passe, et activez l'authentification multifacteur si elle ne l'est pas déjà. Si vous avez utilisé le même mot de passe ailleurs, changez-le là aussi, en commençant par votre compte e-mail, puisque l'e-mail est souvent la clé pour réinitialiser tout le reste.

Troisièmement, contactez rapidement votre banque ou votre fournisseur de carte si vous avez saisi des coordonnées de paiement. Dites-leur ce qui s'est passé, demandez-leur de surveiller les transactions non autorisées, et renseignez-vous sur le blocage ou le remplacement de la carte. Vérifiez vos relevés au cours des jours suivants pour des transactions que vous ne reconnaissez pas.

Quatrièmement, signalez-le. Aux États-Unis, signalez l'arnaque à la FTC sur ReportFraud.ftc.gov, avec autant de détails que possible : où vous avez vu le code, ce que disait le message, et l'adresse vers laquelle il menait. Signaler aide les autorités à suivre les tendances, comme une série de codes trafiqués dans une zone. Si vous êtes ailleurs, signalez-le à votre service national de protection des consommateurs ou de signalement des fraudes, et à l'entreprise usurpée, via ses canaux officiels.

Enfin, vérifiez votre appareil. Assurez-vous que le système d'exploitation de votre téléphone est à jour et supprimez toute application ou fichier que le code vous a amené à installer. Si quoi que ce soit se comporte bizarrement ensuite, demandez de l'aide au support officiel du fabricant du téléphone plutôt qu'à un numéro affiché par la page suspecte.

Pour les entreprises : protégez vos propres clients contre les faux codes

Si votre entreprise imprime des QR codes, la sécurité de vos clients est en partie votre problème de design. Un client qui ne peut pas distinguer votre vrai code d'un autocollant posé dessus est un client qu'un arnaqueur peut rediriger, et le dommage retombe sur votre réputation même si vous n'avez rien fait de mal. Quelques habitudes pratiques rendent la falsification plus difficile à réaliser et plus facile à repérer.

Utilisez des codes de marque reconnaissables. Un code qui porte votre logo et vos couleurs, et qui mène à votre propre domaine, est plus difficile à imiter de façon convaincante qu'un code ordinaire pointant vers un lien court générique, et il donne aux clients attentifs quelque chose à reconnaître dans l'aperçu. Placez le code dans le design imprimé — sous verre, derrière un comptoir, ou imprimé directement sur l'emballage ou un panneau permanent — plutôt qu'en autocollant libre que n'importe qui peut décoller ou recouvrir.

Dites aux clients où vit le vrai code. Indiquez clairement, sur le panneau lui-même et sur votre site web, où les clients trouveront votre code authentique et où il doit les mener. Par exemple : notre code de paiement est imprimé sur l'horodateur lui-même, pas sur un autocollant séparé, et il mène à notre propre site web. Cette seule phrase transforme chaque autocollant ailleurs en faux évident. Si vous déplacez un code ou réimprimez un panneau, dites-le aux clients via vos canaux habituels, et retirez les anciens codes plutôt que de les laisser en place pour être exploités.

Préférez les codes que vous pouvez changer sans réimprimer. Les codes dynamiques, modifiables après impression, permettent de mettre à jour une destination si un lien change ou si un code est compromis, sans laisser un code obsolète en circulation. Si un code imprimé est signalé comme trafiqué, vous pouvez changer la destination des codes survivants et ne réimprimer que ce qui doit l'être. Un code statique compromis, en revanche, doit être physiquement remplacé.

Bon à savoir

Qu'est-ce que le quishing ?

Le quishing est l'hameçonnage par QR code : une arnaque dans laquelle un QR code cache un lien nuisible menant à une fausse page de connexion ou de paiement, ou à un téléchargement conçu pour voler des informations.

Un QR code peut-il infecter mon téléphone à lui seul ?

Le code n'est qu'un lien ou une instruction encodée, mais la page ou le téléchargement derrière lui peut tenter de voler des informations ou d'installer un logiciel malveillant, c'est pourquoi vous devez lire l'aperçu avant d'aller plus loin.

Est-il sûr de scanner un QR code sur un horodateur ?

Ça peut l'être, mais vérifiez d'abord que le code est imprimé dans l'horodateur ou le panneau plutôt que collé dessus. S'il semble superposé, décollé ou déplacé, payez plutôt via l'application officielle ou l'horodateur.

Dois-je scanner un QR code dans un SMS ou un e-mail inattendu ?

Non, surtout s'il vous pousse à agir immédiatement. Contactez plutôt l'entreprise via un numéro de téléphone ou un site web en qui vous avez déjà confiance au lieu de suivre le code.

Que dois-je vérifier dans l'aperçu après le scan ?

Lisez le domaine lettre par lettre, surveillez les fautes d'orthographe ou les lettres interverties, et méfiez-vous des liens raccourcis qui cachent la vraie destination. Si le domaine ne correspond pas à l'entreprise attendue, fermez l'aperçu.

J'ai saisi mon mot de passe sur une page atteinte par scan. Que dois-je faire ?

Fermez la page, puis changez ce mot de passe via la vraie application ou le vrai site web, activez l'authentification multifacteur, et changez le même mot de passe partout où vous l'avez utilisé, en commençant par votre compte e-mail.

Où signaler une arnaque par QR code ?

Aux États-Unis, signalez-la à la FTC sur ReportFraud.ftc.gov, en incluant où vous avez vu le code, ce que disait le message, et où il menait. Ailleurs, utilisez votre service national de signalement de fraude et avertissez l'entreprise usurpée via ses canaux officiels.
