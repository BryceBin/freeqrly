Scanner un QR code depuis une photo

Le code est dans une photo, pas devant votre caméra. Voici comment le décoder sur iPhone, Android et bureau — pas d’app requise.

14 octobre 2026 · Dernière mise à jour : 3 novembre 2026 · 15 min de lecture

Réponse courte : pas besoin d'un deuxième téléphone, ni de pointer un appareil photo vers votre propre écran. Un QR code qui arrive sous forme de photo, de capture d'écran, de pièce jointe de message, ou d'image sur une page web peut être lu depuis l'image elle-même. Sur un iPhone, ouvrez l'image dans Photos et appuyez longuement sur le code. Sur Android, ouvrez-la dans Google Photos et touchez le bouton Lens. Sur un ordinateur, téléversez l'image vers un décodeur qui la lit dans votre navigateur, comme le lecteur FreeQrly. Le reste de ce guide consiste à choisir le bon de ces parcours selon l'endroit où vit réellement votre image, à nettoyer une image récalcitrante avant d'abandonner, et à garder les images privées privées pendant que vous le faites.

La distinction centrale est simple. Un appareil photo en direct lit un motif devant lui. Un lecteur d'images lit un motif déjà stocké en pixels. Les deux tâches se ressemblent, mais elles utilisent des outils différents, et tendre la main vers l'appareil photo en direct quand le code est déjà un fichier est la raison la plus fréquente pour laquelle on conclut qu'un code « ne peut pas être scanné » alors qu'il le peut. Si le code est entre vos mains sous forme de fichier, commencez par un lecteur d'images, pas par un appareil photo.

Les étapes de base, quel que soit l'appareil utilisé

  1. Mettez l'image sous une forme qu'un lecteur peut ouvrir. Enregistrez une pièce jointe, faites une capture d'écran d'un code affiché à l'écran, ou téléchargez la photo depuis la page. Un lecteur a besoin d'un fichier ou d'une image ouverte, pas d'une miniature dans une liste de conversations.
  2. Ouvrez l'image en plein écran. Les lecteurs travaillent sur ce qu'ils peuvent voir. Un code réduit à une miniature dans un fil de messages est une cible bien plus petite que le même code ouvert en plein écran, et l'ouvrir en plein écran ne coûte rien.
  3. Utilisez d'abord le lecteur d'images intégré de votre téléphone. Sur iPhone, Photos ; sur Android, Google Photos avec Lens ; sur Samsung, Galerie. Ces lecteurs tournent sur l'appareil et n'exigent aucun téléversement, ce qui compte pour la section sur la vie privée ci-dessous.
  4. Lisez l'aperçu avant d'ouvrir quoi que ce soit. La même règle que pour le scan en direct s'applique, avec une raison de plus : une image qu'on vous a transférée est passée entre d'autres mains, et l'aperçu est votre vérification que le code mène bien là où l'expéditeur a dit qu'il menait.
  5. Si le premier lecteur ne trouve rien, nettoyez l'image et réessayez — recadrez, éclaircissez, et réessayez — avant de conclure que le code est illisible. Les étapes de nettoyage ci-dessous sauvent plus d'images que n'importe quel changement de lecteur.

Sur iPhone : Photos, appuyer longuement

Ouvrez la photo ou la capture d'écran dans l'application Photos et appuyez longuement sur le QR code lui-même. Le téléphone détecte le code dans l'image et propose le lien ou l'action, que vous touchez après avoir lu l'aperçu. C'est toute la méthode, et elle couvre les cas les plus fréquents : une capture qu'un ami vous a envoyée, une photo d'affiche prise hier, une carte d'embarquement enregistrée dans votre pellicule, un code dans un e-mail que vous avez capturé plutôt qu'enregistré. Si l'appui long ne fait rien, vérifiez deux choses avant tout : que vous appuyez bien sur le code lui-même plutôt que sur un espace vide près de lui, et que le code est entièrement visible dans l'image plutôt que coupé à un bord. Un code rogné par le bord de la capture est l'équivalent en image d'un code rogné par le cadre de l'appareil photo, et aucun lecteur ne peut reconstruire le coin manquant.

Quand le code n'est pas du tout une photo enregistrée — il s'affiche dans un message, un e-mail, ou une page web sur le même téléphone — faites d'abord une capture d'écran, puis ouvrez la capture dans Photos et appuyez longuement sur le code. Cette danse en deux temps semble maladroite la première fois et devient vite automatique, et c'est la réponse à la question qui embrouille le plus de gens : vous ne pouvez pas pointer votre propre appareil photo vers votre propre écran, vous capturez donc l'écran et vous lisez la capture à la place. Les codes en direct devant vous sont traités dans le guide de scan sur téléphone et le guide général de scan.

Sur Android : Google Photos et Lens

Ouvrez l'image dans Google Photos et touchez le bouton Lens. Lens analyse l'image, trouve le code, et affiche le lien ou l'action décodé, que vous touchez après avoir lu l'aperçu. Lens lit des pixels, pas des sources, donc cela marche pareil pour une photo enregistrée, une capture d'écran, ou une image téléchargée. Si vous ne voyez pas de bouton Lens, cherchez-le dans les options de l'image ou le menu de partage. Vous pouvez aussi atteindre Lens depuis l'application Google en touchant son icône Lens et en choisissant l'image.

Sur un Samsung Galaxy, il y a un parcours intégré supplémentaire. Ouvrez l'image dans l'application Galerie Samsung et touchez le bouton Bixby Vision ; le téléphone lit l'image et propose d'ouvrir le lien ou de le copier. Le guide d'assistance Samsung, mis à jour en octobre 2026, décrit le même parcours via le lecteur des Réglages rapides : ouvrez les Réglages rapides, touchez Scanner le QR code, touchez l'icône d'image de la galerie en bas, choisissez la photo, et confirmez. Les deux portes mènent au même résultat, utilisez donc celle que vous trouvez d'abord. Si votre téléphone n'est ni un Samsung ni un téléphone avec Google Photos, le repli est le même que sur un ordinateur : enregistrez l'image et téléversez-la vers un décodeur dans le navigateur, ce qui est traité ensuite.

Sur un ordinateur : téléverser vers un décodeur dans le navigateur

Un ordinateur n'a pas de lecteur d'images intégré pour les QR codes comme un téléphone, c'est donc là qu'un décodeur dans le navigateur gagne sa place. Enregistrez l'image — ou faites une capture d'écran du code sur la page web, dans le document, ou dans la présentation — et téléversez-la vers un décodeur. Le lecteur FreeQrly décode l'image dans votre navigateur, donc l'image ne quitte jamais la page ; ce détail compte le plus justement quand la capture contient quelque chose de privé, ce qui arrive souvent, et la section sur la vie privée ci-dessous explique pourquoi. Le décodeur renvoie le contenu décodé brut, avec un bouton de lien pour les liens et un bouton de copie pour tout le reste. Lisez le lien décodé avant de l'ouvrir, comme vous liriez l'aperçu d'un téléphone.

Les images que d'autres vous envoient

Un code qu'on vous envoie dans une conversation, un e-mail ou une publication sociale mérite une habitude de plus : enregistrez-le avant de le scanner. Lire dans une bulle de conversation, c'est lire une version petite, possiblement compressée, de l'image, dans une application qui n'offre peut-être aucun lecteur. Enregistrer l'image vous donne le fichier complet, l'ouvre dans Photos ou Google Photos là où vit le lecteur, et vous permet de recadrer et d'éclaircir si la première tentative échoue. Cela vous donne aussi un moment pour réfléchir : un code arrivé d'un expéditeur inconnu, avec une histoire urgente jointe, est la version image du message inattendu contre lequel les guides de sécurité mettent en garde. Enregistrez-le, lisez l'aperçu, et décidez ensuite seulement.

Nettoyer une image récalcitrante

La plupart des images illisibles ne sont pas des codes illisibles ; ce sont des codes lisibles enfouis dans une mauvaise photo. Parcourez ces correctifs dans l'ordre, et retestez après chacun, parce que le premier correctif qui marche vous épargne les autres.

  • Recadrez serré autour du code. Coupez la fenêtre de conversation, le texte environnant, la table et l'arrière-plan. Gardez la zone de silence — la marge blanche autour du code — à l'intérieur du recadrage.
  • Redressez et aplatissez. Un code photographié en angle, sur une surface courbe, ou en perspective est étiré dans l'image. Si votre application photo propose un outil de redressement, utilisez-le légèrement ; sinon, reprenez la photo bien de face.
  • Éclaircissez, n'accentuez pas à l'aveugle. Augmenter la luminosité ou le contraste peut sauver un code photographié dans une lumière faible. Une accentuation forte peut inventer des bords qui n'existent pas, éclaircissez donc d'abord et n'accentuez qu'un peu.
  • Essayez le fichier d'origine. Si vous travaillez depuis une copie de conversation compressée, revenez à la photo d'origine, au téléchargement d'origine, ou à une capture toute fraîche. Retoucher ne peut pas restaurer un détail que la compression a supprimé.
  • Essayez un autre lecteur. Si Photos ne trouve rien, essayez Lens ; si Lens ne trouve rien, essayez un décodeur dans le navigateur ; si un décodeur dans le navigateur ne trouve rien, essayez l'autre téléphone de la maison. Un code à la limite de la lisibilité passe parfois avec un lecteur et pas avec un autre. Un code qu'aucun lecteur ne peut lire depuis le fichier d'origine devrait être remplacé par l'expéditeur.

Cas particuliers : images de vidéo, codes multiples, et petits codes

Un code dans une vidéo est un problème de capture d'écran déguisé : mettez en pause sur une image où le code est net, entièrement visible et immobile, capturez cette image, et lisez la capture. Plusieurs codes dans une image — une affiche, une page de billets — doivent être lus un par un : recadrez sur un seul code, lisez-le, et recommencez, puisqu'un lecteur à qui l'on montre plusieurs codes en choisira généralement un, et ce ne sera peut-être pas celui que vous vouliez. Un petit code dans une grande image peut simplement avoir trop peu de pixels pour être résolu ; recadrez dessus, et si les modules se confondent encore quand vous zoomez, l'image ne contient pas assez de détail — demandez une photo plus rapprochée, un téléchargement en plus haute résolution, ou un code tout neuf.

Vie privée : ce que votre capture contient en plus du code

Les captures d'écran et les photos contiennent presque toujours plus que le QR code. Une capture d'une conversation contient la conversation autour du code. Une photo d'un billet contient le nom, la référence de réservation, et le code-barres à côté du code. Une capture d'une page de paiement contient des montants et des détails de compte. Avant de téléverser une telle image vers un décodeur, regardez ce qu'il y a d'autre dans le cadre, et recadrez pour l'enlever. Recadrer n'est pas seulement un correctif de lisibilité ; c'est un correctif de vie privée, et cela coûte les mêmes quelques secondes dans les deux cas.

La question plus profonde est de savoir où va l'image. Beaucoup de décodeurs en ligne téléversent votre image vers leur serveur pour la lire, ce qui veut dire que le serveur d'un inconnu reçoit votre capture — conversation, billet, et tout — juste pour lire un code. Un décodeur qui lit l'image dans votre navigateur, comme le lecteur FreeQrly, n'envoie jamais l'image nulle part ; la lecture se fait sur votre appareil, dans la page, et l'image reste avec vous. Préférez un décodeur local pour toute image que vous n'enverriez pas par e-mail à un inconnu, et recadrez avant de téléverser même dans ce cas.

La comparaison honnête : lecteurs intégrés, décodeurs dans le navigateur, et applications de scan

Pour un code dans une image, trois types d'outils se disputent, et le classement honnête dépend de l'image, pas du marketing de l'outil. Les lecteurs intégrés — Photos sur iPhone, Lens sur Android, Galerie sur Samsung — sont le meilleur premier choix pour une image enregistrée sur votre propre téléphone : ils sont déjà installés, ils tournent sur l'appareil, et ils n'exigent aucun téléversement. Les décodeurs dans le navigateur sont le meilleur choix sur un ordinateur, et le meilleur repli sur un téléphone quand le lecteur intégré échoue, à condition que le décodeur lise localement dans le navigateur plutôt que de téléverser votre image. Les applications de scan sont le choix par défaut le plus faible pour ce travail : elles ajoutent une installation, un écran d'autorisation, et souvent des publicités ou un compte, en échange d'une capacité que votre téléphone possède déjà.

Une dernière remarque honnête : aucun lecteur ne sauve un code dont le détail a disparu. Un transfert fortement compressé, une image de vidéo floue, un code coupé au bord d'une capture — ce sont des problèmes de données manquantes, pas des problèmes de lecteur, et changer de lecteur cinq fois ne restaurera pas ce qui n'a jamais été capturé. Le correctif pour des données manquantes est un meilleur original, et en demander un à l'expéditeur est plus rapide et plus honnête que d'essayer tous les décodeurs d'internet. Les lecteurs sont bons pour trouver des codes dans les images ; ils ne sont pas bons pour inventer des codes qui ne sont pas là.

Quand l'image se lit mais que la destination échoue

Parfois l'image se lit parfaitement et le résultat déçoit quand même : un lien mort, une page déplacée, un formulaire qui n'existe plus, un billet déjà utilisé. Ce n'est pas un échec de scan ; c'est un échec de destination, et le correctif appartient à celui qui a émis le code. Un code statique contient sa destination directement, donc si la destination a disparu, le code n'a rien à dire — et si la destination a déménagé, seul l'émetteur peut pointer le code ailleurs, ce qui est exactement à quoi sert un code dynamique : il reste modifiable après impression, avec des statistiques de scan, sous un compte gratuit. Pour les codes qui ne se lisent pas du tout, voir pourquoi votre QR code ne scanne pas et pourquoi votre QR code est flou. Si le lien est mort, demandez un code tout neuf à l'expéditeur plutôt que de rescanner.

Créer un code qui vaut d'être envoyé en image

L'autre versant de ce guide vaut un paragraphe, parce que les codes que les gens peinent à lire depuis des images sont souvent des codes mal faits au départ. Si c'est vous qui envoyez un code en image, envoyez le fichier d'origine, pas une capture d'une capture ; gardez le code grand dans le cadre, avec sa zone de silence intacte et des modules foncés sur fond clair ; et testez-le en le relisant vous-même depuis l'image avant de l'envoyer. Le générateur FreeQrly couvre 17 types, et un code statique créé là est gratuit sans inscription, sans filigrane et sans expiration, donc un code de test ne coûte rien. Si le code sera transféré ou réutilisé, envisagez plutôt un code dynamique : il reste modifiable si la destination change, rapporte des statistiques de scan, et est gratuit pour 20 codes, actuellement avec une disponibilité illimitée pendant la période promotionnelle, et avec des scans illimités. Pour beaucoup de codes d'un coup, la génération en lot crée un code par lien. Envoyez un original propre, et la personne à l'autre bout n'aura pas besoin de la section nettoyage de ce guide.

Bon à savoir

Comment scanner un QR code depuis une capture d’écran sur iPhone ?

Ouvrez la capture d'écran dans l'application Photos et appuyez longuement sur le QR code lui-même. Le téléphone détecte le code dans l'image et propose le lien ou l'action ; lisez l'aperçu avant de le toucher.

Comment scanner un QR code depuis une image sur Android ?

Ouvrez l'image dans Google Photos et touchez le bouton Lens. Lens lit le code dans l'image et affiche le lien ou l'action décodé. Sur un Samsung Galaxy vous pouvez aussi ouvrir l'image dans Galerie et toucher le bouton Bixby Vision.

Comment scanner un QR code depuis une image sur un ordinateur ?

Enregistrez l'image, ou capturez le code sur la page, et téléversez-la vers un décodeur dans le navigateur. Préférez un décodeur qui lit l'image dans votre navigateur, pour que l'image ne soit jamais envoyée à un serveur — le lecteur FreeQrly fonctionne ainsi.

Quelqu'un m'a envoyé un QR code dans une conversation. Comment le scanner ?

Enregistrez d'abord l'image, puis ouvrez le fichier enregistré dans Photos ou Google Photos et utilisez le lecteur d'images intégré. Lire dans une bulle de conversation, c'est lire une copie plus petite, possiblement compressée, et l'application de conversation n'offre peut-être aucun lecteur.

Pourquoi le décodeur ne peut-il pas lire ma photo ?

Généralement le code est coupé à un bord, trop petit dans le cadre, flou, ou photographié en angle. Recadrez serré autour du code tout en gardant sa zone de silence, éclaircissez s'il est sombre, essayez le fichier d'origine au lieu d'un transfert compressé, et essayez un autre lecteur. Si aucun lecteur ne peut lire le fichier d'origine, demandez un code tout neuf à l'expéditeur.

Et si une image contient plusieurs QR codes ?

Recadrez sur un seul code et lisez-le, puis recommencez pour le suivant. Un lecteur à qui l'on montre plusieurs codes à la fois en choisira généralement un, et ce ne sera peut-être pas celui que vous vouliez.

Est-il sûr de téléverser une capture d'écran vers un décodeur en ligne ?

Recadrez pour ne garder que le code d'abord — les captures contiennent souvent des conversations, des billets ou des détails de paiement à côté du code. Préférez un décodeur qui lit localement dans votre navigateur, pour que l'image ne soit jamais téléversée vers un serveur.
