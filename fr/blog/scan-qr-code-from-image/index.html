Scanner un QR code depuis une photo

Le code est dans une photo, pas devant votre caméra. Voici comment le décoder sur iPhone, Android et bureau — pas d’app requise.

14 octobre 2026 · 4 min de lecture

Sur iPhone

Ouvrez la photo dans l’app Photos et appui long sur le QR code — iOS le détecte directement dans l’image et propose d’ouvrir le lien. Pas d’outils supplémentaires nécessaires.

Sur Android

Ouvrez l’image dans Google Photos et touchez le bouton Lens. La plupart des apps de galerie sur les téléphones Samsung et Pixel font pareil depuis le menu de partage.

Sur PC / Mac

Les téléphones ne peuvent pas vous aider ici — c’est là qu’un décodeur en ligne gagne sa place. Faites une capture d’écran (ou enregistrez l’image), puis téléversez-la dans le scanner de FreeQrly. Elle est décodée dans votre navigateur, donc l’image n’est jamais téléversée nulle part — agréable quand la capture d’écran contient quelque chose de privé.

Astuces pour les images récalcitrantes

Recadrez serré autour du code avant de téléverser — les décodeurs fonctionnent plus vite et plus fiablement sur un recadrage propre. Si la photo est floue ou prise sous un angle, aucun décodeur ne peut la sauver ; reprenez-la de face. Plus dans pourquoi votre QR code ne se scanne pas.

Note de confidentialité

Les captures d’écran contiennent souvent plus que le QR code — discussions, billets, photos personnelles. Réfléchissez à deux fois avant de les téléverser vers un site de décodage au hasard. Un décodeur local ne voit jamais rien d’autre que votre propre onglet de navigateur.
