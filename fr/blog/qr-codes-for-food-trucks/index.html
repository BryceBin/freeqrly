QR codes pour food trucks : le camion bouge chaque jour — vos codes imprimés doivent suivre

Un restaurant imprime un panneau de menu une fois et il reste vrai toute une saison. Un food truck en imprime un le lundi, et le mardi le camion est dans un autre parking, la poitrine de porc est épuisée, et le panneau est déjà faux.

Imaginez maintenant chaque panneau imprimé pointant vers une adresse web fixe. Les employés de bureau du lundi scannent le code le mercredi et atterrissent sur l’adresse du parc de bureaux du lundi ; le client qui a adoré les raviolis au marché conduit jusqu’au parc de bureaux le jeudi parce que c’est là que le flyer dit que le camion est — et le camion est dans une brasserie à dix kilomètres.

C’est ce qu’un code fixe imprimé fait quand l’entreprise qu’il annonce change d’emplacement chaque jour. Un restaurant peut se permettre un code imprimé qui pointe vers une seule adresse pour toujours ; un food truck ne le peut pas, parce que l’adresse est la seule chose qui n’est jamais la même deux fois. La question de l’emplacement vient donc en premier : si un client ne peut pas trouver le camion aujourd’hui, rien d’autre ne compte.

Ce que « dynamique » veut dire quand votre adresse change chaque jour

Un code statique intègre sa destination dans le motif imprimé : si l’adresse change, le motif est faux, et la seule solution est une réimpression. Un code dynamique pointe vers une courte redirection que vous contrôlez — changez la destination dans votre tableau de bord et chaque copie imprimée, sur le camion, les sacs et les flyers du mois dernier, suit instantanément.

Pour une boutique fixe, c’est un confort ; pour un food truck, c’est la différence entre un panneau qui fonctionne et un panneau qui ment. Le panneau sur le camion peut rester en place pendant un an pendant que la destination derrière son code change chaque matin — et encore à midi si un emplacement est annulé à cause de la pluie.

Faites-en une routine du matin : avant que le camion ne parte, passez deux minutes à vérifier que la page des horaires commence par aujourd’hui, que le menu marque les épuisements et montre le spécial, et que le code de commande à l’avance ouvre la bonne page. Avec un code statique, le même matin veut dire réimprimer le panneau, le panneau de la file et les flyers — ou accepter que l’impression soit fausse.

Le code « Trouvez-nous aujourd’hui » : le code le plus important du camion

Si vous n’imprimez qu’un seul code, imprimez celui-ci — il répond à la question que chaque food truck entend le plus : « Où êtes-vous aujourd’hui ? »

Pointez un code dynamique vers votre page d’horaires — une page qui commence toujours par aujourd’hui et demain — et mettez-le partout où un client pourrait vous rencontrer après votre départ : le flanc du camion, le sac, le gobelet, le reçu, le flyer. La page a un seul travail : répondre à trois choses en moins de cinq secondes pour un inconnu.

  • Où êtes-vous aujourd’hui, exactement ? Nom du lieu, adresse, et un point de repère (« à côté des marches de la bibliothèque »). Un code postal seul ne suffit pas sur un marché, où cinq camions partagent le même.
  • Quand êtes-vous là ? Heure d’ouverture, heure de fermeture, et quand vous arrêtez de servir — souvent plus tôt que quand vous remballez. Indiquez les deux.
  • Et si ça a changé ? Si un emplacement est annulé ou tombé à l’eau à cause de la pluie, la page des horaires est la première chose que vous mettez à jour, avant toute publication sociale. Le code sur le flyer de la semaine dernière y mène toujours, donc le flyer n’est jamais faux.

Ne pointez pas ce code vers un repère de carte pour un seul emplacement passé : un repère a l’air officiel longtemps après votre départ, et un client qui le suit jusqu’à un parking vide ne vous donnera pas une seconde chance. Ne le pointez pas non plus vers un profil de réseau social : un fil enterre l’emplacement d’aujourd’hui sous les photos d’hier en quelques heures.

La page des horaires se rentabilise aussi les jours où vous ne servez pas le public : le samedi du Dumpling House est un mariage privé, et la page le dit — « Fermé au public aujourd’hui, de retour au parc du lac dimanche, 10 h 00–16 h 00. » Un jour fermé bien géré est un client conservé.

Le code de menu qui survit aux épuisements

Le code de menu est le deuxième code à imprimer. Il n’est pas là pour montrer un beau menu — il est là pour montrer le menu du jour à une personne affamée dans une file avec une main libre et soixante secondes pour décider. La page derrière le code compte donc plus que le code lui-même :

  • Les articles du jour d’abord. Le menu complet peut vivre plus bas, mais le haut, c’est aujourd’hui : ce qui est là, ce qui ne l’est pas, le spécial.
  • Épuisé veut dire marqué, pas supprimé. Quand le porc est épuisé à 13 h 00, marquez-le « Épuisé » plutôt que de le supprimer : supprimer déroute le client qui l’a vu sur le panneau il y a cinq minutes ; marquer dit la vérité et le pousse vers le choix suivant.
  • Prix, allergènes et notes alimentaires en langage clair. Mettez le prix à côté de l’article, à chaque fois — une file n’est pas l’endroit pour deviner si les raviolis contiennent des crustacés.
  • Pas de téléchargement, pas de zoom par pincement, pas de connexion. Si votre menu est un PDF, il doit s’ouvrir dans le navigateur et montrer la première page immédiatement, sur un téléphone, sur les données mobiles — s’il force un téléchargement, la moitié de votre file abandonne. S’il vit comme une publication sociale, il glisse dans le fil et est introuvable dès demain. Une page sur votre propre site, ou la page de menu de votre plateforme de commande, est le bon endroit, et un code dynamique vous permet de l’échanger sans réimprimer.

N’imprimez pas un code de menu séparé pour chaque jour de la semaine. Un seul code de menu, mis à jour quotidiennement, vaut mieux que sept codes que personne ne peut distinguer.

Commander depuis la file : laissez le temps d’attente faire le travail

Une file devant un food truck est une bonne nouvelle jusqu’à ce qu’elle commence à faire fuir les gens. La personne au bout d’une file de vingt personnes se demande combien de temps cela va prendre — et chaque minute sans information rend le départ plus probable. Un code de commande à l’avance lui donne quelque chose d’utile à faire pendant l’attente : parcourir, choisir, payer, et récupérer au guichet quand son nom ou son numéro est appelé.

Le code ne prend pas la commande ; il supprime les étapes entre une personne affamée et la page de commande que vous utilisez. Mettez-le donc au bout de la file, pas seulement au guichet — au moment où un client atteint le guichet, l’occasion de commander est passée. Mettez-le sur le panneau de la file, un panneau sur pied à mi-chemin dans la file, et le panneau du menu, avec un libellé qui promet l’avantage : « Commandez à l’avance depuis la file — évitez l’attente au guichet. »

Trois détails font ou défont la commande à l’avance. Dites comment fonctionne la récupération, sur le panneau et sur la page — numéro de commande, nom appelé, ou texto quand c’est prêt ; choisissez-en un et tenez-vous-y. Dites honnêtement combien dure l’attente : aux heures de pointe, mettez l’attente actuelle sur la page de commande ou le panneau de la file. Gardez la commande au guichet ouverte : un client sans batterie ou sans données mobiles, ou qui veut parler à un humain, doit toujours pouvoir commander au guichet.

Testez tout le parcours vous-même, sur les données mobiles, depuis le bout de votre propre file — et au rassemblement, pas seulement à l’emplacement calme de la semaine, où la file est la plus longue et le signal le pire.

Transformer une visite en prochaine visite : fidélité et suivi social

Le problème marketing le plus difficile d’un food truck, ce n’est pas la première visite. C’est la deuxième : le camion bouge, le client oublie, et la prochaine fois il va à l’endroit qu’il peut trouver. Les codes de fidélité et de suivi social comblent cet écart.

La fidélité sans application. Personne ne veut installer une application au milieu d’une file de restauration, et un programme de fidélité qui l’exige sera ignoré. Un code qui ouvre une simple inscription — un formulaire e-mail ou téléphone, une page de carte à tampons, ou votre plateforme de fidélité existante — ne demande presque rien et donne au client une raison de revenir. Gardez la récompense assez simple pour l’énoncer en une ligne : « Achetez-en neuf, le dixième est gratuit. » Un système de points qui nécessite un paragraphe d’explication, c’est un devoir, pas de la fidélité. Ne collectez que ce dont vous avez besoin pour reconnaître le client la prochaine fois, énoncez la récompense sur le panneau, et placez le code là où le client est déjà satisfait et sans hâte : le guichet de retrait, le reçu, le sac — pas le bout de la file.

Le suivi social, fait une fois et bien fait. Un code qui ouvre votre profil Instagram ou TikTok a un seul travail : transformer un mangeur occasionnel en abonné qui voit la publication de l’emplacement de demain. Mettez-le sur le sac et le reçu, avec une raison, pas juste un logo : « Suivez-nous pour voir où nous sommes demain. » Gardez-le à une plateforme par code — une page de six icônes sociales force un choix, et la plupart ne choisiront rien.

Ne combinez pas la fidélité et le social en un seul code « suivez et rejoignez ». Le client qui veut le tampon de fidélité et celui qui veut vous suivre sur Instagram font deux choses différentes, et un code qui sert les deux ne sert bien ni l’un ni l’autre.

Avis et traiteur : les codes qui travaillent pendant que vous partez

Les deux appartiennent à l’emballage, parce que l’emballage est la seule partie du camion qui rentre à la maison avec le client.

Les avis au moment du bonheur maximum. Le meilleur moment pour demander, c’est quand la nourriture est entre les mains du client et qu’il en est content. Un code ouvrant directement votre formulaire d’avis Google transforme ce moment en un scan. Obtenez le lien direct depuis votre fiche Google Business et placez le code au guichet de retrait, sur le reçu et sur le sac.

Demandez à tout le monde de la même façon, une fois. N’offrez jamais rien en échange d’un avis, et ne demandez jamais uniquement aux clients que vous attendez satisfaits — les plateformes d’avis traitent les incitations et la sollicitation sélective comme de la manipulation. Un code visible plus une demande faite oralement, sans insister, suffit. Un code statique convient : un lien d’avis Google change rarement. Utilisez le dynamique si vous voulez des nombres de scans par placement.

Traiteur : transformez une foule de festival en travail futur. Les festivals et les marchés sont là où les demandes de traiteur se produisent, et elles se produisent en vitesse : un organisateur goûte votre nourriture à un rassemblement, a une fête d’entreprise dans trois semaines, et veut saisir l’idée avant que la foule ne l’emporte. Un code de traiteur ouvrant un court formulaire — date, lieu, nombre d’invités, coordonnées — lui permet de le faire en moins d’une minute, sur un téléphone.

Gardez le formulaire assez court pour le terminer debout ; chaque champ supplémentaire est une demande que vous ne recevrez jamais. Dites quand vous répondrez — « Nous répondons sous un jour ouvré » — et pensez-le vraiment. Imprimez le code de traiteur séparément, étiqueté « Traiteur et événements privés — scannez pour demander », comme un code dynamique, pour que les cartes imprimées continuent de fonctionner si votre formulaire change d’adresse. Mettez-le là où se tiennent les organisateurs : la bannière du festival, les cartes de visite au guichet, les flyers — pas enfoui sur le panneau du menu.

Quoi mettre où : une carte de placement pour tout le camion

Un code sur le camion et un code sur l’emballage ont l’air identiques, mais ils fonctionnent à des moments différents : le code du camion est scanné par quelqu’un qui se tient devant vous, en train de décider maintenant ; le code de l’emballage est scanné plus tard, à la maison, par quelqu’un qui a déjà mangé et qui veut peut-être vous retrouver ou vous réserver.

Deux règles régissent le tableau. Ne surchargez jamais un panneau de cinq codes, et n’imprimez jamais un code sans un libellé disant ce que le client obtient en le scannant — si vous ne pouvez pas écrire cette phrase, le code n’a pas sa place là.

Imprimer pour un véhicule qui vit dehors

Un food truck est un panneau publicitaire mobile qui se fait pleuvoir dessus, décolorer par le soleil et heurter par les chariots. Ses codes échouent pour des raisons ordinaires et réparables : trop petits, une marge encombrée, un faible contraste, des reflets, ou une surface décolorée.

La taille est une décision de distance, pas de design. En règle générale, n’imprimez jamais plus petit que 2 cm sur 2 cm, et faites le code au moins un dixième aussi large que la distance de scan : un code de gobelet scanné à 50 cm doit faire environ 5 cm de large ; un code de flanc de camion scanné à 5 mètres, environ 50 cm. En cas de doute, imprimez plus grand — un code plus grand ne coûte presque rien, une réimpression coûte tout le tirage.

La zone de silence n’est pas une décoration. La marge vierge autour du code — au moins quatre modules de large sur les quatre côtés, dans la même couleur claire que le fond — est la façon dont un téléphone trouve les bords du motif. Le texte, les bordures et les logos doivent rester en dehors, ou un code d’apparence parfaite ne se scannera pas. Gardez le code foncé sur fond clair, et gardez les trois carrés d’angle découverts.

Les matériaux comptent. Utilisez du vinyle ou du papier plastifié, une finition mate là où la lumière du soleil ou les projecteurs provoquent des reflets, et un panneau plat, pas une surface courbe. Faites une épreuve à taille finale sur le matériau final, scannez-la avec plus d’un téléphone en plein jour et en lumière tamisée, et vérifiez-la à nouveau après la pluie et le nettoyage. Un code qui ne se scanne que parfois est cassé.

Exportez correctement et gardez les fichiers : SVG, qui s’agrandit sans flou, ou un PNG haute résolution — jamais un JPEG de basse qualité. Gardez chaque export étiqueté par placement, pour qu’un panneau endommagé puisse être réimprimé exactement. Les codes de mon food truck doivent-ils être statiques ou dynamiques ?

Dynamiques, pour presque tout : l’emplacement, le menu, les prix et les spéciaux changent chaque jour, et un code dynamique peut être redirigé après impression. Les codes statiques sont pour les choses qui ne changent jamais, comme votre page d’accueil. Avec FreeQrly, les codes dynamiques sont gratuits après inscription — 20 sur l’offre gratuite.

Que se passe-t-il si mon camion bouge après que j’ai imprimé le code ?

Si le code est dynamique, rien ne casse : mettez à jour la destination dans votre tableau de bord, ou modifiez la page des horaires, et chaque copie imprimée suit. S’il est statique, le motif pointe toujours vers l’ancienne adresse, donc vous devez réimprimer le panneau ou restaurer l’ancienne page.

Un seul QR code peut-il gérer le menu, la commande, les avis et le traiteur ?

Il peut pointer vers une page qui renvoie vers tous, mais une personne affamée dans une file ne cherchera pas le bon lien. Donnez à chaque travail son propre code et son libellé.

Où le code de commande à l’avance doit-il aller ?

Au bout de la file, sur le panneau de la file et un panneau sur pied à mi-chemin dans la file. Un code qui n’apparaît qu’au guichet arrive trop tard. Gardez aussi la commande au guichet ouverte, pour que le code soit l’option la plus rapide, pas la seule option.

Que dois-je vérifier chaque matin avant le service ?

Trois choses, en deux minutes : la page des horaires commence par aujourd’hui ; le menu marque les épuisements et montre le spécial ; le code de commande à l’avance ouvre la bonne page.
