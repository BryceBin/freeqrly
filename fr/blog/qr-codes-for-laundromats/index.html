QR codes pour laveries automatiques : moins d'attente, moins de questions

Une laverie automatique tourne autour de petites questions posées au mauvais moment — quelle est cette machine, comment payer, combien de temps reste-t-il, et à qui signaler une panne. Placez un QR code bien étiqueté là où chaque question se pose, et les clients pourront y répondre eux-mêmes, même quand le personnel est occupé ailleurs.

4 novembre 2026 · 15 min de lecture

Une laverie automatique est une salle d'attente avec des machines dedans. Les clients arrivent avec un panier, passent du temps à charger, attendre, plier et repartir, tandis que le personnel aide souvent quelqu'un d'autre ou est absent de la pièce. Un QR code ne peut pas plier une serviette, mais il peut répondre à la question que le client se pose déjà : quelle est cette machine, comment la payer, combien de temps cela prendra-t-il, et à qui signaler un problème ?

Donnez à chaque tâche son propre code, à l'endroit où la tâche se déroule. Un seul grand code sur la porte d'entrée qui ouvre votre page d'accueil n'aide personne debout devant la machine numéro sept avec une lessive mouillée et une porte bloquée.

Commencez par un code par machine

Étiquetez chaque machine, puis faites correspondre le code à l'étiquette. Inscrivez le numéro de la machine en gros caractères à côté du code — par exemple W-04 ou D-12 — et assurez-vous que la page ouverte par le code affiche le même numéro. Cette seule habitude évite la plupart des confusions : un client qui paie pour la mauvaise machine, qui signale la mauvaise machine, ou qui demande au personnel de retrouver une lessive qui n'est pas là où il le pensait.

Ce que le code de la machine ouvre dépend de l'équipement de votre établissement. Un QR code seul ne sait pas si une machine est en marche, et il ne peut pas démarrer une machine par lui-même. C'est un raccourci vers une page, un formulaire ou un système de paiement. Si vous utilisez un système de paiement de laverie connecté, ce système peut proposer un code de démarrage par scan pour chaque machine : un fournisseur, par exemple, décrit son parcours invité comme le scan du code sur la machine, le choix du cycle et des options, puis le paiement par portefeuille mobile ou carte, après quoi la machine démarre automatiquement. Sans ce type de système, le code de la machine peut tout de même ouvrir une page simple pour cette machine, avec sa capacité, ses options de cycle, son prix et un lien pour signaler un problème.

Utilisez le code de la machine pour l'aide au cycle et les signalements de panne

Pour un établissement sans système connecté, la page de machine la plus pratique est un petit guide : ce que cette machine contient, quels cycles conviennent aux délicats, à la grosse literie ou à un rafraîchissement rapide, combien de temps dure un cycle typique, et quoi faire si la porte ne s'ouvre pas. Restez concis. Personne ne veut lire un essai pendant que son linge tourne.

Le même code, ou un second code clairement étiqueté sur la machine, peut ouvrir un formulaire de signalement de panne. Préremplissez le numéro de machine quand votre outil de formulaire le permet, et ne demandez que ce dont le personnel a besoin pour agir : ce qui s'est passé, si la machine peut être utilisée sans danger, et un contact uniquement si le client souhaite une réponse au sujet d'un remboursement ou d'un objet perdu. Un signalement qui prend trente secondes à envoyer sera envoyé ; un signalement qui demande un compte et un mot de passe ne le sera pas. Ajoutez une solution de repli courte à côté du code — un numéro de téléphone, ou une note invitant à s'adresser au comptoir — pour les clients dont la batterie de téléphone est à plat.

Et le suivi de cycle en direct ?

Le suivi en direct — une page indiquant qu'il reste douze minutes à une machine — est la fonctionnalité que les clients demandent le plus, et c'est aussi celle qu'un code imprimé seul ne peut pas fournir. Un code ne peut qu'ouvrir une page ; le minutage en direct exige un système connecté qui suit le cycle. Si votre système le propose, le code de la machine en est la porte d'entrée naturelle. Sinon, ne promettez pas de suivi en direct sur vos panneaux.

Lavage et pliage : un code pour le dépôt, un pour le retrait

Le service de lavage et pliage transforme une visite en libre-service en un transfert, et les transferts sont le moment où les choses se perdent : des sacs sans nom, des instructions spéciales que personne n'a notées, et des heures de retrait que personne ne retient. Un code au comptoir peut ouvrir un formulaire de dépôt demandant un nom, un moyen de contact, le nombre de sacs et toute instruction — lavage à froid, pas de lessive parfumée, séchage à l'air des délicats — avant que le client ne parte. Imprimez le même code, ou un code de retrait, sur le ticket de dépôt ou le reçu, pour que le client puisse retrouver les mêmes informations plus tard.

Pour le retrait, restez tout aussi simple. Le code du ticket peut ouvrir une page indiquant les heures de retrait, ce qu'il faut apporter, et comment contacter le magasin si une heure de retrait doit changer. Si votre système peut afficher l'état de la commande, liez-le ; sinon, dites-le clairement et donnez le numéro de téléphone du comptoir. L'objectif est de recevoir moins d'appels demandant « mon linge est-il prêt ? », pas une page d'état qui devine. Ne mettez aucune donnée personnelle dans le QR code lui-même : le code doit ouvrir un formulaire ou une page de commande protégée par connexion, jamais encoder un nom de client ou un numéro de téléphone dans le motif imprimé.

Une fidélité qui survit à une poche détrempée

Les cartes à tampons en papier fonctionnent jusqu'à ce qu'elles passent en machine, ce qui, dans une laverie automatique, n'est pas un accident rare. Un QR code peut remplacer la carte par un lien vers votre page de fidélité, où les clients peuvent voir l'offre en cours et comment en profiter. Un exemple simple est « chaque dixième lavage offert » — considérez-le comme une illustration, pas comme une règle. Choisissez un seuil que vos marges peuvent supporter, écrivez-le en mots simples sur le panneau, et gardez la même formulation sur la page ouverte par le code.

Soyez honnête sur ce que le code fait ici. Les statistiques de scan peuvent vous dire combien de fois une page de fidélité a été ouverte ; à elles seules, elles n'identifient pas les clients individuels ni ne comptent les visites d'une personne. Une vraie fidélité par client exige un compte ou une application de fidélité derrière la page, le QR code n'étant que le moyen le plus simple d'y accéder.

Le Wi-Fi pour les clients qui attendent

L'attente fait partie de l'expérience de la laverie automatique, et le Wi-Fi est un moyen peu coûteux de la rendre agréable. Un code Wi-Fi permet au client de rejoindre le réseau en scannant, sans taper un long mot de passe lu sur un panneau décoloré. En règle empirique, mettez le Wi-Fi sur un réseau invité plutôt que sur le réseau utilisé par votre système de paiement ou vos ordinateurs de bureau, et placez le code là où les gens s'assoient — près des tables de pliage et des chaises — pas seulement près de la porte devant laquelle ils passent.

Le Wi-Fi est l'exemple le plus clair d'un usage pour un code statique. Le nom et le mot de passe de votre réseau changent rarement, et réimprimer un ou deux panneaux de la zone d'attente est un petit travail s'ils changent. Plus de détails dans notre guide pour partager le Wi-Fi avec un QR code.

Avis Google : demandez au bon moment, pas une note

Le meilleur moment pour demander un avis est quand le travail est bien fait — des machines propres, une lessive pliée, un membre du personnel serviable — pas pendant que le client charge encore une machine. Placez un code d'avis sur les tables de pliage, sur le reçu ou près de la sortie, avec une invitation courte et honnête comme « Bonne visite ? Parlez-en aux autres ici. » Le code doit ouvrir directement votre page d'avis Google, pour que le client n'ait pas à chercher votre établissement ni à choisir la bonne succursale. Le profil d'établissement Google fournit un lien de demande d'avis à cet effet, dont les étapes consistent à sélectionner Lire les avis, puis Obtenir plus d'avis, et à copier le lien.

N'offrez ni réduction, ni lavage gratuit, ni aucune autre incitation en échange d'un avis. La politique de Google interdit les incitations à publier, modifier ou supprimer un avis. Si vous avez plusieurs succursales, vérifiez que le code ouvre le bon établissement avant d'imprimer. Notre guide pour obtenir des avis Google avec un QR code détaille la configuration.

Prix et liens de paiement

Les prix changent : les coûts de lessive augmentent, une nouvelle machine grande capacité arrive, ou une promotion de week-end dure un mois. C'est exactement pourquoi une liste de prix ne doit pas être intégrée dans un code imprimé qui ne peut pas être modifié. Un code dynamique sur le panneau des prix peut pointer vers une page de prix en direct, de sorte qu'un changement de prix signifie modifier la page une fois, et non réimprimer chaque panneau, autocollant et prospectus du magasin.

Le paiement exige le même soin, et un avertissement supplémentaire. Un QR code peut renvoyer vers une page de paiement, une page de recharge ou une application de laverie connectée, mais il ne doit jamais contenir d'identifiants de paiement ou de coordonnées bancaires, ni déplacer de l'argent sans une étape de paiement claire et fiable entre les deux. Les clients doivent toujours voir le nom de l'établissement, le numéro de machine et le montant avant de confirmer quoi que ce soit. Testez vous-même tout le parcours de paiement, sur un vrai téléphone, avant que le code ne soit apposé sur une machine.

Objets trouvés, sans exposer publiquement le linge des autres

Chaque laverie automatique a une étagère d'objets trouvés, et la plupart y restent parce que personne ne sait quoi faire d'une chaussette seule, d'un chargeur de téléphone ou d'une veste oubliée dans un sèche-linge. Un code au comptoir et près de la sortie peut ouvrir un simple formulaire d'objets perdus : ce qui a été perdu, dans quelle machine cela peut se trouver, et comment contacter le propriétaire. Gardez ce formulaire réservé au personnel. Ne publiez ni photos ni descriptions d'objets trouvés sur une page publique, où n'importe qui pourrait les réclamer, et n'encodez pas de données personnelles dans le code lui-même. Sur la même page, indiquez clairement combien de temps les objets sont conservés et quand ils peuvent être récupérés.

Dynamique ou statique ? Décidez selon que la destination changera

C'est la décision qui évite le plus de réimpressions. Un code statique stocke sa destination directement dans le motif imprimé, il ne peut donc pas être modifié après impression ; un code dynamique stocke un court lien de redirection, de sorte que la destination derrière lui peut être modifiée et les scans comptés. Posez-vous une seule question pour chaque panneau : cette page, ce prix ou cette offre devra-t-il un jour changer, ou ai-je besoin de savoir à quelle fréquence il est scanné ? Si la réponse à l'une ou l'autre est oui, utilisez un code dynamique. Si la réponse aux deux est non, un code statique est plus simple et n'a rien derrière lui qui puisse expirer.

Impression et placement : conçus pour la chaleur, l'humidité et les mains mouillées

Une laverie automatique est un endroit difficile pour le papier. La vapeur, les mains humides, les éclaboussures de lessive et les machines chaudes vont gondoler, baver et décolorer un panneau non protégé plus vite que n'importe quel commerce sec. Cela ne veut pas dire qu'il faut des matériaux coûteux ; cela veut dire qu'il faut tester une étiquette à son emplacement réel avant d'en imprimer cinquante.

Commencez par la taille. En règle empirique, faites un code imprimé au moins un dixième aussi large que la distance à laquelle il sera scanné, et ne descendez jamais en dessous d'environ 2 × 2 cm, même pour une étiquette en gros plan. Un code lu à environ 25 cm de distance doit donc mesurer au moins environ 2,5 cm de large, tandis qu'une affiche lue à 3 mètres exige un code d'environ 30 cm de large. Laissez une marge blanche — la zone de silence — de 4 modules de chaque côté, dans la même couleur claire que le fond du code, et gardez-en éloignés texte, bordures et motifs chargés. Imprimez des modules sombres sur fond clair, et pour l'impression utilisez un fichier vectoriel comme le SVG, ou un PNG à 300 pixels par pouce à la taille finale, pour que les bords des modules restent nets.

Pour la durabilité, plastifiez les étiquettes de machines ou imprimez-les sur un support essuyable, et choisissez une finition mate quand vous le pouvez : les finitions brillantes peuvent renvoyer la lumière droit dans l'appareil photo et compliquer le scan, tandis que les finitions mates sont plus faciles à scanner. En règle empirique, éloignez les codes des surfaces les plus chaudes — le dessus d'un sèche-linge en usage constant, par exemple — et de la vapeur directe, des distributeurs de lessive et de tout endroit où une manche mouillée frottera dessus chaque jour. Placez l'étiquette là où le client regarde naturellement : à côté de la fente de paiement ou du bouton de démarrage.

Avant un tirage complet, testez comme un client utilisera réellement le code : imprimez une épreuve à la taille réelle, sur le matériau réel, et scannez-la avec au moins un iPhone et un téléphone Android, à la distance réelle, dans l'éclairage réel du magasin. Si un code échoue, vérifiez la taille, la zone de silence, le contraste et les reflets avant d'incriminer le téléphone. Notre guide des tailles d'impression des QR codes détaille les dimensions, et notre guide de dépannage des QR codes couvre les correctifs quand un code ne veut pas scanner.

Un plan de déploiement qui commence petit

Ne réétiquetez pas tout le magasin le premier jour. Commencez par un pilote : deux ou trois machines, le code du comptoir et le panneau Wi-Fi. Observez pendant une semaine — demandez au personnel ce que les clients ont demandé, quels codes ont été le plus scannés, et quelles étiquettes se sont décollées, embuées ou ont semé la confusion. Corrigez d'abord la formulation et le placement, car un code qui ouvre la bonne page mais se trouve au mauvais endroit sera quand même ignoré.

Déployez ensuite machine par machine, par lots, en utilisant chaque fois le même modèle : numéro de machine en gros caractères, une courte ligne indiquant ce que fait le code (« Scannez pour payer W-04 », « Scannez pour signaler une panne sur D-12 »), et le code lui-même. Tenez une simple liste maîtresse — numéro de machine, destination du code et date d'impression — pour savoir exactement quels panneaux vérifier quand une machine est remplacée ou qu'un prix change. Enfin, ajoutez le code d'avis près de la sortie et le code d'objets trouvés au comptoir, et vérifiez à nouveau chaque code après le premier jour de grande affluence.

Bon à savoir

Chaque machine d'une laverie automatique doit-elle avoir son propre QR code ?

Oui, en règle pratique. Un code par machine, associé à un numéro de machine imprimé en gros, évite que paiements et signalements de panne aillent à la mauvaise machine. Un seul code pour tout le magasin ne peut pas dire de quelle machine à laver ou sèche-linge un client parle.

Un QR code peut-il démarrer une machine à laver ?

Pas tout seul. Un QR code est un raccourci vers une page, un formulaire ou un système de paiement. Il ne peut démarrer une machine que s'il renvoie vers un système de paiement de laverie connecté prenant en charge le démarrage par scan. Sinon, il ouvre une page utile pour cette machine, comme sa capacité, ses cycles, son prix et son formulaire de signalement de panne.

Un QR code peut-il afficher l'état d'un cycle en direct ?

Uniquement via un système de machine ou de paiement connecté qui suit le cycle et met la page à jour. Un code imprimé seul ne peut pas savoir combien de minutes il reste, ne promettez donc pas de suivi en direct sauf si votre système le fournit réellement.

Les codes de prix d'une laverie automatique doivent-ils être statiques ou dynamiques ?

Dynamiques. Les prix, les promotions et les services changent, et un code dynamique permet de modifier la destination derrière le code imprimé au lieu de réimprimer chaque étiquette de machine, chaque panneau et chaque prospectus.

Quel est le meilleur QR code pour le Wi-Fi d'une laverie automatique ?

Un code statique. Le nom et le mot de passe du réseau Wi-Fi changent rarement, il n'y a pas de promotion à mettre à jour, et vous n'avez pas besoin de statistiques de scan pour cela, donc un code fixe est plus simple et n'a rien derrière lui qui puisse expirer.

Puis-je offrir un lavage gratuit contre un avis Google ?

Non. La politique de Google interdit d'offrir des incitations en échange de la publication, de la modification ou de la suppression d'un avis. Invitez plutôt à un avis honnête sur une vraie visite, et assurez-vous que le code ouvre la bonne succursale.

Quelle taille doit faire un QR code sur une machine à laver ?

En règle empirique, au moins un dixième aussi large que la distance de scan, et jamais en dessous d'environ 2 sur 2 cm. Un code de machine scanné à bout de bras doit mesurer au moins 3 à 5 cm de large, avec une zone de silence blanche de 4 modules de chaque côté.

Comment protéger les QR codes d'une laverie automatique contre la vapeur et les mains mouillées ?

Plastifiez les étiquettes de machines ou imprimez-les sur un support essuyable, préférez une finition mate au brillant, éloignez les codes de la vapeur directe et des surfaces de sèche-linge les plus chaudes, et testez une étiquette à son emplacement réel avant d'imprimer tout le lot.
