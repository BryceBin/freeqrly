QR codes pour laveries automatiques : quoi mettre sur chaque machine, mur et reçu

une laverie automatique a besoin d’environ huit QR codes, chacun faisant un travail à un endroit — payer une machine précise, signaler cette machine quand elle tombe en panne, vérifier les horaires d’ouverture, rejoindre le Wi-Fi, déposer du linge à laver et plier, retrouver une chaussette perdue, gagner une récompense de fidélité, et laisser un avis en sortant. Les codes qui font gagner le plus de temps au personnel sont ceux liés à un numéro de machine, parce que « la machine 4 a avalé mes pièces » est un problème que vous pouvez résoudre, et « une machine a avalé mes pièces » est une conversation.

Les codes statiques conviennent à tout ce qui ne change jamais, comme le Wi-Fi ; les codes dynamiques conviennent à tout ce qui pourrait changer, comme les prix — et un code dynamique peut être modifié après impression.

Dans une laverie libre-service, le client fait le travail, le personnel n’est souvent pas dans la salle, et la visite dure assez longtemps pour que les petits problèmes deviennent de grandes frustrations. Les QR codes conviennent ici parce qu’ils répondent aux questions à l’endroit exact où la question se pose — mais seulement si chaque code fait un travail, le dit en mots simples, et ouvre une page qui fait ce que le panneau a promis.

La visite, minute par minute

Planifiez les codes autour de la visite du client plutôt que d’une liste de fonctions. Une visite typique en libre-service a cinq phases, et chacune produit des questions différentes :

Les codes qui comptent le plus sont ceux dont la question est entendue par le personnel trois fois par jour.

Ce qu’un code ne peut pas faire

Un code imprimé est un raccourci vers une page, un formulaire ou une étape de paiement. Il ne peut pas démarrer une machine à laver tout seul, et il ne peut pas dire à un client combien de minutes restent, sauf s’il renvoie vers un système de blanchisserie connecté qui suit cette machine. Certains systèmes de paiement offrent le démarrage par scan : scannez le code, choisissez un cycle, payez, et la machine démarre. Si le vôtre le fait, le code de la machine en est la porte d’entrée ; sinon, ne promettez pas de statut en direct sur vos panneaux.

Payer une machine sans la panique du monnayeur

Le paiement est le premier endroit où une visite en laverie peut mal tourner, et le moment où un client est le moins patient — il se tient devant une machine avec un panier plein, et l’étape de paiement est entre lui et le linge propre. La plupart des laveries aujourd’hui acceptent un mélange de pièces, de cartes, et d’une application de blanchisserie ou d’un portefeuille mobile. Le travail du code est de supprimer les tâtonnements, pas d’ajouter une nouvelle étape :

  • Scannez pour payer cette machine. Le code sur la machine W-04 ouvre une page de paiement pour W-04 — et le dit sur la page, dans la même grande typographie que le libellé. Le client voit le numéro de la machine, les options de cycle et le montant avant de confirmer quoi que ce soit.
  • Scannez pour obtenir de l’aide pour payer. Les pièces se bloquent, les cartes sont refusées, les applications demandent des mises à jour au pire moment. Un petit second code sur la machine qui ouvre un court guide « le paiement ne fonctionne pas ? » couvre la panne sans qu’une file se forme derrière le client.

Deux règles s’appliquent à chaque code de paiement. D’abord, ne mettez jamais d’identifiants de paiement, de détails de carte ou d’instruction de paiement dans le code lui-même — le code doit ouvrir une étape de paiement de confiance où le client peut voir le nom de l’entreprise, le numéro de la machine et le montant avant de confirmer. Ensuite, testez tout le parcours vous-même sur un vrai téléphone avant que le code n’aille sur une machine.

Quand une machine prend l’argent et ne fait rien

C’est la question de remboursement la plus courante dans toute laverie, et le code est ce qui la rend traitable. Un code de signalement de panne sur la machine doit ouvrir un formulaire qui sait déjà de quelle machine il s’agit — le numéro de machine pré-rempli — et ne demande que trois choses : ce qui s’est passé, si la machine est sûre à utiliser, et une coordonnée si le client veut une réponse sur un remboursement. Un signalement qui prend trente secondes est envoyé ; un signalement qui exige un compte et un mot de passe ne l’est pas.

Quelle est la taille de cette charge ? Un code par rangée de machines

Toutes les machines ne sont pas identiques, et les clients le savent — ils ne peuvent simplement pas dire de l’extérieur quelle machine prend une couette king-size et laquelle est pour une petite charge de vêtements de sport. Un court guide de taille de charge épargne à la fois le client et la machine : les machines surchargées lavent mal et tombent en panne plus tôt. La version la plus simple est un panneau au bout de chaque rangée : petites machines pour les charges quotidiennes, grandes machines pour la literie et les articles volumineux, avec un code renvoyant vers un guide d’un écran — la capacité en mots simples (« environ deux paniers de linge »), les cycles adaptés, et le prix pour chaque taille.

Des libellés clairs comptent plus que le design : mettez le numéro de la machine en gros caractères à côté du code — W-04, D-12 — et assurez-vous que la page que le code ouvre montre le même numéro.

L’attente de 35 minutes est un atout commercial

Un cycle de lavage dure environ une demi-heure, et le séchage en ajoute — 30 à 45 minutes pendant lesquelles votre client est assis dans votre magasin, à regarder son téléphone, sans rien faire. C’est le temps le plus précieux que vous ayez.

Un code Wi-Fi permet à un client de rejoindre le réseau en scannant, sans taper un long mot de passe depuis un panneau décoloré. Mettez le code là où les gens s’assoient — près des tables de pliage et des chaises — pas seulement près de la porte qu’ils dépassent en entrant. Le Wi-Fi est l’exemple le plus clair d’un travail pour un code statique : le nom de votre réseau et votre mot de passe changent rarement, et s’ils changent, réimprimer un ou deux panneaux de la zone d’attente est un petit travail. Mettez le Wi-Fi sur un réseau invité, séparé de votre système de paiement.

Un code « en attendant » transforme le temps mort en un petit service. Une courte page peut contenir les identifiants Wi-Fi pour les clients qui préfèrent taper le mot de passe, les cafés à proximité et les liens de commande à l’avance — le café deux portes plus loin, la boulangerie en face — avec les horaires d’ouverture et la durée de la marche, et une note honnête sur le timing des cycles : si votre système offre un statut en direct, renvoyez vers lui ; sinon, dites combien de temps durent un lavage et un séchage typiques et suggérez une alarme de téléphone.

Laver et plier : une deuxième activité dans le magasin

Laver et plier est un autre type de transaction : un client libre-service paie et part, tandis qu’un client laver et plier remet son linge et vous fait confiance. Chaque remise est une occasion pour quelque chose de se perdre : des sacs sans noms, des instructions spéciales que personne n’a notées, des heures de récupération dont personne ne se souvient. Deux codes couvrent toute la remise :

  • Dépôt. Un code au comptoir ouvre un formulaire demandant un nom, un moyen de contact, le nombre de sacs, et toute instruction — lavage à froid, pas de détergent parfumé, séchage à l’air des délicats — avant que le client ne parte. Gardez les détails personnels hors du QR code lui-même : le code ouvre un formulaire ou une page de commande protégée par connexion ; il n’encode jamais un nom de client ou un numéro de téléphone dans le motif imprimé.
  • Récupération. Le ticket de retrait ou le reçu porte un code qui ouvre une page montrant les horaires de récupération, quoi apporter, et comment contacter le magasin si une heure de récupération doit changer. Si votre système peut montrer le statut de la commande, renvoyez vers lui ; sinon, donnez le numéro de téléphone du comptoir à la place. L’objectif est moins d’appels demandant « mon linge est-il prêt ? », pas une page de statut qui devine.

Parce que les services, les horaires et les promotions de laver et plier changent avec le temps, ces codes doivent être dynamiques : une modification met à jour la destination derrière le code imprimé au lieu de réimprimer chaque modèle de ticket et panneau de comptoir. La même logique s’applique au tableau des prix.

Chaussettes perdues, téléphones retrouvés, et l’étagère que personne ne vérifie

Chaque laverie a une étagère d’objets trouvés, et la plupart y restent parce que personne ne sait quoi faire d’une seule chaussette, d’un chargeur de téléphone ou d’une veste laissée dans un sèche-linge. Un code au comptoir et près de la sortie peut ouvrir un simple formulaire d’objets perdus : ce qui a été perdu, dans quelle machine cela a pu être, et comment contacter le propriétaire. Gardez ce formulaire privé pour le personnel — ne publiez pas de photos ou de descriptions d’objets trouvés sur une page publique, où n’importe qui pourrait les réclamer — et n’encodez pas de détails personnels dans le code lui-même. Sur la même page, indiquez clairement combien de temps les articles sont gardés et quand ils peuvent être récupérés.

Les habitués : une fidélité qui survit à une poche détrempée

Une laverie vit de ses habitués — les mêmes visages chaque mardi soir, la même famille chaque dimanche matin. Les cartes à tampons papier fonctionnent jusqu’à ce qu’elles passent à la machine, ce qui, dans une laverie, n’est pas un accident rare. Un QR code peut remplacer la carte par un lien vers votre page de fidélité, où les clients peuvent voir l’offre actuelle et comment en profiter. Un exemple simple est « chaque dixième lavage gratuit » — considérez cela comme une illustration, pas une règle. Choisissez un seuil que vos marges peuvent supporter, écrivez-le en mots simples sur le panneau, et gardez le même libellé sur la page que le code ouvre.

Soyez honnête sur ce que le code fait ici. Les statistiques de scan peuvent vous dire combien de fois une page de fidélité a été ouverte ; à elles seules, elles n’identifient pas les clients individuels ni ne comptent les visites d’une personne. Une vraie fidélité par client nécessite un compte ou une application de fidélité derrière la page, avec le QR code comme moyen le plus simple de l’atteindre. Les offres de fidélité tournent, et c’est pourquoi ce code doit être dynamique.

La sortie : les avis au moment où ils sont mérités

Le meilleur moment pour demander un avis est quand le travail est bien fait — des machines propres, une charge pliée, un membre du personnel serviable — pas pendant qu’un client est encore en train de charger une machine. Mettez un code d’avis sur les tables de pliage, sur le reçu, ou près de la sortie, avec une courte invitation honnête comme « Bonne visite ? Dites-le aux autres ici. » Le code doit ouvrir directement votre page d’avis Google, pour que le client n’ait pas à chercher votre entreprise et choisir la bonne succursale — Google Business Profile fournit un lien de demande d’avis à cet effet.

N’offrez pas de réduction, de lavage gratuit, ou toute autre incitation en échange d’un avis. La politique de Google interdit les incitations pour publier, modifier ou supprimer un avis.

Propriétaires de plus d’un magasin

Un propriétaire d’un seul magasin peut se souvenir de quel panneau est où. Un propriétaire de trois ou cinq emplacements ne le peut pas — et une laverie multi-emplacements est l’endroit où les QR codes font soit économiser de l’argent réel, soit créer une vraie confusion.

  • Un modèle, chaque magasin. La même mise en page d’étiquette de machine, le même libellé, les mêmes tailles de code. Un client qui apprend le système dans votre premier magasin doit pouvoir utiliser le deuxième magasin sans le réapprendre.
  • Un code par machine par magasin, jamais partagé entre magasins. La machine W-04 du magasin de la rue Maple et la machine W-04 du magasin Riverside doivent ouvrir des pages différentes. Un signalement de panne pour la mauvaise succursale est pire que pas de signalement du tout. La génération en série — créer beaucoup de codes d’un coup à partir d’une liste de liens — est le moyen pratique de produire un ensemble complet par magasin.
  • Une liste maîtresse. Numéro de machine, magasin, destination du code, et date d’impression, dans une seule feuille. Quand une machine est remplacée ou qu’un prix change, la liste vous dit exactement quels panneaux vérifier.
  • Codes d’avis par succursale. Le code de sortie de chaque magasin doit ouvrir la page d’avis de ce magasin. Vérifiez-le après chaque réimpression, pas seulement la première.

Pour une chaîne, les codes dynamiques font leurs preuves à maintes reprises : un changement de prix, une promotion, une amélioration de formulaire, appliqués une fois, atteignent chaque panneau imprimé dans chaque magasin. Statique ou dynamique ? Deux questions décident

Pour chaque panneau, posez deux questions : cette page, ce prix ou cette offre aura-t-il un jour besoin de changer ? et ai-je besoin de savoir combien de fois il est scanné ? Si la réponse à l’une ou l’autre est oui, utilisez un code dynamique. Si la réponse aux deux est non, un code statique est plus simple et n’a rien derrière lui qui puisse expirer.

Imprimer pour une pièce pleine de vapeur, de chaleur et de mains mouillées

La vapeur, les mains humides, les éclaboussures de détergent et les machines chaudes recourberont, tacheront et décoloreront un panneau non protégé plus vite qu’un magasin sec ne le ferait jamais — alors testez une étiquette au vrai endroit avant d’en imprimer cinquante.

Taille. En règle générale, faites un code imprimé au moins un dixième aussi large que la distance à laquelle il sera scanné, et ne descendez jamais en dessous d’environ 2 × 2 cm. Pour les étiquettes de machines scannées à bout de bras, 3–5 cm de large est un minimum pratique ; les panneaux de comptoir et les chevalets de table de pliage fonctionnent à 5–10 cm ; une affiche murale ou un tableau des prix lu à un mètre nécessite environ 10 cm.

La zone de silence. Laissez une marge vierge de 4 modules de chaque côté, dans la même couleur claire que le fond du code, et gardez le texte et les bordures hors de celle-ci.

Contraste et format de fichier. Imprimez des modules foncés sur fond clair, et pour le travail d’impression utilisez un fichier vectoriel comme SVG, ou un PNG à 300 pixels par pouce à la taille finale, pour que les bords des modules restent nets.

Durabilité. Plastifiez les étiquettes de machines ou imprimez-les sur un support nettoyable, et choisissez une finition mate quand vous pouvez : les finitions brillantes peuvent refléter la lumière directement dans l’appareil photo et rendre le scan plus difficile. Gardez les codes loin des surfaces les plus chaudes et loin de la vapeur directe et des distributeurs de détergent. Mettez l’étiquette là où un client regarde naturellement : à côté de la fente de paiement ou du bouton de démarrage, avec le numéro de la machine à côté.

Testez comme un client. Avant un tirage complet, imprimez une épreuve à taille réelle, sur le matériau réel, plastifiez-la comme prévu, et scannez-la avec au moins un iPhone et un téléphone Android, depuis la distance réelle, sous le vrai éclairage du magasin.

Déploiement : une semaine, pas un jour

Ne réétiquetez pas tout le magasin le premier jour. Commencez par un pilote : deux ou trois machines, le code du comptoir, et le panneau Wi-Fi. Observez pendant une semaine — demandez au personnel ce que les clients ont demandé, quels codes ont été le plus scannés, et quels libellés se sont décollés, embués ou ont dérouté les gens. Corrigez d’abord le libellé et le placement, parce qu’un code qui ouvre la bonne page mais se trouve au mauvais endroit sera quand même ignoré. Puis déployez machine par machine, par lots, en utilisant le même modèle à chaque fois : numéro de machine en gros caractères, une courte ligne disant ce que fait le code, et le code lui-même. Enfin, ajoutez le code d’avis près de la sortie et le code d’objets trouvés au comptoir, et vérifiez chaque code à nouveau après la première ruée du jour de lavage.

Une liste de contrôle suggérée pour la première semaine :

  1. Parcourez le magasin et listez chaque question à laquelle le personnel répond à répétition. Chacune est un code candidat.
  2. Étiquetez les machines — les grands numéros d’abord, les codes ensuite.
  3. Construisez les pages de destination — courtes, adaptées au mobile, et honnêtes sur ce qu’elles peuvent et ne peuvent pas faire.
  4. Choisissez statique ou dynamique pour chaque panneau en utilisant les deux questions ci-dessus.
  5. Générez l’ensemble — génération en série pour une rangée complète de machines, export SVG pour l’impression.
  6. Imprimez un ensemble pilote et testez-le sur deux téléphones, à distance réelle, sous un vrai éclairage.
  7. Déployez par lots, gardez la liste maîtresse, et revérifiez après le premier week-end chargé.

Bien faits, les codes disparaissent dans la visite. Les clients paient sans faire la queue, signalent une panne en trente secondes, rejoignent le Wi-Fi sans demander, et laissent un avis en sortant. Bon à savoir

Chaque machine d'une laverie automatique doit-elle avoir son propre QR code ?

Oui. Un code par machine, associé à un grand numéro de machine imprimé, évite que les paiements et les signalements de panne aillent à la mauvaise machine.

Un QR code peut-il démarrer une machine à laver ?

Pas tout seul. Un QR code est un raccourci vers une page, un formulaire ou un système de paiement. Il ne peut démarrer une machine que lorsqu’il renvoie vers un système de paiement de blanchisserie connecté qui prend en charge le démarrage par scan.

Que dois-je faire si une machine prend mon argent et ne démarre pas ?

Scannez le code de signalement de panne sur cette machine et envoyez un court signalement : ce qui s’est passé, et une coordonnée si vous voulez une réponse sur un remboursement. Le formulaire connaît déjà le numéro de la machine, donc le personnel peut vérifier cette machine exacte.

Les codes de prix d'une laverie automatique doivent-ils être statiques ou dynamiques ?

Dynamique. Les prix, les promotions et les services changent, et un code dynamique vous permet de modifier la destination derrière le code imprimé au lieu de réimprimer chaque panneau. Il montre aussi les nombres de scans, pour que vous puissiez voir quels placements les clients utilisent vraiment.

Quel est le meilleur QR code pour le Wi-Fi d'une laverie automatique ?

Un code statique. Le nom et le mot de passe d’un réseau Wi-Fi changent rarement, et vous n’avez pas besoin de statistiques de scan pour cela, donc un code fixe est plus simple et n’a rien derrière lui qui puisse expirer. Mettez le code là où les gens s’assoient, sur un réseau invité.

Puis-je offrir un lavage gratuit contre un avis Google ?

Non. La politique de Google interdit d’offrir des incitations en échange de la publication, de la modification ou de la suppression d’un avis. Invitez plutôt à un avis honnête sur une vraie visite, avec un code près de la sortie.

Je gère trois laveries — puis-je utiliser les mêmes QR codes dans toutes ?

Non — pas les codes de machines. La machine W-04 de chaque magasin doit ouvrir la page de ce magasin, ou les signalements de panne et les paiements iront à la mauvaise succursale. Utilisez un modèle et une liste maîtresse pour tous les magasins, et donnez à chaque magasin son propre code d’avis pointant vers sa propre fiche Google Business.
