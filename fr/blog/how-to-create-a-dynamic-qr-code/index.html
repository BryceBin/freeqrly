Comment créer un QR code dynamique

Un QR code dynamique vous permet de changer la destination après impression — et de voir combien de personnes ont scanné. Voici comment en faire un, gratuitement, en environ une minute.

16 octobre 2026 · 4 min de lecture

Les codes statiques sont formidables — jusqu’à ce que la destination change. Le dépliant est imprimé, le menu a déménagé, l’URL de campagne n’était pas définitive. Un QR code dynamique règle cela : le motif imprimé reste le même, mais vous pouvez changer sa destination, à tout moment, depuis votre tableau de bord. Vous obtenez aussi le nombre de scans, pour savoir si quelqu’un scanne vraiment.

Sur FreeQrly, les codes dynamiques sont gratuits. Connectez-vous (e-mail, Google ou GitHub) et vous en recevez 8. Pas d’essai, pas de carte, pas de jeux d’expiration. Voici tout le processus.

  1. Connectez-vous — gratuit. Ouvrez la page de connexion et créez un compte avec e-mail + mot de passe, Google ou GitHub. Les codes statiques n’en ont jamais besoin ; les dynamiques, oui, parce que le code doit appartenir à quelqu’un.
  2. Basculez en Dynamique. Dans le studio, basculez de Statique à Dynamique. Tout le reste — types, style, téléchargement — fonctionne exactement pareil.
  3. Choisissez un type et remplissez-le. Site web, WiFi, contact, événement — les 12 types de contenu fonctionnent en codes dynamiques. (Le lot reste statique : un code dynamique par génération.)
  4. Personnalisez-le si vous voulez. Points, couleurs, logo, cadre — l’aperçu se met à jour en direct. Le style est enregistré avec le code, donc le tableau de bord et le téléchargement correspondent.
  5. Générer. Cliquez sur Générer. Vous obtenez un lien court comme freeqrly.com/q/XXXXXXX — c’est ce que le motif du QR encode. Imprimez-le, envoyez-le, collez-le au mur.
  6. Gérez-le plus tard. Vos codes vivent dans le tableau de bord : modifiez, consultez les statistiques, ou supprimez-en un pour libérer une place.

Ce que le QR code contient vraiment

Un code dynamique ne contient pas directement votre lien. Il contient un lien court FreeQrly, et notre serveur redirige ceux qui scannent vers votre destination. C’est le mécanisme qui rend l’édition et le comptage possibles — et c’est pourquoi les codes dynamiques ont besoin d’un compte, pas les statiques. Si un service vous dit un jour que ses codes « gratuits » ont besoin d’un compte, c’est ce mécanisme qui est à l’œuvre ; la différence ici, c’est que le compte est gratuit et que les codes ne meurent pas.

Les limites, clairement dites

  • 8 codes, gratuits. C’est le quota gratuit. Supprimez un code et la place se libère.
  • Un par un. Les codes dynamiques sont générés un par un ; la génération en lot reste statique.
  • Modifier change la destination, pas le motif. Le code imprimé continue de marcher à chaque modification — c’est tout l’intérêt.
