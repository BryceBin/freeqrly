Comment créer un QR code dynamique

Un QR code dynamique vous permet de changer la destination après impression — et de voir combien de personnes ont scanné. Voici comment en faire un, gratuitement, en environ une minute.

16 octobre 2026 · Dernière mise à jour : 3 novembre 2026 · 14 min de lecture

Oui : vous pouvez créer un QR code dynamique gratuitement, en une minute environ, et changer sa destination après l'avoir imprimé. Choisissez le dynamique quand la destination n'est pas encore définitive, quand vous voulez compter les scans, ou quand un même code imprimé devra renvoyer vers une nouvelle page le mois prochain. Choisissez le statique quand la destination ne changera jamais : un lien fixe, un mot de passe WiFi ou une carte de visite n'exigent ni compte ni redirection. Ce guide explique la démarche FreeQrly, le mécanisme de redirection en langage simple, et les limites gratuites sans détour.

Sur FreeQrly, les codes dynamiques sont gratuits. Connectez-vous avec e-mail et mot de passe, Google ou GitHub, et vous obtenez 20 codes dynamiques sur le compte gratuit, actuellement illimités pendant la promotion à durée limitée. Pas de période d'essai, pas de carte bancaire pour commencer, et des scans illimités. Vous pouvez modifier un code après impression, consulter ses statistiques de scan, générer des codes en lot sous forme statique, et utiliser l'API.

Dynamique ou statique ? Décidez avant d'imprimer

Une fois le code imprimé, il n'y a plus de retour en arrière. Un code statique contient la destination dans son motif, on ne peut donc jamais le rediriger ailleurs. Un code dynamique contient un lien court qui redirige vers la destination, qu'on peut donc modifier plus tard. Un code statique imprimé avec un mauvais lien exige une réimpression ; un code dynamique imprimé ne demande qu'une modification dans le tableau de bord.

Comment un code dynamique fonctionne vraiment

Un code dynamique ne contient pas directement votre lien. Il contient un lien court FreeQrly, de la forme freeqrly.com/q/XXXXXXX, et c'est ce lien court que le motif encode. Quand quelqu'un scanne le code, son téléphone ouvre le lien court, le serveur FreeQrly retrouve la destination que vous avez définie, et la personne est redirigée vers elle. Elle arrive sur votre page ; le lien court n'est que le carrefour au milieu.

Ce carrefour explique chaque fonction et chaque limite :

  • La modification marche parce que le motif ne change jamais. Le motif ne contient que le lien court. Modifier change la fiche derrière lui, donc chaque exemplaire imprimé sert la nouvelle destination dès le scan suivant.
  • Le comptage marche parce que chaque scan passe par le carrefour. Le serveur voit le scan en route vers la destination et l'ajoute aux statistiques. Un code statique ne touche jamais un serveur, il n'y a donc rien à compter.
  • Un compte est requis parce que le carrefour doit appartenir à quelqu'un. Seul le compte créateur peut changer la destination de son lien court. Sans propriétaire, n'importe qui pourrait rediriger le code imprimé d'un autre.
  • La suppression est définitive parce que le carrefour est retiré. Supprimez un code et son lien court cesse de rediriger, donc les exemplaires imprimés cessent de fonctionner. Pas de retour en arrière, et la place libérée peut servir à un nouveau code.

Ceux qui scannent ne voient rien de tout cela : ils visent, touchent l'aperçu, et arrivent sur votre page. Une chose peut les frapper : une redirection qui affiche d'abord une publicité ou une page à la marque du fournisseur. Quand vous comparez des générateurs, scannez donc un code d'essai et regardez ce qui s'affiche avant le chargement de votre destination.

Pas à pas : créer un QR code dynamique

  1. Connectez-vous — gratuit. Ouvrez la page de connexion et créez un compte avec e-mail et mot de passe, Google ou GitHub. Les codes statiques n'en ont jamais besoin ; les dynamiques, oui, parce que le code doit appartenir à quelqu'un qui seul peut le modifier.
  2. Basculez en Dynamique. Dans le studio, passez de Statique à Dynamique. Types, style et téléchargement fonctionnent exactement pareil.
  3. Choisissez un type et remplissez-le. Site web, WiFi, contact, événement : les 17 types de contenu fonctionnent en codes dynamiques. (La génération en lot reste statique : un code dynamique par génération, parce que chacun exige son propre lien court et sa propre fiche dans le tableau de bord.)
  4. Personnalisez-le si vous voulez. Points, couleurs, logo, cadre : l'aperçu se met à jour en direct, et le style est enregistré avec le code, donc la miniature du tableau de bord et le téléchargement correspondent. Gardez un contraste fort et ne recouvrez jamais les trois grands carrés de repérage dans les coins.
  5. Générer. Cliquez sur Générer. Vous obtenez un lien court comme freeqrly.com/q/XXXXXXX — c'est ce que le motif encode. Nommez le fichier téléchargé d'après l'endroit où le code vivra, par exemple cafe-window-menu.png.
  6. Gérez-le plus tard. Vos codes vivent dans le tableau de bord : modifiez, consultez les statistiques, ou supprimez-en un pour libérer une place. Testez le code imprimé avec l'appareil photo de votre téléphone avant un tirage complet, et à nouveau après chaque modification.

Choisir le type

Le type décide ce que la personne qui scanne voit et fait. Un code Site web ouvre une page. Un code WiFi propose de rejoindre un réseau. Un code Contact propose d'enregistrer une personne. Un code Événement propose d'enregistrer une date. Le bon type supprime une étape, et cela vaut généralement plus qu'un design plus malin. Un restaurant devrait utiliser un code Site web pointant vers sa page de menu, pas un code texte contenant le menu : la page peut être mise à jour, le code texte non. Un code WiFi invité devrait être un code WiFi, parce que le téléphone peut rejoindre le réseau dès le scan — voir comment partager le WiFi avec un QR code.

Pointez vers une page que vous contrôlez, pas vers un fichier hébergé quelque part hors de votre contrôle : un fichier supprimé laisse un code qui fonctionne mais ne pointe vers rien. Et notez qu'un long texte donne un motif plus dense, qui exige une taille d'impression plus grande pour être scanné à la même distance ; voir le guide des tailles d'impression des QR codes.

Personnaliser sans casser le scan

Les codes dynamiques acceptent le même style que les codes statiques : formes de points, couleurs, logo au centre, cadre avec texte. Trois règles gardent un code personnalisé lisible. D'abord, gardez un contraste élevé et un fond clair ; les lecteurs lisent des modules foncés sur fond clair. Ensuite, gardez le logo modeste et centré, et ne recouvrez jamais un carré de repérage. La correction d'erreur reconstruit les modules cachés derrière un petit logo central — au niveau Élevé de la norme ISO/IEC 18004, environ 30 % des mots de code peuvent être restaurés — mais ce budget couvre tous les dégâts cumulés, usure d'impression et saleté comprises, pas le logo seul. Enfin, gardez la zone de silence : la marge blanche autour du code, d'au moins 4 modules de large sur les quatre côtés selon ISO/IEC 18004, fait partie du code, ce n'est pas de la décoration. Pour en savoir plus sur les logos, voir comment ajouter un logo à un QR code.

Pour l'impression, testez une vraie épreuve imprimée, pas seulement l'aperçu à l'écran : un exemplaire à la taille prévue, sur le matériau prévu, scanné sur deux téléphones différents — un iPhone et un Android si possible — dans la lumière où il sera réellement utilisé. Un pelliculage brillant sous une lumière vive et un code enroulé autour d'une bouteille échouent d'une façon qu'un aperçu à l'écran ne montre jamais. Si l'épreuve scanne lentement, imprimez plus grand ; la taille est le correctif le moins cher qui soit.

Lire les statistiques honnêtement

Chaque code dynamique remonte dans votre tableau de bord : total des scans, scans du jour, scans uniques, et graphique sur sept jours, avec des répartitions par pays, ville, appareil et système d'exploitation. Le guide complet est dans ce que les statistiques des QR codes dynamiques vous apprennent. Trois habitudes comptent le plus. Comparez les codes entre eux, pas à un repère imaginaire : un code en vitrine et un code sur un colis de livraison vivent dans des mondes différents. Traitez le zéro comme une donnée : un code sans scan pendant une semaine veut généralement dire que l'emplacement est mauvais, que l'appel à l'action manque, ou que le code est trop petit. Et donnez un contexte aux pics : une rafale de scans juste après la publication d'un post, c'est le post, pas l'affiche.

Les statistiques FreeQrly sont uniquement des agrégats — des comptes par jour, pays, ville, appareil et système d'exploitation — sans fiche par visiteur et sans moyen d'identifier une personne qui scanne. Un scan unique est compté avec un hachage à sens unique, pas un nom ni une adresse.

Les cas où le dynamique vaut vraiment le coup

Un menu de restaurant qui change avec les saisons

Imprimez un seul code sur les chevalets de table et pointez-le vers la page du menu. Quand la saison change, mettez la page à jour ou redirigez le code — les chevalets restent. Voir les QR codes pour les restaurants.

Une affiche d'événement imprimée avant que les détails soient définitifs

Les affiches partent à l'impression des semaines avant que le lieu, le lien de billetterie ou le programme soient figés. Un code dynamique permet à l'affiche de sortir en pointant vers une page d'attente, puis de passer à la page de billetterie à l'ouverture des ventes, et à une page de bilan après l'événement. Voir les QR codes pour les événements.

Un produit ou un emballage qui survit à sa première campagne

L'emballage est imprimé en masse et vendu pendant des mois ou des années. Un code dynamique sur l'emballage peut commencer par une offre de lancement, passer à une page de mode d'emploi ou de garantie, puis à un produit successeur — sans réimpression. Gardez une liste de l'endroit où vit chaque code : un code introuvable dans le tableau de bord est un code qu'on ne peut pas corriger.

Un code par emplacement, sinon les chiffres mentent

Donnez à chaque emplacement son propre code. Partager un code entre un dépliant, une carte de visite et un stand de marché fusionne leurs statistiques en un seul chiffre qui n'explique rien. Un code près de la caisse qui ouvre une page d'avis fonctionne pareil ; voir comment obtenir des avis Google avec un QR code.

La question honnête pour n'importe quel générateur, FreeQrly compris, est : qu'arrive-t-il exactement à un code imprimé si je ne paie jamais, si j'arrête de payer, et si je supprime le code ? La réponse devrait tenir en une phrase chacune, sur la page de tarifs.

Une dépendance mérite d'être dite clairement. Un code dynamique dépend du service de redirection du fournisseur tant qu'il circule — c'est vrai ici aussi. Si ce service disparaissait, les codes dynamiques cesseraient de rediriger, tandis que les codes statiques, qui contiennent la destination dans le motif, continueraient de fonctionner. C'est pourquoi le statique convient à tout ce qui doit marcher pendant des décennies sans personne pour l'entretenir, comme un panneau permanent. Le dynamique est pour du matériel vivant que quelqu'un suit encore ; le statique est pour du matériel qui doit se débrouiller seul.

Les erreurs qui gâchent un tirage

  • Imprimer en statique alors que le lien n'était pas définitif. Si la destination peut changer, le code aurait dû être dynamique avant l'impression ; un code statique imprimé ne peut pas être sauvé par une modification.
  • Partager un code dynamique entre plusieurs emplacements. Un code, un emplacement, un relevé statistique — sinon les chiffres ne peuvent pas dire quel emplacement a marché.
  • Supprimer un code pour « faire du rangement ». La suppression est définitive et les exemplaires imprimés s'arrêtent net. Redirigez d'abord un code en fin de vie vers une page de clôture, et ne supprimez que quand plus aucun exemplaire imprimé ne circule.
  • Sauter l'épreuve imprimée. Un aperçu à l'écran prouve le design ; seule une épreuve imprimée à la vraie taille, sur le vrai matériau et dans la vraie lumière prouve le scan. Voir pourquoi votre QR code ne fonctionne pas.
  • Oublier l'appel à l'action. Un code nu demande à ceux qui scannent de deviner. Un cadre qui dit ce qu'ils obtiennent — menu, billets, WiFi, réduction — transforme une décoration en porte d'entrée.

Faut-il un compte pour un QR code dynamique ?

Vers quoi pointe un QR code dynamique ?

Un lien court FreeQrly (freeqrly.com/q/XXXXXXX) qui redirige vers votre destination. Ceux qui scannent arrivent sur votre page ; la redirection est ce qui rend l'édition et les statistiques de scan possibles.

Puis-je modifier un QR code dynamique après impression ?

Oui. Modifier change la destination derrière le lien court, pas le motif imprimé, donc chaque exemplaire imprimé sert la nouvelle destination dès le scan suivant. Testez à nouveau le code après chaque modification.

Quand choisir le statique plutôt que le dynamique ?

Quand la destination ne changera jamais — un lien fixe, un mot de passe WiFi, une carte de visite. Les codes statiques contiennent la destination dans le motif lui-même, n'exigent pas de compte, et continuent de fonctionner sans service de redirection à entretenir.

Puis-je créer des codes dynamiques en lot ?

Non : les codes dynamiques sont générés un par un, parce que chacun exige son propre lien court et sa propre fiche dans le tableau de bord. La génération en lot reste statique.

Qu'arrive-t-il à mes scans si un code devient populaire ?

Rien de grave sur FreeQrly : les scans sont illimités, donc un code populaire ne cesse pas de fonctionner parce qu'il a été trop scanné. Sur les offres gratuites d'autres fournisseurs, un plafond de scans peut arrêter un code — vérifiez la page de tarifs ou de FAQ du fournisseur avant d'imprimer.
