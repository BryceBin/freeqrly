Les QR codes expirent-ils ?

Réponse courte : non — du moins, pas ceux que vous créez ici. La réponse longue vaut la peine d’être connue avant d’en imprimer un millier.

13 octobre 2026 · Dernière mise à jour : 3 novembre 2026 · 15 min de lecture

Réponse courte : non — du moins, pas ceux que vous créez ici. Un QR code statique ne peut pas expirer, parce qu'il n'y a pas d'horloge dans ces petits carrés. Un code statique, c'est juste votre lien, dessiné en motif. Tant que le lien fonctionne, le code fonctionne — imprimez-le aujourd'hui, scannez-le dans dix ans. Ce qui cesse vraiment de fonctionner, c'est autre chose qui porte le même nom : un code dynamique payant dont l'abonnement a pris fin, un lien supprimé, ou une impression abîmée au point d'être illisible. Chacune de ces pannes exige un correctif différent, et une seule d'entre elles justifie d'acheter quoi que ce soit.

La confusion se comprend, parce que l'avertissement arrive généralement à côté d'une page de tarifs : « les QR codes gratuits expirent ! » Ce qui expire dans cette phrase, c'est rarement le code. C'est l'essai gratuit, l'abonnement, ou la volonté du fournisseur de continuer à rediriger vos scans gratuitement.

Alors pourquoi dit-on que les QR codes expirent ?

Trois choses différentes s’emmêlent :

  • Les codes dynamiques meurent quand vous arrêtez de payer. Beaucoup de générateurs « gratuits » créent en fait des codes dynamiques : au lieu de votre lien, le motif contient une URL courte sur leur serveur, qui redirige vers votre lien. Arrêtez de payer, et ils coupent la redirection. Votre code n'a pas expiré — il a été pris en otage.
  • Les liens pourrissent ; les codes, non. Si la page derrière le code est supprimée, le scan ne mène nulle part. C'est la destination qui meurt, pas le code. Un QR code pointant vers un lien mort est un code en parfaite santé qui n'a rien à dire.
  • Les comptes d'essai sont désactivés. Certains services lient vos codes à un compte, puis vous poussent vers un abonnement. Le code n'a pas expiré — c'est le compte qui a expiré.

Il y a un quatrième cas qui ressemble à une expiration mais n'est pas la faute du motif : les codes émis par le système de quelqu'un d'autre. Une carte d'embarquement, un billet ou un code de connexion à usage unique peut cesser de fonctionner parce que l'émetteur invalide la session, le billet ou la réservation derrière lui. Le motif reste lisible ; le système derrière lui a retiré l'autorisation. C'est une propriété des billets et des connexions, pas des QR codes en général.

Un motif sans horloge dedans

Le QR code a été développé en 1994 par DENSO WAVE pour dépasser les limites des codes-barres sur les lignes de production : les codes-barres alors utilisés ne pouvaient contenir qu'une vingtaine de caractères alphanumériques, alors que le suivi des pièces en exigeait bien plus. Le QR code qui les a remplacés pouvait stocker jusqu'à environ 7 000 caractères et a été diffusé avec des brevets et des spécifications ouverts, pour que tout le monde puisse l'utiliser. Le format a été conçu comme un moyen de transporter des données, pas comme un service avec un compte ou une date de renouvellement. L'édition actuelle de sa norme, ISO/IEC 18004:2024, spécifie la symbologie, l'encodage et les règles de correction d'erreur — et elle ne contient ni minuteur, ni vérification de licence, ni date d'expiration, parce qu'un motif imprimé n'a nulle part où en stocker une et personne à qui en rendre compte.

C'est pourquoi le point de vue FreeQrly découle du design, pas d'un argument marketing. Chaque code statique créé ici est gratuit, et à vous — pas de compte, pas de serveur de redirection, rien à annuler. Il n'existe simplement aucun mécanisme par lequel il pourrait expirer. Le papier peut s'estomper, se déchirer ou être jeté, mais on ne peut pas l'éteindre à distance.

Statique vs dynamique, en un paragraphe

Un code statique encode la destination directement : WIFI:T:WPA;S:MyCafe;P:secret;; ou https://your-site.com/menu. Rien à entretenir, rien à facturer. Un code dynamique encode une redirection sur le serveur de quelqu'un, ce qui permet au propriétaire de changer la destination plus tard et de compter les scans. Utile pour les campagnes marketing — et un abonnement tant que le code doit continuer de fonctionner. La comparaison complète, avec les cas où chacun l'emporte, est dans QR codes statiques ou dynamiques.

Règle générale : si la destination ne changera jamais — votre WiFi, votre carte de visite, votre menu de restaurant — le statique n'est pas l'option bon marché. C'est la bonne option.

Étapes : découvrez quelle panne vous avez

  1. Ouvrez la destination directement. Tapez le lien dans un navigateur, sans scanner. Si la page elle-même manque, le code est innocent : restaurez la page ou, pour un code dynamique, redirigez-le. Si la page se charge, le problème vient du code, de l'impression ou de la redirection.
  2. Scannez une épreuve imprimée sur deux téléphones. Un iPhone et un Android si possible. Si aucun ne le lit, suspectez la taille, le contraste, les dégâts ou une zone de silence rognée. Si un seul le lit, l'impression est limite — réimprimez plus grand plutôt que de faire confiance au téléphone qui a marché.
  3. Lisez l'aperçu du scan, pas seulement le résultat. Avant de toucher, regardez l'URL que votre téléphone affiche. Un domaine court de fournisseur là où vous attendiez le vôtre veut dire qu'une redirection dynamique s'interpose. Une page de mise à niveau du fournisseur veut dire que la redirection a été coupée. Un domaine étrange veut dire un autocollant ou une contrefaçon, pas une expiration.
  4. Vérifiez le compte et l'offre derrière un code dynamique. Connectez-vous au compte créateur et vérifiez si l'offre est active, si le code est dans son quota de scans, et s'il n'a pas été supprimé. Supprimer un code dynamique arrête ses exemplaires imprimés d'un coup, chez n'importe quel fournisseur, parce que la redirection est retirée.
  5. Corrigez la bonne couche. Problème d'impression : réimprimez. Page morte : restaurez la page. Redirection morte : renouvelez, ou remplacez le code par un code statique pointant vers une page que vous contrôlez.

Ce qui va vraiment mal avec les codes imprimés

Puisque l'expiration n'existe pas, surveillez plutôt ceci :

  • Impression trop petite. En règle générale, gardez les codes d'au moins 2 × 2 cm avec une marge calme. Les petits codes sur cartes de visite sont un échec de scan courant. Le guide complet des tailles, distance comprise, est dans le guide des tailles d'impression des QR codes.
  • Faible contraste. Encre foncée sur fond clair. Ce code de mariage champagne-sur-crème est beau et illisible.
  • Dégâts. Les codes extérieurs s'estompent et se rayent. Une correction d'erreur plus élevée aide : FreeQrly utilise le niveau M par défaut et l'augmente automatiquement quand vous ajoutez un logo. Au niveau Élevé de la norme ISO/IEC 18004, environ 30 % des mots de code peuvent être restaurés — des mots de code, pas de la surface visible, donc « 30 % de dégâts » induit en erreur. Une petite rayure sur un carré de repérage, le grand carré d'angle que le lecteur utilise pour localiser le code, peut bloquer un scan même quand le motif semble intact dans sa plus grande partie.
  • Pas de zone de silence. La marge blanche autour du code, d'au moins 4 modules de large sur les quatre côtés selon ISO/IEC 18004, fait partie du code. Du texte ou un design tassé dedans empêche les lecteurs de trouver les bords.
  • Changements de lien. Vous déménagez votre site ? L'ancien code pointe toujours vers l'ancienne URL. Gardez une liste de l'endroit où vit chaque code — ou utilisez un code dynamique et redirigez-le au lieu de réimprimer. Liste complète : pourquoi votre QR code ne fonctionne pas.

Scénarios : quels codes devraient survivre à leur créateur

Une carte de visite

Une carte de visite est imprimée une fois et distribuée pendant des années. Un code statique contenant une carte de contact ou une page personnelle est le bon choix : pas de compte à entretenir, pas de redirection à continuer de payer, et personne qui puisse l'éteindre. Si l'intitulé du poste change, la carte est réimprimée de toute façon, donc la destination figée du code ne coûte rien.

Une invitation de mariage

Les invitations partent des mois avant le jour J, et les invités les gardent sur le frigo longtemps après. Un code statique vers une page RSVP que vous contrôlez fonctionnera encore quand les remerciements partiront, à condition que la page reste en ligne. Un code dynamique fonctionne aussi, mais seulement si quelqu'un s'occupe encore du compte dans un an — pour un événement d'un jour, la permanence bat la possibilité de modifier. Voir les QR codes RSVP de mariage et les QR codes gratuits qui n'expirent pas.

Un menu de restaurant ou une vitrine

Ici le choix se joue sur une question : la destination change-t-elle ? Une page de menu que vous mettez à jour sur place n'a besoin que d'un code statique pointant vers cette page — mettez la page à jour, pas le code. Un menu qui change de plateforme, ou une offre en vitrine qui change chaque mois, mérite un code dynamique, parce que réimprimer un panneau de vitrine chaque mois est l'option coûteuse. Voir les QR codes pour les restaurants.

Une affiche de campagne avec une échéance

Une affiche est le cas dynamique classique : elle doit s'imprimer avant que la page de destination soit définitive, et plus tard elle peut pointer vers un bilan ou une liste d'attente. Mais c'est aussi là que le piège de l'abonnement mord le plus fort, parce que l'affiche peut encore être sur les murs des mois après l'épuisement du budget de campagne. Avant d'imprimer un code de campagne chez un fournisseur, lisez ce que ce fournisseur fait à la fin de l'offre, et envisagez de pointer, en statique, vers une page de campagne qui vous appartient.

Un emballage vendu pendant des années

L'emballage est l'impression qui vit le plus longtemps, et le pire endroit pour un code dépendant d'un abonnement. Un code statique vers une page produit que vous contrôlez survit aux changements d'équipe et aux cycles budgétaires, parce que rien en lui n'a besoin d'être renouvelé. Un code dynamique sur un emballage ne se justifie que si la destination doit vraiment changer pendant la vie du produit, et si quelqu'un se charge de garder ce compte en vie pendant toute la durée de vie du produit en rayon.

Une remarque de sécurité que le débat sur l'expiration oublie généralement

Un code qui scanne n'est pas forcément un code en qui avoir confiance. Dans une alerte aux consommateurs datée du 6 décembre 2023, la Federal Trade Commission américaine a averti que des escrocs collent leurs propres autocollants QR par-dessus de vrais codes sur les parcmètres, et envoient des QR codes dans des messages inattendus en inventant des raisons urgentes de scanner — une livraison manquée, un problème de compte, un mot de passe à changer. Le code d'un escroc peut mener à un site contrefait ou à un logiciel malveillant. Le conseil de la FTC est la meilleure habitude : inspectez l'aperçu de l'URL avant d'ouvrir un code dans un endroit inattendu, cherchez les fautes d'orthographe ou une lettre échangée, et ne scannez pas un code venu d'un message inattendu qui presse d'agir vite — contactez plutôt l'entreprise par un numéro ou un site que vous connaissez déjà. Pour vos propres codes, vérifiez l'aperçu après chaque modification.

Bon à savoir

Les QR codes gratuits expirent-ils ?

Non, s'ils sont statiques. Un QR code statique gratuit dure aussi longtemps que le lien vers lequel il pointe. Les codes qui cessent de fonctionner sont généralement des codes dynamiques liés à un abonnement payant — le fournisseur coupe la redirection quand vous arrêtez de payer — ou des codes pointant vers une page supprimée.

Un QR code peut-il cesser de fonctionner ?

Oui, mais pas à cause de l'expiration. Les causes habituelles sont : la page de destination a été supprimée, le code a été imprimé trop petit ou à faible contraste, il a été physiquement endommagé, sa zone de silence a été rognée, ou une offre dynamique a pris fin ou a atteint un plafond de scans.

Combien de temps durent les QR codes statiques ?

Indéfiniment, tant que la destination fonctionne encore. Le motif encode vos données directement sans aucun serveur, il n'y a donc rien à entretenir ni à renouveler.

Qu'arrive-t-il aux codes dynamiques payants à la fin d'un abonnement ?

Cela dépend du fournisseur, et la page FAQ du fournisseur est la source à vérifier. La FAQ de QR TIGER dit que les codes payants ont des scans illimités tant que l'abonnement est valide et « If your plan expires, it will stop working ». The QR Code Generator dit qu'après un essai, 2 codes restent actifs mais affichent des publicités, tandis que sur sa plateforme mère Uniqode les codes d'essai deviennent inactifs sans offre payante.

Une limite de scans peut-elle arrêter un QR code ?

Oui, chez les fournisseurs qui plafonnent les scans dynamiques gratuits. L'offre freemium de QR TIGER, selon sa propre page d'abonnement, donne 3 codes dynamiques avec une limite de 500 scans chacun. Un code qui atteint son plafond cesse de servir sa destination même si le motif est intact. Les codes dynamiques FreeQrly ont des scans illimités.

Les dégâts tuent-ils un QR code ?

Pas toujours. La correction d'erreur peut reconstruire des données manquantes : au niveau Élevé de la norme ISO/IEC 18004, environ 30 % des mots de code peuvent être restaurés. Cela compte des mots de code, pas de la surface visible — une petite rayure sur un carré de repérage d'angle peut bloquer un scan même quand le motif semble intact dans sa plus grande partie.

Comment distinguer un lien mort d'un abonnement mort d'une mauvaise impression ?

Ouvrez la destination directement dans un navigateur ; scannez une épreuve imprimée sur deux téléphones ; lisez l'URL de l'aperçu du scan avant de toucher ; et, pour un code dynamique, vérifiez l'offre et le quota de scans du compte créateur. Chaque vérification pointe vers une couche différente, et chaque couche a un correctif différent.

Un panneau permanent ou un emballage doit-il utiliser le statique ou le dynamique ?

Statique, si la destination est fixe. Un code statique vers une page que vous contrôlez n'exige ni compte ni renouvellement, il survit donc aux changements d'équipe et aux cycles budgétaires. N'utilisez le dynamique que si la destination doit vraiment changer et si quelqu'un gardera le compte en vie pendant toute la vie du code.
