Les QR codes expirent-ils ?

Réponse courte : non — du moins, pas ceux que vous créez ici. La réponse longue vaut la peine d’être connue avant d’en imprimer un millier.

13 octobre 2026 · 4 min de lecture

Vous avez vu les avertissements : « les QR codes gratuits expirent ! » Généralement juste à côté d’une page de tarifs. Alors réglons ça clairement : un QR code statique ne peut pas expirer. Il n’y a pas d’horloge dans ces petits carrés. Un code statique, c’est juste votre lien, dessiné en motif. Tant que le lien fonctionne, le code fonctionne — imprimez-le aujourd’hui, scannez-le dans dix ans.

Alors pourquoi dit-on que les QR codes expirent ?

Trois choses différentes s’emmêlent :

  • Les codes dynamiques meurent quand vous arrêtez de payer. Beaucoup de générateurs « gratuits » créent en fait des codes dynamiques : au lieu de votre lien, le motif contient une URL courte sur leur serveur, qui redirige vers votre lien. Arrêtez de payer, et ils coupent la redirection. Votre code n’a pas expiré — il a été pris en otage.
  • Les liens pourrissent ; les codes, non. Si la page derrière le code est supprimée, le scan ne mène nulle part. C’est la destination qui meurt, pas le code. Un QR code pointant vers un lien mort est un code en parfaite santé qui n’a rien à dire.
  • Les comptes d’essai sont désactivés. Certains services lient vos codes à un compte, puis vous poussent vers un abonnement. Le code n’a pas expiré — c’est le compte qui a expiré.

Statique vs dynamique, en un paragraphe

Un code statique encode la destination directement : WIFI:T:WPA;S:MyCafe;P:secret;; ou https://your-site.com/menu. Rien à entretenir, rien à facturer. Un code dynamique encode une redirection sur le serveur de quelqu’un, ce qui permet au propriétaire de changer la destination plus tard et de compter les scans. Utile pour les campagnes marketing — et un abonnement pour toujours.

Règle générale : si la destination ne changera jamais — votre WiFi, votre carte de visite, votre menu de restaurant — le statique n’est pas l’option bon marché. C’est la bonne option.

Ce qui va vraiment mal avec les codes imprimés

Puisque l’expiration n’existe pas, voici ce qu’il faut vraiment surveiller :

  • Impression trop petite. En règle générale, gardez les codes d’au moins 2 × 2 cm avec une marge calme. Les petits codes sur cartes de visite sont un échec de scan courant.
  • Faible contraste. Encre foncée sur fond clair. Ce code de mariage champagne-sur-crème est beau et illisible.
  • Dégâts. Les codes extérieurs s’estompent et se rayent. Une correction d’erreur plus élevée (nous utilisons M par défaut, et nous l’augmentons automatiquement quand vous ajoutez un logo) permet à un code de survivre à jusqu’à 30 % de dégâts au niveau Élevé défini dans ISO/IEC 18004.
  • Changements de lien. Vous déménagez votre site ? L’ancien code pointe toujours vers l’ancienne URL. Gardez une liste de l’emplacement de chaque code.

Bon à savoir

Les QR codes gratuits expirent-ils ?

Non. Un QR code statique gratuit dure aussi longtemps que le lien vers lequel il pointe. Les codes qui « expirent » sont des codes dynamiques liés à un abonnement payant — le fournisseur les coupe quand vous arrêtez de payer.

Un QR code peut-il cesser de fonctionner ?

Oui, mais pas à cause de l’expiration. Les causes habituelles : la page de destination a été supprimée, le code a été imprimé trop petit ou à faible contraste, ou il a été physiquement endommagé.

Combien de temps durent les QR codes statiques ?

Indéfiniment. Le motif encode vos données directement sans aucun serveur impliqué, donc il n’y a rien à entretenir ni à renouveler.
