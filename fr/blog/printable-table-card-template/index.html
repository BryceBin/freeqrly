Cartes de table imprimables pour WiFi, avis et menus

Imprimez une carte, posez-la sur la table, et laissez les clients scanner au lieu de demander. Ce modèle vous offre trois cartes prêtes à l'emploi — choisissez celle dont vous avez besoin, déposez-y votre propre QR code, et imprimez.

4 novembre 2026 · 4 min de lecture

Les cartes de table fonctionnent parce que les clients sont déjà assis avec un téléphone en main. Une courte ligne de texte et un QR code clair suffisent — pas d'application à installer, rien à expliquer. Ce modèle couvre les trois demandes que les cafés et restaurants entendent le plus : le mot de passe WiFi, un avis, et le menu.

Chaque carte ci-dessous mesure 105 × 148 mm (A6), elle s'adapte donc à un présentoir de table standard ou un porte-carte plié. Pour l'utiliser : générez votre QR code, collez-le dans l'emplacement pointillé de la carte voulue, imprimez sur du papier cartonné, et découpez le long du bord. N'imprimez que la carte dont vous avez besoin — il n'est pas nécessaire d'imprimer les trois. Si vos détails WiFi peuvent changer, voir comment partager le WiFi avec un QR code ; pour la carte d'avis, obtenir des avis Google avec un QR code explique comment renvoyer directement vers votre page d'avis. Plus d'idées pour utiliser les codes dans une salle à manger sont dans QR codes pour restaurants, et parcourez la checklist pré-impression avant un grand tirage.

Astuce : utilisez un QR code dynamique pour la carte de menu si votre menu change. Ainsi la carte imprimée n'a jamais besoin d'être réimprimée — voir comment modifier un QR code après impression.

Bon à savoir

Sur quel papier dois-je imprimer les cartes de table ?

Le papier ordinaire convient pour un test rapide, mais le papier cartonné (environ 250–300 g/m²) tient dans un présentoir et survit à un service chargé. Si la carte restera près de boissons, plastifiez-la — puis testez son scan, car le brillant peut produire des reflets sous les projecteurs.

Puis-je les imprimer en noir et blanc ?

Oui. Les cartes sont conçues pour que le texte et l'emplacement QR se lisent bien sans couleur ; les en-têtes colorés s'impriment simplement en gris. Ce qui compte est le contraste : un code sombre sur fond clair, jamais l'inverse.

Comment placer mon propre QR code dans l'emplacement pointillé ?

Générez votre code, imprimez-le à 30 × 30 mm, et collez-le sur la case pointillée dans votre outil de mise en page — ou imprimez la carte, puis collez une étiquette de code imprimée sur l'emplacement. Dans tous les cas, testez le scan de la carte finie avant d'imprimer tout le tirage.

Quelle taille le QR code doit-il faire ?

30 × 30 mm est dimensionné pour un client scannant depuis sa place, à environ 30–50 cm. Ne le réduisez pas pour caser plus de texte ; un code trop petit pour sa distance est la raison la plus fréquente d'échec d'un code imprimé.

Puis-je imprimer une seule des trois cartes ?

Oui — c'est l'intérêt. Choisissez la carte dont vous avez besoin, imprimez cette page ou recadrez jusqu'à cette carte, et ignorez les deux autres. Chaque carte est une carte autonome de 105 × 148 mm (A6).

Mon menu change souvent. Dois-je réimprimer à chaque fois ?

Non si vous utilisez un QR code dynamique pour la carte de menu : la destination derrière le code peut être mise à jour tandis que la carte imprimée reste la même. Une carte WiFi peut rester statique sauf si votre mot de passe change.
