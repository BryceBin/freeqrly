Comment scanner un QR code avec son téléphone

Aucune app à installer — votre téléphone sait déjà faire. Voici où se cache le scanner sur iPhone et Android, et quoi faire quand il ne lit pas.

19 octobre 2026 · 4 min de lecture

Presque toutes les questions du type « comment je scanne ça » ont la même réponse : ouvrez votre appareil photo et pointez-le vers le code. Les téléphones modernes lisent les QR codes nativement — le scanner est intégré à l'app photo, ce n'est pas un téléchargement séparé. L'emplacement exact diffère légèrement entre iPhone et Android.

Sur iPhone

Méthode 1 — l'app Appareil photo. Ouvrez Appareil photo, pointez vers le code et restez immobile une seconde. Une bannière de notification jaune apparaît en haut — touchez-la pour ouvrir le lien. C'est tout ; il n'y a rien à activer avant.

Méthode 2 — le Centre de contrôle. Balayez vers le bas depuis le coin supérieur droit, touchez l'icône QR code (un petit symbole de code). Si vous ne la voyez pas, allez dans Réglages → Centre de contrôle et ajoutez « Scanner de code ». Cela ouvre une vue de scanner dédiée, pratique en faible lumière.

Sur Android

Méthode 1 — l'app Appareil photo. Sur la plupart des téléphones Android (Samsung, Pixel et autres), ouvrez l'appareil photo et pointez vers le code. Une fenêtre de lien apparaît — touchez-la. Si rien ne se passe, vérifiez dans les réglages de l'appareil photo l'option « Scanner les QR codes » et activez-la.

Méthode 2 — Google Lens. Ouvrez l'app Google ou Google Lens, pointez vers le code et touchez le déclencheur. Lens lit le code et affiche le lien. Certains téléphones ont aussi une tuile QR dans les réglages rapides (balayez deux fois vers le bas depuis le haut).

Quand ça ne scanne pas

Neuf fois sur dix, c'est l'un de ceux-ci :

  • Trop loin ou trop près. Remplissez environ la moitié du viseur avec le code, puis restez immobile.
  • Reflet ou ombre. Inclinez légèrement le téléphone pour que les reflets s'éloignent du code.
  • Impression sale ou abîmée. Un code taché peut encore scanner — les QR codes tolèrent jusqu'à 30 % de dommages au niveau de correction d'erreur le plus élevé — mais un motif de repérage déchiré (les trois grands carrés) est fatal.
  • Ce n'est pas un QR code. Certains « codes » sur les emballages sont des codes-barres ou des marques propriétaires. Un QR code a toujours trois marques de positionnement carrées dans les coins.

Avez-vous besoin d'une app de scan ?

Non — et c'est la réponse honnête même si des apps de scan existent. L'appareil photo intégré gère les QR codes standards, et les apps de scan tierces ajoutent surtout des pubs et du suivi. La seule exception : si votre téléphone est assez ancien pour ne pas avoir de lecteur intégré, n'importe quelle app de scan réputée fera l'affaire.

Envie de tester tout de suite ? Pointez votre appareil photo vers n'importe quel code sur notre page de scan gratuite — ou importez une photo d'un code et décodez-la dans votre navigateur, sans rien envoyer.

Bon à savoir

Comment scanner un QR code sur mon iPhone ?

Ouvrez l'app Appareil photo et pointez vers le code — une bannière de notification apparaît en haut. Touchez-la. Vous pouvez aussi ajouter le Scanner de code au Centre de contrôle (Réglages → Centre de contrôle) pour un scanner dédié.

Comment scanner un QR code sur Android ?

Ouvrez votre app appareil photo et pointez vers le code ; une fenêtre de lien apparaît. Si ça ne marche pas, activez « Scanner les QR codes » dans les réglages de l'appareil photo, ou utilisez Google Lens.

Dois-je télécharger une app de scan de QR code ?

Non. Les iPhone et la plupart des téléphones Android lisent les QR codes avec l'appareil photo intégré. Les apps de scan sont inutiles pour les codes standards.

Pourquoi mon téléphone ne scanne-t-il pas le QR code ?

Généralement la distance, un reflet ou une impression abîmée. Tenez le téléphone pour que le code remplisse la moitié du viseur, évitez les reflets, et vérifiez que les trois carrés des coins ne sont pas déchirés.
