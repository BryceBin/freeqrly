Comment scanner un QR code avec son téléphone

Aucune app à installer — votre téléphone sait déjà faire. Voici où se cache le scanner sur iPhone et Android, et quoi faire quand il ne lit pas.

19 octobre 2026 · Dernière mise à jour : 3 novembre 2026 · 15 min de lecture

Réponse courte : ouvrez l'application Appareil photo de votre téléphone, pointez-la vers le code, et touchez le lien qui apparaît. Pas besoin de télécharger une application de scan, de créer un compte, ni d'appuyer sur le déclencheur. Sur un iPhone ou un téléphone Android moderne, la lecture des QR est intégrée à l'appareil photo et à quelques raccourcis système autour de lui. Le savoir-faire, c'est de savoir quel raccourci convient à chaque situation : l'application Appareil photo pour un menu sur la table, une vue de lecteur dédiée pour une file de billets dans une lumière faible, et une méthode d'image enregistrée quand le code est déjà sur votre propre écran.

Une habitude couvre tous les cas : lisez l'aperçu avant de toucher. Votre téléphone affiche le lien, le nom du réseau Wi-Fi, ou l'action que le code veut accomplir avant que quoi que ce soit s'ouvre. Cet aperçu est votre seule chance de repérer un code qui n'a rien à faire là où il se trouve. Si l'aperçu ne correspond pas au panneau devant vous, arrêtez-vous avant de toucher.

Sur iPhone : Appareil photo, Scanner le code, et l'écran de verrouillage

Méthode 1 — l'application Appareil photo. Ouvrez Appareil photo, tenez le téléphone pour que tout le code apparaisse dans le cadre, et attendez un instant. Pas besoin de prendre une photo. Un lien ou une action apparaît ; touchez-le pour ouvrir la destination. Apple décrit exactement ce parcours — ouvrir Appareil photo ou le lecteur de code, tenir l'appareil pour que le code apparaisse, puis toucher le lien — dans son guide d'assistance pour scanner un QR code avec un iPhone ou un iPad. Gardez tout le carré en vue, y compris les trois grands carrés d'angle. Si une partie du code est coupée par le bord du cadre, le lecteur doit deviner, et c'est là que les échecs commencent. Tenez le téléphone stable et à peu près parallèle à la surface.

Méthode 2 — la commande Scanner le code dans le Centre de contrôle. Ouvrez le Centre de contrôle et touchez le bouton Scanner le code pour ouvrir une vue de lecteur dédiée. Si vous ne la voyez pas, touchez longuement l'arrière-plan du Centre de contrôle, touchez le bouton Ajouter une commande, et choisissez Scanner le code dans la galerie. Configurez-la une fois et oubliez-la jusqu'au moment où vous en aurez besoin : dans une file de billets ou un restaurant sombre, un balayage et un toucher vous mettent dans un lecteur sans rien d'autre en travers, et la vue du lecteur comprend une lampe torche. L'application Appareil photo est meilleure quand vous voulez peut-être aussi une photo ; la commande Scanner le code est meilleure quand le scan est tout le travail. Les deux utilisent la même lecture intégrée, la différence est donc la vitesse, pas la capacité. Vous pouvez aussi ouvrir Appareil photo depuis l'écran de verrouillage, ce qui compte à un portail ou une caisse où un scan est un travail à une main, sous pression — même si la règle de l'aperçu s'applique toujours, même pressé.

Sur Pixel : suggestions de l'appareil photo et Réglages rapides

Méthode 1 — l'application Appareil photo. Ouvrez l'application Appareil photo et pointez-la vers le code, en vous assurant que tout le code s'affiche à l'écran. Pas besoin de prendre une photo ; l'appareil photo reconnaît le code et affiche une bulle ou un lien, que vous touchez pour ouvrir. Le guide Pixel de Google ajoute un réglage à vérifier si rien n'apparaît : dans l'application Appareil photo, ouvrez Réglages, puis Plus de réglages, et assurez-vous que Suggestions de scan par l'appareil photo est activé. Ce seul interrupteur est la raison la plus fréquente pour laquelle un appareil photo Pixel reste muet devant un code parfaitement bon, et il vaut la peine d'être vérifié avant de conclure que le code est en cause.

Méthode 2 — le lecteur des Réglages rapides. Balayez vers le bas depuis le haut de l'écran pour ouvrir les Réglages rapides et touchez Scanner le QR code. Si vous ne voyez pas la tuile, balayez vers la gauche pour plus de boutons ou touchez l'icône crayon pour l'ajouter. Un lecteur dédié s'ouvre ; pointez-le vers le code. C'est le repli le plus rapide quand l'application Appareil photo fait des siennes. Le conseil de dépannage de Google est court : tenez stable, utilisez une bonne lumière sans reflets, essuyez un objectif maculé, et rapprochez-vous tout en gardant tout le carré dans le cadre. Un dernier détail de mode : sur les appareils photo basés sur le logiciel photo de Google, un code se lit en vue photo normale, pas en mode portrait ou vidéo, donc revenez d'abord à la vue normale si vous avez ouvert l'appareil photo pour filmer quelque chose.

Sur Samsung Galaxy : Appareil photo, Réglages rapides et Galerie

Le guide d'assistance Samsung, mis à jour en octobre 2026, énumère plusieurs portes d'entrée vers le même lecteur ; en pratique, commencez par l'application Appareil photo, gardez les Réglages rapides comme repli rapide, et utilisez la Galerie pour une photo enregistrée.

Méthode 1 — l'application Appareil photo. Ouvrez Appareil photo, pointez-la vers le code, et attendez le message contextuel ; touchez-le pour aller aux informations du code. Pas besoin de prendre une photo. Si rien n'apparaît, ouvrez les réglages de l'appareil photo avec l'icône d'engrenage et assurez-vous que l'interrupteur Scanner les QR codes est activé. Comme pour Pixel, cet interrupteur est la première chose à vérifier quand un appareil photo Samsung ignore un code, et le guide de Samsung le nomme explicitement comme le correctif pour un appareil photo qui ne veut pas scanner.

Méthode 2 — le panneau Réglages rapides. Balayez vers le bas depuis le haut de l'écran pour ouvrir les Réglages rapides et touchez Scanner le QR code ; l'application Appareil photo se lance en mode scan. Cette vue de lecteur donne un accès rapide à la lampe torche, vraiment utile dans un lieu sombre : un code sous la faible lumière d'un bar est souvent un problème d'éclairage, pas un problème de code. Si la tuile manque, ajoutez-la au panneau pour qu'elle soit là la prochaine fois que vous ferez la queue. Méthode 3 — Galerie. Si vous avez déjà photographié un code, ouvrez-le dans l'application Galerie Samsung, sélectionnez l'image, et touchez le bouton Bixby Vision ; le téléphone lit l'image et propose d'ouvrir le lien ou de le copier. Le lecteur des Réglages rapides offre un parcours similaire : ouvrez-le, touchez l'icône d'image de la galerie, choisissez la photo, et confirmez. Voir le guide pour scanner un QR code depuis une photo pour ces parcours en détail.

Autres téléphones Android : le même schéma, d'autres libellés

Android n'a pas de lecteur unique, parce que chaque fabricant de téléphone arrange les mêmes pièces différemment. Le schéma, pourtant, est constant : une application Appareil photo qui lit les codes dans sa vue photo normale, une tuile Scanner le QR code dans les Réglages rapides, et Google Lens comme repli universel. Si votre téléphone n'est ni un Pixel ni un Samsung, parcourez le schéma dans cet ordre. D'abord, ouvrez l'application Appareil photo et pointez-la vers un code en vue photo normale. Si rien n'apparaît, cherchez dans les réglages de l'appareil photo un interrupteur de scan — le nom varie selon le fabricant, cherchez donc une formulation sur les QR codes, le scan ou les suggestions — et activez-le. S'il n'y a pas d'interrupteur, ou s'il est déjà activé et que rien ne se passe, balayez vers le bas pour les Réglages rapides et cherchez la tuile Scanner le QR code. Si elle manque aussi, ouvrez Google Lens depuis l'application Google ou depuis l'appareil photo et pointez-le vers le code. Lens lit aussi les images enregistrées dans Google Photos.

Un mot sur les téléphones anciens. Un téléphone assez vieux pour n'avoir aucun lecteur intégré est le seul cas où une application de scan séparée est une réponse raisonnable. Choisissez-en une dans la boutique officielle avec une demande d'autorisation claire et limitée — l'accès à l'appareil photo, et rien d'autre dont elle n'a pas besoin — et méfiez-vous de tout lecteur qui demande vos contacts, votre position ou un compte avant même de lire un seul code. Sinon, sautez carrément l'installation et utilisez le lecteur gratuit dans votre navigateur, qui lit un code depuis votre appareil photo ou depuis une image téléversée sans aucune installation, et ne laisse rien derrière lui sur le téléphone quand vous avez fini.

Scénarios : adapter la méthode au moment

À la table d'un restaurant, utilisez l'application Appareil photo ; le code est proche et vous voulez le menu en un toucher, en inclinant le téléphone si une carte plastifiée brillante éblouit sous un spot. À un portail ou un contrôle de billets, utilisez le raccourci de lecteur dédié et ouvrez-le avant d'arriver en tête de file, puisque les codes de billets sont souvent sensibles au temps. Sur une affiche ou une vitrine, reculez jusqu'à ce que tout le code entre confortablement dans le cadre, et souvenez-vous de la règle de taille du guide des tailles d'impression : en règle générale, un code doit faire au moins un dixième de la distance à laquelle vous le scannez. Un code que vous n'arrivez pas à faire entrer dans le cadre depuis l'endroit où vous êtes est un code imprimé trop petit pour son emplacement, et aucun réglage du téléphone n'y remédiera. Sur un téléviseur, un portable ou l'écran d'un autre téléphone, pointez votre appareil photo vers l'autre écran comme vous le feriez vers du papier, mais attention aux reflets sur le verre et au scintillement propre à l'écran ; inclinez légèrement contre les reflets, tenez stable contre le scintillement, et scannez vite un code de connexion ou d'appairage, puisqu'un code actualisé remplace l'ancien.

Quand rien ne se passe : la liste de contrôle côté téléphone

  1. Tout le code dans le cadre ? Reculez jusqu'à ce que les quatre coins et la marge calme autour du code soient visibles.
  2. Bon mode photo ? Utilisez la vue photo normale, pas le portrait ni la vidéo ; utilisez le raccourci de lecteur dédié si votre appareil photo en propose un.
  3. Le scan est-il activé ? Vérifiez l'interrupteur : Suggestions de scan par l'appareil photo sur Pixel, Scanner les QR codes dans les réglages photo de Samsung, la commande Scanner le code sur iPhone.
  4. Objectif propre ? Essuyez-le avec un chiffon doux ; un objectif maculé floute tous les codes pareillement.
  5. La lumière aide-t-elle ou gêne-t-elle ? Ajoutez de la lumière dans une pièce sombre, supprimez les reflets dans une pièce lumineuse, gardez votre ombre hors du code.
  6. Le code lui-même est-il lisible ? Vérifiez les trois carrés d'angle, le contraste, et tout dégât, effacement ou courbure qui déforme la grille.
  7. Test du deuxième téléphone : si un autre téléphone lit le code et pas le vôtre, le problème vient des réglages, de l'objectif ou de la lumière de votre téléphone — pas du code.

Si le code se lit mais que la destination échoue — un lien mort, une page déplacée, un formulaire qui n'existe plus — c'est une autre panne, avec un autre responsable. Le code a fait son travail ; la page derrière lui, non. Toute la chaîne des pannes côté code est traitée dans pourquoi votre QR code ne scanne pas, et l'impression floue en particulier dans pourquoi votre QR code est flou. Si aucune des sept étapes ci-dessus n'aide, l'étape suivante est un autre lecteur ou un autre téléphone, pas plus de bricolage avec le vôtre.

La comparaison honnête : le scan intégré contre les applications de scan

Les applications de scan existent, et pour un téléphone sans lecteur intégré elles sont une vraie solution. Pour tous les autres, elles sont une version moins bonne de quelque chose que le téléphone fait déjà. L'appareil photo intégré lit les codes standards, affiche le même aperçu, et ouvre les mêmes destinations, sans compte, sans écran d'abonnement, et sans un flux de publicités entre vous et un menu. Une application de scan ajoute un intermédiaire à une transaction qui n'en a pas besoin, et cet intermédiaire est généralement payé avec de l'attention, des données, ou les deux. Le cas pour une application est étroit mais réel : un téléphone ancien sans lecteur intégré en a besoin, ou d'un lecteur dans le navigateur, et une personne qui scanne des codes toute la journée pour le travail peut vouloir un historique ou une lecture en masse. Le cas contre une application, pour le scan de tous les jours, est tout aussi concret : beaucoup d'applications de scan affichent des publicités, et certaines demandent des autorisations bien au-delà de l'appareil photo — contacts, position, ou un compte qui lie votre historique de scans à une identité. L'appareil photo intégré, lui, lit le code et passe à autre chose ; il ne tient pas un journal de vos scans.

Sécurité : l'aperçu est toute la défense

Un QR code cache sa destination par construction. On ne peut pas lire une URL en regardant le motif, et c'est exactement pourquoi un code est un véhicule si efficace pour un lien sur lequel vous ne cliqueriez jamais si vous pouviez le voir. La défense n'est pas d'éviter les codes — c'est de lire l'aperçu, à chaque fois, et de traiter l'aperçu comme une décision, pas comme une formalité. La Federal Trade Commission américaine a mis en garde contre ce schéma dans une alerte aux consommateurs datée du 6 décembre 2023 : des escrocs recouvrent de vrais codes avec leurs propres autocollants — sur les parcmètres, par exemple — ou envoient des codes dans des messages inattendus, et un code scanné peut mener à un site contrefait qui semble réel, où tout ce qui est saisi peut être volé, ou à un logiciel malveillant. Le conseil de la FTC dans cette alerte est la même habitude que ce guide recommande : inspectez l'URL avant de l'ouvrir, cherchez les fautes d'orthographe ou une lettre échangée dans un nom familier, et ne scannez pas un code venu d'un message inattendu, surtout un message qui presse d'agir vite. Lisez l'aperçu, vérifiez les falsifications comme un autocollant collé par-dessus un autre code, et vérifiez le contexte : attendiez-vous ce code, à cet endroit, pour cet usage ? Échouer à l'un seul de ces contrôles suffit pour s'arrêter.

Bon à savoir

Comment scanner un QR code sur mon iPhone ?

Ouvrez l'application Appareil photo, tenez le téléphone pour que tout le code soit dans le cadre, et touchez le lien qui apparaît. Sinon, ouvrez le Centre de contrôle et touchez le bouton Scanner le code pour une vue de lecteur dédiée ; si le bouton manque, ajoutez-le depuis la galerie du Centre de contrôle.

Comment scanner un QR code sur un téléphone Pixel ?

Ouvrez l'application Appareil photo et pointez-la vers le code, en vous assurant que tout le carré s'affiche à l'écran. Si rien n'apparaît, vérifiez que Suggestions de scan par l'appareil photo est activé dans les Réglages de l'application Appareil photo, puis Plus de réglages. La tuile Scanner le QR code des Réglages rapides est le repli le plus rapide.

Comment scanner un QR code sur un téléphone Samsung Galaxy ?

Ouvrez l'application Appareil photo et pointez-la vers le code, puis touchez le message contextuel. Si rien n'apparaît, ouvrez les réglages de l'appareil photo et assurez-vous que l'interrupteur Scanner les QR codes est activé. Vous pouvez aussi balayer vers le bas pour les Réglages rapides et toucher Scanner le QR code, ou lire une photo enregistrée dans l'application Galerie avec Bixby Vision.

Dois-je télécharger une app de scan de QR code ?

Non, pas pour les codes standards sur un téléphone moderne. L'appareil photo intégré les lit avec le même aperçu que n'importe quelle application. Un lecteur séparé n'est une réponse raisonnable que pour un téléphone sans lecteur intégré, ou pour un travail qui exige vraiment un historique de scans ou une lecture en masse.

Pourquoi mon téléphone ne scanne-t-il pas le QR code ?

Parcourez la liste de contrôle côté téléphone dans l'ordre : tout le code dans le cadre, vue photo normale plutôt que portrait ou vidéo, scan activé, objectif propre, bonne lumière sans reflets, carrés d'angle intacts et contraste, et enfin un test sur un deuxième téléphone. Si un autre téléphone le lit, le problème vient de votre téléphone ; si aucun ne le lit, c'est le code.

Puis-je scanner un QR code qui est sur l'écran de mon propre téléphone ?

Pas avec l'appareil photo, puisqu'un appareil photo ne peut pas viser son propre écran. Faites une capture d'écran du code ou enregistrez l'image, puis lisez-la depuis l'image — voir le guide pour scanner un QR code depuis une photo.

Est-il sûr de scanner un QR code dans un lieu public ?

Lisez l'aperçu avant de toucher, et vérifiez que le domaine correspond au panneau devant vous, que le code ne montre aucun signe de falsification comme un autocollant collé par-dessus un autre code, et que vous attendiez ce code à cet endroit. Échouer à l'un seul de ces contrôles suffit pour s'arrêter.
