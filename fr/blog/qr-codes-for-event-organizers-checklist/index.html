QR codes pour organisateurs d’événements : la liste de contrôle complète (avant, pendant et après)

Un QR code ne fonctionne que si quelqu’un peut le scanner, au bon endroit, au bon moment. Cette liste de contrôle couvre tout ce dont un organisateur d’événements a besoin pour planifier, imprimer, tester, faire fonctionner et réutiliser des QR codes — avant l’ouverture des portes, le jour J, et après le départ du dernier invité.

19 novembre 2026 · 17 min de lecture

La plupart des QR codes d’événements échouent pour des raisons simples : le code renvoie vers une page qui a déménagé, l’impression est trop petite pour être scannée à deux mètres, le Wi-Fi lâche à l’enregistrement, ou personne n’a testé le code sur un téléphone.

Avant l’événement : planifier, créer, imprimer, tester

Tout dans cette phase se passe pendant que vous avez encore le temps de corriger les erreurs : un QR code imprimé sur 500 badges ne peut pas être réimprimé le matin de l’événement, mais sa destination peut encore être changée — si vous avez choisi le bon type de code.

1. Décidez quels codes sont statiques et lesquels doivent être dynamiques

  • Codes statiques : ils encodent leur destination de façon permanente. Une fois imprimés, la destination ne peut plus changer. Ils sont vraiment gratuits, sans inscription, sans filigrane, n’expirent jamais, et sont générés entièrement dans le navigateur — rien de téléversé, rien de suivi.
  • Codes dynamiques : ils pointent vers un lien court que vous contrôlez. Le code imprimé ne change jamais, mais vous pouvez modifier sa destination à tout moment — même après qu’il a été imprimé, affiché et distribué. Les codes dynamiques enregistrent aussi des statistiques de scan, et les scans sont illimités. Leur création nécessite une inscription gratuite. En cas de doute, choisissez dynamique. Le coût d’un code dynamique inutile est nul ; le coût d’un code statique dont la destination a déménagé, c’est une réimpression.

2. Créez les codes de billetterie et d’inscription

Votre QR code de billetterie est généralement le premier code qu’un participant scanne, et il apparaît sur les affiches, les publications sociales, les e-mails et les sites web des partenaires.

  • Liez-le à la page de billets en direct, pas à une page d’accueil. Chaque tap supplémentaire risque de faire perdre un acheteur.
  • Utilisez un code dynamique pour pouvoir changer de destination entre les phases de billets (early bird → tarif normal → dernière mise en vente) sans rien réimprimer ni republier.
  • Mettez le même code sur tous les canaux — affiche, signature d’e-mail, lien de bio sociale, page partenaire — et ses statistiques de scan montrent le total sur l’ensemble des canaux. Pour comparer les canaux, donnez plutôt à chaque canal son propre code.
  • Ajoutez une courte URL imprimée sous le code. Si le code ne se scanne pas, l’URL est la solution de secours.
  • Si vous proposez plusieurs types de billets (général, VIP, étudiant, intervenant), créez un code par type. La génération en série peut créer jusqu’à 50 codes statiques d’un coup, ce qui est utile pour les variantes par type ou par canal, mais la série est réservée aux codes statiques — les codes dynamiques se créent un par un.

3. Créez les codes d’enregistrement

L’enregistrement, c’est là qu’un mauvais QR code crée une file visible. Planifiez-le comme un processus, pas comme une affiche.

  • Décidez ce que l’invité scanne : un code sur l’e-mail de confirmation de son billet, un code sur un badge imprimé, ou un code affiché à l’entrée qui ouvre la page d’enregistrement.
  • Décidez ce que le personnel voit : un tableau de bord d’enregistrement, une liste de participants consultable, ou une simple page « confirmé ». Testez cela sur l’appareil exact que le personnel tiendra — un téléphone, une tablette ou un ordinateur portable.
  • Si chaque participant reçoit un code unique (un par billet), générez-les en série : jusqu’à 50 codes statiques par série, donc un événement de 200 personnes nécessite quatre séries.
  • Imprimez quelques codes d’enregistrement génériques de rechange pour les visiteurs sans billet, la presse et les ajouts de dernière minute.

4. Créez les codes du lieu, du programme, des intervenants et des sponsors

Ce sont les codes que les invités scannent une fois à l’intérieur. Chacun répond à une question qu’un invité poserait sinon à un bénévole.

  • Itinéraire et parking : un code qui renvoie vers un repère de carte ou une page d’itinéraire. Imprimez-le sur l’invitation, l’e-mail de confirmation et un panneau à l’entrée du parking. Le statique convient — le lieu ne déménage pas.
  • Programme et planning : un code qui renvoie vers le programme en direct. Utilisez le dynamique : des sessions sont annulées, des salles changent, et les horaires glissent. Mettez ce code au dos de chaque badge, sur le mur du hall et à la porte de chaque salle.
  • Liens des intervenants : un code par intervenant, ou un code qui renvoie vers une page des intervenants avec la biographie, les diapositives et les liens sociaux de chacun. Dynamique, parce que les diapositives arrivent tard.
  • Liens des sponsors : un code par sponsor, imprimé sur le panneau de son stand et dans le programme. Dynamique, pour que le sponsor puisse changer la page de destination après l’événement sans vous demander de réimprimer. Dites aux sponsors que le code est dynamique et modifiable — c’est un argument de vente pour le forfait stand.
  • Wi-Fi : un QR code Wi-Fi qui rejoint le réseau en un scan. Imprimez-le en grand à l’entrée et dans chaque salle de session. Le statique convient, et les invités vous en remercieront.

5. Faites un plan d’impression et de placement

Un QR code au mauvais endroit, c’est comme pas de QR code. Avant d’imprimer quoi que ce soit, notez où va chaque code.

Règles de placement qui préviennent les échecs les plus courants :

  • Ne placez jamais un code là où les reflets le frappent. Du papier brillant sous un projecteur, un code derrière une vitre, ou un écran face à une fenêtre ne se scannera pas. Le papier mat et un placement à l’ombre préviennent la plupart de ces échecs.
  • Gardez une zone de silence autour de chaque code. La marge vierge autour d’un QR code fait partie du code. Ne laissez pas du texte, des logos ou des bordures l’envahir. Un logo au centre, ça va — le centre est prévu pour ça — mais gardez les bords dégagés.
  • Un code par panneau, un rôle par code. Une affiche avec cinq codes est une affiche que personne ne scanne. Si un panneau a besoin de plusieurs destinations, renvoyez vers une seule page de destination et listez-les là.
  • Imprimez la courte URL sous chaque code important. C’est la solution de secours quand un appareil photo ne peut pas lire le code.

6. Testez tout par scan

C’est l’étape que la plupart des organisateurs sautent, et celle qui sauve l’événement.

  • Scannez chaque code imprimé avec au moins deux téléphones différents — un iPhone et un Android si possible — depuis la distance à laquelle un invité se tiendra.
  • Scannez sous l’éclairage réel du lieu si vous pouvez, ou au moins sous une lumière vive et dans une lumière tamisée.
  • Scannez les codes à l’écran aussi bien que sur papier : un code qui a l’air bien dans un fichier de mise en page peut être trop petit une fois sur un badge.
  • Cliquez jusqu’à la destination finale à chaque fois. Un code qui se scanne mais atterrit sur une page 404 est pire qu’un code qui ne se scanne pas, parce que personne ne le signale — ils partent, c’est tout.
  • Testez le flux d’enregistrement de bout en bout avec un vrai billet : scannez, confirmez, entrez. Si cela prend plus de quelques secondes par invité, la file va grandir.
  • Retestez après tout changement de destination. Les codes dynamiques rendent les changements faciles — et les changements non testés faciles aussi. Changez, puis scannez, puis faites confiance.

Un journal de test de dix minutes — code, téléphone testé, distance, réussite ou échec — attrape le code qui aurait échoué devant cent personnes.

Le jour J : faites tourner le flux, gérez les pannes

Le jour J, votre travail n’est pas de créer des codes. Surveillez le flux, réparez ce qui casse, et mettez à jour ce qui change — sans rien réimprimer.

7. Faites tourner le flux d’enregistrement

Ce que l’invité voit :

  1. Ils ouvrent l’e-mail de leur billet ou présentent leur badge.
  2. Ils scannent le code d’enregistrement (ou le personnel scanne le code de leur billet).
  3. Une page de confirmation apparaît — leur nom, le type de billet, et un message clair « Vous êtes enregistré ».
  4. Ils entrent. Pas d’application à télécharger, pas de compte à créer.
  • Ce que le personnel voit :
  1. La page d’enregistrement ou la liste des participants, avec le nom de l’invité marqué comme arrivé.
  2. Un compte des invités enregistrés par rapport aux invités attendus, pour savoir d’un coup d’œil si la salle se remplit comme prévu.
  3. Un champ de recherche par nom, pour l’invité dont le téléphone est mort ou dont l’e-mail n’est jamais arrivé.

Brifez le personnel cinq minutes avant l’ouverture des portes : montrez à chaque membre du personnel la page d’enregistrement sur son propre téléphone ; convenez qu’un scan raté ne renvoie jamais un invité — cherchez le nom manuellement à la place ; gardez un téléphone ou une tablette de rechange chargé au bureau, et gardez la liste papier des participants à portée de main.

8. Changer un lien après impression — pourquoi les codes dynamiques comptent

C’est là que les codes dynamiques font leurs preuves. Une session change de salle. Un intervenant annule. La page de billetterie déménage vers une nouvelle plateforme. Avec des codes statiques, chacun de ces cas veut dire réimprimer. Avec des codes dynamiques, chacun veut dire ouvrir le tableau de bord, modifier la destination, et scanner le code imprimé une fois pour confirmer que la nouvelle destination se charge. Dites au personnel ce qui a changé, pour que personne ne donne aux invités les anciennes informations de mémoire.

Le schéma est clair : tout ce qui peut changer le jour J aurait dû être dynamique dès le départ. Le Wi-Fi est l’exception : définissez le mot de passe avant l’impression et ne le changez pas en plein événement.

9. Ayez un plan de secours

Quelque chose va mal tourner. Le plan décide si c’est une réparation de deux minutes ou un problème visible.

Si un code ne se scanne pas : vérifiez d’abord la lumière — sortez le panneau des reflets directs ou inclinez-le légèrement. Essuyez l’objectif de l’appareil photo de l’invité ; ça a l’air anodin, mais ça résout beaucoup d’échecs. Essayez un autre téléphone : si le code se scanne sur un second téléphone, le problème vient de l’appareil de l’invité, pas de votre code. Lisez la courte URL imprimée à voix haute ou tapez-la — c’est pour cela qu’elle est imprimée sous le code. Si le code lui-même est endommagé (déchiré, mouillé, décoloré), remplacez le panneau par une impression de rechange. Apportez toujours des impressions de rechange des panneaux d’entrée et d’enregistrement.

Si le Wi-Fi tombe : l’enregistrement ne doit pas dépendre du Wi-Fi. Gardez la liste papier des participants au bureau et une copie téléchargée de la liste sur le téléphone d’un membre du personnel. Demandez au personnel de dire aux invités le nom du réseau et le mot de passe à voix haute jusqu’au retour du réseau, et connaissez les identifiants du réseau de secours du lieu ou du point d’accès mobile avant l’ouverture des portes.

Si la page de billetterie déménage : si le code de billetterie est dynamique, modifiez la destination et rescannez pour confirmer — cela prend quelques minutes. S’il est statique, vous ne pouvez pas réparer le code imprimé : publiez le nouveau lien sur les comptes sociaux de votre événement, envoyez un e-mail aux participants inscrits, et placez un membre du personnel à l’entrée avec le nouveau lien prêt à partager. C’est l’échec qui convainc les organisateurs d’utiliser des codes dynamiques à partir de là.

Si le programme change en plein événement : modifiez la destination du programme dynamique une fois. Chaque code de programme imprimé dans le bâtiment montre maintenant le nouveau programme — badges, mur du hall, portes des salles — sans réimpression. Annoncez le changement sur l’écran principal et à voix haute aussi, puisque tous les invités ne rescanneront pas le code, et placez un membre du personnel à la porte de l’ancienne salle pendant les dix premières minutes pour diriger les invités vers la nouvelle salle.

10. Utilisez les mises à jour en direct et le partage de photos

Les QR codes ne servent pas seulement à l’entrée. Pendant l’événement, ils sont le moyen le plus rapide d’envoyer des informations à jour à toute une salle.

  • Changements de programme en direct : un seul code de programme dynamique, mis à jour une fois, atteint chaque invité qui le scanne. Annoncez « scannez le code de votre badge pour le programme mis à jour » depuis la scène.
  • Changements de salle : mettez à jour la destination, puis placez un membre du personnel à la porte de l’ancienne salle pendant les dix premières minutes pour diriger les invités vers la nouvelle salle.
  • Partage de photos : mettez un code de partage de photos sur la toile de fond de la scène, le mur du hall et les tables. Les invités le scannent pour téléverser des photos vers un album partagé ou pour trouver le hashtag de l’événement. Utilisez un code dynamique : le lien de l’album n’existe généralement pas tant que l’événement n’est pas en cours.
  • Liens sociaux : un code qui renvoie vers une page avec tous vos profils sociaux et le hashtag de l’événement. Mettez-le là où les gens prennent des photos — la toile de fond, le mur photo, l’espace sponsors — parce que c’est à ce moment-là qu’ils veulent publier.

Après l’événement : suivi et réutilisation

L’événement se termine, mais les codes continuent de fonctionner — et les mêmes supports imprimés peuvent servir au prochain événement.

11. Partagez l’album photo

  • Mettez à jour la destination du code dynamique de partage de photos vers l’album terminé une fois les photos collectées et triées. Chaque affiche, badge et carte de table qui portait le code photo pointe maintenant vers l’album — les invités qui scannent un badge gardé chez eux atterrissent sur les photos.
  • Envoyez aussi un e-mail aux participants avec le lien de l’album. Tout le monde ne garde pas le badge, et l’e-mail atteint des gens que le code ne peut pas atteindre.

12. Recueillez les retours tant que la mémoire est fraîche

  • Mettez à jour la destination du code dynamique de retour vers le sondage final, puis envoyez-le par e-mail et publiez-le sur les réseaux sociaux dans les 24 heures. Les taux de réponse chutent fortement après le premier jour.
  • Gardez le sondage court : trois à cinq questions, plus une zone de texte libre. Un long sondage attaché à un QR code est ouvert puis abandonné.
  • Mettez le code de retour sur le mur de sortie et les tables, pas seulement dans l’e-mail. Les invités qui quittent le lieu sont ceux qui ont les opinions les plus fraîches.
  • Lisez les statistiques de scan du code de retour : si beaucoup de personnes ont ouvert le sondage mais que peu l’ont terminé, le sondage est trop long.

13. Envoyez des messages de remerciement et faites le suivi des sponsors

  • Mettez à jour le code de remerciement (ou le code principal de l’événement) vers une page de remerciement avec l’album photo, le lien de retour et la date du prochain événement.
  • Envoyez aux sponsors leurs statistiques de scan : combien de fois le code de leur stand a été scanné, et quand. Les sponsors renouvellent les stands quand ils peuvent voir les chiffres. Les statistiques de scan sont disponibles sur les codes dynamiques ; les codes statiques n’enregistrent rien, ce qui est une autre raison pour laquelle les codes des sponsors doivent être dynamiques.
  • Partagez aussi les résultats principaux avec les intervenants — les scans sur le code de leur session, les mentions dans les retours — parce que les intervenants qui se sentent valorisés reviennent.

14. Réutilisez les supports imprimés pour le prochain événement

C’est le bénéfice durable d’avoir choisi des codes dynamiques. Les bannières, badges, cartes de table et panneaux que vous avez imprimés pour cet événement n’ont pas besoin d’être réimprimés pour le suivant :

  1. Gardez les supports imprimés qui portent des codes dynamiques.
  2. Avant le prochain événement, modifiez la destination de chaque code vers les pages du nouvel événement : nouveau lien de billetterie, nouveau programme, nouvel album photo, nouveau formulaire de retour.
  3. Scannez chaque code réutilisé et confirmez qu’il atterrit sur les pages du nouvel événement. Un code qui pointe vers le programme de l’année dernière est pire que pas de code.
  4. Réimprimez uniquement les supports dont les codes sont statiques et dont les destinations ont changé — généralement juste la date et les détails du lieu.

Pour un événement récurrent — un meetup mensuel, une conférence annuelle, une foire saisonnière — cela transforme l’impression d’un coût par événement en un coût unique. La liste de contrôle du prochain événement commence à l’étape 6 (tout tester par scan) au lieu de l’étape 1.

Bon à savoir

Les QR codes d’événement doivent-ils être statiques ou dynamiques ?

Dynamiques pour tout ce qui pourrait changer après impression : billetterie, programme, intervenants, sponsors, albums photo, retours et pages de remerciement. Statiques pour les choses qui ne changeront jamais : l’adresse du lieu, la connexion Wi-Fi et la page d’accueil permanente de l’événement. Si vous hésitez, choisissez dynamique — l’offre gratuite autorise 20 codes dynamiques, ce qui couvre la plupart des événements uniques.

Puis-je changer la destination d’un QR code après l’avoir imprimé ?

Oui, si c’est un code dynamique. Modifiez la destination dans les paramètres du code et le code imprimé mène immédiatement à la nouvelle page. Les codes statiques ne peuvent pas être changés après impression ; la destination est encodée dans le code lui-même.

Quelle taille doit faire un QR code imprimé ?

Il n’y a pas de taille universelle, parce que la bonne taille dépend de la distance de scan : un code de badge scanné à bout de bras peut être petit, tandis qu’un code de toile de fond de scène scanné à huit mètres doit être très grand. La méthode fiable, c’est d’imprimer, puis de tester par scan depuis la distance à laquelle un invité se tiendra vraiment, sur deux téléphones différents.

Puis-je réutiliser les mêmes QR codes imprimés pour mon prochain événement ?

Oui, pour les codes dynamiques. Modifiez la destination de chaque code vers les pages du nouvel événement et retestez chaque code en scannant le support imprimé réel. Les codes statiques ne peuvent être réutilisés que si leur destination est toujours correcte pour le prochain événement.

Y a-t-il une limite au nombre de fois qu’un QR code d’événement peut être scanné ?

Non. Les scans sont illimités sur les codes statiques comme dynamiques, donc un code populaire lors d’un grand événement ne cessera pas de fonctionner en plein milieu de la journée.

Combien coûte la création de QR codes pour un événement ?

Les codes statiques sont gratuits sans inscription, sans filigrane et sans expiration. Les codes dynamiques sont gratuits avec une inscription gratuite, jusqu’à 20 codes, avec statistiques de scan incluses. Pro (9 $/mois ou 90 $/an) n’ajoute que les codes dynamiques illimités.
