Comment générer 100 QR codes d’un coup : du tableur aux codes imprimés

oui — 100 codes, ça veut dire deux séries de 50. Le mode série de FreeQrly génère jusqu’à 50 QR codes à la fois, donc cent codes, c’est deux passages dans le même outil : construisez un tableau de 100 lignes, générez les 50 premiers, puis les 50 suivants, téléchargez deux fichiers ZIP, testez par scan, et imprimez.

19 novembre 2026 · 17 min de lecture

C’est gratuit, sans inscription, et les codes ne portent pas de filigrane. La suite couvre le tableau, la méthode de saisie, les vérifications avant impression, et quoi faire quand quelque chose semble anormal.

Ce guide ne couvre que les codes statiques, parce que le mode série ne fabrique que des codes statiques. Un code statique porte sa destination dans le motif : il n’expire jamais, ne demande aucun compte, et il est généré entièrement dans votre navigateur — rien de téléversé, rien de suivi. Le revers : un code statique ne peut pas être modifié après impression. Si un lien change, régénérez ce code et réimprimez-le. Si vous avez besoin de codes modifiables après impression, avec des statistiques de scan, utilisez des codes dynamiques — créés un par un, pas en série.

Étape 1 : construisez votre tableau

Tout ce qui peut mal tourner avec cent codes tourne mal dans le tableau, pas dans le générateur — une faute de frappe à la ligne 37 devient un code erroné à la ligne 37. Accordez d’abord dix minutes d’attention au tableau.

La seule règle : une ligne, un code

Chaque ligne de votre tableau devient exactement un QR code, dans le même ordre. La ligne 1 devient qr-1.png, la ligne 2 devient qr-2.png, et ainsi de suite. Cet ordre est la seule correspondance entre un code et sa destination, alors gardez le fichier du tableau à côté des ZIP téléchargés et ne réordonnez pas les lignes.

Un exemple concret : 100 pages produit

Supposons qu’une petite boutique veuille un code par page produit, pour des étiquettes de rayon. Le tableau n’a besoin que de deux colonnes pour un code de lien : quelque chose qui identifie la ligne, et le lien lui-même. Toutes les valeurs ci-dessous sont des SAMPLE DATA.

Si vos destinations sont déjà dans un tableur — un export d’inventaire, une liste de produits, une liste d’invités — copiez la colonne des destinations dans une nouvelle feuille au lieu de téléverser tout l’export.

Colonnes par type

Le mode série prend en charge 16 types : url, text, email, sms, phone, geo, wifi, vcard, event, bitcoin, coupon, appstore, review, mp3, google-form et menu. Les types à un seul champ n’ont besoin que d’une colonne. Les types à plusieurs champs regroupent leurs champs sur une ligne avec le caractère pipe | comme séparateur, les champs dans l’ordre indiqué, avec un espace de chaque côté du pipe pour la lisibilité.

Les ordres de champs ci-dessus correspondent à ce que lit le générateur en série — l’aide au format sous la zone de texte indique le même ordre. D’abord, le pipe est le séparateur, donc il ne peut pas apparaître dans un champ : un mot de passe WiFi contenant | se découpera dans les mauvais champs. Ensuite, l’ordre des champs est fixe. Pour le WiFi, c’est nom du réseau, mot de passe, type de sécurité — MyWiFi | mot de passe | WPA, exactement comme indiqué. Un ordre inversé génère quand même un code, mais le téléphone lira les champs aux mauvais endroits. Troisièmement, gardez les destinations courtes quand vous pouvez. Un lien court donne un motif plus aéré avec des modules plus grands, qui se scanne plus sûrement aux petites tailles d’impression. Raccourcissez les liens longs avant de les mettre dans le tableau — et testez d’abord les liens raccourcis.

Nettoyer le tableau avant de générer

Parcourez cette liste une fois, sur les 100 lignes, avant d’ouvrir le générateur :

  1. Pas de lignes vides. Une ligne vide dans une liste collée est ignorée, mais le générateur peut quand même lire une ligne vide d’un tableur comme un élément vide, alors supprimez les lignes vides.
  2. Pas de ligne d’en-tête dans le collage. Laissez l’en-tête hors du texte collé. (Une ligne d’en-tête CSV est détectée automatiquement et ignorée — voir l’étape 2 — mais le texte collé, lui, ne bénéficie pas de cette détection.)
  3. Pas d’espaces en fin de ligne. Un espace à la fin d’un lien fait partie du contenu du code. Dans un tableur, sélectionnez la colonne et nettoyez-la.
  4. Chaque lien s’ouvre. Vérifiez au hasard le premier, le dernier et quelques liens du milieu. Un lien qui renvoie une 404 dans le navigateur renvoie une 404 une fois scanné.
  5. Un type par série. Un téléversement CSV utilise un seul type : celui sélectionné dans le générateur. Ne mélangez pas des lignes WiFi et des lignes de liens dans une même série ; séparez les tâches mixtes par type, ou utilisez le téléversement Excel décrit ensuite.

Le mode série offre deux entrées ; la bonne dépend de l’endroit où vit déjà votre liste.

Pour 100 codes, le téléversement est généralement meilleur : le fichier garde votre tableau intact, le générateur gère la ligne d’en-tête, et vous pouvez téléverser à nouveau le même fichier si vous repérez une erreur. Le collage est plus rapide pour une liste courte, ou qui vient d’ailleurs que d’un tableur.

L’astuce Excel : une feuille par type

Seul le téléversement Excel peut porter plusieurs types dans un seul fichier. Chaque feuille est un type, et le nom de la feuille choisit le type — url, website ou link pour les liens ; text ; email ; sms ; phone ; geo ; wifi ; vcard ou contact pour les contacts ; event. Une feuille dont le nom n’est pas reconnu revient à url par défaut, alors vérifiez les noms avant de téléverser. Les types au-delà de ces neuf noms de feuilles ne sont pas choisis par le nom de feuille ; pour ceux-là, utilisez le téléversement CSV ou le collage avec le type sélectionné.

Étape 3 : utilisez le fichier modèle

Si vous partez d’une feuille vierge, pas d’un export existant, ne construisez pas les colonnes de mémoire. FreeQrly fournit un modèle téléchargeable, freeqrly-batch-template.xlsx, avec une feuille par type, des en-têtes et des lignes d’exemple remplies. Téléchargez-le, remplacez les lignes d’exemple par les vôtres, supprimez les exemples dont vous n’avez pas besoin, et téléversez le résultat. Le modèle est le moyen le plus rapide d’avoir le bon ordre de champs : pour les types à plusieurs champs comme le WiFi et la vCard, la ligne d’exemple le montre. La feuille vCard a 8 colonnes — nom, téléphone, e-mail, entreprise, fonction, site web, adresse, note — et le mode série lit les huit, dans l’ordre du modèle, comme le formulaire de contact du code unique, donc l’entreprise et la fonction apparaissent aussi dans le contact enregistré.

Il existe aussi un modèle CSV pour le type sélectionné uniquement. Pour une tâche à plusieurs types, le modèle Excel est le bon.

Gardez deux copies de votre fichier terminé — le fichier de travail que vous téléversez, et un original intact sauvegardé avec les ZIP téléchargés, pour que les numéros de lignes répondent encore à « quel code correspond à quel produit » dans trois mois.

Étape 4 : générez et vérifiez les codes

La génération est l’étape la plus courte. Sélectionnez le type, ajoutez votre liste — en collant ou en téléversant — et générez. Chaque élément devient son propre code, prévisualisé en grille sur la page. Puis, avant tout téléchargement ou impression, vérifiez la grille :

  • Comptez les codes. Chaque série doit en afficher 50. S’il en manque, une ligne a été ignorée — généralement une ligne vide. Retournez au tableau.
  • Lisez le premier et le dernier code. Scannez le premier code, puis le dernier. Si les deux ouvrent la bonne destination, la configuration est bonne ; les codes du milieu utilisent les mêmes réglages. Vérifiez quand même au hasard toute ligne saisie à la main.
  • Vérifiez un code à plusieurs champs au hasard. Si votre série est WiFi ou vCard, scannez-en un et confirmez que le téléphone rejoint le réseau ou enregistre le contact. Un code qui se scanne mais remplit le mauvais champ est un échec silencieux.

Testez d’abord à l’écran : le test à l’écran est gratuit et instantané. Mais un code qui se scanne sur un écran lumineux peut quand même échouer sur papier, et c’est pourquoi le test d’impression de l’étape 6 compte.

Étape 5 : téléchargez — un par un, ou tout le ZIP

Chaque code peut être téléchargé individuellement en PNG 1024 px — utile pour un code de remplacement, ou quand vous placez les codes un par un dans une mise en page. Pour cent codes, le ZIP est le choix pratique : un clic télécharge freeqrly-batch.zip contenant qr-1.png à qr-50.png, chacun un PNG de 1024 px. Il n’y a pas d’option SVG en mode série.

Deux choses à bien faire au moment du téléchargement. D’abord, gardez les deux ZIP séparés : les deux arrivent avec le même nom de fichier, freeqrly-batch.zip, donc le second écrasera le premier dans le même dossier. Renommez le premier en batch-1-rows-1-50.zip avant de télécharger le second, ou téléchargez chacun dans son propre dossier. Ensuite, gardez la correspondance : les noms de fichiers dans le ZIP sont des numéros de lignes, pas des noms de produits. Si vous renommez les PNG, renommez-les à partir du tableau — qr-37.png devient SKU-037-mug.png, par exemple — et travaillez sur une copie, en gardant le ZIP original intact.

Aucune connexion n’est requise : les codes en série sont statiques et générés dans le navigateur, donc pas de compte à créer, pas de filigrane, et pas d’expiration.

Étape 6 : imprimez — taille, contraste et zone de silence

Trois choses décident si un code qui se scanne à l’écran se scanne aussi sur papier, là où il vivra vraiment : une étiquette de rayon sous les lumières d’une boutique, une étiquette de colis dans un entrepôt, une carte de table dans un restaurant tamisé.

Taille

Le guide des tailles d’impression de FreeQrly couvre les tailles par cas d’usage — cartes, flyers, affiches. Au minimum, un code simple doit être imprimé à au moins 2 × 2 cm, comme indiqué sur la page. Les codes plus denses ont besoin de plus de place : à taille d’impression égale, un code avec une destination plus longue a besoin de plus de place qu’un code avec une destination courte, et les codes scannés de loin doivent être plus grands en proportion de la distance. En cas de doute, imprimez une étiquette de test et scannez-la depuis la distance à laquelle vos clients se tiendront.

Contraste et zone de silence

Le contraste ne change jamais : des modules foncés sur fond clair, avec un fort contraste. Un code en gris pâle sur blanc, ou dans une couleur de marque trop claire, échouera sur des téléphones que vous ne pouvez pas tester — les appareils photo plus anciens, les pièces sombres, les reflets. Gardez les modules foncés et le fond clair et uni.

Autour de chaque code se trouve la zone de silence : la marge vierge qui permet à un appareil photo de trouver les bords du code. Ne laissez pas du texte, une bordure, un pli ou une étiquette voisine l’envahir. Donnez au code son propre espace dégagé sur fond clair, zone de silence libre sur les quatre côtés.

Papier, encre et test d’impression

Le papier mat vaut mieux que le brillant sous les lumières vives, parce que le brillant renvoie la lumière. Si les étiquettes doivent être brillantes, testez le scan sous les lumières sous lesquelles elles seront placées. Faites toujours un test d’impression avant la série complète : imprimez une feuille et scannez le premier, le dernier et un code du milieu au hasard sur le papier, avec deux téléphones si vous pouvez — un iPhone et un Android. Si les trois se scannent du premier coup, imprimez les cent. Si l’un hésite, imprimez plus grand, augmentez le contraste ou raccourcissez la destination.

Quand la série est le mauvais outil

Le mode série est le bon outil quand les destinations sont fixées et que la quantité est le problème. Il ne convient pas dans trois cas. D’abord, vous devez modifier des codes après impression : un lien de menu qui change chaque mois a besoin d’un code dynamique, créé un par un et modifiable depuis le tableau de bord. L’offre gratuite autorise 20 codes dynamiques ; Pro coûte 9 $/mois ou 90 $/an, et sa seule différence avec l’offre gratuite est les codes dynamiques illimités. Pendant l’offre limitée en cours, les codes dynamiques gratuits sont illimités ; une fois l’offre terminée, le forfait gratuit comprendra 20 codes dynamiques. Ensuite, chaque code a besoin d’un style différent : le mode série fabrique l’ensemble dans un seul style cohérent, alors utilisez le générateur principal un par un. Enfin, vous avez besoin de statistiques de scan par code : les codes statiques n’enregistrent aucun scan, alors utilisez des codes dynamiques — et les codes dynamiques ne se font pas en série de 50.

Le flux de travail, en un paragraphe

Construisez un tableau, une ligne par code, avec des colonnes adaptées au type. Nettoyez-le : pas de lignes vides, pas d’en-tête dans le collage, chaque lien vérifié. Téléversez-le ou collez-le en deux moitiés de 50, en utilisant le modèle si vous partez de zéro. Comptez la grille, scannez le premier et le dernier code, téléchargez les ZIP dans des dossiers séparés avec le tableau à côté. Imprimez une feuille, scannez-la sur papier, puis imprimez les cent. Cent codes, ce n’est pas cent petits travaux. C’est un tableau, deux séries, et un test d’impression.

Bon à savoir

Combien de QR codes puis-je générer d’un coup ?

Jusqu’à 50 par série, que vous colliez ou téléversiez — donc 100 codes, c’est deux séries : lignes 1 à 50, puis lignes 51 à 100. Gardez l’ordre des lignes identique dans les deux moitiés pour que les noms de fichiers correspondent au tableau.

Ai-je besoin d’un compte pour générer des QR codes en masse ?

Non. Les codes en série sont statiques et générés entièrement dans votre navigateur, donc aucune inscription n’est nécessaire, rien de téléversé, et les codes n’expirent jamais et ne portent pas de filigrane.

Les codes en série peuvent-ils être dynamiques ou modifiables après impression ?

Non. Le mode série est uniquement statique. Si une destination change après impression, régénérez ce code et réimprimez-le. Pour les codes à modifier après impression, créez plutôt des codes dynamiques un par un.

Quels types de fichiers puis-je téléverser ?

Un fichier CSV (.csv) ou un fichier Excel (.xlsx / .xls). Un CSV porte un type par fichier, et le générateur gère les champs entre guillemets, donc les virgules dans un champ ne posent pas de problème. Un fichier Excel peut porter un type par feuille, le nom de la feuille choisissant le type.

Comment formater le WiFi et les coordonnées dans le fichier ?

Les types à plusieurs champs utilisent le caractère pipe | entre les champs, dans un ordre fixe. Le WiFi, c’est nom du réseau, mot de passe, type de sécurité — par exemple, MyWiFi | mot de passe | WPA (SAMPLE DATA). Une vCard, c’est nom, téléphone, e-mail, entreprise, fonction, site web, adresse, note — par exemple, Ada Lovelace | +1 555 010 2040 | ada@example.com | Alder Design Studio | Designer | https://example.com | 123 Main St | Ami (SAMPLE DATA). Le modèle, freeqrly-batch-template.xlsx, montre l’ordre des champs pour chaque type, avec des en-têtes et des lignes d’exemple.

Qu’est-ce que j’obtiens au téléchargement ?

Chaque code peut être téléchargé individuellement en PNG de 1024 px. Le ZIP est freeqrly-batch.zip avec qr-1.png à qr-50.png, chacun un PNG de 1024 px. Aucune option SVG en mode série.

Comment savoir quel PNG correspond à quel produit ?

Par le numéro de ligne : qr-1.png est la ligne 1, qr-37.png est la ligne 37. Gardez le tableau avec les ZIP ; renommez des copies à partir du tableau pour des noms de fichiers explicites.

À quelle taille dois-je imprimer les codes ?

Au moins 2 × 2 cm pour un code simple, comme indiqué sur la page ; plus grand pour les codes denses ou les codes scannés de loin. Le guide des tailles d’impression de FreeQrly couvre les tailles par cas d’usage — quelle que soit la taille choisie, imprimez d’abord une feuille et scannez-la sur papier.

Pourquoi certains de mes codes ne se scannent-ils pas après impression ?

Les causes habituelles, dans l’ordre : l’impression est trop petite pour la densité du code ; le contraste est trop faible ; ou quelque chose — du texte, une bordure, un pli — a envahi la zone de silence. Imprimez plus grand, foncez les modules, dégagez la marge, et testez à nouveau sur papier.
