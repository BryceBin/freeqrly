Le guide du restaurant

Trois QR codes couvrent 90 % de ce dont un restaurant a besoin : le menu, le lien d’avis et le mot de passe WiFi. Tous gratuits, tous imprimables aujourd’hui.

14 octobre 2026 · 4 min de lecture

1. Le code du menu

Liez-le à votre menu en ligne — votre site web, un PDF ou votre menu Google Business. Imprimez-en un par table ou un seul code encadré à l’entrée. Générez-le avec le générateur de liens en quelques secondes, exportez à 1024 px, et c’est fait. Astuce de pro : liez vers une page que vous contrôlez, pas une capture d’écran — quand le menu change, vous mettez à jour la page, pas l’impression.

2. Le code d’avis

C’est le centimètre carré à plus haut ROI de votre restaurant. Un code liant directement vers votre formulaire d’avis Google — sur le reçu, le chevalet de table, le sac à emporter — transforme les repas satisfaits en avis publics. Il existe un générateur de QR code d’avis Google dédié qui vous guide pour trouver votre lien d’avis.

3. Le code WiFi

Les invités demandent le mot de passe WiFi cinquante fois par jour. Un QR code WiFi sur chaque table les connecte en un scan — fini d’épeler « K majuscule, tiret bas, 123 ». Il n’expire jamais, donc imprimez-le une fois.

Conseils d’impression pour restaurants

Plastifiez les codes de table (les renversements arrivent), utilisez au moins 3x3 cm pour que les invités scannent depuis leurs sièges, et gardez un contraste élevé — les salles à manger sombres punissent les codes pastel. Règles complètes de taille : guide des tailles d’impression.

Ce que ça coûte

Rien. Ce sont des codes statiques — pas d’abonnements, pas de limites de scan, pas de « forfait pro » pour débloquer le lien du menu. Imprimez-les une fois et ils fonctionnent pendant des années. C’est tout le discours.

Bon à savoir

De quels QR codes un restaurant a-t-il besoin ?

Trois : un lien de menu, un lien d’avis Google et les identifiants WiFi. Ça couvre presque chaque interaction avec les invités.

Le QR du menu doit-il pointer vers un PDF ou une page web ?

Une page web que vous contrôlez. Quand les prix changent, vous mettez à jour la page — le code imprimé reste le même. Un PDF fonctionne mais est plus difficile à mettre à jour.

Comment obtenir plus d’avis Google avec un QR code ?

Liez un code directement à votre formulaire d’avis Google et placez-le là où les clients satisfaits regardent : reçus, chevalets de table, sacs à emporter.
