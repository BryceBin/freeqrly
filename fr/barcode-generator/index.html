Bon à savoir

Quel format de code-barres dois-je utiliser ?

Code 128 pour un usage général — il accepte n’importe quel texte. EAN-13 pour les produits vendus en magasin à l’international, UPC-A pour le commerce américain, Code 39 quand le scanner est ancien ou que le code doit rester lisible par l’humain, ITF-14 pour les cartons d’expédition.

Ai-je besoin d’un chiffre de contrôle ?

Non — pour EAN-13, UPC-A et ITF-14, saisissez un chiffre de moins et le chiffre de contrôle est calculé pour vous. Code 128 et Code 39 n’en ont pas besoin.

PNG ou SVG pour l'impression ?

SVG pour l’emballage et l’impression professionnelle — il se redimensionne à l’infini sans flou. PNG pour l’impression au bureau et les applications qui n’acceptent pas le SVG.

C’est vraiment gratuit ? Sans filigrane ?

Gratuit, sans filigrane, sans inscription. Le code-barres est dessiné dans votre navigateur — rien n’est téléversé.
