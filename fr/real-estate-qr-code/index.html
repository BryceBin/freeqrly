Bon à savoir

Vers quoi les agents lient-ils habituellement ?

Pages d’annonces, visites virtuelles, horaires des portes ouvertes, calculateurs de prêt et carte de contact de l’agent.

Quelle taille pour un panneau ?

Utilisez la règle empirique du 1:10 : la largeur du code doit être au moins un dixième de la distance de lecture. Un panneau lu à 5 mètres a besoin d’un code de 50 cm — l’export SVG le garde net à toutes les tailles.

Puis-je ajouter ma photo ou le logo de mon agence ?

Oui — téléversez votre logo ou portrait au centre. La correction d’erreur s’ajuste automatiquement pour qu’il se scanne toujours.

Et si l’annonce se vend ?

Pointez le code vers votre profil d’agent ou votre page d’annonces au lieu d’un seul bien, pour que le panneau continue de fonctionner après la vente. Le code lui-même n’expire jamais.
