Bon à savoir

Morceau, playlist ou artiste — quel lien ?

Les trois marchent. Un lien morceau lance un titre ; un lien playlist ouvre la liste ; un lien artiste ouvre le profil. Choisissez la page sur laquelle votre public doit arriver.

Est-ce que ça s'ouvre dans l'app Spotify ?

Sur la plupart des téléphones, oui — toucher le lien scanné propose l'app si elle est installée, sinon il s'ouvre dans le navigateur. Les comptes gratuits peuvent aussi l'ouvrir.

Est-ce la même chose qu'un Spotify Code ?

Non. Les Spotify Codes sont les codes-barres scannables dans l'app Spotify. Un QR code marche partout — affiches, impression, emballages — avec n'importe quel appareil photo de téléphone, sans app Spotify pour scanner.

Expire-t-il ?

Non. Les codes statiques n’expirent jamais et ne demandent aucun compte.
