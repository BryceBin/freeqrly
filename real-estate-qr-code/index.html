Good to know

What do agents usually link to?

Listing pages, virtual tours, open-house schedules, mortgage calculators, and the agent’s contact card.

How big for a yard sign?

Use the 1:10 rule: code width at least one-tenth of the viewing distance. A sign read from 5 meters needs a 50 cm code — SVG export keeps it sharp at any size.

Can I add my photo or brokerage logo?

Yes — upload your logo or headshot in the center. Error correction adjusts automatically so it still scans.

What if the listing sells?

Point the code at your agent profile or listings page instead of a single property, so the sign keeps working after the sale. The code itself never expires.
