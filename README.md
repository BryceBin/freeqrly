FreeQrly is a free QR code generator built on a simple idea: the tool should live in your browser, not on somebody's server. No sign-up walls, no watermarks, no subscriptions — and static codes that can never expire.

## Features

**Generate**
- 12 code types + batch mode: URL, text, WiFi, vCard, email, SMS, phone, location, calendar events, Bitcoin, coupons, App Store links
- Batch generation — paste a list or drop a spreadsheet, download everything as one ZIP
- Free **dynamic codes** (8 on a free sign-in): edit the destination after printing, with scan statistics by day, country, city and device
- Free **barcode generator**: Code 128, EAN-13, UPC-A, Code 39, ITF-14
- Built-in **scanner**: decode from your camera or an uploaded image, fully on-device

**Customize**
- Your logo in the centre (6 brand presets or your own upload) — error correction rises automatically so it still scans
- Colours, dot shapes, transparent background, rounded / text frames
- Print-ready PNG (up to 4096 px) and SVG export

**Private by design**
- Static codes are generated 100% client-side — links, contacts and WiFi passwords never leave your device
- No account, no tracking, no analytics on static codes

**For everyone, everywhere**
- 10 languages, including right-to-left Arabic · dark mode · mobile-friendly

## For AI agents 🤖

FreeQrly is agent-native. Two free ways to generate codes without a browser:

**MCP** — add `https://freeqrly.com/mcp` (Streamable HTTP) to any MCP client.

| tool | auth | what it does |
|---|---|---|
| `generate_qr` | none | static QR as SVG (`data`, `size`, `color`, `bgcolor`, `ecc`) |
| `dynamic_qr_create` / `list` / `update` / `delete` / `stats` | `Authorization: Bearer <api_token>` | editable dynamic codes, same free quota as the web UI |

**HTTP API** — `GET https://freeqrly.com/api/qr?data=…&size=1024` returns SVG, no key.
Authenticated dynamic endpoints (`POST /api/codes`, `GET /api/me/codes`, `GET /api/codes/{code}/stats`, `PATCH`, `DELETE`) take the same Bearer token, created in the dashboard under **API Tokens**.

Full reference: [freeqrly.com/developers](https://freeqrly.com/developers/) · machine-readable: [llms.txt](https://freeqrly.com/llms.txt) · agent skill: [`skills/qr-generator/SKILL.md`](skills/qr-generator/SKILL.md)

## Tech stack

Plain HTML/CSS/JS on **Cloudflare Pages**, plus a small Cloudflare backend (**Functions** + **D1** + **R2**) for accounts, dynamic codes and the API. Zero build step for the frontend — pages are generated by Python scripts in `tools/` and deployed via `git push`.

## Local development

```bash
git clone https://github.com/BryceBin/qrforge.git
cd qrforge

# regenerate all pages after editing sources
python3 tools/build-all.py

# preview (needs wrangler)
npx wrangler pages dev . --d1 DB
```

Only four source files matter for content work: `index.html` (homepage structure), `assets/js/app.js` (generator logic + translations), `tools/gen-landing.py` (landing page copy), `assets/css/main.css` (styles). Everything else is generated.

## Project structure

```
├── index.html              # homepage (source)
├── dashboard/              # account dashboard (dynamic codes, API tokens)
├── developers/             # API & MCP docs
├── scan/                   # on-device QR scanner
├── barcode-generator/      # barcode tool
├── blog/ about/            # content
├── functions/              # Cloudflare Functions (API, MCP, auth)
│   ├── api/qr.js           # no-key SVG API
│   ├── api/codes*.js       # dynamic codes (session or Bearer auth)
│   ├── api/tokens*.js      # API token management (session only)
│   └── mcp.js              # MCP server (Streamable HTTP)
├── tools/                  # page generators (build-all.py, gen-landing.py, …)
├── skills/qr-generator/    # agent skill
└── assets/                 # css / js / img
```
