Good to know

Profile link or a specific post?

Profile link for general follows. Linking a Reel or post works too — handy for campaigns and packaging inserts.

Does it open in the Instagram app?

On most phones, tapping the scanned link offers to open it in the app if installed; otherwise it opens in the browser.

Can I add my logo or brand colors?

Yes — upload your logo and set your brand colors. Keep contrast high so it scans in any light.

Does it expire if I change my username?

The code encodes the exact URL, so if your handle changes, make a fresh code. The code itself never expires.
