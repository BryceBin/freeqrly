आपका logo, बीचों-बीच — फिर भी scan होगा

Logo code को आपका बना देता है। लेकिन वह pattern का एक हिस्सा भी ढक देता है। दोनों पाने का तरीका यह है: logo बिल्कुल बीच में, और code पहली बार में ही scan हो जाए।

28 अक्टूबर 2026 · 4 मिनट में पढ़ें

सादा QR code काम करता है। Logo वाला QR कोड काम भी करता है और पहचाना भी जाता है — packaging पर, business card पर, कमरे के दूसरी ओर लगे poster पर। लेकिन एक पेंच सच में है: logo pattern के ऊपर बैठता है, और phone उसी pattern को पढ़ता है। Balance गलत हुआ तो code scan होना बंद हो जाएगा। Balance सही हुआ तो किसी को engineering नज़र नहीं आएगी — सिर्फ आपका brand दिखेगा।

तीन rules

  1. Transparency वाला square PNG। Transparent background वाला square logo बीच में सबसे साफ बैठता है। Rectangular logo या white box वाला logo जगह बर्बाद करता है और pattern से टकराता है।
  2. इसे code area के ~30% से कम रखें। Generator भी यही thumb rule इस्तेमाल करता है: इतना छोटा कि बाकी pattern data संभाल सके, इतना बड़ा कि एक नज़र में पढ़ा जा सके।
  3. Error correction को अपना काम करने दें। QR code नुकसान झेलने के लिए ही बने हैं — pattern का 30% तक गायब हो, तब भी code पढ़ा जाता है। Logo लगाने पर error correction अपने आप बढ़ जाती है, ताकि ढका हुआ बीच का हिस्सा मायने न रखे।

Step by step

पहले code बनाएँ — logo के साथ कोई भी type चलता है: link, vCard, WiFi network। फिर studio के logo step में logo upload करें, उसे बीच में size करें, और download करें। Print के लिए 2048 px तक का PNG, या अगर infinitely scalable चाहिए तो SVG। Logo step हर code type के साथ काम करता है, और वही logo पूरे batch पर भी लगाया जा सकता है।

चार गलतियाँ जो scan खराब कर देती हैं

  • Logo बहुत बड़ा। Area के ~30% से ज़्यादा होने पर error correction भी गायब data को वापस नहीं बना सकती। अगर logo बड़ा ही रखना है, तो छोटा link इस्तेमाल करें — कम data का मतलब है ज़्यादा खुला pattern।
  • Low-contrast logo। हल्के code पर हल्का logo, या modules में घुल जाने वाला logo, camera को confuse कर देता है। गहरा logo, हल्का background, मज़बूत contrast — वही rule जो code पर लागू होता है।
  • Code के पीछे busy background। Photo या pattern पर logo वाला code एक साथ दो लड़ाइयाँ लड़ता है। Code को बैठने के लिए एक साफ, हल्का patch दें, जिसका quiet margin साफ हो।
  • Code को खींचना। Proportion के बिना resize करने से grid टेढ़ा हो जाता है। बराबर scale करें, ताकि square, square ही रहें।

वह test जो इसे साबित कर देता है

Print का पूरा run निकालने से पहले, code को दो phones से scan करें — एक iPhone, एक Android — और screen पर ही नहीं, print पर scan करें। अगर दोनों पहली बार में पढ़ लें, तो भेज दीजिए। अगर कोई एक भी अटके, तो logo थोड़ा छोटा करें या contrast बढ़ाएँ और फिर test करें। यहाँ के तीस seconds एक reprint बचा लेते हैं।

आज़माएँ: अपने logo वाला QR code बनाएँ — free, static code के लिए कोई sign-up नहीं, कोई watermark नहीं।

क्या मेरा logo QR code को खराब कर देगा?

नहीं, अगर वह code area के ~30% से कम रहे। Logo लगाते ही error correction अपने आप बढ़ जाती है, इसलिए ढका हुआ बीच का हिस्सा scan नहीं रोकता।

कौन सी logo file सबसे अच्छी चलती है?

Transparency वाला एक square PNG। Rectangular logo और white box वाले logo जगह बर्बाद करते हैं और pattern से टकराते हैं।

क्या मैं किसी भी QR code type के साथ logo इस्तेमाल कर सकता हूँ?
