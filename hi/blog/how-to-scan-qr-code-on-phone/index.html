क्यूआर कोड कैसे स्कैन करें अपने phone से

कोई app install नहीं करनी — आपका phone पहले से जानता है। यहाँ बताया है कि iPhone और Android पर scanner कहाँ रहता है, और जब वह पढ़ न पाए तो क्या करें।

19 अक्टूबर 2026 · 4 मिनट में पढ़ें

लगभग हर "इसे scan कैसे करूँ" सवाल का जवाब एक ही है: अपना camera खोलें और code की ओर point करें। Modern phone QR code को natively पढ़ लेते हैं — scanner camera app में ही built-in होता है, अलग से download नहीं करना पड़ता। iPhone और Android में इसकी सही जगह थोड़ी अलग होती है।

iPhone पर

Method 1 — Camera app। Camera खोलें, code की ओर point करें, और एक second स्थिर रखें। ऊपर एक पीला notification banner दिखेगा — link खोलने के लिए उस पर tap करें। बस इतना ही; पहले कुछ enable करने की ज़रूरत नहीं है।

Method 2 — Control Center। ऊपर-दाएँ कोने से नीचे swipe करें, QR code icon (एक छोटा code symbol) पर tap करें। अगर वह न दिखे, तो Settings → Control Center में जाकर "Code Scanner" add करें। इससे एक dedicated scanner view खुलता है, जो कम रोशनी में काम आता है।

Android पर

Method 1 — Camera app। ज़्यादातर Android phone (Samsung, Pixel, और दूसरे) पर camera खोलें और code की ओर point करें। एक link popup दिखेगा — उस पर tap करें। अगर कुछ न हो, तो camera settings में "Scan QR codes" toggle देखें और उसे on करें।

Method 2 — Google Lens। Google app या Google Lens खोलें, code की ओर point करें, और shutter button पर tap करें। Lens code पढ़कर link दिखा देगा। कुछ phones में Quick Settings में भी QR tile होता है (ऊपर से दो बार नीचे swipe करें)।

जब scan न हो

दस में से नौ बार वजह इनमें से कोई एक होती है:

  • बहुत दूर या बहुत पास। Viewfinder का लगभग आधा हिस्सा code से भरें, फिर स्थिर रखें।
  • Glare या shadow। Phone को थोड़ा टेढ़ा करें, ताकि reflection code से हट जाए।
  • गंदा या खराब print। धुंधला code फिर भी scan हो सकता है — सबसे ऊँचे error-correction level पर QR code 30% तक damage झेल लेते हैं — लेकिन फटा हुआ finder pattern (तीन बड़े square) जानलेवा होता है।
  • यह QR code ही नहीं है। Packaging पर कुछ "code" barcode या proprietary mark होते हैं। QR code के कोनों में हमेशा तीन square positioning mark होते हैं।

क्या आपको scanner app चाहिए?

नहीं — और scanner app होने के बावजूद यही ईमानदार जवाब है। Built-in camera standard QR code संभाल लेता है, और third-party scanner app ज़्यादातर सिर्फ ads और tracking जोड़ते हैं। एक ही exception है: अगर आपका phone इतना पुराना है कि उसमें built-in reader ही नहीं है, तो कोई भी भरोसेमंद scanner app काम कर देगा।

मैं अपने iPhone पर QR code कैसे scan करूँ?

Camera app खोलें और code की ओर point करें — ऊपर एक notification banner दिखेगा। उस पर tap करें। या फिर, dedicated scanner के लिए Control Center में Code Scanner add करें (Settings → Control Center)।

मैं Android पर QR code कैसे scan करूँ?

अपना camera app खोलें और code की ओर point करें; एक link popup दिखेगा। अगर वह काम न करे, तो camera settings में 'Scan QR codes' enable करें, या Google Lens इस्तेमाल करें।

क्या मुझे QR scanner app download करनी चाहिए?

नहीं। iPhone और ज़्यादातर Android phone built-in camera से ही QR code पढ़ लेते हैं। Standard code के लिए scanner app की ज़रूरत नहीं होती।

मेरा phone QR code scan क्यों नहीं कर रहा?

आमतौर पर दूरी, glare, या खराब print वजह होती है। Phone ऐसे रखें कि code viewfinder का आधा हिस्सा भरे, reflection से बचें, और check करें कि कोनों के तीन square फटे न हों।
