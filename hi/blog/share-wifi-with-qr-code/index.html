अपना WiFi QR कोड से शेयर करें

मेहमान password पूछते हैं। आप fridge की ओर इशारा करते हैं। एक scan और वे online हैं — न spelling, न typo, न router के sticker से पढ़कर बताना।

28 अक्टूबर 2026 · 4 मिनट में पढ़ें

हर host इस ritual को जानता है: मेहमान आता है, WiFi password पूछता है, और आप capital letters, numbers और symbols वाली एक लंबी string बोलते हैं, जिसे वे दो बार गलत type करते हैं। WiFi QR code इसे खत्म कर देता है। एक code print करें, जहाँ मेहमान देखते हैं वहाँ चिपकाएँ, और scan करते ही उनका phone network से जुड़ जाएगा — बिल्कुल typing के बिना।

WiFi QR code में क्या होता है

तीन चीज़ें: network का नाम (SSID), password, और security type — home router पर आमतौर पर WPA या WPA2, बहुत पुराने hardware पर WEP, या open network के लिए कुछ नहीं। Code scan करने वाला phone तीनों को पढ़ लेता है और सीधे जुड़ जाता है, settings खोलकर type करने की ज़रूरत नहीं पड़ती।

तीन steps में बनाएँ

  1. अपने network details पता करें। नाम और password आमतौर पर router पर लगे sticker पर होते हैं। अगर आपने इन्हें बदला है, तो वही इस्तेमाल करें जो आपने set किया है — code को router से बिल्कुल match करना चाहिए, capitals समेत।
  2. Code generate करें। WiFi QR code generator में WiFi type चुनें, network का नाम, password और security type डालें। Code तुरंत बन जाएगा।
  3. Print करें और जहाँ मेहमान देखते हैं वहाँ लगाएँ। घर में fridge के दरवाज़े पर, café में counter card पर, Airbnb में welcome book में, office में reception desk पर। Print पर कम से कम 2 × 2 cm रखें, ताकि phone हाथ की दूरी से भी इसे पढ़ सके।

किन phones से scan करके जुड़ा जा सकता है?

iOS 11 और उसके बाद वाले iPhone सीधे Camera app से जुड़ जाते हैं — point करें, notification पर tap करें, हो गया। Android 10 और उसके बाद वाले ज़्यादातर Android phone भी camera या WiFi settings से यही करते हैं। दोनों तरफ किसी extra app की ज़रूरत नहीं है, और मेहमानों को password कभी दिखाई भी नहीं देता।

ईमानदारी वाली security बात

Static WiFi code इसलिए convenient है क्योंकि password उसी pattern के अंदर होता है — जिसका मतलब यह भी है कि जो कोई printed code की photo ले ले, वह आपके network से जुड़ सकता है। घर, café या rental के लिए यही सही trade है: मेहमानों को online होना ही चाहिए। दो rules इसे सही रखते हैं:

  • इसे privately generate करें। Static code पूरी तरह आपके browser में बनता है — आपका password कभी upload या store नहीं होता। और भी निश्चिंत रहने के लिए, page load करें, internet से disconnect करें, फिर type करें।
  • अगर code गलत जगह leak हो जाए, तो password बदलें और दोबारा print करें। Print के बाद static code को edit नहीं किया जा सकता, लेकिन नया बनाना free है और एक minute लगता है।

Hidden network और मुश्किल router

Hidden network भी वैसे ही काम करते हैं — network का सही नाम डालें और phone उसे list में देखे बिना ही connect हो जाएगा। WPA3 router के लिए, अगर WPA3 listed नहीं है तो WPA2/WPA option चुनें; ज़्यादातर WPA3 router WPA2 client को accept कर लेते हैं। और अगर किसी मेहमान का phone जुड़ने से मना कर दे, तो पहले password के capitals check करें — लगभग हर बार यही वजह होती है।

Code ही चाहिए? अपना WiFi QR code बनाएँ — static code के लिए free, कोई sign-up नहीं, और यह कभी expire नहीं होता।

जानना अच्छा रहेगा

क्या QR code में मेरा WiFi password safe है?

Static code के लिए, हाँ — यह पूरी तरह आपके browser में बनता है और कभी upload या store नहीं होता। जो कोई printed code की photo ले ले, वह जुड़ सकता है, इसलिए इसे guest key की तरह समझें: घर, café और rental के लिए ठीक है, और leak हो तो दोबारा print कर लें।

कौन से phone WiFi QR code scan कर सकते हैं?

iOS 11+ वाले iPhone सीधे Camera app से जुड़ जाते हैं; Android 10+ वाले ज़्यादातर Android phone भी camera या WiFi settings से यही करते हैं। किसी extra app की ज़रूरत नहीं है।

क्या यह WPA3 या hidden network के साथ काम करता है?

अपने router से match करने वाला security type चुनें (WPA, WPA2, WEP, या open)। Hidden network का नाम बिल्कुल सही डालें, वह वैसे ही connect हो जाएगा।

अगर मैं बाद में अपना WiFi password बदल दूँ तो क्या होगा?

Static code को edit नहीं किया जा सकता, इसलिए एक fresh code print करें — यह free है और एक minute लगता है। यही वजह है कि यह code उन network के लिए सबसे अच्छा है जिनका password शायद ही कभी बदलता हो।
