QR कोड, बिना ब्राउज़र के।

FreeQrly HTTP और MCP बोलता है। किसी भी एजेंट, स्क्रिप्ट या वर्कफ़्लो से स्टैटिक QR कोड बनाएं — न की, न साइन-अप, न एक्सपायरी। अगर आप रिक्वेस्ट कर सकते हैं, तो कोड बना सकते हैं।

कनेक्ट करने के तरीके

🧰 MCP सर्वर

https://freeqrly.com/mcp को अपने MCP क्लाइंट में जोड़ें। एक टूल — generate_qr — कोई ऑथ नहीं। Claude Code, Cursor और Streamable HTTP बोलने वाली हर चीज़ के साथ काम करता है।

🌐 HTTP API

SVG लौटाने वाला एक सीधा GET एंडपॉइंट। CORS पूरी तरह खुला है, इसलिए ब्राउज़र, curl और सर्वरलेस फंक्शन सब इसे सीधे कॉल कर सकते हैं।

📜 एजेंट स्किल

पेलोड रेसिपी वाली एक SKILL.md रेपो में skills/qr-generator/ पर रहती है। अपने एजेंट को उसकी तरफ़ इशारा करें और वह बाकी जान जाएगा।

🤖 llms.txt

/llms.txt क्रॉलर और असिस्टेंट के लिए पूरी साइट का वर्णन करता है — एंडपॉइंट, पेलोड फॉर्मेट और पेज मैप, एक ही फ़ाइल में।

HTTP API

GET https://freeqrly.com/api/qr?data=TEXT&size=1024&margin=4&color=2F4A62&bgcolor=ffffff&ecc=M

image/svg+xml लौटाता है। सिर्फ़ data ज़रूरी है; बाकी सबका समझदार डिफ़ॉल्ट है। एरर JSON में error फ़ील्ड के साथ वापस आते हैं।

curl "https://freeqrly.com/api/qr?data=https://example.com&size=1024" \
  -o qr.svg

# WiFi QR code for guests
curl "https://freeqrly.com/api/qr?data=WIFI:T:WPA;S:CafeNet;P:s3cret;;" \
  -o wifi.svg

पैरामीटर

  • data — एनकोड करने वाला टेक्स्ट (ज़रूरी, अधिकतम 2000 अक्षर)। URL, WiFi स्ट्रिंग, vCard, सादा टेक्स्ट।
  • size — आउटपुट साइज़ px में, 128–2048 (डिफ़ॉल्ट 1024)।
  • margin — मॉड्यूल में क्वाइट ज़ोन, 0–10 (डिफ़ॉल्ट 4)।
  • color / bgcolor — 6-अंकीय hex, बिना # (डिफ़ॉल्ट 2F4A62 / ffffff)।
  • ecc — एरर करेक्शन L, M, Q, H (डिफ़ॉल्ट M)। प्रिंट या लोगो के लिए Q/H इस्तेमाल करें।

MCP

POST https://freeqrly.com/mcp

स्टैंडर्ड Streamable HTTP: initialize, फिर tools/list / tools/call। generate_qr टूल data, size, color, bgcolor, ecc लेता है और डाउनलोड के लिए तैयार SVG URL लौटाता है।

{
  "jsonrpc": "2.0", "id": 1, "method": "tools/call",
  "params": {
    "name": "generate_qr",
    "arguments": { "data": "https://example.com", "size": 1024 }
  }
}

पेलोड रेसिपी

Website : https://example.com/menu
WiFi    : WIFI:T:WPA;S:CafeNet;P:s3cret;;
Contact : BEGIN:VCARD\nVERSION:3.0\nN:Ada Lovelace\nTEL:+15550100\nEND:VCARD
Place   : geo:37.7749,-122.4194
SMS     : sms:+15550100?body=Hello

उचित उपयोग

यह मुफ़्त है, लेकिन दयालु बनें: एक ही कोड को बार-बार मांगने के बजाय रिज़ल्ट कैश करें, और ऑटोमेटेड ट्रैफ़िक को उचित रखें। प्रति-IP रेट लिमिट लागू होती है। स्टैटिक कोड डिटरमिनिस्टिक हैं — एक ही इनपुट हमेशा एक ही आउटपुट देता है, इसलिए कैशिंग आसान है।
