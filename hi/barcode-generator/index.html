बारकोड जनरेटर

बारकोड, बिना किसी सॉफ़्टवेयर के।

Code 128, EAN-13, UPC-A, Code 39, ITF-14 — आपके ब्राउज़र में बनते हैं, मुफ़्त, बिना साइन-अप, बिना वॉटरमार्क। पैकेजिंग और लेबल के लिए PNG या SVG डाउनलोड करें।

कोई भी अक्षर, अंक और चिह्न। अक्षरों में बड़े-छोटे का फ़र्क़ होता है।

12 या 13 अंक — आखिरी अंक चेक डिजिट है, अगर आप 12 डालते हैं तो यह अपने आप जुड़ जाता है।

11 या 12 अंक — अगर आप 11 डालते हैं तो चेक डिजिट अपने आप जुड़ जाता है।

जानना अच्छा रहेगा

मुझे कौन सा बारकोड फ़ॉर्मेट इस्तेमाल करना चाहिए?

सामान्य इस्तेमाल के लिए Code 128 — इसमें कोई भी टेक्स्ट आ जाता है। अंतरराष्ट्रीय स्तर पर बिकने वाले रिटेल प्रोडक्ट के लिए EAN-13, US रिटेल के लिए UPC-A, पुराने स्कैनर के लिए या जब कोड इंसान से पढ़ा जाना हो तो Code 39, शिपिंग केस के लिए ITF-14।

क्या मुझे चेक डिजिट चाहिए?

नहीं — EAN-13, UPC-A और ITF-14 के लिए एक अंक कम डालें, चेक डिजिट आपके लिए कैलकुलेट हो जाता है। Code 128 और Code 39 को इसकी ज़रूरत नहीं होती।

प्रिंट के लिए PNG या SVG?

पैकेजिंग और प्रोफ़ेशनल प्रिंट के लिए SVG — यह बिना धुंधलाए अनंत रूप से स्केल होता है। ऑफ़िस प्रिंटिंग और उन ऐप्स के लिए PNG जो SVG स्वीकार नहीं करते।

क्या यह सच में मुफ़्त है? कोई वॉटरमार्क?

मुफ़्त, बिना वॉटरमार्क, बिना साइन-अप। बारकोड आपके ब्राउज़र में बनता है — कुछ भी अपलोड नहीं होता।
