QR-коды, минус браузер.

FreeQrly говорит по HTTP и MCP. Генерируйте статические QR-коды от любого агента, скрипта или рабочего процесса — без ключа, без регистрации, без срока действия. Если умеете делать запрос — сумеете сделать код.

Способы подключения

🧰 MCP-сервер

Добавьте https://freeqrly.com/mcp в ваш MCP-клиент. Один инструмент — generate_qr — без авторизации. Работает с Claude Code, Cursor и всем, что говорит по Streamable HTTP.

🌐 HTTP API

Простой GET-эндпоинт, возвращающий SVG. CORS открыт полностью, так что браузеры, curl и бессерверные функции могут вызывать его напрямую.

📜 Навык для агента

В репозитории лежит SKILL.md с рецептами полезных нагрузок: skills/qr-generator/. Направьте на него вашего агента — остальное он знает сам.

🤖 llms.txt

/llms.txt описывает весь сайт для краулеров и ассистентов — эндпоинты, форматы полезных нагрузок и карта страниц в одном файле.

HTTP API

GET https://freeqrly.com/api/qr?data=TEXT&size=1024&margin=4&color=2F4A62&bgcolor=ffffff&ecc=M

Возвращает image/svg+xml. Обязателен только data; у остального разумные значения по умолчанию. Ошибки возвращаются как JSON с полем error.

curl "https://freeqrly.com/api/qr?data=https://example.com&size=1024" \
  -o qr.svg

# WiFi QR code for guests
curl "https://freeqrly.com/api/qr?data=WIFI:T:WPA;S:CafeNet;P:s3cret;;" \
  -o wifi.svg

Параметры

  • data — текст для кодирования (обязательно, макс. 2000 символов). URL, WiFi-строки, vCard, обычный текст.
  • size — размер вывода в px, 128–2048 (по умолчанию 1024).
  • margin — тихая зона в модулях, 0–10 (по умолчанию 4).
  • color / bgcolor — 6-значный hex, без # (по умолчанию 2F4A62 / ffffff).
  • ecc — коррекция ошибок L, M, Q, H (по умолчанию M). Для печати или логотипов используйте Q/H.

MCP

POST https://freeqrly.com/mcp

Стандартный Streamable HTTP: initialize, затем tools/list / tools/call. Инструмент generate_qr принимает data, size, color, bgcolor, ecc и возвращает готовую к скачиванию ссылку на SVG.

{
  "jsonrpc": "2.0", "id": 1, "method": "tools/call",
  "params": {
    "name": "generate_qr",
    "arguments": { "data": "https://example.com", "size": 1024 }
  }
}

Рецепты полезных нагрузок

Website : https://example.com/menu
WiFi    : WIFI:T:WPA;S:CafeNet;P:s3cret;;
Contact : BEGIN:VCARD\nVERSION:3.0\nN:Ada Lovelace\nTEL:+15550100\nEND:VCARD
Place   : geo:37.7749,-122.4194
SMS     : sms:+15550100?body=Hello

Добросовестное использование

Бесплатно, но будьте вежливы: кэшируйте результаты вместо повторных запросов одного и того же кода и держите автоматический трафик в разумных пределах. Действуют ограничения на IP. Статические коды детерминированы — один и тот же ввод всегда даёт один и тот же вывод, так что кэширование тривиально.
