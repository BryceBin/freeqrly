Полезно знать

Сколько QR-кодов можно сделать за раз?

До 50 за пакет. Нужно больше? Запустите ещё пакет — нет ни дневного лимита, ни аккаунта, в который можно упереться.

Пакетная генерация правда бесплатна?

Да. Многие генераторы берут подписку за массовый экспорт; здесь тот же бесплатный инструмент, без водяных знаков, без регистрации для статических кодов.

В каком формате будут загрузки?

Один ZIP с PNG в высоком разрешении (1024 px), каждый с именем qr-1.png, qr-2.png и так далее — готово к печати.

Можно ли добавить логотип в пакетные коды?

Загрузите логотип один раз — он применится ко всему пакету, а коррекция ошибок поднимется автоматически, чтобы каждый код остался сканируемым.
