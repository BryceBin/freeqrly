Полезно знать

Какой формат штрихкода выбрать?

Code 128 — для общего использования, он хранит любой текст. EAN-13 — для розничных товаров, продаваемых по всему миру, UPC-A — для розничной торговли в США, Code 39 — когда сканер старый или код должен читаться человеком, ITF-14 — для транспортных коробок.

Нужна ли контрольная цифра?

Нет — для EAN-13, UPC-A и ITF-14 введите на одну цифру меньше, и контрольная цифра будет рассчитана за вас. Code 128 и Code 39 в ней не нуждаются.

PNG или SVG для печати?

SVG — для упаковки и профессиональной печати: масштабируется бесконечно без размытия. PNG — для офисной печати и приложений, не принимающих SVG.

Это правда бесплатно? Без водяных знаков?

Бесплатно, без водяных знаков, без регистрации. Штрихкод рисуется в вашем браузере — ничего не загружается.
