Gut zu wissen

Laufen kostenlose QR-Codes ab?

Nie. Das Ziel ist direkt im Muster codiert — der Code funktioniert, solange das Ziel existiert. Bezahlte dynamische Codes laufen über Server des Anbieters und können sterben, wenn du nicht mehr zahlst — ein Grund mehr für statisch.

Ist mein WLAN-Passwort hier sicher?

Bei einem statischen Code ja. Dein Passwort verlässt nie deinen Browser — nichts wird irgendwohin gesendet. Vorsichtig? Seite laden, offline gehen, dann tippen.

Statisch oder dynamisch?

Wenn sich das Ziel nicht ändert: statisch — WLAN, Visitenkarten, feste Links. Dynamische Codes (änderbare Links + Scan-Statistiken) sind für Kampagnen — jetzt live: kostenloses Konto, nach dem Druck änderbar, Scans im Blick.

Darf ich sie kommerziell nutzen?

Absolut. Alles, was du hier erstellst, gehört dir — Verpackungen, Speisekarten, Karten, ohne Namensnennung.

Ist FreeQrly wirklich kostenlos?

Ja — alles auf dieser Seite ist gratis, ohne Wasserzeichen. Statische ohne Konto. Wir verkaufen keine Abos; das hier ist ein Werkzeug, kein Trichter.

Brauche ich ein Konto?

Für statische nicht. Es gibt nichts anzumelden — Seite öffnen, Code erstellen. Dynamische brauchen ein kostenloses Konto, damit du sie nach dem Druck noch ändern kannst.

Kann ich mein Logo in den QR-Code setzen?

Ja — lade ein quadratisches Logo hoch, wir setzen es in die Mitte und erhöhen automatisch die Fehlerkorrektur, damit er scanbar bleibt. Für Druck: Q oder H.
