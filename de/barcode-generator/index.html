Gut zu wissen

Welches Barcode-Format soll ich nehmen?

Code 128 für den allgemeinen Gebrauch — er speichert jeden Text. EAN-13 für Produkte im internationalen Einzelhandel, UPC-A für den US-Einzelhandel, Code 39 bei alten Scannern oder wenn der Code menschenlesbar sein muss, ITF-14 für Versandkartons.

Brauche ich eine Prüfziffer?

Nein — bei EAN-13, UPC-A und ITF-14 gibst du eine Ziffer weniger ein, und die Prüfziffer wird für dich berechnet. Code 128 und Code 39 brauchen keine.

PNG oder SVG für den Druck?

SVG für Verpackungen und professionellen Druck — es skaliert unbegrenzt ohne Unschärfe. PNG für den Bürodruck und Apps, die kein SVG akzeptieren.

Ist es wirklich kostenlos? Irgendein Wasserzeichen?

Kostenlos, ohne Wasserzeichen, ohne Anmeldung. Der Barcode wird in deinem Browser gezeichnet — nichts wird hochgeladen.
