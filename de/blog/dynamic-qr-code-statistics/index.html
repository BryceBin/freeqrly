Was dir dynamische QR-Statistiken sagen

Ein dynamischer Code meldet sich bei jedem Scan. Hier steht, was FreeQrly zählt, wie du es liest — und was es nie sammelt.

16. Oktober 2026 · Zuletzt aktualisiert: 3. November 2026 · 15 Min. Lesezeit

Ein statischer Code ist stumm: Er meldet sich nie nach Hause, niemand – dich eingeschlossen – weiß also, wie oft er gescannt wurde. Ein dynamischer Code meldet jeden Scan an dein Dashboard. Hier steht, was FreeQrly zählt, wie man es liest, was es bewusst nie erhebt und wie du deine eigenen Zahlen nutzt, um Entscheidungen zu treffen – plus die einzigen externen Zahlen, die dieser Beitrag zitiert, jeweils mit ihrer Originalquelle, sodass du sie selbst prüfen kannst.

Die kurze Antwort zuerst: Scan-Statistiken beantworten drei Fragen und nur drei. Welche Platzierung hat Aufmerksamkeit bekommen? Wann hat sie sie bekommen? Und auf welcher Art von Gerät und von grob wo? Alles andere – ob aus einem Scan ein Kunde wurde, ob das Plakat gut war – ist eine Interpretation, die du obendrauf legst, und die meisten Fehldeutungen kommen daher, eine Interpretation zu behandeln, als wäre sie eine Messung.

Was FreeQrly zählt

Öffne einen dynamischen Code in deinem Dashboard und du siehst für jeden Code denselben Satz Zahlen. Die Definitionen zählen, denn zwei der häufigsten Fehldeutungen kommen daher, „gesamt“ mit „eindeutig“ und „heute“ mit „gesamt“ zu verwechseln.

Jede Aufschlüsselung kommt mit Zählungen und Prozentwerten. Prozentwerte sind Anteile an den Scans dieses Codes, nicht Anteile an etwas Größerem – ein Code mit meist iOS-Scans heißt nicht, dass die meisten deiner Kunden iPhones nutzen. Er heißt, dass die meisten Leute, die diesen Code gescannt haben, dies auf einem iPhone getan haben.

Zwei externe Zahlen, mit ihren Quellen dazu

Dieser Beitrag zitiert bewusst sehr wenige externe Zahlen, und der Grund lohnt es sich, schlicht zu nennen: Eine QR-Statistik, die aus einer Zusammenfassung entlehnt wurde, kommt meist ohne die drei Fakten an, die eine Zahl nutzbar machen – was gemessen wurde, bei wem und wann. Die zwei Zahlen unten kommen mit allen dreien, von ihren Originalverlagen.

Der QR-Standard selbst: Wie viel Schaden ein Code überleben kann

Scan-Statistiken sind nur die halbe Druckentscheidung; die andere Hälfte ist, ob der Code Handhabung überlebt. Der QR-Standard ISO/IEC 18004:2024 definiert vier Fehlerkorrekturstufen, die jeweils angeben, wie viel der Codewörter des Symbols wiederhergestellt werden kann, wenn es beschädigt ist:

StufeWiederherstellbare CodewörterTypische Nutzung
L7 %Saubere digitale Anzeige
M15 %Alltäglicher Innendruck
Q25 %Druck, der angefasst wird oder draußen lebt
H30 %Codes mit einem zentralen Logo oder bei rauer Handhabung

Quelle: ISO/IEC 18004:2024, die Spezifikation der QR-Code-Barcodesymbologie, über die ISO-Standardseite (iso.org/standard/83389.html). Lies die Prozentwerte sorgfältig: Sie beschreiben Codewörter, nicht gedruckte Fläche. Ein Code auf Stufe H überlebt nicht jedes mögliche 30-%-Loch im Druck, und eine höhere Stufe kauft Belastbarkeit, indem sie mehr vom Code für Redundanz ausgibt. Für Statistiken der praktische Punkt: Ein Code, der auf einer angefassten Fläche auf niedriger Stufe gedruckt wurde, wird sein wahres Publikum unterberichten – Leute versuchten zu scannen, der Code versagte, und kein Scan wurde aufgezeichnet.

Wer ein Kamera-Handy trägt: Pews US-Umfrage

Wenn du eine Geräteaufschlüsselung liest, hilft es, die Obergrenze zu kennen: Wie viele Leute im Publikum konnten überhaupt scannen. Pews mobiles Fact Sheet 2026 berichtet, dass 91 % der Erwachsenen in den USA sagten, sie besäßen ein Smartphone, und 98 % sagten, sie besäßen irgendein Handy, gegenüber 35 % Smartphone-Besitz in der ersten solchen Umfrage des Centers im Jahr 2011. Quelle: Pew Research Center, „Americans' Use of Mobile Devices in 2026“ (pewresearch.org/internet/fact-sheet/mobile/), basierend auf einer Umfrage unter 5.511 Erwachsenen in den USA, durchgeführt vom 30. Januar bis 18. Juni 2026, mit einer Gesamtfehlerspanne von plus/minus 1,8 Prozentpunkten.

Drei Warnungen reisen mit dieser Zahl mit, und sie gelten für jede externe Zahl, der du begegnest. Erstens, Bevölkerung: Das sind Erwachsene in den USA, nicht die Welt und nicht die Gästeliste deines Events. Zweitens, Messgröße: selbstberichteter Besitz, nicht Scan-Verhalten. Drittens, Datum: Eine Umfrage von 2026 beschreibt 2026. Eine Zahl, die außerhalb ihrer Bevölkerung, ihrer Messgröße oder ihres Datums genutzt wird, hört auf, Beleg zu sein, und wird Deko.

So liest du deine eigenen Zahlen: fünf Fragen

Deine Dashboard-Zahlen brauchen keinen externen Benchmark, um nützlich zu sein. Jage jede Lesart durch diese fünf Fragen, bevor du danach handelst:

  1. Verglichen womit? Die Summe eines Codes heißt allein wenig. Vergleiche Codes, die im selben Zeitraum, in ähnlichen Platzierungen, für dasselbe Angebot liefen. Ein Flyer-Code und ein Plakat-Code aus derselben Woche lassen sich vergleichen; ein Flyer-Code vom letzten Frühling und ein Plakat-Code von dieser Woche nicht, denn Saison, Angebot und Publikum haben sich dazwischen alle geändert.
  2. Über welchen Zeitraum? Das 7-Tage-Diagramm existiert, um Einzeltages-Lesarten zu stoppen. Ein Code, der an einem Montag tot aussieht, kann ein Abend-Code, ein Wochenend-Code oder ein Pendlerstrecken-Code sein. Lies die Form der Woche, bevor du die Höhe eines Tages beurteilst.
  3. Gesamt oder eindeutig? Wenn „gesamt“ weit vor „eindeutig“ läuft, kommen dieselben Leute zurück – was gut ist für eine Speisekarte oder einen Fahrplan und ein Warnzeichen für ein einmaliges Angebot. Wenn „eindeutig“ nah an „gesamt“ läuft, ist jeder Scan eine andere Person, und der Code erreicht breit statt tief.
  4. Was ist sonst an diesem Tag passiert? Ausschläge brauchen Kontext. Ein Scan-Schub direkt nach einem Post ist der Post, nicht das Plakat. Ein Schub an einem Tag, an dem du das Ziel geändert hast, ist das neue Ziel, nicht die alte Platzierung. Notiere externe Ereignisse – ein Post, eine Erwähnung, eine Preisänderung – neben dem Diagramm, oder das Diagramm wird dich mit perfekter Zuversicht irreführen.
  5. Wozu hat der Scan geführt? Ein Scan ist ein Blick, keine Conversion. Kopple Scan-Statistiken mit dem, was das Ziel selbst misst – Formular-Einreichungen, Bestellungen, Anmeldungen –, und beurteile den Code nach dem Ergebnis des Ziels, nicht allein nach der Scan-Zahl.

Eine echte Woche lesen: Muster, nicht nur Summen

Dieselben Aufschlüsselungen, als Verhalten gelesen statt als Zahlen:

  • Nur-Abend-Scans. Ein Code, der nach Feierabend aufwacht, steht wahrscheinlich auf einer Pendlerstrecke oder an einem Abend-Veranstaltungsort – Abendbesucher, nicht Bürobesucher.
  • Eine plötzlich neue Stadt. Scans, die sich in eine Stadt ausbreiten, in der du nie gedruckt hast, heißen meist, jemand hat den Code in einem Chat oder Post geteilt – der Code ist ohne dich gereist. Prüfe, wohin der Code zeigt: Ein geteilter Code schickt Fremde zu deinem Ziel, das Ziel sollte also für einen Fremden Sinn ergeben.
  • Nur wochentags gescannt. Ein Code, der am Wochenende verstummt, hängt wahrscheinlich an einem Büroposter oder einem Wochentags-Lokal, nicht an einem Wochenend-Lokal.
  • Desktop-lastige Scans. Ein Plakat, das Desktop-Scans bekommt, wird wahrscheinlich aus einem Screenshot oder einem weitergeleiteten Bild gescannt, nicht von der Wand. Die Wandversion kann in Ordnung sein; die Screenshot-Version macht die Arbeit, und das Ziel sollte auch auf einem Desktop-Bildschirm geprüft werden, nicht nur auf einem Handy.
  • Null ist ein Datum. Ein Code ohne Scans über eine Woche sagt dir, dass die Platzierung falsch ist, nicht der Code. Codes versagen selten leise – ein gedruckter Code scannt entweder oder nicht, und ein schneller Test mit dem eigenen Handy klärt das in Sekunden. Wenn er scannt und niemand ihn scannt, ist das Problem Position, Größe, Kontrast oder das Fehlen eines Scan-Grunds, in dieser Reihenfolge.

Ein durchgerechnetes Beispiel, mit gezeigter Rechnung

Anschauliches Beispiel – die Zahlen unten sind hypothetisch, nur um die Rechnung zu zeigen, keine Messungen aus einer echten Kampagne. Angenommen, zwei Codes zeigen für dieselben zwei Wochen auf dieselbe Seite. Code A, auf einem Tresenschild, verzeichnet 120 Gesamt-Scans und 90 eindeutige Scans. Code B, auf einem Schaufensterplakat, verzeichnet 60 Gesamt-Scans und 55 eindeutige Scans. Drei Lesarten folgen, jede mit einer anderen Handlung:

  • Reichweite: Code A erreichte mehr unterschiedliche Leute (90 gegen 55), das Tresenschild ist also die breitere Platzierung.
  • Wiederholte Nutzung: Code As Summe läuft 30 Scans vor seiner eindeutigen Zahl, während Code Bs nur 5 vorausläuft, Tresenbesucher scannen also wiederholt, während Plakatbesucher meist einmal scannen. Das passt zu einem Tresenschild, das Stammkunden sehen, und einem Plakat, das Passanten sehen – und es legt nahe, dass das Ziel des Tresen-Codes einen zweiten Besuch belohnen sollte, während das Ziel des Plakat-Codes seinen Fall in einem Besuch machen sollte.
  • Nächster Test: Noch nichts tauschen. Bewege Code Bs Plakat für eine Woche zum Tresen und Code As Schild zum Fenster und vergleiche dann erneut. Wenn das Muster der Platzierung folgt, war die Platzierung die Ursache. Wenn das Muster dem Code folgt, waren Ziel oder Design die Ursache. Ein Tausch schlägt einen Monat Debatte darüber, welches Schild besser ist.

Die Disziplin in diesem Beispiel ist der Punkt, nicht die Zahlen: derselbe Zeitraum, dasselbe Ziel, eine Änderung nach der anderen und eine Entscheidungsregel, die geschrieben wurde, bevor der Test läuft.

Einen Vergleich aufbauen, dem du trauen kannst

  1. Gib jeder Platzierung ihren eigenen dynamischen Code. Ein Code pro Platzierung – Tresen, Fenster, Flyer, Beleg –, alle zeigen auf dasselbe Ziel. Geteilte Codes können Platzierungen nicht auseinanderhalten, und ein Vergleich, der auf einem geteilten Code aufbaut, ist Raten mit Diagramm.
  2. Halte das Ziel identisch. Wenn zwei Codes auf verschiedene Seiten zeigen, testest du Seiten, nicht Platzierungen. Teste eine Variable nach der anderen.
  3. Lass sie über denselben Zeitraum laufen. Starte und ende gemeinsam, durch dieselben Wochentage und Wochenenden. Ein Code, der über ein Feiertagswochenende lief, ist nicht vergleichbar mit einem, der über eine gewöhnliche Woche lief.
  4. Notiere, was sonst passiert ist. Führe ein einzeiliges Protokoll neben dem Diagramm: Post veröffentlicht, Preis geändert, Veranstaltungsort geschlossen. Ausschläge ohne Notizen werden zu Rätseln.
  5. Entscheide die Handlung, bevor du schaust. Schreibe auf, was du tun wirst, wenn A B übertrifft – B bewegen, B neu drucken, B ausmustern –, bevor du die Statistiken öffnest.
  6. Handle nach dem Ergebnis und miss dann erneut. Bewege den schwachen Code, ändere das Ziel des starken oder mustere den stillen aus – und beobachte das nächste 7-Tage-Diagramm auf die Änderung. Eine Statistik, die nie eine Entscheidung ändert, war Unterhaltung, keine Messung.

Was FreeQrly nie sammelt

Stats sind Aggregate – es gibt keinen Datensatz pro Besucher, den man sich ansehen könnte. Ein „eindeutiger Scan“ ist ein Einweg-Hash aus der IP-Adresse des Scanners, dem Browser und dem Datum: genug, um unterschiedliche Scanner pro Tag zu zählen, unmöglich, in eine Person zurückzuverwandeln. Keine Namen, keine E-Mails, keine exakten Standorte, kein Cross-Code-Tracking von Einzelpersonen. Und statische Codes tracken gar nichts – sie berühren nie einen Server, es gibt also nichts zu zählen.

Diese Grenze formt, was du von den Statistiken verlangen solltest. Du kannst fragen, welche Platzierung gewonnen hat, wann sie gewonnen hat und auf welchen Geräten. Du kannst nicht fragen, wer gescannt hat: Ein Scan trägt keine Identität, und jede Identität, die daran hängt, kam von woanders. Wenn deine Entscheidung wirklich wissen muss, wer reagiert hat, lege ein Formular hinter den Code und lass Leute sich dort freiwillig identifizieren.

Was Scan-Statistiken dir nicht sagen können

  • Scans sind keine Kunden. Ein Scan ist ein Blick. Jemand kann aus Neugier scannen, aus Versehen oder um es einem Freund zu zeigen, und nichts davon ist ein Verkauf. Beurteile das Ergebnis des Ziels, nicht die Scan-Zahl.
  • Scans sind keine Zufriedenheit. Ein stark gescannter Code auf einem Beschwerdeformular ist keine Erfolgsgeschichte. Lies den Inhalt des Ziels neben den Zählungen.
  • Durchschnitte verbergen die Form. Zwei Codes mit derselben Wochensumme können entgegengesetzte Muster haben – einer stetig, einer sprunghaft –, und der stetige ist meist die gesündere Platzierung. Lies immer das 7-Tage-Diagramm, nicht nur die Summe.
  • Stille ist mehrdeutig. Null Scans können eine schlechte Platzierung, einen beschädigten Druck, ein geändertes Ziel oder einen Code bedeuten, der gedruckt wurde, wo niemand hinschaut. Teste den Druck mit deinem eigenen Handy, bevor du irgendetwas über das Publikum schließt.
  • Externe Benchmarks irreführen mehr, als sie helfen. Eine Zahl, die ohne ihre Bevölkerung, Messgröße und Datum zitiert wird, lässt sich nicht mit deinen Codes vergleichen, denn du weißt nicht, was sie gezählt hat. Von Anbietern veröffentlichte Zahlen verdienen eine zusätzliche Prüfung: Lies sie als den eigenen Bericht des Anbieters über seine eigenen Nutzer und suche nach der Methodik-Seite, die angibt, wer befragt wurde und wie. Eine Zahl, deren Originalseite ihre Methode angibt, kann genutzt werden, mit ihrem Umfang dazu; eine Zahl, die aus zweiter Hand getragen wird, ihrer Methode beraubt, sollte ganz aus deiner Entscheidung herausgelassen werden. Darum stützt sich dieser Beitrag auf dein eigenes Dashboard und auf zwei Quellen auf Standard-Niveau statt auf eine Zusammenfassung entlehnter Prozentwerte.

Eine wöchentliche Routine, die zehn Minuten dauert

  • Öffne jeden Live-Code und lies zuerst die Form des 7-Tage-Diagramms, dann die Summen.
  • Vergleiche Platzierungen, die nebeneinander liefen, derselbe Zeitraum, dasselbe Ziel.
  • Bewege, leite um oder mustere die schwächste Platzierung aus – eine Änderung, nicht fünf.
  • Prüfe das Ziel auf dem Gerät, das die meisten Scanner in dieser Woche genutzt haben.
  • Notiere jedes externe Ereignis neben dem Diagramm, damit der Ausschlag der nächsten Woche schon eine Erklärung bereit hat.

Mach das einen Monat lang wöchentlich und die Statistiken werden zu einer Gewohnheit, die Schilder bewegt und tote Platzierungen ausmustert.

Gut zu wissen

Was zählt als unique Scan?

Ein Scanner, einmal pro Tag. FreeQrly zählt unterschiedliche Scanner über einen Einweg-Hash aus IP-Adresse, Browser und Datum — dieselbe Person, die zweimal am Tag scannt, zählt einmal.

Tracken statische QR-Codes Scans?

Nein. Statische Codes berühren nie einen Server – das Ziel lebt im Muster –, es gibt also nichts zu zählen. Nur dynamische Codes melden Scans.

Sind Besucherdaten privat?

Ja. Nur Aggregate: Zahlen nach Tag, Land, Stadt, Gerät und Betriebssystem. Keine Namen, E-Mails, exakte Standorte oder Datensätze pro Besucher. Unique Scans nutzen einen nicht umkehrbaren Hash.

Kann ich sehen, wer meinen QR-Code gescannt hat?

Nein – und das ist Absicht. FreeQrly zählt Scans; es identifiziert keine Scanner. Ein Scan trägt keine Identität, wenn eine Entscheidung also wissen muss, wer reagiert hat, lege ein Formular hinter den Code und lass Leute sich dort freiwillig identifizieren.

Warum zeigt ein Code weit mehr Gesamt-Scans als eindeutige Scans?

Weil dieselben Leute wiederholt scannen. Eine Summe, die weit vor der eindeutigen Zahl liegt, passt zu einem Code, den Stammkunden sehen, etwa einem Tresenschild oder einer Speisekarte; eine Summe nah an der eindeutigen Zahl passt zu einem Code, den meist Passanten sehen. Vergleiche die zwei Zahlen zusammen – allein verbirgt „gesamt“ wiederholte Nutzung.

Mein Code zeigt null Scans – ist er kaputt?

Nicht unbedingt. Teste zuerst den Druck mit deinem eigenen Handy: Wenn er scannt, ist das Problem Platzierung, Größe, Kontrast oder das Fehlen eines Scan-Grunds, in dieser Reihenfolge. Null Scans über eine Woche sind Daten über die Platzierung, kein Beweis, dass der Code versagt hat. Wenn er nicht scannt, prüfe Schaden, Kontrast und Größe, bevor du irgendetwas über das Publikum schließt.

Wie vergleiche ich zwei Platzierungen fair?

Gib jeder Platzierung ihren eigenen dynamischen Code, der auf dasselbe Ziel zeigt, lass sie über denselben Zeitraum durch dieselben Wochentage und Wochenenden laufen und entscheide die Handlung, bevor du schaust – was du tun wirst, wenn einer den anderen übertrifft. Notiere alles andere, was in dieser Woche passiert ist, etwa einen Post, der rausging, neben dem Diagramm.

Warum zitiert dieser Beitrag so wenige externe Statistiken?

Weil eine externe Zahl nur mit ihrer Messgröße, ihrer Bevölkerung und ihrem Datum dazu nutzbar ist. Dieser Beitrag zitiert zwei Zahlen, die mit allen dreien von ihren Originalverlagen kommen – die ISO-QR-Fehlerkorrekturstufen und Pews US-Smartphone-Umfrage –, und stützt sich für den Rest auf dein eigenes Dashboard. Eine Zahl, die aus zweiter Hand getragen wird, ihrer Methode beraubt, wird hier aus Entscheidungen herausgelassen.
