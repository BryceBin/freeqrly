Ein QR-Code auf deiner Visitenkarte sollte den Kontakt speichern, nicht nur clever aussehen

Eine Visitenkarte hat nach dem Händedruck eine Aufgabe: den nächsten Schritt leicht machen. Ein QR-Code kann diese Aufgabe mit einem einzigen Scan erledigen, aber nur, wenn er auf etwas Nützliches verlinkt, dort sitzt, wo ein Handy ihn wirklich findet, und groß genug bleibt, um auf einer kleinen Karte gelesen zu werden. Dieser Leitfaden geht Layout, Größe und Ziel durch, damit deine Karte einen Monat später in einer Brieftasche genauso gut funktioniert wie auf der Veranstaltung.

4. November 2026 · 14 Min. Lesezeit

Eine Visitenkarte ist eine kleine Fläche, die viel beweisen muss. Name, Rolle, Firma, Telefon, E-Mail und Website konkurrieren ohnehin schon um Platz, und ein QR-Code kann aus einer sauberen Karte leicht eine überfüllte machen. Die Lösung ist, zu entscheiden, wofür der Code ist, bevor du entscheidest, wohin er kommt. Wenn der Code nur die Website wiederholt, die daneben im Klartext gedruckt ist, bringt er wenig. Wenn er den Kontakt speichert, eine Buchungsseite öffnet oder die Leserin oder den Leser auf eine Seite schickt, die sie wirklich brauchen, verdient er seine Ecke auf der Karte.

Fang bei der Leserin oder dem Leser an, nicht beim Design. Jemand, der dich auf einer Konferenz, einer Messe oder einem Kundentermin trifft, will meist eines von zwei Dingen: deine Kontaktdaten korrekt gespeichert oder einen klaren nächsten Schritt. Ein vCard-Code ist für die erste Aufgabe gebaut. Er speichert strukturierte Kontaktfelder wie Name, Telefon, E-Mail, Firma, Berufsbezeichnung und Website in einem Standardformat, das Handys erkennen, und das Scannen kann das Handy dazu veranlassen, die Details als neuen Kontakt anzubieten. Ein Link-Code ist besser für die zweite Aufgabe, etwa ein Portfolio, eine Buchungsseite, eine Produktseite oder eine kurze Vorstellungsseite. Beide Aufgaben in einem Code zu vermischen, hilft selten. Ein Code, der gleichzeitig einen Kontakt speichern und ein Produkt verkaufen will, lässt die Leserin oder den Leser unsicher, was beim Scannen passieren wird.

Die Wahl zwischen einem statischen und einem dynamischen Code zählt auf einer Visitenkarte mehr als auf einem Flyer, denn Karten werden in Chargen gedruckt und über Wochen oder Monate verteilt. Ein statischer vCard-Code trägt die Details im Muster selbst, was bedeutet, dass er im Moment des Scannens ohne Internetverbindung funktioniert, aber nach dem Druck nicht geändert werden kann. Wenn sich deine Telefonnummer, E-Mail oder Berufsbezeichnung ändert, werden die alten Karten auf eine Weise falsch, die schwer zu beheben ist. Ein dynamischer Link-Code verweist auf ein kurzes Ziel, das du später aktualisieren kannst, sodass eine neue Rolle, eine neue Telefonnummer oder eine neue Zielseite keinen Neudruck erzwingt. Diese Flexibilität ist der Hauptgrund, einen dynamischen Code für alles zu nutzen, was sich ändern könnte, und einen statischen vCard-Code für Details zu reservieren, bei denen du sicher bist, dass sie stabil bleiben. Wenn du unsicher bist, welche Art von Code passt, lies statische vs. dynamische Codes, bevor du die Karte in den Druck gibst.

Worauf sollte der Code verlinken?

Für die meisten Leute ist die sicherste Voreinstellung ein Kontaktspeichern oder eine einzige, fokussierte Seite. Ein vCard ist ideal, wenn das Treffen selbst der Punkt ist: Die andere Person will sich an dich erinnern, dich anrufen oder dir später mailen, und die korrekte Schreibweise deines Namens oder deiner Adresse zählt. Halt die vCard schlank. Name, eine Handynummer, eine E-Mail-Adresse, Firma und Website decken fast jede echte Nachfassaktion ab, und jedes zusätzliche Feld macht das Muster dichter und bei Kartengröße schwerer zu lesen. Nutz ein internationales Telefonformat mit Landesvorwahl, damit die Nummer auch funktioniert, wenn die Karte ins Ausland reist, und nutz eine E-Mail-Adresse, die du voraussichtlich behalten wirst. Eine persönliche Adresse, die bei einem Jobwechsel verschwindet, ist eine schlechte Wahl für eine Karte, die ein Jahr in einer Schublade liegen könnte.

Ein Link-Code ergibt Sinn, wenn die Karte wirklich eine Einladung ist. Eine Designerin verlinkt vielleicht auf ein Portfolio, ein Berater auf eine Buchungsseite, eine Gründerin auf eine einseitige Vorstellung und eine Verkäuferin auf eine Produktdemo. In jedem Fall sollte die Zielseite die Frage beantworten, die die Karte aufwirft, nicht die Leserin oder den Leser auf eine generische Startseite werfen. Wenn die Karte sagt, dass du Restaurantmenüs gestaltest, sollte der Scan bei Menüs landen, nicht auf einer Startseite, auf der Menüs nur ein Punkt unter vielen sind. Ergänz eine kurze Beschriftung neben dem Code, etwa „Scannen, um meinen Kontakt zu speichern“ oder „Scannen, um einen Anruf zu buchen“, damit die Leserin oder der Leser weiß, was sie erwartet. Ein nackter Code ohne Beschriftung verlangt Vertrauen, ohne einen Grund zu geben, und viele Leute werden ihn einfach nicht scannen.

Es gibt Ziele, die auf einer Visitenkarte zu vermeiden sind. Verlink nicht auf eine Seite, die ein Konto, ein langes Formular oder einen Download verlangt, bevor die Leserin oder der Leser irgendeinen Wert bekommt. Verlink nicht auf ein Social-Media-Profil, das du selten aktualisierst, oder auf eine Seite voller konkurrierender Handlungsaufforderungen. Und nutz einen Code nicht als Ersatz für die wesentlichen gedruckten Details. Eine Karte sollte auch ohne Handy lesbar bleiben. Wenn der Handyakku leer ist, das Licht schlecht oder die Leserin oder der Leser Papier bevorzugt, sollten dein Name, deine Firma und mindestens eine Kontaktmethode trotzdem im Klartext sichtbar sein.

Layout: Gib dem Code Luft zum Atmen

Visitenkarten sind in den USA und Kanada üblicherweise 3,5 × 2 Zoll und im Vereinigten Königreich und weiten Teilen Europas 85 × 55 Millimeter groß. Dieser Unterschied ist klein, aber er zählt, wenn du einen Code, ein Logo und mehrere Textzeilen auf eine Seite unterbringen willst. Gestalte für den Markt, in dem die Karten wirklich verteilt werden, nicht nur für den Markt, in dem sie gedruckt werden, und bestätig Zuschnittgröße und Beschnitt mit deiner Druckerei, bevor du das Layout finalisierst. Ein Code, der zu nah an der Schnittkante sitzt, kann beschnitten werden, und ein Code, der in eine Ecke gequetscht wird, kann den klaren Rand verlieren, den er braucht.

Das zuverlässigste Layout setzt den Code auf die Rückseite der Karte oder in eine klare Zone auf der Vorderseite, wo er nicht mit Name und Titel konkurriert. Die Rückseite ist oft die bessere Wahl, denn sie gibt dem Code eine volle, aufgeräumte Fläche und lässt die Vorderseite für die Person frei. Wenn der Code sich die Vorderseite teilen muss, halt ihn auf einer Seite, richt ihn am Textblock aus statt ihn in der Mitte schweben zu lassen und lass die Ruhezone vollständig frei. Die Ruhezone ist der leere Rand um den Code herum, mindestens vier Module breit auf jeder Seite, und Scanner nutzen sie, um die Kanten des Symbols zu finden. Text, ein Rahmen, ein Logo oder ein Hintergrundmuster innerhalb dieses Rands kann einen Scan brechen, selbst wenn der Code selbst perfekt ist. Für eine praktische Anleitung zu diesem Rand und zu Druckgrößen allgemein sieh dir den Leitfaden zu QR-Code-Druckgrößen an.

Kontrast und Hintergrund zählen genauso viel wie die Position. Dunkle Module auf hellem Hintergrund bleiben die sicherste Wahl, und ein weißer oder sehr heller Fleck hinter dem Code ist den Platz auch auf einer dunklen oder bunten Karte wert. Den Code umzukehren, ihn in blasser Farbe auf einer dunklen Karte zu drucken oder ihn über ein Foto zu legen, mag eindrucksvoll aussehen, verlangt der Kamera aber mehr Arbeit genau unter den Bedingungen, unter denen Karten gescannt werden: dunkle Veranstaltungshallen, helles Sonnenlicht und eilige Hände. Wenn deine Markenfarbe unverzichtbar ist, nutz sie im umgebenden Design und in der Handlungsaufforderung und halt den Code selbst kontrastreich. Ein Logo in der Mitte des Codes ist möglich, aber es verdeckt einen Teil des Musters, also nutz eine höhere Fehlerkorrekturstufe und halt das Logo klein und fern von den drei großen Eckquadraten, die Scanner zur Orientierung des Symbols nutzen.

Größe: kleine Karte, fester Mindestwert

Visitenkarten werden aus nächster Nähe gescannt, meist mit dem Handy etwa 15 bis 25 Zentimeter entfernt gehalten, und das bestimmt die Größe. Eine weit verbreitete Faustregel besagt, dass der Code etwa ein Zehntel der Scan-Entfernung betragen sollte, was für eine Karte aus nächster Nähe auf rund 2 Zentimeter hinausläuft. Versteh das als Mindestwert, nicht als Ziel. Ein kurzer Link-Code kann mit etwa 2 Zentimetern funktionieren, aber ein vollerer vCard-Code oder ein Code mit Logo sollte mindestens 2,5 bis 3 Zentimeter breit sein, denn die zusätzlichen Daten machen das Muster dichter und die einzelnen Module bei gleicher physischer Größe kleiner. Ein Vergleich macht den Punkt klar: Ein kurzer Link kann einen Code von etwa 29 Modulen Breite ergeben, während ein längerer Kontaktdatensatz bei gleicher Fehlerkorrekturstufe einen Code von 61 Modulen oder mehr ergeben kann, sodass seine Module bei gleicher Druckbreite etwa halb so groß sind.

Dieser Dichteeffekt ist der Grund, warum sich ein schlankes Ziel auf einer Visitenkarte doppelt auszahlt. Ein kurzer Link oder eine schlanke vCard hält die Module größer, was älteren Handys, schlechtem Licht und strukturiertem Kartenmaterial hilft. Wenn du viele Details kodieren musst, gleich das aus, indem du den Code größer druckst, den Link hinter einem dynamischen Code verkürzt oder die zusätzlichen Details auf die Zielseite statt in den Code selbst verlagerst. Gleich das nicht aus, indem du die Ruhezone verkleinerst, die Druckauflösung senkst oder den Code dehnst, um eine Lücke zu füllen. Ein verzerrter Code ist keine kleinere Version eines guten Codes; er ist ein anderes, schlechter lesbares Muster. Exportier den Code als Vektordatei oder als hochauflösendes Bild in der endgültigen Druckgröße und prüf, ob die Druckerei ihn beim Einsetzen in die Kartendatei neu abgetastet, umgefärbt oder seinen Rand beschnitten hat.

Proof vor dem Druck der ganzen Charge

Der günstigste Scantest ist auch der überzeugendste: Druck eine Karte in Endgröße auf dem Endmaterial und scann sie mit mehr als einem Handy. Teste ihn in dem Licht, in dem er wirklich genutzt wird, aus der Entfernung, in der er wirklich gehalten wird, und mit der Karte leicht geneigt, wie Leute Karten wirklich halten. Teste auch das Ziel, nicht nur den Scan. Wird der Kontakt mit dem richtigen Namen und der richtigen Nummer gespeichert? Lädt die Zielseite schnell und liest sich gut auf einem Handy? Passt die Handlungsaufforderung auf dieser Seite zur Beschriftung neben dem Code? Ein Code, der auf die falsche Seite scannt, eine Seite, die zu viel verlangt, oder ein Kontakt, der mit falsch geschriebenem Namen gespeichert wird, machen den Vorteil einer sonst perfekten Karte zunichte.

Prüf die Details, die in einer Designdatei leicht übersehen werden. Bestätig, dass die Telefonnummer eine Landesvorwahl enthält, dass die E-Mail-Adresse korrekt geschrieben ist und dass die Websiteadresse die aktuelle Domain nutzt. Bestätig, dass der Code nach dem Anfassen der Karte weiterhin scannt, denn Glanz, Prägung, Folie und starke Textur können alle verändern, wie eine Kamera das Muster liest. Wenn du eine Sonderveredelung nutzt, prüf sie auf dieser Veredelung, nicht auf einfachem Papier. Wenn die Karte in zwei Größen oder zwei regionalen Formaten gedruckt wird, prüf jede Version separat, denn ein Code, der in einer Größe funktioniert, kann in der anderen versagen. Für einen strukturierten Durchlauf nutz die Vor-Druck-QR-Code-Checkliste neben deinem Drucker-Proof.

Wenn eine Karte versagt, geh die üblichen Ursachen der Reihe nach durch: Größe, Ruhezone, Kontrast, Dichte und Verzerrung. Vergrößer den Code, bevor du die Karte neu gestaltest, räum den Rand frei, bevor du die Farbe änderst, und kürz das Ziel, bevor du mehr Daten hinzufügst. Wenn das Problem bestehen bleibt, vereinfache. Eine Karte mit einem klaren Code und einer klaren Beschriftung schlägt eine Karte mit zwei konkurrierenden Codes, einem winzigen Code und keiner Erklärung – so clever das Design auf dem Bildschirm auch aussehen mag. Wenn ein Scan nach diesen Korrekturen immer noch fehlschlägt, sieh dir an, warum ein QR-Code möglicherweise nicht funktioniert, und warum ein QR-Code unscharf aussehen kann für die weiteren Fehlerbehebungsschritte an.

Wann neu drucken – und wann nicht

Ein dynamischer Link-Code verschafft dir Zeit, wenn sich Details ändern. Aktualisier das Ziel, teste die neue Seite von einer gedruckten Karte aus und verteil die Charge weiter. Ein statischer vCard-Code bietet diesen Ausweg nicht: Wenn sich die Details darin ändern, ist die ehrliche Lösung ein Neudruck, denn Karten zu verteilen, von denen du weißt, dass sie falsch sind, kostet mehr an verpassten Nachfassaktionen als eine neue Charge an Druckkosten. Das ist ein praktischer Grund, einen kleinen Vorrat an Karten zu behalten statt auf einmal eine sehr große Charge zu drucken, wenn sich deine Rolle, Firma oder Kontaktdaten bald ändern könnten. Es ist auch ein Grund, die stabilsten Details in den Druck zu geben und die veränderlichsten Details hinter einen dynamischen Link zu legen, damit die Karte nützlich bleibt, auch wenn sich deine Arbeit ändert.

Schließlich: Denk daran, dass die Karte immer noch ein menschliches Objekt ist. Der Code sollte das Gespräch unterstützen, nicht ersetzen. Stell dich vor, schreib eine Notiz auf die Karte, wenn der Moment es verlangt, und lass den Scan den Teil übernehmen, den Menschen falsch machen: Schreibweise, Vorwahlen und lange Webadressen. Eine Visitenkarte mit einem gut platzierten, gut dimensionierten, klar beschrifteten Code macht genau das. Sie verwandelt ein kurzes Treffen in einen gespeicherten Kontakt oder einen gebuchten nächsten Schritt, ohne dass die andere Person etwas tippen, sich etwas merken oder raten muss, was du von ihr wolltest.

Gut zu wissen

Wie groß sollte ein QR-Code auf einer Visitenkarte sein?

Ziel auf mindestens 2 cm für einen kurzen Link-Code und 2,5 bis 3 cm für einen volleren vCard-Code oder einen Code mit Logo. Karten werden meist aus 15 bis 25 cm Entfernung gescannt, also deutet die 10-zu-1-Faustregel auf etwa 2 cm als Mindestwert hin, und dichtere Codes brauchen mehr Platz.

Sollte der Code meinen Kontakt speichern oder auf meine Website verlinken?

Speicher den Kontakt, wenn das Treffen selbst der Punkt ist, und verlink auf eine fokussierte Seite, wenn die Karte eine Einladung zu einem Portfolio, einer Buchungsseite oder einer Demo ist. Versuch nicht, beide Aufgaben mit einem einzigen Code zu erledigen, und beschrifte den Code, damit die Leserin oder der Leser weiß, was passieren wird.

Ist ein vCard-Code besser als ein Link-Code für eine Visitenkarte?

Ein vCard ist besser für ein sauberes Kontaktspeichern, denn die Details stecken im Code und können ohne Tippen als neuer Kontakt angeboten werden. Ein Link-Code ist besser, wenn sich Details ändern können, denn ein dynamischer Link lässt sich aktualisieren, ohne die Karten neu zu drucken.

Kann ich das Ziel nach dem Druck der Karten noch ändern?

Nur, wenn der Code dynamisch ist. Ein dynamischer Code verweist auf ein Ziel, das du später aktualisieren kannst. Ein statischer vCard-Code trägt seine Details im Muster, sodass eine Änderung von Telefon, E-Mail oder Titel einen Neudruck bedeutet.

Wo gehört der Code auf der Karte hin?

Die Rückseite der Karte ist meist am besten, denn sie gibt dem Code eine klare Fläche und lässt die Vorderseite für deinen Namen und Titel frei. Wenn er sich die Vorderseite teilt, halt ihn auf einer Seite, am Text ausgerichtet, mit vollständig freier Ruhezone.

Kann ich mein Logo in die Mitte des Codes setzen?

Ja, wenn du das Logo klein hältst, fern von den drei Eckquadraten, und eine höhere Fehlerkorrekturstufe wie Q oder H nutzt. Teste die gedruckte Karte auf mehr als einem Handy, denn ein Logo, das auf dem Bildschirm gut aussieht, kann einen kleinen gedruckten Code trotzdem brechen.

Sollte ich Telefon und E-Mail trotzdem auf die Karte drucken?

Ja. Die Karte sollte ohne Handy funktionieren. Druck mindestens deinen Namen, deine Firma und eine Kontaktmethode im Klartext, damit ein leerer Akku, schlechtes Licht oder eine Leserin oder ein Leser, die Papier bevorzugt, den Kontakt nicht verliert.

Warum scannt mein Code auf dem Bildschirm, aber nicht auf der gedruckten Karte?

Die üblichen Ursachen sind Größe, eine bedrängte Ruhezone, niedriger Kontrast, ein dichteres Muster, als die gedruckte Größe tragen kann, oder Verzerrung aus der Druckdatei. Mach einen Proof in Endgröße auf Endmaterial, vergrößer den Code, räum den Rand frei und kürz das Ziel, bevor du die Karte neu gestaltest.
