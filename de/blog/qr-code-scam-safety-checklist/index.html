Erkenn einen gefälschten QR-Code, bevor du ihn scannst

Ein QR-Code ist ein Link, den du mit deinen Augen nicht lesen kannst – genau deshalb mögen Betrüger ihn. Diese Checkliste gibt dir zwei Pausen, die die meisten QR-Betrugsversuche stoppen: eine schnelle Prüfung vor dem Scannen und ein sorgfältiges Lesen der Vorschau nach dem Scannen.

4. November 2026 · 14 Min. Lesezeit

Ein QR-Code ist ein Link, den du mit deinen Augen nicht lesen kannst. Das macht ihn bequem, und das macht ihn auch für Betrüger nützlich. Ein Code an einer Parkuhr, auf einem Plakat, auf einem Paket oder in einer Nachricht kann gewöhnlich aussehen und dabei auf eine gefälschte Anmeldeseite, eine Bezahlseite, die du nie besuchen wolltest, oder einen Download verweisen, den du nie angefordert hast. Die meisten QR-Betrugsversuche scheitern, wenn du an zwei Momenten langsamer wirst: vor dem Scannen und nachdem dein Handy dir das Ziel zeigt.

Wie ein QR-Code-Betrug üblicherweise funktioniert

Die meisten QR-Betrugsversuche, oft Quishing genannt – QR-Phishing –, folgen demselben Muster. Ein Betrüger versteckt einen schädlichen Link in einem Code und gibt dir dann einen Grund, ihn in Eile zu scannen. Die Federal Trade Commission (FTC) warnte in ihrer Verbraucherwarnung vom Dezember 2023, dass Betrüger echte Codes an Parkuhren mit eigenen Codes überdecken und Codes per SMS oder E-Mail mit erfundenen Geschichten senden: ein Paket, das nicht zugestellt werden konnte, ein Problem mit einem Konto oder verdächtige Aktivität, die angeblich eine Passwortänderung erfordert. Jede Geschichte ist darauf ausgelegt, Dringlichkeit zu erzeugen, sodass du den Code scannst und den Link öffnest, ohne darüber nachzudenken.

Nach dem Scannen ist die Falle meist die Seite hinter dem Code statt der Code selbst. Die FTC beschreibt eine gefälschte Seite, die echt aussieht, aber es nicht ist: Wenn du dich dort anmeldest, können die Betrüger alles stehlen, was du eingibst, und ein schlechter Code kann auch versuchen, Malware zu installieren. ESET, das über Quishing schreibt, macht einen verwandten Punkt: Weil das Ziel in einem visuellen Muster kodiert ist statt als lesbarer Text ausgeschrieben, bleibt es bis zum Scan verborgen, und manche traditionellen E-Mail-Filter können es nicht so prüfen wie einen sichtbaren Link. Nichts davon bedeutet, dass QR-Codes an sich unsicher sind. Es bedeutet, dass die Prüfung nach dem Scan stattfinden muss, in der Vorschau, die dein Handy dir zeigt, bevor du durchtippst.

Vor dem Scannen: die Fünf-Sekunden-Prüfung

Deine Handykamera kann dir nicht sagen, ob ein gedruckter Code manipuliert wurde. Deine Augen können helfen. Geh diese Prüfungen durch, bevor du deine Kamera auf irgendetwas richtest.

1. Such nach einem Aufkleber über dem echten Code

Fühl und schau dir die Ränder an. Ein Aufkleber über einem gedruckten Schild hat oft einen sichtbaren Rand, eine leicht erhabene Kante, eine andere Glanz- oder Papierstruktur oder sich lösende Ecken. Wenn der Code auf einem anderen Code, einem Logo oder gedrucktem Text sitzt, behandel ihn als verdächtig. Das ist der klassische Parkuhren-Trick, den die FTC beschreibt: Der echte Bezahlcode ist verdeckt und die Zahlung geht stattdessen an den Betrüger. Wenn irgendetwas geschichtet aussieht, scann es nicht. Bezahl stattdessen über die offizielle App, die Uhr selbst oder die Veranstaltungswebsite, die du schon kennst.

2. Prüf auf beschädigten, unpassenden oder schlampigen Druck

Vergleich den Code mit dem Rest des Schildes. Ein echter Code, der als Teil eines Schildes gedruckt wurde, passt meist zu seiner Umgebung: gleiche Druckqualität, gleiche Ausrichtung, gleicher Stil. Sei vorsichtig, wenn der Code unscharf ist, während der Rest des Schildes scharf ist, wenn er schief oder für seinen Rahmen seltsam dimensioniert ist oder wie ein Heimausdruck aussieht, der auf eine professionelle Anzeige geklebt wurde. Schaden allein beweist keinen Betrug – ein wettergegerbtes Plakat kann einfach alt sein –, aber Schaden zusammen mit einer unerwarteten Zahlungs- oder Anmeldeaufforderung sollte dich stoppen. Unser Leitfaden zur Fehlerbehebung erklärt, wie man ein Druckproblem von einem Manipulationsproblem unterscheidet.

3. Frag, ob der Code überhaupt an diesen Ort gehört

Ein Code an einem unerwarteten Ort ist schon für sich ein Warnsignal. Ein Code, der an einen Laternenpfahl, einen Geldautomaten oder einen beliebigen Flyer geklebt ist, ohne Firmenname, ohne Kontext und ohne Erklärung, wohin er führt, hat dein Vertrauen nicht verdient. Dasselbe gilt für einen Code in einem unerwarteten Paket oder in einer Nachricht von einem Absender, den du nicht kennst. Seriöse Unternehmen sagen dir, wofür der Code ist – Menü ansehen, Parken bezahlen, WLAN beitreten – und wohin er dich führen soll. Wenn beides nicht klar ist, lass ihn in Ruhe.

4. Lies die Nachricht um den Code herum, nicht nur den Code

Dringlichkeit ist das Lieblingswerkzeug von Betrügern. Achte auf Nachrichten, die sofortiges Handeln verlangen: Ein Konto werde geschlossen, ein Paket werde zurückgeschickt oder eine Zahlung sei überfällig. Achte auf Drohungen, auf Preise, an deren Verlosung du nicht teilgenommen hast, und auf Bitten, die zu nichts passen, was du tatsächlich bestellt hast. Ein seriöses Unternehmen gibt dir fast immer einen anderen Weg zur Prüfung – seine eigene App, seine offizielle Website oder eine Telefonnummer, der du schon vertraust – und wird nicht darauf bestehen, dass Scannen die einzige Option ist.

5. Entscheide vor dem Scannen, wie du scannen wirst

Nutz die eingebaute Kamera deines Handys oder einen Scanner, dem du vertraust, und plane ein, die Vorschau zu lesen. Deine eingebaute Kamera zeigt typischerweise die Zieladresse, bevor sie sie öffnet – genau die Pause, auf die diese Checkliste setzt. Vermeide es, in dem Moment, in dem du scannen musst, eine neue Scanner-App zu installieren, besonders eine, die genau von dem Schild oder der Nachricht beworben wird, die den Code trägt. Unsere Anleitung zum Scannen eines QR-Codes geht den Vorschau-Schritt auf gängigen Handys durch.

Nach dem Scannen: Lies die Vorschau, bevor du tippst

Scannen ist nicht der gefährliche Schritt. Durchtippen ohne Lesen ist es. Wenn deine Kamera einen Code erkennt, zeigt sie eine Vorschau – meist die Adresse, manchmal eine kurze Beschreibung. Diese Vorschau ist dein Inspektionsfenster. Nutz sie jedes Mal.

Prüf die Schreibweise der Adresse, Buchstabe für Buchstabe

Achte auf Rechtschreibfehler, vertauschte Buchstaben und zusätzliche Wörter. Der zentrale Rat der FTC für einen unerwarteten Code lautet, die URL vor dem Öffnen zu prüfen und, wenn sie wie eine vertraute Adresse aussieht, sicherzustellen, dass sie nicht gefälscht ist. Ein einzelner vertauschter Buchstabe, ein Bindestrich, wo keiner hingehört, ein zusätzliches Wort wie „secure“ oder „verify“ oder ein bekannter Markenname an einer unbekannten Domain können alle auf eine Fälschung hindeuten. Lies die Domain – den Teil der Adresse, der die Seite identifiziert –, nicht den Markennamen im Seitentitel oder Logo, denn Logos lassen sich leicht kopieren und Domains schwerer überzeugend fälschen. Wenn du ein bestimmtes Unternehmen erwartet hast und die Domain nicht dieses Unternehmen ist, schließ die Vorschau.

Sei misstrauisch bei verborgenen Zielen

Ein verkürzter Link verbirgt das echte Ziel, also behandel ihn als unbewiesen. Wenn die Vorschau einen Kurzlink-Dienst oder eine lange Zeichenkette aus Zufallszeichen statt einer erkennbaren Domain zeigt, kannst du nicht sagen, wohin er wirklich führt, bis du ihn öffnest – und genau das ist das Risiko. Wenn das Ziel verborgen ist, wähl stattdessen den bekannten Weg: Tipp die Adresse des Unternehmens selbst ein oder öffne seine App.

Gib niemals Passwörter oder Zahlungsdaten auf einer unerwarteten Seite ein

Das ist die Regel, die die meisten QR-Betrugsversuche sofort stoppt. Wenn du eine Anmelde- oder Bezahlseite nur erreicht hast, weil du einen Code gescannt hast – besonders einen aus einer Nachricht, die du nicht erwartet hast –, gib dort kein Passwort, keine Kartennummer, keine Bankdaten und keinen Bestätigungscode ein, so überzeugend die Seite auch aussieht. Gefälschte Seiten sind so gebaut, dass sie exakt wie das Original aussehen. Schließ stattdessen die Seite und geh direkt zum Dienst: Öffne seine App, tippe seine Adresse selbst ein oder ruf eine Nummer an, der du schon vertraust. Wenn die Nachricht behauptete, es gebe ein Problem mit deinem Konto, sagt dir die Prüfung über die offizielle App, ob dieses Problem echt ist, ohne deine Zugangsdaten an irgendjemanden zu übergeben.

Achte auf Dringlichkeitstricks auf der Seite selbst

Countdown-Timer, Warnungen und Pop-ups sind Drucktaktiken, keine Beweise. Eine Seite, die sagt, dein Konto werde in Minuten gesperrt oder du müsstest handeln, bevor ein Timer abläuft, versucht, dich an den obigen Prüfungen vorbei zu hetzen. Schließ den Tab. Echte Kontoprobleme verschwinden nicht, wenn du dir fünf Minuten nimmst, um sie über einen separaten Kanal zu verifizieren.

Lade keine Dateien herunter und tritt keinen Netzen über einen gescannten Code ohne Grund bei

Ein QR-Code kann auf mehr als eine Website verweisen. Er kann einen Download auslösen oder anbieten, dich mit einem WLAN-Netz zu verbinden. Installier keine App und akzeptier keinen Download, nur weil ein gescannter Code dich darum gebeten hat, und sei besonders vorsichtig bei Apps, die außerhalb des offiziellen Stores deines Handys angeboten werden. Tritt keinem unbekannten WLAN-Netz bei, das ein Code auf einem Plakat anbietet, ohne beim Veranstaltungsort zu bestätigen, dass das Netz ihm gehört.

Wenn du schon einen schlechten Code gescannt hast

Das Scannen eines schlechten Codes bedeutet nicht automatisch, dass dir Schaden entstanden ist, und selbst das Eingeben von Daten auf einer schlechten Seite ist wieder gutzumachen, wenn du umgehend handelst. Geh diese Schritte der Reihe nach durch und lass dich nicht von Scham ausbremsen – Betrüger setzen darauf, dass Leute schweigen.

Erstens: Stopp und trenn die Verbindung. Schließ den Tab oder die App, gib nichts Weiteres ein und folg keinen weiteren Anweisungen der Seite, etwa eine dort angezeigte Nummer anzurufen oder etwas zu installieren, das sie anbietet. Wenn ein Download begonnen hat, öffne ihn nicht.

Zweitens: Änder alle Passwörter, die du eingegeben hast, über ein Gerät und einen Weg, dem du vertraust. Öffne die App des echten Dienstes oder tippe seine Adresse selbst ein, ändere dort das Passwort und schalte die Mehrfaktor-Authentifizierung ein, falls sie noch nicht an ist. Wenn du dasselbe Passwort woanders verwendet hast, ändere es auch dort, beginnend mit deinem E-Mail-Konto, denn E-Mail ist oft der Schlüssel zum Zurücksetzen von allem anderen.

Drittens: Kontaktiere umgehend deine Bank oder deinen Kartenanbieter, wenn du Zahlungsdaten eingegeben hast. Sag ihnen, was passiert ist, bitte sie, auf unbefugte Transaktionen zu achten, und frag nach Sperrung oder Ersatz der Karte. Prüf deine Auszüge in den folgenden Tagen auf Transaktionen, die du nicht erkennst.

Viertens: Melde es. In den Vereinigten Staaten melde den Betrug bei der FTC unter ReportFraud.ftc.gov, mit so vielen Details wie möglich: wo du den Code gesehen hast, was die Nachricht sagte und wohin die Adresse führte. Melden hilft Behörden, Muster zu verfolgen, etwa eine Häufung manipulierter Codes in einer Gegend. Wenn du woanders bist, melde ihn bei deinem nationalen Verbraucherschutz- oder Betrugsmeldedienst und bei dem imitierten Unternehmen über dessen offizielle Kanäle.

Schließlich: Prüf dein Gerät. Stell sicher, dass das Betriebssystem deines Handys aktuell ist, und entferne jede App oder Datei, zu deren Installation der Code dich geführt hat. Wenn sich danach etwas seltsam verhält, such Hilfe beim offiziellen Support des Handyherstellers statt bei einer Nummer, die die verdächtige Seite zeigt.

Für Unternehmen: Schütz deine eigenen Kunden vor gefälschten Codes

Wenn dein Unternehmen QR-Codes druckt, ist die Sicherheit deiner Kundschaft teilweise dein Designproblem. Eine Kundschaft, die deinen echten Code nicht von einem Aufkleber darüber unterscheiden kann, ist eine Kundschaft, die ein Betrüger umleiten kann, und der Schaden trifft deinen Ruf, obwohl du nichts falsch gemacht hast. Ein paar praktische Gewohnheiten machen Manipulation schwerer durchzuführen und leichter zu erkennen.

Nutz gebrandete, erkennbare Codes. Ein Code, der dein Logo und deine Farben trägt und auf deine eigene Domain führt, ist schwerer überzeugend zu imitieren als ein schlichter Code, der auf einen generischen Kurzlink zeigt, und er gibt aufmerksamer Kundschaft etwas, das sie in der Vorschau wiedererkennt. Platzier den Code als Teil des gedruckten Designs – unter Glas, hinter einer Theke oder direkt auf Verpackung oder ein dauerhaftes Schild gedruckt – statt als losen Aufkleber, den jede und jeder abziehen oder überdecken kann.

Sag Kundschaft, wo der echte Code lebt. Sag offen, auf dem Schild selbst und auf deiner Website, wo Kundschaft deinen echten Code findet und wohin er sie führen soll. Zum Beispiel: Unser Bezahlcode ist auf die Uhr selbst gedruckt, nicht auf einen separaten Aufkleber, und er führt auf unsere eigene Website. Dieser eine Satz macht jeden Aufkleber anderswo zu einer offensichtlichen Fälschung. Wenn du einen Code verschiebst oder ein Schild neu druckst, sag es Kundschaft über deine üblichen Kanäle und entferne alte Codes, statt sie liegen zu lassen, wo sie ausgenutzt werden können.

Bevorzug Codes, die du ohne Neudruck ändern kannst. Dynamische Codes, die nach dem Druck bearbeitet werden können, lassen dich ein Ziel aktualisieren, wenn sich ein Link ändert oder ein Code kompromittiert wird, ohne einen veralteten Code im Umlauf zu lassen. Dynamische FreeQrly-Codes sind nach der Anmeldung kostenlos, mit 20 Gratis-Codes und aktuell unbegrenzten Codes während einer zeitlich begrenzten Aktion, und sie lassen sich nach dem Druck bearbeiten, mit Scan-Statistiken und unbegrenzten Scans. Wenn ein gedruckter Code als manipuliert gemeldet wird, kannst du ändern, wohin die übrigen Codes zeigen, und nur neu drucken, was neu gedruckt werden muss. Ein kompromittierter statischer Code muss dagegen physisch ersetzt werden.

Gut zu wissen

Was ist Quishing?

Quishing ist QR-Phishing: ein Betrug, bei dem ein QR-Code einen schädlichen Link verbirgt, der zu einer gefälschten Anmelde- oder Bezahlseite führt oder zu einem Download, der Informationen stehlen soll.

Kann ein QR-Code selbst mein Handy infizieren?

Der Code ist nur ein kodierter Link oder eine Anweisung, aber die Seite oder der Download dahinter kann versuchen, Informationen zu stehlen oder Malware zu installieren – deshalb solltest du die Vorschau lesen, bevor du durchtippst.

Ist es sicher, einen QR-Code an einer Parkuhr zu scannen?

Es kann sein, aber prüf zuerst, ob der Code als Teil der Uhr oder des Schildes gedruckt ist statt darauf geklebt. Wenn er geschichtet, sich lösend oder deplatziert aussieht, bezahl stattdessen über die offizielle App oder Uhr.

Sollte ich einen QR-Code in einer unerwarteten SMS oder E-Mail scannen?

Nein, besonders wenn sie dich zu sofortigem Handeln drängt. Kontaktiere das Unternehmen über eine Telefonnummer oder Website, der du schon vertraust, statt dem Code zu folgen.

Was sollte ich nach dem Scannen in der Vorschau prüfen?

Lies die Domain Buchstabe für Buchstabe, achte auf Rechtschreibfehler oder vertauschte Buchstaben und sei misstrauisch bei verkürzten Links, die das echte Ziel verbergen. Wenn die Domain nicht zu dem Unternehmen passt, das du erwartet hast, schließ die Vorschau.

Ich habe mein Passwort auf einer Seite eingegeben, die ich durch Scannen erreicht habe. Was tue ich?

Schließ die Seite, änder dann dieses Passwort über die echte App oder Website, schalte die Mehrfaktor-Authentifizierung ein und ändere dasselbe Passwort überall sonst, wo du es verwendet hast, beginnend mit deinem E-Mail-Konto.

Wo melde ich einen QR-Code-Betrug?

In den Vereinigten Staaten melde ihn bei der FTC unter ReportFraud.ftc.gov, inklusive wo du den Code gesehen hast, was die Nachricht sagte und wohin er führte. Anderswo nutz deinen nationalen Betrugsmeldedienst und benachrichtige das imitierte Unternehmen über dessen offizielle Kanäle.
