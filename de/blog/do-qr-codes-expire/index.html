Laufen QR-Codes ab?

Kurze Antwort: nein — zumindest nicht die Sorte, die du hier machst. Die längere Antwort solltest du kennen, bevor du tausend davon druckst.

13. Oktober 2026 · 4 Min. Lesezeit

Du hast die Warnungen gesehen: „Kostenlose QR-Codes laufen ab!“ Meist direkt neben einer Preisseite. Also klären wir es plain: Ein statischer QR-Code kann nicht ablaufen. In diesen kleinen Quadraten tickt keine Uhr. Ein statischer Code ist einfach dein Link, als Muster gezeichnet. Solange der Link funktioniert, funktioniert der Code — heute drucken, in zehn Jahren scannen.

Warum sagen Leute dann, QR-Codes liefen ab?

Drei verschiedene Dinge werden durcheinandergeworfen:

  • Dynamische Codes sterben, wenn du aufhörst zu zahlen. Viele „kostenlose“ Generatoren machen tatsächlich dynamische Codes: Statt deines Links hält das Muster eine kurze URL auf ihrem Server, die auf deinen Link weiterleitet. Hörst du auf zu zahlen, schalten sie die Weiterleitung ab. Dein Code ist nicht abgelaufen — er wurde als Geisel genommen.
  • Links verrotten; Codes nicht. Wenn die Seite hinter dem Code gelöscht wird, führt das Scannen ins Nichts. Das ist das Ziel, das stirbt, nicht der Code. Ein QR-Code, der auf einen toten Link zeigt, ist ein kerngesunder Code ohne etwas zu sagen.
  • Testkonten werden deaktiviert. Manche Dienste binden deine Codes an ein Konto und schubsen dich dann Richtung Abo. Der Code ist nicht abgelaufen — das Konto schon.

Statisch vs. dynamisch, in einem Absatz

Ein statischer Code kodiert das Ziel direkt: WIFI:T:WPA;S:MyCafe;P:secret;; oder https://your-site.com/menu. Nichts zu pflegen, nichts abzurechnen. Ein dynamischer Code kodiert eine Weiterleitung auf jemandes Server, die es dem Besitzer erlaubt, das Ziel später zu ändern und Scans zu zählen. Nützlich für Marketingkampagnen — und ein Abo für immer.

Faustregel: Wenn sich das Ziel nie ändern wird — dein WLAN, deine Visitenkarte, dein Restaurantmenü — ist statisch nicht die billige Option. Es ist die richtige Option.

Was bei gedruckten Codes wirklich schiefgeht

Da Ablauf kein Thema ist, hier worauf du wirklich achten solltest:

  • Zu klein gedruckt. Als Faustregel: Codes mindestens 2 × 2 cm mit einer ruhigen Randzone halten. Winzige Codes auf Visitenkarten sind ein häufiger Scan-Fehler.
  • Niedriger Kontrast. Dunkle Tinte auf hellem Hintergrund. Dieser Champagner-auf-Creme-Hochzeits-Code ist wunderschön und unlesbar.
  • Schaden. Outdoor-Codes verblassen und verkratzen. Höhere Fehlerkorrektur (wir starten mit M und erhöhen sie automatisch, wenn du ein Logo hinzufügst) lässt einen Code bis zu 30 % Schaden auf der High-Stufe nach ISO/IEC 18004 überleben.
  • Link-Änderungen. Ziehst du mit deiner Seite um? Der alte Code zeigt weiterhin auf die alte URL. Führ eine Liste, wo jeder Code lebt.

Der FreeQrly-Blickwinkel

Jeder statische Code, der hier gemacht wird, ist kostenlos und deiner — kein Konto, kein Weiterleitungsserver, nichts zu kündigen. Es gibt einfach keinen Mechanismus, durch den er ablaufen könnte. Das ist keine Marketing-Behauptung; so funktionieren statische Codes einfach, wenn sich niemand dazwischenschiebt.

Gut zu wissen

Laufen kostenlose QR-Codes ab?

Nein. Ein kostenloser statischer QR-Code hält so lange wie der Link, auf den er zeigt. Codes, die „ablaufen“, sind dynamische Codes, die an ein bezahltes Abo gebunden sind — der Anbieter schaltet sie ab, wenn du aufhörst zu zahlen.

Kann ein QR-Code aufhören zu funktionieren?

Ja, aber nicht durch Ablauf. Die üblichen Ursachen: Die Zielseite wurde gelöscht, der Code wurde zu klein oder mit niedrigem Kontrast gedruckt, oder er wurde physisch beschädigt.

Wie lange halten statische QR-Codes?

Unbegrenzt. Das Muster kodiert deine Daten direkt, ohne Server dazwischen, also gibt es nichts zu pflegen oder zu erneuern.
