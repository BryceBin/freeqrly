Laufen QR-Codes ab?

Kurze Antwort: nein — zumindest nicht die Sorte, die du hier machst. Die längere Antwort solltest du kennen, bevor du tausend davon druckst.

13. Oktober 2026 · Zuletzt aktualisiert: 3. November 2026 · 15 Min. Lesezeit

Kurze Antwort: nein – zumindest nicht die Sorte, die du hier machst. Ein statischer QR-Code kann nicht ablaufen, weil in diesen kleinen Quadraten keine Uhr steckt. Ein statischer Code ist einfach dein Link, als Muster gezeichnet. Solange der Link funktioniert, funktioniert der Code – heute gedruckt, in zehn Jahren gescannt. Was tatsächlich aufhört zu funktionieren, ist etwas anderes, das denselben Namen trägt: ein bezahlter dynamischer Code, dessen Abo abgelaufen ist, ein Link, der gelöscht wurde, oder ein Druck, der bis zur Unlesbarkeit beschädigt ist. Jeder dieser Fehler braucht eine andere Lösung, und nur einer davon ist ein Grund, etwas zu kaufen.

Die Verwirrung ist verständlich, denn die Warnung steht meist direkt neben einer Preisseite: „Kostenlose QR-Codes laufen ab!“ Was in diesem Satz abläuft, ist selten der Code. Es ist das kostenlose Trial, das Abo oder die Bereitschaft des Anbieters, deine Scans weiterhin kostenlos weiterzuleiten.

Warum sagen Leute dann, QR-Codes liefen ab?

Drei verschiedene Dinge werden durcheinandergeworfen:

  • Dynamische Codes sterben, wenn du aufhörst zu zahlen. Viele „kostenlose“ Generatoren machen tatsächlich dynamische Codes: Statt deines Links trägt das Muster eine Kurz-URL auf deren Server, die zu deinem Link weiterleitet. Hörst du auf zu zahlen, schalten sie die Weiterleitung ab. Dein Code ist nicht abgelaufen – er wurde als Geisel genommen.
  • Links verrotten; Codes nicht. Wenn die Seite hinter dem Code gelöscht wird, führt das Scannen ins Nichts. Das ist das Ziel, das stirbt, nicht der Code. Ein QR-Code, der auf einen toten Link zeigt, ist ein kerngesunder Code ohne etwas zu sagen.
  • Testkonten werden deaktiviert. Manche Dienste binden deine Codes an ein Konto und schubsen dich dann Richtung Abo. Der Code ist nicht abgelaufen – das Konto ist es.

Es gibt einen vierten Fall, der wie Ablauf aussieht, aber nicht die Schuld des Musters ist: Codes, die von einem fremden System ausgegeben werden. Eine Bordkarte, ein Ticket oder ein einmaliger Login-Code kann aufhören zu funktionieren, weil der Aussteller die Sitzung, das Ticket oder die Buchung dahinter ungültig macht. Das Muster ist weiterhin lesbar; das System dahinter hat die Erlaubnis entzogen. Das ist eine Eigenschaft von Tickets und Logins, nicht von QR-Codes allgemein.

Ein Muster ohne Uhr darin

Der QR-Code wurde 1994 von DENSO WAVE entwickelt, um die Grenzen von Barcodes an Fertigungslinien zu überwinden: Die damals genutzten Barcodes konnten nur etwa 20 alphanumerische Zeichen halten, während die Teileverfolgung weit mehr brauchte. Der QR-Code, der sie ersetzte, konnte bis zu etwa 7.000 Zeichen speichern und wurde mit offenen Patenten und Spezifikationen veröffentlicht, sodass ihn jeder nutzen konnte. Das Format wurde als Weg entworfen, Daten zu tragen, nicht als Dienst mit einem Konto oder einem Verlängerungsdatum. Die aktuelle Ausgabe seines Standards, ISO/IEC 18004:2024, legt Symbologie, Codierung und Fehlerkorrekturregeln fest – und enthält keinen Timer, keine Lizenzprüfung und kein Ablaufdatum, denn ein gedrucktes Muster hat keinen Ort, an dem es eines speichern könnte, und niemanden, dem es melden könnte.

Darum ist der FreeQrly-Blickwinkel eine Folge des Designs, kein Marketingversprechen. Jeder statische Code, der hier gemacht wird, ist kostenlos und deiner – kein Konto, kein Weiterleitungsserver, nichts zu kündigen. Es gibt einfach keinen Mechanismus, durch den er ablaufen könnte. Papier kann verblassen, reißen oder weggeworfen werden, aber es kann nicht aus der Ferne abgeschaltet werden.

Statisch vs. dynamisch, in einem Absatz

Ein statischer Code codiert das Ziel direkt: WIFI:T:WPA;S:MyCafe;P:secret;; oder https://your-site.com/menu. Nichts zu pflegen, nichts zu berechnen. Ein dynamischer Code codiert eine Weiterleitung auf dem Server eines Anbieters, die es dem Eigentümer erlaubt, das Ziel später zu ändern und Scans zu zählen. Nützlich für Marketingkampagnen – und ein Abo, solange der Code funktionieren muss. Der vollständige Vergleich, mit den Fällen, in denen jeweils einer gewinnt, steht in Statische vs. dynamische QR-Codes.

Faustregel: Wenn sich das Ziel nie ändern wird – dein WLAN, deine Visitenkarte, dein Restaurantmenü –, ist statisch nicht die billige Option. Es ist die richtige Option.

Schritte: Finde heraus, welchen Fehler du hast

  1. Das Ziel direkt öffnen. Tippe den Link in einen Browser ein, ohne zu scannen. Wenn die Seite selbst fehlt, ist der Code unschuldig: Stelle die Seite wieder her oder leite einen dynamischen Code um. Wenn die Seite lädt, liegt das Problem beim Code, beim Druck oder bei der Weiterleitung.
  2. Einen gedruckten Proof auf zwei Handys scannen. Wenn möglich einem iPhone und einem Android-Gerät. Wenn keines ihn liest, vermute Größe, Kontrast, Schaden oder eine beschnittene Ruhezone. Wenn nur eines ihn liest, ist der Druck grenzwertig – lieber größer neu drucken, als dem Handy zu trauen, das funktioniert hat.
  3. Die Scan-Vorschau lesen, nicht nur das Ergebnis. Schau dir vor dem Tippen die URL an, die dein Handy zeigt. Eine kurze Anbieter-Domain, wo du deine eigene erwartet hast, heißt, dass eine dynamische Weiterleitung dazwischenliegt. Eine Anbieter-Upgrade-Seite heißt, dass die Weiterleitung abgeschaltet wurde. Eine fremde Domain heißt Aufkleber oder Fälschung, kein Ablauf.
  4. Das Konto und den Tarif hinter einem dynamischen Code prüfen. Melde dich beim erstellenden Konto an und prüfe, ob der Tarif aktiv ist, der Code innerhalb seiner Scan-Freimenge liegt und der Code nicht gelöscht wurde. Das Löschen eines dynamischen Codes stoppt seine gedruckten Exemplare sofort, bei jedem Anbieter, weil die Weiterleitung entfernt wird.
  5. Die richtige Schicht reparieren. Druckproblem: neu drucken. Tote Seite: Seite wiederherstellen. Tote Weiterleitung: verlängern oder den Code durch einen statischen Code ersetzen, der auf eine Seite zeigt, die du kontrollierst.

Was bei gedruckten Codes wirklich schiefgeht

Da Ablauf kein Thema ist, achte stattdessen auf Folgendes:

  • Zu klein gedruckt. Als Faustregel: Codes mindestens 2 × 2 cm mit einer ruhigen Randzone halten. Winzige Codes auf Visitenkarten sind ein häufiger Scan-Fehler. Die vollständige Größenanleitung, inklusive Distanz, steht im QR-Code-Druckgrößen-Leitfaden.
  • Niedriger Kontrast. Dunkle Tinte auf hellem Hintergrund. Dieser Champagner-auf-Creme-Hochzeits-Code ist wunderschön und unlesbar.
  • Schaden. Outdoor-Codes verblassen und verkratzen. Höhere Fehlerkorrektur hilft: FreeQrly startet standardmäßig mit Stufe M und erhöht sie automatisch, wenn du ein Logo hinzufügst. Auf der Stufe „Hoch“ nach ISO/IEC 18004 können bis zu etwa 30 % der Codewörter wiederhergestellt werden – Codewörter, nicht sichtbare Fläche, „30 % Schaden“ irreführt also. Ein kleiner Kratzer über einem Suchmuster, dem großen Eckquadrat, mit dem der Scanner den Code findet, kann einen Scan stoppen, selbst wenn der Großteil des Musters intakt aussieht.
  • Keine Ruhezone. Der leere Rand um den Code, mindestens 4 Module breit auf allen vier Seiten nach ISO/IEC 18004, gehört zum Code. Text oder Design, das dort hineingedrängt wird, lässt Scanner die Kanten gar nicht erst finden.
  • Link-Änderungen. Ziehst du mit deiner Website um? Der alte Code zeigt weiterhin auf die alte URL. Führe eine Liste, wo jeder Code lebt – oder nutze einen dynamischen Code und leite ihn um, statt neu zu drucken. Vollständige Checkliste: Warum dein QR-Code nicht funktioniert.

Szenarien: Welche Codes ihren Macher überleben sollten

Eine Visitenkarte

Eine Visitenkarte wird einmal gedruckt und jahrelang verteilt. Ein statischer Code mit einer Kontaktkarte oder persönlichen Seite ist die richtige Wahl: kein Konto zu pflegen, keine Weiterleitung, für die man weiter zahlen müsste, und niemand, der ihn abschalten kann. Ändert sich der Jobtitel, wird die Karte ohnehin neu gedruckt, das eingefrorene Ziel des Codes kostet also nichts.

Eine Hochzeitseinladung

Einladungen gehen Monate vor dem Tag raus, und Gäste behalten sie noch lange nachher am Kühlschrank. Ein statischer Code zu einer RSVP-Seite, die du kontrollierst, funktioniert noch, wenn die Dankeskarten rausgehen, vorausgesetzt, die Seite bleibt online. Ein dynamischer Code funktioniert auch, aber nur, wenn sich in einem Jahr noch jemand um das Konto kümmert – für ein einmaliges Event schlägt Dauerhaftigkeit Änderbarkeit. Siehe QR-Codes für Hochzeits-RSVP und Kostenlose QR-Codes, die nicht ablaufen.

Eine Restaurant-Speisekarte oder ein Schaufenster

Hier spaltet sich die Wahl an einer Frage: Ändert sich das Ziel? Eine Menüseite, die du an Ort und Stelle aktualisierst, braucht nur einen statischen Code, der auf diese Seite zeigt – aktualisiere die Seite, nicht den Code. Ein Menü, das die Plattform wechselt, oder ein Schaufensterangebot, das sich monatlich ändert, verdient einen dynamischen Code, denn ein Schaufensterschild jeden Monat neu zu drucken, ist die teure Option. Siehe QR-Codes für Restaurants.

Ein Kampagnenplakat mit Deadline

Ein Plakat ist der klassische dynamische Fall: Es muss gedruckt werden, bevor die Landingpage final ist, und später kann es auf eine Rückblick- oder Warteliste zeigen. Aber genau hier beißt die Abo-Falle am härtesten, denn das Plakat hängt vielleicht noch Monate nach dem Kampagnenbudget an den Wänden. Bevor du einen Kampagnen-Code bei irgendeinem Anbieter druckst, lies, was dieser Anbieter bei Tarifende tut, und erwäge, statisch auf eine Kampagnenseite zu zeigen, die dir gehört.

Verpackungen, die jahrelang verkauft werden

Verpackung ist der langlebigste Druck von allen und der schlechteste Ort für einen aboabhängigen Code. Ein statischer Code zu einer Produktseite, die du kontrollierst, überlebt Personalwechsel und Budgetzyklen, weil nichts daran erneuert werden muss. Ein dynamischer Code auf Verpackungen ist nur gerechtfertigt, wenn sich das Ziel über die Lebensdauer des Produkts wirklich ändern muss und wenn jemand dafür zuständig ist, dieses Konto über die gesamte Haltbarkeit des Produkts am Leben zu halten.

Der ehrliche Vergleich: Was Anbieter tatsächlich sagen

Jeder Anbieter beschreibt sein eigenes Ablaufverhalten auf seiner Preis- oder FAQ-Seite, und diese Seiten sind die einzige faire Quelle für einen Vergleich. Die Zahlen unten sind jeweils die eigenen Angaben der Anbieter, geprüft am 3. November 2026. Preise und Limits ändern sich, also prüfe die Anbieterseite, bevor du etwas druckst, das lange halten muss – und lies den kostenlosen Tarif, nicht die Schlagzeile.

Erstens: Eine Scan-Begrenzung ist ein zweiter Ablauf: Ein kostenloser Code mit einer Begrenzung von 500 Scans stirbt an Beliebtheit, nicht an Alter, im denkbar schlechtesten Moment – wenn die Kampagne funktioniert. Zweitens: Ein Trial ist ein Kalender: Codes, die während eines Trials gemacht wurden, können weiter funktionieren, weiter funktionieren mit Werbung oder ganz aufhören, je nach Anbieter, und die Preis- oder FAQ-Seite des Anbieters, nicht die Verkaufsseite, ist der Ort, an dem diese Unterscheidung steht. Drittens: „Unbegrenzte Scans“ bei einem bezahlten Tarif heißt unbegrenzt, solange das Abo gültig ist – ein fairer Deal für eine laufende Kampagne, ein schlechter Deal für ein dauerhaftes Schild.

Ein dynamischer Code ist auf einem kostenlosen Konto kostenlos, mit unbegrenzten Scans, nach dem Druck änderbar und im Dashboard gezählt. Ihn zu löschen, stoppt ihn endgültig, weil die Weiterleitung entfernt wird – lösche also nur Codes, von denen kein gedrucktes Exemplar mehr im Umlauf ist.

Ein Sicherheitshinweis, den die Ablaufdebatte meist auslässt

Ein Code, der scannt, ist nicht unbedingt ein Code, dem du trauen solltest. In einer Verbraucherwarnung vom 6. Dezember 2023 warnte die US Federal Trade Commission, dass Betrüger ihre eigenen QR-Aufkleber über echte Codes auf Parkautomaten kleben und QR-Codes in unerwarteten Nachrichten verschicken, in denen dringende Gründe zum Scannen erfunden werden – eine verpasste Lieferung, ein Kontoproblem, ein Passwort, das geändert werden muss. Der Code eines Betrügers kann zu einer gefälschten Website oder zu Malware führen. Der Rat der FTC ist die beste Gewohnheit: Prüfe die URL-Vorschau, bevor du einen Code an einem unerwarteten Ort öffnest, achte auf Rechtschreibfehler oder einen vertauschten Buchstaben und scanne keinen Code aus einer unerwarteten Nachricht, die zu sofortigem Handeln drängt – kontaktiere das Unternehmen stattdessen über eine Nummer oder Website, die du bereits kennst. Prüfe bei deinen eigenen Codes die Vorschau nach jeder Bearbeitung.

Der FreeQrly-Blickwinkel und die Wahl, die daraus folgt

Jeder statische Code, der hier gemacht wird, ist kostenlos und deiner – kein Konto, kein Weiterleitungsserver, nichts zu kündigen. Es gibt einfach keinen Mechanismus, durch den er ablaufen könnte. So funktionieren statische Codes eben, wenn sich niemand dazwischen schiebt. Dynamische Codes sind ein anderer, ehrlicher Handel: kostenlos anmelden, 20 Codes bekommen (aktuell während der zeitlich begrenzten Aktion unbegrenzt), sie nach dem Druck bearbeiten und ihre Statistiken sehen, mit unbegrenzten Scans – Abhängigkeit von einer Weiterleitung und einem Konto im Tausch gegen Änderbarkeit und Messbarkeit.

Die Frage vor dem Druck lautet also nicht „Wird dieser Code ablaufen?“, sondern „Was könnte diesen Code stoppen, und wer kontrolliert es?“ Wenn die Antwort lautet „Nichts, weil das Ziel im Muster steckt und die Seite meine ist“, drucke statisch und hör auf, dir Sorgen zu machen. Wenn die Antwort lautet „Das Ziel wird sich ändern, und ich werde da sein, um es zu ändern“, drucke dynamisch, behalte das Konto und behalte die Liste, wo jeder Code lebt. Wenn die Antwort lautet „Das Abo eines Anbieters, und ich bin nicht sicher, ob ich es verlängere“, drucke diesen Code nicht auf etwas, das lange halten soll – zeige stattdessen mit einem statischen Code auf eine Seite, die dir gehört. Gut zu wissen

Laufen kostenlose QR-Codes ab?

Nein, wenn sie statisch sind. Ein kostenloser statischer QR-Code hält so lange wie der Link, auf den er zeigt. Codes, die aufhören zu funktionieren, sind meist dynamische Codes, die an ein bezahltes Abo hängen – der Anbieter schaltet die Weiterleitung ab, wenn du aufhörst zu zahlen –, oder Codes, die auf eine gelöschte Seite zeigen.

Kann ein QR-Code aufhören zu funktionieren?

Ja, aber nicht durch Ablauf. Die üblichen Ursachen sind: Die Zielseite wurde gelöscht, der Code wurde zu klein oder mit zu niedrigem Kontrast gedruckt, er wurde physisch beschädigt, seine Ruhezone wurde beschnitten oder ein dynamischer Tarif endete oder erreichte eine Scan-Begrenzung.

Wie lange halten statische QR-Codes?

Unbegrenzt, solange das Ziel noch funktioniert. Das Muster codiert deine Daten direkt, ohne dass ein Server beteiligt ist, es gibt also nichts zu pflegen oder zu verlängern.

Was passiert mit bezahlten dynamischen Codes, wenn ein Abo endet?

Das hängt vom Anbieter ab, und die eigene FAQ-Seite des Anbieters ist die Quelle, die man prüfen sollte. Die FAQ von QR TIGER sagt, dass bezahlte Codes unbegrenzte Scans haben, solange das Abo gültig ist, und: „If your plan expires, it will stop working.“ The QR Code Generator sagt, dass nach Ende eines Trials 2 Codes aktiv bleiben, aber Werbung zeigen, während auf der Mutterplattform Uniqode Trial-Codes ohne bezahlten Tarif inaktiv werden.

Kann eine Scan-Begrenzung einen QR-Code stoppen?

Ja, bei Anbietern, die kostenlose dynamische Scans begrenzen. Der Freemium-Tarif von QR TIGER gibt laut dessen eigener Abo-Seite 3 dynamische Codes mit je einem Limit von 500 Scans. Ein Code, der seine Begrenzung erreicht, liefert sein Ziel nicht mehr aus, obwohl das Muster unbeschädigt ist. Dynamische Codes bei FreeQrly haben unbegrenzte Scans.

Tötet Schaden einen QR-Code?

Nicht immer. Die Fehlerkorrektur kann fehlende Daten wiederherstellen: Auf der Stufe „Hoch“ nach ISO/IEC 18004 können bis zu etwa 30 % der Codewörter wiederhergestellt werden. Das zählt Codewörter, nicht sichtbare Fläche – ein kleiner Kratzer über einem Eck-Suchmuster kann einen Scan stoppen, selbst wenn der Großteil des Musters intakt aussieht.

Woran erkenne ich einen toten Link, ein totes Abo oder einen schlechten Druck?

Öffne das Ziel direkt in einem Browser; scanne einen gedruckten Proof auf zwei Handys; lies die Scan-Vorschau-URL, bevor du tippst; und prüfe bei einem dynamischen Code den Tarif und die Scan-Freimenge des erstellenden Kontos. Jede Prüfung zeigt auf eine andere Schicht, und jede Schicht hat eine andere Lösung.

Sollten ein dauerhaftes Schild oder Verpackungen statisch oder dynamisch sein?

Statisch, wenn das Ziel feststeht. Ein statischer Code zu einer Seite, die du kontrollierst, braucht kein Konto und keine Verlängerung, er überlebt also Personalwechsel und Budgetzyklen. Nutze dynamisch nur, wenn sich das Ziel wirklich ändern muss und jemand das Konto über die gesamte Lebensdauer des Codes am Leben halten wird.
