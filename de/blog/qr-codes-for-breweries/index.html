QR-Codes für Brauereien, die mit der Getränkekarte mithalten

Eine Brauerei verändert sich schneller als ein gedrucktes Menü kann. Dieser Leitfaden zeigt, welche Brauerei-QR-Codes bearbeitbar sein sollten, welche fest bleiben können und wie man sie druckt, damit sie in einem lebhaften, feuchten Taproom weiterhin scannen.

4. November 2026 · 15 Min. Lesezeit

Ein Taproom lebt vom Wandel. Ein Fass wird mitten im Service leer, ein kleinseriges Sauerbier ist vor dem Abendessen ausverkauft, und das Bier, für das ein Stammgast gekommen ist, ist plötzlich weg. Ein gedrucktes Menü kann nicht mithalten, ohne zur Last zu werden: Jedes Mal neu drucken, und Kosten und Abfall summieren sich; so lassen, wie es ist, und Gäste bestellen Biere, die nicht mehr laufen. Deshalb ist eine Brauerei einer der klarsten Fälle für einen QR-Code – und genauer: für die richtige Art von QR-Code am richtigen Ort.

Die Regel, die fast jede Brauerei-Entscheidung sortiert, ist einfach: Wenn sich die Information hinter dem Code ändern kann, sollte der Code selbst nach dem Druck bearbeitbar sein. Wenn sie sich nie ändern wird, ist ein fester Code einfacher und vollkommen zuverlässig. Wenn du diese Unterscheidung richtig triffst, fallen Getränkekarten, Führungen, Merch, Clubs, Veranstaltungen, Bewertungen und Speisenbegleitungen alle an ihren Platz.

Die Getränkekarte ist der stärkste Fall für einen dynamischen Code

Eine Getränkekarte ist ein bewegliches Ziel, besonders für eine Brauerei, die Kleinserien- oder Saisonbiere herausbringt. Ein Leitfaden zu Brauerei-QR-Codes sagt es schlicht: Getränkekarten ändern sich, und ein dynamischer Code lässt das verlinkte Menü aktualisieren, während der gedruckte Code gleich bleibt. Druck den Code einmal auf Tischaufsteller, Untersetzer, die Bartheke oder eine Wandtafel und aktualisier dann die Seite, auf die er verweist, sobald sich ein Hahn ändert. Gäste sehen immer, was wirklich läuft, und das Personal hört auf, den ganzen Abend dieselbe Frage zu beantworten – läuft das hier noch?

Was sollte diese Seite zeigen? Mindestens braucht jedes Bier seinen Namen, Stil, Alkoholgehalt (ABV), Ausschankgrößen und Preise, plus einen klaren Ausverkauft-Zustand. Bittere (IBU), eine einzeilige Verkostungsnotiz und das Glas helfen Gästen, ohne Nachfragen zu wählen. Markier ein leeres Fass in dem Moment als ausverkauft, in dem es leer wird, statt das Bier still zu löschen: Ein Gast, der sieht, dass ein Bier weg ist, wählt gern eine zweite Option.

Ein Hinweis zählt mehr als jede Designentscheidung: Halt das Ziel aktuell, sonst arbeitet der Code gegen dich. Eine veraltete Getränkekarte stiftet mehr Verwirrung als gar keine Liste, denn Gäste vertrauen dem Handy in ihrer Hand. Weis pro Schicht eine Person zu, die die Liste aktualisiert, wenn sich ein Fass ändert. Ein dynamischer Code nimmt den Neudruck ab; er nimmt nicht die Notwendigkeit zum Aktualisieren ab.

Dynamisch vs. statisch: Welche Brauerei-Anwendung braucht was?

Ein statischer Code speichert seine Daten direkt im Muster selbst. Einmal gedruckt, ändern sich diese Daten nicht. Ein dynamischer Code speichert stattdessen eine kurze Weiterleitung, sodass das Ziel bearbeitet werden kann, ohne das gedruckte Muster zu ersetzen, und Scans gezählt werden können. Ein Vergleich der beiden Typen sieht es genauso: Statische Codes passen zu festen Informationen ohne Bedarf an Scan-Berichten, während dynamische Codes zu Menüs, Aktionen und Kampagnen passen, die sich ändern.

Wende auf jede Platzierung einen Test an: Könnte ich morgen jede Kopie dieses Codes ersetzen, wenn sich das Ziel änderte? Wenn nicht, wähl dynamisch.

Brauereiführungen: Bring die Geschichte dorthin, wo die Gäste stehen

Eine Führung ist der Moment, in dem Gäste ohnehin schon neugierig sind, wie Bier gemacht wird, und ein Code kann diese Neugier beantworten, ohne den Guide zum Dozenten oder die Wand zum Aufsatz zu machen. Bring an jedem Stopp einen kleinen Code an – der Mühle, der Maischebottich, den Gärtanks, der Abfüllanlage – und verlink jeden mit einer kurzen Notiz: was hier passiert, worauf zu achten oder zu riechen ist und welches Bier im Taproom das Ergebnis zeigt. Eine kurze Brauernotiz, eine Seite über die Brauereigeschichte oder eine Notiz zu einer Saisonabfüllung sind genau die Details, die hinter einen Code passen statt auf ein Schild. Halt jeden Stopp kurz, und wenn sich ein Stopp ändert, lässt dich ein dynamischer Code ihn aktualisieren, ohne den ganzen Pfad neu zu drucken.

Merch: Lass Shirt, Glas oder Dose weiterverkaufen, nachdem sie weg sind

Merch wird oft als einmaliger Verkauf behandelt, aber ein Code macht daraus eine dauerhafte Verbindung. Ein Code auf einem T-Shirt-Etikett, einer Glaskartonage, einem Aufkleber oder einem Dosenetikett kann die Brauereigeschichte, die aktuelle Getränkekarte, den Onlineshop oder die nächste Abfüllung öffnen. Das richtige Ziel hängt davon ab, wie lange der Artikel leben wird. Eine Dose, die binnen Wochen getrunken wird, kann auf genau diese Abfüllung verweisen. Ein Glas oder Hoodie, der jahrelang genutzt wird, sollte auf etwas Dauerhaftes verweisen – deine Startseite, deinen Shop oder deine Veranstaltungsseite, über einen dynamischen Code aktualisiert, wenn sich Details ändern.

Überlad Merch nicht mit Codes. Ein klarer Code mit einer schlichten Beschriftung – „Scannen für unsere Geschichte“, „Dieses Glas kaufen“, „Sehen, was heute läuft“ – schlägt drei unerklärte Quadrate. Lass auf einer Dose gesetzlich vorgeschriebene Etiketteninformationen auf dem Etikett selbst und lass den Code Details ergänzen, etwa Verkostungsnotizen oder Speisenbegleitung. Bring auf einem Shirt den Code dort an, wo er flach gescannt werden kann, nicht über eine Naht, und teste ihn am fertigen Kleidungsstück.

Treueprogramm und Krugclubs: Stammgäste belohnen ohne Tabellenkalkulation an der Bar

Krugclubs leben oder sterben an Reibung. Die klassische Version – ein nummerierter Krug im Regal und eine Papierliste hinter der Bar – funktioniert, bis sie wächst, und wird dann zur Last fürs Personal und zum Rätsel für Mitglieder. Ein QR-Code betreibt den Club nicht allein, aber er beseitigt die zwei häufigsten Reibungspunkte: Beitritt und Wissen, was Mitglieder bekommen.

Bring einen Code an der Bar, im Krugregal und auf der Mitgliedskarte an, der eine klare Seite öffnet: wie man beitritt, was die Mitgliedschaft umfasst, wann Mitgliederabende laufen und wie man einen Vorteil einlöst. Ein Brauerei-Beispiel, beschrieben in einem Leitfaden zu Brauerei-Untersetzern, setzte ein Krugclub-Anmeldeformular hinter den QR-Code auf der Rückseite eines Untersetzers – eine Geste, die Gäste behielten statt wegzuwerfen. Die Lehre ist: Die Anmeldung muss dort sein, wo der Stammgast ohnehin schon ist, in dem Moment, in dem er das Bier ohnehin schon genießt.

Ein dynamischer Code auf der Mitgliedschaftsseite lässt dich Vorteile, Daten und Preise aktualisieren, ohne bei jeder neuen Saison jede Karte und jedes Plakat neu zu drucken, während ein statischer Code für einen dauerhaften Vorteil reicht, der sich nie ändert. Halt den QR-Code als Eingangstür, nicht als ganzes System: Er sollte einen Gast mit einem Scan zur Anmeldung oder zu einem Vorteil bringen, keinen App-Download verlangen.

Veranstaltungen: ein Plakat, das einen Programmwechsel überlebt

Taprooms veranstalten Quizabende, Livemusik, Release-Partys und Foodtruck-Abende, und alle haben dasselbe Druckproblem: Das Plakat hängt schon, bevor die Details final sind. Ein dynamischer Code auf dem Plakat, dem Tischaufsteller und dem Social-Media-Beitrag löst das. Druck einmal und aktualisier dann das Ziel, wenn das Programm fester wird, der Ticketlink öffnet oder die Startzeit sich verschiebt. Gäste, die das frühe Plakat gescannt haben, landen trotzdem bei den aktuellen Details. Mach Eventcodes spezifisch: Ein Code mit der Beschriftung „Trivia an diesem Donnerstag“ sollte dieses Donnerstags-Event öffnen, keine allgemeine Veranstaltungsseite, auf der Gäste suchen müssen, und nimm alte Details jede Woche zügig heraus.

Google-Bewertungen: Frag im richtigen Moment – und ehrlich

Ein QR-Code macht es leicht, eine Bewertung zu hinterlassen: Statt einen Gast zu bitten, nach deinem Namen zu suchen und den Bewertungsbutton zu finden, kann ein Scan ihn direkt zum Bewertungsformular führen. Der Link kommt aus deinem Google-Unternehmensprofil: Öffne am Computer das Profil, wähl „Bewertungen lesen“, dann „Mehr Bewertungen erhalten“, und kopier den Bewertungslink oder speicher das QR-Bild, das Google bereitstellt. Ein Generator kann denselben Link dann in einem individuellen, gebrandeten Design kodieren.

Bring den Bewertungscode dort an, wo das Erlebnis ohnehin schon gut ist, aber setz niemanden unter Druck. Ein Code auf der Rechnungsmappe, der Mitnahmetüte oder einer kleinen Tischkarte funktioniert; ein Code, der einem Gast mitten im Essen aufgedrängt wird, nicht. Formulier ihn schlicht – „Teile eine ehrliche Bewertung auf Google“ – und mach dieselbe Bitte jedem Gast zugänglich, nicht nur denen, die das Bier gelobt haben. Google verbietet Anreize im Austausch für Bewertungen und das gezielte Fragen nur zufriedener Gäste, also biete niemals einen Rabatt, einen Gratis-Ausschank oder einen Preis für eine Bewertung an und verlange niemals eine bestimmte Sternezahl oder Formulierung.

Speisenbegleitung: Gib Gästen einen Grund, ein zweites Gericht zu bestellen

Viele Taprooms servieren Speisen oder beherbergen einen Foodtruck, und ein Code auf dem Menü oder der Flight-Karte kann einen kurzen Pairing-Leitfaden tragen, der niemals aufs gedruckte Menü passen würde. Pairing-Leitfäden beschreiben üblicherweise drei Züge: Ergänzen, Kontrastieren und Schneiden. Ergänzen verbindet ähnliche Aromen, etwa ein röstiges Stout mit gegrilltem oder geräuchertem Fleisch. Kontrastieren balanciert Gegensätze aus, etwa süßes Malz gegen scharfe Hitze. Schneiden nutzt Kohlensäure und Bittere, um Fettigkeit vom Gaumen zu räumen – weshalb ein knackiges Lager oder ein bitteres Pale Ale zu frittiertem Essen, Sahnesaucen und fettem Fisch passt. Vor all dem: Gleich die Intensität an – leichte Biere zu leichten Gerichten und vollere, dunklere oder stärkere Biere zu Braten, Eintöpfen und gereiftem Käse, damit keine Seite die andere übertönt.

Übersetz das in einfacher Sprache auf dein Menü. Ein helles Lager oder Pilsner passt zu Salaten, Meeresfrüchten, frittierten Snacks und mildem Käse. Ein American IPA passt zu frittiertem Essen, würzigen Gerichten in Maßen und gereiftem Cheddar. Ein Brown Ale passt zu Schweinebraten, Barbecue und Burgern. Ein Porter oder Stout passt zu geräuchertem Fleisch, Austern und Schokoladendesserts. Wenn sich dein Küchenmenü ändert, lässt ein dynamischer Code die Pairing-Seite mitwandern, während die gedruckte Flight-Karte gleich bleibt.

Druck- und Platzierungsgrundlagen für einen Taproom

Ein Taproom ist ein harter Ort für einen QR-Code: schwaches Licht, Kondenswasser, fettige Hände, gebogene Gläser und Gäste, die aus Armlänge oder über eine Bar hinweg scannen. Die weit verbreitete Faustregel ist die 10:1-Regel: Mach den Code mindestens ein Zehntel so breit wie die Entfernung, aus der er gescannt wird. Ein Code, der aus etwa 25 Zentimetern gelesen wird, sollte etwa 2,5 Zentimeter breit sein, und ein Plakat, das aus 3 Metern gelesen wird, braucht etwa 30 Zentimeter. Geh im Druck nie unter etwa 2 × 2 Zentimeter und mach dichtere Codes größer, denn mehr Daten bedeuten kleinere Module bei gleicher Größe.

Lass eine Ruhezone – einen leeren Rand von mindestens vier Modulen Breite auf allen vier Seiten, in derselben hellen Farbe wie der Code-Hintergrund – und schneid sie nicht ab oder setz den Code bündig an ein unruhiges Foto. Druck dunkle Module auf hellem Hintergrund und bevorzug matte Oberflächen im Taproom: Glanzlaminierung, Folie und Klarsichtkunststoff können Licht direkt in die Kamera reflektieren. Exportier für den Druck SVG, wo deine Druckerei es akzeptiert, denn ein Vektor bleibt in jeder Größe scharf; wenn du PNG nutzen musst, nimm mindestens 300 Pixel pro Zoll in der endgültigen Druckgröße. Für eine ausführlichere Größenreferenz sieh dir den Leitfaden zu Druckgrößen an und für Codes, die nicht scannen, den Fehlerbehebungs-Hub.

Feuchtigkeit ist das taproomspezifische Problem. Papiertischaufsteller überleben einen trockenen Abend, aber keine wiederholten Abwischvorgänge, Kondenswasserringe und Verschüttungen. Für alles, was abgewischt, nass gehandhabt oder draußen platziert wird, druck auf Vinyl- oder Polyestermaterial oder laminiere den Druck mit versiegelter Kante und nutz Pigment- oder Laserdruck statt Tintenstrahl-Tinte, die nass verschmiert. Ein Leitfaden zu wasserdichten Aufklebern beschreibt diesen zweilagigen Aufbau – eine wasserfeste Basis plus eine Schutzversiegelung – und merkt an, dass Laminierung die Lebensdauer von Vinyl im Freien auf ein bis zwei Jahre verlängert, gegenüber sechs bis zwölf Monaten für unlaminierten Vinyldruck.

Vor jedem Drucklauf teste einen Probeabzug in der echten Größe auf dem echten Material, mit mindestens einem iPhone und einem Android-Handy, aus der echten Entfernung und im echten Winkel bei der echten Beleuchtung, und prüf, ob die Seite auch über mobile Daten schnell lädt, nicht nur über Taproom-WLAN. Ein dynamischer Code kann ein falsches Ziel nach dem Druck noch retten, aber keinen Code, der zu klein, zu kontrastarm oder physisch beschädigt ist.

Ein einfaches Setup, das die ganze Brauerei abdeckt

Fang mit einem dynamischen Code für die Live-Getränkekarte an, denn das ist der Code, den Gäste am meisten nutzen werden, und der, der am meisten Neudruck spart. Füg einen statischen Code für WLAN hinzu, dort platziert, wo Gäste sich setzen statt wo sie anstehen. Füg einen zweiten dynamischen Code für Veranstaltungen hinzu, damit Plakate und Tischaufsteller zwischen Events hängen bleiben können. Füg dann nur dort Codes hinzu, wo sie eine echte Frage beantworten: ein Tourstopp, ein Merch-Artikel, eine Krugclub-Anmeldung, eine Bewertungskarte oder eine Pairing-Notiz. Weniger, klarere Codes schlagen eine Wand aus Quadraten, die Gäste zu ignorieren lernen.

Beschrifte jeden Code in einfachen Worten. „Scannen für die heutige Getränkekarte“ sagt einem Gast mehr als ein nacktes Quadrat je könnte. Führ eine einfache Liste deiner Codes – wo jeder gedruckt ist, worauf er verweist und ob er statisch oder dynamisch ist –, damit bei einer geänderten Getränkekarte, einem beendeten Event oder einem geänderten Clubvorteil eine Person das richtige Ziel in Minuten aktualisieren kann. Gut zu wissen

Sollte eine Brauerei-Getränkekarte einen dynamischen oder statischen QR-Code nutzen?

Dynamisch. Getränkekarten, Preise und Ausverkauft-Zustände ändern sich ständig, und ein dynamischer Code lässt dich die verlinkte Seite aktualisieren, ohne Tischaufsteller, Untersetzer oder Plakate neu zu drucken.

Was sollte eine Getränkekarten-Seite zeigen?

Jeder Biername, Stil, Alkoholgehalt (ABV), Ausschankgrößen und Preise, plus ein klarer Ausverkauft-Zustand. Bittere (IBU), eine einzeilige Verkostungsnotiz und das Glas helfen Gästen, ohne das Personal zu fragen, zu wählen.

Kann ein QR-Code sowohl für die Getränkekarte als auch für Veranstaltungen funktionieren?

Es geht, wenn er auf eine Seite verweist, die du aktualisierst, aber spezifische Codes funktionieren besser. Ein Getränkekarten-Code sollte die Getränkekarte öffnen und ein Eventcode dieses Event, damit Gäste nicht suchen müssen.

Was ist eine gute Anwendung für einen statischen QR-Code in einer Brauerei?

Alles, was sich nicht ändern wird, etwa Gäste-WLAN-Zugang, eine dauerhafte Brauereigeschichts-Seite oder eine feste Tourroute. Statische Codes brauchen bei FreeQrly keine Registrierung, tragen kein Wasserzeichen und laufen nie ab.

Wie groß sollte ein QR-Code auf einem Untersetzer oder Tischaufsteller sein?

Als Faustregel: Mach den Code mindestens ein Zehntel so breit wie die Scan-Entfernung. Für einen Untersetzer oder eine Flight-Karte, die aus 20 bis 30 Zentimetern gescannt wird, heißt das etwa 2 bis 3 Zentimeter und nie unter etwa 2 × 2 Zentimetern im Druck.

Wie lasse ich einen Taproom-QR-Code Verschüttungen und Kondenswasser überstehen?

Druck auf Vinyl- oder Polyestermaterial oder laminiere den Druck mit versiegelter Kante und nutz Pigment- oder Laserdruck statt Tintenstrahl-Tinte, die nass verschmiert. Papier allein überlebt keine wiederholten Abwischvorgänge.

Darf ich ein Gratisgetränk für eine Google-Bewertung anbieten?

Nein. Google verbietet Anreize im Austausch für Bewertungen und das gezielte Fragen nur zufriedener Gäste, also bitte jeden Gast um eine ehrliche Bewertung und verlange niemals eine bestimmte Sternezahl oder Formulierung.

Brauche ich für jedes Bier einen anderen QR-Code?

Meist nicht. Ein Getränkekarten-Code, der die volle Liste öffnet, ist einfacher zu pflegen. Nutze einen separaten Code nur, wenn ein einzelnes Bier, eine Abfüllung oder ein Merch-Artikel wirklich eine eigene Seite braucht.
