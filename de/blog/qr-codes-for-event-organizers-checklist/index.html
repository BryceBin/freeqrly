QR-Codes für Veranstalter: Die komplette Checkliste (vor, während und nach dem Event)

Ein QR-Code funktioniert nur, wenn ihn jemand scannen kann — am richtigen Ort, im richtigen Moment. Diese Checkliste deckt alles ab, was ein Veranstalter braucht, um QR-Codes zu planen, zu drucken, zu testen, einzusetzen und wiederzuverwenden — bevor die Türen aufgehen, am Tag selbst und nachdem der letzte Gast gegangen ist.

19. November 2026 · 17 Min. Lesezeit

Die meisten Event-QR-Codes scheitern aus einfachen Gründen: Der Code verlinkt auf eine umgezogene Seite, der Druck ist zu klein, um aus zwei Metern gescannt zu werden, das WLAN bricht beim Check-in weg, oder niemand hat den Code auf einem Telefon getestet.

Vor dem Event: Planen, erstellen, drucken, testen

Alles in dieser Phase passiert, solange du noch Zeit hast, Fehler zu beheben: Einen QR-Code, der auf 500 Badges gedruckt ist, kann man am Morgen des Events nicht neu drucken — aber sein Ziel lässt sich trotzdem noch ändern, wenn du die richtige Art von Code gewählt hast.

1. Entscheide, welche Codes statisch sind und welche dynamisch sein müssen

  • Statische Codes codieren ihr Ziel dauerhaft. Einmal gedruckt, lässt sich das Ziel nicht mehr ändern. Sie sind wirklich kostenlos, brauchen keine Anmeldung, tragen kein Wasserzeichen, laufen nie ab und werden komplett im Browser erzeugt — nichts wird hochgeladen und nichts wird verfolgt.
  • Dynamische Codes zeigen auf einen kurzen Link, den du kontrollierst. Der gedruckte Code ändert sich nie, aber du kannst jederzeit bearbeiten, wohin er führt — auch nachdem er gedruckt, aufgehängt und verteilt wurde. Dynamische Codes zeichnen außerdem Scan-Statistiken auf, und Scans sind unbegrenzt. Um sie zu erstellen, braucht es eine kostenlose Anmeldung. Die kostenlose Stufe erlaubt 20 dynamische Codes; Pro (9 $/Monat oder 90 $/Jahr) unterscheidet sich nur darin, dass unbegrenzte dynamische Codes erlaubt sind. Während des aktuellen, zeitlich begrenzten Angebots sind kostenlose dynamische Codes unbegrenzt; nach Ende des Angebots umfasst der Gratis-Tarif 20 dynamische Codes.

Im Zweifel wähle dynamisch. Die Kosten eines unnötigen dynamischen Codes sind null; die Kosten eines statischen Codes, dessen Ziel umgezogen ist, sind ein Neudruck.

2. Erstelle die Ticket- und Anmelde-Codes

Dein Ticket-QR-Code ist meist der erste Code, den ein Gast scannt, und er erscheint auf Plakaten, in Social Posts, E-Mails und auf Partner-Websites.

  • Verlinke ihn auf die Live-Ticketseite, nicht auf eine Startseite. Jeder zusätzliche Tap riskiert, einen Käufer zu verlieren.
  • Nutze einen dynamischen Code, damit du das Ziel zwischen den Ticketphasen wechseln kannst (Early Bird → regulär → letzter Abverkauf), ohne etwas neu zu drucken oder neu zu posten.
  • Setze denselben Code auf jeden Kanal — Plakat, E-Mail-Signatur, Social-Bio-Link, Partnerseite — und seine Scan-Statistiken zeigen die Summe über alle. Um Kanäle zu vergleichen, gib stattdessen jedem Kanal seinen eigenen Code.
  • Füge eine kurze gedruckte URL unter den Code. Wenn der Code je nicht scannt, ist die URL die Sicherung.
  • Wenn du mehrere Ticketarten hast (regulär, VIP, Student, Speaker), erstelle einen Code pro Art. Die Stapel-Erzeugung kann bis zu 50 statische Codes auf einmal erstellen, was für Varianten pro Art oder pro Kanal nützlich ist — aber der Stapel ist nur statisch, dynamische Codes werden einzeln erzeugt.

3. Erstelle die Check-in-Codes

Beim Check-in verursacht ein schlechter QR-Code eine sichtbare Schlange. Plane ihn als Prozess, nicht als Plakat.

  • Entscheide, was der Gast scannt: einen Code in seiner Ticket-Bestätigungs-E-Mail, einen Code auf einem gedruckten Badge oder einen Code am Eingang, der die Check-in-Seite öffnet.
  • Entscheide, was das Personal sieht: ein Check-in-Dashboard, eine durchsuchbare Gästeliste oder eine einfache „Bestätigt“-Seite. Teste das auf genau dem Gerät, das das Personal in der Hand halten wird — einem Telefon, einem Tablet oder einem Laptop.
  • Wenn jeder Gast einen eigenen Code bekommt (einen pro Ticket), erzeuge sie im Stapel: bis zu 50 statische Codes pro Stapel, also braucht ein Event mit 200 Personen vier Stapel.
  • Drucke ein paar zusätzliche allgemeine Check-in-Codes für Spontanbesucher, Presse und Last-Minute-Zugänge.

4. Erstelle die Codes für Anfahrt, Programm, Speaker und Sponsoren

Das sind die Codes, die Gäste scannen, sobald sie drinnen sind. Jeder beantwortet eine Frage, die ein Gast sonst einem Helfer stellen würde.

  • Anfahrt und Parken: ein Code, der auf eine Kartenmarkierung oder eine Anfahrtsseite verlinkt. Drucke ihn auf die Einladung, die Bestätigungs-E-Mail und ein Schild am Eingang des Parkplatzes. Statisch reicht — der Veranstaltungsort zieht nicht um.
  • Programm und Ablauf: ein Code, der auf den Live-Ablauf verlinkt. Nutze dynamisch: Sessions werden abgesagt, Räume wechseln, Startzeiten rutschen. Setze diesen Code auf die Rückseite jedes Badges, an die Lobbywand und an jede Raumtür.
  • Speaker-Links: ein Code pro Speaker oder ein Code, der auf eine Speaker-Seite verlinkt, mit Bios, Folien und Social-Media-Links von allen. Dynamisch, denn Folien kommen spät.
  • Sponsoren-Links: ein Code pro Sponsor, gedruckt auf seinem Stand-Schild und im Programm. Dynamisch, damit der Sponsor die Landingpage nach dem Event ändern kann, ohne dich um einen Neudruck zu bitten. Sag den Sponsoren, dass der Code dynamisch und bearbeitbar ist — das ist ein Verkaufsargument für das Stand-Paket.
  • WLAN: ein WLAN-QR-Code, der mit einem Scan ins Netzwerk bringt. Drucke ihn groß am Eingang und in jedem Session-Raum. Statisch reicht, und die Gäste werden es dir danken.

5. Mach einen Druck- und Platzierungsplan

Ein QR-Code am falschen Ort ist dasselbe wie kein QR-Code. Schreibe auf, wohin jeder Code kommt, bevor du irgendetwas druckst.

* Die Druckgröße ist ein Planungshinweis, keine Spezifikation: Teste jeden gedruckten Code immer per Scan aus der Entfernung, aus der ein Gast tatsächlich stehen wird (siehe Schritt 6).

Platzierungsregeln, die die häufigsten Fehler verhindern:

  • Platziere einen Code nie dort, wo Blendung hinkommt. Glänzendes Papier unter einem Spot, ein Code hinter Glas oder ein Bildschirm vor einem Fenster lässt sich nicht scannen. Mattes Papier und schattige Platzierung verhindern die meisten dieser Ausfälle.
  • Halte eine Ruhezone um jeden Code frei. Der leere Rand um einen QR-Code gehört zum Code. Lass weder Text noch Logos oder Rahmen ihn einengen. Ein Logo in der Mitte ist in Ordnung — die Mitte ist dafür gedacht — aber halte die Ränder frei.
  • Ein Code pro Schild, eine Aufgabe pro Code. Ein Plakat mit fünf Codes ist ein Plakat, das niemand scannt. Wenn ein Schild mehrere Ziele braucht, verlinke auf eine Landingpage und liste sie dort auf.
  • Drucke die kurze URL unter jeden wichtigen Code. Sie ist die Sicherung, wenn eine Kamera den Code nicht lesen kann.

6. Teste alles per Scan

Das ist der Schritt, den die meisten Veranstalter überspringen — und der, der das Event rettet.

  • Scanne jeden gedruckten Code mit mindestens zwei verschiedenen Telefonen — wenn möglich einem iPhone und einem Android — aus der Entfernung, aus der ein Gast stehen wird.
  • Scanne wenn möglich im echten Licht des Veranstaltungsorts, oder zumindest bei hellem Licht und bei schwachem Licht.
  • Scanne die Codes auf dem Bildschirm ebenso wie auf Papier: Ein Code, der in einer Designdatei gut aussieht, kann auf einem Badge zu klein sein.
  • Klicke dich jedes Mal bis zum endgültigen Ziel durch. Ein Code, der scannt, aber auf einer 404-Seite landet, ist schlimmer als ein Code, der nicht scannt — denn niemand meldet ihn, die Leute gehen einfach.
  • Teste den Check-in-Ablauf von Anfang bis Ende mit einem echten Ticket: scannen, bestätigen, eintreten. Wenn es pro Gast mehr als ein paar Sekunden dauert, wächst die Schlange.
  • Teste nach jeder Änderung eines Ziels erneut. Dynamische Codes machen Änderungen leicht — und ungetestete Änderungen ebenfalls leicht. Ändern, dann scannen, dann vertrauen.

Ein zehnminütiges Testprotokoll — Code, getestetes Telefon, Entfernung, bestanden oder nicht — fängt den einen Code, der sonst vor hundert Menschen versagt hätte.

Am Tag selbst: Den Ablauf steuern, die Pannen abfangen

Am Tag selbst ist deine Aufgabe nicht, Codes zu erstellen. Beobachte den Ablauf, repariere, was kaputtgeht, und aktualisiere, was sich ändert — ohne etwas neu zu drucken.

7. Den Check-in-Ablauf steuern

Was der Gast sieht:

  1. Er öffnet seine Ticket-E-Mail oder hält sein Badge hoch.
  2. Er scannt den Check-in-Code (oder das Personal scannt seinen Ticket-Code).
  3. Eine Bestätigungsseite erscheint — sein Name, seine Ticketart und eine klare „Du bist eingecheckt“-Nachricht.
  4. Er geht hinein. Keine App zum Herunterladen, kein Konto zum Anlegen.
  • Was das Personal sieht:
  1. Die Check-in-Seite oder Gästeliste, mit dem Namen des Gastes als angekommen markiert.
  2. Eine Zählung von eingecheckten vs. erwarteten Gästen, damit du auf einen Blick siehst, ob sich der Raum wie geplant füllt.
  3. Ein Suchfeld für Namen, für den Gast, dessen Telefon gestorben ist oder dessen E-Mail nie angekommen ist.

Weise das Personal fünf Minuten vor Türöffnung ein: Zeige jedem Mitarbeiter die Check-in-Seite auf seinem eigenen Telefon; vereinbare, dass ein fehlgeschlagener Scan einen Gast nie abweist — suche den Namen stattdessen manuell; halte ein geladenes Ersatz-Telefon oder -Tablet am Schalter bereit und die Papier-Gästeliste in Reichweite.

8. Einen Link nach dem Drucken ändern — warum dynamische Codes zählen

Hier beweisen dynamische Codes ihren Wert. Eine Session wechselt den Raum. Ein Speaker sagt ab. Die Ticketseite zieht auf eine neue Plattform um. Mit statischen Codes bedeutet jede davon ein Neudruck. Mit dynamischen Codes bedeutet jede: Dashboard öffnen, Ziel bearbeiten und den gedruckten Code einmal scannen, um zu bestätigen, dass das neue Ziel lädt. Sag dem Personal, was sich geändert hat, damit niemand Gästen die alte Information aus dem Gedächtnis gibt.

Das Muster ist klar: Alles, was sich am Tag ändern kann, hätte von Anfang an dynamisch sein sollen. WLAN ist die Ausnahme: Lege das Passwort vor dem Drucken fest und ändere es nicht mitten im Event.

9. Einen Plan für Pannen haben

Etwas wird schiefgehen. Der Plan entscheidet, ob es eine Zwei-Minuten-Reparatur oder ein sichtbares Problem wird.

Wenn ein Code nicht scannt: Prüfe zuerst das Licht — stell das Schild aus der direkten Blendung oder kippe es leicht. Wische die Kameralinse des Gastes ab; es klingt nebensächlich, behebt aber viele Fehler. Probiere ein anderes Telefon: Wenn es auf einem zweiten Telefon scannt, liegt das Problem am Gerät des Gastes, nicht an deinem Code. Lies die kurze gedruckte URL laut vor oder tippe sie ein — dafür ist sie unter dem Code gedruckt. Wenn der Code selbst beschädigt ist (zerrissen, nass, verblasst), ersetze das Schild durch einen Ersatzdruck. Bring immer Ersatzdrucke der Eingangs- und Check-in-Schilder mit.

Wenn das WLAN ausfällt: Der Check-in darf nicht vom WLAN abhängen. Halte die Papier-Gästeliste am Schalter und eine heruntergeladene Kopie der Liste auf einem Personal-Telefon bereit. Lass das Personal den Gästen Netzwerknamen und Passwort mündlich nennen, bis das Netzwerk zurück ist, und kenne die Zugangsdaten für das Backup-Netzwerk des Veranstaltungsorts oder den mobilen Hotspot, bevor die Türen aufgehen.

Wenn die Ticketseite umzieht: Wenn der Ticket-Code dynamisch ist, bearbeite das Ziel und scanne erneut zur Bestätigung — das dauert Minuten. Wenn er statisch ist, kannst du den gedruckten Code nicht reparieren: Poste den neuen Link auf den Social Accounts deines Events, maile registrierte Teilnehmer an und stelle einen Mitarbeiter an den Eingang, der den neuen Link zum Teilen bereithält. Das ist die Panne, die Veranstalter dazu bringt, von da an dynamische Codes zu nutzen.

Wenn sich der Ablauf mitten im Event ändert: Bearbeite das dynamische Programm-Ziel einmal. Jeder gedruckte Programm-Code im Gebäude zeigt jetzt den neuen Ablauf — Badges, Lobbywand, Raumtüren — ohne Neudruck. Kündige die Änderung auch auf dem Hauptbildschirm und per Ansage an, denn nicht jeder Gast scannt den Code erneut, und stelle für die ersten zehn Minuten einen Mitarbeiter an die alte Raumtür, der Gäste zum neuen Raum leitet.

10. Live-Updates und Fototeilen nutzen

QR-Codes sind nicht nur für den Einlass. Während des Events sind sie der schnellste Weg, aktualisierte Informationen an einen ganzen Raum zu schicken.

  • Live-Programmänderungen: Ein dynamischer Programm-Code, einmal aktualisiert, erreicht jeden Gast, der ihn scannt. Kündige von der Bühne an: „Scanne den Code auf deinem Badge für den aktualisierten Ablauf“.
  • Raumwechsel: Aktualisiere das Ziel und stelle dann für die ersten zehn Minuten einen Mitarbeiter an die alte Raumtür, der Gäste zum neuen Raum leitet.
  • Fototeilen: Setze einen Fototeilen-Code auf die Bühnenrückwand, die Lobbywand und die Tische. Gäste scannen ihn, um Fotos in ein geteiltes Album hochzuladen oder den Event-Hashtag zu finden. Nutze einen dynamischen Code: Der Album-Link existiert meist erst, wenn das Event schon läuft.
  • Social-Media-Links: Ein Code, der auf eine Seite mit all deinen Social Profilen und dem Event-Hashtag verlinkt. Setze ihn dorthin, wo Leute Fotos machen — die Rückwand, die Fotowand, der Sponsorenbereich — denn dann wollen sie posten.

Nach dem Event: Nachfassen und wiederverwenden

Das Event endet, aber die Codes funktionieren weiter — und dieselben gedruckten Materialien können dem nächsten Event dienen.

11. Das Fotoalbum teilen

  • Aktualisiere das Ziel des dynamischen Fototeilen-Codes auf das fertige Album, sobald Fotos gesammelt und kuratiert sind. Jedes Plakat, Badge und jede Tischkarte, die den Foto-Code trug, zeigt jetzt auf das Album — Gäste, die ein Badge scannen, das sie zu Hause behalten haben, landen bei den Fotos.
  • Schicke Teilnehmern den Album-Link ebenfalls per E-Mail. Nicht jeder behält das Badge, und E-Mail erreicht Menschen, die der Code nicht erreicht.

12. Feedback einsammeln, solange die Erinnerung frisch ist

  • Aktualisiere das Ziel des dynamischen Feedback-Codes auf die finale Umfrage, schicke sie dann per E-Mail und poste sie innerhalb von 24 Stunden auf Social-Media-Kanälen. Die Antwortquoten fallen nach dem ersten Tag stark.
  • Halte die Umfrage kurz: drei bis fünf Fragen plus ein offenes Textfeld. Eine lange Umfrage an einem QR-Code wird geöffnet und abgebrochen.
  • Setze den Feedback-Code auf die Ausgangswand und die Tische, nicht nur in die E-Mail. Gäste, die den Veranstaltungsort verlassen, haben die frischesten Meinungen.
  • Lies die Scan-Statistiken des Feedback-Codes: Wenn viele Menschen die Umfrage geöffnet, aber nur wenige sie abgeschlossen haben, ist die Umfrage zu lang.

13. Dankeschön-Nachrichten und Sponsoren-Nachfassen senden

  • Aktualisiere den Dankeschön-Code (oder den Haupt-Event-Code) auf eine Dankeschön-Seite mit Fotoalbum, Feedback-Link und dem Datum des nächsten Events.
  • Schicke Sponsoren ihre Scan-Statistiken: wie oft ihr Stand-Code gescannt wurde und wann. Sponsoren verlängern Stände, wenn sie die Zahlen sehen können. Scan-Statistiken gibt es auf dynamischen Codes; statische Codes zeichnen nichts auf — ein weiterer Grund, warum Sponsoren-Codes dynamisch sein sollten.
  • Teile die wichtigsten Ergebnisse auch mit Speakern — Scans auf ihrem Session-Code, Feedback-Erwähnungen — denn Speaker, die sich wertgeschätzt fühlen, kommen zurück.

14. Die gedruckten Materialien für das nächste Event wiederverwenden

Das ist der bleibende Vorteil der Entscheidung für dynamische Codes. Die Banner, Badges, Tischkarten und Schilder, die du für dieses Event gedruckt hast, müssen für das nächste nicht neu gedruckt werden:

  1. Behalte die gedruckten Materialien, die dynamische Codes tragen.
  2. Bearbeite vor dem nächsten Event das Ziel jedes Codes auf die Seiten des neuen Events: neuer Ticket-Link, neuer Ablauf, neues Fotoalbum, neues Feedback-Formular.
  3. Scanne jeden wiederverwendeten Code und bestätige, dass er auf den Seiten des neuen Events landet. Ein Code, der auf den Ablauf vom letzten Jahr zeigt, ist schlimmer als kein Code.
  4. Drucke nur die Materialien neu, deren Codes statisch sind und deren Ziele sich geändert haben — meist nur Datum und Veranstaltungsort.

Bei einem wiederkehrenden Event — einem monatlichen Meetup, einer jährlichen Konferenz, einer saisonalen Messe — macht aus Druckkosten pro Event einmalige Kosten. Die Checkliste für das nächste Event beginnt bei Schritt 6 (alles per Scan testen) statt bei Schritt 1.

Gut zu wissen

Sollen Event-QR-Codes statisch oder dynamisch sein?

Dynamisch für alles, was sich nach dem Drucken ändern könnte: Ticketing, Programm, Speaker, Sponsoren, Fotoalben, Feedback und Dankeschön-Seiten. Statisch für Dinge, die sich nie ändern werden: die Adresse des Veranstaltungsorts, der WLAN-Login und die permanente Startseite des Events. Wenn du unsicher bist, wähle dynamisch — die kostenlose Stufe erlaubt 20 dynamische Codes, was für die meisten einzelnen Events reicht.

Kann ich das Ziel eines QR-Codes nach dem Drucken ändern?

Ja, wenn es ein dynamischer Code ist. Bearbeite das Ziel in den Einstellungen des Codes, und der gedruckte Code führt sofort zur neuen Seite. Statische Codes lassen sich nach dem Drucken nicht ändern; das Ziel ist im Code selbst codiert.

Wie groß sollte ein gedruckter QR-Code sein?

Es gibt keine universelle Größe, denn die richtige Größe hängt von der Scan-Entfernung ab: Ein Badge-Code, der auf Armlänge gescannt wird, kann klein sein, während ein Code auf der Bühnenrückwand, der aus acht Metern Entfernung gescannt wird, sehr groß sein muss. Die verlässliche Methode ist: drucken, dann per Scan aus der Entfernung testen, aus der ein Gast tatsächlich stehen wird, auf zwei verschiedenen Telefonen.

Kann ich dieselben gedruckten QR-Codes für mein nächstes Event wiederverwenden?

Ja, bei dynamischen Codes. Bearbeite das Ziel jedes Codes auf die Seiten des neuen Events und teste jeden Code erneut, indem du das tatsächliche gedruckte Material scannst. Statische Codes lassen sich nur wiederverwenden, wenn ihr Ziel für das nächste Event noch stimmt.

Gibt es ein Limit, wie oft ein Event-QR-Code gescannt werden kann?

Nein. Scans sind bei statischen wie dynamischen Codes unbegrenzt, also hört ein beliebter Code bei einem großen Event nicht mitten am Tag auf zu funktionieren.

Was kostet es, QR-Codes für ein Event zu machen?

Statische Codes sind kostenlos ohne Anmeldung, ohne Wasserzeichen und ohne Ablauf. Dynamische Codes sind kostenlos mit kostenloser Anmeldung, bis zu 20 Codes, inklusive Scan-Statistiken. Pro (9 $/Monat oder 90 $/Jahr) fügt nur unbegrenzte dynamische Codes hinzu.
