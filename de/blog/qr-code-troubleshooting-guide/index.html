QR-Code-Fehlerbehebung, von Anfang bis Ende

Scannt nicht, scannt manchmal oder scannt ins Nichts? Finde deinen Fehler in der Tabelle, folge seiner Lösung und teste erneut – die meisten Codes werden ohne Neudruck repariert.

3. November 2026 · 15 Min. Lesezeit

Ein QR-Code, der nicht scannt, ist selten ein Rätsel. Die meisten Fehler laufen auf eine von elf Ursachen hinaus, und sie teilen sich in drei Fragen auf: Ist das Muster unlesbar, kämpft das Handy, oder hat der Code einwandfrei gescannt und das Ziel hat dich im Stich gelassen? Beantworte diese zuerst, und du wirst weder einen einwandfreien Code neu drucken noch ein Muster reparieren, wenn der Link tot ist.

Prüfe zuerst diese drei

  1. Versuch ein zweites Handy. Wenn ein anderes Handy den Code liest, ist das Muster in Ordnung. Spring unten zu den Handy-Prüfungen.
  2. Schau auf den Code, nicht auf den Bildschirm. Ist er klein, blass, von nahem Text bedrängt, von einem Logo verdeckt, zerkratzt oder verblasst? Jeder einzelne davon kann ein Muster unlesbar machen. Versuch auch eine frische Kopie der Originaldatei: Wenn die frische Kopie scannt, ist der Originaldruck gescheitert, nicht die Daten.
  3. Lies, was der Scan zurückgibt. Wenn das Handy den Code erkennt, die Seite aber nie lädt oder irgendwo Unerwartetem landet, hat das Muster seine Arbeit getan. Das Ziel ist das Problem: eine gelöschte Seite, ein vertippter Link oder ein abgeschalteter dynamischer Code.

Eine Unterscheidung zählt durchgehend: Ein Code, der nie scannt, hat ein Muster- oder Kamera-Problem, während ein Code, der manchmal scannt – bei hellem Licht, aber nicht bei schwachem Licht, aus der Nähe, aber nicht aus Armlänge –, ein grenzwertiger Code ist. Grenzwerte Codes bestehen an deinem Schreibtisch und versagen in den Händen eines Kunden: Behandle einen Manchmal-Code als kaputt.

Das Muster selbst: sechs Wege, wie ein Code unlesbar wird

1. Zu klein für die Scandistanz

Kleine Codes versagen, weil Kameras die einzelnen Module – die kleinen Quadrate – nicht auflösen können, wenn sie im Bild winzig sind. Als Faustregel halte gedruckte Codes bei mindestens 2 × 2 cm und skaliere mit der Distanz hoch: Die Codebreite sollte mindestens ein Zehntel der erwarteten Scandistanz betragen. Eine Tischkarte, die aus 50 cm gescannt wird, braucht einen Code von etwa 5 cm Breite; ein Plakat, das aus 5 Metern gescannt wird, braucht einen von etwa 50 cm Breite. Dichte Codes mit langen Links brauchen mehr Raum als kurze Links. Die vollständigen Größentabellen stehen im Druckgrößen-Leitfaden.

2. Unscharf oder niedrige Auflösung

Unschärfe heißt zu wenige Pixel, die über zu viel Fläche gezogen werden, sodass Modulkanten ineinander verschmieren. Die üblichen Schuldigen sind ein Export in niedriger Auflösung, ein JPEG-Speichern, das scharfe Kanten aufweicht, ein Screenshot von einem Screenshot oder eine Datei, die außer Proportion gestreckt wurde, sodass Quadrate zu Rechtecken werden. Behebe es an der Quelldatei: Neu exportieren als hochauflösendes PNG oder als SVG, das ohne Unschärfe skaliert, und nur proportional skalieren. Ein schon unscharfer Druck lässt sich nicht zurückschärfen – vom sauberen File neu drucken. Die fünf Ursachen und ihre Lösungen stehen in Warum dein QR-Code unscharf ist.

3. Niedriger Kontrast

Scanner suchen dunkle Module auf hellem Hintergrund. Hellgrau auf Weiß, pastellfarbene Markenfarben, ein Code über einem Foto oder dunkle Module auf dunklem Hintergrund entfernen alle den Unterschied, den die Kamera braucht. Das ist der häufigste designbedingte Fehler und der am leichtesten vermeidbare: Schwarz auf Weiß funktioniert immer, und jedes Farbpaar sollte noch in Schwarz-Weiß lesen. Vorsicht bei invertierten Codes und Codes über unruhigen Bildern, wo der Hintergrund mit dem Muster konkurriert. Wenn ein Code bei hellem Licht scannt, aber nicht in einem dunklen Raum, ist Kontrast der erste Verdächtige.

4. Ruhezone bedrängt oder beschnitten

Der leere Rand um einen Code ist keine Deko. Scanner nutzen ihn, um die Kanten des Musters zu finden, und der Standard legt eine Ruhezone von mindestens 4 Modulen Breite fest – vier der eigenen kleinen Quadrate des Codes – auf allen vier Seiten, wie in ISO/IEC 18004 definiert. Text oder Muster, die in diesen Rand drängen, verwirren die Erkennung, das Handy liest die Daten also nie. Dieser Fehler lässt sich leicht übersehen, weil der Code selbst perfekt aussieht. Teste ihn, indem du alles um den Code herum abdeckst: Wenn er sauber scannt, stelle den Rand wieder her und halte ihn leer.

5. Ein Logo, das zu viel vom Muster verdeckt

Ein zentrales Logo funktioniert nur, weil die Fehlerkorrektur die verdeckten Daten wiederherstellt. ISO/IEC 18004 definiert vier Fehlerkorrekturstufen – L, M, Q und H – mit einer ungefähren Codewort-Wiederherstellung von 7 %, 15 %, 25 % bzw. 30 %. Diese Prozentwerte beschreiben die Wiederherstellung von Codewörtern, nicht einen garantierten Anteil sichtbarer Fläche, den du verdecken darfst. Als Faustregel halte das Logo klein – der Druckgrößen-Leitfaden schlägt unter etwa 30 % der Codefläche vor –, nutze die höchste Fehlerkorrekturstufe, drucke größer als für einen schlichten Code und verdecke nie die drei großen Eckquadrate, die der Scanner braucht, um das Muster zu orientieren. Test-scanne zuerst auf zwei Handys. Siehe So fügst du einem QR-Code ein Logo hinzu und den Logo-Code-Generator.

6. Schaden, Schmutz und Verblassen

Knicke, Kratzer, Flecken, Verblassen und abgenutzte Aufkleber fressen alle ins Muster, und die Fehlerkorrektur kann nur so viel wiederherstellen. Schaden an den Eckquadraten ist besonders tödlich: Ohne sie kann der Scanner den Code überhaupt nicht finden. Bei Codes aus der echten Welt – Speisekarten, Etiketten, Outdoor-Schilder – schlägt Vorbeugung Reparatur: laminiere die Fläche, wähle eine höhere Fehlerkorrekturstufe, drucke ein Ersatzexemplar und inspiziere zuerst die ältesten Exemplare. Wenn das Muster selbst abgenutzt ist, drucke von der Originaldatei neu, statt die beschädigte Kopie zu flicken.

Das Ziel: Wenn der Code scannt, aber nichts Gutes passiert

Ein Scan, der eine Fehlerseite, eine fehlende Seite oder eine Landingpage zurückgibt, die du nicht erwartet hast, ist ein erfolgreicher Scan eines kaputten Ziels. Öffne den Link auf einem Computer und lies ihn Zeichen für Zeichen: eine umgezogene oder gelöschte Seite, eine vertippte Adresse, eine Website, die down ist, oder ein Kurzlink, dessen Eigentümer sein Ziel geändert hat, sind die üblichen Ursachen.

Eine strukturelle Version entscheidet, ob eine Lösung überhaupt möglich ist. Ein statischer Code hält das Ziel direkt in seinem Muster, er funktioniert also, solange der Link funktioniert – und wenn der Link stirbt, kann nur die Seite dahinter wiederhergestellt oder der Code neu gedruckt werden. Ein dynamischer Code hält stattdessen einen kurzen Redirect, sein Eigentümer kann also das Ziel ändern, ohne neu zu drucken – aber der Code hängt dann davon ab, dass dieses Konto und dieser Dienst aktiv bleiben. Wenn dieses Konto verfällt oder der Dienst den Redirect abschaltet, hört der gedruckte Code auf, irgendwo Nützliches hinzuführen, obwohl das Muster makellos ist. Das ist der Mechanismus hinter den meisten „Mein Code ist abgelaufen“-Geschichten, erklärt in Laufen QR-Codes ab?. Prüfe zuerst, ob das Ziel wiederhergestellt oder umgeleitet werden kann, bevor du neu druckst.

Das Handy und der Moment: Berechtigung, Fokus, Licht und Bildschirme

  • Kamera-Berechtigung. Ein Scanner, dem nie Kamera-Zugriff gewährt wurde, kann überhaupt nichts sehen. Erlaube Kamera-Zugriff und versuch es dann erneut. FreeQrlys Scanner decodiert in deinem Browser auf deinem eigenen Gerät – siehe die Scanner-Seite –, aber der Browser braucht trotzdem die Berechtigung, die Kamera zu öffnen.
  • Eine schmutzige Linse. Wische die Linse mit einem weichen Tuch ab. Eine verschmierte Linse verwischt genau die feinen Details, aus denen ein QR-Code gemacht ist.
  • Fokus und Distanz. Halte das Handy ruhig, halte den ganzen Code und seine Ruhezone im Bild und bewege dich langsam, bis der Fokus einrastet. Sehr nah ist nicht immer besser: Die meisten Kameras können aus wenigen Zentimetern Entfernung nicht fokussieren.
  • Licht und Blendung. Glänzende Laminierung, ein Bildschirm oder ein Spot kann Licht zurück in die Kamera reflektieren und die Module auswaschen. Neige den Code oder das Handy, geh aus direktem Licht heraus oder wechsle zu matter Oberfläche. Blendung, die sich beim Neigen bewegt, ist Blendung, kein Schaden.
  • Gewölbte oder schräge Flächen. Ein Code, der sich um eine Flasche wickelt oder aus einem steilen Winkel aufgenommen wird, ist verzerrt, und Scanner tolerieren nur so viel davon. Glätte, was du kannst, und nimm so gerade von vorn wie möglich auf.
  • Ein Code auf dem eigenen Bildschirm des Handys. Du kannst die Kamera eines Handys nicht auf das eigene Display richten. Für einen Code in einem Foto, Screenshot oder einer Nachricht auf demselben Handy decodiere stattdessen die Bilddatei: Auf dem iPhone halte den Code in Fotos lange gedrückt; auf Android nutze Lens in Fotos; auf einem Computer lade sie in einen Decoder hoch, etwa FreeQrlys Scanner. Die vollständigen Schritte stehen in So scannst du einen QR-Code aus einem Bild, und die Schritte Kamera für Kamera stehen in So scannst du einen QR-Code mit deinem Handy.

Apples eigene Anleitung bestätigt die Basis: Auf dem iPhone öffne die Kamera-App oder den Code-Scanner im Kontrollzentrum, halte das Handy so, dass der Code im Bild erscheint, und tippe auf den Link, der erscheint. Wenn dieser Weg bei einem Code, den andere Handys lesen, nichts tut, vermute Berechtigung, Fokus und Licht – keine fehlende Scanner-App. Die allgemeinen Schritte für iPhone und Android stehen in So scannst du einen QR-Code.

Nach Szene: Druck, Bildschirm und draußen

Gedruckte Codes: Flyer, Karten, Speisekarten, Verpackungen

Druckfehler sind meist Größe, Auflösung, Kontrast oder Verschleiß – in dieser Reihenfolge. Teste in endgültiger Größe, nicht auf dem Bildschirm: Drucke ein Exemplar, tritt auf die echte Betrachtungsdistanz zurück und scanne es mit zwei Handys. Prüfe die Ruhezone im fertigen Layout, nicht nur in der Vorschau, denn Layout-Tools schneiden Ränder weg. Laminiere angefasste Codes und behalte den Original-Export.

Codes auf Bildschirmen: Folien, TV, Videoanrufe, Websites

Bildschirm-Codes versagen an Blendung, Bildwiederhol-Flimmern und Größe im Verhältnis zur Distanz des Betrachters. Mach den Code groß auf der Folie, halte ihn mehrere Sekunden auf dem Bildschirm, statt ihn vorbeiflashen zu lassen, und vermeide es, ihn über einen bewegten Hintergrund zu legen. Bei Handy-zu-Handy-Anzeige Helligkeit erhöhen und von Deckenlichtern weg neigen.

Outdoor-Codes: Plakate, Schilder, Fahrzeuge, Schaufenster

Outdoor-Codes stehen allen Fehlern auf einmal gegenüber: Distanz, Sonnenlicht, Blendung, Wetter und Verblassen. Wähle großzügig größer nach der Ein-Zehntel-Regel, drucke mit hohem Kontrast auf mattem Material, mache sie wetterfest und teste aus echter Passanten-Distanz und echtem Winkel. Schaufenster-Codes brauchen eine besondere Prüfung: Scanne von außerhalb des Glases, bei Tageslicht, denn Reflexionen, die von innen unsichtbar sind, können den Code auswaschen.

Neu machen, neu drucken oder das Ziel reparieren?

  • Das Ziel reparieren, wenn der Code scannt, die Seite aber falsch ist oder fehlt, und du die Seite oder den Redirect kontrollierst. Kein Neudruck nötig.
  • Von der Originaldatei neu drucken, wenn die frische Kopie scannt, die installierte Kopie aber nicht: Druck, Fläche oder Platzierung sind gescheitert.
  • Den Code neu machen, wenn auch die frische Kopie versagt, die Daten falsch sind oder das Design – Größe, Kontrast, Logo, Rand – schuld ist. Generiere einen sauberen Code, teste ihn auf zwei Handys und drucke erst dann.
  • Code-Typ wechseln bei wiederkehrenden strukturellen Fehlern: Ein sich änderndes Ziel gehört in einen dynamischen Code; eines, das nie von einem Konto abhängen darf, gehört in einen statischen.

Wenn ein Code auf zwei Handys weiterhin versagt, von einem frischen, großen, Schwarz-auf-Weiß-Druck mit klarem Rand, vermute die Daten selbst – einen überlangen Link oder eine vertippte Adresse. Kürze den Link und generiere neu.

Gut zu wissen

Warum scannt mein QR-Code auf einem Handy, aber nicht auf einem anderen?

Dann sind Code und Link beide in Ordnung – das versagende Handy ist das Problem. Wische seine Linse ab, erlaube Kamera-Zugriff, halte ruhig mit dem ganzen Code im Bild und versuch es bei besserem Licht. Wenn er auf diesem Handy allein weiterhin versagt, nutze den eingebauten Kamera-Weg statt einer Scanner-App von Dritten.

Mein QR-Code scannt manchmal, aber nicht immer – ist er in Ordnung?

Nein. Ein Manchmal-Code ist ein grenzwertiger Code: Er besteht an deinem Schreibtisch und versagt in den Händen eines Kunden. Behandle ihn als kaputt und behebe die zugrundeliegende Ursache – meist Größe, Kontrast, Blendung oder eine bedrängte Ruhezone –, statt auf gutes Licht zu hoffen.

Wie groß sollte ein gedruckter QR-Code sein?

Als Faustregel mindestens 2 × 2 cm und mindestens ein Zehntel der erwarteten Scandistanz: Eine Tischkarte, die aus 50 cm gescannt wird, braucht einen Code von etwa 5 cm Breite, und ein Plakat, das aus 5 Metern gescannt wird, braucht einen von etwa 50 cm Breite. Dichte Codes mit langen Links brauchen mehr Raum als kurze Links.

Wie viel von einem QR-Code kann ein Logo verdecken?

Halte es klein. Nutze die höchste Fehlerkorrekturstufe, drucke größer als für einen schlichten Code und verdecke nie die drei großen Eckquadrate, die der Scanner braucht, um das Muster zu orientieren. Als Faustregel schlägt der Druckgrößen-Leitfaden unter etwa 30 % der Codefläche vor – und test-scanne den fertigen Code immer auf zwei Handys vor dem Druck.

Mein Code scannt, aber die Seite ist weg – ist der Code kaputt?

Nein. Das Muster hat perfekt decodiert; das Ziel ist gescheitert. Eine Seite, die umgezogen oder gelöscht wurde, eine vertippte Adresse oder ein dynamischer Code, dessen Konto oder Redirect abgeschaltet wurde, sehen alle so aus. Wenn du die Seite oder den dynamischen Redirect kontrollierst, stelle sie wieder her oder leite sie um – kein Neudruck nötig. Ein statischer Code lässt sich nicht umleiten; nur die Seite dahinter kann wiederhergestellt werden.

Brauche ich eine Scanner-App, um meinen Code zu testen?

Nein. Auf dem iPhone nutze die Kamera-App oder den Code-Scanner im Kontrollzentrum; auf Android nutze die eingebaute Kamera oder Lens. Für einen Code, der schon auf dem eigenen Bildschirm des Handys ist – in einem Foto oder Screenshot –, decodiere stattdessen die Bilddatei, statt die Kamera auf das eigene Display zu richten.
