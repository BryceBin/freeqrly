Dutzende Codes, ein Download

Fünfzig Produktseiten, fünfzig Codes, ein Nachmittag, den du nicht damit verbringen musst, sie einzeln zu erstellen. Links einfügen, ZIP herunterladen, fertig.

28. Oktober 2026 · 4 Min. Lesezeit

Einen QR-Code zu erstellen dauert Sekunden. Fünfzig einzeln zu erstellen dauert einen Nachmittag – und der fünfzigste hat garantiert einen Tippfehler. Die Massenerstellung gibt es genau für diese Aufgabe: Du fügst eine Liste mit Links ein, jeder Link wird zu einem eigenen Code, und du lädst den ganzen Satz in einer ZIP herunter.

So funktioniert's

  1. Links einfügen, einen pro Zeile. Bis zu 50 auf einmal im Batch-QR-Code-Generator.
  2. „Alle erzeugen“ anklicken. Jeder Link wird zu einem eigenen QR-Code, in einem Raster als Vorschau angezeigt.
  3. Die ZIP herunterladen. Ein Klick packt alle als druckfertige PNGs mit 1024 px, benannt qr-1.png, qr-2.png usw. Mehr als 50 nötig? Einfach einen weiteren Durchlauf starten – es gibt kein Tageslimit und kein Konto, an das du stößt.

Wo sich Massencodes bezahlt machen

  • Produktverpackungen und Etiketten. Ein Code pro Produktseite, Anleitung oder Nachbestell-Link – direkt auf die Verpackung gedruckt.
  • Veranstaltungen. Ein Code pro Ticket oder pro Check-in-Punkt, in einem Durchgang erzeugt statt an einem langen Abend voller Klicks.
  • Immobilien und Einzelhandel. Ein Code pro Angebot oder pro Regalartikel, jeder öffnet seine eigene Seite.
  • Speisekarten und Standorte. Ein Code pro Filiale oder pro Tisch, alle aus derselben Liste.

Drei Gewohnheiten, die Nachdrucke sparen

Liste vor dem Erzeugen prüfen. Ein falscher Link wird zu einem falschen Code – fünfzigfach, wenn er sich wiederholt. Die Liste einmal überfliegen, besonders die erste und letzte Zeile, wo sich Einfügefehler verstecken.

Ersten und letzten Code testscannen. Wenn diese beiden beim ersten Versuch lesbar sind, sind es die mittleren auch – sie werden auf dieselbe Weise gerendert. Auf dem Ausdruck testen, nicht nur am Bildschirm, wenn sie auf Papier kommen.

Bei der Druckgröße ehrlich bleiben. Ein Code auf einem Etikett braucht trotzdem mindestens 2 × 2 cm und dunkle Tinte auf hellem Hintergrund, mit freiem Rand (Ruhezone). Die Batch-Ausgabe ist druckfertig, aber ein winziges Etikett macht das zunichte.

Was Batch-Codes sind – und was nicht

Batch-Codes sind statisch: Der Link steckt in jedem Muster selbst, sie laufen also nie ab und brauchen keine Anmeldung. Das heißt auch: Ein Batch-Code lässt sich nach dem Druck nicht mehr bearbeiten – ändert sich ein Link, erzeuge diesen einen Code (oder den Batch) neu und drucke ihn erneut. Logo auf jedem Code gewünscht? Einmal hochladen, und es wird auf den ganzen Batch angewendet, wobei die Fehlerkorrektur automatisch erhöht wird, damit jeder Code scanbar bleibt.

Bereit? Erstelle deinen Batch – kostenlos, kein Wasserzeichen, kein Konto für statische Codes.

Gut zu wissen

Wie viele QR-Codes kann ich auf einmal erstellen?

Bis zu 50 pro Batch. Mehr nötig? Einfach einen weiteren Batch starten – es gibt kein Tageslimit und kein Konto, an das du stößt.

Ist die Massenerstellung wirklich kostenlos?

Ja. Viele Generatoren verlangen ein Abo für den Massenexport; hier ist es dasselbe kostenlose Tool, kein Wasserzeichen, keine Anmeldung für statische Codes.

In welchem Format kommen die Downloads?

Eine einzige ZIP mit hochauflösenden PNGs (1024 px), jeweils benannt qr-1.png, qr-2.png usw. – druckfertig.

Kann ich mein Logo zu Batch-Codes hinzufügen?

Lade dein Logo einmal hoch, und es wird auf den ganzen Batch angewendet, wobei die Fehlerkorrektur automatisch erhöht wird, sodass jeder Code scanbar bleibt.

Kann ich einen Batch-Code nach dem Druck noch bearbeiten?

Batch-Codes sind statisch, also nein – ändert sich ein Link, erzeuge den Code neu und drucke ihn erneut. Für bearbeitbare Codes nimm stattdessen einen dynamischen Code.
