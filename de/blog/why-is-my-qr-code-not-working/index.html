Warum will das Ding nicht scannen?

Ein QR-Code, der nicht scannt, ist fast nie ein Rätsel. Geh diese sieben Checks durch — in der Reihenfolge — und du findest den Übeltäter in etwa zwei Minuten.

2026-10-14 · 4 Min. Lesezeit

1. Zu klein

Der Klassiker. Ein Code, der mit 1 cm Breite in die Ecke einer Visitenkarte gequetscht wurde, scannt nicht zuverlässig. Minimum für den Druck, als Faustregel: 2×2 cm, und größer ist immer sicherer. Die vollständige Aufschlüsselung steht im Druckgrößen-Leitfaden.

2. Niedriger Kontrast hat ihn gekillt

QR-Leser suchen dunkle Module auf hellem Hintergrund. Hellgrau auf Weiß, Marken-Pastell oder ein Code über einem unruhigen Foto werden versagen — besonders bei dunklem Licht. Im Zweifel: Schwarz auf Weiß funktioniert immer.

3. Er ist beschädigt oder verblasst

Geknickte Flyer, sonnenverblasste Poster, verkratzte Aufkleber. Fehlerkorrektur kann etwas Schaden überleben (deshalb funktioniert das Hinzufügen eines Logos), aber es gibt eine Grenze. Wenn ein Viertel des Codes weg ist, neu drucken.

4. Keine Ruhezone

Der leere Rand um den Code ist keine Deko — Scanner brauchen ihn, um die Kanten zu finden. Halt eine klare Umrandung mindestens 4 Module breit auf allen vier Seiten, wie in ISO/IEC 18004 festgelegt. Lass Text oder Designelemente ihn nicht zupacken.

5. Blendung, Krümmung oder Winkel

Glänzende Laminierung unter hellem Licht, ein Code um eine Flasche gewickelt oder aus steilem Winkel aufgenommen. Flach machen, Blendung killen, frontal aufnehmen.

6. Der Inhalt ist tot

Der Code scannt gut — aber der Link ist kaputt, die Seite ist umgezogen, oder die Testphase des „kostenlosen“ Generators ist abgelaufen und hat deinen Code mitgenommen. Das ist die Abgelaufener-Link-Falle: Laufen QR-Codes ab? erklärt, welche es tun und wie du sie vermeidest.

7. Deine Kamera

Linse abwischen. Ernsthaft — eine verschmierte Linse steckt hinter einer peinlich hohen Zahl von „kaputten“ Codes. Dann auf einem zweiten Handy testen: Wenn Handy B ihn liest, war der Code nie das Problem.

Vor dem Druck testen

Den Code auf zwei verschiedenen Handys scannen (einem iPhone, einem Android, wenn du kannst), bevor du etwas in den Druck schickst. Dreißig Sekunden jetzt sparen später einen Neudruck. Erzeug einen Test-Code im kostenlosen Generator und probiere ihn aus.

Gut zu wissen

Warum scannt mein QR-Code auf einem Handy, aber nicht auf einem anderen?

Dann ist der Code selbst in Ordnung — es ist die Kamera, das Licht oder der Winkel auf dem versagenden Handy. Linse abwischen und bei besserem Licht versuchen.

Kann ein beschädigter QR-Code noch funktionieren?

Oft ja, dank Fehlerkorrektur — bis zu 30 % Schaden können auf der High-Stufe toleriert werden, wie in ISO/IEC 18004 definiert. Aber starker Schaden, Verblassen oder fehlende Finder-Patterns killen ihn.

Mein QR-Code scannt, aber der Link funktioniert nicht — ist der Code kaputt?

Nein, der Code macht seinen Job. Das Ziel ist das Problem: Die Seite ist umgezogen, die Seite ist down, oder ein testphasenbasierter Generator hat ihn deaktiviert.
