Warum will das Ding nicht scannen?

Ein QR-Code, der nicht scannt, ist fast nie ein Rätsel. Geh diese sieben Checks durch — in der Reihenfolge — und du findest den Übeltäter in etwa zwei Minuten.

14. Oktober 2026 · Zuletzt aktualisiert: 3. November 2026 · 15 Min. Lesezeit

Ein QR-Code, der nicht scannt, ist fast nie ein Rätsel. Geh diese Prüfungen – der Reihe nach – durch, und du findest den Schuldigen in etwa zwei Minuten. Bevor du irgendetwas änderst, teile das Problem dreifach auf: das Handy, den gedruckten oder angezeigten Code und das Ziel. Scanne mit einem zweiten Handy. Wenn es den Code liest, sind das erste Handy, seine Kamera oder sein Licht das Problem. Wenn kein Handy ihn liest, ist der Code selbst – Größe, Kontrast, Rand, Schaden oder Logo – das Problem. Wenn Handys ihn lesen, der Link aber ins Nichts führt, macht der Code seine Arbeit und das Ziel ist das Problem. Diese Dreiteilung erspart den meisten Leuten einen sinnlosen Neudruck, denn jeder Zweig hat eine andere Lösung.

Die zwei Standards, die die meisten Fehler erklären

Zwei Ideen aus ISO/IEC 18004, der Spezifikation der QR-Code-Symbologie, erklären einen überraschend großen Anteil an Scan-Fehlern. Die erste ist die Ruhezone: ein leerer Rand von mindestens 4 Modulen Breite auf jeder Seite, wobei ein Modul ein kleines Quadrat des Rasters ist. Scanner nutzen diesen Rand, um zu finden, wo das Symbol beginnt und endet, Text, Grafiken oder ein Beschnitt, der in ihn eindringt, können also einen perfekten Code für eine Kamera unsichtbar machen. Die zweite ist die Fehlerkorrektur: zusätzliche Daten, die es einem Leser erlauben, Codewörter wiederherzustellen, die falsch oder unlesbar zurückkommen, in vier Stufen – L etwa 7 %, M etwa 15 %, Q etwa 25 %, H etwa 30 %. Diese Prozentwerte beschreiben Codewörter, nicht sichtbare Fläche: Ein gerissenes Suchmuster kann einen Code weit innerhalb seiner Stufe töten, während verstreute kleine Schäden anderswo überleben können. Höhere Stufen sind auch nicht gratis: Mehr Wiederherstellungsdaten bedeuten ein dichteres Raster, das Erhöhen der Stufe bei einem ohnehin kleinen Code kann ihn also schwerer lesbar machen. Erhöhe sie aus einem Grund – ein Logo, raue Handhabung, Outdoor-Nutzung –, prüfe dann Größe erneut und test-scanne.

Schritt 1: Das Handy ausschließen

Wische die Linse ab. Eine verschmierte Linse steckt hinter einer peinlich großen Zahl angeblich kaputter Codes, denn ein dünner Fettfilm weicht das ganze Bild gerade genug auf, um Modulkanten zu verwischen. Teste dann auf einem zweiten Handy: Wenn Handy B ihn liest, war der Code nie das Problem. Das ganze Quadrat muss im Bild sein, mit ein bisschen Raum darum – ein Code, der vom Sucherrand beschnitten wird, liest sich nicht. Halte ruhig, sobald der Code etwa den halben Sucher füllt, und geh bei schwachem Licht zu besserem Licht. Ein Code, der eine Vorschau zeigt, aber beim Tippen ins Nichts führt, hat ein Zielproblem (Schritt 9), kein Scan-Problem.

Schritt 2: Größe und Distanz

Der klassische Fehler ist ein Code, der in eine Visitenkartenecke mit 1 cm Breite gequetscht wird. Als Faustregel brauchen gedruckte Codes mindestens 2 × 2 cm (etwa 0,8 Zoll), und größer ist immer sicherer. Größe und Distanz folgen der 1:10-Distanz-Faustregel: Codebreite mindestens ein Zehntel der Scandistanz – 5 cm für eine Tischkarte, die aus 50 cm gescannt wird, 50 cm für ein Plakat, das aus 5 Metern gescannt wird. Unterhalb dieser Regel für seine Distanz werden kein Putzen, kein Neuausrichten und kein Neu-Exportieren zuverlässig helfen – größer neu drucken oder den Code näher dorthin bringen, wo Leute stehen. Die vollständige Aufschlüsselung nach Anwendungsfall steht im Druckgrößen-Leitfaden. Dichte verschärft die Regel: Ein kurzer Link ergibt ein luftiges Raster, während ein langer Link, eine vollständige Kontaktkarte oder ein langes WLAN-Passwort ein dichteres Raster mit kleineren Modulen ergibt, das größer gedruckt werden muss. Ein dynamischer Code verkürzt das gedruckte Muster, ohne das endgültige Ziel zu verkürzen, denn er codiert einen Kurzlink, den du kontrollierst und später umleiten kannst, mit Scan-Stats, die die Leistung zeigen.

Schritt 3: Kontrast

QR-Leser suchen dunkle Module auf hellem Hintergrund. Hellgrau auf Weiß, Marken-Pastelltöne, ein dunkler Code auf Dunklem oder ein Code über einem unruhigen Foto werden versagen – besonders bei schwachem Licht. Beurteile ihn bei dem Licht, in dem der Code tatsächlich gescannt wird: Wenn du blinzeln musst, um Module vom Hintergrund zu unterscheiden, wird eine Handykamera ebenfalls kämpfen. Die Lösung ist Schwarz auf Weiß, was immer funktioniert, mit der Ruhezone in derselben hellen Hintergrundfarbe. Invertierte Codes – helle Module auf Dunklem – sind ein Sonderfall: Manche Leser kommen damit zurecht und viele nicht, verlasse dich also bei öffentlichen Codes nicht auf Invertierung. Wenn Markenfarben zählen, behalte sie im umgebenden Design und in einem kleinen zentralen Logo, nicht in den Modulen, und teste die farbige Version zuerst bei schwachem Licht.

Schritt 4: Die Ruhezone

Der leere Rand um den Code ist keine Deko – Scanner brauchen ihn, um die Kanten zu finden. Halte einen klaren Rand von mindestens 4 Modulen Breite auf allen vier Seiten, wie in ISO/IEC 18004 festgelegt, und halte Text, Linien, dekorative Rahmen und nahe Bilder daraus heraus. Dieser Fehler ist in gestalteten Layouts häufig, wo eine Überschrift, eine Linie oder eine Fotokante in den Rand kriecht, und an einer Seitenkante, wo ein Code zu nah am Beschnitt seinen Rand verliert. Prüfe alle vier Seiten: Ein Rand, der auf drei Seiten großzügig und auf der vierten null ist, versagt trotzdem. Die Lösung ist Layout, kein Neu-Export – gib dem Code Raum oder lege ihn auf ein schlichtes helles Feld, das den Rand in einem unruhigen Layout garantiert.

Schritt 5: Schaden, Verblassen und Verschleiß

Geknickte Flyer, sonnenverblasste Plakate, zerkratzte Aufkleber, regengesprenkelte Etiketten: Die Fehlerkorrektur kann manchen Schaden überleben, aber der Ort zählt mehr als die Größe. Schaden an den drei großen Eck-Suchmustern ist am schwerwiegendsten, denn ohne sie kann der Leser das Raster weder finden noch orientieren – ein gerissenes Suchmuster ist oft tödlich, selbst wenn der Rest intakt aussieht. Verstreute Kratzer über den Datenbereich sind weit nachsichtiger, denn genau dafür ist die Fehlerkorrektur gebaut, um sie wiederherzustellen. Verblassen ist langsamerer Schaden: Während dunkle Module Richtung Hintergrund aufhellen, sinkt der Kontrast, bis der Leser Module nicht mehr trennen kann, obwohl das Muster noch da ist. Beurteile einen abgenutzten Code zuerst an den Ecken, dann am Kontrast, dann an der Oberfläche. Die Lösung für einen beschädigten Druck ist ein Neudruck; für einen Code, der ein hartes Leben führen wird – draußen, auf Verpackungen, auf einem Fahrzeug –, sei vorbeugend: höhere Fehlerkorrektur, ein größerer Druck, Laminierung oder eine geschützte Position.

Schritt 6: Logo-Verdeckung

Ein Logo in der Mitte frisst sich ins Muster und verbraucht einen Teil des Fehlerkorrektur-Budgets schon von Natur aus – weshalb es funktionieren kann und weshalb es versagen kann. Beurteile es danach, wie viel vom Raster das Logo verdeckt und ob es ein Suchmuster berührt: Ein kleines Logo, sauber zentriert, frei von den drei Ecken, ist sicher; ein großes Logo, eines, das sich Richtung Ecken ausbreitet, oder eines mit unruhigen Details, die Module nachahmen, ist riskant. Als Faustregel halte das Logo unter etwa 30 % der Codefläche, drucke Logo-Codes mit 3 × 3 cm oder größer und nutze Fehlerkorrektur Q oder H. Teste speziell die Logo-Version: Ein schlichter Code, der scannt, sagt nichts über seinen Logo-Zwilling aus. Wenn ein Logo-Code versagt, verkleinere zuerst das Logo, vergrößere dann den Druck, erhöhe dann die Stufe und teste nach jeder Änderung. Schritt 7: Blendung, Wölbung und Winkel

Glänzende Laminierung bei hellem Licht, ein Code, der sich um eine Flasche wickelt, oder ein Foto aus einem steilen Winkel verzerren alle, was die Kamera sieht. Blendung wäscht Module fleckenweise aus; eine Wölbung streckt Randmodule, während sie mittlere staucht; ein steiler Winkel macht aus Quadraten Trapeze, die der Leser erst entzerren muss. Neige den Druck langsam: Wenn sich der unlesbare Fleck mit der Reflexion bewegt, ist es Blendung. Glätte die Fläche, wenn du kannst, und nimm gerade von vorn auf. Bevorzuge ein flaches Feld gegenüber einer engen Kurve, matt gegenüber Glanz, wo Lichter stark sind, und eine Position, der Leute frontal gegenüberstehen können. Ein Flaschen-Code, der scannt, wenn man die Flasche zur Kamera dreht, ist ein Platzierungsproblem – bring ihn an die flachste, am frontalsten gelegene Stelle und drucke ihn größer.

Schritt 8: Schärfe – wenn Unschärfe der Schuldige ist

Wenn der Code die richtige Größe hat, hohen Kontrast, gut bemessen, unbeschädigt und logo-frei ist, aber trotzdem zögert, schau auf die Modulkanten: scharf oder verschmiert? Exporte in niedriger Auflösung, JPEG-Komprimierung, Strecken, schlechter Druck und Kopien von Kopien weichen alle Kanten auf, und weiche Kanten versagen zuerst bei schwachem Licht und aus der Distanz. Die vollständige Diagnose steht in Warum dein QR-Code unscharf aussieht. Kurzversion: Neu exportieren mit 1024 px für Karten und Flyer oder 2048 px für Plakate, SVG nutzen, wann immer der Drucker es akzeptiert, nie JPEG für einen Code nutzen, Proportionen beim Skalieren behalten und zuerst einen echten Druck aus echter Distanz test-scannen. Weichheit und schwacher Kontrast verstärken sich, behebe also beides, statt nach einem einzigen Schuldigen zu suchen.

Schritt 9: Das Ziel ist tot

Manchmal scannt der Code einwandfrei – aber der Link ist kaputt, die Seite umgezogen, die Website down oder ein Trial-basierter Generator hat den Code deaktiviert. Das ist die Falle des abgelaufenen Links: Nach dem Tippen passiert nichts Nützliches, es fühlt sich also wie ein Scan-Fehler an. Beobachte die Link-Vorschau: Wenn eine Vorschau erscheint, hat der Code decodiert und das Ziel ist das Problem. Prüfe, ob die Seite sich öffnet, wenn man sie direkt in einen Browser tippt, und ob der Link von einem Dienst gekürzt wurde, der seither seine Bedingungen geändert hat. Statische Codes laufen nie von allein ab – das Ziel lebt im Muster, ein statischer Code versagt also nur, wenn das Ziel selbst verschwindet. Dynamische Codes zeigen auf einen Kurzlink, den du kontrollierst, eine umgezogene Seite lässt sich also ohne Neudruck reparieren: anmelden, das Ziel ändern, und der gedruckte Code funktioniert wieder, mit Scan-Stats zur Bestätigung. Diese Änderbarkeit ist auch die Falle, die man bei der Wahl eines Generators vermeiden sollte: Ein Code, der an ein beendetes Trial hängt, kann aufhören zu funktionieren, obwohl das Muster perfekt ist – siehe Laufen QR-Codes ab? vor einer großen Auflage. Für schon gedruckte Codes: statisch plus umgezogene Seite heißt Seite wiederherstellen oder neu drucken; dynamisch heißt umleiten und auf zwei Handys testen.

Szenarien: dieselbe Checkliste, andere Schuldige

Ein Flyer, der im Büro scannt, aber nicht auf dem Event

Bürolicht ist gnädig; Eventlicht ist es nicht. Die üblichen Schuldigen sind Kontrast, der bei hellem Licht nur gerade so besteht, ein Code, der für die Distanz, aus der Leute stehen, etwas zu klein ist, und Glanz unter Veranstaltungslichtern. Behebe der Reihe nach: Teste im Licht des Veranstaltungsorts, vergrößere den Code, wechsle zu matt und kehre vor dem Neudruck zu Schwarz auf Weiß zurück.

Eine Visitenkarte, die bei dir scannt, aber nicht bei Kunden

Dein Handy kennt den Code; das Handy eines Fremden trifft ihn kalt, bei schlechterem Licht, aus einem anderen Winkel. Prüfe zuerst die Größe – unter 2 cm versagt als Faustregel auf vielen Handys –, dann die Ruhezone, die Kartendesigns gern bedrängen, dann das Material, das Tinte aufsaugen und Kanten aufweichen kann.

Ein Code auf dem Bildschirm – Folien, Video oder Social-Bilder

Bildschirm-Codes versagen an Komprimierung, Größe und Zeit. Ein Code, der von einer Plattform erneut komprimiert, klein in einer Folienecke gezeigt oder kurz in einem Video eingeblendet wird, gibt der Kamera wenig zu arbeiten. Halte ihn groß, flach zur Kamera und lange genug auf dem Bildschirm, um zu scannen; für einen Code in einem Foto ist Scannen aus einem Bild die Ausweichlösung.

Ehrlicher Vergleich: Neu drucken, umleiten oder neu gestalten?

Nicht jeder Fehler verdient einen Neudruck. Wenn das Ziel umgezogen ist und der Code dynamisch ist, schlägt Umleiten Neudrucken bei Kosten, Abfall und Tempo – das Muster bleibt gültig und die Lösung dauert Minuten. Wenn der Code statisch ist und das Ziel umgezogen ist, ist Umleiten keine Option: Stelle das Ziel wieder her oder drucke neu und wähle beim nächsten Mal dynamisch, wenn sich das Ziel wieder ändern könnte. Wenn das Muster selbst schuld ist – zu klein, niedriger Kontrast, bedrängter Rand, schweres Logo, weicher Druck –, hilft kein Umleiten, denn der Leser kann das Muster nicht decodieren; drucke mit diesem geänderten Parameter neu, einen Parameter nach dem anderen, damit du lernst, welche Lösung gewirkt hat. Zwei Kompromisse verdienen eine klare Aussage. Erstens: Höhere Fehlerkorrektur ist kein Allheilmittel: Sie kauft Toleranz für Schaden und Logos, verdichtet aber das Raster, das Erhöhen der Stufe bei einem ohnehin kleinen Code kann es also schlimmer machen. Zweitens: Ein farbiger oder Logo-Code, der in deinem Büro scannt, ist nicht bewiesen: Er ist erst bewiesen, wenn er beim ersten Versuch, bei echtem Licht, aus echter Distanz, auf zwei verschiedenen Handys, auf echtem Material scannt.

Vor dem Druck testen – jedes Mal

  1. Auf zwei Handys scannen – wenn du kannst, einem iPhone und einem Android-Gerät – vor dem Druck.
  2. Bei echter Distanz und bei echtem Licht testen, auf echtem Material.
  3. Die Vorschau prüfen, dann das Ziel: Eine Vorschau heißt, der Code hat decodiert; eine sich öffnende Seite heißt, das Ziel funktioniert.
  4. Eine Sache nach der anderen ändern, wenn ein Test fehlschlägt, damit du weißt, welche Lösung tatsächlich geholfen hat.

Gut zu wissen

Warum scannt mein QR-Code auf einem Handy, aber nicht auf einem anderen?

Dann ist der Code selbst meist in Ordnung – es sind Kamera, Licht oder Winkel auf dem versagenden Handy. Wische die Linse ab, geh zu besserem Licht, halte den Code so, dass er etwa den halben Sucher füllt, und versuch es erneut.

Kann ein beschädigter QR-Code noch funktionieren?

Oft ja, dank Fehlerkorrektur – auf der Stufe „Hoch“ können etwa 30 % der Codewörter wiederhergestellt werden, wie in ISO/IEC 18004 definiert. Aber Schaden an den drei Eck-Suchmustern oder an der Ruhezone lässt sich weit schwerer beheben, und starkes Verblassen tötet einen Code, selbst wenn seine Form intakt aussieht.

Mein QR-Code scannt, aber der Link funktioniert nicht – ist der Code kaputt?

Nein, der Code macht seine Arbeit. Das Ziel ist das Problem: Die Seite ist umgezogen, die Website ist down oder ein Trial-basierter Generator hat ihn deaktiviert. Wenn der Code dynamisch ist, melde dich an und leite ihn um; wenn er statisch ist, stelle die Seite wieder her oder drucke neu.

Wie groß sollte ein gedruckter QR-Code sein?

Als Faustregel mindestens 2 × 2 cm und mindestens ein Zehntel der Scandistanz: 5 cm für eine Tischkarte, die aus 50 cm gescannt wird, 50 cm für ein Plakat, das aus 5 Metern gescannt wird. Dichtere Codes mit langen Links oder Kontaktkarten müssen bei derselben Distanz größer sein.

Warum versagt mein Logo-Code, wenn die schlichte Version scannt?

Das Logo verdeckt einen Teil des Rasters und verbraucht Fehlerkorrektur-Budget. Halte das Logo als Faustregel unter etwa 30 % der Codefläche, drucke Logo-Codes mit 3 × 3 cm oder größer, nutze Fehlerkorrektur Q oder H und teste die Logo-Version selbst – ein schlichter Code, der scannt, beweist nichts über seinen Logo-Zwilling.

Wie viel Leerraum braucht ein QR-Code um sich herum?

Eine Ruhezone von mindestens 4 Modulen Breite auf allen vier Seiten, wie in ISO/IEC 18004 festgelegt. Halte Text, Linien, dekorative Rahmen und nahe Bilder daraus heraus und prüfe alle vier Seiten – ein Rand, der auf drei Seiten großzügig und auf der vierten null ist, versagt trotzdem.

Kann ich einen gedruckten QR-Code ohne Neudruck reparieren?

Nur wenn das Problem das Ziel ist und der Code dynamisch ist: anmelden, das Ziel ändern, und das gedruckte Muster funktioniert wieder. Wenn das Muster selbst schuld ist – zu klein, niedriger Kontrast, bedrängter Rand, schweres Logo oder weicher Druck –, ist die Lösung ein Neudruck mit diesem geänderten Parameter.
