QR-Code nach dem Druck bearbeiten

Die Flyer sind schon raus — und der Link ist falsch. Mit einem dynamischen Code ist das ein Zwei-Minuten-Fix, kein Neudruck.

16. Oktober 2026 · 4 Min. Lesezeit

Die Flyer sind schon raus — und der Link ist falsch. Oder das Menü ist umgezogen. Oder die Kampagnenseite war nicht final, als das Poster in den Druck ging. Mit einem statischen Code ist das ein Neudruck. Mit einem dynamischen ein Zwei-Minuten-Fix.

Der Trick: Das Muster eines dynamischen Codes ändert sich nie. Es zeigt auf einen kurzen Link auf FreeQrlys Server, und du bestimmst, wohin dieser Link die Leute schickt. Bearbeitest du das Ziel, liefert jede gedruckte Kopie — schon an Wänden, Flyern, Verpackungen — sofort den neuen Inhalt. Kein Neudruck, keine Aufkleber über dem alten Code.

  1. Anmelden. Öffne die Anmeldeseite und meld dich bei dem Konto an, dem der Code gehört.
  2. Dashboard öffnen. Geh zu deinem Dashboard. Jeder dynamische Code deines Kontos ist dort als Karte, mit QR-Thumbnail und Scan-Zahl.
  3. Bearbeiten öffnen. Auf der Karte des Codes auf Bearbeiten klicken. Du siehst denselben Generator, mit dem du ihn erstellt hast — Typ, Inhalt, Stil, alles.
  4. Ändern, was du brauchst. Ziel, Inhalt, sogar der Typ: Ein Website-Code kann ein WLAN-Code werden. Farben, Logo, Rahmen — alles ebenfalls änderbar.
  5. Speichern. Klick Änderungen speichern. Fertig. Der gedruckte Code liefert jetzt den neuen Inhalt. Test es mit deiner Handykamera, um sicher zu gehen.

Was du ändern kannst — und was nicht

  • Ziel und Inhalt: der Link, der Text, das WLAN-Passwort — alles, was der Code trägt.
  • Typ: einen Code von einem Inhaltstyp auf einen anderen umstellen. Dem Muster ist das egal; es hält nur den kurzen Link.
  • Stil: Farben, Punkte, Logo, Rahmen. Das Dashboard-Thumbnail aktualisiert sich entsprechend.
  • Was du nicht ändern kannst: das gedruckte Muster selbst — aber das musst du auch nie, weil das Muster nur den kurzen Link hält. Und du kannst einen Code nicht an ein anderes Konto übertragen.

Zwei Dinge, die man wissen sollte

Bearbeitungen sind sofort und lautlos. Es gibt keinen „Erneut veröffentlichen"-Schritt und keine Verzögerung — der nächste Scan bekommt das neue Ziel. Wenn das alte Ziel eine Seite war, die du runtergenommen hast, fix erst den Code, dann nimm die Seite runter.

Löschen ist endgültig. Lösch einen Code und seine gedruckten Kopien funktionieren nicht mehr — es gibt kein Undo. Lösch nur, wenn der Code wirklich außer Dienst ist; der Platz wird für einen neuen Code frei. (Immer noch unsicher, ob dynamisch das Richtige für dich ist? Statisch vs. dynamisch, ehrlich erklärt. Gut zu wissen

Muss ich einen QR-Code nach dem Bearbeiten neu drucken?

Nein. Das gedruckte Muster hält einen kurzen Link; Bearbeiten ändert, wohin dieser Link zeigt. Jede gedruckte Kopie liefert sofort den neuen Inhalt.

Kann ich einen dynamischen QR-Code auf einen anderen Typ umstellen?

Ja. Im Dashboard Bearbeiten öffnen und einen neuen Typ wählen — ein Website-Code kann z. B. ein WLAN-Code werden. Das gedruckte Muster bleibt gültig.

Setzt das Bearbeiten eines QR-Codes seine Scan-Statistiken zurück?

Nein. Die Stats laufen auf demselben Code weiter. Einen Code zu löschen entfernt ihn und seine Stats endgültig.

Was, wenn ich einen dynamischen QR-Code aus Versehen lösche?

Es gibt kein Undo — gedruckte Kopien funktionieren nicht mehr und der Platz wird frei. Lösch nur Codes, die wirklich außer Dienst sind.
