So scannst du einen QR-Code

Keine App erforderlich. Jedes moderne iPhone und Android-Handy scannt QR-Codes mit der Kamera, die es schon hat. So geht's — plus was zu tun ist, wenn nichts passiert.

2026-10-14 · 4 Min. Lesezeit

  1. Kamera auf den Code richten Öffne die eingebaute Kamera-App und richte sie auf den QR-Code, das ganze Quadrat im Bild halten.
  2. Auf die Benachrichtigung tippen Ein Banner oder eine Link-Vorschau erscheint — tippe drauf, um das Ziel zu öffnen.
  3. Auf dem iPhone die eingebauten Shortcuts nutzen QR-Scanner im Kontrollzentrum oder langes Drücken auf das Kamera-Symbol. Für einen Code in einem Foto: in Fotos lange draufdrücken.
  4. Auf Android Lens oder Schnelleinstellungen nutzen Google Lens in der Kamera oder Google-App, oder die Kachel „QR-Code scannen“ in den Schnelleinstellungen. Für ein gespeichertes Bild: Google Fotos + Lens.
  5. Wenn nichts passiert, repariere den Code, nicht das Handy Näher rangehen, Linse abwischen und den Code selbst prüfen: zu klein, niedriger Kontrast, beschädigt oder auf eine Kurve gedruckt.
  6. Vor dem Öffnen die Vorschau prüfen Vor dem Tippen einen Blick auf die URL werfen, besonders bei Codes, die du an öffentlichen Orten findest.

Auf dem iPhone

Öffne die Kamera-App und richte sie auf den Code — eine Sekunde ruhig halten. Eine gelbe Benachrichtigung erscheint; tippe drauf. Das war's. Das funktioniert auf jedem modernen iPhone — Apples Anleitung behandelt die Kamera-App und den Code-Scanner.

Zwei Shortcuts, die es wert sind, sie zu kennen: Kontrollzentrum öffnen und auf das QR-Scanner-Symbol tippen (via Einstellungen → Kontrollzentrum hinzufügen, wenn es fehlt), oder auf dem Sperrbildschirm lange auf das Kamera-Symbol drücken. Wenn der Code in einem Foto oder Screenshot ist, öffne ihn in der Fotos-App und drück lange auf den Code — iOS erkennt ihn direkt im Bild.

Auf Android

Die meisten Android-Handys scannen auch mit der eingebauten Kamera: draufhalten, auf die Aufforderung warten, tippen. Auf Pixel und vielen anderen übernimmt Google Lens in der Kamera oder Google-App. Samsung-Handys haben einen eigenen Scanner im Schnelleinstellungs-Bereich — runterwischen und nach „QR-Code scannen“ suchen. Und wie beim iPhone kannst du ein gespeichertes Bild in Google Fotos öffnen und auf den Lens-Button tippen.

Wenn nichts passiert

Neun von zehn Mal liegt es am Code, nicht an deinem Handy: zu klein, niedriger Kontrast, beschädigt oder auf eine Kurve gedruckt. Die vollständige Checkliste steht in Warum sich dein QR-Code nicht scannen lässt. Die schmutzige Kameralinse ist der klassische übersehene Übeltäter — abwischen und nochmal versuchen.

Eine 3-Sekunden-Sicherheitsgewohnheit

Dein Handy zeigt eine Vorschau des Links, bevor es ihn öffnet. Schau drauf. Wenn ein Code auf einer Laterne eine Parkuhr verspricht, aber die URL wie eine zufällige Zeichenfolge aussieht, tippe nicht drauf — Aufkleber über echten Codes sind ein bekannter Betrug, vor dem die FTC gewarnt hat. Codes, die du selbst mit FreeQrly erzeugst, sind statisch und enthalten genau das, was du getippt hast, nichts Verstecktes.

Gut zu wissen

Brauche ich eine App, um QR-Codes zu scannen?

Nein. iPhones und praktisch alle Android-Handys scannen QR-Codes mit der eingebauten Kamera. Scanner-Apps von Drittanbietern sind unnötig und oft voller Werbung. Apples Anleitung behandelt die Kamera-App und den Code-Scanner auf dem iPhone.

Wie scanne ich einen QR-Code aus einem Screenshot?

Auf dem iPhone den Screenshot in Fotos öffnen und lange auf den Code drücken. Auf Android in Google Fotos öffnen und auf den Lens-Button tippen.

Warum scannt meine Kamera den QR-Code nicht?

Meist ist der Code zu klein, kontrastarm, beschädigt oder es gibt keine Ruhezone drumherum. Linse abwischen, näher rangehen und die vollständige Fix-Liste in unserem Ratgeber zur Fehlerbehebung ansehen.
