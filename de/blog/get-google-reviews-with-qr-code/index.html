Mehr Google Bewertungen mit einem QR-Code

Der beste Zeitpunkt, um um eine Bewertung zu bitten, ist der Moment, in dem ein zufriedener Kunde vor dir steht. Ein QR-Code macht aus diesem Moment einen einzigen Scan.

19. Oktober 2026 · Zuletzt aktualisiert: 3. November 2026 · 15 Min. Lesezeit

Google-Bewertungen entscheiden, wer gewählt wird – und die Unternehmen mit den meisten Bewertungen haben sie nicht durch Glück bekommen. Sie haben gefragt, im richtigen Moment, ohne jede Hürde. Ein QR-Code, der direkt auf dein Google-Bewertungsformular zeigt, verwandelt „Bitte hinterlasse uns eine Bewertung“ in einen einzigen Scan. Hol dir den Link, den Google selbst ausgibt, mach daraus einen Code, platziere ihn dort, wo ein zufriedener Kunde schon steht, und frage einmal, schlicht. Alles andere in dieser Anleitung ist Detail um diese Abfolge herum.

Der Grund, warum ein Code funktioniert, wo eine Follow-up-E-Mail oft nicht funktioniert, ist Timing. Eine Anfrage, die Tage später ankommt, konkurriert mit allem anderen in einem Posteingang. Ein Code auf dem Tisch, dem Beleg oder der Karte, die am Ende eines Besuchs überreicht wird, trifft den Kunden, während das Erlebnis noch frisch ist. Der Code überzeugt niemanden. Er entfernt die Schritte zwischen „Ich würde diesen Ort bewerten“ und dem Bewertungsformular: kein Suchen nach dem Unternehmensnamen, kein Wählen des richtigen Eintrags unter ähnlichen, kein Suchen nach dem Bewertungs-Knopf.

Wo jede Platzierung ihren Scan verdient

Platzierung ist das ganze Spiel, und verschiedene Platzierungen erwischen Kunden in verschiedenen Momenten. Nutze diese Tabelle, um Platzierungen für dein Unternehmen zu wählen, statt überall dasselbe Schild zu drucken.

Zwei Anmerkungen zu dieser Tabelle. Ein Visitenkarten-Code lässt sich leicht zu klein drucken: Ein Code, der in eine Ecke gequetscht wird, wird ignoriert, während ein 5-cm-Code auf einem Tischaufsteller gescannt wird. Und eine E-Mail-Signatur ist die eine Platzierung, bei der der Code selbst das falsche Werkzeug ist – der Leser ist schon auf einem Bildschirm, gib ihm also den Bewertungs-Link als Text, den er antippen kann. Der Link geht dorthin, wo Leute lesen, der Code dorthin, wo Leute stehen.

Schritt 1 – deinen Google-Bewertungslink holen

Du brauchst den direkten Link zu deinem Bewertungsformular, nicht nur deinen Unternehmenseintrag. Google gibt diesen Link aus deinem Unternehmensprofil aus, und seine aktuelle Hilfeseite gibt diese Schritte an:

  1. Gehe auf einem Computer zu deinem Unternehmensprofil, während du bei dem Google-Konto angemeldet bist, das es verwaltet.
  2. Wähle Bewertungen lesen, dann Mehr Bewertungen erhalten.
  3. Wähle Kopieren, um den Bewertungs-Link zu kopieren. Der Link sieht aus wie g.page/r/…/review – ein Kurzlink, der dein Bewertungsformular direkt öffnet.

Zwei Details zählen hier. Erstens: Dasselbe Feld enthält auch einen QR-Code, den du speichern kannst, indem du ihn mit der rechten Maustaste anklickst und „Bild speichern unter“ wählst – aber Google weist darauf hin, dass Bewertungs-QR-Codes nur in einem Computer-Browser erstellt werden können, nicht auf einem Mobilgerät, mach diesen Schritt also am Schreibtisch. Zweitens: Googles eigener Code ist schlicht: kein Branding, kein Rahmen, keine Anleitungszeile. Für ein Tresenschild oder einen Tischaufsteller lohnt es sich meist, aus demselben Link einen gestylten Code zu generieren – Logo, Rahmen und eine Zeile, die den Leuten sagt, was passiert, wenn sie scannen –, die zusätzliche Minute wert. Das Ziel ist in beiden Fällen identisch.

Teste den Link, bevor irgendetwas in Druck geht. Öffne ihn in einem privaten Browserfenster und bestätige, dass er auf dem Bewertungsformular deines Unternehmens landet, nicht auf einem allgemeinen Eintrag oder einem ähnlich benannten Unternehmen. Ein gedruckter Code mit falschem Ziel lehrt Kunden, dass deine Codes ins Nichts Nützliches führen.

Schritt 2 – daraus einen QR-Code machen

Füge den Link in einen Google-Bewertungs-QR-Code-Generator ein – es dauert Sekunden, es ist kostenlos, und ein statischer Code läuft nie ab. Drucke ihn in einer anständigen Größe, halte dunkle Tinte auf hellem Hintergrund und lass einen klaren ruhigen Rand um den Code. Der Druckgrößen-Leitfaden behandelt Größen im Detail; die Kurzversion ist, dass ein Code, bei dem Leute sich vorbeugen müssen, um ihn zu lesen, ein Code ist, den Leute nicht scannen werden.

Wähle nun zwischen statisch und dynamisch, denn die Wahl lässt sich schwerer rückgängig machen, sobald Hunderte Karten gedruckt sind:

  • Statisch ist der Standard für die meisten Läden. Der Bewertungs-Link lebt im Muster selbst, der Code braucht kein Konto, und er funktioniert weiter, solange dein Unternehmensprofil existiert. Ein statischer Code, gut gedruckt und gut platziert, ist alles, was die meisten Unternehmen mit einem Standort brauchen.
  • Dynamisch lohnt sich in zwei Situationen. Erstens, wenn sich das Ziel ändern könnte: Wenn Google je deinen Bewertungs-Link ändert oder du die Anfrage auf eine andere Seite verlegst, lässt dich ein dynamischer Code das Ziel aus deinem Dashboard ändern, ohne neu zu drucken. Zweitens, wenn du Platzierungen vergleichen willst: Gib Tresen, Beleg und Liefertasche jeweils ihren eigenen dynamischen Code, und die Scan-Statistiken zeigen, welche Platzierung tatsächlich gescannt wird. Dynamische Codes sind kostenlos zum Starten mit einer Anmeldung, nach dem Druck änderbar und kommen mit Scan-Statistiken, mit 20 Codes auf dem kostenlosen Konto und unbegrenzten Scans während der zeitlich begrenzten Aktion. Der Kompromiss ist ehrlich: Ein dynamischer Code zeigt auf einen Kurzlink auf einem Server, er hängt also davon ab, dass dieser Dienst oben bleibt, während ein statischer Code von nichts abhängt außer dem gedruckten Muster und dem Ziel.

Wenn du mehrere Standorte betreibst, teile keinen Code über sie. Jeder Standort hat sein eigenes Unternehmensprofil und seinen eigenen Bewertungs-Link, mach also einen Code pro Standort, beschrifte die Dateien nach Standortnamen und prüfe jeden vor dem Druck.

Schritt 3 – dort platzieren, wo der Moment passiert

Der Code muss vor einem zufriedenen Kunden stehen, bevor er geht. Geh deine eigene Kundenreise durch und markiere jeden Punkt, an dem jemand glücklich, ohne Eile und mit Handy in der Hand ist – das sind deine Platzierungen, und alles andere ist Deko.

Restaurants und Cafés

Tischaufsteller und Beleg sind die zwei Platzierungen, die zählen. Der Tischaufsteller erwischt Leute mitten im Essen, wenn sie entspannt sind und das Handy schon auf dem Tisch liegt. Der Beleg erwischt sie am Ende, wenn der ganze Besuch frisch ist. Ein Code an der Eingangstür wird dagegen von ankommenden Leuten gescannt – dem einen Moment, in dem sie noch nichts zu bewerten haben. Passe die Formulierung an den Moment an: „Hat das Essen geschmeckt? Ein Scan.“

Einzelhandel und Salons

Der Tresen an der Kasse ist der natürliche Ort – Zufriedenheit erreicht beim Kauf ihren Höhepunkt, und der Kunde steht schon dort, Handy in der Hand, während die Kartenzahlung durchgeht. Platziere den Code auf Augenhöhe, nicht flach auf dem Tresen, wo Taschen ihn verdecken, und nicht hinter der Kasse, wo nur Personal ihn sehen kann. Ein kleines Stehschild neben dem Kartenleser schlägt ein Plakat an der fernen Wand.

Dienstleistungen: Klempner, Nachhilfe, Kliniken, Salons

Bei Arbeit, die beim Kunden zu Hause oder in einem Termin erledigt wird, ist der Übergabemoment alles. Eine Karte, die am Ende des Besuchs überreicht wird – oder ein Aufkleber auf der Rechnung –, reist nach Hause und liegt als Erinnerung auf der Küchentheke. Die gesprochene Bitte zählt genauso viel wie die Karte: „Wenn du mit der Arbeit zufrieden warst, bringt dich diese Karte direkt zu unseren Google-Bewertungen.“ Ohne diesen Satz ist die Karte nur ein weiteres Stück Papier.

Lieferung und Takeaway

Ein Aufkleber auf der Tasche oder Box bringt den Code genau in dem Moment vor den Kunden, in dem er das Essen öffnet. Das Essen ist die Erinnerung, und der Code ist schon in seinen Händen. Halte die Formulierung bei einer Zeile: Eine Liefertasche hat begrenzten Platz und ein kurzes Aufmerksamkeitsfenster.

E-Mail-Signaturen und Follow-up-Nachrichten

Für Unternehmen, die Kunden schon per E-Mail schreiben – Rechnungen, Buchungsbestätigungen, Dankesnotizen –, ist die Signatur eine leise, dauerhafte Platzierung. Füge den Bewertungs-Link als kurze Textzeile hinzu statt als Code-Bild, da der Leser schon auf einem Bildschirm ist. Dasselbe gilt für eine Follow-up-Nachricht nach dem Besuch: eine kurze Nachricht, ein Link, noch am selben Tag geschickt, während der Besuch noch frisch ist.

Was daneben stehen sollte

Ein nackter Code bekommt weniger Scans als ein Code mit einem Grund. Halte es kurz und konkret:

  • „Begeistert von deinem Besuch? Scanne, um uns auf Google zu bewerten.“
  • „Hat das Essen geschmeckt? Ein Scan, um uns zu bewerten.“
  • „Zufrieden mit der Arbeit? Dieser Code bringt dich zu unseren Google-Bewertungen.“

Um Google-Bewertungen namentlich zu bitten, zählt – Kunden greifen standardmäßig auf die Plattform zurück, die am einfachsten ist. Formulierungen, die auf eine Sternebewertung hindeuten („Gib uns fünf Sterne“), überschreiten die Grenze vom Bitten zum Lenken, und Googles Richtlinie behandelt Lenken als Verstoß, wie der Compliance-Abschnitt unten erklärt.

Die Compliance-Regeln, verifiziert anhand Googles eigener Seiten

Dieser Abschnitt nennt nur Richtlinienpunkte, die auf Googles offiziellen Support-Seiten stehen, denn Bewertungspolitik ist genau das Thema, bei dem Zusammenfassungen aus zweiter Hand abdriften. Googles Seite zu verbotenen und eingeschränkten Inhalten und seine Seite mit Tipps für mehr Bewertungen stimmen in Folgendem überein:

  • Bewertungen müssen eine echte Erfahrung widerspiegeln und echt und unvoreingenommen sein. Das ist das Fundament, an dem alles andere hängt. Eine Bewertung von jemandem, der nie da war, oder eine Bewertung, die nach Diktat des Unternehmens geschrieben wurde, besteht diesen Test nicht, egal wie sie beschafft wurde.
  • Nie Anreize für eine Bewertung anbieten. Google erlaubt Händlern nicht, Zahlung, Rabatte, kostenlose Waren oder kostenlose Dienstleistungen im Tausch gegen das Posten einer Bewertung, das Überarbeiten einer Bewertung oder das Entfernen einer negativen Bewertung anzubieten. Anreiz- oder voreingenommene Bewertungen werden von Maps entfernt. Das deckt die offensichtlichen Fälle ab – ein Rabatt für eine Bewertung, ein kostenloses Dessert für eine Bewertung – und die weniger offensichtlichen, wie eine Teilnahme an einer Verlosung für Bewerter oder ein Vorteil, um eine negative Bewertung herunterzunehmen.
  • Negative Bewertungen nicht entmutigen und nicht nur die Kunden fragen, von denen du erwartest, dass sie glücklich sind. Googles Richtlinie listet beides als Bewertungsmanipulation: das Entmutigen oder Verbieten negativer Bewertungen und das selektive Einholen positiver Bewertungen. Die regelkonforme Version ist einfach und auch besseres Geschäft: Frage jeden Kunden, auf dieselbe Weise, am selben Punkt der Reise. Ein Bewertungsprofil, das nur aus handverlesenen glücklichen Kunden gebaut ist, ist sowohl ein Richtlinienrisiko als auch ein Glaubwürdigkeitsproblem – Leser merken es.
  • Leute nicht dazu verpflichten oder drängen, zu bewerten, während sie vor Ort sind, und den Inhalt nicht vorschreiben. Googles Richtlinie sagt, Händler sollten Nutzer nicht dazu verpflichten oder drängen, Bewertungen oder Ratings zu hinterlassen, während sie vor Ort sind, und nicht verlangen, dass bestimmte Inhalte enthalten sind – inklusive Personal-Quoten oder Bewertungen, die einen bestimmten Mitarbeiter erwähnen. Die praktische Grenze: Ein sichtbarer Code plus eine gesprochene, freiwillige Bitte ist regelkonform; über einem Kunden zu stehen, bis er postet, ist es nicht.
  • Bitten selbst ist erlaubt. Google erlaubt Händlern ausdrücklich, Inhalte zu erbitten oder zu ermutigen, die eine echte Erfahrung darstellen, vorausgesetzt, kein Anreiz wird angeboten und kein Versuch unternommen, die Bewertung oder die Inhalte zu beeinflussen. Der QR-Code ist schlicht die reibungsärmste Form dieser erlaubten Bitte.

Über Googles eigene Regeln hinaus sollten US-Unternehmen wissen, dass die Consumer-Reviews-Regel der Federal Trade Commission, in Kraft seit dem 21. Oktober 2024, verbietet, Vergütung oder andere Anreize zu gewähren, die an eine Bewertung mit einer bestimmten Stimmung geknüpft sind, und zivilrechtliche Strafen für wissentliche Verstöße zulässt. Beachte den Unterschied im Umfang: Die FTC-Regel zielt auf Anreize, die an eine Stimmung geknüpft sind, während Googles Formulierung Anreize für das Posten einer Bewertung überhaupt ausschließt.

Compliance heißt nicht nur, Entfernung zu vermeiden. Ein Unternehmen, das seine Bewertungen beantwortet, bekommt mehr davon, denn Bewerter sehen, dass sie gelesen werden. Googles Tipps-Seite rät, Antworten professionell, höflich, kurz und konkret zu halten statt jedem dasselbe Danke zu schicken, und eine komplexe Beschwerde auf einen privaten Kanal zu verlagern statt öffentlich zu streiten. Antworte auch auf die negativen Bewertungen, ruhig und ohne private Informationen des Bewerters zu teilen.

Der ehrliche Vergleich: Was ein Bewertungs-Code nicht kann

Ein Bewertungs-Code ist ein Reibungsentferner, keine Reputationsmaschine, und es lohnt sich, seine Grenzen schlicht zu nennen, bevor du hundert Karten druckst:

  • Er kann keine Zufriedenheit erschaffen. Ein Code vor einem unzufriedenen Kunden erzeugt bestenfalls nichts und schlimmstenfalls eine ehrliche negative Bewertung. Repariere zuerst das Erlebnis.
  • Er kann das Bitten nicht ersetzen. Der Code ist passiv. Bei jeder Platzierung oben funktioniert er am besten gepaart mit einem gesprochenen Satz im richtigen Moment und danach Stille.
  • Er kann nicht nur glückliche Kunden anvisieren. Jedes System, das filtert – ein Code, der nur nach einem guten Ergebnis gezeigt wird, eine Anfrage, die nur an Kunden geschickt wird, die gelächelt haben –, bricht Googles Regel gegen selektives Einholen. Frage alle und antworte auf alles.
  • Er kann einen kaputten Link nicht allein reparieren. Ein statischer Code hält den Link, mit dem er gedruckt wurde. Wenn sich dein Bewertungs-Link ändert, zeigt ein statischer Code weiterhin auf das alte Ziel. Das ist der eine Fall, in dem sich ein dynamischer Code bezahlt macht: Ändere das Ziel einmal im Dashboard und jedes gedruckte Exemplar folgt.

Ein paar ehrliche Tipps

  • Bitten, nicht betteln. Ein sichtbarer Code plus ein gesprochenes „Wir würden uns über eine Bewertung freuen“ schlägt fünf Schilder.
  • Starte mit einer Platzierung, nicht mit fünf. Platziere den Code dort, wo dein glücklichster Moment schon passiert, und lass ihn ein paar Wochen laufen, bevor du ihn überall druckst.
  • Antworte auf Bewertungen. Ein Unternehmen, das Bewertungen beantwortet, bekommt mehr davon; Bewerter sehen, dass du sie liest. Halte Antworten kurz, konkret und menschlich.
  • Verfolge, was funktioniert. Wenn du wissen willst, welche Platzierung Scans bringt, nutze einen dynamischen Code für einen Standort und vergleiche.

Bereit, deinen zu machen? Kopiere deinen Bewertungs-Link aus deinem Unternehmensprofil, füge ihn in den Google-Bewertungs-QR-Code-Generator ein und drucke ihn für den Ort, an dem deine glücklichsten Kunden schon stehen. Statische Codes sind kostenlos, brauchen keine Anmeldung und laufen nie ab. Wenn sich das Ziel ändern könnte oder du Platzierungen vergleichen willst, mach ihn stattdessen dynamisch – kostenlos mit Anmeldung, nach dem Druck änderbar, mit Scan-Statistiken und unbegrenzten Scans.

Gut zu wissen

Wie erstelle ich einen QR-Code für Google Bewertungen?

Kopiere deinen Google-Bewertungs-Link aus deinem Unternehmensprofil (Bewertungen lesen, dann Mehr Bewertungen erhalten, dann Kopieren), füge ihn in einen kostenlosen QR-Code-Generator ein und drucke den Code. Statische Codes sind kostenlos und laufen nie ab. Beachte, dass Google seinen eigenen Bewertungs-QR-Code nur in einem Computer-Browser erstellt, nicht auf einem Mobilgerät.

Wo sollte ich meinen QR-Code für Google Bewertungen platzieren?

Wo immer ein zufriedener Kunde vor dem Gehen steht: Restauranttische und Belege, Tresen im Einzelhandel, Dienstleistungsrechnungen oder Lieferverpackungen. Für E-Mails nutze den Bewertungs-Link als anklickbare Textzeile in deiner Signatur statt als Code-Bild, da der Leser schon auf einem Bildschirm ist.

Laufen QR-Codes für Google Bewertungen ab?

Ein statischer QR-Code läuft nie ab – er hält deinen Bewertungs-Link direkt. Solange dein Google-Unternehmensprofil existiert, funktioniert der Code weiter. Ein dynamischer Code funktioniert auch weiter, solange der Dienst hinter seinem Kurzlink oben bleibt und du den Code nicht löschst.

Sollte ich einen Rabatt für eine Google Bewertung anbieten?

Nein. Google verbietet, Zahlung, Rabatte, kostenlose Waren oder kostenlose Dienstleistungen im Tausch gegen das Posten, Überarbeiten oder Entfernen einer Bewertung anzubieten, und Anreiz- oder voreingenommene Bewertungen werden von Maps entfernt. In den USA verbietet die FTC-Consumer-Reviews-Regel außerdem Anreize, die an eine Bewertung mit einer bestimmten Stimmung geknüpft sind. Frage stattdessen im richtigen Moment – dafür ist der QR-Code da.

Sollte ich für Google-Bewertungen einen statischen oder einen dynamischen Code nutzen?

Statisch für die meisten Unternehmen mit einem Standort: kostenlos, keine Anmeldung, läuft nie ab. Dynamisch, wenn sich das Ziel ändern könnte oder wenn du Platzierungen vergleichen willst – gib Tresen, Beleg und Liefertasche jeweils ihren eigenen dynamischen Code und vergleiche ihre Scan-Statistiken. Dynamische Codes sind kostenlos mit Anmeldung, nach dem Druck änderbar und kommen mit Scan-Statistiken.

Kann ich Kunden um eine Bewertung bitten, während sie noch in meinem Laden sind?

Ja, mit einer gesprochenen, freiwilligen Bitte – aber verpflichte oder dränge niemanden, vor Ort zu bewerten, und gib ihnen keine Formulierung zum Kopieren in die Hand. Googles Richtlinie verbietet, Nutzer dazu zu verpflichten oder zu drängen, vor Ort Ratings oder Bewertungen zu hinterlassen, und verbietet, bestimmte Inhalte zu verlangen, inklusive Bewertungs-Quoten für Personal.

Was, wenn sich mein Google-Bewertungs-Link ändert, nachdem ich Karten gedruckt habe?

Ein statischer Code zeigt weiterhin auf den alten Link, du müsstest also neu drucken. Ein dynamischer Code lässt sich im Dashboard ohne Neudruck umleiten: Ändere das Ziel einmal und jedes gedruckte Exemplar folgt. Wenn du statische Codes druckst, notiere dir, welchen Link jede Charge trägt, und teste den Link erneut nach jeder Änderung an deinem Unternehmensprofil.
