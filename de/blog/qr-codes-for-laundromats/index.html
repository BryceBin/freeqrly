QR-Codes für Waschsalons: weniger Warten, weniger Fragen

Ein Waschsalon lebt von kleinen Fragen, die immer im falschen Moment kommen – welche Maschine ist das, wie bezahle ich, wie lange dauert es noch, und wem sage ich Bescheid, wenn etwas kaputtgeht? Setz einen gut beschrifteten QR-Code genau dorthin, wo jede Frage auftaucht, und deine Kundschaft kann sie sich selbst beantworten, auch wenn das Personal gerade woanders beschäftigt ist.

4. November 2026 · 15 Min. Lesezeit

Ein Waschsalon ist ein Warteraum mit Maschinen darin. Die Kundschaft kommt mit dem Wäschekorb, belädt, wartet, faltet und geht wieder, während das Personal oft jemand anderem hilft oder gerade nicht im Raum ist. Ein QR-Code kann kein Handtuch falten, aber er kann die Frage beantworten, die sich die Kundschaft ohnehin schon stellt: Welche Maschine ist das, wie bezahle ich sie, wie lange dauert es, und wem sage ich Bescheid, wenn etwas schiefgeht?

Gib jeder Aufgabe ihren eigenen Code, genau dort, wo die Aufgabe anfällt. Ein großer Code an der Eingangstür, der nur deine Startseite öffnet, hilft niemandem, der mit nasser Wäsche vor Waschmaschine Nummer sieben und einer klemmenden Tür steht.

Fang mit einem Code pro Maschine an

Beschrifte jede Maschine und gleiche den Code mit der Beschriftung ab. Druck die Waschmaschinen- oder Trocknernummer groß neben den Code – zum Beispiel W-04 oder D-12 – und stell sicher, dass die Seite, die der Code öffnet, dieselbe Nummer zeigt. Diese eine Gewohnheit verhindert die meisten Verwechslungen: Kundschaft, die für die falsche Maschine bezahlt, die falsche Maschine meldet oder das Personal bittet, eine Ladung zu finden, die gar nicht dort ist, wo sie vermutet wird.

Was der Maschinencode öffnet, hängt davon ab, wie dein Laden aufgestellt ist. Ein QR-Code allein weiß nicht, ob eine Maschine läuft, und er kann eine Maschine auch nicht von selbst starten. Er ist eine Abkürzung zu einer Seite, einem Formular oder einem Bezahlsystem. Wenn du ein vernetztes Wasch-Bezahlsystem nutzt, bietet es vielleicht einen Scan-to-Start-Code für jede Maschine an: Ein Anbieter beschreibt seinen Gast-Ablauf zum Beispiel so, dass man den Code an der Maschine scannt, Programm und Zusatzoptionen wählt und mit Mobile Wallet oder Karte bezahlt, woraufhin die Maschine automatisch startet. Ohne ein solches System kann der Maschinencode trotzdem eine einfache Seite für diese Maschine öffnen – mit Fassungsvermögen, Programmoptionen, Preis und einem Link zur Problemmeldung.

Nutze den Maschinencode für Programmhilfe und Störungsmeldungen

Für einen Laden ohne vernetztes System ist die praktischste Maschinenseite eine kurze Anleitung: was diese Maschine fasst, welche Programme für Feinwäsche, schwere Bettwäsche oder ein schnelles Auffrischen passen, wie lange ein typisches Programm dauert und was zu tun ist, wenn sich die Tür nicht öffnen lässt. Halt den Text kurz. Niemand will einen Aufsatz lesen, während die Wäsche schleudert.

Derselbe Code oder ein zweiter, klar beschrifteter Code an der Maschine kann ein Störungsformular öffnen. Füll die Maschinennummer vorab aus, wo dein Formulartool das zulässt, und frag nur, was das Personal zum Handeln braucht: was passiert ist, ob die Maschine sicher benutzt werden kann, und eine Kontaktdatenangabe nur, wenn die Kundschaft eine Antwort zu einer Erstattung oder einem verlorenen Gegenstand wünscht. Eine Meldung, die in dreißig Sekunden abgeschickt ist, wird abgeschickt; eine Meldung, die ein Konto und ein Passwort verlangt, nicht. Ergänz daneben eine kurze Ausweichmöglichkeit – eine Telefonnummer oder den Hinweis, an der Theke Bescheid zu sagen – für Kundschaft, deren Handyakku leer ist.

Und was ist mit dem Live-Programmstatus?

Live-Status – also eine Seite, die sagt, dass eine Maschine noch zwölf Minuten braucht – ist die Funktion, nach der die Kundschaft am häufigsten fragt, und zugleich die, die ein gedruckter Code allein nicht liefern kann. Ein Code kann nur eine Seite öffnen; eine Live-Zeitangabe braucht ein vernetztes System, das das Programm verfolgt. Wenn dein System das anbietet, ist der Maschinencode der natürliche Zugang dazu. Wenn nicht, versprich auf deinen Schildern keinen Live-Status.

Wasch- und Legeservice: ein Code für die Abgabe, einer für die Abholung

Der Wasch- und Legeservice macht aus einem Selbstbedienungsbesuch eine Übergabe, und bei Übergaben geht etwas verloren: Taschen ohne Namen, Sonderwünsche, die niemand aufgeschrieben hat, und Abholzeiten, an die sich niemand erinnert. Ein Code an der Theke kann ein Abgabeformular öffnen, das nach Name, Kontaktweg, Anzahl der Taschen und etwaigen Hinweisen fragt – Kaltwäsche, kein parfümiertes Waschmittel, Feinwäsche zum Trocknen aufhängen –, bevor die Kundschaft geht. Druck denselben Code oder einen Abholcode auf den Abholschein oder den Beleg, damit die Kundschaft dieselben Informationen später noch einmal prüfen kann.

Halt es bei der Abholung genauso einfach. Der Scheincode kann eine Seite öffnen, die Abholzeiten zeigt, was mitzubringen ist und wie man den Laden erreicht, wenn sich eine Abholzeit ändern muss. Wenn dein System den Bestellstatus anzeigen kann, verlinke darauf; wenn nicht, sag das offen und gib stattdessen die Telefonnummer der Theke an. Das Ziel sind weniger Anrufe mit der Frage „Ist meine Wäsche fertig?“, keine Statusseite, die rät. Lass persönliche Daten aus dem QR-Code selbst heraus: Der Code soll ein Formular oder eine passwortgeschützte Bestellseite öffnen, niemals einen Kundennamen oder eine Telefonnummer im gedruckten Muster verschlüsseln.

Treueprogramm, das eine durchnässte Tasche überlebt

Papier-Stempelkarten funktionieren, bis sie mitgewaschen werden – was in einem Waschsalon kein seltener Unfall ist. Ein QR-Code kann die Karte durch einen Link zu deiner Treueseite ersetzen, wo die Kundschaft das aktuelle Angebot sieht und erfährt, wie sie es einlöst. Ein einfaches Beispiel ist „jede zehnte Wäsche gratis“ – versteh das als Veranschaulichung, nicht als Regel. Wähl eine Schwelle, die deine Marge trägt, schreib sie in einfachen Worten aufs Schild und behalt denselben Wortlaut auf der Seite, die der Code öffnet.

Sei ehrlich darüber, was der Code hier leistet. Scan-Statistiken sagen dir, wie oft eine Treueseite geöffnet wurde; allein identifizieren sie keine einzelnen Kundinnen und Kunden und zählen auch nicht die Besuche einer einzelnen Person. Echte Treue pro Kundschaft braucht ein Treuekonto oder eine App hinter der Seite, mit dem QR-Code als einfachstem Weg dorthin.

WLAN für wartende Kundschaft

Warten gehört im Waschsalon dazu, und WLAN ist eine günstige Art, es angenehm zu machen. Mit einem WLAN-Code tritt die Kundschaft per Scan dem Netz bei, ohne ein langes Passwort von einem verblassten Schild abtippen zu müssen. Als Faustregel: Leg das WLAN auf ein Gästenetz statt auf das Netz, das dein Bezahlsystem oder deine Bürorechner nutzen, und bring den Code dort an, wo die Leute sitzen – bei den Falttischen und Stühlen –, nicht nur an der Tür, an der sie vorbeilaufen.

WLAN ist das klarste Beispiel für eine Aufgabe für einen statischen Code. Netzname und Passwort ändern sich selten, und ein oder zwei Wartebereichsschilder neu zu drucken, ist ein kleiner Aufwand, falls doch. Mehr dazu in unserer Anleitung zum Teilen von WLAN per QR-Code.

Google-Bewertungen: Frag im richtigen Moment – und nicht nach einer Note

Der beste Moment, um um eine Bewertung zu bitten, ist, wenn die Arbeit gut erledigt ist – saubere Maschinen, eine gefaltete Ladung, ein hilfsbereites Personalmitglied –, nicht während die Kundschaft noch eine Waschmaschine belädt. Bring einen Bewertungscode auf den Falttischen, auf dem Beleg oder am Ausgang an, mit einer kurzen, ehrlichen Einladung wie „Guter Besuch? Erzähl es hier anderen.“ Der Code soll deine Google-Bewertungsseite direkt öffnen, damit die Kundschaft dein Unternehmen nicht erst suchen und die richtige Filiale auswählen muss. Google Unternehmensprofil stellt dafür einen Link zur Bewertungsanfrage bereit; die Schritte sind: „Bewertungen lesen“ wählen, dann „Mehr Bewertungen erhalten“ und den Link kopieren.

Biete keinen Rabatt, keine Gratiswäsche und keinen anderen Anreiz im Austausch für eine Bewertung an. Googles Richtlinie verbietet Anreize für das Veröffentlichen, Ändern oder Entfernen einer Bewertung. Wenn du mehr als eine Filiale hast, prüf vor dem Druck, ob der Code den richtigen Standort öffnet. Unsere Anleitung zum Einholen von Google-Bewertungen per QR-Code geht die Einrichtung genauer durch.

Preise und Bezahllinks

Preise ändern sich: Waschmittelkosten steigen, eine neue Großraumwaschmaschine kommt dazu oder eine Wochenendaktion läuft einen Monat lang. Genau deshalb sollte eine Preisliste nicht in einen gedruckten Code eingebrannt sein, der sich nicht ändern lässt. Ein dynamischer Code auf der Preistafel kann auf eine aktuelle Preisseite zeigen, sodass eine Preisänderung bedeutet, die Seite einmal zu bearbeiten – nicht jedes Schild, jeden Aufkleber und jeden Flyer im Laden neu zu drucken.

Bezahlen braucht dieselbe Sorgfalt und eine zusätzliche Warnung. Ein QR-Code kann auf eine Bezahlseite, eine Aufladeseite oder eine vernetzte Wasch-App verlinken, aber er darf niemals Zahlungszugänge oder Kartendaten enthalten oder Geld bewegen, ohne einen klaren, vertrauenswürdigen Bezahlschritt dazwischen. Die Kundschaft sollte vor jeder Bestätigung immer Unternehmensname, Maschinennummer und Betrag sehen. Teste den kompletten Bezahlweg selbst auf einem echten Handy, bevor der Code auf eine Maschine kommt.

Fundsachen – ohne fremde Wäsche öffentlich auszustellen

Jeder Waschsalon hat ein Fundregal, und das meiste bleibt dort liegen, weil niemand weiß, was mit einer einzelnen Socke, einem Handyladegerät oder einer Jacke im Trockner zu tun ist. Ein Code an der Theke und am Ausgang kann ein einfaches Fundformular öffnen: was verloren wurde, in welcher Maschine es gelegen haben könnte und wie man die Besitzerin oder den Besitzer erreicht. Halt dieses Formular nur fürs Personal zugänglich. Stell keine Fotos oder Beschreibungen von Fundsachen auf eine öffentliche Seite, wo sie sich jede und jeder abholen könnte, und verschlüssel keine persönlichen Daten im Code selbst. Sag auf derselben Seite offen, wie lange Gegenstände aufbewahrt werden und wann sie abgeholt werden können.

Dynamisch oder statisch? Entscheide danach, ob sich das Ziel ändern wird

Das ist die Entscheidung, die am meisten Neudruck spart. Ein statischer Code speichert sein Ziel direkt im gedruckten Muster und lässt sich nach dem Druck nicht ändern; ein dynamischer Code speichert einen kurzen Weiterleitungslink, sodass das Ziel dahinter bearbeitet und Scans gezählt werden können. Stell dir für jedes Schild eine Frage: Wird diese Seite, dieser Preis oder dieses Angebot jemals geändert werden müssen, oder muss ich wissen, wie oft es gescannt wird? Lautet die Antwort auf eines davon ja, nimm einen dynamischen Code. Lautet sie auf beides nein, ist ein statischer Code einfacher und hat nichts hinter sich, was ablaufen könnte.

Druck und Platzierung: gemacht für Hitze, Feuchtigkeit und nasse Hände

Ein Waschsalon ist ein harter Ort für Papier. Dampf, feuchte Hände, Waschmittelspritzer und warme Maschinen lassen ein ungeschütztes Schild schneller wellen, verschmieren und verblassen als jeder trockene Laden. Das heißt nicht, dass du teure Materialien brauchst; es heißt, dass du ein Etikett an der echten Stelle testen solltest, bevor du fünfzig davon druckst.

Fang mit der Größe an. Als Faustregel: Mach einen gedruckten Code mindestens ein Zehntel so breit wie die Entfernung, aus der er gescannt wird, und geh nie unter etwa 2 × 2 cm, selbst bei einem Nah-Etikett. Ein Code, der aus etwa 25 cm Entfernung gelesen wird, sollte also mindestens etwa 2,5 cm breit sein, während ein Plakat, das aus 3 Metern gelesen wird, einen Code von rund 30 cm Breite braucht. Lass einen leeren Rand – die Ruhezone – von 4 Modulen auf jeder Seite, in derselben hellen Farbe wie der Code-Hintergrund, und halt Text, Rahmen und unruhige Muster davon fern. Druck dunkle Module auf hellem Hintergrund und nutz für Druckarbeiten eine Vektordatei wie SVG oder ein PNG mit 300 Pixeln pro Zoll in der Endgröße, damit die Modulkanten scharf bleiben.

Für Haltbarkeit laminiere Maschinenetiketten oder druck sie auf abwischbares Material und wähl, wo möglich, eine matte Oberfläche: Glänzende Oberflächen können Licht direkt in die Kamera reflektieren und das Scannen erschweren, während matte Oberflächen leichter zu scannen sind. Als Faustregel: Halt Codes von den heißesten Flächen fern – zum Beispiel der Oberseite eines ständig laufenden Trockners – und weg von direktem Dampf, Waschmittelspendern und überall dort, wo jeden Tag ein nasser Ärmel darüber reibt. Bring das Etikett dort an, wo die Kundschaft natürlicherweise hinschaut: neben dem Münzschlitz oder dem Startknopf.

Vor einem vollen Drucklauf teste so, wie die Kundschaft den Code wirklich nutzen wird: Druck einen Probeabzug in der echten Größe auf dem echten Material und scann ihn mit mindestens einem iPhone und einem Android-Handy, aus der echten Entfernung, bei der echten Beleuchtung im Laden. Wenn ein Code versagt, prüf Größe, Ruhezone, Kontrast und Spiegelung, bevor du dem Handy die Schuld gibst. Unser Leitfaden zu QR-Code-Druckgrößen behandelt Größen im Detail, und unser Leitfaden zur QR-Code-Fehlerbehebung behandelt die Lösungen, wenn ein Code nicht scannt.

Ein Einführungsplan, der klein anfängt

Beschrifte am ersten Tag nicht den ganzen Laden neu. Fang mit einem Pilotprojekt an: zwei oder drei Maschinen, der Thekencode und das WLAN-Schild. Beobachte eine Woche lang – frag das Personal, wonach die Kundschaft gefragt hat, welche Codes am häufigsten gescannt wurden und welche Etiketten sich lösten, beschlugen oder verwirrten. Korrigier zuerst Wortlaut und Platzierung, denn ein Code, der die richtige Seite öffnet, aber am falschen Ort sitzt, wird trotzdem ignoriert.

Roll dann Maschine für Maschine in Chargen aus, jedes Mal mit derselben Vorlage: Maschinennummer in Großdruck, eine kurze Zeile, die sagt, was der Code tut („Scannen, um W-04 zu bezahlen“, „Scannen, um eine Störung an D-12 zu melden“), und der Code selbst. Führ eine einfache Masterliste – Maschinennummer, Code-Ziel und Druckdatum –, damit du bei einem Maschinentausch oder einer Preisänderung genau weißt, welche Schilder zu prüfen sind. Füg schließlich den Bewertungscode am Ausgang und den Fundcode an der Theke hinzu und prüf nach dem ersten Waschtag-Ansturm jeden Code noch einmal.

Gut zu wissen

Sollte jede Maschine in einem Waschsalon ihren eigenen QR-Code haben?

Ja, als praktische Regel. Ein Code pro Maschine, abgeglichen mit einer groß gedruckten Maschinennummer, verhindert, dass Zahlungen und Störungsmeldungen an die falsche Maschine gehen. Ein einziger Code für den ganzen Laden kann dir nicht sagen, welche Waschmaschine oder welchen Trockner die Kundschaft meint.

Kann ein QR-Code eine Waschmaschine starten?

Nicht allein. Ein QR-Code ist eine Abkürzung zu einer Seite, einem Formular oder einem Bezahlsystem. Er kann eine Maschine nur starten, wenn er auf ein vernetztes Wasch-Bezahlsystem verlinkt, das Scan-to-Start unterstützt. Ansonsten öffnet er eine hilfreiche Seite für diese Maschine, etwa mit Fassungsvermögen, Programmen, Preis und Störungsformular.

Kann ein QR-Code den Live-Programmstatus zeigen?

Nur über eine vernetzte Maschine oder ein Bezahlsystem, das das Programm verfolgt und die Seite aktualisiert. Ein gedruckter Code allein kann nicht wissen, wie viele Minuten noch bleiben, also versprich keinen Live-Status, es sei denn, dein System liefert ihn wirklich.

Sollten Waschsalon-Preiscodes statisch oder dynamisch sein?

Dynamisch. Preise, Aktionen und Leistungen ändern sich, und ein dynamischer Code lässt dich das Ziel hinter dem gedruckten Code bearbeiten, statt jedes Maschinenetikett, jedes Schild und jeden Flyer neu zu drucken.

Was ist der beste QR-Code für Waschsalon-WLAN?

Ein statischer Code. Ein WLAN-Netzname und ein Passwort ändern sich selten, es gibt keine Aktion zu aktualisieren, und du brauchst dafür keine Scan-Statistiken, sodass ein fester Code einfacher ist und nichts hinter sich hat, was ablaufen könnte.

Darf ich eine Gratiswäsche für eine Google-Bewertung anbieten?

Nein. Googles Richtlinie verbietet es, Anreize im Austausch für das Veröffentlichen, Ändern oder Entfernen einer Bewertung anzubieten. Bitte stattdessen um eine ehrliche Bewertung eines echten Besuchs und stell sicher, dass der Code die richtige Filiale öffnet.

Wie groß sollte ein QR-Code an einer Waschmaschine sein?

Als Faustregel mindestens ein Zehntel so breit wie die Scan-Entfernung und nie unter etwa 2 × 2 cm. Ein Maschinencode, der aus Armlänge gescannt wird, sollte mindestens 3 bis 5 cm breit sein, mit einer leeren Ruhezone von 4 Modulen auf jeder Seite.

Wie schütze ich Waschsalon-QR-Codes vor Dampf und nassen Händen?

Laminiere Maschinenetiketten oder druck sie auf abwischbares Material, bevorzug eine matte Oberfläche gegenüber Glanz, halt Codes von direktem Dampf und den heißesten Trocknerflächen fern und teste ein Etikett an seiner echten Stelle, bevor du das volle Set druckst.
