Druck es einmal, weil du es zuerst getestet hast

Die günstigste Zeit, einen kaputten QR-Code zu finden, ist auf einem einzelnen Proof, nicht in einem Lager voller gedruckter Ware. Diese Checkliste führt den Proof durch zwei Handys, echtes Licht, echte Entfernung und echtes Material, bevor der volle Lauf freigegeben wird.

4. November 2026 · 14 Min. Lesezeit

Ein Code, der auf dem Bildschirm einer Designerin scannt, kann auf Papier trotzdem versagen. Bildschirme sind hinterleuchtet, vollkommen flach und werden aus Armlänge betrachtet. Papier ist es nicht. Es spiegelt, wölbt sich, saugt Tinte auf, verblasst in der Sonne, wird bei der Handhabung zerkratzt und wird aus Entfernungen gelesen, in denen die Designerin nie stand. Diese Lücke ist der Grund, warum es Vor-Druck-Tests gibt, und warum sie eine Checkliste sein sollten statt eines Blicks. Ein Blick fängt einen Code, der offensichtlich kaputt ist. Eine Checkliste fängt einen Code, der im Studio funktioniert und am Veranstaltungsort, im Regal oder in der Hand einer Kundin versagt.

Dieser Leitfaden ist für den Moment vor der Freigabe geschrieben: Der Proof ist gedruckt, der volle Lauf hat noch nicht begonnen, und es bleibt noch Zeit, Größe, Kontrast, Material oder Link zu korrigieren, ohne Ware zu verschwenden. Er geht davon aus, dass du Ziel und Code schon gewählt und erzeugt hast. Wenn nicht, fang mit Ziel und Link an, denn kein Maß an Drucktests kann ein privates Video, eine abgelaufene Seite oder eine falsch getippte Adresse beheben. Sobald der Link stimmt, arbeite die Prüfungen unten der Reihe nach durch und gib den Lauf erst frei, wenn jedes Muss-Item einen Haken von einem echten Proof hat, nicht von einer Bildschirmvorschau.

Fang mit der Datei an, nicht mit dem Proof

Bevor du irgendetwas druckst, prüf die Datei, die du der Druckerei übergibst. Nutz für den Druck eine Vektordatei wie SVG oder PDF, wenn du kannst, denn Vektorkanten bleiben in jeder Größe scharf, von der Visitenkarte bis zum Banner. Ein kleines PNG, das auf ein großes Format gezogen wird, weicht die Modulkanten zu Treppen auf, und aufgeweichte Kanten sind eine häufige Ursache für Scan-Fehler bei großen Drucken. Wenn du ein PNG nutzen musst, exportier es mit 300 Pixeln pro Zoll in der endgültigen Druckgröße und mit 600 Pixeln pro Zoll für Codes unter 25 Millimetern, sodass die Module scharf statt unscharf bleiben.

Prüf den Farbmodus und den Kontrast in der endgültigen Datei, nicht nur im Design-Tool. Ein in RGB gestalteter Code kann sich bei der Umwandlung in CMYK für den Druck verschieben, und eine dunkle Markenfarbe, die auf dem Bildschirm stark aussah, kann auf Papier schlammig werden. Ziel auf ein Kontrastverhältnis von mindestens 4:1 zwischen den Code-Modulen und dem Hintergrund, mit dunklen Modulen auf hellem Hintergrund als sicherer Voreinstellung. Schwarz auf Weiß funktioniert immer. Dunkles Marineblau auf Creme kann funktionieren. Helle Module auf dunklem Hintergrund, blasse Farben auf blassem Papier, Verläufe hinter dem Code und unruhige Fotos darunter sind die üblichen Verdächtigen, wenn ein Code stilvoll aussieht, aber langsam scannt. Wenn die Marke einen dunklen Hintergrund verlangt, setz den Code in ein weißes oder hell getöntes Feld und die Markenfarbe überall sonst hin.

Prüf die Daten selbst. Kürzerer Inhalt macht einen einfacheren, nachsichtigeren Code, denn jedes zusätzliche Zeichen kann den Code eine Version höher schieben, Module hinzufügen und jedes einzelne bei derselben Druckgröße verkleinern. Ein kurzer Link oder ein dynamischer Code, der eine kurze Weiterleitung speichert, hält das Muster dünn. Eine lange Adresse mit Tracking-Parametern, eine volle Visitenkarte oder ein Textabsatz bewirken das Gegenteil. Wenn der Code dicht aussieht – ein enges Raster winziger Quadrate –, erwäg, den Link zu kürzen, die Druckgröße zu erhöhen oder beides, bevor du irgendetwas anderes testest. Dichte ist für sich kein Defekt, aber dichte Codes brauchen größere Größen, besseres Licht und neuere Handys, und genau das kann ein gedruckter Code nicht garantieren.

Größe, Ruhezone und Fehlerkorrektur: die drei Zahlen, die zuerst festzulegen sind

Die Größe kommt aus der Entfernung. Eine weit verbreitete Faustregel ist das 10:1-Verhältnis: Der Code sollte mindestens ein Zehntel so breit sein wie die Entfernung, aus der er gescannt wird. Ein Code, der aus 30 Zentimetern Entfernung gescannt wird, sollte mindestens 3 Zentimeter breit sein. Ein Plakat, das aus 1 Meter Entfernung gelesen wird, braucht einen Code von mindestens 10 Zentimetern Breite. Eine Wandgrafik, die aus 3 Metern gelesen wird, braucht etwa 30 Zentimeter. Das sind Minima, keine Ziele, und sie setzen gutes Licht und eine ordentliche Kamera voraus. Schlechtes Licht, glänzendes Material, ein dichter Code oder ein älteres Handy sprechen alle für größer. Geh nie unter etwa 2 × 2 Zentimeter für Nahbereichsdruck, selbst auf einer Visitenkarte, denn unter dieser Größe wird selbst Nahbereichsscannen auf vielen Handys unzuverlässig.

Die Ruhezone ist Teil des Codes, kein Abstand, den du zurechtschneiden kannst, damit er ins Layout passt. Die QR-Spezifikation verlangt einen leeren Rand von mindestens vier Modulen Breite auf allen vier Seiten, und Scanner nutzen diesen leeren Rand, um zu finden, wo das Muster beginnt und endet. Text, Linien, Logos oder Fotos, die an die Kante gedrückt sind, können die Erkennung verwirren, selbst wenn der Code selbst perfekt ist. Praktisch gesehen: Halt mindestens einen halben Zentimeter um einen kleinen Code herum frei und mehr um einen großen herum, und lass keinen Rahmen, Falz oder Stanzkante in diesen Rand hineinragen. Prüf die Ruhezone auf dem Proof, nicht nur in der Vorlage, denn Beschnitt, Falz und Bindung können den Code näher an eine Kante rücken, als die Designerin beabsichtigt hat.

Fehlerkorrektur ist die Versicherung des Codes. QR-Codes bieten vier Stufen: L stellt etwa 7 Prozent, M etwa 15 Prozent, Q etwa 25 Prozent und H etwa 30 Prozent beschädigter oder verdeckter Daten wieder her. M ist eine sinnvolle Voreinstellung für die meisten gedruckten Materialien. Q passt zu Outdoor- oder angefasstem Material, das zerkratzt werden kann, und H ist die übliche Wahl, wenn ein Logo in der Mitte sitzt, denn das Logo verdeckt bewusst Datenmodule. Höhere Korrektur macht den Code für denselben Inhalt dichter, sodass ein Logo-Code meist etwas größer gedruckt werden muss als ein schlichter Code. Wenn du ein Logo hinzufügst, leg zuerst die Korrektur fest, erzeug den Code und dimensionier und teste dann genau diese Version, nicht eine schlichte Vorschau.

Der Zwei-Handy-Test: Warum ein Handy nicht reicht

Teste mit mindestens zwei verschiedenen Handys und mach eines davon älter. Ein Flaggschiff-Handy mit schneller Kamera und starker Schwachlichtleistung verzeiht einen kleinen, dichten oder kontrastarmen Code, den ein älteres Handy überhaupt nicht lesen kann. Leitfäden zum Drucken von QR-Codes geben wiederholt dieselbe Empfehlung: Teste das endgültige gedruckte Ergebnis mit mehr als einem Handy, eines davon älter, und teste es in echter Größe und auf echtem Material. Dieser Rat existiert, weil das Publikum nicht alle das neueste Gerät trägt und der Code für das schwächste Handy im Publikum funktionieren muss, nicht für das stärkste Handy im Studio.

Nutz die native Kamera auf jedem Handy, nicht nur eine einzelne QR-App, denn die meisten Betrachter scannen mit der Kamera, die sie schon haben. Notier auf jedem Handy drei Dinge: ob der Code überhaupt erkannt wird, wie lang die Erkennung dauert und in welcher Entfernung und welchem Winkel er funktioniert. Ein Code, der aus Armlänge sofort erkannt wird, aber erst nach mehreren Sekunden Suchen, ist kein Bestanden. Er ist eine Warnung, dass Größe, Kontrast oder Dichte grenzwertig sind, und grenzwertige Codes versagen zuerst bei schlechtem Licht, auf gewölbten Oberflächen oder wenn die Hände der Betrachterin zittern. Wenn die beiden Handys uneins sind, vertrau dem schwächeren Ergebnis und behebe den Code, statt sie zu einem Bestanden zu mitteln.

Licht, Entfernung und Winkel: Teste dort, wo er wirklich leben wird

Licht ist die am meisten unterschätzte Variable im Vor-Druck-Test. Ein Proof, der unter hellem Studiolicht geprüft wurde, sagt wenig über einen Code aus, der auf einem sonnigen Fenster, einer dunklen Flurwand, einer glänzenden Speisekarte unter Spots oder einem Außenschild in der Dämmerung leben wird. Teste den Proof im hellsten und dunkelsten Licht, dem er plausibel ausgesetzt wird, und teste ihn mit Spiegelung. Glanzlaminierung, Glas und glänzende Verpackung reflektieren Licht in die Kamera und können einen Scanner selbst dann besiegen, wenn der Code groß und kontrastreich ist. Wenn Spiegelung ein Problem ist, gib eine matte Oberfläche vor, verleg den Code weg von der Lichtquelle, neige den Proof oder setz den Code auf ein mattes Feld statt direkt auf die glänzende Oberfläche.

Entfernung und Winkel zählen genauso viel. Steh dort, wo die Betrachterin stehen wird, nicht dort, wo die Designerin stand. Ein Tischaufsteller wird aus sitzender Position gescannt, etwa 40 bis 60 Zentimeter entfernt. Ein Plakat wird aus Stehentfernung gescannt, oft 1 bis 2 Meter. Ein Schaufensterschild wird vielleicht vom Bürgersteig aus gescannt, schräg, durch Glas. Teste am fernen Ende dieser Spanne, nicht am nahen Ende, und teste in leichtem Winkel, denn Betrachter stehen selten frontal vor einem Schild. Wenn der Code nur funktioniert, wenn du näher trittst oder dich frontal stellst, ist er für seine Platzierung zu klein oder zu kontrastarm, und ihn zu verschieben, zu vergrößern oder eine kurze Anweisung zum Näherkommen hinzuzufügen, ist besser, als zu hoffen, dass Betrachter es schon herausfinden.

Material: Papier, Kunststoff, Metall und Stoff verhalten sich anders

Material verändert die Regeln, und das Proof-Material sollte dem endgültigen Material entsprechen. Papier und Karton funktionieren am besten mit mattem oder ungestrichenem Material. Glänzende Oberflächen verursachen Spiegelung, also vergrößere die Codegröße um 15 bis 20 Prozent, wenn Glanzmaterial erforderlich ist, laut einem Druckleitfaden. Wellpappe mit ihrer unebenen Oberfläche braucht einen größeren Code und höhere Fehlerkorrektur, wobei Stufe Q oder H empfohlen wird. Vinyl und Kunststoff brauchen matte Laminierung und UV-beständige Tinte für den Außeneinsatz, mit Stufe H für Außenbelastung, und einen Plan zum Ersetzen oder Neulaminieren, wenn Sonne und Wetter den Druck abbauen. Metall und Aluminium, bei denen Lasergravur geringeren Kontrast ergibt, brauchen eine Größenzunahme von 30 bis 40 Prozent und Stufe H, getestet auf der echten Oberflächenbeschaffenheit.

Stoff, Holz und strukturierte Oberflächen bringen eigene Probleme mit. Tinte verläuft auf saugfähigem Material und verwischt Modulkanten, während raue Texturen das saubere Raster brechen, das der Scanner erwartet. Druck auf diesen Materialien größer, nutz höhere Fehlerkorrektur und teste ein Muster, das angefasst, gewaschen oder verwittert wurde, wenn der Artikel dieser Behandlung ausgesetzt wird. Das Gleiche gilt für Etiketten, die gefroren, erhitzt oder mit nassen Händen angefasst werden: Teste das behandelte Muster, nicht nur den frischen Druck.

Die Proof-Checkliste, der Reihe nach

Arbeite den Proof in der Reihenfolge unten durch und vermerk für jedes Item Bestanden oder Nicht bestanden, mit den genutzten Handymodellen, Entfernungen und Lichtbedingungen. Eine Checkliste mit Notizen ist nützlich, wenn die Druckerei fragt, was sich geändert hat, wenn eine Kollegin das Item neu druckt oder wenn ein Code im Feld versagt und du wissen musst, was tatsächlich getestet wurde. Behalt einen freigegebenen Proof, signiert und datiert, als Referenz für den vollen Lauf und vergleiche die ersten Bögen von der Presse damit, denn Pressebedingungen können von Proof-Bedingungen abweichen.

Wenn ein Muss-Item versagt, behebe es und teste die ganze Kette erneut, nicht nur das versagte Item. Vergrößern kann Dichte und Ruhezone verändern. Kontrast erhöhen kann die Farbbalance verändern. Material wechseln kann Spiegelung verändern. Eine Korrektur an einer Stelle kann eine andere brechen, sodass der erneute Test die Zwei-Handy-, Licht-, Entfernungs- und Materialprüfungen am neuen Proof wiederholen sollte, selbst wenn sich nur eine Variable geändert hat. Diese Disziplin fühlt sich bei einem einzelnen Proof langsam an und ist dramatisch schneller als ein voller Lauf neu zu drucken.

Wann man stoppen und neu denken sollte, statt nachzujustieren

Manche Proofs sollten nicht nachjustiert, sondern neu gestaltet werden. Wenn der Code winzig sein muss, um ins Layout zu passen, und Vergrößern das Design bricht, ist das Layout falsch für einen QR-Code, nicht der Code für das Layout. Erwäg ein größeres Format, eine andere Platzierung, einen kürzeren Link, der einen dünneren Code erlaubt, oder eine ganz andere Handlungsaufforderung, etwa eine kurze, einprägsame Adresse für eine Visitenkarte. Ein Code, der nur funktioniert, wenn die Betrachterin schon weiß, dass sie näher treten, die Karte neigen und sie vor Spiegelung schützen muss, ist kein funktionierender Code, was auch immer das Proof-Blatt sagt.

Gut zu wissen

Mit wie vielen Handys sollte ich einen gedruckten QR-Code testen?

Mindestens zwei, mit einem älteren Handy darunter, jeweils mit der nativen Kamera. Ein Code, der nur auf einem Flaggschiff-Handy funktioniert, ist nicht bereit für ein allgemeines Publikum.

Was ist die kleinste Größe, in der ich einen QR-Code drucken kann?

Etwa 2 × 2 Zentimeter für Nahbereichsdruck als Untergrenze und mindestens ein Zehntel der Scan-Entfernung für alles, was weiter entfernt gelesen wird. Ein Plakat, das aus 1 Meter Entfernung gelesen wird, braucht mindestens 10 Zentimeter.

Was ist die Ruhezone, und kann ich sie zurechtschneiden, damit sie in ein Layout passt?

Es ist der leere Rand von mindestens vier Modulen Breite auf allen vier Seiten, den die QR-Spezifikation verlangt, damit Scanner die Musterkanten finden. Schneide ihn nicht zurecht und prüf ihn auf dem beschnittenen und gefalteten Proof, nicht nur in der Vorlage.

Sollte ich für den Druck PNG oder SVG nutzen?

SVG- oder PDF-Vektordateien, wenn du kannst, denn ihre Kanten bleiben in jeder Größe scharf. Wenn du PNG nutzt, exportier mit 300 Pixeln pro Zoll in Endgröße und mit 600 für Codes unter 25 Millimetern.

Welche Fehlerkorrekturstufe sollte ich für den Druck wählen?

M als Voreinstellung, Q für Outdoor- oder stark angefasstes Material und H, wenn ein Logo in der Mitte sitzt. Höhere Korrektur macht den Code dichter, also druck einen Logo-Code etwas größer.

Warum scannt mein Code auf dem Bildschirm, aber nicht auf Papier?

Häufige Ursachen sind Spiegelung durch Glanzpapier, Tintenverlauf auf saugfähigem Material, Wölbung, eine für die Betrachtungsentfernung zu kleine Größe oder Kontrastverlust bei der CMYK-Umwandlung. Teste einen Proof auf dem endgültigen Material, bei echtem Licht, aus echter Entfernung.

Was, wenn der Code scannt, aber die falsche Seite öffnet?

Das ist ein Zielfehler, kein Scan-Fehler. Prüf den Link in einer privaten Browsersitzung abgemeldet, bestätig, dass die Seite auf einem Handy lädt, und nutz einen dynamischen Code oder eine Zielseite, wenn sich das Ziel nach dem Druck ändern könnte.

Muss ich nach dem Beheben eines Problems erneut testen?

Ja. Vergrößern, Umfärben oder Materialwechsel können Größe, Kontrast, Dichte und Spiegelung beeinflussen. Wiederhole die Zwei-Handy-, Licht-, Entfernungs- und Materialprüfungen am neuen Proof, bevor du den Lauf freigibst.
