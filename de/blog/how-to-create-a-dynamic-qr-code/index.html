So erstellst du einen dynamischen QR-Code

Ein dynamischer QR-Code lässt dich das Ziel nach dem Druck ändern — und sehen, wie viele Leute gescannt haben. So machst du einen, kostenlos, in etwa einer Minute.

16. Oktober 2026 · 4 Min. Lesezeit

Statische Codes sind super — bis sich das Ziel ändert. Der Flyer ist gedruckt, das Menü ist umgezogen, die Kampagnen-URL war nicht final. Ein dynamischer QR-Code fixt das: Das gedruckte Muster bleibt gleich, aber du kannst jederzeit ändern, wohin es zeigt — aus deinem Dashboard. Dazu kommen Scan-Zahlen, damit du weißt, ob überhaupt jemand scannt.

Bei FreeQrly sind dynamische Codes kostenlos. Meld dich an (E-Mail, Google oder GitHub) und du bekommst 8 davon. Kein Trial, keine Karte, keine Ablaufspielchen. Hier der ganze Ablauf.

  1. Anmelden — kostenlos. Öffne die Anmeldeseite und erstell ein Konto mit E-Mail + Passwort, Google oder GitHub. Statische Codes brauchen das nie; dynamische schon, weil der Code jemandem gehören muss.
  2. Zu Dynamisch wechseln. Im Studio den Schalter von Statisch auf Dynamisch stellen. Alles andere — Typen, Styling, Download — funktioniert genau gleich.
  3. Typ wählen und ausfüllen. Website, WLAN, Kontakt, Event — alle 12 Inhaltstypen funktionieren als dynamische Codes. (Stapel bleibt statisch: ein dynamischer Code pro Durchgang.)
  4. Stylen, wenn du willst. Punkte, Farben, Logo, Rahmen — die Vorschau aktualisiert sich live. Der Stil wird mit dem Code gespeichert, damit Dashboard und Download übereinstimmen.
  5. Generieren. Klick Generieren. Du bekommst einen kurzen Link wie freeqrly.com/q/XXXXXXX — genau den codiert das QR-Muster. Drucken, verschicken, an die Wand kleben.
  6. Später verwalten. Deine Codes leben im Dashboard: bearbeiten, Stats checken oder einen löschen, um einen Platz freizumachen.

Was der QR-Code wirklich enthält

Ein dynamischer Code hält deinen Link nicht direkt. Er hält einen kurzen FreeQrly-Link, und unser Server leitet Scanner zu deinem Ziel weiter. Dieser Mechanismus macht Bearbeiten und Zählen überhaupt erst möglich — und er ist der Grund, warum dynamische Codes ein Konto brauchen und statische nicht. Wenn dir ein Dienst je sagt, seine „kostenlosen" Codes bräuchten ein Konto, ist das genau dieser Mechanismus; der Unterschied hier: Das Konto ist kostenlos und die Codes sterben nicht.

Die Limits, klar gesagt

  • 8 Codes, kostenlos. Das ist die kostenlose Quote. Lösch einen Code und der Platz wird wieder frei.
  • Einer nach dem anderen. Dynamische Codes werden einzeln generiert; Stapelgenerierung bleibt statisch.
  • Bearbeiten ändert das Ziel, nicht das Muster. Der gedruckte Code funktioniert durch jede Bearbeitung weiter — genau darum geht es.

Ist das Erstellen eines dynamischen QR-Codes wirklich kostenlos?

Ja. Kostenlos anmelden, bis zu 8 dynamische Codes erstellen, bearbeiten, Stats sehen. Keine Testphase, keine Karte, kein Abo. Statische Codes bleiben kostenlos und unbegrenzt, ganz ohne Konto.

Brauche ich ein Konto für einen dynamischen QR-Code?

Ja — der Code muss jemandem gehören, damit nur du ihn bearbeiten kannst. E-Mail + Passwort, Google oder GitHub. Statische Codes brauchen nie ein Konto.

Wohin verlinkt ein dynamischer QR-Code?

Ein kurzer FreeQrly-Link (freeqrly.com/q/XXXXXXX), der zu deinem Ziel weiterleitet. Scanner landen auf deiner Seite; die Weiterleitung macht Bearbeiten und Stats erst möglich.
