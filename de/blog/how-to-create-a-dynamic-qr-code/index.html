So erstellst du einen dynamischen QR-Code

Ein dynamischer QR-Code lässt dich das Ziel nach dem Druck ändern — und sehen, wie viele Leute gescannt haben. So machst du einen, kostenlos, in etwa einer Minute.

October 16, 2026 · Last updated: November 3, 2026 · 15 min read

Ja – einen dynamischen QR-Code kannst du kostenlos erstellen, in etwa einer Minute, und sein Ziel auch nach dem Druck noch ändern. Wähl dynamisch, wenn das Ziel noch nicht endgültig feststeht, wenn du Scans zählen willst oder wenn ein gedruckter Code nächsten Monat auf eine neue Seite führen soll. Wähl statisch, wenn sich das Ziel nie ändern wird: Ein fester Link, ein WLAN-Passwort oder eine Visitenkarte brauchen kein Konto und keine Weiterleitung. Diese Anleitung erklärt den Ablauf bei FreeQrly, den Weiterleitungsmechanismus in einfachen Worten und vorab die kostenlosen Limits.

Bei FreeQrly sind dynamische Codes kostenlos. Melde dich mit E-Mail und Passwort, Google oder GitHub an, und du erhältst 20 dynamische Codes auf dem kostenlosen Konto, aktuell während der zeitlich begrenzten Aktion unbegrenzt. Es gibt keine Testphase und keine Karte, die zum Start nötig wäre, und Scans sind unbegrenzt. Du kannst einen Code nach dem Druck bearbeiten, seine Scan-Statistiken sehen, Codes in Stapeln in statischer Form erstellen und die API nutzen.

Dynamisch oder statisch? Entscheide dich vor dem Druck

Diese Entscheidung lässt sich für einen bereits gedruckten Code nicht mehr rückgängig machen. Ein statischer Code trägt das Ziel im Muster selbst, er kann also nie umgeleitet werden. Ein dynamischer Code trägt einen Kurzlink, der zum Ziel weiterleitet, das Ziel lässt sich also später ändern. Ein gedruckter statischer Code mit falschem Link muss neu gedruckt werden; ein gedruckter dynamischer Code braucht nur eine Bearbeitung im Dashboard.

Wenn du noch unsicher bist, gibt statisch vs. dynamisch, ehrlich erklärt weitere Beispiele. Kurz gesagt: Dynamisch kauft dir Flexibilität und Messbarkeit zum Preis der Abhängigkeit von einem Weiterleitungsdienst und einem Konto; statisch kauft dir Unabhängigkeit zum Preis eines Ziels, das beim Druck eingefroren wird.

Wie ein dynamischer Code wirklich funktioniert

Ein dynamischer Code trägt deinen Link nicht direkt. Er trägt einen kurzen FreeQrly-Link in der Form freeqrly.com/q/XXXXXXX, und das Muster codiert genau diesen Kurzlink. Wenn jemand den Code scannt, öffnet das Handy den Kurzlink, der FreeQrly-Server schlägt das Ziel nach, das du aktuell eingestellt hast, und der Scanner wird dorthin weitergeleitet. Der Scanner landet auf deiner Seite; der Kurzlink ist nur die Weiche dazwischen.

Diese Weiche erklärt jede Funktion und jedes Limit:

  • Bearbeiten funktioniert, weil sich das Muster nie ändert. Das Muster trägt nur den Kurzlink. Bearbeiten ändert den Datensatz dahinter, sodass jede gedruckte Kopie beim nächsten Scan das neue Ziel ausliefert.
  • Zählen funktioniert, weil jeder Scan durch die Weiche läuft. Der Server sieht den Scan auf dem Weg zum Ziel und zählt ihn zu den Statistiken dazu. Ein statischer Code berührt nie einen Server, es gibt also nichts zu zählen.
  • Ein Konto ist nötig, weil die Weiche jemandem gehören muss. Nur das erstellende Konto darf ändern, wohin sein Kurzlink zeigt. Ohne Eigentümer könnte jeder den gedruckten Code eines anderen umleiten.
  • Löschen ist endgültig, weil die Weiche entfernt wird. Löschst du einen Code, leitet sein Kurzlink nicht mehr weiter, gedruckte Kopien funktionieren also nicht mehr. Es gibt kein Zurück, und der frei gewordene Platz kann für einen neuen Code genutzt werden.

Scanner sehen davon nichts – sie zeigen drauf, tippen auf die Vorschau und landen auf deiner Seite. Eines können sie allerdings bemerken: eine Weiterleitung, die zuerst Werbung oder eine Seite mit Anbietermarke zeigt. Wenn du also Generatoren vergleichst, scanne einen Beispielcode und schau, was erscheint, bevor dein Ziel lädt.

Schritt für Schritt: Dynamischen QR-Code erstellen

  1. Anmelden – kostenlos. Öffne die Anmeldeseite und lege ein Konto mit E-Mail und Passwort, Google oder GitHub an. Statische Codes brauchen das nie; dynamische schon, weil der Code jemandem gehören muss, der allein ihn bearbeiten darf.
  2. Zu „Dynamisch“ wechseln. Im Studio den Schalter von „Statisch“ auf „Dynamisch“ stellen. Typen, Styling und Download funktionieren genau gleich.
  3. Typ wählen und ausfüllen. Website, WLAN, Kontakt, Event – alle 17 Inhaltstypen funktionieren als dynamische Codes. (Stapel bleibt statisch: ein dynamischer Code pro Erstellung, weil jeder seinen eigenen Kurzlink und Dashboard-Eintrag braucht.)
  4. Stylen, wenn du willst. Punkte, Farben, Logo, Rahmen – die Vorschau aktualisiert sich live, und der Stil wird mit dem Code gespeichert, sodass Dashboard-Vorschaubild und Download übereinstimmen. Kontrast stark halten und die drei großen Suchmuster in den Ecken nie verdecken.
  5. Generieren. Auf „Generieren“ klicken. Du erhältst einen Kurzlink wie freeqrly.com/q/XXXXXXX – genau den codiert das Muster. Benenne die Download-Datei nach dem Ort, an dem der Code leben wird, zum Beispiel cafe-window-menu.png.
  6. Später verwalten. Deine Codes leben im Dashboard: bearbeiten, Stats prüfen oder einen löschen, um einen Platz freizumachen. Den gedruckten Code vor einer vollen Druckauflage mit der Handykamera testen, und nach jeder Bearbeitung erneut.

Den Typ wählen

Der Typ entscheidet, was der Scanner sieht und tut. Ein Website-Code öffnet eine Seite. Ein WLAN-Code bietet an, einem Netzwerk beizutreten. Ein Kontakt-Code bietet an, eine Person zu speichern. Ein Event-Code bietet an, ein Datum zu speichern. Der richtige Typ spart einen Schritt, und das ist meist mehr wert als ein raffinierteres Design. Ein Restaurant sollte einen Website-Code nutzen, der auf seine Menüseite zeigt, keinen Text-Code mit dem Menü darin: Die Seite lässt sich aktualisieren, der Text-Code nicht. Ein Gäste-WLAN-Code sollte ein WLAN-Code sein, weil das Handy direkt aus dem Scan heraus beitreten kann – siehe So teilst du WLAN per QR-Code.

Zeige auf eine Seite, die du selbst kontrollierst, nicht auf eine Datei, die irgendwo liegt, wo du sie nicht kontrollierst: Eine gelöschte Datei hinterlässt einen funktionierenden Code, der ins Nichts zeigt. Und beachte: Langer Text ergibt ein dichteres Muster, das für dieselbe Scandistanz größer gedruckt werden muss; siehe den QR-Code-Druckgrößen-Leitfaden.

Stylen, ohne den Scan zu brechen

Dynamische Codes unterstützen dasselbe Styling wie statische Codes: Punktformen, Farben, ein Logo in der Mitte und einen Rahmen mit Text. Drei Regeln halten einen gestylten Code scanbar. Erstens: Kontrast hoch halten, Hintergrund hell; Scanner lesen dunkle Module vor hellen. Zweitens: Logo dezent und mittig halten und nie ein Suchmuster verdecken. Die Fehlerkorrektur stellt Module wieder her, die hinter einem kleinen zentralen Logo versteckt sind – auf der Stufe „Hoch“ nach ISO/IEC 18004 können etwa 30 % der Codewörter wiederhergestellt werden –, aber dieses Budget deckt alle Schäden zusammen ab, inklusive Druckabnutzung und Schmutz, nicht das Logo allein. Drittens: die Ruhezone einhalten: Der leere Rand um den Code, mindestens 4 Module breit auf allen vier Seiten nach ISO/IEC 18004, gehört zum Code, nicht zur Deko. Mehr zu Logos steht in So fügst du einem QR-Code ein Logo hinzu.

Für den Druck einen echten gedruckten Proof testen, nicht nur die Bildschirmvorschau: ein Exemplar in der vorgesehenen Größe, auf dem vorgesehenen Material, gescannt auf zwei verschiedenen Handys – wenn möglich einem iPhone und einem Android-Gerät – bei dem Licht, in dem der Code tatsächlich genutzt wird. Glänzende Laminierung bei hellem Licht und ein Code, der sich um eine Flasche wickelt, scheitern auf Arten, die eine Bildschirmvorschau nie zeigt. Wenn der Proof langsam scannt, größer drucken; Größe ist die günstigste Lösung, die es gibt.

Statistiken ehrlich lesen

Jeder dynamische Code meldet an dein Dashboard: Gesamt-Scans, Scans heute, eindeutige Scans und ein Sieben-Tage-Diagramm, mit Aufschlüsselungen nach Land, Stadt, Gerät und Betriebssystem. Die ausführliche Anleitung steht in Was dir Statistiken dynamischer QR-Codes sagen. Drei Gewohnheiten sind am wichtigsten. Vergleiche Codes miteinander, nicht mit einem eingebildeten Benchmark: Ein Schaufenster-Code und ein Code auf einer Lieferbox leben in verschiedenen Welten. Behandle Null als Datum: Ein Code ohne Scans über eine Woche heißt meist, dass die Platzierung falsch ist, der Handlungsaufruf fehlt oder der Code zu klein ist. Und gib einem Ausschlag Kontext: Ein Scan-Schub direkt nach einem Post ist der Post, nicht das Plakat.

FreeQrlys Statistiken sind nur Aggregate – Zählungen nach Tag, Land, Stadt, Gerät und Betriebssystem – ohne Datensatz pro Besucher und ohne Möglichkeit, eine einzelne scannende Person zu identifizieren. Ein eindeutiger Scan wird mit einem Einweg-Hash gezählt, nicht mit einem Namen oder einer Adresse.

Szenarien, in denen sich dynamisch wirklich lohnt

Eine Restaurant-Speisekarte, die sich mit der Saison ändert

Drucke einen Code auf die Tischaufsteller und zeige damit auf die Menüseite. Wenn die Saison wechselt, aktualisiere die Seite oder leite den Code um – die Aufsteller bleiben. Siehe QR-Codes für Restaurants.

Ein Event-Plakat, das gedruckt wird, bevor die Details feststehen

Plakate gehen Wochen vor dem Druck in Druck, bevor Veranstaltungsort, Ticket-Link oder Programm fix sind. Ein dynamischer Code lässt das Plakat zunächst auf eine Warteseite zeigen, dann bei Verkaufsstart auf die Ticketseite wechseln und nach dem Event auf eine Rückblick-Seite. Siehe QR-Codes für Events.

Ein Produkt oder eine Verpackung, das länger lebt als seine erste Kampagne

Verpackungen werden in großen Auflagen gedruckt und über Monate oder Jahre verkauft. Ein dynamischer Code auf der Packung kann mit einem Launch-Angebot starten, dann auf eine Anleitungs- oder Garantiesseite wechseln und später auf ein Nachfolgeprodukt – ohne Neudruck. Führe eine Liste, wo jeder Code lebt: Einen Code, den du im Dashboard nicht findest, kannst du auch nicht reparieren.

Ein Code pro Platzierung, sonst lügen die Zahlen

Gib jeder Platzierung ihren eigenen Code. Ein Code, der über Flyer, Visitenkarte und Marktstand geteilt wird, vermischt deren Statistiken zu einer Zahl, die nichts erklärt. Ein Code an der Kasse, der eine Bewertungsseite öffnet, funktioniert genauso; siehe So bekommst du Google-Bewertungen mit einem QR-Code.

Der ehrliche Vergleich: Was dynamisch anderswo kostet

Dynamische Codes sind nicht überall auf dieselbe Weise kostenlos. Was nach dem Druck wehtut, ist, wie viele kostenlose Codes du bekommst, ob Scans begrenzt sind und was passiert, wenn ein Tarif endet. Die Zahlen unten sind jeweils die eigenen Angaben der Anbieter auf deren Preis- oder FAQ-Seite, geprüft am 3. November 2026. Preise und Limits ändern sich, also prüfe die Anbieterseite, bevor du etwas druckst, das lange halten muss.

Das ist kein Urteil über irgendeinen Anbieter – ein bezahlter Tarif mit mehr Codes, einer eigenen Domain oder Team-Plätzen kann für eine große Kampagne genau richtig sein –, aber es zeigt, warum man den kostenlosen Tarif lesen muss, nicht nur überfliegen. Ein kostenloser Tarif mit Scan-Begrenzung ist ein Code, der an Beliebtheit sterben kann. Ein kostenloser Tarif, der an ein Trial hängt, ist ein Code mit einem Kalender dran. Die faire Frage an jeden Generator, FreeQrly eingeschlossen, lautet: Was genau passiert mit einem gedruckten Code, wenn ich nie zahle, wenn ich aufhöre zu zahlen und wenn ich den Code lösche? Die Antwort sollte jeweils ein Satz sein, auf der Preisseite.

Eine Abhängigkeit verdient eine klare Aussage. Ein dynamischer Code hängt so lange, wie er im Umlauf ist, vom Weiterleitungsdienst des Anbieters ab – hier genauso. Wäre dieser Dienst weg, würden dynamische Codes aufhören weiterzuleiten, während statische Codes, die das Ziel im Muster tragen, weiter funktionieren würden. Darum ist statisch richtig für alles, was jahrzehntelang funktionieren muss, ohne dass sich jemand darum kümmert, etwa ein dauerhaftes Schild. Dynamisch ist für lebendiges Material, um das sich noch jemand kümmert; statisch ist für Material, das für sich selbst sorgen muss.

Fehler, die eine Druckauflage verschwenden

  • Statisch drucken, obwohl der Link noch nicht final war. Wenn sich das Ziel ändern könnte, hätte der Code vor dem Druck dynamisch sein müssen; ein gedruckter statischer Code lässt sich durch Bearbeiten nicht retten.
  • Einen dynamischen Code über Platzierungen teilen. Ein Code, eine Platzierung, ein Statistik-Eintrag – sonst können die Zahlen nicht sagen, welche Platzierung funktioniert hat.
  • Einen Code zum „Aufräumen“ löschen. Löschen ist endgültig und gedruckte Exemplare stoppen sofort. Leite einen auslaufenden Code zuerst auf eine Abschlussseite um und lösche erst, wenn kein gedrucktes Exemplar mehr im Umlauf ist.
  • Den gedruckten Proof auslassen. Eine Bildschirmvorschau beweist das Design; nur ein gedruckter Proof in echter Größe, auf echtem Material und bei echtem Licht beweist den Scan. Siehe Warum dein QR-Code nicht funktioniert.
  • Den Handlungsaufruf vergessen. Ein nackter Code lässt Scanner raten. Ein Rahmen, der sagt, was sie bekommen – Speisekarte, Tickets, WLAN, Rabatt –, macht aus einer Deko eine Tür.

Stapel, API und die Limits, klar gesagt

Dynamische Codes werden einzeln erstellt, weil jeder seinen eigenen Kurzlink und Dashboard-Eintrag braucht. Wenn du viele Codes auf einmal brauchst – einen pro Produkt, pro Tisch, pro Paket –, bleibt die Stapelerstellung statisch; siehe QR-Codes in großen Mengen. Für Programme, die Codes aus einem anderen System heraus erstellen, bietet FreeQrly außerdem eine API für dynamische Codes. Die kostenlosen Limits an einer Stelle:

  • 20 Codes, kostenlos (aktuell während der zeitlich begrenzten Aktion unbegrenzt). Lösch einen Code und der Platz wird wieder frei.
  • Unbegrenzte Scans. Ein beliebter Code stoppt nicht, weil er zu oft gescannt wurde.
  • Einer nach dem anderen. Dynamische Codes werden einzeln generiert; Stapelgenerierung bleibt statisch.
  • Bearbeiten ändert das Ziel, nicht das Muster. Der gedruckte Code funktioniert durch jede Bearbeitung weiter.
  • Löschen ist endgültig. Gedruckte Exemplare funktionieren nicht mehr, ohne Zurück, also nur ausgemusterte Codes löschen.

Gut zu wissen

Ist das Erstellen eines dynamischen QR-Codes wirklich kostenlos?

Ja. Melde dich kostenlos an und erstelle bis zu 20 dynamische Codes, aktuell während der zeitlich begrenzten Aktion unbegrenzt, mit unbegrenzten Scans. Es gibt keine Testphase und keine Karte, die zum Start nötig wäre. Statische Codes bleiben kostenlos und unbegrenzt, ganz ohne Konto.

Brauche ich ein Konto für einen dynamischen QR-Code?

Ja – der Code muss jemandem gehören, damit nur du ihn bearbeiten kannst. Melde dich mit E-Mail und Passwort, Google oder GitHub an. Statische Codes brauchen nie ein Konto.

Wie viele dynamische QR-Codes kann ich haben?

20 auf dem kostenlosen Konto, aktuell während der zeitlich begrenzten Aktion unbegrenzt. Lösch einen Code, um seinen Platz freizugeben – aber Löschen ist endgültig, und gedruckte Exemplare eines gelöschten Codes funktionieren nicht mehr.

Wohin verlinkt ein dynamischer QR-Code?

Ein kurzer FreeQrly-Link (freeqrly.com/q/XXXXXXX), der zu deinem Ziel weiterleitet. Scanner landen auf deiner Seite; die Weiterleitung ist es, die Bearbeiten und Scan-Statistiken erst möglich macht.

Kann ich einen dynamischen QR-Code nach dem Druck bearbeiten?

Ja. Bearbeiten ändert das Ziel hinter dem Kurzlink, nicht das gedruckte Muster, sodass jede gedruckte Kopie beim nächsten Scan das neue Ziel ausliefert. Teste den Code nach jeder Bearbeitung erneut.

Wann sollte ich stattdessen statisch wählen?

Wenn sich das Ziel nie ändern wird – ein fester Link, ein WLAN-Passwort, eine Visitenkarte. Statische Codes tragen das Ziel im Muster selbst, brauchen kein Konto und funktionieren weiter, ohne dass ein Weiterleitungsdienst gepflegt werden muss.

Kann ich dynamische Codes in Stapeln erstellen?

Nein – dynamische Codes werden einzeln erstellt, weil jeder seinen eigenen Kurzlink und Dashboard-Eintrag braucht. Die Stapelerstellung bleibt statisch.

Was passiert mit meinen Scans, wenn ein Code beliebt wird?

Bei FreeQrly nichts Schlimmes: Scans sind unbegrenzt, ein beliebter Code hört also nicht auf zu funktionieren, weil er zu oft gescannt wurde. Bei kostenlosen Tarifen mancher anderer Anbieter kann eine Scan-Begrenzung einen Code stoppen – prüfe die Preis- oder FAQ-Seite des Anbieters, bevor du druckst.
