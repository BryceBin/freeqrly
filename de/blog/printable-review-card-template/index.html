Druckbare Bewertungskarten, die in eine Brieftasche passen

Der beste Moment, um um eine Bewertung zu bitten, ist der Moment, in dem eine Kundin lächelt. Diese Karten in Brieftaschengröße – acht pro A4-Seite – lassen dich die Bitte ohne Rede übergeben: ein Scan, direkt auf deine Bewertungsseite.

4. November 2026 · 4 Min. Lesezeit

Bewertungen laut zu erbitten, ist unangenehm, weshalb die meisten zufriedenen Kundinnen und Kunden nie eine hinterlassen. Eine kleine Karte löst das Timing-Problem: Gib sie mit dem Beleg, der Tüte oder dem Abschied mit, und die Kundin entscheidet später, auf dem eigenen Handy, mit dem Link schon in der Hand.

Jede Karte unten ist 85 × 55 mm – Standard-Visitenkartengröße –, und die Seite legt acht davon in einem Raster an, sodass ein A4-Blatt einen Stapel ergibt, den du an der Kasse bereithältst. So nutzt du sie: Erzeug einen QR-Code, der direkt auf deine Bewertungsseite verlinkt, füg ihn in den gestrichelten Schlitz ein, druck und schneide. Wenn die Bitte speziell bei Google landen soll, behandelt Google-Bewertungen per QR-Code erhalten die Link-Einrichtung. Nutz einen dynamischen Code, wenn sich dein Bewertungslink ändern könnte – dann werden die gedruckten Karten nie alt; sieh dir an, wie man einen QR-Code nach dem Druck bearbeitet. Für ein größeres Einzelkartenformat sieh dir QR-Codes auf Visitenkarten an.

Gut zu wissen

Auf welchem Papier sollte ich Bewertungskarten drucken?

Standard-Karton funktioniert gut – er fühlt sich wie eine echte Visitenkarte an und überlebt eine Tasche oder Brieftasche. Normales Druckerpapier reicht für eine Testcharge, knickt aber schnell in der Hand einer Kundin.

Kann ich diese in Schwarz-Weiß drucken?

Ja. Nichts auf der Karte hängt von Farbe ab; ein dunkler Code auf hellem Hintergrund scannt in Schwarz-Weiß genauso gut. Halt den Code so oder so dunkel auf hell – nie invertieren.

Wie setze ich meinen eigenen QR-Code in den gestrichelten Schlitz ein?

Erzeug den Code, druck ihn in 25 × 25 mm und füg ihn über dem gestrichelten Kasten in deinem Layout-Tool ein – oder druck das Blatt und kleb ein gedrucktes Code-Etikett über jeden Schlitz. Scan eine fertige Karte testweise, bevor du die ganze Seite zerschneidest.

Reichen 25 mm für den Code?

Ja für eine Karte, die in der Hand gehalten und aus 20–30 cm Entfernung gescannt wird – sie liegt über der 2-cm-Untergrenze für Druck. Verkleinere ihn nicht weiter, um mehr Text unterzubringen; ein zu kleiner Code ist der häufigste Druckfehler.

Was, wenn sich mein Bewertungslink ändert, nachdem ich einen Stapel gedruckt habe?

Nutz einen dynamischen QR-Code: Das Ziel hinter dem Code kann aktualisiert werden, während die gedruckten Karten gültig bleiben. Mit einem statischen Code bedeutet ein geänderter Link Neudruck.

Wie viele Karten passen auf eine Seite, und wie schneide ich sie?

Acht Karten pro A4-Seite, in einem 2 × 4-Raster. Schneide entlang der Kartenränder mit einem Schneidegerät für gerade Kanten; die Rasterabstände geben dir etwas Schneidetoleranz.

Sollte ich sie laminieren?

Nur, wenn sie nass werden oder grob angefasst werden. Laminierung verstärkt Spiegelungen unter hellem Licht, also scanne eine laminierte Karte testweise, wenn du laminierst, bevor du den vollen Lauf druckst.
