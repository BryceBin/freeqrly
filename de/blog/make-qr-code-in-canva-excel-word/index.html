QR-Codes in Canva, Excel & Word

Keine dieser Apps hat einen guten eingebauten QR-Maker. Der schnelle Weg: Code in FreeQrly generieren, PNG runterladen, einfügen. Zwei Minuten, jedes Mal.

17. Oktober 2026 · 4 Min. Lesezeit

Canva hat eine QR-App, vergraben in seinem Marketplace. Excel hat keine. Word hat keine. Google Docs und Sheets auch nicht. Jede von ihnen lässt dich aber ein Bild einfügen — und ein QR-Code ist nur ein Bild. Der verlässliche Ablauf ist also überall derselbe: Code in einem echten Generator erstellen, PNG runterladen, einfügen.

Der Ablauf (funktioniert in allen vier)

  1. Code erstellen. Im FreeQrly-Studio den Typ wählen (Website für einen Link, WLAN für ein Netzwerk, vCard für einen Kontakt), ausfüllen, nach Wunsch stylen.
  2. PNG runterladen. Den PNG-Download mit 1024 px oder mehr nutzen. PNG hält die Kanten in Druck und auf dem Bildschirm scharf; SVG ist besser, wenn deine App es akzeptiert (Word und Docs nicht, Canva schon).
  3. Einfügen. Canva: Uploads → Dateien hochladen. Excel: Einfügen → Bilder. Word: Einfügen → Bilder. Google Docs/Sheets: Einfügen → Bild → Von Computer hochladen.
  4. Testen. Handykamera auf den Bildschirm (oder einen Testausdruck) richten. Wenn er beim ersten Versuch scannt, raus damit.

Canva

Canvas eigene QR-App funktioniert, aber sie sperrt den Stil und der Code lebt in Canva. Ein FreeQrly-PNG gibt dir volle Kontrolle — Logo, Farben, Rahmen — und dieselbe Datei funktioniert in deinem Flyer, deinem Instagram-Post und deinem PDF-Export. Einmal hochladen, überall wiederverwenden. Im finalen Design mindestens 2 × 2 cm groß, damit Handys ihn aus Armlänge lesen.

Excel

Excel hat keine QR-Funktion. Die BILD-Funktion (neueres Excel) kann einen QR-Code aus einer URL anzeigen, aber sie braucht das Bild irgendwo gehostet und versagt in älteren Versionen und im Druck. Ein eingefügtes PNG ist der verlässliche Weg: Es druckt, überlebt das Teilen von Dateien und funktioniert in jeder Excel-Version. In einer Zellecke platzieren oder frei über dem Blatt schweben lassen — in beiden Fällen die Ruhezone rundherum freihalten.

Word

Word hat auch kein QR-Tool. Einfügen → Bilder, dann den Textumbruch auf Quadrat oder Eng stellen, damit der Absatz um ihn herum fließt. Für Briefköpfe und Rechnungen den Code an einer festen Stelle fixieren (Kopfzeile, Fußzeile oder Textfeld), damit er auf jeder Seite an derselben Stelle landet. Für den Druck das Dokument als PDF exportieren — der Code bleibt scharf.

Google Docs & Sheets

Gleiches Muster: Einfügen → Bild → Von Computer hochladen. In Docs „Textumbruch" nutzen, damit der Code neben dem Absatz sitzt. In Sheets über einem Eck-Zellbereich schweben lassen. Ein Extra-Tipp: Docs komprimiert große Bilder beim Export, also von einem 1024-px-PNG ausgehen und den Code in vernünftiger Größe halten — ein winziger Code auf einer großen Seite ist der häufigste Grund für fehlgeschlagene Scans.

Drei Fehler, die Scans kaputtmachen

  • Zu klein. Unter 2 × 2 cm im Druck oder unter ~150 px auf dem Bildschirm haben Handys Probleme. Im Zweifel größer machen.
  • Niedriger Kontrast. Schicke Farben sehen toll aus und versagen leise. Immer dunkler Code auf hellem Hintergrund. Die Abstandsregel steht in der Druckgrößen-Anleitung.
  • Verzerren. Das Ziehen an einer Ecke verzerrt das Raster. Proportional skalieren (in den meisten Apps Shift halten), damit die Quadrate quadratisch bleiben.

Gut zu wissen

Hat Canva einen eingebauten QR-Code-Generator?

Canva hat eine QR-App in seinem Marketplace, aber sie sperrt den Stil und behält den Code in Canva. Ein FreeQrly-PNG gibt dir volle Kontrolle und funktioniert überall.

Kann Excel QR-Codes nativ generieren?

Nein. Excel hat keine QR-Funktion. Ein PNG einfügen — es druckt, überlebt das Teilen von Dateien und funktioniert in jeder Version.

PNG oder SVG für Word und Docs?

PNG. Word und Google Docs verarbeiten PNG-Bilder nativ; SVG-Unterstützung ist uneinheitlich. Für den Druck mit 1024 px oder mehr exportieren.

Bleibt der Code scharf, wenn ich als PDF exportiere?

Ja, wenn du von einem 1024-px-PNG ausgehst und ihn nicht winzig schrumpfst. Das exportierte PDF vor dem Versenden test-scannen.
