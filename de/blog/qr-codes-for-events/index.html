QR-Codes für Events, richtig gemacht

Check-in-Schlangen, Ticket-Chaos, „Wo sind die Fotos?“ — ein paar gut platzierte QR-Codes lösen die wiederkehrenden Event-Kopfschmerzen. Hier ist das Playbook.

14. Oktober 2026 · Zuletzt aktualisiert: 3. November 2026 · 15 Min. Lesezeit

Check-in-Schlangen, Ticket-Chaos, „Wo sind die Fotos?“ – ein paar gut platzierte QR-Codes lösen die wiederkehrenden Event-Kopfschmerzen. Der Trick ist nicht der Code selbst; es ist, jeden Code einem Moment in der Reise des Gastes zuzuordnen und für jeden Moment bewusst statisch oder dynamisch zu wählen. Ein Code auf der Einladung macht einen anderen Job als ein Code auf dem Ausgangsschild, und die falsche Art am falschen Ort zu drucken, ist der Weg, wie Events mit einer Wand aus Codes enden, die niemand scannt.

Starte beim Gast, nicht bei der Technik. Ein Gast begegnet deinem Event in grob fünf Momenten: Er hört davon, er sagt zu, er kommt an, er nimmt teil und er geht. Jeder Moment hat eine Frage – wann ist es, bin ich dabei, wohin gehe ich, was passiert, was fand ich –, und jede Frage hat einen Code, der sie mit einem Scan beantwortet.

Das Muster in dieser Tabelle ist die ganze Strategie: Alles, was sich nach dem Druck ändern könnte, wird dynamisch, und alles Feste wird statisch. Ein statischer Code läuft nie ab – richtig für eine Einladung als Andenken, falsch für ein Programm, das am Morgen des Events noch bearbeitet wird.

Vor dem Event: Einladungen, Kalender und RSVP

Die Einladung ist der Ort, an dem die meisten Event-Codes versagen, denn Organisatoren drucken einen Code, der zu einer Homepage führt, und erwarten, dass Gäste das RSVP-Formular selbst finden. Verlinke den Code zum Formular, nicht zur Website. Baue zuerst dein RSVP-Formular – ein einfaches Formular-Tool reicht –, generiere dann den Code, drucke ihn auf die Einladungssuite, und Gäste scannen, tippen und antworten. Keine Briefmarken, keine verlorenen Antwortkarten, kein Entziffern von Handschrift. Nachdem die Antworten eingehen, zählt das Formular sie automatisch, Essenswünsche inklusive; exportiere in ein Blatt, teile es mit dem Caterer, und die Verwaltung ist erledigt.

Kopple den RSVP-Code mit einem Code zum Kalender hinzufügen, dem am meisten unterschätzten Event-Code überhaupt. Ein Scan legt das Event – Titel, Start- und Endzeit, Ort – direkt in den Kalender des Gastes, sowohl auf iPhone als auch auf Android. Drucke ihn auf die Einladung, und ein Schritt weniger steht zwischen Einladung und Kalender, was weniger Nichterscheinen bedeuten kann. Eine Hochzeitseinladungs-Suite ist der klassische Fall: Der RSVP-Code kommt auf die Detailkarte, der Kalender-Code daneben, und der Fotoalbum-Code wartet auf die Tischkarten. Derselbe Einladungstrick funktioniert für Weihnachtsfeiern – siehe den Weihnachts-QR-Code-Generator.

Formuliere den Einladungs-Code so, wie du eine Anweisung an einen Fremden formulieren würdest. Drucke genau daneben, was als Nächstes zu tun ist: „Scanne, um bis zum 1. Juni zuzusagen.“ Ältere Gäste brauchen vielleicht den Anstoß, und die wirklich Scan-Abgeneigten brauchen trotzdem eine Telefonnummer auf der Einladung. Jeder Code sollte neben einer kurzen gedruckten Alternative stehen – einem Link oder einer Telefonnummer –, sodass ein Gast mit leerem Akku, ohne Signal oder ohne Kamera-Handy nicht ausgesperrt ist.

Tickets: Ein Code pro Ticket, und was das wirklich heißt

Bei Events mit Tickets verlinke jedes Ticket mit seiner eigenen Prüfseite statt einen gemeinsamen Code auf jedes Ticket zu drucken. Ein gemeinsamer Code kann ein Ticket nicht vom anderen unterscheiden, er kann also kein Ticket erwischen, das zweimal gescannt wurde – und ein Screenshot eines gemeinsamen Codes ist ein Gratis-Ticket für jeden, der ihn erhält.

Die Stapelerstellung verwandelt eine Liste von Ticket-Links in einem Download in einen Satz Codes. Benenne die Dateien nach Ticket oder Gast und test-scanne eine Stichprobe vor dem Versand. An der Tür braucht das Check-in-Team vor allem eines: eine Ausweichlösung. Handys sterben, Bildschirme springen, und Screenshots kommen zu dunkel an, um sie zu lesen. Halte eine gedruckte Gästeliste am Eingang bereit und schule das Tür-Team, einen Namen zu prüfen, wenn ein Code sich nicht lesen lässt.

An der Tür: Check-in ohne Klemmbrett-Schlange

Platziere einen Code in der Bestätigungs-E-Mail, der zu einem Check-in-Formular verlinkt, oder zu einer einfachen „Ich bin da“-Seite. Gäste scannen an der Tür, statt ihre Namen einem Freiwilligen mit Klemmbrett zu buchstabieren. Für ein kleines Event kann dieses Formular so einfach sein wie ein Namensfeld und ein Absenden-Knopf.

Drei Details lassen Tür-Check-in funktionieren. Erstens: Drucke den Eingangs-Code groß und auf Brusthöhe, wo ein Gast, der ein Handy hält, es natürlicherweise hinrichtet – nicht auf einem Tisch, hinter dem Leute Schlange stehen, und nicht auf einer schwingenden Tür. Zweitens: Gib dem Tür-Team einen zweiten Weg hinein: einen gedruckten Link und die Gästeliste auf Papier. Drittens: Entscheide vor Türöffnung, was passiert, wenn ein Code schon benutzt wurde. Ein Ticket, das zweimal gescannt wurde, ist entweder ein zurückkehrender Gast oder ein Screenshot, der die Runde macht; das Tür-Team braucht eine Regel, keine Debatte vor einer Schlange.

Während des Events: Programm, Sprecher, WLAN und die Fotowand

Programm und Sprecher-Bios

Ein Code auf dem Programm – oder in der Fußzeile jeder Session-Folie –, der zur Live-Programmseite verlinkt, erspart dir, das Programm jedes Mal neu zu drucken, wenn eine Session den Raum wechselt. Das ist der stärkste Fall für dynamische Codes bei einem Event: Das gedruckte Muster bleibt gleich, während sich das Ziel aus deinem Dashboard ändert. Sprecher-Bios funktionieren genauso.

WLAN des Veranstaltungsorts

Teilnehmer werden nach WLAN fragen. Ein WLAN-QR-Code auf Schildern verbindet sie mit einem Scan – kein Buchstabieren von Passwörtern über laute Musik, keine Schlange am Helpdesk. Platziere ihn dort, wo Leute zuerst danach suchen: am Eingang, am Anmeldetresen und auf den Tischen, nicht nur auf einer Folie, die nach dreißig Sekunden verschwindet. Ein ehrlicher Kompromiss: Jeder, der den gedruckten Code fotografiert, kann dem Netzwerk beitreten, behandle einen Veranstaltungs-WLAN-Code also wie einen Gastschlüssel.

Das geteilte Fotoalbum

Jedes Event hat dasselbe Problem: Die Fotos verstreuen sich über fünfzig Handys, und der Organisator verbringt die nächste Woche damit, darum zu betteln. Ein Code, der zu einem geteilten Album auf Tischkarten verlinkt, behebt es – Gäste laden ihre Aufnahmen mit einem Tipp hoch, die ganze Nacht, an einen Ort. Drucke ihn auf die Tischkarten, auf ein Fotowand-Schild und auf die Abschlussfolie, wo Gäste ihn sehen, wenn sie ein Foto machen. Prüfe die Freigabe-Einstellungen des Albums vor dem Event: Jeder mit dem Link kann meist zu einem geteilten Album hinzufügen. Wenn das Album nur für Gäste gedacht ist, halte den Code im Raum statt auf einer öffentlichen Event-Seite.

Nach dem Event: Feedback, solange es noch frisch ist

Ein Code, der zu einem kurzen Feedback-Formular auf der Ausgangsbeschilderung oder der Abschlussfolie verlinkt, erwischt Gäste, solange das Event noch frisch ist, statt mit einer Follow-up-E-Mail Tage später zu konkurrieren, die die meisten Gäste ignorieren werden. Halte das Formular bei zwei Fragen: einer Bewertung und einem offenen Feld für das, was zu ändern ist. Eine Zehn-Fragen-Umfrage am Ausgang wird abgebrochen; ein Zwei-Fragen-Formular wird auf dem Weg zum Auto beantwortet. Die Danke-E-Mail am nächsten Tag kann denselben Code erneut tragen, plus den Fotoalbum-Link, für Gäste, die zu schnell gegangen sind.

Nach dem Event zahlt sich die Statisch-vs.-Dynamisch-Wahl ein zweites Mal aus. Ein dynamischer Code auf einem wiederverwendbaren Schild lässt sich auf das Feedback-Formular des nächsten Events umleiten, das Schild muss also nie neu gedruckt werden. Ein statischer Code auf einem Andenken funktioniert jahrelang als Erinnerung weiter. Entscheide vor dem Druck, welche Art von Nachleben jedes Schild haben soll.

Statisch oder dynamisch: der Vorher-Nachher-Unterschied

Der ehrliche Vergleich ist nicht „dynamisch ist besser“. Die zwei Arten versagen unterschiedlich, und ein Event ist genau der Ort, an dem sich beide Fehlermodi zeigen:

Eine praktische Regel: Nutze dynamische Codes für alles, was das Event-Team am Tag kontrolliert – Programm, Check-in, Feedback –, und statische Codes für alles, was der Gast behält – Einladungen, Kalendereinträge, Fotoalben, die das Event überleben sollen. Wenn jemand ändern müssen könnte, wohin ein Code zeigt, nachdem er gedruckt ist, mach ihn dynamisch.

Drucken und Testen: der unspektakuläre Teil, der alles entscheidet

Event-Codes werden bei chaotischem Licht von eiligen Leuten gescannt. Drucke für diese Realität, nicht für ein Design-Mockup:

  • Größer wählen, als du denkst. Die 1:10-Distanz-Faustregel ist ein guter Ausgangspunkt: Ein Code, der aus einem Meter Entfernung gescannt wird, muss grob zehnmal größer sein als einer, der aus zehn Zentimetern gescannt wird. Bemale jeden nach seiner tatsächlichen Distanz.
  • Kontrast hoch halten und den Rand frei lassen. Dunkle Tinte auf hellem Hintergrund, mit einem klaren ruhigen Rand um den Code. Ein Code, der über ein unruhiges Foto gedruckt wird, oder in Markenfarben mit niedrigem Kontrast, ist der häufigste Grund, warum ein sonst guter Code bei einem Event versagt.
  • Für Schaden drucken. Tickets werden gefaltet, Tischkarten werden bekleckert, Outdoor-Schilder werden verregnet. Der QR-Standard ISO/IEC 18004:2024 definiert vier Fehlerkorrekturstufen – L, M, Q und H –, die 7 %, 15 %, 25 % bzw. 30 % der Codewörter des Symbols wiederherstellen, ein Code mit einer höheren Stufe scannt also weiter, nachdem mehr von ihm beschädigt wurde. Nutze eine höhere Stufe für alles, was Gäste anfassen werden, und halte Logos klein und zentriert, damit sie diesen Spielraum nicht auffressen.
  • Auf iPhone und Android testen, bevor du hundert von irgendetwas druckst. Die eingebaute Kamera moderner Handys liest Codes ohne App – Apples Support-Seite beschreibt das Öffnen der Kamera oder des Kontrollzentrum-Scanners, das Halten des Handys, sodass der Code im Bild erscheint, und das Tippen auf den Link, der erscheint –, aber Kamera-Verhalten variiert zwischen Modellen, und ein Code, der auf einem Handy bei hellem Licht scannt, kann auf einem anderen in einer dunklen Halle versagen. Teste den tatsächlichen Druck, in tatsächlicher Größe, bei Licht wie dem des Veranstaltungsorts.
  • Ein Code pro Schild, mit Beschriftung. Zwei Codes nebeneinander lassen Gäste zögern und Kameras den falschen wählen. Beschrifte jeden Code mit dem, was er tut – „Scanne für WLAN“, „Scanne für Fotos“ –, denn ein nackter Code bei einem Event ist ein Code, an dem Gäste vorbeigehen.

Eine weitere Zahl, die sich vor der Planung rund um Handys zu wissen lohnt: In der Pew-Research-Center-Umfrage 2026 unter Erwachsenen in den USA sagten 91 %, sie besäßen ein Smartphone, gegenüber 35 % in der ersten solchen Umfrage des Centers im Jahr 2011. Das ist eine US-Zahl, aus einer Umfrage unter 5.511 Erwachsenen, durchgeführt vom 30. Januar bis 18. Juni 2026 – keine globale Rate und kein Versprechen über deine spezielle Gästeliste. Ihre praktische Bedeutung ist bescheiden: Für die meisten Publika heißt Planung rund um Handykameras, Planung rund um das Gerät, das fast jeder schon trägt, während man trotzdem eine gedruckte Alternative für den Rest behält.

Was schiefgehen kann – und die Lösung für jedes

  • Ein Code führt zu einer Seite, die umgezogen ist. Lösung: dynamische Codes für alles, was das Team bewegen könnte, und eine letzte Link-Prüfung am Morgen des Events, vom Handy aus, im Netzwerk des Veranstaltungsorts.
  • Gäste können sich nicht verbinden, weil der WLAN-Code auf einer Folie ist. Lösung: WLAN-Codes auf dauerhafter Beschilderung am Eingang und auf den Tischen, nicht nur auf einer Folie.
  • Das Fotoalbum füllt sich mit Uploads von Fremden. Lösung: Den Album-Code im Raum halten, die Freigabe-Einstellungen vor Türöffnung prüfen und den Album-Link nach dem Event ändern, wenn der Link entkommen ist.
  • Ein Ticket-Screenshot macht die Runde. Lösung: ein Code pro Ticket, eine Regel für zweite Scans an der Tür und die Papier-Gästeliste als Reserve.
  • Ältere Gäste oder Gäste ohne Smartphone stranden. Lösung: eine Telefonnummer auf der Einladung, eine Papierliste an der Tür und ein gedrucktes Programm neben dem Code. Der Code ist ein zusätzlicher Weg, nie der einzige.

Checkliste für Event-Codes

  • Check-in: ein Code in der Bestätigungsmail, an der Tür gescannt.
  • Zum Kalender hinzufügen: auf der Einladung, damit die Gäste den Termin behalten.
  • RSVP: auf der Detailkarte, verlinkt zum Formular.
  • Tickets: ein Code pro Ticket, als Stapel generiert, vor dem Versand test-gescannt.
  • Programm und Sprecher: auf dem Programm und in Folienfußzeilen, dynamisch.
  • Fotoalbum: auf Tischkarten, damit alle Aufnahmen in einem gemeinsamen Album landen.
  • WLAN vor Ort: auf Schildern, damit niemand das Passwort bei lauter Musik buchstabieren muss.
  • Feedback: auf Ausgangsbeschilderung und der Abschlussfolie, solange das Event noch frisch ist.

Zusammengesetzt: ein Code pro Gästefrage, dynamisch, wo sich Dinge ändern, statisch, wo Dinge halten sollen, jeder Code beschriftet, getestet und durch eine gedruckte Alternative abgesichert. Gut zu wissen

Wie mache ich einen QR-Code für den Event-Check-in?

Verlinke den Code zu deinem Check-in-Formular oder deiner Anmeldeseite, drucke ihn für den Eingang, und Gäste scannen bei Ankunft, statt an einem Tresen Schlange zu stehen. Halte eine gedruckte Gästeliste neben dem Scanner als Ausweichlösung für Handys, die sterben, oder Bildschirme, die sich nicht lesen lassen.

Kann ein QR-Code ein Event zu meinem Kalender hinzufügen?

Ja – Kalender-Codes (VEVENT) öffnen auf iPhones und Android-Geräten eine „Zum Kalender hinzufügen“-Aufforderung. FreeQrly generiert sie kostenlos mit seinem Event-Typ: Titel, Start- und Endzeit und Ort in einem Scan.

Welche QR-Codes brauche ich für ein Event?

Mindestens: Check-in/Anmeldung, ein geteiltes Fotoalbum und WLAN des Veranstaltungsorts. Codes zum Kalender hinzufügen auf Einladungen sind das hochwertige Extra. Für Konferenzen füge Programm- und Sprecher-Codes hinzu; für Events mit Tickets einen Code pro Ticket.

Sollten Event-Ticket-Codes statisch oder dynamisch sein?

Ein Code pro Ticket, und dynamisch, wenn ein Ticket übertragen oder storniert werden kann oder wenn sich die Prüfseite ändern könnte – ein dynamischer Code lässt sich ohne Neudruck des Tickets umleiten. Ein einfaches, nicht übertragbares Ticket mit einer finalen Prüfseite kann einen statischen Code nutzen. Drucke nie einen gemeinsamen Code auf jedes Ticket: Er kann ein Ticket nicht vom anderen unterscheiden.

Was, wenn der Ticket-Code eines Gastes an der Tür nicht scannt?

Prüfe den Namen anhand der gedruckten Gästeliste, statt den Gast abzuweisen. Handys sterben, Bildschirme springen, und Screenshots kommen zu dunkel an, um sie zu lesen. Entscheide vor Türöffnung, was das Tür-Team tut, wenn ein Code schon benutzt wurde – ein zurückkehrender Gast oder ein Screenshot, der die Runde macht, braucht eine Regel, keine Debatte vor einer Schlange.

Kann ich Event-Beschilderung fürs nächste Event wiederverwenden?

Ja, wenn die Codes darauf dynamisch sind. Ein dynamischer Code auf einem wiederverwendbaren Schild lässt sich auf das Feedback-Formular oder Programm des nächsten Events umleiten, das Schild muss also nie neu gedruckt werden. Statische Codes sind besser für Andenken – Einladungen und gedruckte Programme, die jahrelang weiter funktionieren sollen.

Wie groß sollten Event-QR-Codes gedruckt werden?

Bemale jeden Code nach seiner tatsächlichen Scandistanz, mit der 1:10-Distanz-Faustregel aus dem Druckgrößen-Leitfaden: Ein Code, der aus einem Meter Entfernung gescannt wird, muss grob zehnmal größer sein als einer, der aus zehn Zentimetern gescannt wird. Halte den Kontrast hoch, lass einen klaren ruhigen Rand und teste den tatsächlichen Druck auf iPhone und Android bei Licht wie dem des Veranstaltungsorts, bevor du eine volle Auflage druckst.
