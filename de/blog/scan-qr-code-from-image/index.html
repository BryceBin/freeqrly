QR-Code aus einem Bild scannen

Der Code ist in einem Foto, nicht vor deiner Kamera. So dekodierst du ihn auf iPhone, Android und Desktop — keine App erforderlich.

14. Oktober 2026 · 4 Min. Lesezeit

Auf dem iPhone

Öffne das Foto in der Fotos-App und drück lange auf den QR-Code — iOS erkennt ihn direkt im Bild und bietet an, den Link zu öffnen. Keine extra Tools nötig.

Auf Android

Öffne das Bild in Google Fotos und tippe auf den Lens-Button. Die meisten Galerie-Apps auf Samsung- und Pixel-Handys machen dasselbe aus dem Teilen-Menü.

Auf PC / Mac

Handys helfen hier nicht weiter — hier verdient sich ein Online-Decoder seinen Platz. Mach einen Screenshot (oder speichere das Bild) und lade ihn in FreeQrlys Scanner hoch. Er wird in deinem Browser dekodiert, also wird das Bild nirgends hochgeladen — gut, wenn der Screenshot etwas Privates enthält.

Tipps für störrische Bilder

Vor dem Hochladen eng um den Code zuschneiden — Decoder arbeiten auf einem sauberen Ausschnitt schneller und zuverlässiger. Wenn das Foto verschwommen oder aus einem Winkel aufgenommen ist, kann kein Decoder es retten; nimm es frontal neu auf. Mehr in Warum sich dein QR-Code nicht scannen lässt.

Datenschutz-Hinweis

Screenshots enthalten oft mehr als den QR-Code — Chats, Tickets, persönliche Fotos. Denk zweimal nach, bevor du sie auf eine beliebige Decoder-Seite hochlädst. Ein lokaler Decoder sieht nie etwas außer deinem eigenen Browser-Tab.

Gut zu wissen

Wie scanne ich einen QR-Code aus einem Screenshot auf dem iPhone?

Den Screenshot in Fotos öffnen und lange auf den Code drücken — iOS liest ihn direkt aus dem Bild.

Wie scanne ich einen QR-Code aus einem Bild auf dem PC?

Das Bild in einen kostenlosen Online-QR-Decoder hochladen. Bevorzuge einen, der lokal im Browser dekodiert, damit dein Bild nie hochgeladen wird.

Warum kann der Decoder mein Bild nicht lesen?

Meist Unschärfe, ein steiler Winkel oder der Code ist zu klein im Bild. Eng um den Code zuschneiden und bei gutem Licht nochmal versuchen.
