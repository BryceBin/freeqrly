QR-Code aus einem Bild scannen

Der Code ist in einem Foto, nicht vor deiner Kamera. So dekodierst du ihn auf iPhone, Android und Desktop — keine App erforderlich.

14. Oktober 2026 · Zuletzt aktualisiert: 3. November 2026 · 15 Min. Lesezeit

Die kurze Antwort: Du brauchst kein zweites Handy und musst die Kamera nicht auf den eigenen Bildschirm richten. Ein QR-Code, der als Foto, Screenshot, Nachrichtenanhang oder Bild auf einer Webseite ankommt, lässt sich aus dem Bild selbst lesen. Auf einem iPhone öffne das Bild in Fotos und halte den Code gedrückt. Auf Android öffne es in Google Fotos und tippe auf den Lens-Knopf. Auf einem Computer lade das Bild in einen Decoder hoch, der es in deinem Browser liest, etwa FreeQrlys Scanner. Im Rest dieser Anleitung geht es darum, den richtigen dieser Wege danach zu wählen, wo dein Bild tatsächlich liegt, ein störrisches Bild zu bereinigen, bevor du aufgibst, und private Bilder dabei privat zu halten.

Die Kernunterscheidung ist einfach. Eine Live-Kamera liest ein Muster vor sich. Ein Bildleser liest ein Muster, das schon als Pixel gespeichert ist. Die beiden Aufgaben sehen ähnlich aus, nutzen aber verschiedene Werkzeuge, und nach der Live-Kamera zu greifen, wenn der Code schon eine Datei ist, ist der häufigste Grund, warum Leute schließen, ein Code „lasse sich nicht scannen“, obwohl er es kann. Wenn der Code als Datei in deiner Hand liegt, starte mit einem Bildleser, nicht mit einer Kamera.

Die grundlegenden Schritte, egal auf welchem Gerät

  1. Das Bild in eine Form bringen, die ein Leser öffnen kann. Speichere einen Anhang, mache einen Screenshot eines Codes, der auf dem Bildschirm gezeigt wird, oder lade das Bild von der Seite herunter. Ein Leser braucht eine Datei oder ein geöffnetes Bild, kein Vorschaubild in einer Chat-Liste.
  2. Das Bild im Vollbild öffnen. Leser arbeiten mit dem, was sie sehen können. Ein Code, der in einem Nachrichten-Thread auf Vorschaugröße geschrumpft ist, ist ein viel kleineres Ziel als derselbe Code im Vollbild geöffnet, und ihn im Vollbild zu öffnen, kostet nichts.
  3. Zuerst den eingebauten Bildleser deines Handys nutzen. Auf dem iPhone Fotos; auf Android Google Fotos mit Lens; auf Samsung die Galerie. Diese Leser laufen auf dem Gerät und brauchen keinen Upload, was für den Datenschutzabschnitt unten zählt.
  4. Die Vorschau lesen, bevor du irgendetwas öffnest. Dieselbe Regel wie beim Live-Scannen gilt, mit einem zusätzlichen Grund: Ein Bild, das an dich weitergeleitet wurde, ist durch fremde Hände gegangen, und die Vorschau ist deine Prüfung, ob der Code dorthin führt, wohin der Absender gesagt hat.
  5. Wenn der erste Leser nichts findet, das Bild bereinigen und erneut versuchen – zuschneiden, aufhellen und wiederholen –, bevor du schließt, der Code sei unlesbar. Die Bereinigungsschritte unten retten mehr Bilder als jeder Leserwechsel.

Auf dem iPhone: Fotos, gedrückt halten

Öffne das Foto oder den Screenshot in der Fotos-App und halte den QR-Code selbst gedrückt. Das Handy erkennt den Code im Bild und bietet den Link oder die Aktion an, auf die du nach dem Lesen der Vorschau tippst. Das ist die ganze Methode, und sie deckt die häufigsten Fälle ab: ein Screenshot, den dir ein Freund geschickt hat, ein Foto eines Plakats, das du gestern aufgenommen hast, eine Bordkarte, die in deinen Aufnahmen gespeichert ist, ein Code in einer E-Mail, von dem du einen Screenshot gemacht hast, statt ihn zu speichern. Wenn Gedrückthalten nichts bewirkt, prüfe vor allem anderen zwei Dinge: dass du auf den Code selbst drückst und nicht auf leere Fläche daneben, und dass der Code im Bild vollständig sichtbar ist und nicht an einem Rand abgeschnitten wird. Ein Code, der vom Screenshot-Rand beschnitten wurde, ist das Bild-Äquivalent eines Codes, der vom Kamera-Bildrand beschnitten wurde, und kein Leser kann die fehlende Ecke rekonstruieren.

Wenn der Code überhaupt kein gespeichertes Foto ist – er wird in einer Nachricht, einer E-Mail oder einer Webseite auf demselben Handy gezeigt –, mache zuerst einen Screenshot, öffne dann den Screenshot in Fotos und halte den Code gedrückt. Dieser Zwei-Schritte-Tanz fühlt sich beim ersten Mal unbeholfen an und wird schnell automatisch, und er ist die Antwort auf die Frage, die die meisten Leute verwirrt: Du kannst deine eigene Kamera nicht auf deinen eigenen Bildschirm richten, also nimmst du den Bildschirm auf und liest die Aufnahme stattdessen. Live-Codes vor dir behandeln die Anleitung zum Scannen mit dem Handy und die allgemeine Scan-Anleitung.

Auf Android: Google Fotos und Lens

Öffne das Bild in Google Fotos und tippe auf den Lens-Knopf. Lens analysiert das Bild, findet den Code und zeigt den decodierten Link oder die Aktion, auf die du nach dem Lesen der Vorschau tippst. Lens liest Pixel, keine Quellen, es funktioniert also für ein gespeichertes Foto, einen Screenshot oder ein heruntergeladenes Bild gleichermaßen. Wenn du keinen Lens-Knopf siehst, suche ihn in den Optionen des Bildes oder im Teilen-Menü. Du erreichst Lens auch aus der Google-App, indem du auf ihr Lens-Symbol tippst und das Bild wählst.

Auf einem Samsung Galaxy gibt es einen zusätzlichen eingebauten Weg. Öffne das Bild in der Samsung-Galerie-App und tippe auf den Bixby-Vision-Knopf; das Handy liest das Bild und bietet an, den Link zu öffnen oder zu kopieren. Samsungs Support-Anleitung, aktualisiert im Oktober 2026, beschreibt denselben Weg über den Schnelleinstellungs-Scanner: Schnelleinstellungen öffnen, auf „QR-Code scannen“ tippen, auf das Galerie-Bild-Symbol unten tippen, das Foto wählen und bestätigen. Beide Türen führen zum selben Ergebnis, nutze also die, die du zuerst findest. Wenn dein Handy weder ein Samsung noch ein Handy mit Google Fotos ist, ist die Ausweichlösung dieselbe wie auf einem Computer: Speichere das Bild und lade es in einen Browser-Decoder hoch, was als Nächstes behandelt wird.

Auf einem Computer: In einen Browser-Decoder hochladen

Ein Computer hat keinen eingebauten Bildleser für QR-Codes so wie ein Handy, hier verdient sich ein Browser-Decoder also seine Berechtigung. Speichere das Bild – oder mache einen Screenshot des Codes auf der Webseite, im Dokument oder in der Präsentation – und lade es in einen Decoder hoch. FreeQrlys Scanner decodiert das Bild in deinem Browser, das Bild verlässt also die Seite nie; dieses Detail zählt genau dann am meisten, wenn der Screenshot etwas Privates enthält, was oft der Fall ist, und der Datenschutzabschnitt unten erklärt, warum. Der Decoder gibt den decodierten Rohinhalt zurück, mit einem Link-Knopf für Links und einem Kopieren-Knopf für alles andere. Lies den decodierten Link, bevor du ihn öffnest, genauso wie du die Vorschau eines Handys lesen würdest.

Bilder, die dir andere Leute schicken

Ein Code, der dir in einem Chat, per E-Mail oder in einem Social Post geschickt wird, verdient eine zusätzliche Gewohnheit: Speichere ihn, bevor du ihn scannst. In einer Chat-Blase zu lesen, heißt, eine kleine, möglicherweise komprimierte Version des Bildes zu lesen, in einer App, die vielleicht gar keinen Leser anbietet. Das Speichern des Bildes gibt dir die vollständige Datei, öffnet sie in Fotos oder Google Fotos, wo der Leser lebt, und lässt dich zuschneiden und aufhellen, wenn der erste Versuch fehlschlägt. Es gibt dir auch einen Moment zum Nachdenken: Ein Code, der von einem Absender kommt, den du nicht kennst, mit einer dringenden Geschichte dazu, ist die Bildversion der unerwarteten Nachricht, vor der Sicherheitsanleitungen warnen. Speichere ihn, lies die Vorschau und entscheide erst dann.

Ein störrisches Bild bereinigen

Die meisten unlesbaren Bilder sind keine unlesbaren Codes; sie sind lesbare Codes, die in einem schlechten Bild vergraben sind. Arbeite diese Lösungen der Reihe nach ab und teste nach jeder erneut, denn die erste Lösung, die funktioniert, erspart dir den Rest.

  • Eng um den Code zuschneiden. Schneide das Chat-Fenster, den umgebenden Text, den Tisch und den Hintergrund weg. Behalte die Ruhezone – den leeren Rand um den Code – im Ausschnitt.
  • Gerade richten und glätten. Ein Code, der schräg, auf einer gewölbten Fläche oder in Perspektive fotografiert wurde, ist im Bild verzerrt. Wenn deine Foto-App ein Werkzeug zum Geraderichten anbietet, nutze es behutsam; sonst nimm das Foto gerade von vorn neu auf.
  • Aufhellen, nicht blind schärfen. Helligkeit oder Kontrast anzuheben, kann einen Code retten, der bei schwachem Licht aufgenommen wurde. Starkes Schärfen kann Kanten erfinden, die es nicht gibt – also zuerst aufhellen und nur wenig schärfen.
  • Die Originaldatei versuchen. Wenn du bisher mit einer komprimierten Chat-Kopie gearbeitet hast, geh zurück zum Originalfoto, zum Original-Download oder zu einem frischen Screenshot. Bearbeiten kann Details nicht wiederherstellen, die die Komprimierung entfernt hat.
  • Einen anderen Leser versuchen. Wenn Fotos nichts findet, versuch Lens; wenn Lens nichts findet, versuch einen Browser-Decoder; wenn ein Browser-Decoder nichts findet, versuch das andere Handy im Haus. Ein Code an der Grenze der Lesbarkeit schafft es manchmal bei einem Leser und bei einem anderen nicht. Ein Code, den kein Leser aus der Originaldatei lesen kann, sollte vom Absender ersetzt werden.

Sonderfälle: Video-Standbilder, mehrere Codes und winzige Codes

Ein Code in einem Video ist ein Screenshot-Problem in Verkleidung: Halte bei einem Bild an, auf dem der Code scharf, vollständig sichtbar und nicht in Bewegung ist, mache einen Screenshot dieses Bildes und lies den Screenshot. Mehrere Codes in einem Bild – ein Plakat, eine Seite mit Tickets – sollten einzeln gelesen werden: Schneide auf einen einzigen Code zu, lies ihn und wiederhole, denn ein Leser, dem mehrere Codes gezeigt werden, wählt typischerweise einen aus, und es ist vielleicht nicht der, den du wolltest. Ein winziger Code in einem großen Bild ist vielleicht einfach zu wenig Pixel, um ihn aufzulösen; schneide auf ihn zu, und wenn die Module beim Hineinzoomen immer noch ineinander verschwimmen, enthält das Bild nicht genug Details – bitte um ein näheres Foto, einen Download in höherer Auflösung oder einen frischen Code.

Datenschutz: Was dein Screenshot außer dem Code noch enthält

Screenshots und Fotos enthalten fast immer mehr als den QR-Code. Ein Screenshot eines Chats enthält die Unterhaltung um den Code herum. Ein Foto eines Tickets enthält den Namen, die Buchungsreferenz und den Barcode neben dem Code. Ein Screenshot einer Zahlungsseite enthält Beträge und Kontodetails. Bevor du ein solches Bild in einen Decoder hochlädst, schau, was sonst noch im Bild ist, und schneide es heraus. Zuschneiden ist nicht nur eine Lösung für die Lesbarkeit; es ist eine Lösung für den Datenschutz, und es kostet in beiden Fällen dieselben paar Sekunden.

Die tiefere Frage ist, wohin das Bild geht. Viele Online-Decoder laden dein Bild zum Lesen auf ihren Server hoch, was heißt, dass der Server eines Fremden deinen Screenshot erhält – Chat, Ticket und alles –, nur um einen Code zu lesen. Ein Decoder, der das Bild in deinem Browser liest, wie FreeQrlys Scanner, schickt das Bild nie irgendwohin; das Lesen geschieht auf deinem Gerät, auf der Seite, und das Bild bleibt bei dir. Bevorzuge einen lokalen Decoder für jedes Bild, das du keinem Fremden per E-Mail schicken würdest, und schneide auch dann vor dem Hochladen zu.

Der ehrliche Vergleich: eingebaute Leser, Browser-Decoder und Scanner-Apps

Für einen Code in einem Bild konkurrieren drei Arten von Werkzeugen, und die ehrliche Rangliste hängt vom Bild ab, nicht vom Marketing des Werkzeugs. Eingebaute Leser – Fotos auf dem iPhone, Lens auf Android, Galerie auf Samsung – sind die beste erste Wahl für ein gespeichertes Bild auf dem eigenen Handy: Sie sind schon installiert, laufen auf dem Gerät und brauchen keinen Upload. Browser-Decoder sind die beste Wahl auf einem Computer und die beste Reserve auf einem Handy, wenn der eingebaute Leser versagt, vorausgesetzt, der Decoder liest lokal im Browser, statt dein Bild hochzuladen. Scanner-Apps sind die schwächste Standardwahl für diese Aufgabe: Sie fügen eine Installation, einen Berechtigungsbildschirm und oft Werbung oder ein Konto hinzu, im Tausch gegen eine Fähigkeit, die dein Handy schon hat.

Noch eine ehrliche Anmerkung: Kein Leser rettet einen Code, dessen Details weg sind. Eine stark komprimierte Weiterleitung, ein verschwommenes Videobild, ein Code, der am Rand eines Screenshots abgeschnitten wurde – das sind Probleme fehlender Daten, keine Leserprobleme, und fünfmal den Leser zu wechseln, stellt nicht wieder her, was nie aufgenommen wurde. Die Lösung für fehlende Daten ist ein besseres Original, und den Absender darum zu bitten, ist schneller und ehrlicher, als jeden Decoder im Internet auszuprobieren. Leser sind gut darin, Codes in Bildern zu finden; sie sind nicht gut darin, Codes zu erfinden, die es nicht gibt.

Wenn das Bild liest, aber das Ziel versagt

Manchmal liest sich das Bild perfekt und das Ergebnis enttäuscht trotzdem: ein toter Link, eine umgezogene Seite, ein Formular, das es nicht mehr gibt, ein Ticket, das schon eingelöst wurde. Das ist kein Scan-Fehler; das ist ein Zielfehler, und die Lösung gehört demjenigen, der den Code ausgegeben hat. Ein statischer Code trägt sein Ziel direkt, wenn das Ziel weg ist, hat der Code also nichts zu sagen – und wenn das Ziel umgezogen ist, kann nur der Aussteller den Code woandershin zeigen, und genau dafür ist ein dynamischer Code da: Er bleibt nach dem Druck änderbar, mit Scan-Statistiken, unter einem kostenlosen Konto. Für Codes, die sich gar nicht lesen lassen, siehe Warum dein QR-Code nicht scannt und Warum dein QR-Code unscharf ist. Wenn der Link tot ist, bitte den Absender um einen frischen Code, statt erneut zu scannen.

Mach einen Code, der es wert ist, als Bild verschickt zu werden

Die andere Seite dieser Anleitung verdient einen Absatz, denn die Codes, mit denen Leute beim Lesen aus Bildern kämpfen, sind oft Codes, die von Anfang an schlecht gemacht wurden. Wenn du derjenige bist, der einen Code als Bild verschickt, schicke die Originaldatei, keinen Screenshot von einem Screenshot; halte den Code groß im Bild, mit intakter Ruhezone und dunklen Modulen auf hellem Hintergrund; und teste ihn, indem du ihn selbst aus dem Bild zurückliest, bevor du ihn schickst. Der FreeQrly-Generator deckt 17 Typen ab, und ein dort gemachter statischer Code ist kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Ablauf, ein Test-Code kostet also nichts. Wenn der Code weitergeleitet oder wiederverwendet wird, erwäge stattdessen einen dynamischen Code: Er bleibt änderbar, wenn sich das Ziel ändert, meldet Scan-Statistiken und ist für 20 Codes kostenlos, aktuell während der Aktionsphase unbegrenzt verfügbar, und mit unbegrenzten Scans. Für viele Codes auf einmal erstellt die Stapelerstellung einen Code pro Link. Schicke ein sauberes Original, und die Person am anderen Ende braucht den Bereinigungsabschnitt dieser Anleitung gar nicht.

Gut zu wissen

Wie scanne ich einen QR-Code aus einem Screenshot auf dem iPhone?

Öffne den Screenshot in der Fotos-App und halte den QR-Code selbst gedrückt. Das Handy erkennt den Code im Bild und bietet den Link oder die Aktion an; lies die Vorschau, bevor du darauf tippst.

Wie scanne ich einen QR-Code aus einem Bild auf Android?

Öffne das Bild in Google Fotos und tippe auf den Lens-Knopf. Lens liest den Code im Bild und zeigt den decodierten Link oder die Aktion. Auf einem Samsung Galaxy kannst du das Bild auch in der Galerie öffnen und auf den Bixby-Vision-Knopf tippen.

Wie scanne ich einen QR-Code aus einem Bild auf einem Computer?

Speichere das Bild oder mache einen Screenshot des Codes auf der Seite und lade es in einen Browser-Decoder hoch. Bevorzuge einen Decoder, der das Bild in deinem Browser liest, damit das Bild nie an einen Server geschickt wird – FreeQrlys Scanner funktioniert so.

Jemand hat mir einen QR-Code in einem Chat geschickt. Wie scanne ich ihn?

Speichere das Bild zuerst und öffne dann die gespeicherte Datei in Fotos oder Google Fotos und nutze den eingebauten Bildleser. In einer Chat-Blase zu lesen, heißt, eine kleinere, möglicherweise komprimierte Kopie zu lesen, und die Chat-App bietet vielleicht gar keinen Leser an.

Warum kann der Decoder mein Bild nicht lesen?

Meist ist der Code an einem Rand abgeschnitten, zu klein im Bild, unscharf oder schräg aufgenommen. Schneide eng um den Code zu, während du seine Ruhezone behältst, helle ihn auf, wenn er dunkel ist, versuch die Originaldatei statt einer komprimierten Weiterleitung und versuch einen anderen Leser. Wenn kein Leser die Originaldatei lesen kann, bitte den Absender um einen frischen Code.

Was, wenn ein Bild mehrere QR-Codes enthält?

Schneide auf einen einzigen Code zu und lies ihn, dann wiederhole für den nächsten. Ein Leser, dem mehrere Codes auf einmal gezeigt werden, wählt typischerweise einen aus, und es ist vielleicht nicht der, den du wolltest.

Ist es sicher, einen Screenshot in einen Online-Decoder hochzuladen?

Schneide zuerst alles außer dem Code heraus – Screenshots enthalten oft Chats, Tickets oder Zahlungsdetails neben dem Code. Bevorzuge einen Decoder, der lokal in deinem Browser liest, damit das Bild nie auf einen Server hochgeladen wird.
