QR-Codes online scannen, privat

Viele Online-QR-Scanner bitten dich, dein Bild auf ihren Server hochzuladen. Unserer nicht — der Code wird direkt in deinem Browser dekodiert. Kamera oder Bild-Upload, für immer kostenlos.

2026-10-14 · 4 Min. Lesezeit

Warum „kein Upload“ zählt

QR-Codes enthalten oft sensible Dinge: WLAN-Passwörter, Event-Tickets, Bordkarten, private Links. Dieses Bild auf den Server eines Fremden hochzuladen — nur um es zu lesen — ist ein Privatsphäre-Deal, den die meisten gar nicht bemerken. FreeQrlys QR-Scanner dekodiert das Bild mit JavaScript auf deinem Gerät (die Open-Source-jsQR-Bibliothek). Das Bild verlässt nie die Seite.

Zwei Wege zum Scannen

Kamera: Auf „Kamera starten“ klicken, auf den Code richten, fertig. Nutzt auf Handys deine Rückkamera. Dein Browser fragt einmal um Kamera-Berechtigung — das ist zwischen dir und deinem Browser; wir sehen den Feed nie.

Upload: Hast du einen Screenshot, einen gespeicherten Flyer oder ein Foto mit einem Code drin? Bild hochladen und es wird sofort dekodiert. Das funktioniert sogar offline — Seite einmal laden, trennen, und das Upload-Scannen funktioniert weiterhin.

Was du zurückbekommst

Der rohe dekodierte Inhalt, plus smarte Aktionen: Links bekommen einen „Link öffnen“-Button (erst die URL prüfen — die Scan-Anleitung hat eine 3-Sekunden-Sicherheitsgewohnheit), alles andere bekommt einen Kopieren-Button.

Wenn er deinen Code nicht lesen kann

Verschwommene Fotos, winzige Codes, starke Blendung — die üblichen Verdächtigen. Die vollständige Fix-Liste steht in Warum sich dein QR-Code nicht scannen lässt. Und wenn du stattdessen deinen eigenen QR-Code machen musst, ist das das Haupt-Studio — auch kostenlos, auch privat.

Gut zu wissen

Ist es sicher, QR-Codes online zu scannen?

Es hängt davon ab, wohin das Bild geht. Viele Online-Scanner laden dein Bild auf ihren Server hoch. FreeQrly dekodiert es lokal in deinem Browser, also wird nichts irgendwohin übertragen.

Muss ich eine App herunterladen, um QR-Codes zu scannen?

Nein. Der Scanner läuft in jedem modernen Browser auf Handy oder Desktop — Kameramodus auf dem Handy, Bild-Upload überall.

Kann ich einen QR-Code aus einem Screenshot scannen?

Ja — den Screenshot hochladen und er wird sofort dekodiert, sogar offline, nachdem die Seite geladen ist.
