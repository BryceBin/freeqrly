Black-Friday-Angebote, einen Scan entfernt.

Ein Black-Friday-Käufer tippt keinen Promo-Code, keine lange URL ein und erstellt kein Konto an der Kasse. Er scannt einen Code — oder geht am Angebot vorbei. Ein QR-Code verwandelt jede Fläche in und um deinen Laden in eine Tür zum Sale — Fensterposter, Regaletikett, Flyer, Kassenbon, Social-Media-Post, E-Mail. Der Käufer hält sein Handy drauf, und der Rabatt öffnet sich. Die eine Entscheidung, die am wichtigsten ist, triffst du, bevor du irgendetwas druckst: statisch oder dynamisch? Ein statischer Code passt zu einem festen Coupon. Ein dynamischer Code passt zu allem, was sich ändern könnte — die Sale-Seite, der stündliche Drop, der Artikel, der bis Mittag ausverkauft ist. Triff diese Wahl für jede Platzierung richtig, und der Rest des Wochenendes läuft von allein.

Statische vs. dynamische Codes für eine kurze Aktion

Ein statischer Code hat sein Ziel — einen Link, einen Coupon-Code, einen Text — fest ins Muster eingebacken. Es kann sich nie ändern, braucht kein Konto und keinen Server: FreeQrly erzeugt ihn komplett in deinem Browser, ohne dass etwas hochgeladen wird und ohne Tracking. Ein dynamischer Code hält stattdessen einen kurzen Weiterleitungs-Link. Das gedruckte Muster bleibt gleich, aber du kannst ändern, wohin er zeigt, und sehen, wie oft er gescannt wurde. Dynamische Codes brauchen eine kostenlose Anmeldung zum Erstellen.

Für einen dreitägigen Sale ist dieser Unterschied die ganze Strategie — die meisten Läden brauchen beides, entschieden pro Platzierung, nicht pro Kampagne.

Die Faustregel: Wenn das Angebot als Text auf demselben Poster gedruckt ist („20 % Rabatt, Code BF20“), kann der Code statisch sein — der Coupon-Text ändert sich nie. Wenn der Scan eine Webseite öffnet, deren Inhalt, Preis oder Bestand sich während des Wochenendes ändern könnte, mach ihn dynamisch. Ein dynamischer Code kostet eine kostenlose Anmeldung und eine Minute Einrichtung; ein Neudruck kostet einen Posterlauf, eine Leiter und den Freitagmorgen.

Die Kundenreise: sehen, scannen, Coupon sichern, einlösen

Ein Black-Friday-QR-Code scheitert an genau vier Stellen, eine pro Schritt der Reise. Gestalte für den Schritt, an dem Käufer tatsächlich abspringen.

Abbildung 1: Vom Poster zum Kauf. Vier Schritte mit Pfeilen — Code sehen, scannen, Coupon sichern, einlösen (im Laden an der Kasse oder online an der Kasse). Hinweis darunter: „Jeder Schritt sollte Sekunden dauern. Wenn ein Schritt Tippen, eine Anmeldung oder einen App-Download braucht, springen Käufer ab.“

  • Code sehen. Der Code muss bemerkt werden, bevor er gescannt werden kann. Stell ihn auf Augenhöhe, lass einen ruhigen Rand frei und schreib eine kurze Zeile dazu, was der Scan bringt: „Scannen für 20 % Rabatt“ schlägt „Scann mich“, weil es die einzige Frage des Passanten beantwortet — was bekomme ich?
  • Scannen. Es muss allein mit der Handykamera funktionieren, ohne App — das gilt für jeden Code, den FreeQrly macht. Teste vor dem Drucken auf iPhone und Android, im echten Licht, aus der echten Entfernung.
  • Coupon sichern. Die Seite, die der Scan öffnet, sollte den Rabatt und seine Bedingungen auf dem ersten Bildschirm zeigen — Prozentsatz, Mindestbestellwert, Ablauf — ohne etwas zu tippen und ohne Anmeldung. Jedes zusätzliche Feld kostet Einlösungen.
  • Einlösen. Im Laden zeigt der Kunde das Handy an der Kasse. Online sollte der Rabatt an der Kasse schon angewendet sein, oder der Coupon mit einem Tap zu kopieren sein. Wenn das Einlösen verlangt, dass Personal etwas nachschlagen muss oder ein Kunde sich eine Zeichenfolge merken muss, bricht die Reise am letzten Schritt ab.

Druck- und Platzierungstipps

  • Größe folgt Entfernung. Grobe Regel: Der Code sollte etwa ein Zehntel so breit sein wie die Entfernung, aus der er gescannt wird. Ein Regaletikett, das aus 30 cm Entfernung gescannt wird, kann 3 cm breit sein; ein Fensterposter, das vom Bürgersteig gescannt wird, braucht mindestens 10 cm (4 Zoll). Im Zweifel größer drucken.
  • Kontrast ist nicht verhandelbar. Dunkler Code auf hellem Hintergrund, immer. Ein schwarzer Code auf einem schwarzen Poster, ein goldener Code auf Gelb oder ein Code über einem unruhigen Foto scannt im Ladenlicht nicht zuverlässig. Wenn das Poster dunkel ist, setz den Code auf ein weißes Quadrat.
  • Ruhezone lassen. Lass rund um den Code einen freien Rand, der mindestens so breit ist wie eines seiner kleinen Quadrate — kein Text, keine Logos, kein Rahmen, der ihn berührt.
  • Hohe Fehlerkorrektur für alles, was angefasst wird oder draußen hängt. Stell die Fehlerkorrektur für Kassenbons, Flyer und Verpackungen, die gefaltet, nass oder zerkratzt werden, auf Hoch oder Max. Eine höhere Fehlerkorrektur lässt den Code Schäden überstehen; der Preis dafür ist ein etwas dichteres Muster.
  • Logo vorsichtig in die Mitte setzen. Halt es klein — unter etwa einem Fünftel der Code-Breite — und nutz hohe Fehlerkorrektur, damit der Code trotzdem lesbar bleibt.
  • Eins drucken, scannen, dann den Rest drucken. Druck ein Exemplar von jedem Design, scann es am echten Ort, aus der echten Entfernung, im echten Licht, und druck erst dann die Auflage.
  • Das Angebot in Worten neben den Code schreiben. „Heute nur: Scannen für 20 % Rabatt“ sagt einem Käufer, warum es sich lohnt. Ein nackter Code ist Deko — und wenn ein Handy ihn nicht scannen kann, kann der Käufer das Angebot trotzdem lesen.

Einlösen und Betrug: Einmal-Coupons vs. unbegrenzte Coupons

  • Unbegrenzte Coupons sind der Standard für einen Black-Friday-Doorbuster: ein Code, jeder kann ihn nutzen, kein Tracking, wer eingelöst hat. Einfach, schnell an einer vollen Kasse, und genau richtig, wenn der Rabatt moderat ist und das Ziel Laufkundschaft heißt. Das Risiko ist genau das, wonach es klingt — der Code verbreitet sich. Für ein Angebot von 10–20 % aufs ganze Sortiment ist das meist akzeptabel; das Teilen ist das Marketing.
  • Einmal-Coupons lohnen sich, wenn der Rabatt tief ist — ein hochwertiger Artikel, ein hoher Prozentsatz, ein Gratisgeschenk. Einmal-Nutzung braucht ein System hinter dem Code: einen eigenen Code pro Kunde, eine Liste, die die Kasse prüfen kann, eine Möglichkeit, ihn als benutzt zu markieren. Ein einzelner statischer Code kann das nicht — jeder, der dasselbe Poster scannt, bekommt denselben Code. Wenn du Einmal-Nutzung brauchst, erzeug eigene Codes pro Kunde (der Stapel-Modus schafft bis zu 50 auf einmal) und prüf sie an der Kasse oder an der Online-Kasse.
  • Praktischer Mittelweg. Die meisten kleinen Händler kommen mit unbegrenzten Codes plus drei billigen Kontrollen gut aus: ein klares Ablaufdatum („nur Freitag“), ein Mindestbestellwert und ein Limit pro Einkauf („ein Rabatt pro Einkauf“). Druck sie aufs Poster, zeig sie auf der Zielseite, setz sie an der Kasse durch — kein extra System nötig.
  • Ein Briefing fürs Personal zählt mehr als Software. Sag dem Kassenpersonal schriftlich, was jeder Code tut, welche Bedingungen gelten und was zu tun ist, wenn ein Kunde den Screenshot vom Handy eines anderen zeigt. Ein fünfminütiges Briefing am Freitagmorgen verhindert mehr Betrug — und mehr Streit — als jedes Prüfsystem.
  • Nach dem Sale sichtbar ablaufen lassen. Wenn ein Coupon ein Ablaufdatum hat, halt es ein und schreib es aufs Poster. Nichts beschädigt Vertrauen schneller als ein Code, der am Freitag funktioniert hat und am Samstag still versagt.

Wenn sich das Angebot mitten im Sale ändert

  1. Neu ausrichten, nicht neu drucken. Genau dafür nutzt man dynamische Codes für Sale-Seiten und Doorbuster. Bearbeite das Ziel in deinem Dashboard; der gedruckte Code funktioniert weiter. Ein Neudruck kostet Stunden, die du an einem Freitag nicht hast.
  2. Vorher entscheiden, wohin ein ausverkaufter Code zeigt. Der Standard sollte die Haupt-Sale-Seite oder der nächstliegende Ersatzartikel sein — nie eine tote Seite und nie eine Seite, die den ausverkauften Artikel noch zum alten Preis bewirbt. Schreib den Fallback in der Planungswoche in deine Code-Liste.
  3. Zuerst das Ziel ändern, dann — wenn möglich — den Postertext. Wenn auf dem Poster „50 % Rabatt auf Kopfhörer“ steht und die Kopfhörer weg sind, ist ein kleiner Aufkleber „ausverkauft — sieh dir die Angebote von heute an“ über der Headline ehrlich und dauert eine Minute. Die Neuausrichtung des Codes erledigt den Rest.
  4. Eine Person für Änderungen zuständig halten. Änderungen von drei Leuten mitten im Sale ergeben drei verschiedene Ziele. Eine Person besitzt das Dashboard für das Wochenende; alle anderen leiten Anfragen über sie. Protokolliere jede Änderung in einer Zeile — Zeit, Code, altes und neues Ziel.

Gut zu wissen

Statisch oder dynamisch — was braucht ein Black-Friday-Sale?

Beides, für verschiedene Jobs. Statisch für den Coupon-Code selbst: Er trägt den Code als Text und läuft nie ab. Dynamisch für alles, was sich ändert — die Sale-Seite, stündliche Drops, Bestand, der ausverkauft. Dynamische Codes sind nach einer Anmeldung kostenlos, und die kostenlose Stufe umfasst 20 davon.

Kann ich ändern, wohin ein gedruckter Code zeigt?

Ja — genau das bedeutet dynamisch hier. Bearbeite das Ziel jederzeit aus deinem Dashboard; der gedruckte Code ändert sich nie. Statische Codes lassen sich nach dem Drucken nicht ändern, weshalb sie nur für feste Coupons passen.

Was passiert nach dem Sale mit meinen Codes?

Nichts läuft ab. Richte dynamische Codes auf deine nächste Kampagne aus, und behalte die Poster für nächstes Jahr — gleiche Codes, neue Angebote. Statische Codes funktionieren weiter, solange die Seite oder der Coupon dahinter noch gültig ist.

Wie groß sollte ein Fensterposter-Code sein?

Groß genug, um durch Glas vom Gehweg aus zu scannen — 10 cm oder mehr. Die Regel ist etwa ein Zehntel der Scan-Entfernung, also teste vom Gehweg aus, nicht von innen im Laden.

Kann ich für jedes Produkt im Sale einen anderen Code erstellen?

Ja — nutze den Stapel-Modus im Generator: ein Link pro Zeile, oder lade eine CSV/XLSX-Datei hoch, bis zu 50 Codes pro Stapel, heruntergeladen als ZIP mit PNGs. Stapel ist nur statisch, also nutze ihn für feste Produktseiten und Coupons pro Produkt.

Brauchen Kunden eine App, um den Code zu scannen?

Nein. Jeder Code öffnet sich mit der eingebauten Kamera des Handys. Wenn ein Code eine App zu brauchen scheint, wurde er falsch erstellt — teste vor dem Drucken mit einer normalen Kamera.

Wie verhindere ich, dass ein Coupon überall in Social Media geteilt wird?

Du kannst nicht verhindern, dass ein statischer Coupon per Screenshot geteilt wird. Wenn der Rabatt hoch ist, nutze Einmal-Codes, die an der Kasse validiert werden, statt eines geteilten Codes. Für die meisten ladenweiten Angebote reichen ein Ablaufdatum, ein Mindestbestellwert und eine Einmal-pro-Transaktion-Grenze — und das Teilen bringt dir Kunden.
