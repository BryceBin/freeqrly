Gut zu wissen

Was sieht der Scanner?

Deine Beschreibung plus Code als Klartext — z. B. „20 % Rabatt“ in einer Zeile und „Code: SAVE20“ in der nächsten. Das Personal tippt wie gewohnt.

Wird der Rabatt automatisch abgezogen?

Nein — das ist ein statischer Code mit Promo-Text, kein Deep-Link in deinen Shop. Kombiniere ihn mit einer Kurz-URL zur Angebotsseite, wenn ein Scan beides soll.

Ein Code pro Coupon oder einer für alle?

Ein Code pro Coupon. Jeder Code ist statisch und kostenlos — erstelle so viele, wie du Aktionen hast.

Läuft er ab?

Der Code selbst läuft nie ab. Wenn die Aktion endet, drucke ihn einfach nicht mehr — Daten kann der Code nicht durchsetzen.
