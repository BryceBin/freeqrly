Welchen TikTok-Link du nimmst

TikTok gibt dir drei Arten von URLs, und gedruckt verhalten sie sich unterschiedlich.

Link-ArtSieht aus wieEin Scan öffnetÜberlebt der Code ein gelöschtes Video?
Profiltiktok.com/@yourhandledein Profil, Folgen-Button obenja
Einzelnes Videotiktok.com/@yourhandle/video/7312…das Video, das gerade läuftnein
Hashtagtiktok.com/tag/yourcampaignjedes Video zum Tagja, zeigt aber auch Beiträge anderer

Für Visitenkarte, Schaufenster oder Packungsbeilage nimmst du den Profil-Link. Er funktioniert weiter, während du postest, und der Folgen-Button liegt einen Tipp von der Zielseite entfernt.

Einen Video-Link nimmst du, wenn der Code genau eine Aufgabe hat: ein Launch-Poster oder ein Aufkleber auf dem Produkt, der auf die Anzeige zeigt. Der Link fixiert eine Video-ID. Löschst du das Video, ist der Code tot.

Hashtag-Links funktionieren, zeigen aber alle Beiträge zum Tag, nicht nur deine. Gut für eine Kampagnenseite, falsch für eine Visitenkarte.

Die Übergabe an die App ist ein Hinweis, keine Garantie. Manche Handys zeigen ein bildschirmfüllendes „In TikTok öffnen?“, andere einen schmalen Balken oben, und einige öffnen die Mobilseite ganz ohne Hinweis. Meistens tippen die Leute durch, manche aber nicht – rechne damit, dass ein Teil der Scans auf der Webversion landet.

Zwei Konsequenzen solltest du einplanen. Ein Scan ist kein Follow: Die Person muss nach dem Landen noch auf Folgen tippen, der Code bringt sie also zur Tür, nicht hindurch. Und die mobile Webversion lädt langsamer als die App – wichtig, wenn der Code auf einer Verpackung klebt, wo die Aufmerksamkeit ohnehin knapp ist.

Ein privates Konto zeigt allen, die scannen, ein reduziertes Profil und einen Anfrage-Button. Kein QR-Code kommt um diese Einstellung herum.

TikToks eigener QR-Code – und wann du ihn besser nimmst

Die App hat einen QR-Code eingebaut: Profil öffnen, Teilen-Symbol antippen, QR-Code wählen. Kostenlos, und er funktioniert – innerhalb von TikTok.

Der Haken ist, wer ihn lesen kann. Dieser Code ist für TikToks eigenen Scanner gedacht. Scannst du ihn mit der iPhone-Kamera oder einer Standard-Android-Kamera, passiert oft gar nichts – oder du wirst erst aufgefordert, TikTok zu installieren. Auf einem Handybildschirm, wo die App schon offen ist, ist das in Ordnung. Auf einem gedruckten Aufkleber, im Schaufenster oder auf einer Speisekarte hält ein Fremder eine Standard-Kamera-App darauf.

Der Code, den du hier erzeugst, ist ein Standard-QR-Code. Jede Kamera liest ihn, und der Link darin verhält sich wie eine eingetippte URL. Das ist der ganze Unterschied – und der Grund, warum es sich lohnt, für den Druck einen eigenen Code zu erzeugen statt den aus der App zu verwenden.

Eines solltest du beachten: Dein Handle ist Teil der URL. Benennst du das Konto um, funktionieren beide Codes nicht mehr. Erzeuge nach einer Umbenennung einen neuen und ersetze alles, was schon gedruckt ist.

Teste den Probedruck mit einem Handy, bevor die Auflage läuft. Ein Code, der am Bildschirm funktioniert, kann auf einer gewölbten Flasche oder einem glänzenden Etikett versagen – und das merkst du erst, wenn die Kartons da sind.

Gut zu wissen

Profil-Link oder ein bestimmtes Video?

Profil-Link für allgemeine Follows. Ein Videolink spielt ein Video ab — praktisch für Kampagnen, Verpackungseinleger und Poster für einen Launch.

How do I copy my TikTok link?

Open the profile or video, tap Share, then Copy link. On desktop, copy the URL from the address bar. Both give the same permanent address.

Öffnet er sich in der TikTok-App?

Auf den meisten Handys ja — beim Antippen des gescannten Links wird die App angeboten, falls installiert, sonst öffnet er sich im Browser.

Kann ich mein Logo oder meine Markenfarben einfügen?

Ja — lad dein Logo hoch und stell deine Markenfarben ein. Halt den Kontrast hoch, damit er bei jedem Licht scannt.

Läuft er ab, wenn ich meinen Benutzernamen ändere?

Der Code codiert die exakte URL, also erstelle bei geändertem Handle einen neuen Code. Der Code selbst läuft nie ab.
