Good to know

How does one code open two stores?

The code opens your iOS link by default; Android users get your Play link. Set both so every scanner lands in the right store.

What if I only have one platform?

Just fill that one. The code opens whichever link you provided.

Can it detect the phone and route automatically?

This is a static code with your links — it opens the iOS link first. For automatic device detection you'd need a smart link service in front; the code still works as the front door.

Does it track installs?

No — static codes are private by design and phone nothing home. Your App Store Connect and Play Console already count installs.
