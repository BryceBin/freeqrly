在 Canva、Excel 和 Word 里用二维码

这些 App 都没有好用的内置二维码生成器。最快的办法：在 FreeQrly 里生成二维码，下载 PNG，放进去。每次只要两分钟。

2026 年 10 月 17 日 · 阅读约 4 分钟

Canva 的应用市场里藏着一个二维码 App。Excel 没有。Word 没有。Google Docs 和 Sheets 也没有。但它们都支持插入图片——而二维码就是一张图片。所以可靠的工作流程在各处都一样：在真正的生成器里做码，下载 PNG，插进去。

工作流程（四个都适用）

  1. 生成二维码。在 FreeQrly 生成器里选类型（链接用网址、网络用 WiFi、联系人用名片），填好，想美化就美化一下。
  2. 下载 PNG。下载 1024 px 或更高的 PNG。PNG 在打印和屏幕上边缘都清晰；如果你的 App 支持 SVG，SVG 更好（Word 和 Docs 不支持，Canva 支持）。
  3. 插进去。Canva：上传 → 上传文件。Excel：插入 → 图片。Word：插入 → 图片。Google Docs/Sheets：插入 → 图片 → 从计算机上传。
  4. 测试一下。拿手机摄像头对着屏幕（或一张测试打印）。一次扫出，就可以发布了。

Canva

Canva 自带的二维码 App 能用，但样式锁死，而且码只能留在 Canva 里。FreeQrly 的 PNG 给你完全的控制——Logo、颜色、边框——同一个文件可以用在传单、Instagram 帖子和 PDF 导出里。上传一次，到处复用。最终设计上至少留 2 × 2 厘米，这样手机一臂远也能读出来。

Excel

Excel 没有二维码功能。IMAGE 函数（新版 Excel）可以从 URL 显示二维码，但需要图片托管在某个地方，而且在旧版本和打印时会出问题。粘贴 PNG 是靠谱的办法：能打印、经得起文件分享，在每个 Excel 版本里都好用。放在单元格角落或浮在表格上方都行——不管哪种，都要把周围的留白区空出来。

Word

Word 也没有二维码工具。插入 → 图片，然后把文字环绕设为四周型或紧密型，让段落绕着它走。信头和发票的话，把码固定在一个位置（页眉、页脚或文本框），这样每页都落在同一个地方。打印的话，把文档导出为 PDF——二维码依然清晰。

Google Docs 和 Sheets

同样的套路：插入 → 图片 → 从计算机上传。在 Docs 里用“文字环绕”，让二维码待在段落旁边。在 Sheets 里，把它浮在角落的单元格区域上。再给一个小提示：Docs 导出时会压缩大图，所以从 1024 px 的 PNG 开始，码保持合理大小——大页面上的小码是扫码失败最常见的原因。

三个会让扫码失败的错误

  • 太小。打印上小于 2 × 2 厘米，或屏幕上小于约 150 px，手机就吃力了。拿不准就印大一点。
  • 对比度太低。花哨的颜色好看，但会悄悄失败。永远是深色码配浅色底。距离规则见打印尺寸指南。
  • 拉伸变形。拖角会把网格拉歪。等比例缩放（大多数 App 里按住 Shift），让方块保持方形。

小提示

Canva 有内置的二维码生成器吗？

Canva 的应用市场里有个二维码 App，但它锁死样式，而且码只能留在 Canva 里。FreeQrly 的 PNG 给你完全的控制，到处都能用。

Excel 能原生生成二维码吗？

不能。Excel 没有二维码功能。粘贴一张 PNG——能打印、经得起文件分享，在每个版本里都好用。

Word 和 Docs 用 PNG 还是 SVG？

PNG。Word 和 Google Docs 原生支持 PNG 图片；SVG 支持不稳定。打印用 1024 px 或更高导出。

导出为 PDF 后二维码还清晰吗？

清晰，只要你从 1024 px 的 PNG 开始、不要缩得太小。发出去之前，先扫一下导出的 PDF 测试。
