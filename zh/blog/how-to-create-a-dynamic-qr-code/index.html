动态还是静态？印之前先定

这个决定对已经印出来的码是不可逆的。静态码把目标装在图案里，所以永远没法改指向。动态码装的是一个跳转到目标的短链接，所以目标以后可以改。印好的静态码链接错了就得重印；印好的动态码只需要在 Dashboard 里改一下。

还拿不准的话，静态 vs 动态，实话实说里有更多例子。简而言之：动态是用对跳转服务和账号的依赖，换灵活性和可测量性；静态是用印出来就定死的目标，换独立性。

动态码实际上是怎么工作的

动态码并不直接装你的链接。它装的是一个 FreeQrly 短链接，形式是 freeqrly.com/q/XXXXXXX，图案编码的就是这个短链接。有人扫码时，手机打开短链接，FreeQrly 的服务器查到你当前设置的目标，再把扫码者跳转过去。扫码者最终落在你的页面上；短链接只是中间的交汇点。

这个交汇点解释了所有功能和限制：

  • 能编辑，是因为图案永远不变。图案里只有短链接。编辑改的是它背后的记录，所以每一张印好的码下次被扫时都会服务新目标。
  • 能计数，是因为每次扫码都要经过交汇点。服务器在去往目标的路上看到这次扫码，就把它计入统计。静态码永远不碰服务器，所以没什么可计的。
  • 需要账号，是因为交汇点必须属于某个人。只有创建账号才能改它短链接的指向。没有归属，任何人都能改别人印好的码的指向。
  • 删除是永久的，是因为交汇点被拆掉了。删掉一个码，它的短链接就不再跳转，印好的码也就停工了。没有撤销，腾出来的位置可以给新码用。

扫码者看不到这些——他们对准、点预览、落在你的页面上。有一件事他们能注意到：跳转之前先出现广告或者厂商品牌页面，所以比较生成器时，先扫一个示例码，看看目标加载之前出现了什么。

一步一步：创建动态二维码

  1. 登录——免费。打开登录页，用邮箱加密码、Google 或 GitHub 创建账号。静态码永远不需要这一步；动态码需要，因为码必须属于一个能独自编辑它的人。
  2. 切换到动态。在工作室里，把开关从静态拨到动态。类型、样式、下载的用法完全一样。
  3. 选类型，填内容。网址、WiFi、联系人、活动——17 种内容类型都能做动态码。（批量还是静态的：一次生成一个动态码，因为每个都需要自己的短链接和 Dashboard 记录。）
  4. 想做样式就做。圆点、颜色、Logo、边框——预览实时更新，样式跟码一起保存，所以 Dashboard 缩略图和下载文件是一致的。对比度保持够强，三个大的角定位方块永远别盖住。
  5. 生成。点“生成”。你会得到一个短链接，比如 freeqrly.com/q/XXXXXXX——二维码图案编码的就是它。按码将要待的地方给下载文件起个名字，比如 cafe-window-menu.png。
  6. 之后管理。你的码都在Dashboard 里：编辑、看统计，或者删一个腾个位置。批量印刷之前先用手机相机测一下印好的码，任何一次编辑之后再测一次。

选类型

类型决定扫码者看到什么、做什么。网址码打开页面。WiFi 码提示加入网络。联系人码提示保存一个人。活动码提示保存一个日期。合适的类型能省一步，这通常比更花哨的设计更有价值。餐厅应该用指向菜单页的网址码，别用装着菜单的文本码：页面可以更新，文本码不能。访客 WiFi 码就该是 WiFi 码，因为手机可以从扫码本身直接加入——见怎么用二维码分享 WiFi。

指向一个你掌控的页面，别指向一个你掌控不了的地方托管的文件：文件一删，能用的码就指向了空气。还要注意，文字越长图案越密，在同样距离下扫出来需要的印刷尺寸就越大；见二维码打印尺寸指南。

做样式但不破坏扫码

动态码支持跟静态码一样的样式：圆点形状、颜色、中间的 Logo、带文字的边框。三条规则能让带样式的码保持可扫。第一，对比度保持高、背景保持浅；扫码器读的是浅色上的深色模块。第二，Logo 保持适度并居中，永远别盖住定位方块。纠错能把藏在小小中央 Logo 后面的模块补回来——按 ISO/IEC 18004，高级别下大约 30% 的码字可以恢复——但这份预算要覆盖所有损伤的总和，包括印刷磨损和脏污，不只是 Logo 一个。第三，保持静区：码周围的空白边，按 ISO/IEC 18004 的规定四边都至少 4 个模块宽，是码的一部分，不是装饰。关于 Logo 的更多内容见怎么给二维码加 Logo。

印刷要测真实印出来的样张，不只测屏幕预览：按目标尺寸、目标材质印一张，在实际使用的光线下，用两部不同的手机扫——条件允许一部 iPhone、一部安卓。强光下的光面覆膜和包在瓶子上的码，失败方式是屏幕预览永远显示不出来的。如果样张扫起来慢，印大一点；尺寸是最便宜的修法。

老实看统计

每个动态码都会向你的 Dashboard 汇报：总扫码数、今日扫码数、独立扫码数和七日图表，还有按国家、城市、设备和操作系统分的明细。完整指南见动态二维码统计告诉你什么。三条习惯最重要。拿码跟码比，别跟想象中的基准比：橱窗码和快递箱码活在不同的世界里。把零当成数据：一个码一周没有扫码，通常说明位置不对、行动号召缺失，或者码太小。再给高峰一个背景：帖子发出去之后立刻出现的一波扫码，是帖子的功劳，不是海报的。

FreeQrly 的统计只有聚合数据——按日、国家、城市、设备和操作系统计的数——没有针对单个访客的记录，也没法认出任何一个扫码者。独立扫码是用单向哈希计的，不是名字或地址。

动态码值回票价的场景

随季节变的餐厅菜单

桌卡上印一个码，指向菜单页。季节一换，更新页面或者给码改指向——桌卡不用动。见餐厅二维码。

细节还没定就先印的活动海报

海报要在场地、票务链接或日程定下来几周前就送印。动态码能让海报先指着一个占位页发出去，售票开始时移到票务页，活动结束后再移到回顾页。见活动二维码。

比第一波营销活动活得久的产品或包装

包装是批量印的，要卖几个月甚至几年。包装上的动态码可以先指向首发优惠，再移到说明书或保修页，之后再移到后续产品——不用重印。记一张清单，写清每个码都在哪：一个在 Dashboard 里找不到的码，就是一个你修不了的码。

一个位置一个码，否则数字会撒谎

每个位置给它自己的码。一个码同时用在传单、名片和集市摊位上，会把它们的统计合并成一个什么都说明不了的数字。收银台边打开评价页的码也是同一个道理；见怎么用二维码获得 Google 评价。

浪费一次印刷的错误

  • 链接还没定就印了静态码。目标可能变的话，码在印刷之前就该是动态的；印好的静态码靠编辑是救不回来的。
  • 一个动态码用在多个位置。一个码、一个位置、一条统计记录——否则数字说不清是哪个位置起了作用。
  • 为了“整理一下”删码。删除是永久的，印好的码立刻停工。先把要退役的码改指向一个收尾页，等没有印好的码还在流通时再删。
  • 跳过印刷样张。屏幕预览证明的是设计；只有按真实尺寸、真实材质、真实光线印出来的样张才能证明扫码。见二维码为什么扫不出来。
  • 忘了行动号召。光秃秃的码是让扫码者猜。边框上写清他们能得到什么——菜单、票、WiFi、折扣——才能把装饰品变成入口。
