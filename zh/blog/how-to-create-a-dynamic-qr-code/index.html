怎么创建动态二维码

动态二维码打印后还能改目标地址，还能看到多少人扫过。下面讲怎么免费做一个，大约一分钟。

2026 年 10 月 16 日 · 阅读约 4 分钟

静态码很好——直到目标地址变了。传单印好了，菜单搬了，活动链接还没定稿。动态二维码就是解决这个的：印出来的图案不变，但你可以随时在 Dashboard 里改它指向哪里。还能看扫码数，知道到底有没有人扫。

在 FreeQrly，动态码免费。登录（邮箱、Google 或 GitHub）就送 8 个。没有试用期，不用绑卡，不玩过期套路。下面是完整流程。

  1. 登录——免费。打开登录页，用邮箱 + 密码、Google 或 GitHub 创建账号。静态码永远不用这一步；动态码需要，因为码必须属于某个人。
  2. 切换到动态。在工作室里，把开关从静态拨到动态。其他一切——类型、样式、下载——用法完全一样。
  3. 选类型，填内容。网址、WiFi、联系人、活动——12 种内容类型都能做动态码。（批量还是静态的：一次生成一个动态码。）
  4. 想做样式就做。圆点、颜色、Logo、边框——预览实时更新。样式跟码一起保存，Dashboard 里看到的和下载下来的是一样的。
  5. 生成。点“生成”。你会得到一个短链接，比如 freeqrly.com/q/XXXXXXX——二维码图案编码的就是它。打印出来，发出去，贴墙上。
  6. 之后管理。你的码都在Dashboard 里：编辑、看统计，或者删一个腾个位置。

二维码里到底装了什么

动态码并不直接装你的链接。它装的是一个 FreeQrly 短链接，服务器把扫码的人重定向到你的目标地址。正是这个机制让编辑和计数成为可能——也是动态码需要账号、静态码不需要的原因。如果哪家服务告诉你它的“免费”码需要账号，就是这个机制在起作用；这里的不同是，账号免费，码也不会死。

限制，明明白白说清楚

  • 免费 8 个码。这就是免费额度。删一个码，位置就腾出来了。
  • 一次一个。动态码一个一个生成；批量生成还是静态的。
  • 编辑改的是目标地址，不是图案。印出来的码每次编辑后都照常能用——这就是它的意义所在。

不确定到底需不需要动态码？静态还是动态，老实讲清楚。已经印出来了、需要改链接？印出来之后怎么改二维码。好奇数据长什么样？动态二维码统计能告诉你什么。
