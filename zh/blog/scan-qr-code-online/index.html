很多在线二维码扫码器要你把图片上传到它们的服务器。我们的不用——二维码直接在你的浏览器里解码。摄像头或图片上传，永久免费。

为什么“不上传”重要

二维码里常常有敏感东西：WiFi 密码、活动门票、登机牌、私密链接。把那张图片上传到陌生人的服务器——只是为了读它——是大多数人没意识到自己在做的隐私交易。FreeQrly 的二维码扫码器用你设备上的 JavaScript 解码图片（开源 jsQR 库）。图片永远不会离开这个页面。

两种扫法

摄像头：点“打开摄像头”，对准二维码，搞定。手机上用后置摄像头。浏览器会申请一次摄像头权限——那是你和浏览器之间的事；我们永远看不到画面。

上传：有截图、保存的传单或带二维码的照片？上传图片，立刻解码。这甚至离线也能用——打开一次页面，断网，上传扫码照样能用。

你会得到什么

原始解码内容，加上智能操作：链接有“打开链接”按钮（先检查链接——扫码指南里有个 3 秒安全习惯），其他内容有复制按钮。

读不出你的码时

模糊照片、过小的码、严重反光——都是老生常谈的原因。完整修复清单在为什么二维码扫不出来。如果你需要自己做二维码，那是主生成器——同样免费，同样私密。
