FreeQrly 是什么？

FreeQrly 是免费二维码生成器，理念很简单：静态码应该待在你的浏览器里，而不是别人的服务器上。你输入，它画出来——不上传、不追踪、不收费。

静态码：100% 浏览器端生成每个静态码都用 JavaScript 在本地画出来。你的链接、联系方式和 WiFi 密码永远不会离开你的设备。
只有静态码没有试用，没有订阅，没有被停用的码。今天印的，十年后照样能扫。
Free, no sign-up for static codesLogo upload, batch generation, 2048 px PNG and SVG export — all free, no watermark. Static codes need no account.
10 种语言英语、中文、西班牙语、印地语、阿拉伯语（RTL）、葡萄牙语、法语、俄语、德语、日语。
打印友好高分辨率导出和矢量 SVG，留足静区——为名片、菜单和海报而做。
智能体友好免费的 API 和 MCP 服务器，AI 助手也能生成二维码。
