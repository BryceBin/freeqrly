HTTP API

GET https://freeqrly.com/api/qr?data=TEXT&size=1024&margin=4&color=2F4A62&bgcolor=ffffff&ecc=M

返回 image/svg+xml。只有 data 是必填的；其他都有合理的默认值。错误以 JSON 返回，带一个 error 字段。

curl "https://freeqrly.com/api/qr?data=https://example.com&size=1024" \
  -o qr.svg

# WiFi QR code for guests
curl "https://freeqrly.com/api/qr?data=WIFI:T:WPA;S:CafeNet;P:s3cret;;" \
  -o wifi.svg

参数

  • data —— 要编码的文本（必填，最多 2000 个字符）。链接、WiFi 字符串、vCard、纯文本。
  • size —— 输出尺寸，单位 px，128–2048（默认 1024）。
  • margin —— 静区，单位模块，0–10（默认 4）。
  • color / bgcolor —— 6 位十六进制，没有 #（默认 2F4A62 / ffffff）。
  • ecc —— 纠错等级 L、M、Q、H（默认 M）。打印或加 Logo 时用 Q/H。

Dynamic codes API (authenticated)

动态码打印后仍可编辑，并可追踪扫码——与你在控制台中管理的是同一批码，额度相同（免费 20 个——当前限时优惠期间所有人不限量）。在控制台的 API Tokens 下创建令牌（仅显示一次），然后将其作为 Bearer 令牌传入：

POST https://freeqrly.com/api/codes
export FQ_TOKEN="fqly_..."  # from your dashboard

# create (same validation + quota as the dashboard UI)
curl -X POST https://freeqrly.com/api/codes \
  -H "Authorization: Bearer $FQ_TOKEN" -H "Content-Type: application/json" \
  -d '{"type":"url","payload":"https://example.com/menu"}'
# → {"code":"aB3x9Qz","shortUrl":"https://freeqrly.com/q/aB3x9Qz"}

# list (with quota) · stats · edit · delete
curl https://freeqrly.com/api/me/codes -H "Authorization: Bearer $FQ_TOKEN"
curl https://freeqrly.com/api/codes/aB3x9Qz/stats -H "Authorization: Bearer $FQ_TOKEN"
curl -X PATCH https://freeqrly.com/api/codes/aB3x9Qz \
  -H "Authorization: Bearer $FQ_TOKEN" -H "Content-Type: application/json" \
  -d '{"type":"url","payload":"https://example.com/new-menu"}'
curl -X DELETE https://freeqrly.com/api/codes/aB3x9Qz \
  -H "Authorization: Bearer $FQ_TOKEN"

Tokens are per-user, revocable anytime from the dashboard, and deleted with your account. A token can never create or revoke other tokens — that requires a login session. Without a token these endpoints return 401; over quota returns 403 quota_exceeded.

MCP

POST https://freeqrly.com/mcp

Standard Streamable HTTP: initialize, then tools/list / tools/call. The generate_qr tool takes data, size, color, bgcolor, ecc and returns a ready-to-download SVG URL — no auth needed.

{
  "jsonrpc": "2.0", "id": 1, "method": "tools/call",
  "params": {
    "name": "generate_qr",
    "arguments": { "data": "https://example.com", "size": 1024 }
  }
}

With an Authorization: Bearer <api_token> header, five more tools appear: dynamic_qr_create, dynamic_qr_list, dynamic_qr_update, dynamic_qr_delete, dynamic_qr_stats — your editable dynamic codes, same quota as the dashboard.

curl -X POST https://freeqrly.com/mcp \
  -H "Authorization: Bearer $FQ_TOKEN" -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call",
       "params":{"name":"dynamic_qr_create",
                 "arguments":{"type":"url","payload":"https://example.com/menu"}}}'
