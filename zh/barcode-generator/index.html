小提示

该用哪种条形码格式？

Code 128 通用——能装任意文本。EAN-13 用于国际零售商品，UPC-A 用于美国零售，扫描器老旧或条码必须能人工识读时用 Code 39，ITF-14 用于运输箱。

需要校验位吗？

不需要——EAN-13、UPC-A 和 ITF-14 少输一位，校验位会自动算好。Code 128 和 Code 39 不需要校验位。

打印用 PNG 还是 SVG？

SVG 用于包装和专业印刷——可以无限放大而不模糊。PNG 用于办公打印和不支持 SVG 的应用。
