How to create a dynamic QR code

A dynamic QR code lets you change the destination after printing — and see how many people scanned. Here's how to make one, free, in about a minute.

October 16, 2026 · 4 min read

Static codes are great — until the destination changes. The flyer is printed, the menu moved, the campaign URL wasn't final. A dynamic QR code fixes that: the printed pattern stays the same, but you can change where it points, any time, from your Dashboard. You also get scan counts, so you know whether anyone is actually scanning.

On FreeQrly, dynamic codes are free. Sign in (email, Google, or GitHub), and you get 8 of them. No trial, no card, no expiry games. Here's the whole process.

  1. Sign in — free. Open the sign-in page and create an account with email + password, Google, or GitHub. Static codes never need this; dynamic codes do, because the code has to belong to someone.
  2. Switch to Dynamic. In the studio, flip the toggle from Static to Dynamic. Everything else — types, styling, download — works exactly the same.
  3. Pick a type and fill it in. Website, WiFi, contact, event — all 12 content types work as dynamic codes. (Batch stays static: one dynamic code per generation.)
  4. Style it if you want. Dots, colors, logo, frame — the preview updates live. The style is saved with the code, so the Dashboard and the download match.
  5. Generate. Hit Generate. You get a short link like freeqrly.com/q/XXXXXXX — that's what the QR pattern encodes. Print it, ship it, stick it on the wall.
  6. Manage it later. Your codes live in the Dashboard: edit, check stats, or delete one to free a slot.

What the QR code actually contains

A dynamic code does not hold your link directly. It holds a short FreeQrly link, and our server redirects scanners to your destination. That's the mechanism that makes editing and counting possible — and it's why dynamic codes need an account while static ones don't. If a service ever tells you its "free" codes need an account, this is the mechanism at work; the difference here is that the account is free and the codes don't die.

The limits, stated plainly

  • 8 codes, free. That's the free quota. Delete a code and the slot frees up.
  • One at a time. Dynamic codes are generated one by one; batch generation stays static.
  • Editing changes the destination, not the pattern. The printed code keeps working through every edit — which is the entire point.
