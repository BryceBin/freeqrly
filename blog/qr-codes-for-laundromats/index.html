QR Codes for Laundromats: What to Put on Every Machine, Wall, and Receipt

a laundromat needs about eight QR codes, each doing one job in one place — pay for a specific machine, report that machine when it breaks, check opening hours, join the Wi-Fi, drop off wash-and-fold, find a lost sock, earn a loyalty reward, and leave a review on the way out. The codes that save the most staff time are the ones tied to a machine number, because "washer 4 ate my quarters" is a problem you can fix, and "a washer ate my quarters" is a conversation.

November 4, 2026 · Last updated: November 19, 2026 · 17 min read

Static codes suit anything that never changes, like Wi-Fi; dynamic codes suit anything that might, like prices — and a dynamic code can be edited after printing.

In a self-service laundromat the customer does the work, staff are often not on the floor, and the visit lasts long enough for small problems to become big frustrations. QR codes fit here because they answer questions at the exact spot where the question happens — but only if each code does one job, says so in plain words, and opens a page that does what the sign promised.

The visit, minute by minute

Plan codes around the customer's visit rather than a list of features. A typical self-service visit has five phases, and each one produces different questions:

The codes that matter most are the ones whose question you hear staff answer three times a day.

What a code cannot do

A printed code is a shortcut to a page, a form, or a payment step. It cannot start a washer by itself, and it cannot tell a customer how many minutes are left unless it links to a connected laundry system that tracks that machine. Some payment systems offer scan-to-start: scan the code, pick a cycle, pay, and the machine starts. If yours does, the machine code is the front door to it; if not, do not promise live status on your signs.

Paying for a machine without the coin-slot panic

Payment is the first place a laundromat visit can go wrong, and the moment when a customer is least patient — they are standing in front of a machine with a full basket, and the payment step is between them and clean laundry. Most laundromats today take some mix of coins, cards, and a laundry app or mobile wallet. The code's job is to remove the fumbling, not to add a new step:

  • Scan to pay for this machine. The code on washer W-04 opens a payment page for W-04 — and says so on the page, in the same large type as the label. The customer sees the machine number, the cycle options, and the amount before confirming anything.
  • Scan for help paying. Coins jam, cards decline, apps ask for updates at the worst moment. A small second code on the machine that opens a short "payment not working?" guide covers the failure without a queue forming behind the customer.

Two rules apply to every payment code. First, never put payment credentials, card details, or a payment instruction inside the code itself — the code should open a trusted checkout step where the customer can see the business name, the machine number, and the amount before confirming. Second, test the whole journey yourself on a real phone before the code goes on a machine.

When a machine takes the money and does nothing

This is the most common refund question in any laundromat, and the code is what makes it answerable. A fault-report code on the machine should open a form that already knows which machine it is — the machine number pre-filled — and asks only three things: what happened, whether the machine is safe to use, and a contact detail if the customer wants a reply about a refund. A report that takes thirty seconds gets sent; a report that demands an account and a password does not.

How big is this load? A code per machine row

Not every machine is the same, and customers know it — they just cannot tell from the outside which washer takes a king-size duvet and which one is for a quick load of gym clothes. A short load-size guide saves both the customer and the machine: overloaded washers wash badly and break sooner. The simplest version is a sign at the end of each row: small washers for everyday loads, large washers for bedding and bulky items, with a code linking to a one-screen guide — capacity in plain words ("about two laundry baskets"), suitable cycles, and the price for each size.

Clear labels matter more than design: put the machine number in large print next to the code — W-04, D-12 — and make sure the page the code opens shows the same number.

The 35-minute wait is a business asset

A wash cycle lasts roughly half an hour, and drying adds more — 30 to 45 minutes in which your customer is sitting in your store, looking at their phone, with nothing to do. That is the most valuable time you have.

A Wi-Fi code lets a customer join the network by scanning, without typing a long password from a faded sign. Put the code where people sit — by the folding tables and the chairs — not only by the door they walk past on the way in. Wi-Fi is the clearest example of a job for a static code: your network name and password rarely change, and if they do, reprinting one or two waiting-area signs is a small job. Put the Wi-Fi on a guest network, separate from your payment system.

A "while you wait" code turns dead time into a small service. One short page can hold the Wi-Fi details for customers who prefer to type the password, nearby cafés and order-ahead links — the coffee shop two doors down, the bakery across the street — with opening hours and how long the walk takes, and an honest note on cycle timing: if your system offers live status, link to it; if it does not, say how long a typical wash and dry take and suggest a phone alarm.

Wash-and-fold: a second business inside the store

Wash-and-fold is a different kind of transaction: a self-service customer pays and leaves, while a wash-and-fold customer hands over their laundry and trusts you with it. Every handover is a chance for something to go missing: bags without names, special instructions nobody wrote down, pickup times nobody remembers. Two codes cover the whole handover:

  • Drop-off. A code at the counter opens a form asking for a name, a contact method, the number of bags, and any instructions — cold wash, no scented detergent, hang-dry the delicates — before the customer leaves. Keep personal details out of the QR code itself: the code opens a form or a login-protected order page; it never encodes a customer name or phone number in the printed pattern.
  • Pickup. The claim ticket or receipt carries a code that opens a page showing pickup hours, what to bring, and how to contact the store if a pickup time needs to change. If your system can show order status, link to that; if not, give the counter phone number instead. The goal is fewer calls asking "is my laundry ready?", not a status page that guesses.

Because wash-and-fold services, hours, and promotions change over time, these codes should be dynamic: one edit updates the destination behind the printed code instead of reprinting every ticket template and counter sign. The same logic applies to the price board.

Lost socks, found phones, and the shelf nobody checks

Every laundromat has a lost-and-found shelf, and most of it stays there because nobody knows what to do about a single sock, a phone charger, or a jacket left in a dryer. A code at the counter and by the exit can open a simple lost-property form: what was lost, which machine it may have been in, and how to contact the owner. Keep that form private to staff — do not post photos or descriptions of found items on a public page, where anyone could claim them — and do not encode personal details in the code itself. On the same page, state plainly how long items are kept and when they can be collected.

Regulars: loyalty that survives a soggy pocket

A laundromat lives on regulars — the same faces every Tuesday night, the same family every Sunday morning. Paper stamp cards work until they go through the wash, which, in a laundromat, is not a rare accident. A QR code can replace the card with a link to your loyalty page, where customers can see the current offer and how to claim it. A simple example is "every tenth wash free" — treat that as an illustration, not a rule. Pick a threshold your margins can carry, write it in plain words on the sign, and keep the same wording on the page the code opens.

Be honest about what the code does here. Scan statistics can tell you how many times a loyalty page was opened; on their own, they do not identify individual customers or count one person's visits. True per-customer loyalty needs a loyalty account or app behind the page, with the QR code as the easiest way to reach it. Loyalty offers rotate, which is why this code should be dynamic.

The exit: reviews at the moment they are earned

The best moment to ask for a review is when the job is done well — clean machines, a folded load, a helpful staff member — not while a customer is still loading a washer. Put a review code on the folding tables, on the receipt, or by the exit, with a short, honest invitation such as "Had a good visit? Tell others about it here." The code should open your Google review page directly, so the customer does not have to search for your business and pick the right branch — Google Business Profile provides a review-request link for this purpose.

Do not offer a discount, a free wash, or any other incentive in exchange for a review. Google's policy prohibits incentives for posting, changing, or removing a review.

Owners with more than one store

A single-store owner can remember which sign is where. An owner with three or five locations cannot — and a multi-location laundromat is where QR codes either save real money or create real confusion.

  • One template, every store. The same machine-label layout, the same wording, the same code sizes. A customer who learns the system at your first store should be able to use the second store without relearning it.
  • One code per machine per store, never shared across stores. Washer W-04 in the Maple Street store and washer W-04 in the Riverside store must open different pages. A fault report for the wrong branch is worse than no report at all. Batch generation — creating many codes at once from a list of links — is the practical way to produce a full set per store.
  • One master list. Machine number, store, code destination, and date printed, in a single sheet. When a machine is replaced or a price changes, the list tells you exactly which signs to check.
  • Review codes per branch. Each store's exit code must open that store's review page. Check it after every reprint, not just the first one.

Static or dynamic? Two questions decide it

For each sign, ask two questions: will this page, price, or offer ever need to change? and do I need to know how often it is scanned? If the answer to either is yes, use a dynamic code. If the answer to both is no, a static code is simpler and has nothing behind it that can lapse.

Printing for a room full of steam, heat, and wet hands

Steam, damp hands, detergent splashes, and warm machines will curl, smudge, and fade an unprotected sign faster than a dry shop ever would — so test one label in the real spot before printing fifty of them.

Size. As a rule of thumb, make a printed code at least one-tenth as wide as the distance it will be scanned from, and never go below about 2 × 2 cm. For machine labels scanned at arm's length, 3–5 cm wide is a practical minimum; counter signs and folding-table tents work at 5–10 cm; a wall poster or price board read from a metre away needs about 10 cm.

The quiet zone. Leave a blank margin of 4 modules on every side, in the same light colour as the code background, and keep text and borders out of it.

Contrast and file format. Print dark modules on a light background, and for print work use a vector file such as SVG, or a PNG at 300 pixels per inch at the final size, so module edges stay sharp.

Durability. Laminate machine labels or print them on a wipe-clean stock, and choose a matte finish where you can: gloss finishes can reflect light straight into the camera and make scanning harder. Keep codes off the hottest surfaces and away from direct steam and detergent dispensers. Put the label where a customer naturally looks: next to the payment slot or start button, with the machine number beside it.

Test like a customer. Before a full print run, print one proof at the real size, on the real material, laminate it as planned, and scan it with at least one iPhone and one Android phone, from the real distance, in the store's real lighting.

Rolling it out: one week, not one day

Do not relabel the whole store on day one. Start with a pilot: two or three machines, the counter code, and the Wi-Fi sign. Watch for a week — ask staff what customers asked about, which codes were scanned most, and which labels peeled, fogged, or confused people. Fix the wording and placement first, because a code that opens the right page but sits in the wrong place will still be ignored. Then roll out machine by machine, in batches, using the same template every time: machine number in large print, one short line saying what the code does, and the code itself. Finally, add the review code by the exit and the lost-and-found code at the counter, and check every code again after the first wash-day rush.

A suggested first-week checklist:

  1. Walk the floor and list every question staff answer repeatedly. Each one is a candidate code.
  2. Label the machines — large numbers first, codes second.
  3. Build the destination pages — short, mobile-friendly, and honest about what they can and cannot do.
  4. Choose static or dynamic for each sign using the two questions above.
  5. Generate the set — batch generation for a full machine row, SVG export for print.
  6. Print a pilot set and test it on two phones, at real distance, in real lighting.
  7. Roll out in batches, keep the master list, and recheck after the first busy weekend.

Done well, the codes disappear into the visit. Customers pay without queuing, report a fault in thirty seconds, join the Wi-Fi without asking, and leave a review on the way out. Good to know

Should every machine in a laundromat have its own QR code?

Yes. A code per machine, matched to a large printed machine number, avoids payments and fault reports going to the wrong machine.

Can a QR code start a washing machine?

Not on its own. A QR code is a shortcut to a page, form, or payment system. It can start a machine only when it links to a connected laundry payment system that supports scan-to-start.

What should I do if a machine takes my money and does not start?

Scan the fault-report code on that machine and send a short report: what happened, and a contact detail if you want a reply about a refund. The form already knows the machine number, so staff can check that exact machine.

Should laundromat price codes be static or dynamic?

Dynamic. Prices, promotions, and services change, and a dynamic code lets you edit the destination behind the printed code instead of reprinting every sign. It also shows scan counts, so you can see which placements customers actually use.

What is the best QR code for laundromat Wi-Fi?

A static code. A Wi-Fi network name and password rarely change, and you do not need scan statistics for it, so a fixed code is simpler and has nothing behind it that can lapse. Put the code where people sit, on a guest network.

Can I offer a free wash for a Google review?

No. Google's policy prohibits offering incentives in exchange for posting, changing, or removing a review. Invite an honest review of a real visit instead, with a code by the exit.

I run three laundromats — can I use the same QR codes in all of them?

No — not the machine codes. Each store's washer W-04 must open that store's page, or fault reports and payments will go to the wrong branch. Use one template and one master list across all stores, and give each store its own review code pointing at its own Google Business Profile listing.
