QR codes for laundromats: less waiting, fewer questions

A laundromat runs on small questions asked at the wrong moment — which machine is this, how do I pay, how long is left, and who do I tell when something breaks. Put a well-labelled QR code where each question happens, and customers can answer it themselves, even when staff are busy elsewhere.

November 4, 2026 · 15 min read

A laundromat is a waiting room with machines in it. Customers arrive with a basket, spend time loading, waiting, folding, and leaving, while staff are often helping someone else or out of the room. A QR code cannot fold a towel, but it can answer the question a customer is already asking: which machine is this, how do I pay for it, how long will it take, and who do I tell when something goes wrong?

Give each job its own code, in the place where the job happens. One big code on the front door that opens your homepage helps nobody standing in front of washer number seven with a wet load and a jammed door.

Start with one code per machine

Label every machine, then match the code to the label. Put the washer or dryer number in large print next to the code — for example, W-04 or D-12 — and make sure the page the code opens shows the same number. That one habit prevents most mix-ups: a customer paying for the wrong machine, reporting the wrong machine, or asking staff to find a load that is not where they think it is.

What the machine code opens depends on how your store is set up. A QR code on its own does not know whether a machine is running, and it cannot start a machine by itself. It is a shortcut to a page, a form, or a payment system. If you use a connected laundry payment system, that system may offer a scan-to-start code for each machine: one vendor, for example, describes its guest flow as scanning the code on the machine, choosing the cycle and add-ons, and paying with a mobile wallet or card, after which the machine starts automatically. Without that kind of system, the machine code can still open a simple page for that machine with its size, cycle options, price, and a link to report a problem.

Use the machine code for cycle help and fault reports

For a store without a connected system, the most practical machine page is a short guide: what this machine holds, which cycles suit delicates, heavy bedding, or a quick refresh, how long a typical cycle takes, and what to do if the door will not open. Keep the wording short. Nobody wants to read an essay while their laundry is spinning.

The same code, or a second clearly labelled code on the machine, can open a fault report form. Pre-fill the machine number where your form tool allows it, and ask only for what staff need to act: what happened, whether the machine is safe to use, and a contact detail only if the customer wants a reply about a refund or a lost item. A report that takes thirty seconds to send will be sent; a report that asks for an account and a password will not. Add a short fallback next to the code — a phone number, or a note saying to tell the counter — for customers whose phone battery has died.

What about live cycle status?

Live status — a page saying a machine has twelve minutes left — is the feature customers ask for most, and it is also the one a printed code alone cannot deliver. A code can only open a page; live timing needs a connected system that tracks the cycle. If your system offers it, the machine code is the natural front door to it. If it does not, do not promise live status on your signs.

Wash-and-fold: one code for drop-off, one for pickup

Wash-and-fold turns a self-service visit into a handover, and handovers are where things get lost: bags without names, special instructions nobody wrote down, and pickup times nobody remembers. A code at the counter can open a drop-off form asking for a name, a contact method, the number of bags, and any instructions — cold wash, no scented detergent, hang-dry the delicates — before the customer leaves. Print the same code, or a pickup code, on the claim ticket or receipt so the customer can check the same information later.

For pickup, keep it equally simple. The ticket code can open a page showing pickup hours, what to bring, and how to contact the store if a pickup time needs to change. If your system can show order status, link to that; if it cannot, say so plainly and give the counter phone number instead. The goal is fewer calls asking “is my laundry ready?”, not a status page that guesses. Keep personal details out of the QR code itself: the code should open a form or a login-protected order page, never encode a customer name or phone number in the printed pattern.

Loyalty that survives a soggy pocket

Paper stamp cards work until they go through the wash, which, in a laundromat, is not a rare accident. A QR code can replace the card with a link to your loyalty page, where customers can see the current offer and how to claim it. A simple example is “every tenth wash free” — treat that as an illustration, not a rule. Pick a threshold your margins can carry, write it in plain words on the sign, and keep the same wording on the page the code opens.

Be honest about what the code does here. Scan statistics can tell you how many times a loyalty page was opened; on their own, they do not identify individual customers or count one person's visits. True per-customer loyalty needs a loyalty account or app behind the page, with the QR code as the easiest way to reach it.

Wi-Fi for waiting customers

Waiting is part of the laundromat experience, and Wi-Fi is a cheap way to make it pleasant. A Wi-Fi code lets a customer join the network by scanning, without typing a long password from a faded sign. As a rule of thumb, put Wi-Fi on a guest network rather than the network your payment system or office computers use, and put the code where people sit — by the folding tables and chairs — not only by the door they walk past.

Wi-Fi is the clearest example of a job for a static code. Your network name and password rarely change, and reprinting one or two waiting-area signs is a small job if they do. More detail is in our guide to sharing Wi-Fi with a QR code.

Google reviews: ask at the right moment, not for a rating

The best moment to ask for a review is when the job is done well — clean machines, a folded load, a helpful staff member — not while a customer is still loading a washer. Put a review code on the folding tables, on the receipt, or by the exit, with a short, honest invitation such as “Had a good visit? Tell others about it here.” The code should open your Google review page directly, so the customer does not have to search for your business and pick the right branch. Google Business Profile provides a review-request link for this purpose, and its steps are to select Read reviews, then Get more reviews, and copy the link.

Do not offer a discount, a free wash, or any other incentive in exchange for a review. Google's policy prohibits incentives for posting, changing, or removing a review. If you have more than one branch, check the code opens the right location before printing. Our guide to getting Google reviews with a QR code walks through the setup in more detail.

Pricing and payment links

Prices change: detergent costs rise, a new large-capacity washer arrives, or a weekend promotion runs for a month. That is exactly why a price list should not be baked into a printed code that cannot be changed. A dynamic code on the price board can point to a live price page, so a price change means editing the page once, not reprinting every sign, sticker, and flyer in the store.

Payment needs the same care, and one extra warning. A QR code can link to a payment page, a top-up page, or a connected laundry app, but it should never contain payment credentials or card details, or move money without a clear, trusted checkout step in between. Customers should always see the business name, the machine number, and the amount before they confirm anything. Test the full payment journey yourself, on a real phone, before the code goes on a machine.

Lost-and-found, without a public display of other people's laundry

Every laundromat has a lost-and-found shelf, and most of it stays there because nobody knows what to do about a single sock, a phone charger, or a jacket left in a dryer. A code at the counter and by the exit can open a simple lost-property form: what was lost, which machine it may have been in, and how to contact the owner. Keep that form private to staff. Do not post photos or descriptions of found items on a public page, where anyone could claim them, and do not encode personal details in the code itself. On the same page, state plainly how long items are kept and when they can be collected.

Dynamic or static? Decide by whether the destination will change

This is the decision that saves the most reprinting. A static code stores its destination directly in the printed pattern, so it cannot be changed after printing; a dynamic code stores a short redirect link, so the destination behind it can be edited and scans can be counted. Ask one question for each sign: will this page, price, or offer ever need to change, or do I need to know how often it is scanned? If the answer to either is yes, use a dynamic code. If the answer to both is no, a static code is simpler and has nothing behind it that can lapse.

Print and placement: built for heat, humidity, and wet hands

A laundromat is a hard place for paper. Steam, damp hands, detergent splashes, and warm machines will curl, smudge, and fade an unprotected sign faster than a dry shop ever would. That does not mean you need expensive materials; it means you should test one label in the real spot before you print fifty of them.

Start with size. As a rule of thumb, make a printed code at least one-tenth as wide as the distance it will be scanned from, and never go below about 2 × 2 cm, even for a close-up label. A code read from about 25 cm away should therefore be at least about 2.5 cm wide, while a poster read from 3 metres needs a code around 30 cm wide. Leave a blank margin — the quiet zone — of 4 modules on every side, in the same light colour as the code background, and keep text, borders, and busy patterns out of it. Print dark modules on a light background, and for print work use a vector file such as SVG, or a PNG at 300 pixels per inch at the final size, so module edges stay sharp.

For durability, laminate machine labels or print them on a wipe-clean stock, and choose a matte finish where you can: gloss finishes can reflect light straight into the camera and make scanning harder, while matte finishes are easier to scan. As a rule of thumb, keep codes off the hottest surfaces — the top of a dryer in constant use, for example — and away from direct steam, detergent dispensers, and anywhere a wet sleeve will rub across them every day. Put the label where a customer naturally looks: next to the payment slot or start button.

Before a full print run, test the way a customer will actually use the code: print one proof at the real size, on the real material, and scan it with at least one iPhone and one Android phone, from the real distance, in the store's real lighting. If a code fails, check size, quiet zone, contrast, and glare before blaming the phone. A rollout plan that starts small

Do not relabel the whole store on day one. Start with a pilot: two or three machines, the counter code, and the Wi-Fi sign. Watch for a week — ask staff what customers asked about, which codes were scanned most, and which labels peeled, fogged, or confused people. Fix the wording and placement first, because a code that opens the right page but sits in the wrong place will still be ignored.

Then roll out machine by machine, in batches, using the same template every time: machine number in large print, one short line saying what the code does (“Scan to pay for W-04”, “Scan to report a fault with D-12”), and the code itself. Keep a simple master list — machine number, code destination, and date printed — so that when a machine is replaced or a price changes, you know exactly which signs to check. Finally, add the review code by the exit and the lost-and-found code at the counter, and check every code again after the first wash-day rush.

Good to know

Should every machine in a laundromat have its own QR code?

Yes, as a practical rule. A code per machine, matched to a large printed machine number, avoids payments and fault reports going to the wrong machine. A single code for the whole store cannot tell you which washer or dryer a customer means.

Can a QR code start a washing machine?

Not on its own. A QR code is a shortcut to a page, form, or payment system. It can start a machine only when it links to a connected laundry payment system that supports scan-to-start. Otherwise it opens a helpful page for that machine, such as its size, cycles, price, and fault report form.

Can a QR code show live cycle status?

Only through a connected machine or payment system that tracks the cycle and updates the page. A printed code alone cannot know how many minutes are left, so do not promise live status unless your system actually provides it.

Should laundromat price codes be static or dynamic?

Dynamic. Prices, promotions, and services change, and a dynamic code lets you edit the destination behind the printed code instead of reprinting every machine label, sign, and flyer.

What is the best QR code for laundromat Wi-Fi?

A static code. A Wi-Fi network name and password rarely change, there is no promotion to update, and you do not need scan statistics for it, so a fixed code is simpler and has nothing behind it that can lapse.

Can I offer a free wash for a Google review?

No. Google's policy prohibits offering incentives in exchange for posting, changing, or removing a review. Invite an honest review of a real visit instead, and make sure the code opens the correct branch.

How big should a QR code on a washing machine be?

As a rule of thumb, at least one-tenth as wide as the scanning distance, and never below about 2 by 2 cm. A machine code scanned at arm's length should be at least 3 to 5 cm wide, with a blank quiet zone of 4 modules on every side.

How do I protect laundromat QR codes from steam and wet hands?

Laminate machine labels or print them on wipe-clean stock, prefer a matte finish over gloss, keep codes away from direct steam and the hottest dryer surfaces, and test one label in its real spot before printing the full set.
