Share your WiFi with a QR code

Guests ask for the password. You point at the fridge. One scan and they're online — no spelling, no typos, no reading it off the router sticker.

October 28, 2026 · 4 min read

Every host knows the ritual: a guest arrives, asks for the WiFi password, and you recite a string of capitals, numbers, and symbols while they mistype it twice. A WiFi QR code ends it. You print one code, stick it where guests look, and their phone joins the network the moment they scan — no typing at all.

What a WiFi QR code holds

Three things: the network name (SSID), the password, and the security type — usually WPA or WPA2 on a home router, WEP on very old hardware, or nothing at all for an open network. A phone that scans the code reads all three and joins directly, instead of opening settings and typing.

Make one in three steps

  1. Find your network details. The name and password are usually on a sticker on the router. If you changed them, use the ones you set — the code has to match the router exactly, including capitals.
  2. Generate the code. In the WiFi QR code generator, pick the WiFi type, enter the network name, password, and security type. The code appears instantly.
  3. Print it and put it where guests look. Fridge door at home, counter card in a café, the welcome book in an Airbnb, the reception desk in an office. At least 2 × 2 cm on print so phones read it at arm's length.

Which phones join from a scan?

iPhones on iOS 11 and later join straight from the Camera app — point, tap the notification, done. Most Android phones on Android 10 and later do the same from the camera or from WiFi settings. No extra app needed on either side, and guests never see the password itself.

The honest security note

A static WiFi code is convenient because the password lives inside the pattern — which also means anyone who photographs the code can join your network. For a home, a café, or a rental, that is exactly the trade you want: guests are supposed to be online. Two rules keep it sane:

  • Generate it privately. A static code is drawn entirely in your browser — your password is never uploaded or stored anywhere. For extra peace of mind, load the page, disconnect from the internet, then type.
  • If the code leaks somewhere it shouldn't, change the password and reprint. A static code can't be edited after printing, but making a new one is free and takes a minute.

Hidden networks and tricky routers

Hidden networks work the same way — enter the exact network name and the phone connects without ever seeing it in a list. For WPA3 routers, pick the WPA2/WPA option if WPA3 isn't listed; most WPA3 routers accept WPA2 clients. And if a guest's phone refuses to join, check the password's capitals first — that is the cause almost every time.

Good to know

Is my WiFi password safe in a QR code?

For a static code, yes — it is drawn entirely in your browser and never uploaded or stored. Anyone who photographs the printed code can join, so treat it like a guest key: fine for homes, cafés, and rentals, and reprint if it leaks.

Which phones can scan a WiFi QR code?

iPhones on iOS 11+ join straight from the Camera app; most Android phones on Android 10+ do the same from the camera or WiFi settings. No extra app needed.

Does it work with WPA3 or hidden networks?

Choose the security type that matches your router (WPA, WPA2, WEP, or open). Enter a hidden network's name exactly and it connects the same way.

What if I change my WiFi password later?

A static code can't be edited, so print a fresh one — it's free and takes a minute. That's also why the code is best for networks whose password rarely changes.
