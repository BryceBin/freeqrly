Do QR codes expire?

Short answer: no — at least, not the kind you make here. The longer answer is worth knowing before you print a thousand of them.

October 13, 2026 · Last updated: November 3, 2026 · 15 min read

Short answer: no — at least, not the kind you make here. A static QR code cannot expire, because there is no clock inside those little squares. A static code is just your link, drawn as a pattern. As long as the link works, the code works — print it today, scan it in ten years. What actually stops working is something else wearing the same name: a paid dynamic code whose subscription has ended, a link that has been deleted, or a print damaged beyond reading. Each of those failures needs a different fix, and only one of them is a reason to buy anything.

The confusion is understandable, because the warning usually arrives next to a pricing page: “free QR codes expire!” What expires in that sentence is rarely the code. It is the free trial, the subscription, or the vendor's willingness to keep redirecting your scans for free.

Then why do people say QR codes expire?

Three different things get tangled together:

  • Dynamic codes die when you stop paying. Many “free” generators actually make dynamic codes: instead of your link, the pattern holds a short URL on their server, which redirects to your link. Stop paying, and they switch the redirect off. Your code is not expired — it has been taken hostage.
  • Links rot; codes do not. If the page behind the code is deleted, scanning leads nowhere. That is the destination dying, not the code. A QR code pointing at a dead link is a perfectly healthy code with nothing to say.
  • Trial accounts get deactivated. Some services tie your codes to an account, then nudge you toward a subscription. The code did not expire — the account did.

There is a fourth case that looks like expiry but is not the pattern's fault: codes issued by someone else's system. A boarding pass, ticket, or one-time login code can stop working because the issuer invalidates the session, ticket, or booking behind it. The pattern is still readable; the system behind it has withdrawn permission. That is a property of tickets and logins, not of QR codes in general.

A pattern with no clock in it

The QR code was developed in 1994 by DENSO WAVE to overcome the limits of barcodes on factory lines: the barcodes then in use could hold only about 20 alphanumeric characters, while parts tracking needed far more. The QR code that replaced them could store up to about 7,000 characters and was released with open patents and specifications, so anyone could use it. The format was designed as a way to carry data, not as a service with an account or a renewal date. The current edition of its standard, ISO/IEC 18004:2024, specifies the symbology, encoding, and error-correction rules — and it contains no timer, no licence check, and no expiry date, because a printed pattern has nowhere to store one and no one to report to.

That is why the FreeQrly angle is a consequence of the design, not a marketing claim. Every static code made here is free, and yours — no account, no redirect server, nothing to cancel. There is simply no mechanism by which it could expire. Paper can fade, tear, or be thrown away, but it cannot be switched off remotely.

Static vs. dynamic, in one paragraph

A static code encodes the destination directly: WIFI:T:WPA;S:MyCafe;P:secret;; or https://your-site.com/menu. Nothing to maintain, nothing to bill. A dynamic code encodes a redirect on someone's server, which lets the owner change the destination later and count scans. Useful for marketing campaigns — and a subscription for as long as the code must keep working. The full comparison, with the cases where each wins, is in static vs dynamic QR codes.

Rule of thumb: if the destination will never change — your WiFi, your business card, your restaurant menu — static is not the cheap option. It is the correct option.

Steps: find out which failure you have

  1. Open the destination directly. Type the link into a browser, without scanning. If the page itself is missing, the code is innocent: restore the page, or, for a dynamic code, repoint it. If the page loads, the problem is the code, print, or redirect.
  2. Scan a printed proof on two phones. One iPhone and one Android if you can. If neither reads it, suspect size, contrast, damage, or a cropped quiet zone. If only one reads it, the print is marginal — reprint larger rather than trusting the phone that worked.
  3. Read the scan preview, not just the result. Before tapping, look at the URL your phone shows. A short vendor domain where you expected your own means a dynamic redirect is in the middle. A vendor upgrade page means the redirect has been switched off. A strange domain means a sticker or spoof, not an expiry.
  4. Check the account and plan behind a dynamic code. Log in to the creating account and check whether the plan is active, the code is within its scan allowance, and the code has not been deleted. Deleting a dynamic code stops its printed copies at once, on any vendor, because the redirect is removed.
  5. Fix the right layer. Print problem: reprint. Dead page: restore the page. Dead redirect: renew, or replace the code with a static code pointing at a page you control.

What actually goes wrong with printed codes

Since expiry is not a thing, watch for these instead:

  • Print too small. As a rule of thumb, keep codes at least 2 × 2 cm with a quiet margin. Tiny codes on business cards are a common scan failure. The full sizing guidance, including distance, is in the QR code print size guide.
  • Low contrast. Dark ink on a light background. That champagne-on-cream wedding code is beautiful and unreadable.
  • Damage. Outdoor codes fade and scratch. Higher error correction helps: FreeQrly defaults to level M and bumps it automatically when you add a logo. At the High level in ISO/IEC 18004, up to about 30% of codewords can be restored — codewords, not visible area, so “30% damage” misleads. A small scratch over a finder square, the large corner square the scanner uses to locate the code, can stop a scan even when most of the pattern looks intact.
  • No quiet zone. The blank margin around the code, at least 4 modules wide on all four sides under ISO/IEC 18004, is part of the code. Text or design crowded into it makes scanners fail to find the edges at all.
  • Link changes. Moving your site? The old code still points at the old URL. Keep a list of where each code lives — or use a dynamic code and repoint it instead of reprinting. Full checklist: why your QR code is not working.

Scenarios: which codes should outlive their maker

A business card

A business card is printed once and handed out for years. A static code holding a contact card or personal page is the right call: no account to maintain, no redirect to keep paying for, and no one who can switch it off. If the job title changes, the card is reprinted anyway, so the code's frozen destination costs nothing.

A wedding invitation

Invitations go out months before the day, and guests keep them on fridges long after. A static code to an RSVP page you control will still work when the thank-you notes go out, provided the page stays up. A dynamic code also works, but only if someone still minds the account in a year's time — for a one-day event, permanence beats editability. See wedding RSVP QR codes and free QR codes that don't expire.

A restaurant menu or a shop window

Here the choice splits on one question: does the destination change? A menu page you update in place needs only a static code pointing at that page — update the page, not the code. A menu that moves platforms, or a window offer that changes monthly, earns a dynamic code, because reprinting a window sign every month is the expensive option. See QR codes for restaurants.

A campaign poster with a deadline

A poster is the classic dynamic case: it must print before the landing page is final, and later it can point at a recap or waiting list. But it is also where the subscription trap bites hardest, because the poster may still be on walls months after the campaign budget is gone. Before printing a campaign code on any vendor, read what that vendor does when the plan ends, and consider pointing, statically, at a campaign page you own instead.

Packaging sold for years

Packaging is the longest-lived print of all, and the worst place for a subscription-dependent code. A static code to a product page you control survives staff changes and budget cycles, because nothing about it needs renewing. A dynamic code on packaging is justified only when the destination genuinely must change over the product's life, and when someone owns keeping that account alive for the product's whole shelf life.

A safety note the expiry debate usually skips

A code that scans is not necessarily a code you should trust. In a consumer alert dated 6 December 2023, the US Federal Trade Commission warned that scammers place their own QR stickers over real codes on parking meters, and send QR codes in unexpected messages inventing urgent reasons to scan — a missed delivery, an account problem, a password that must be changed. A scammer's code can lead to a spoofed site or to malware. The FTC's advice is the best habit: inspect the URL preview before opening a code in an unexpected place, look for misspellings or a switched letter, and do not scan a code from an unexpected message urging immediate action — contact the company through a number or site you already know instead. For your own codes, check the preview after every edit.

Good to know

Do free QR codes expire?

No, if they are static. A free static QR code lasts as long as the link it points to. Codes that stop working are usually dynamic codes tied to a paid subscription — the vendor switches the redirect off when you stop paying — or codes pointing at a deleted page.

Can a QR code stop working?

Yes, but not from expiry. The usual causes are: the destination page was deleted, the code was printed too small or with low contrast, it got physically damaged, its quiet zone was cropped, or a dynamic plan ended or hit a scan cap.

How long do static QR codes last?

Indefinitely, as long as the destination still works. The pattern encodes your data directly with no server involved, so there is nothing to maintain or renew.

What happens to paid dynamic codes when a subscription ends?

It depends on the vendor, and the vendor's own FAQ page is the source to check. QR TIGER's FAQ says paid codes have unlimited scans while the subscription is valid and 'If your plan expires, it will stop working.' The QR Code Generator says that after a trial ends, 2 codes remain active but display ads, while on its parent platform Uniqode trial codes become inactive without a paid plan.

Can a scan limit stop a QR code?

Yes, on vendors that cap free dynamic scans. QR TIGER's freemium plan, as stated on its own subscription page, gives 3 dynamic codes with a 500 scan limit each. A code that hits its cap stops serving its destination even though the pattern is undamaged. FreeQrly dynamic codes have unlimited scans.

Does damage kill a QR code?

Not always. Error correction can rebuild missing data: at the High level in ISO/IEC 18004, up to about 30% of codewords can be restored. That counts codewords, not visible area — a small scratch over a corner finder square can stop a scan even when most of the pattern looks intact.

How do I tell a dead link from a dead subscription from a bad print?

Open the destination directly in a browser; scan a printed proof on two phones; read the scan preview URL before tapping; and, for a dynamic code, check the creating account's plan and scan allowance. Each check points at a different layer, and each layer has a different fix.

Should a permanent sign or packaging use static or dynamic?

Static, if the destination is fixed. A static code to a page you control needs no account and no renewal, so it survives staff changes and budget cycles. Use dynamic only when the destination genuinely must change and someone will keep the account alive for the code's whole life.
