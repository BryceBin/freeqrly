Why won’t this thing scan?

A QR code that won't scan is almost never a mystery. Run through these seven checks — in order — and you'll find the culprit in about two minutes.

2026-10-14 · 4 min read

1. It's too small

The classic. A code squeezed into the corner of a business card at 1 cm wide won't scan reliably. Minimum for print, as a rule of thumb: 2x2 cm (about 0.8 inches), and bigger is always safer. There's a full breakdown in the print size guide.

2. Low contrast killed it

QR readers look for dark modules on a light background. Light gray on white, brand pastels, or a code over a busy photo will fail — especially in dim light. When in doubt: black on white always works.

3. It's damaged or faded

Creased flyers, sun-faded posters, scratched stickers. Error correction can survive some damage (that's why adding a logo works), but there's a limit. If a quarter of the code is gone, reprint.

4. No quiet zone

The blank margin around the code isn't decoration — scanners need it to find the edges. Keep a clear border at least 4 modules wide on all four sides, as specified in ISO/IEC 18004. Don't let text or design elements crowd it.

5. Glare, curve, or angle

Glossy lamination under bright light, a code wrapped around a bottle, or shot at a steep angle. Flatten it, kill the glare, shoot straight on.

6. The content is dead

The code scans fine — but the link is broken, the page moved, or the "free" generator's trial expired and took your code with it. This is the expired-link trap: do QR codes expire? explains which ones do and how to avoid them.

7. Your camera

Wipe the lens. Seriously — a smudged lens is behind an embarrassing number of "broken" codes. Then test on a second phone: if phone B reads it, the code was never the problem.

Test before you print

Scan the code on two different phones (one iPhone, one Android if you can) before sending anything to print. Thirty seconds now saves a reprint later. Generate a test code in the free generator and try it.

Sources

Good to know

Why does my QR code scan on one phone but not another?

Then the code itself is fine — it's the camera, lighting, or angle on the failing phone. Wipe the lens and try in better light.

Can a damaged QR code still work?

Often yes, thanks to error correction — up to 30% damage can be tolerated at the High setting, as defined in ISO/IEC 18004. But heavy damage, fading, or missing finder patterns will kill it.

My QR code scans but the link doesn't work — is the code broken?

No, the code is doing its job. The destination is the problem: the page moved, the site is down, or a trial-based generator deactivated it.
