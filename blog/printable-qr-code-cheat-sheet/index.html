QR code cheat sheet: one page, print-ready

Tape this next to your printer. One A4 page holds the size table, the quiet-zone rule, and the contrast rules you need before any print run — no second page, no hunting through guides.

November 4, 2026 · 5 min read

Most printed QR codes fail for boring, preventable reasons: printed too small for the distance, the quiet zone cropped by a layout, or contrast too weak to scan in dim light. This sheet collects the three checks that catch those failures, on a single A4 page you can keep by the printer.

The size table uses the distance ÷ 10 rule of thumb: the code's size should be at least one-tenth of the scanning distance. Sizes below are for the code itself — the quiet zone goes on top, so the finished footprint is larger. For the full reasoning and edge cases, see the QR code print size guide. If a printed code still will not scan, work through the QR code troubleshooting guide before reprinting, and run the pre-print checklist on any large run.

Quiet zone — the margin is part of the code

  • Leave at least 4 modules of clear, light margin on all four sides, in the same light color as the code background.
  • Never let text, borders, or a tight crop run into the margin — a cropped quiet zone stops the scan.
  • A 2 cm code with its quiet zone needs more than 2 cm of clear space. Size the layout slot, not just the code.
  • Never stretch the code: scaling must keep squares square, or phones cannot read the grid.

Contrast rules

  • Dark code on a light background. Inverted (light-on-dark) codes often fail — avoid them in print.
  • If two colors look close on screen, they will be worse in print. When in doubt, use black on white.
  • Gloss laminate and glass both glare: test the finished, laminated print under real light.
  • Print proof first: one copy, real paper, real distance, real phone — before the full run.

Before you print — 60-second check

  • Size ≥ distance ÷ 10 for where it will actually be scanned?
  • Quiet zone of 4 modules intact on all sides?
  • Exported as SVG, or PNG at 300 DPI at final size?
  • Short destination behind the code, so the pattern stays simple?
  • Proof scanned first time, in the real light, from the real distance?

Good to know

Does this really fit on one A4 page?

Yes — the sheet is laid out for A4 with tightened margins and compact type (about 10–11 pt). Print at 100% scale, not "fit to page," and check in the print preview that it stays on one page before printing.

Can I print it in black and white?

Yes. The green header and yellow note print as grey on a monochrome printer and nothing essential depends on color. The rules themselves — size, quiet zone, contrast — are what matter.

What is a "module" in the quiet-zone rule?

One square of the code's grid. The quiet zone must be at least 4 such squares wide on every side, in the same light color as the code's background. On a small code the modules are tiny, which is why the margin looks small but still matters.

The table says 2 × 2 cm for a business card. Is that an absolute minimum?

Treat 2 cm as the floor for print, not a target: it assumes a clean print, good contrast, and a short destination. Dense codes, textured stock, or poor light all argue for sizing up.

My code will be scanned from farther away than the table lists. What do I do?

Apply the distance ÷ 10 rule directly: divide the real scanning distance by 10 and print at least that large. If the result is impractically big, move the code closer to where people walk instead of making a giant sign.

Can I scale this sheet down to A5?

You can, but the type will drop below comfortable reading size. If you need a smaller sheet, print it at A4 and cut, or keep it posted by the printer at full size.
