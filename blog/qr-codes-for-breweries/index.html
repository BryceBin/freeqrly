QR Codes for Breweries That Keep Up With the Tap List

A brewery changes faster than a printed menu can. This guide shows which brewery QR codes should be editable, which can stay fixed, and how to print them so they still scan in a busy, wet taproom.

November 4, 2026 · 15 min read

A taproom runs on change. A keg kicks mid-service, a small-batch sour sells out before dinner, and the beer a regular came in for is suddenly gone. A printed menu cannot keep up without becoming a chore: reprint it every time, and cost and waste add up; leave it as it is, and guests order beers that are no longer pouring. That is why a brewery is one of the clearest cases for a QR code — and, more precisely, for the right kind of QR code in the right place.

The rule that sorts almost every brewery decision is simple: if the information behind the code can change, the code itself should be editable after printing. If it will never change, a fixed code is simpler and perfectly reliable. Get that distinction right, and tap lists, tours, merch, clubs, events, reviews, and food pairings all fall into place.

The tap list is the strongest case for a dynamic code

A tap list is a moving target, especially for a brewery that releases small-batch or seasonal beers. One guide to brewery QR codes puts it plainly: tap lists change, and a dynamic code lets the linked menu be updated while the printed code stays the same. Print the code once on table tents, coasters, the bar top, or a wall board, then update the page it points to whenever a tap changes. Guests always see what is actually pouring, and staff stop answering the same question — is this one still on? — all evening.

What should that page show? At minimum, each beer needs its name, style, alcohol by volume (ABV), pour sizes, and prices, plus a clear sold-out state. Bitterness (IBU), a one-line tasting note, and glassware help guests choose without asking. Mark a kicked keg as sold out the moment it kicks, rather than deleting the beer silently: a guest who can see a beer is gone will happily pick a second choice.

One caution matters more than any design choice: keep the destination up to date, or the code works against you. An out-of-date tap list creates more confusion than no list at all, because guests trust the phone in their hand. Assign one person per shift to update the list when a keg changes. A dynamic code removes the reprint; it does not remove the need to update.

Dynamic versus static: which brewery use needs which

A static code stores its data directly in the pattern itself. Once printed, that data does not change. A dynamic code stores a short redirect instead, so the destination can be edited without replacing the printed pattern, and scans can be counted. A comparison of the two types puts it the same way: static codes suit fixed information with no need for scan reporting, while dynamic codes suit menus, promotions, and campaigns that change.

Apply one test to each placement: could I replace every copy of this code if the destination changed tomorrow? If not, choose dynamic.

Brewery tours: put the story where guests are standing

A tour is the moment guests are already curious about how beer is made, and a code can answer that curiosity without turning the guide into a lecturer or the wall into an essay. Place a small code at each stop — the mill, the mash tun, the fermenters, the canning line — and link each one to a short note: what happens here, what to look or smell for, and which beer in the taproom shows the result. A short brewer note, a page about the brewery history, or a note on a seasonal release are exactly the kinds of detail that fit behind a code rather than on a sign. Keep each stop short, and if a stop changes, a dynamic code lets you update it without reprinting the whole trail.

Merch: make a shirt, glass, or can keep selling after it leaves

Merch is often treated as a one-time sale, but a code turns it into a lasting connection. A code on a T-shirt hang tag, a glass box, a sticker, or a can label can open the brewery story, the current tap list, the online shop, or the next release. The right destination depends on how long the item will live. A can drunk within weeks can point to that specific release. A glass or hoodie used for years should point to something durable — your homepage, shop, or events page, updated through a dynamic code when details change.

Do not overload merch with codes. One clear code with a plain label — Scan for our story, Shop this glass, See what is pouring today — beats three unexplained squares. On a can, leave legally required label information on the label itself and let the code add detail, such as tasting notes or food pairings. On a shirt, put the code where it can be scanned flat, not across a seam, and test it on the finished garment.

Loyalty and mug clubs: reward regulars without a spreadsheet on the bar

Mug clubs live or die on friction. The classic version — a numbered mug on a shelf and a paper list behind the bar — works until it grows, and then it becomes a chore for staff and a mystery for members. A QR code does not run the club by itself, but it removes the two most common friction points: joining, and knowing what members get.

Put a code on the bar, on the mug shelf, and on the member card that opens one clear page: how to join, what membership includes, when member nights run, and how to claim a perk. One brewery example, described in a guide to brewery coasters, put a mug-club signup form behind the QR code on the back of a coaster — a touch guests kept rather than threw away. The lesson is that signup has to be where the regular already is, at the moment they are already enjoying the beer.

A dynamic code on the membership page lets you update perks, dates, and prices without reprinting every card and poster when a new season starts, while a static code is enough for a permanent benefit that never changes. Keep the QR code as the front door, not the whole system: it should get a guest to signup or a perk in one scan, not demand an app download.

Events: one poster that survives a lineup change

Taprooms run trivia nights, live music, release parties, and food-truck evenings, and every one has the same printing problem: the poster goes up before the details are final. A dynamic code on the poster, the table tent, and the social post solves it. Print once, then update the destination as the lineup firms up, the ticket link opens, or the start time moves. Guests who scanned the early poster still land on the current details. Make event codes specific: a code labelled Trivia this Thursday should open that Thursday event, not a general events page where guests have to hunt, and retire old details promptly each week.

Google reviews: ask at the right moment, and ask honestly

A QR code makes leaving a review easy: instead of asking a guest to search for your name and find the review button, a scan can take them directly to the review form. The link comes from your Google Business Profile: on a computer, open the profile, choose Read reviews, then Get more reviews, and copy the review link or save the QR image Google provides. A generator can then encode that same link in a custom, branded design.

Place the review code where the experience is already good, but do not pressure anyone. A code on the bill folder, the takeout bag, or a small table card works; a code thrust at a guest mid-meal does not. Word it plainly — Share an honest review on Google — and make the same request available to every guest, not only to those who praised the beer. Google prohibits incentives in exchange for reviews and selectively asking only happy customers, so never offer a discount, a free pour, or a prize for a review, and never ask for a particular star rating or wording.

Food pairings: give guests a reason to order a second item

Many taprooms serve food or host a food truck, and a code on the menu or flight card can carry a short pairing guide that would never fit on the printed menu. Pairing guides commonly describe three moves: complement, contrast, and cut. Complement matches similar flavours, such as a roasty stout with grilled or smoked meat. Contrast balances opposites, such as sweet malt against spicy heat. Cut uses carbonation and bitterness to clear richness from the palate, which is why a crisp lager or bitter pale ale works with fried food, cream sauces, and fatty fish. Before any of those, match intensity: light beers with light dishes, and fuller, darker, or stronger beers with roasts, stews, and aged cheese, so neither side drowns the other out.

Translate that into your menu in plain language. A light lager or pilsner suits salads, seafood, fried snacks, and mild cheese. An American IPA suits fried food, spicy dishes in moderation, and aged cheddar. A brown ale suits roast pork, barbecue, and burgers. A porter or stout suits smoked meat, oysters, and chocolate desserts. If your kitchen menu changes, a dynamic code lets the pairing page change with it while the printed flight card stays the same.

Print and placement basics for a taproom

A taproom is a hard place for a QR code: dim light, condensation, greasy hands, curved glasses, and guests scanning at arm length or across a bar. The widely used rule of thumb is the 10:1 rule: make the code at least one tenth as wide as the distance it will be scanned from. A code read from about 25 centimetres should be about 2.5 centimetres wide, and a poster read from 3 metres needs about 30 centimetres. Never go below about 2 by 2 centimetres in print, and make denser codes larger, because more data means smaller modules at the same size.

Leave a quiet zone — a blank margin at least four modules wide on all four sides, in the same light colour as the code background — and do not crop it or place the code flush against a busy photo. Print dark modules on a light background, and prefer matte finishes in a taproom: gloss lamination, foil, and clear plastic can reflect light straight into the camera. For print, export SVG where your printer accepts it, because a vector stays sharp at any size; if you must use PNG, use at least 300 pixels per inch at the final printed size. For a deeper sizing reference, see the print-size guide, and for codes that will not scan, see the troubleshooting hub.

Moisture is the taproom-specific problem. Paper table tents survive a dry evening but not repeated wipe-downs, condensation rings, and spills. For anything that will be wiped, handled wet, or placed outdoors, print on vinyl or polyester stock, or laminate the print with a sealed edge, and use pigment-based or laser printing rather than dye-based ink, which smears when wet. One waterproof-sticker guide describes that two-layer build — a water-resistant base plus a protective seal — and notes that lamination extends outdoor life for vinyl to one to two years, compared with six to twelve months for an unlaminated vinyl print.

Before any print run, test a proof at real size on the real material, with at least one iPhone and one Android phone, from the real distance and angle in the real lighting, and check that the page loads quickly on mobile data, not just on taproom WiFi. A dynamic code can rescue a wrong destination after printing, but it cannot rescue a code that is too small, too low-contrast, or physically damaged.

A simple setup that covers the whole brewery

Start with one dynamic code for the live tap list, because that is the code guests will use most and the one that saves the most reprinting. Add a static code for WiFi, placed where guests sit down rather than where they queue. Add a second dynamic code for events, so posters and table tents can stay up between events. Then add codes only where they answer a real question: a tour stop, a merch item, a mug-club signup, a review card, or a pairing note. Fewer, clearer codes beat a wall of squares guests learn to ignore.

Label every code in plain words. Scan for today tap list tells a guest more than a bare square ever will. Keep a simple list of your codes — where each one is printed, what it points to, and whether it is static or dynamic — so that when a tap list moves, an event ends, or a club perk changes, one person can update the right destination in minutes. Print once, update often, and let the beer do the rest. See also QR codes for restaurants.

Good to know

Should a brewery tap list use a dynamic or a static QR code?

Dynamic. Tap lists, prices, and sold-out states change constantly, and a dynamic code lets you update the linked page without reprinting the table tents, coasters, or posters.

What should a tap-list page show?

Each beer name, style, ABV, pour sizes, and prices, plus a clear sold-out state. IBU, a one-line tasting note, and glassware help guests choose without asking staff.

Can one QR code work for both a tap list and events?

It can if it points to a page you update, but specific codes work better. A tap-list code should open the tap list, and an event code should open that event, so guests do not have to hunt.

What is a good use for a static QR code in a brewery?

Anything that will not change, such as guest WiFi login, a permanent brewery history page, or a fixed tour route. Static codes need no registration with FreeQrly, carry no watermark, and never expire.

How big should a QR code be on a coaster or table tent?

As a rule of thumb, make the code at least one tenth as wide as the scan distance. For a coaster or flight card scanned from 20 to 30 centimetres, that means about 2 to 3 centimetres, and never below about 2 by 2 centimetres in print.

How do I make a taproom QR code survive spills and condensation?

Print on vinyl or polyester stock, or laminate the print with a sealed edge, and use pigment-based or laser printing rather than dye-based ink, which smears when wet. Paper alone will not survive repeated wipe-downs.

Can I offer a free drink for a Google review?

No. Google prohibits incentives in exchange for reviews and selectively asking only happy customers, so ask every guest for an honest review and never request a particular star rating or wording.

Do I need a different QR code for each beer?

Not usually. One tap-list code that opens the full list is simpler to maintain. Use a separate code only when a single beer, release, or merch item genuinely needs its own page.
