Good to know

Profile link or a specific video?

Profile link for general follows. A video link plays one video — handy for campaigns, packaging inserts, and posters for a launch.

Does it open in the TikTok app?

On most phones, yes — tapping the scanned link offers the app if installed, otherwise it opens in the browser.

Can I add my logo or brand colors?

Yes — upload your logo and set your brand colors. Keep contrast high so it scans in any light.

Does it expire if I change my username?

The code encodes the exact URL, so if your handle changes, make a fresh code. The code itself never expires.
