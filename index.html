Good to know

Do free QR codes expire?

Never. The destination is encoded directly in the pattern, so a code works as long as the destination does. Paid dynamic codes run through a vendor's servers and can die when you stop paying — one more reason static feels safer.

Is my WiFi password safe here?

For a static code, yes. Your password never leaves your browser — nothing is sent anywhere. Extra careful? Load the page, disconnect, then type.

Static or dynamic — which should I choose?

If the destination won't change, go static: WiFi, business cards, fixed links. Dynamic codes (editable links + scan stats) suit marketing campaigns — they're live now: free sign-in, edit after printing, track scans.

Can I use these commercially?

Absolutely. Every code you make here is yours — packaging, menus, business cards, no attribution needed.

Is FreeQrly really free?

Yes — everything on this page is free, with no watermark. Static codes need no account. We don't sell subscriptions; this is a tool, not a funnel.

Do I need an account?

Not for static codes — open the page and make your code. Dynamic codes need a free sign-in, so you can edit them after they're printed.

Can I add my logo to the QR code?

Yes — upload any square logo and it goes in the center, with error correction raised automatically so it keeps scanning. For print, use Q or H.
