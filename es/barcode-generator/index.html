¿Qué formato de código de barras debo usar?

Code 128 para uso general: admite cualquier texto. EAN-13 para productos de venta internacional, UPC-A para venta en EE. UU., Code 39 cuando el escáner es viejo o el código debe leerse a simple vista, ITF-14 para cajas de envío.

¿Necesito un dígito de control?

No: para EAN-13, UPC-A e ITF-14, escribe un dígito menos y el dígito de control se calcula por ti. Code 128 y Code 39 no necesitan ninguno.

¿PNG o SVG para imprimir?

SVG para empaques e impresión profesional: escala sin límite y sin borrosidad. PNG para impresión de oficina y apps que no aceptan SVG.

¿De verdad es gratis? ¿Sin marca de agua?

Gratis, sin marca de agua, sin registro. El código se dibuja en tu navegador: nada se sube.
