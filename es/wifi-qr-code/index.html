Bueno saberlo

¿Mi contraseña WiFi está segura aquí?

Para un código estático, sí. El código se dibuja por completo en tu navegador: tu contraseña nunca se sube ni se guarda en ningún lado. Para mayor tranquilidad, carga la página, desconéctate de internet y luego escribe.

¿Qué teléfonos pueden escanear un código QR WiFi?

Los iPhone con iOS 11+ se unen directo desde la app Cámara; la mayoría de los teléfonos Android con Android 10+ hacen lo mismo desde la cámara o los ajustes de WiFi. Sin app extra.

¿Funciona con WPA3 o redes ocultas?

Elige el tipo de seguridad que coincida con tu router (WPA, WPA2, WEP o abierta). Escribe el nombre de una red oculta exactamente y se conecta igual.

¿Puedo usar esto para mi café o Airbnb?

Absolutamente: ese es el uso clásico. Imprímelo una vez y funciona para cada invitado, para siempre, sin costo.
