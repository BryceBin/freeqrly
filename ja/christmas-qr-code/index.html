クリスマスのQRコード：ギフトカード、イベント、寄付、そしてもっとできるカード。

クリスマスのQRコードは、人々がすでに手にしているもの——カード、ギフトタグ、ポスター、マーケットの屋台の看板——に印刷された近道です。見せたいページ、動画、フォームに直接連れて行きます。行き先が決して変わらないなら、無料の静的コードを使ってください。登録不要、透かしなし、期限切れなし。シーズン中に行き先が変わるかもしれないなら——売り切れたイベント、新しい寄付の合計、違うメニュー——無料の動的コードを使ってください。印刷後に行き先を変更でき、スキャン回数も表示されます。FreeQrlyは両方作ります。静的コードはブラウザ内で完全に生成され、アップロードされるものも、追跡されるものもありません。

  1. 1瞬間を選ぶビデオの挨拶、写真アルバム、プレイリスト——またはパーティーそのものをカレンダーイベントとして。店や募金活動では、その瞬間はページです。ギフトカードショップ、寄付フォーム、イベントページ。
  2. 2静的か動的かを決める固定で個人的なもの：静的、無料、登録不要。変わるかもしれないもの、測る価値のあるもの：動的、無料サインイン、印刷後に編集でき、スキャン統計付き。
  3. 3リンクを貼るか、日付を設定するリンクはすぐに静的コードになります。登録不要。招待状には、イベントタイプがタイトル、開始、終了、場所を運びます。一度に多くのコード——ギフトタグ、アドベントの扉——には、バッチモードを使ってください。1行に1つのリンク、最大50個のコード、ZIPでダウンロード。
  4. 4スタイルを整え、テストスキャンし、驚きが届く場所に印刷するお好みでドットのスタイル、色、中央のロゴを選び、1024px以上で書き出してください。実際のサイズで1部印刷し、フル印刷の前に本物のスマホでスキャンします。それから、驚きが届く場所に置きます。カードの中、ギフトタグの上、屋台のカウンターに、スキャンで何が起きるか短い一文を添えて。

クリスマスのQRコードが実際にすること

QRコードは、贈り物でも、チケットでも、寄付でもありません。それへの入り口です。人がスキャンし、スマホがページを開き、ページが仕事をします。動画の挨拶を流す、ギフトカードを売る、寄付を受け取る。コードは一度印刷したら取り消せません。裏側のページは修正も、更新も、差し替えもできます。だから、このガイドで最も重要な決定は、どの種類のコードを印刷するかです。

静的か動的か：他のすべてが決まる選択

静的コードは、内容を模様そのものの中に持ちます。印刷したものが、ずっとそのままの働きをします。動的コードは、短いリダイレクトを持ちます。印刷した模様は同じままですが、行き先はFreeQrlyに保存されるので、印刷後に行き先を変えられます。スキャン回数も分かります。

お客様の旅の仕組み

旅A — ギフトカードの購入

図1は5つのステップを示します。買い物客がギフトカードのディスプレイ、ポスター、棚の端でコードを見つける → スマホのカメラでスキャンし、アプリは不要 → 金額とメッセージを選び、ページで支払う → ギフトカードをメールで受け取るか、印刷できるカードとして受け取る → 受取人が店頭またはオンラインで引き換えます。

教訓はステップ2にあります。コードが開くページは、ホームページではなく、ギフトカードのページでなければなりません。タップが1回増えるごとに、店内でスマホを手に買い物の準備ができている買い物客を失います。

旅B — イベントチケットと寄付

図2は5つのステップを示します。ゲストがポスター、教会の掲示板、マーケットの屋台、ソーシャル投稿でコードを見つける → スキャンしてイベントページまたは寄付フォームを開く → チケットを予約する、参加を返信する、寄付する → チケットまたは領収書をメールで受け取り、カレンダー招待が追加される → 主催者がお礼の連絡をし、動的コードならスキャン数がどのポスターが効果的だったかを示します。

教訓はステップ4にあります。支払いが通ったとしても、寄付や予約が沈黙で終われば、壊れたように感じられます。画面とメールで行動を確認してください。イベントでは、イベントコードの種類が日付、時刻、場所を1回のスキャンでゲストのカレンダーアプリに直接追加します。

ギフトカード：最も価値の高いクリスマスのコード

ギフトカードは、QRコードが最も直接的にお金に変わる場所です。そして、間違った選択が最も高くつく場所でもあります。

  1. ディスプレイには動的コードを使ってください。ギフトカードの金額は売り切れ、デザインは変わります。動的コードなら、ディスプレイスタンドを刷り直さずに行き先を変えられます。無料プランでは動的コードは20個までで、ディスプレイ、ポスター、ソーシャル投稿をまかなって余りがあります。Pro（月額9ドルまたは年額90ドル）は、その20個の上限を取り除くだけです。期間限定キャンペーンでは、無料の動的コードは無制限です。キャンペーン終了後は、無料プランの動的コードは20個までとなります。
  2. 金額の範囲をディスプレイに印刷してください。コードだけでなく。「$10からのギフトカード」とコードの横にあれば、スキャン前に期待が決まります。文脈のない裸のコードは、スキャンが少なくなります。買い物客は、何のためにスキャンしているのか分からないからです。
  3. 購入全体を本物のスマホでテストしてください。印刷したディスプレイをスキャンし、一番安いカードを自分で買い、受取人が受け取るメールを確認します。どのステップでも、買い手が持っていないアプリのダウンロードやログインを求められたら、ページを修正してください。

寄付と募金：信頼こそが商品です

寄付のコードは、見知らぬ人に、見たこともないページへお金を送るよう頼みます。設定のすべてが、疑いを減らすべきです。

  • 大義、団体、お金の行き先を明記したページにリンクしてください。裸の支払いフォームではなく。印刷した団体と同じに見えるべきです。同じ名前、同じロゴ、同じ大義。
  • 動的コードを使ってください。募金は12月を通して変わります。マッチング寄付の期間が開き、目標に到達し、新しい合計が掲示されます。動的コードなら、同じ印刷したポスターが、11月の文言に凍結されるのではなく、キャンペーンに追従できます。
  • 人が立ち止まる場所にコードを置いてください。人が通り過ぎるポスターの寄付コードは、ちらっと見られるだけです。同じコードを、募金テーブル、プログラム、屋台のカウンター——人がすでに立ち止まり、スマホを手にしている場所——に置けば、スキャンされます。横に短い一文を添えてください。「寄付はこちらをスキャン」は裸のコードより優れています。次に何が起きるかを示すからです。キャンペーンのページに、進行中の合計やお礼のメッセージが表示されれば、2回スキャンした寄付者は、自分の寄付が意味があったと分かります。

グリーティングカード、ギフトタグ、アドベントカレンダー

これらは個人的な用途で、静的コードが輝く場所です。内容は固定され、個人的で、長持ちするものです。

  • 動画のグリーティングカード。挨拶を、共有可能なリンクのある場所にアップロードしてください。非公開のYouTube動画がよく使えます。リンクからQRコードを作り、カードの内側に印刷します。1回のスキャンで再生されます。コードが静的なので、動画がオンラインにある限り、来年のクリスマスにも機能します。
  • 写真アルバム、プレイリスト、招待状。コードを共有アルバムやその夜のプレイリストにリンクしてください。ゲストはワンタップで開けます。アプリのインストールは不要です。イベントコードの種類はタイトル、時刻、場所を運ぶので、1回のスキャンでパーティーがゲストのカレンダーアプリに入ります。
  • すべてのギフトタグに違うコードを。バッチモードで一度にすべて作れます。1行に1リンク、タグごとに1コード、ZIPでダウンロード。バッチは静的コード専用で、1バッチ最大50個まで——1行に1つ貼り付けるか、CSVまたはXLSXファイルをアップロードしてください。
  • 24の扉のあるアドベントカレンダー。各扉の裏にコードを印刷してください。写真、手がかり、小さな動画。24個のコードは、最大50個のバッチ実行1回に十分収まります。各扉の行き先は短く固定しておいてください。印刷後に変わる手がかりは、子どもをがっかりさせる扉です。
  • 木が片付けられた後も残るお礼状。お礼のコードを贈り物と一緒に印刷してください。静的コードは、裏側のページがオンラインにある限り動き続けます。動的コードなら、ホリデーの後に行き先を変更できます。1月のセールや来年のイベントへ、お礼状を刷り直さずに。

計画タイムライン：いつ印刷するか

図4は4段階のタイムラインを示します。日付より順序が重要です。決める、テストする、印刷する、それから見守る。

  • 11月上旬——コードと行き先を決める。コードが現れるすべての場所と、それぞれが何を開くべきかをリストし、表2を使ってそれぞれ静的か動的かを決めます。考えを変えるのに最も安いタイミングです。
  • 11月中旬——テスト印刷と最初のスキャンチェック。各コードを実際のサイズで1部印刷し、実際に使う照明の中で、2台の違うスマホでスキャンします。スキャンできるかどうかだけでなく、開くページも確認してください。
  • 11月下旬——すべて印刷し、配置する。ギフトタグより大きいものは1024px以上の書き出しで、ポスターは2048pxで印刷します。人が立ち止まる場所、光の良い場所にコードを置きます。まぶしく反射するガラスの裏や、足首の高さは避けてください。
  • 12月——見守り、行き先を変え、お礼を言う。動的コードのスキャン数を週に1回確認します。スキャンのないポスターは、不人気なのではなく、配置が悪いのかもしれません。詳細が変わったら、刷り直すのではなく動的コードの行き先を変えてください。

シーズン中に詳細が変わったとき

クリスマスの計画は変わります。イベントが移動する、商品が売り切れる、寄付の目標に到達する、マーケットの屋台が場所を移す。どうするかは、コードの種類によります。

  • 動的コード：FreeQrlyのダッシュボードで行き先を変更してください。印刷したコードは変わらず、すべてのポスター、カード、屋台の看板がすぐに追従します。
  • 静的コードで、裏側のページが自分のもの：ページを更新してください。イベントページを指す静的コードは、ページ自体を編集すれば引き続き機能します。新しい時刻、新しい詳細、同じコード。
  • 静的コードで、裏側のページが自分のものではない：修正できません。削除された動画や、売り切れた第三者のチケットページを指す静的コードは、死んだコードです。だからこそ、自分の管理外のものは動的にすべきです。

FreeQrlyは、17種類のQRコード、バッチ生成、中央のロゴ、10言語を提供します。静的コードは本当に無料です。登録不要、透かしなし、期限切れなし、ブラウザ内で完全に生成され、アップロードされるものはありません。

知っておきたいこと

クリスマスカードに動画を入れるには？

動画を、共有可能なリンクのある場所にアップロードしてください。非公開のYouTube動画がよく使えます。リンクからQRコードを作り、カードの内側に印刷してください。1回のスキャンで再生されます。静的コードを使ってください。挨拶は固定されており、動画がオンラインにある限り、来年のクリスマスにも機能します。

コードでゲストのカレンダーにパーティーを追加できますか？

はい。イベントタイプがタイトル、時間、場所を運びます。1回のスキャンで、パーティーがカレンダーアプリに追加されます。メールだけでなく、招待状そのものに載せてください。紙の招待状は、人々が冷蔵庫に貼っておくものです。

すべてのギフトタグに異なるコードが必要です。どうすればいいですか？

ジェネレーターのバッチモードを使ってください。1行に1つのリンク、タグごとに1つのコード、すべてZIPでダウンロードできます。バッチは静的のみで、1バッチ最大50個のコードです。リンクを貼り付ける代わりに、CSVまたはXLSXファイルをアップロードすることもできます。

クリスマスのポスターを何人がスキャンしたか、確認できますか？

はい、動的コードで。スキャン統計はFreeQrlyのダッシュボードに表示されます。静的コードはブラウザ内で完全に作られ、何もアップロードされないので、数えるものがありません。追跡が重要なら、各ポスターに専用の動的コードを与えてください。共有のコードは合計しか示しません。

クリスマスのQRコードは費用がかかりますか？

静的コードは登録不要で無料です。動的コードは無料サインインで無料です。無料プランで20個、スキャン無制限、有効期限なし。Proは月額9ドルまたは年額90ドルで、唯一の違いは動的コードが無制限なことです。
