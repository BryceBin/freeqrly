あなたのロゴを 中央に——それでも読み取れる

ロゴがあると、コードがあなたのものになります。ただし模様の一部が隠れるのも事実です。両立のコツはこうです。ロゴは真ん中にぴったり、コードは1回で読み取れる。

QRコードの中央のロゴが機能するのは、3つの条件が揃ったときです。ロゴが小さいこと、コードの誤り訂正が高く設定されていること、重要なものが覆われていないことです。実際には、正方形で透明背景のロゴを中央に置き、コード面積の約30%未満を上限として保ち — 安全余裕が欲しいならさらに小さく — 明地に暗地で印刷し、コード全体の周りに明確な余白を取るということです。これを行い、印刷物を2台のスマホでテストすれば、コードは一発で読み取れ、なお紛れもなくあなたのブランドに見えます。

その短い版には、正直な緊張が一つ隠れています。このガイドはそれを避けません。30%は上限であって目標ではありません。最も高い誤り訂正レベルでも再構成できるのはデータの約30%です。だから、その限界に近づくロゴは、擦れた印刷、薄暗い部屋、古いスマホのために、ほとんど余裕を残しません。多くのデザインガイドが、中央のロゴをコード面積の20〜25%程度に保つよう助言するのはそのためです。そうすれば、摩耗にもまだ吸収の余地が残ります。ロゴが大きくならざるを得ないなら、このガイドの残りが、何と交換すべきか — より短い内容、より大きな印刷、よりシンプルなマーク — を示します。上限が救ってくれることを祈るのではなく。

ロゴがそもそも機能する理由：誤り訂正

QRコードは、あなたのリンクの絵だけではありません。モジュールと呼ばれる暗い四角と明るい四角の格子に、欠けた部分をリーダーが再構成できるよう格子全体に織り込まれた冗長なデータを加えたものです。その冗長性は、QRコードの規格ISO/IEC 18004で定められた誤り訂正レベルで決まります。

レベル復元できる目安用途
L（低）7%きれいな、画面専用の、ロゴなしのコード
M（中）15%プレーンな印刷コード。良い既定値
Q（四分位）25%摩耗、汚れ、擦れにさらされる印刷物
H（高）30%ロゴのあるコード、または粗い表面

ロゴを加えると、覆われた中央は損傷として数えられ、リーダーはコードの残りの部分に広がった冗長なデータからそれを再構成します。だから、誤り訂正レベルはロゴファイルそのものより重要なのです。レベルLやMでは、ロゴはコードがプリンターに届く前に安全余裕のほとんどを食いつぶします。一方レベルHでは、同じロゴがはるかに大きな余裕の中に収まります。FreeQrlyはロゴを加えると誤り訂正を自動で上げるため、手動でレベルを設定する必要はありません。ただ、それが何を買ってくれるかは尊重しなければなりません。高いレベルはモジュールも増やし、同じ内容をより密にします。レベルMで29×29の格子に収まる短い住所は、レベルHでは37×37が必要です。だから同じ印刷サイズでは各モジュールが小さくなります。行き先は短く保ち、ロゴ入りコードはプレーンなものより少し大きく印刷してください。

ロゴのサイズ：上限、より安全な範囲、面積と幅の罠

ロゴのサイズの助言は読み間違えやすいです。ガイドは2通りの言い方をするからです。コードの幅の30%に広がるロゴは、面積の約9%しか覆いません。一方、面積の30%を覆うロゴは、幅の約55%に広がります。このガイドが「コード面積の約30%未満」と言うとき、それは面積 — ロゴが隠す四角全体の割合 — を意味し、それがFreeQrlyジェネレーターの上限です。その上限に近いものは、余裕が残っていないコードとして扱ってください。

コード面積に占めるロゴの割合実際には何を意味するか
約20%まで快適です。印刷のばらつき、グレア、摩耗のための余裕が残ります。
約20〜25%ほとんどのデザインガイドが、ブランド入りコードの実用的な最大値として推奨する範囲です。
30%に近づく上限です。きれいな条件ではスキャンできますが、擦れや薄暗い光がとどめを刺すことがあります。
30%超誤り訂正で再構成できる範囲を超えています。ロゴを小さくするか、内容を短くしてください。

ほかに2つの配置ルールがあります。好みの問題ではなく絶対です。第一に、ロゴは真ん中に置きます。中央には位置決めのデータがないため、覆うのに最も安全な場所であり、中央に置くことでマークは角にある3つの大きなファインダーパターン — カメラがコードを見つけ、向きを定め、まっすぐするために最初に探す四角 — から離れます。ファインダーパターンを1つでも覆うと、誤り訂正レベルにかかわらず、スキャンが完全に止まることがあります。第二に、ロゴはクワイエットゾーン — コード周りの空白の余白で、規格が全辺に最低4モジュール幅と定めるもの — に決して触れてはいけません。余白ににじみ出たロゴの端は、カメラがコードの端を見つけるのを妨げることがあります。

ロゴが大きくならざるを得ない場合 — 幅広のワードマーク、細かいクレスト — 正直な調整方法が3つあります。行き先を短くすること。データが少なければ、モジュールの大きなゆったりした模様になります。コードを大きく印刷すること。モジュールが大きければ、より多くの損傷を許します。印刷サイズガイドがカード、チラシ、ポスターのサイズを解説しています。あるいはマークを簡略化すること。完全な組み合わせではなくコンパクトなシンボルを使い、完全版はコード周りのパッケージに取っておきます。

ロゴファイルの準備

アップロードするファイルが、小さなサイズでの結果のきれいさを決めます。透明背景の正方形PNGが、中央に最もきれいに収まります。模様と競合する白い箱もなく、無駄な角もありません。長方形のロゴを正方形に引き伸ばすとマークがゆがみます。横長の組み合わせ全体を中央に無理やり押し込むのではなく、バランスの取れた正方形版のシンボルに切り取ってください。

  • アップロードする前に簡略化する。細かい文字や小さなディテールは、マークがコードの中央まで縮小されると消えます。ロゴにタグラインがあるなら、コード版からは外してください。
  • ロゴに白い台座を与える。マークの周りの小さな明るい裏地が、周囲のモジュールからマークを分離し、カメラがロゴの輪郭をコードのデータとして読むのを防ぎます。
  • マークの暗い版を使う。明るいコード上の淡いロゴはカメラを惑わせます。ブランドマークが明るいなら、対照的な白いパネル上に置いてください。

色とコントラスト：ロゴより重要なルール

ロゴ入りコードは、ロゴのサイズよりも色で失敗することの方がはるかに多いです。ルールは決して変わりません。明るい背景上の暗いモジュールで、強いコントラストです。ブランドカラーは歓迎ですが、暗い側がはっきり暗く、明るい側がはっきり明るい場合に限ります。実務ガイドでは、コントラスト比4.5:1以上を出発点として使うことが一般的で、組み合わせが素朴なほど、対応できるスマホと照明の範囲は広がります。

  • グラデーションはリスク。グラデーションの明るい端はしばしばコントラストを失い、スマホは色の露出を違えて捉えます。最も明るい部分がなおはっきり明るく読めるか確認し、画面プレビューだけでなく印刷物をテストしてください。
  • 反転コードは賭け。暗い背景上の明るいモジュールは規格で認められており、最近のスマホのカメラのほとんどは読みますが、古いスキャナーアプリの中には読めないものがあります。読み手が実際に使う端末でテストできない限り、モジュールは暗く保ってください。
  • ファインダーパターンを、見えなくなるほど色を変えてはいけない。3つの角の四角はスタイルを変えても構いません。角を丸めたり、目をドットにしたりしてもたいていスキャンできます。ただ、外側と内側の四角の間の明るい輪を塗りつぶしたり、目をコードのほかの部分より明るくしたりすると、カメラが最初に探すものが壊れます。
  • 忙しい背景は第二の戦い。写真の上のロゴ入りコードは、カメラに背景、ロゴ、模様を一度に分離させます。コードには、クワイエットゾーンを明確にした、きれいな明るい場所を与えてください。

形、フレーム、枠

角の丸いモジュールやドット風のパターンは問題ありません。格子自体が規則正しいままだからです。スキャンを壊すのは格子のゆがみです。四角が四角でなくなるほどコードを引き伸ばすこと、デザインに沿わせて反らせること、小さなボトルのようなきつい曲面に巻き付けることです。均等に拡大縮小し、コードを四角に保ち、曲面が避けられないならより大きく印刷して実際の物体でテストしてください。

フレームや枠は、クワイエットゾーンの外側に属し、決して内側には入りません。角の丸いフレーム、ブランドカラーの枠、「スキャンして」というキャプションは、4モジュール幅の余白の外側にあり、模様に触れなければ、すべて機能します。パッケージの折り目や継ぎ目も同じです。折り目がコードやその余白を横切るなら、コードを平らなパネルへ移してください。

手順

  1. コードを作る。どの種類もロゴと使えます。リンク、vCard、WiFiネットワーク、その他FreeQrlyが提供するすべての種類です。行き先が短いほど模様はゆったりします。
  2. 正方形のPNGをアップロードする。透明背景が最良です。ロゴはコード面積の約30%未満を上限として保ち、安全余裕が欲しいなら20〜25%程度に近づけてください。
  3. 誤り訂正に任せる。ロゴを加えると自動で上がるため、覆われた中央がスキャンを止めることはありません。書き出す前に、ファインダーパターンとクワイエットゾーンが無傷か確認してください。
  4. 印刷前にテストスキャンする。画面だけでなく、印刷物そのものを、iPhoneとAndroidの2台で。両方が一発で読めれば出荷できます。どちらかがためらうなら、ロゴを一段小さくするか、コントラストを上げるか、より大きく印刷して、再テストします。

印刷用には、PNGを最大2048pxまで、またはバナーや展示会の壁用にSVGをダウンロードします。印刷サイズガイドには完全なサイズ表があり、ロゴ入りコードがプレーンなコードの使える2×2cmではなく印刷で3×3cmの最小が必要な理由も含まれています。

ロゴ入りコードの正しいテスト方法

自分の新しいスマホで、良い光で、画面上でテストしても、ほとんど何も証明されません。印刷されたロゴ入りコードは、より悪い条件に出会います。インクの広がり、ラミネートのグレア、薄暗い部屋、古いカメラです。役立つテスト方法は、意図的に厳しいものです。

  • 最終サイズで、最終素材の印刷物をテストする。画面でスキャンできるコードが、光沢ラミネートやざらついたカードでは失敗することがあります。グレアやインクの広がりがコントラストを変えるからです。
  • 最低2台のスマホでテストする — iPhoneとAndroidを1台ずつ。借りられるなら古いスマホも。新しいフラッグシップは多くを許しますが、顧客のスマホはそうとは限りません。
  • 実際の距離と角度で、実際の光でテストする。テーブルカードは座席から、レストランの照明の下でスキャンされます。ポスターは数メートル離れて、場合によってはガラス越しにスキャンされます。
  • デコードだけでなく行き先をテストする。コードは正しいページを開き、モバイルデータでも速く読み込まれるべきです。
  • ためらいを失敗として扱う。スキャンに数秒かかったり、複数回の試みが必要だったりするなら、そのコードはぎりぎりの状態です。ロゴを小さくするか、コントラストを上げるか、より大きく印刷して、再テストします。

コードがどうしてもスキャンできないなら、原因はたいてい元の4つのミスのいずれかです。上限を超えたロゴ、低コントラスト、混み合った背景、引き伸ばされた格子です。トラブルシューティングガイドがそれらを辿り、ぼやけたコードのガイドが解像度を扱います。

ロゴ入りコードが本領を発揮する場所

ロゴ入りコードが余分な手間をかける価値があるのは、コード自体が単なる道具ではなくブランドの表面の一部である場所です。パッケージでは、マークをコードの中に置くことで、パック全体が一つのデザインとして読めます。名刺では、ロゴ入りコードが忘れられがちな四角を認識できるものに変え、名刺は近距離でスキャンされるため、ロゴ入りコードが最も寛容な場面です。イベントでは、バッジやポスターのロゴ入りコードが部屋の向こうからでも認識できます。出展者10社がみなプレーンな黒い四角を持っているときに、それは重要です。メニューでは、ロゴがゲストに、このコードがそのレストランのものだと安心させます。

一括使用こそ、一貫性が報われる場面です。20バリエーションの商品ラインは、すべてのコードに同じマーク、同じ色、同じクワイエットゾーンを持つべきです。アイテムごとに作り直すのではなく、バッチ全体に一度だけ適用します。それらのコードの裏側の行き先が変わる必要が生じたら、動的コードが印刷物を有効に保ちます。印刷後に行き先を編集でき、スキャン統計も付きます。対して静的コードは、登録不要、透かしなし、期限なしです。ホームページや商品マニュアルのように行き先が固定されている場合の正しい選択です。

正直な比較：ロゴ入りコードとプレーンなコード

プレーンなコードは、あらゆる面でロゴ入りコードより寛容です。より小さな印刷、より低いコントラスト、より密なデータ、より粗い表面に耐えます。模様のどの部分も意図的に隠されていないからです。ロゴ入りコードは、その寛容さの一部を認知度と交換します。その交換は、コードがブランドの表面で、印刷が管理されている場合 — パッケージ、カード、ポスター、メニュー — に価値があります。4つの場面では悪い交換です。

  • 極小の印刷。2cmのコードでは、ロゴを入れると模様がほとんど残らず、各モジュールもすでに小さいです。より大きく印刷するか、ロゴを外してください。
  • 密なデータ。長いURLや連絡先カード全体は、すでに密な格子を作ります。その上にロゴを加えることは、二重の締め付けです。まず内容を短くしてください。
  • 過酷な環境。屋外の看板や作業場のラベルは、生き残るために誤り訂正の余裕をすべて必要とします。装飾のためではありません。
  • 管理できない複製。コードがコピーされたり、ファックスされたり、パートナーに縮小されたり、あなたが選ばなかったサイズで他人に再印刷されたりするなら、プレーンなコードの方がその旅を生き延びます。

過剰なデザインに反対する、ブランドの一貫性という議論もあります。1つの簡略化されたマーク、1つの色の組み合わせ、1つのクワイエットゾーンのルールを、ロット全体で繰り返し使うと、システムとして読めます。コードごとに違うロゴの扱いはノイズとして読め、ノイズこそスキャナーが苦労するものです。

ロット全体でのブランドの一貫性

仕組みは一度だけ決めて、あとは繰り返します。同じ簡略化された正方形のマーク、周囲のパッケージの色が変わっても同じ明地に暗地の組み合わせ、同じクワイエットゾーンと最小印刷サイズを、すべての面で。コードがカードとポスターの両方に現れる場合、ポスター版はカード版を引き伸ばしたものではありません。ポスターのサイズで生成された同じコードで、ロゴの割合も同じです。多くのコードを、ロゴをすべてに適用して一括で生成し、ロットを確定する前に、表面の種類ごとに1つずつ校正スキャンします。FreeQrlyの一括モードとAPIがそのワークフローをカバーし、すべてのコードでスキャン無制限です。

知っておきたいこと

ロゴを入れるとQRコードは壊れる？

コード面積の約30%未満に留まるなら、問題ありません。それがジェネレーターの上限で、安全余裕が欲しいなら20〜25%程度に近づけてください。ロゴを加えると誤り訂正は自動で上がるため、覆われた中央がスキャンを止めることはありません。

最適なロゴファイルは？

透明背景の正方形PNGです。長方形のロゴや白い箱に入ったロゴはスペースを無駄にし、模様と競合します。まずマークを簡略化してください。細かい文字やタグラインは、コード中央のサイズでは消えます。

ロゴはどのQRコードタイプでも使える？

はい。リンク、vCard、Wi-Fi、その他すべてのタイプで使えます。同じロゴをバッチ全体に適用することもできます。

印刷にはPNGとSVG、どっち？

ほとんどの印刷物には最大2048 pxのPNG、バナーのように無限に拡大したい場合はSVG。

ロゴはなぜ中央に置かなければならないのですか？

中央には位置決めのデータがないため、覆うのに最も安全な場所です。中央に置くことで、マークは角にある3つのファインダーパターンから離れます。ファインダーパターンを1つでも覆うと、スキャンが完全に止まることがあります。

ロゴ入りコードは印刷でどのくらい大きくすべきですか？

最低3×3cmです。プレーンなコードが使える2×2cmではなく、データ量が多いコードや光の悪い場所でスキャンされるコードならさらに大きくします。印刷サイズガイドに完全な表があります。

ロゴ入りコードは印刷前にどうテストすべきですか？

最終サイズで、最終素材の印刷物を、最低2台のスマホ — iPhoneとAndroidを1台ずつ — で、実際の距離と実際の光でスキャンします。ためらいを失敗として扱います。ロゴを小さくするか、コントラストを上げるか、より大きく印刷して、再テストします。

ロゴを入れない方がいいのはどんなときですか？

極小の印刷、非常に密なコード、擦れたり風雨にさらされたりする表面、またはあなたが選ばなかったサイズでコードが複製される場合です。そのような場合、プレーンなコードの方が寛容です。
