動的QRコードの作り方

動的QRコードなら、印刷後に行き先を変更できます — 何人にスキャンされたかも分かります。無料で、約1分で作る方法はこちら。

2026年10月16日 · 約4分で読めます

静的コードは素晴らしい — 行き先が変わるまでは。チラシは印刷済み、メニューは移転、キャンペーンのURLは確定していなかった。動的QRコードがそれを解決します。印刷した模様はそのままで、どこを指すかはいつでもダッシュボードから変更できます。スキャン数も分かるので、実際に誰かがスキャンしているかも分かります。

FreeQrlyでは動的コードは無料です。ログイン（メール、Google、GitHub）すれば8個もらえます。試用期間なし、カードなし、期限の駆け引きなし。手順は全部こちら。

  1. ログイン — 無料。ログインページを開き、メール＋パスワード、Google、GitHubでアカウントを作ります。静的コードにはこれが決して不要。動的コードには必要です。コードは誰かのものでなければならないからです。
  2. 動的に切り替える。スタジオで、トグルを静的から動的に切り替えます。それ以外 — 種類、スタイル、ダウンロード — はまったく同じです。
  3. 種類を選んで入力する。Webサイト、WiFi、連絡先、予定 — 12種類すべてが動的コードとして使えます。（一括は静的のままです。動的コードは1回に1個。）
  4. お好みでスタイルを整える。ドット、色、ロゴ、フレーム — プレビューはライブで更新されます。スタイルはコードと一緒に保存されるので、ダッシュボードとダウンロードが一致します。
  5. 生成する。「生成」を押します。freeqrly.com/q/XXXXXXXのような短いリンクがもらえます — QRの模様がエンコードするのはこれです。印刷して、送って、壁に貼りましょう。
  6. あとで管理する。コードはダッシュボードにあります。編集、統計の確認、スロットを空けるための削除ができます。

QRコードが実際に含んでいるもの

動的コードはあなたのリンクを直接持ちません。短いFreeQrlyリンクを持ち、私たちのサーバーがスキャナーをあなたの行き先にリダイレクトします。この仕組みがあるから編集と集計が可能になります — そして動的コードにアカウントが必要で、静的コードに不要な理由もこれです。どこかのサービスが「無料」コードにアカウントが必要だと言ったら、それはこの仕組みのこと。ここでの違いは、アカウントが無料で、コードが死なないことです。

制限 — はっきりと

  • 8コード、無料。これが無料枠です。コードを削除すればスロットが空きます。
  • 1つずつ。動的コードは1つずつ生成します。一括生成は静的のままです。
  • 編集で変わるのは行き先で、模様ではありません。印刷したコードはどんな編集を経ても動き続けます — それがすべてです。

そもそも動的が必要か分からない？静的と動的を正直に解説。すでに印刷してリンクの修正が必要？印刷後にQRコードを編集する方法。数字がどう見えるか気になる？動的QRコードの統計が教えてくれること。

動的QRコードの作成は本当に無料？

はい。無料でサインインし、動的コードを最大20個作成、編集して統計も見られます。試用期間もカードも不要です。静的コードはアカウントなしで無料・無制限のままです。

動的QRコードにアカウントは必要？

はい — コードは誰かのものでなければならず、編集できるのはあなただけです。メール＋パスワード、Google、GitHub。静的コードにアカウントは決して不要です。

動的QRコードはいくつ持てる？

無料アカウントで8個。コードを削除すればスロットが空きます。

動的QRコードは何にリンクする？

あなたの行き先にリダイレクトする短いFreeQrlyリンク（freeqrly.com/q/XXXXXXX）です。スキャナーはあなたのページに着地します。リダイレクトがあるから編集と統計が可能になります。

動的コード無制限 — 期間限定オファー。
