QRコードを印刷後に編集する

チラシはすでに出回っている — なのにリンクが間違っている。動的コードなら、再印刷ではなく2分で直せます。

2026年10月16日 · 約4分で読めます

チラシはすでに出回っている — なのにリンクが間違っている。あるいはメニューが移転した。あるいはポスターが印刷に回ったとき、キャンペーンページが確定していなかった。静的コードなら再印刷です。動的コードなら2分で直せます。

コツはこうです。動的コードの模様は決して変わりません。FreeQrlyのサーバー上の短いリンクを指していて、そのリンクが人をどこに送るかはあなたが管理します。行き先を編集すれば、すでに壁やチラシやパッケージにある印刷済みのコピーすべてが、即座に新しいコンテンツを出します。再印刷なし、古いコードの上にシールを貼る必要もなし。

  1. ログインする。ログインページを開き、コードの所有者であるアカウントでログインします。
  2. ダッシュボードを開く。ダッシュボードへ。あなたのアカウントの動的コードはすべて、QRサムネイルとスキャン数付きのカードで並んでいます。
  3. 編集を開く。コードのカードで「編集」をクリックします。作成時に使ったのと同じジェネレーター — 種類、内容、スタイル、全部 — が表示されます。
  4. 必要なものを変更する。行き先、内容、種類まで。WebサイトのコードがWiFiのコードになることもあります。色、ロゴ、フレームもすべて編集できます。
  5. 保存する。「変更を保存」を押します。完了です。印刷したコードは新しいコンテンツを出すようになります。念のためスマホのカメラでテストしましょう。

変更できるもの — できないもの

  • 行き先と内容：リンク、テキスト、WiFiパスワード — コードが持つものすべて。
  • 種類：コードをあるコンテンツ種類から別の種類に切り替えます。模様は気にしません。短いリンクだけを持っているからです。
  • スタイル：色、ドット、ロゴ、フレーム。ダッシュボードのサムネイルもそれに合わせて更新されます。
  • 変更できないもの：印刷した模様そのもの — でも変更する必要は決してありません。模様が持つのは短いリンクだけだからです。コードを別のアカウントに譲渡することもできません。

知っておきたい2つのこと

編集は即座で静かです。「再公開」ステップも遅延もありません — 次のスキャンで新しい行き先が表示されます。古い行き先が取り下げたページだった場合は、まずコードを修正してから、ページを取り下げましょう。

削除は永遠です。コードを削除すると印刷済みのコピーは動かなくなります — 元に戻すことはできません。本当に引退したコードだけ削除しましょう。スロットは新しいコード用に空きます。（動的が自分に合っているかまだ分からない？静的と動的を正直に解説。作成の完全な手順が知りたい？動的QRコードの作り方。）

知っておきたいこと

編集後にQRコードを再印刷する必要はある？

いいえ。印刷した模様は短いリンクを持っています。編集で変わるのは、そのリンクの指す先です。印刷済みのコピーすべてが、すぐに新しいコンテンツを出します。

動的QRコードの種類を変更できる？

はい。ダッシュボードで「編集」を開いて新しい種類を選びます — たとえばWebサイトのコードがWiFiのコードになります。印刷した模様は有効なままです。

QRコードの編集でスキャン統計はリセットされる？

いいえ。統計は同じコードに蓄積し続けます。コードを削除すると、コードと統計は永遠に消えます。

動的QRコードを間違って削除したら？

元に戻すことはできません — 印刷済みのコピーは動かなくなり、スロットが空きます。本当に引退したコードだけ削除しましょう。
