Good to know

Which barcode format should I use?

Code 128 for general use — it holds any text. EAN-13 for retail products sold internationally, UPC-A for US retail, Code 39 when the scanner is old or the code must be human-readable, ITF-14 for shipping cases.

Do I need a check digit?

No — for EAN-13, UPC-A, and ITF-14, enter one digit short and the check digit is calculated for you. Code 128 and Code 39 need none.

PNG or SVG for print?

SVG for packaging and professional print — it scales infinitely with no blur. PNG for office printing and apps that don't accept SVG.

Free, no watermark, no sign-up. The barcode is drawn in your browser — nothing is uploaded.
